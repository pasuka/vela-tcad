# SLOT 5 mV 原生双精度局部列比较

本次仅复用保存数据，新增求解 0 次。固定此前 Vela 分解结果，将原生参考切换到
Sentaurus 64 位第 0 次矩阵，并同时列出旧 80 位参考和本次精度对照中的 80 位参考。
1621 电子列和 10849 空穴列对 64 位参考更接近，但局部差异尚未消失。

## 比较口径

Vg=5 V、Vd=0.005 V，300 K，原点 0 V；SLOT 网格 13881 节点。
原生 T-2022.03-SP2、PARDISO；64 位配置为 `-ExtendedPrecision`。
输入设置见[原生精度报告](slot_ldmos_native_precision_2026-10-10.md)。
Vela 沿用[此前分解](slot_ldmos_crossblock_flux_source_decomposition_2026-10-10.md)
的 `build/s10crossblock/local_decomposition.csv`，不是本次重装配最新 Bank–Rose runner。

按原生 block/node 对齐，将原生 ψ 内部列除以 VT=0.025851995266484913 V，
得到固定人口 ψ 方向的完整物理列，在此前已核对的局部载流子支撑上比较。
不比较稳定化或限幅方向。列差定义为
`norm(J_native - J_vela) / max(norm(J_native), norm(J_vela))`。
绝对值单位为原生装配残差单位/V，不是 A/V 或 A/µm。

原生64位缺少本批配套无电离矩阵，所以以下是完整列，不能直接称为独立电离源导数。
此前源分解说明1621、10849的所选少子列由源项主导，但不能代替64位源项独立分解。

## 状态及精度解释边界

相对旧80位，64位第0次人口变量最大相对差为电子3.43e-13、空穴3.31e-13，
ψ最大差6.71e-14 V。配对80位相对旧80位ψ和空穴逐值相同，电子最大相对差
9.42e-15。所有 block/node 编号一致；没有把这些小差异强行置零。

10849在两份80位参考之间也发生变化，因此近零驱动力导数不仅要核对标称位宽，
还要核对加载、重建及分支输入。现有数据支持局部表示/分支敏感性仍需考虑，
不单独证明某一方Jacobian错误，也不证明全器件矩阵已一致。
零附近的有限步差分和解析分支导数仍须分别比较。

若要把先前25.1%和0.708%的独立源导数结论正式替换为64位版本，需要补同状态
64位有/无电离装配及正负ψ扰动，先确认人口与派生量身份，再作源矩阵相减。
本次没有执行远端任务、修改模型、门槛或账本。
