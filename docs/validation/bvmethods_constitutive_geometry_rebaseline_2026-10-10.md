# BVmethods 本构契约修复、同状态几何与源项复核（2026-10-10）

本轮执行矩阵物理对齐报告提出的四项优先级。已修复前端 Fermi/OldSlotboom/NoFermi
契约，完成两平台新鲜零偏与短程重新基线化；取得原生同一 Newton 更新前的完整派生量和
源项观察数据。Poisson 介电系数及电荷体积得到独立矩阵验证。统计近似、DOS 和源项支撑
仍有已量化差异，**不认领完整 RHS、Jacobian、Newton 更新或原始高压纯 QS 通过**。

机器结果及归档收据见[配套 JSON](bvmethods_constitutive_geometry_rebaseline_2026-10-10.json)。
本记录接续[前轮元素/物理映射调查](bvmethods_matrix_physics_alignment_2026-10-10.md)，
不把旧物理结果转授给新契约。生成数据放在
`build-release/bvmethods_constitutive_rebaseline_20261010/`，未加入版本控制。

## 2. 前端契约修复与新基线

`Fermi + EffectiveIntrinsicDensity(OldSlotboom)` 现在显式发出
`solver.bandgap_narrowing.fermi_statistics_correction=true`。
Boltzmann + OldSlotboom 发出 false；显式 `NoFermi` 覆盖为 false，**仍保留 Fermi 人口统计**。
解析器不再静默丢弃 NoFermi。语句顺序不改变结果；当前全局求解器不支持的材料区域差异仍拒绝。
直接 JSON 的既有 opt-in 默认不变。相应 golden 只增补这项布尔字段。

两平台均重新计算零偏，没有沿用旧物理接受态。完整有限差分雪崩 Jacobian 候选各受
300 秒上限终止，未获得可与 CSV 对应的接受点；保留这些超时，不能将它们归类为已证明的
数学发散。另一个显式控制保留全部物理 residual、冻结雪崩 Jacobian，获得如下新基线：

| 外电压 | 内电压（两平台一致） | 独立保存态审计 |
| --- | --- | --- |
| 0 V | 0 V | 通过 |
| 10 µV | 4.40296905935198 µV | 载流子行、连续性、负载、四端 KCL 通过 |
| 24.1 µV | 10.61115543303828 µV | 同上 |

仍使用原门限：逐行 `eps_row=0.001`、全局连续性 `0.01`（保留 source-floor/qualified
语义）、负载 `1e-6 V`、KCL `max(1e-12,1e-5*abs(Id)) A/µm`。
10 µV/24.1 µV 负载误差分别约 `6.24e-10/-1.65e-10 V`。
T470p 新鲜零偏/短程约 11.14/48.02 秒；C560 约 13.41/64.63 秒。
冻结导数控制不是默认求解路径认证；旧的 0.01 V 短程资格不能移植到本次新本构。

三个原生 frame 的 VAR、matrix、RHS、SOL 与旧运行逐值一致；旧匹配人口探针据此得到身份确认。
不再把更新后的接受 TDR 与更新前 Jacobian 混用。

原生 Save 的 SLP 信息用于构造固定状态 Load/Plot 观察器。首版直接 Load Newton TDR 因缺 SLP
失败；次版 Tcl Plot 别名无效；第三版使用原生内部字段名成功。全部失败保留。
第三版自由节点 ψ/QF 与所选原生 TDR 逐值相同，Save 反算人口相对误差约 `4e-14`。
runtime 顶点 2678 中 78 个为别名；单元全部使用原始 0–2599 节点。

四个固定自由主变量控制分别为默认、NoFermi、DensityIntegral(240)、取消 dEg0。
切换后自由节点 ψ/QF 保持不变，接触 ψ 会按原生边界模型重算；不能误判为自由节点 gauge 漂移。
NoFermi 控制在节点 790 省去约 `0.02047419 eV` 的 BGN 统计修正，
Boltzmann 人口仍为原生 Fermi 人口的约 1.84 倍，证明 NoFermi 不等于 Boltzmann。

两项剩余本构差异得到独立控制支持：

- 原生电子 DOS 为 `2.8582520073866568e19 cm^-3`，旧 C3 为
  `2.8566791451911786e19`。原生 `dEg0=-0.01595 eV` 同时进入电子 DOS 质量公式的
  Eg(0)/Eg(T)；取消 dEg0 后测得 Nc 比值 `1.000559647429619`，公式预测吻合至约 `2e-16`。
  当前 C3 仅把 dEg0 折入 ni，质量公式和输出 BandGap 未包含该偏移。
  纳入质量偏移后仍约 9.05 ppm 的 DOS 前因子差异，不能通过改全局常数强行抹平。
- 默认原生使用快速 Fermi 统计近似。使用原生 DOS、ni、带边和 Vela 精确 Fhalf 反函数，
  电子 QF 最大误差约 `0.305 mV`；原生启用 DensityIntegral(240) 后降至
  `3.55e-14 V`，空穴约 `1.10e-14 V`。这支持统计积分近似差异，而非矩阵索引错误。

原生带边与 DOS/ni 参考关系闭合至约 `2e-15 V`；旧 C3 的匹配人口 QF 仍有电子约
`0.192 mV`、空穴约 `0.178 mV` 的差异。本轮没有悄悄替换 C3 物理常数或全局统计近似。
固定状态模型隔离不代替新模型的 PDE 重求解资格。

## 4. Poisson 及源项几何支撑

从 `BoxMeasureFromFile/BoxCoefficientsFromFile(GrdNumbering)` 捕获全部单元原生 Measure/κ，
以原始 grid element ID 匹配；边次序 `(0,1),(1,2),(2,0)`。
新辅助脚本只读这些数据，不将它们注入生产配置。

- 按材料 εr（Si 11.7/SiO2 3.9/Nitride 7.5）装配 `epsilon_r*kappa`，
  与原生 ψψ 行归一化后的最大误差 `3.13e-15`。
- 半导体 Measure 之和除以介电对角，能预测全部自由半导体节点的 ψ–n 电荷系数，
  最大相对误差 `6.66e-15`。只在一个体节点固定公共单位比例，**不是绝对单位认证**。
- 节点 129 原生 Si 体积 `3.232955932617187e-6 µm²`，Vela 全材料重心体积
  `6.552124023437499e-6 µm²`；旧电荷系数约两倍的差异由此获得具体解释。
- 原生单元 Measure 总和/单元面积约 `0.515–2.260`；不能要求每个单元单独面积守恒。
  非钝角邻域的 κ 也可能受盒重分配影响，不能仅修正 26 个钝角单元后宣称全图匹配。

当前 Vela 默认 SRH 用全材料重心节点体积，E2 BTBT 默认在半导体单元计算场并三等分源项；
电离为 SG 边源映射。三个路径的支撑分别审计，未作一项统一体积替换。
以原生 Si 盒体积作几何参照，55 个自由界面节点的 Vela SRH 体积比为
`1.458–2.028`，半导体重心体积比为 `0.667–1.333`；接触和钝角邻域另列 CSV。
这些只是体积因子，不能将原生绘图的节点 generation 直接当作完整 element-vertex 源积分。
Vela E2 是固定 A/B 的场强模型，没有带隙输入；DOS/dEg0 差异不证明 E2 存在相同的带隙依赖。

随后在首个非零更新前 Save 上分别关闭 SRH、BTBT、雪崩，仅计算一次原生 Newton 装配。
四组均退出 0；四组 debug 主变量逐值相同。Save 人口与原更新前 frame 的相对差约
`3.55e-14`，不能将高掺杂密度的绝对数值差误读成状态改变。
三个源控制都保持 Poisson/电阻 RHS 不变；关闭 SRH 或 BTBT 后非局部同载流子输运系数
逐值不变，支持对源项差分作解释。关闭雪崩会改变非局部交叉项，不能按局部 SRH 处理。

使用**原 VanOverstraeten 模型**的 `before_des.tdr` 节点源速率，核对
`delta_RHS / (rate * native_Si_box)`。以中位数公共原生比例约 `6.74565787e-19` 为参照：

| 空穴行源控制 | 非弱速率且相减误差估计小于 1 ppm 的节点数 | 比例最大相对偏差 |
| --- | --- | --- |
| SRH | 1451 | 约 `5.6e-7` |
| BTBT | 130 | 约 `6.4e-5` |
| 雪崩 | 879 | 约 `2.8e-6` |

这是几何支撑的独立交叉验证，不是 C++ 源公式或完整 RHS 认证。电子行仍存在明显尾差，
完整输运与微小源相减即使超过 64 ULP 也不保证高相对精度；全部行及相减条件数另存。
1 ppm/非弱速率分组用于描述可分辨性，不改变验收门限。
最初把 alpha=1 观察器的电离速率用于原模型源差分的对照已作废并以
`source_controls_analysis_v1_mismatched_pmi.json` 保留；最终分析仅使用原模型速率。

## 5. SG 电流与局部迁移率

复用 SLOT 已验证的原生 PMI 观察入口，以 alpha=1 的诊断回调取得原生 Eparallel 与
不含迁移率的电流向量；只执行固定状态 Load/Plot，不进行该 PMI 下的 Newton 求解。
原始源模型下的源项隔离另行执行，不能把 alpha=1 观察器当成原 VanOverstraeten 模型。

已经导出每个半导体单元的迁移率、单元电流以及节点字段。单元迁移率不等于最大盒体积
顶点值，也不等于三节点算术平均；生产边迁移率需要明确支撑映射，不能直接相减。

同状态候选采用有效带边 SG、两条代表顶点边重建二维源电流，并与广义 Einstein 因子控制、
界面投影控制比较。首个非零状态，代表顶点候选电流相对误差中位数约电子 `1.27e-5`、
空穴 `1.62e-7`；但 P95 分别约 `0.0327/0.940`，最大值约 `21.94/43.23`。
匹配根据坐标和最小误差选择候选，可能多义，属于乐观诊断；这些尾部误差不能掩盖。
这里的 major 阈值（峰值电流的 `1e-8`）只是描述性分组，不是新增验收门限。
微小偏置下带/不带 Gg 候选几乎相同，**没有足够激励判定原生采用哪一条广义 SG 分支**。
补充全部代表顶点、直接双精度 Bernoulli 相减控制及逐源 RHS 隔离，结果见配套 JSON。

全部代表顶点控制消除了坐标未匹配点，但首点 P95 仍约电子 `0.0231`、空穴 `0.739`，
最大值约 `7.84/18.68`。直接双精度 Bernoulli 相减结果相近，不能单独解释这些尾差。
全部顶点按最小误差选择更加乐观，也没有形成唯一单元/分支识别或 SG 源核资格。

Vela 当前 Eparallel 使用三边单元最小二乘电流并向边平均，与此两边代表顶点候选并不相同。
SLOT 的网格、PhuMob、统计积分和精度配置不同，其 ppm 源积分结果不能移植为本例资格。
