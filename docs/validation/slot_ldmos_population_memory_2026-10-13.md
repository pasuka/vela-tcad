# SLOT 浓度有限步单进程优化复验（2026-10-13）

## 结论

新增显式 `simulation_type: slot_population_memory`，在一个进程内完成单个漏压目标的连续重线性化。没有更改默认 Newton，也没有启动新的漏压长扫描或割线外推。

在 Vg=5 V、Vd=5 mV 和 12.1 mV 的同一旧冻结初态上，新循环分别通过 4、7 次更新取得与旧流程完全相同的终态字段数组、逐步残差、行比超标行数及四端口电流。原始更新误差的求和顺序造成约末位舍入差，没有改变接受判断。

## 固定条件

- 本机 UCRT64 Release；13881 节点、41643 维完整审计矩阵；PARDISO `pardiso_mkl_eliminated`、单线程。HDF5 和 UMFPACK 在构建中启用，本批数值复验使用 PARDISO。
- AverageBox、定义积分 Fermi、effective-band SG、原目标电离/复合/迁移率及材料配置保持不变。
- 浓度负提议投影比例 0.001；电势按 0.0259 V 对数阻尼；相对参考/增量 QF 恢复。载流子正则化和闭合方程替换关闭。
- 接受：RHS≤1e-10 **或**原始物理归一化更新 RMS<1，加真实闭合、边界、正性、逆映射和混合线性误差保护。行比只报告。保存态 RHS 单列；保存态残差一致性仍必须通过。
- 内部人口单位沿用 cm^-3，HDF5 为 m^-3，电势/QF 为 V，端口电流为 A/µm。
- 更新误差支持集单独绑定：13881 个 ψ、各 12634 个电子/空穴节点，不能以 DOS>0 节点集替代。这是误差统计支持，不是线性消元后的自由行集合。

## 性能和输出

|目标|旧批次总记录|新单进程复验|观察到的减少|旧/新迭代核心累计|
|---|---:|---:|---:|---:|

这些是同机不同时段的墙钟观察，不是严格受控的性能基准。旧总时间包含种子生成和单独边界探针（5/12.1 mV 分别 6.29/5.07 s）；新循环从已有相同种子开始，在首次 Poisson 评估中复用边界检查。新入口仍保留终态完整矩阵、行明细和端口审计。中间还有一轮与编译重叠的 12.1 mV 验证（327.69 s），不用于上表。

常规更新仅写小 JSON；不再逐次启动探针进程、导出矩阵、解析 Matrix Market/CSV 或调用外部逆 Fermi 程序。矩阵输出从每步一次改为退出时一次完整包（physical/regularized/stabilized）：本两点分别从约 89.54/156.74 MB 减为约 67 MB。两项稳定化关闭时保留三份矩阵是为审计分层完整，不是三次不同求解。

同一个 NewtonSolver/已加载网格和材料数据库复用；当前/下一次更新共享内存中的人口及行诊断。底层线性装配、受约束残差/行诊断和冻结物理闭合仍保留各自的装配口径，并未全部融合成一次装配，也没有改变不同边界口径来追求速度。因此优化后装配与物理检查仍占主要时间。

## 实现与运行约束

- `src/tools/SlotPopulationMemory.inl`：单目标循环、初始边界检查、相对更新、在线保护、退出审计。
- `include/vela/solver/SlotPopulationNumerics.h`：相对 Fermi 逆及长双精度累积的在线混合线性误差。
- `docs/config_schema.md`：入口选项、支持集与期限约束。
- 常规 `validation_snapshots=false`；仅配对测试可显式逐步保存。
- `final_matrix` 是最后一次更新所用矩阵，属于 `final_matrix_parent.h5`；不能当作已更新终态重新装配的 Jacobian。
- max_updates 1–40、soft_seconds≤1080；软截止在更新之间检查，外层仍应设独立硬截止。配置与统计支持集随输出保存，输入文件/runner 哈希由外层绑定。
- result.json 与退出码是完成依据；progress.json 是中间快照。

## 限制

这些是已知目标的复验，不增加生产偏压点，不证明低密度 QF 的原生一致性，也不证明高漏压路径可达。未改变物理、门槛或默认求解器，未连接远程，未恢复计时器。后续扫描可显式调用该单目标入口；两点外推仍需独立验证。
