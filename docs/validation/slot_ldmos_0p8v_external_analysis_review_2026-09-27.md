## 2. 数学和推理上的修正

1. **密度坐标变换不自动改变精确 Newton 线性方向。** 对固定 ψ，若 D 可逆且
   `(Jcc D)δd=-rc` 精确求解，则 `d=Dδd` 满足 `Jcc d=-rc`。
   冻结 W 后，对未裁剪方向有
   `(Wrc)^T(WJcc d)=-||Wrc||²`。
   这并不保证实际计算下降：非线性密度映射、耗尽裁剪、QF 限幅、有限精度、
   不一致导数和有限回溯范围都可能破坏所需条件。应分别测量。
2. `raw_step_norm` 是转换后的 QF 方向整体范数，不是密度相对变化最大值。
   不能从范数 1e6 直接断定“某个 δn/n 为 1e6”，更不能推出该分量属于热点。
3. `flux=-flux_abs_sum` 在输出离散项口径下支持单向贡献签名，
   但不能独立确定最终平衡密度必须上升多少个数量级，也不能排除相邻状态/场改变。
   所谓“只能升 6–11 个量级”的目标不是已经求出的根。
4. **不能排除残差评估噪声。** 某行最终值约 1e-15，不代表构成它的中间项也是
   1e-15；误差受相消、指数/QF 重构、源项及邻接项求和影响。
   `epsilon*最终残差` 不是可靠误差界。
5. 冻结部分导数后若候选改善，只说明另一线性化方向改善了该次路径；
   它同时改变线性系统条件，不能据一次结果证明“迁移率假谷成立且基本排除线性精度”。
6. Sentaurus 的 `ErrRef` 不能单独解释成“低于该密度的行根本不做收敛要求”。
   需要结合实际误差归一化和其他停止条件；它与本地逐行 flux/source 比值不是
   同一种指标。可以说验收口径不同，不能简单宣布单一指标构成严格包含关系。

## 5. 第二轮补充：649 的累计限幅预算（同日零重算核实）

用户补充的累计上限思路成立，但应将“接近上限”与“实际触发限幅”严格区分。

代码前提核查：

- `clampQuasiFermiStep` 按净掺杂符号分类；649 的净掺杂为
  `-3.0945545956828e13 cm^-3`，电子为少数，实际 cap 为 `min(0.1,0.05)=0.05 V`。
- 当前模式为 `componentwise_poisson_recorrect`；动态 trust multiplier 的扩张/收缩
  分支要求 `uniform_trust_region`，故本路径的 multiplier 保持 1。
- Poisson 重新修正只替换 ψ 分量；当前 `max_update=0`。
- 每步后续 QF 投影模式是 `linear_qf_projection` 才执行，本配置不是此模式。
  配置的 `final_linear_qf_projection` 只有局部行已经通过且闭合失败时才适用；
  本次局部行未过，且最终线搜索失败返回，未经过该修复。
- 历史中恰有 35 个接受更新；线搜索状态为 `x+alpha*step`。
  因此对本次初末态比较，可以使用如下累计上限（忽略数值舍入量级差异）。

令 `s_k` 为第 k 步经过限幅、尚未乘阻尼的 649 电子 QF 更新（V），
`c=0.05 V`，`alpha_k` 为接受阻尼，则：

```text
|s_k| <= c
Delta_phi = sum(alpha_k*s_k)
A = sum(alpha_k) = 13.30078125
B = c*A = 0.6650390625 V
Delta_phi = 0.6488550597391608 V
Delta_phi/B = 0.9756645832201184
D = sum[alpha_k*(1-s_k/c)] = A-Delta_phi/c = 0.32368005521678533
```

这是**阻尼加权的同向上限占用率 97.566%**，不是限幅触发次数比例。
例如所有 `s_k=0.97566458*c` 都未触发裁剪，也能产生相同累计位移。
故“只能几乎每次都被限幅”仍需撤回，限幅是否激活需原始分量或裁剪标记。

比“长期同向”更精确的可证明结果：对任意 `t<1`，

```text
sum(alpha_k for s_k/c <= t) <= D/(1-t)
```

从而非正向步骤的阻尼权重至多占 `D/A=2.434%`；
低于或等于一半正向上限的步骤权重至多占 `2D/A=4.867%`。
这些是权重比例，不是 35 次更新中的次数比例；很多晚期小阻尼步骤仍可能偏离。

前六步 `alpha=1`，每个亏损项非负，所以每步都有
`s_k/c >= 1-D = 0.676319945`；前六步的平均更新至少为
`(1-D/6)*c = 0.0473026662 V`，即正向上限的 94.605%。
它确实把密度塌陷方向的显著 QF 更新定位到了早期六步，
但不等于这六步都触发了裁剪，也不证明限幅是造成错误方向的根因。
密度变化还包括 ψ 变化，不能把 QF 预算直接当成全部密度变化的归因。

6841 的 `|Delta_phip|/0.05 = 9.00388697286`，前 12 次累计阻尼为 `9.0`。
二者接近但不相等，差约 `0.000194349 V`；不足以确定“前12步触顶、随后不动”。

邻接分类也已核实：649 的电子邻居中 609/611/647 是受主占优，
648/650/651 是施主占优。因此此局部确有 0.05/0.1 V cap 的离散切换。
这只是实现和场分布事实，尚未证明 cap 切换造成了本次阻塞。

## 6. 修复计划边界的补充

P1/P2/P3/P4 顺序可采用，但以下边界应保留：

- P1 的回归验证“失败记录完整、可恢复数值失败进入现有缩步、证据门槛保留”，
  **不要求阶段切换**。密度→QF 的事件切换属于 P4；否则 P1 又混入算法变更。
- P1 首先需要可靠的失败协议与绑定。完整最差行和方向诊断可以按需开启，
  不必为了错误分类在每个成功候选上增加大规模输出。
- 单节点残差扫描只定位“其他变量固定时这一标量方程的零点/非单调性”，
  不提供完整耦合器件的真实根。约 10 点也不能保证捕捉狭窄或分段行为。
- 某列方向差分与 Jacobian 一致，可排除该状态、方向及差分分辨率下的明显问题，
  不能单独证明整个 Jacobian 正确或多变量 Newton 方向的异常属于物理模型性质。
- 修复、重编译和更小步长续算尚未执行；当前文档新增内容仅为离线定位证据。
