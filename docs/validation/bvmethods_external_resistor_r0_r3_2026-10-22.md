## R0：旧扫描最终结果

[此前报告](bvmethods_vm_full_bv_attempt_2026-10-21.md)的“仍在运行”已被本次最终证据替代。
外层归档作业退出 0，但完整扫描子进程退出 124，触发了 3600 秒超时。必须读取子任务状态，
不能将归档成功当作科学计算成功。

- 首个非零接受外压为 1e-5 V，内压约 4.97588420843e-6 V，说明扫描确实尝试并通过了最小步。
- 主曲线共有 34 条完整记录（含零偏）和 1 条被中断的不完整记录。最后完整记录为外压
  0.00060526461948948054 V、内压 0.00030202476123710956 V，负载误差约 −8.90950e-8 V。
- 后续边界试探账本还存在更远的设备解，但不得将它们自动提升为完整主曲线接受点；尤其不补齐
  被超时截断的 CSV 字段。当前仍无完整 Vela BV 或击穿电压结果。
- 固定原生首点内压 0.0052443724904 V 的控制退出 1；4 次更新后有 371 条违规载流子行，
  最大行比值 1.90513，电子／空穴全局闭合分别约 0.007796／0.004366，失败为
  `carrier_row_convergence_line_search_rejected`。因此问题并不只在外电阻初始内压预测。

[R0 契约](contracts/bvmethods_external_resistor_r0.v1.json)明确使用 drain、1e7 Ω·μm、电流 A/μm、
外压目标 100000 V、初／最小／最大外压步长 0.01／1e-5／2500 V 和停止电流 1.3e-3 A/μm。

## R1/R3：实际修改

当前前端默认仍为 nested_scalar；本轮没有更换默认 profile。

1. `sweep.step_growth_mode="newton_iterations"` 现在允许纯 Newton 的
   `external_circuit.solver="coupled_newton"`。传递真实增广更新次数，增长预算使用
   `external_circuit.max_iterations`，而非初始化设备求解器的预算。外压增量仍由已有
   `coupled_*outer_step_V` 和 `coupled_outer_growth_factor` 配置；fixed 默认不变。
2. 增广分支接入已有停止电流／停止条件检查，包括自适应中间接受点和显式目标之前的停止。
   原来该分支没有接入这一停止回调，可能在达到电流条件后继续扫描。
3. 对不能在当前浮点数位置产生变化的步长报错或记录 `step_not_representable`，避免空转。
4. 继续使用已接受状态更新预测历史；失败候选不成为种子。已有状态保存测试不等同于已经实现
   完整预测历史／自适应步长／缓存状态的跨进程恢复，本轮不认领严格 L2。

配置说明已同步到[配置 schema 文档](../config_schema.md)。生产载流子门、全局闭合、QF 保护和
线搜索接受逻辑没有替换；未启用 E2/E3 接受策略实验。

## R2：真实方向和阻断

增广审计增加实际可表示的 `trial.x-parent.x` 和 `trial.v-parent.v`，保留完整行向量：

```text
F + J δraw + Fv δvraw
F + J Δapplied + Fv Δvapplied
F(trial)
```

负载行独立记录线性预测和实际残差。分量后向误差在原始矩阵尺度上累加；审计不参与接受。
该误差目前使用 long double，Windows 与 Linux 的有效位数不同，不能将其声称为跨平台高精度
求值的最终契约。两端均保存二进制输入／输出及编译配置。

实际 VM 检查使用既有私有无 BTBT 装配库、2600 节点／5020 三角形、300 K，
Linux Release `-O1 -DNDEBUG`。T470p 使用独立工作树快照、UCRT64 GCC 16.2 Release，单线程；
HDF5/HighFive、UMFPACK、SPQR 均由配置输出确认。直接增广路径首先使用 Eigen SparseLU，
“环境有 UMFPACK”不能证明这次增广求解使用了 UMFPACK。

对象为原生前五个非零接受点中的第 1、5 点，**不是完整 BV 轨迹的终点**。原始冻结态在标量
增广容差内零更新退出，只能作为输入控制。随后增加 1 mV 外压，运行一次增广更新以取得非零
方向；这个诊断不认领生产物理门接受，也不是从零推进的资格运行。

| 指标 | 第 1 点 | 第 5 点 | 判断 |
|---|---:|---:|---|
| 分量后向误差 | 2.81420e-8 | 1.90549e-8 | 均未通过 1e-10 |
| 单档端口 Jv 相对差 | 1.01869e-6 | 1.60247e-5 | 第 5 点未通过 1e-5；三档另列 |
| 全步负载实际残差 V | −3.74015e-10 | −4.78302e-10 | 负载闭合不能代替设备接受 |
| 全步设备残差最大值 | 2.02720e-5 | 7.26983e-5 | 全步被拒绝 |
| 实际采用 alpha | 0.5 | 0.25 | 保持原 merit 策略 |

原始线性方向与实际写回方向的预测设备残差均很小；全步实际余差最大位于 Poisson 行 1136。
第 1 点全步／半步非线性余差约 2.02720e-5／5.06917e-6；第 5 点全步／半步／四分之一步约
7.26983e-5／1.81834e-5／4.54695e-6，接近步长平方缩放。这支持继续分离 Poisson 曲率和弱行
线性精度，而非把所有全步拒绝都归因于外压步长或独立电阻方程。

两态的 off 重复结果与 audit-on 的最终向量哈希、内压、迭代次数、试步次数及退出原因一致；
父态 R/J 哈希在诊断前后不变。这是本次有限回放的无扰动证据，不替代完整 Newton 历史 L2。
