# 原生15帧J/RHS的Vela三层重放（2026-11-04）

## 结论与边界

15个冻结快照均已通过Vela生产CoupledLoadLineNewton的直接增广求解路径返回原始方向；合成已知解预检通过，实际后端为MKL PARDISO。逐帧重置，不是自主连续Newton或BV扫描。

三层结果必须分开：

- 线性层：原生自由方向与重新求解方向并非逐位一致。下述固定权重最大差为1.25674194498e-4；15帧均未达到预先设置的1e-8比较目标。它不是生产线性门，也不是逐分量自然相对误差，不据此直接判线性算法错误。
- 写回层：直接输入原生方向，15帧的生产保护后状态均在1e-8比较目标内；重新求解方向再写回，14/15在该目标内，首帧最大8.30396348644e-8。均不授予逐位相同资格。
- 停止误差层：原生pre/raw/post重建E、原生方向经生产写回后的E、重新求解方向写回后的E，15帧均落在相应原生日志的打印区间；E<1分支逐帧一致。这不证明所有停止分支或后续自主轨迹等价。

原生导出raw对其自身导出J/RHS的分量后向缺陷最大4.36704234772e-8，是参考数据自身的一项限制。不能假定导出方向是导出矩阵精确解，再把全部前向差归因于Vela。尚未唯一分离原生导出/内部求解与Vela线性计算的差别；没有通过修改门限取得一致。
