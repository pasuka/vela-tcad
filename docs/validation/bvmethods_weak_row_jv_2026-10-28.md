# BVMethods：电子尾部形成前的候选进展与弱行导数

日期：2026-10-28。承接[完整扫描停滞定位](bvmethods_stable_population_failure_2026-10-27.md)。
数值摘要见[配套 JSON](bvmethods_weak_row_jv_2026-10-28.json)。
本轮在 T470p 与 C560 编译并执行有界诊断，没有重启完整 BV 扫描。

## 结论

尾部路径的问题在首次局部 1% 回退后已经出现。整体设备残差下降时，节点384的
电子行残差反而增大，其自身人口列导数由正变负。有限差分支持这个负斜率；
分项对照表明主要贡献来自输运迁移率导数，AV 的贡献较小。
因此不能将其简单解释为 Jacobian 的符号装配错误。

另一个独立问题是近似矩阵的减法消去精度：从完整矩阵减去实时迁移率及 AV 导数，
会丢失极小的冻结输运系数。两台机器均复现。该现象说明近似矩阵的构造需要修正和
重新验证，但本轮没有证明它是此前线性后向误差失败的唯一原因。

候选排序、局部正值保护和停止尺度的问题仍然存在：原物理门通过不代表每个弱行
平衡，也不代表尾部状态适合下一偏压。没有据此放宽原 RMS、线性后向误差或物理门。

## 配置与检查口径

- 300 K；同一 2600 节点网格，2152 个 Si 节点；R=1e7 Ω·μm。
- BTBT 关闭，Joyce–Dixon／OldSlotboom，原迁移率、SRH、GradQF AV。
- Release、PARDISO 单线程；完整系统7801维，核心默认约束消元后6765维。
- relative_population 列缩放、自动导数恢复、六项求值复用，预测内压 report_only。
- 两机冻结源码清单 SHA256：
  `a574309de35bcb4837069c34fc0e7651a558f65da223c52b5141dc7b5f41a193`。
  清单含6066个文件，部署前后核验；相同固定输入状态分别校验哈希。
- 四个固定状态：尾部前接受态、首次尾部接受态、失败末态、同目标健康成功态。
  另检查各机器自身回放的第1、6轮入口；这些回放入口不要求跨平台逐位一致。

新增未安装的 `vela_bvmethods_population_jv_probe` 目标；已有有界驱动增加可选
`diagnostic_iteration_states`，默认 false，记录更新前及候选 HDF5 状态和分块 RMS。
生产求解路径没有接入新的保护、限幅或接受策略。

对电子人口采用

\[
D_{n_i}F_r=\left.\frac{dF_r(n_i(1+h))}{dh}\right|_{h=0},
\]

固定其他人口、电势及内压，用同一统计反函数反解 QF；其切向量与解析 Jacobian
相乘比较。另对节点675检查空穴人口列和固定人口的电势列，电势扰动为 h·VT。
扰动 h=0.1、0.01、0.001、0.0001，同时记录正、负单侧及中心差分。
每个方向的零扰动也执行相同反解，避免把状态序列化误差当成导数。
T470p零扰动反解引起的全局RHS变化上界约4.73e−15；有限差分的基值与解析矩阵
均在同一个反解后的零扰动状态重新计算，没有直接以原序列化状态作差分基值。

分别评估 full、关闭 AV、关闭 SRH、仅输运四个同态分项控制。
这些关闭模型的分项 RHS 当然不同，只用于隔离贡献；另做的完整／近似矩阵对照
保持完整物理 RHS 不变。表中残差和导数均为方程内部单位，不能当作 A/μm。

## 第一次回退已改变弱行响应

下表来自 T470p 自身回放，固定目标外压0.7562717828569232 V。

| 状态 | n384，cm⁻³ | 电子行 F384 | Dn384 F384 |
|---|---:|---:|---:|
| 第1轮更新前的预测态 | 8651.28015 | −1.092881e−15 | +9.947807e−14 |
| 第2轮更新前，即首轮局部保护后 | 86.51280 | −3.025133e−14 | −1.372721e−15 |
| 第3轮更新前 | 0.865128 | −1.219432e−13 | −7.923206e−15 |
| 第6轮更新前 | 8.651280e−7 | −3.826120e−13 | −1.197166e−14 |

首轮后负斜率的中心差分相对差约2.64e−7（h=0.001）。
它是整个有限更新后的状态响应；不能只凭一个对角系数推断耦合 Newton 方向。
该节点首次非正候选来自完整耦合方向，而非单行 −F/J 的独立标量更新。

回放第3轮原物理门已通过，但 RMS=562.217，尚未达到联合停止条件。
随后仍有多轮局部1%回退。T470p第13轮联合门通过，n384≈7.370318e−21 cm⁻³，
RMS=0.950758；第11轮曾改选全局到边界步，不能将这段轨迹描述为13次连续局部回退。
同期整体设备残差∞从第1轮后的0.00393737降至2.36229e−10。
这些整体指标的改善没有阻止节点384的局部失配增大和浓度尾部形成。

在稀薄 Boltzmann 极限、固定材料条件下，n缩至1%对应
Δfn≈Δψ+VT·ln(100)。记录中的 Δfn 后期约为0.11905286 V，
并未随人口绝对值减小而消失。该 QF 变化继续改变单元 GradQF、迁移率及 AV，
所以人口 RMS 的参考浓度分母不能代替算子进展诊断。

## 固定检查点的解析／有限差分对照

以下为 T470p 完整 RHS 的自身电子列，C560独立复核相同固定状态。
相对差为解析导数与中心差分之差，分母取两者绝对值的较大值。

| 状态／节点 | 解析人口列导数 | 中心差分相对差 | h |
|---|---:|---:|---:|
| 尾部前／384 | +5.523542e−14 | 8.08e−10 | 1e−4 |
| 首次尾部／384 | −2.276690e−15 | 3.21e−9 | 1e−4 |
| 失败末态／384 | −1.533949e−16 | 3.75e−9 | 1e−4 |
| 失败末态／542 | −1.587792e−28 | 2.59e−5 | 1e−2 |
| 失败末态／666 | +2.289005e−12 | 1.79e−10 | 1e−4 |
| 失败末态／669 | +6.721655e−11 | 2.36e−10 | 1e−4 |
| 失败末态／675 | +9.711617e−11 | 2.17e−11 | 1e−4 |

首次尾部节点384的纯输运导数为 −2.150520e−15，AV贡献约 −1.261697e−16。
完整导数的正、负单侧相对差最大约4.91e−5（h=1e−4）。
冻结迁移率后，该节点的输运系数接近消失，说明变号主要来自迁移率对 QF 场的响应。
代码中单元输运可写成 Σ μK SKi，导数同时包含 μK·dSKi 和 SKi·dμK；
后者不受一个极小本节点人口简单线性抑制，可能改变局部单调性。

失败末态542的完整 RHS 主要由约−9.37942e−19的SRH项组成，而待测导数仅约1e−28。
小扰动下完整 RHS 差分受浮点消去影响，因此不能用更小 h 必然更准作判断。
关闭SRH的同态控制中，h=1e−4的中心相对差约1.40e−10；正、负单侧相对差约4.96e−5。
这支持小导数本身，但不表示该行已平衡。该节点 −F/DnF 的孤立标量估计约−5.91e9，
只用于说明局部刚性，不能替代实际耦合 Newton 方向。

同目标健康态中，384、542的自身人口列分别为正的6.176104e−13、4.300858e−15。
结合以前健康路径四步通过的控制，说明目标偏压本身并非不可求解。

## 近似矩阵相减精度

另用固定状态、相同核心库作六个单步矩阵控制，并直接导出冻结输运分块。
同一状态各控制的完整 RHS 文件哈希相同。以下表格是原 QF 坐标的矩阵系数，
与上表人口列的符号和尺度不同，不应直接混用。

| 失败末态节点542的 QF 自身列 | T470p | C560 |
|---|---:|---:|
| 实时输运 | +1.303852e−28 | +1.303852e−28 |
| AV | +2.839400e−29 | +2.839400e−29 |
| 完整矩阵 | +1.587792e−28 | +1.587792e−28 |
| 直接装配的冻结输运 | −1.631192e−123 | −1.631192e−123 |
| 从完整矩阵减去迁移率／AV导数构造的近似系数 | 0 | 0 |

当前诊断驱动使用 `Jfull + (Jfrozen_transport − Jlive_transport) − Jav`。
约95个数量级的跨度使微小冻结项在相减时消失，不能靠多做一次线性精化恢复。
这一结果没有完整量化SRH等剩余分块的直接装配，也没有证明改为直接分块装配后
必然通过原线性误差门或完整BV；这些必须作为下一项独立控制。
直接分块得到的极小系数本身也须用冻结模型差分或稳定解析形式核验。
本轮完整RHS的有限差分支持完整导数，不等于核验了每个极小近似系数的相对精度。

两机分别确认去除新增诊断字段后，记录开／关的全部迭代记录相同。
跨平台轨迹不逐位一致；固定输入状态的导数与分项结论一致。
每机主扰动实验包含24组状态／物理分项、9216条行响应记录。
96个固定状态自身电子列导数的跨平台最大相对差为4.24e−16。
两机人口反解最大相对误差均为6.23e−14，相关CTest均无失败或跳过。
各机2304组方向／观测行组合中，1890组为严格零响应，397组达到本轮差分
分辨率估计，另17组未据此确认导数；不能把这些数量当作完整矩阵的通过率。
同态分项测试不构成新的生产物理模型。

差分噪声估计依据已记录项量级，是诊断估计而非严格误差界。
大量结构零或低于差分分辨率的交叉条目未被当作通过；单节点列检查也不构成整个
Newton方向、全部矩阵条目或与Sentaurus原生算子的一致性证明。本轮没有重跑Sentaurus。

建议下一控制先从保留的冻结／实时分块直接构造近似矩阵，保持完整RHS不变，
核验原后向误差门及完整方向；再在首次回退前比较带局部行进展记录的候选选择。
不要以新的密度下限、固定QF限幅或放宽停止条件替代这两项验证。

row_nodes、directions（kind/node）和 relative_steps；输出逐项ledger、人口场、
