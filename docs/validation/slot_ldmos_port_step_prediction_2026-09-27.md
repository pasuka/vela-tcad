# SLOT 外电阻步长控制与离线预测（2026-09-27）

本次完成低改动版本及保存态离线核验，未启动求解器，未修改旧运行目录、
物理配置、验收门槛或监测状态。完整 Jacobian 切线及伪弧长未实现。

## 实现与边界

- `scripts/slot_loadline_step_control.py`：默认关闭，由 campaign 的
  `--port-step-control` 启用；外压上限、接受态内压增量上限、内压试探上限
  分别为 `--outer-max-step`、`--accepted-inner-max-step`、`--trial-inner-max-step`。
  默认分别 0.2、0.2、0.1 V；旧模式不变。耦合分支的第三项作用于内压更新上限，
  标量分支作用于器件试探步长，两者都不同于最终接受态增量。
- 最新三个同参考系、间距大于 1e-6 V 的合格点，按 1/2/3 权重线性拟合
  `g=dId/dVinner`，并核对两个相邻割线斜率。负斜率或相邻斜率相差超过两倍
  时停用电阻增步，不把负值裁剪后解释成正微分电导。此策略不支持回折支路。
- 对一致正斜率，用拟合/割线中的最小值计算内压预测限制，最大值计算电流
  预测限制；候选外压步长还受用户上限、下一步反馈、目标剩余距离约束。
  这两个斜率包络只是经验保守选择，不是外推区间的严格导数界。
- 端口预测采用 `ΔVinner=ΔVouter/(1+Rg)`、`ΔId=g ΔVinner`。
  完整场状态外推仍沿用已有合格父态工具。端口误差不等于内部场误差。
- 每次校正后、进入主 ledger 前，额外检查实际内压增量、外压增量和电流变化。
  电流变化额度为 `0.25*max(abs(Id),1e-16 A/µm)`，参数可显式设置。
  保留完整 Newton、全部有效载流子行、闭合、输入哈希和独立电路确认。
- 反馈使用端口预测偏差、全部保存 Newton 历史行（包括失败试探、修正验证）、
  实际耗时。工作目标默认 20 行、120 秒，仅控制增步，不改变求解器限额。
  外层拒绝尝试也计入该接受周期成本；发生恢复则下一步至多取本步的 0.5。
  正常反馈因子限制在 0.5 至 1.4，数值失败沿原有路径减半回退。
- 预测与成本摘要写入 `step_proposal`、`attempt_cost`、`step_feedback`。
  配置和模块哈希进入运行身份；旧 checkpoint 不能通过 `--accept-driver-update`
  静默切换成新策略。实际启用需另建匹配父态的续算目录，不能编辑旧证据绕过身份检查。

## 离线结果与建议

最近合格点为物理外压 **26.77363651770252 V**、内压 **26.767866297307403 V**，
Id=**5.7702203951175324e-15 A/µm**。参考原点为 5 V，表中均已加回。
退出尝试 a0242 因 checkpoint 原子替换 WinError 5 中断，不是新合格点。

三个拟合输入：

|物理外压 V|物理内压 V|Id A/µm|
|---:|---:|---:|
|26.573636737546053|26.56789173134669|5.745006199362132e-15|
|26.67363660066784|26.667878945896597|5.7576547712459355e-15|
|26.77363651770252|26.767866297307403|5.7702203951175324e-15|

拟合 g=1.26004037375748e-16 A/(µm·V)，相邻割线为
1.265018926743883e-16、1.2567213446798845e-16。
因此 `1+Rg=1.000126004`；目前电阻使增量比例仅增加 **0.0126004%**。
扩大步长主要取决于允许的器件内压变化和计算成本，而非电阻本身。

|配置上限：外压/接受内压/试探内压 V|基于最近成本建议的下一外压步长 V|说明|
|---|---:|---|
|0.1 / 0.1 / 0.1|0.1|仍受原来规模的上限限制|
|0.2 / 0.2 / 0.1|0.13999988385|推荐首次试验设置|
|0.5 / 0.5 / 0.1|0.13999988385|增长因子仍限制首步；0.5 V 尚无重算证据|

最近一段 a0241 的标量控制器耗时 33.662 秒，所有历史文件共 3 行实际 Newton
迭代，无恢复事件。按 0.14 V 外压预测，下一外压约 **26.91363640155 V**，
内压约 **26.90784854283 V**，Id 约 **5.78785872321e-15 A/µm**。
若后续仍满足成本、预测误差和完整资格，步长可约按 **0.14 → 0.196 → 0.2 V**
增长；这是条件建议，未实际求解这些电压点。

反例窗口 a0194：最终外压 22.07363737436 V，29 行 Newton 迭代，
标量控制器耗时 364.668 秒且发生恢复。即使端口预测偏差很小，新策略也建议
将下一外压步长降到约 **0.05 V**。它只能在恢复发生后降低后续成本，不能从
平滑 I–V 曲线预先保证局部载流子行收敛；不得将离线回放称为已证明提速。

历史时间来自 scalar/checkpoint 的 elapsed_s，不含外层编排和最终独立确认，
是部分实测成本；新运行会测量完整外层尝试耗时。历史行数不是线性求解次数，
无历史文件的修正成本由时间补充，不能据此断言只有三次全部计算工作。
