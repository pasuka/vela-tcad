# BVmethods 归一化SRH与雪崩SG支撑对齐

日期：2026-10-17。接续[源分量与严格人口精度](bvmethods_source_components_precision_2026-10-17.md)。
本轮在私有冻结实际装配中实现自主归一化SRH，并将雪崩电流接到与连续性方程相同的自主SG路径。
**五态两载流子全部自由连续性行通过原1e-8门限**；零偏和首点的剩余失败消除。
严格QF人口、完整RHS／增广负载及导数资格仍保留，N4未收口、N5未开始。
摘要见[机器可读结果](bvmethods_srh_avalanche_alignment_2026-10-17.json)。

## 固定配置与验证范围

保持安装库原版BVmethods：300 K、普通双精度、Fermi／默认Joyce–Dixon、OldSlotboom统计修正、
GradQuasiFermi、NonLocalPath和固定外电阻。网格2600节点／5020个Tri3，Si为2152节点／4156单元，
每载流子2121条自由连续性行。源接口SI m／m^-3，核心um／cm^-3，端电流A/um；原生RHS转换保持负号乘1e4。
本机UCRT64 Release隔离残差探针链接HDF5／SuiteSparse，没有线性求解、Newton或QS运行。
原生观察及自主GNU/Linux标量程序在Sentaurus VM运行，不构成Ubuntu 26.04发行包资格。
生产默认、公开配置、物理参数和门限未改动；新增实现仍为私有冻结诊断候选。

## SRH相消前操作数的自主生成

本轮确认原版近零SRH使用主人口乘积与统计修正平衡项相减。
上一候选从导出的QF分裂用expm1重建净源，数学关系虽然等价，输入的舍入链并不等价。
因此保留原主人口／主电势、QF reference／increment及接触状态，直接重建归一化源核。

在当前300 K配置下，以同一密度标尺归一化n、p、Nc、Nv，
从自主带隙／BGN生成有效本征浓度，再以默认JD反统计计算：

```text
ni* = sqrt(Nc* Nv*) exp(-(Eg* - BGN*) / 2)
Gamma_n = (n* / Nc*) exp(-JD_inverse(n* / Nc*))
Gamma_p = (p* / Nv*) exp(-JD_inverse(p* / Nv*))
a = ni* Gamma_n
b = ni* Gamma_p
R* = (n* p* - a b) / (tau_p* (n* + a) + tau_n* (p* + b))
```

星号表示归一化量，不表示拟合参数。寿命使用原掺杂总量、原参数和自主时间标尺归一化，
并对齐乘除及相消顺序。Gamma直接按比值乘指数求值，区别于先相减对数再求指数的舍入路径。
材料与BGN仍由已验证的自主参数链生成，不读取原生ni、Gamma、源率或RHS作为候选输入。

两个原生采集将实际SRH人口、有效本征浓度、统计因子、分子／分母及输出与RHS1绑定，
完整变量名、变量、RHS1和矩阵身份保持。自主GNU/Linux标量控制的
**首点及零偏各2152个Si节点源率与原生逐值相同**；重点节点的ni与两个Gamma也逐值相同。
本机SRH标量控制分别有27／26个源率末位不同；其近零影响由独立交叉臂保留，未放宽门限。

## 雪崩弱行：驱动力和系数已对齐，电流路径不同

针对首点229／1308及零偏1546／2587等支撑单元，另做两个原生采集，核对驱动力、
电离系数、代表顶点迁移率、电流幅值及实际源支撑，同样保持完整首系统身份。
区分历史观察器字段名称和实际求值位置，未将未定义的结构体成员当作物理量。

修复前，主动源支撑上的驱动力、电离系数和迁移率已分别在约1e-15、1e-13、1e-15量级一致，
但雪崩路径仍用导出QF分裂的旧电流重建。源电流幅值最大对称相对差为：

| 状态 | 旧雪崩电流路径 | 与连续性相同的自主SG路径 |
| --- | ---: | ---: |
| first | 1.561e-7 | 1.025e-15 |
| zero | 9.815e-2 | 3.132e-16 |

将同一主人口、带状态、统计修正及Bernoulli求值接入雪崩电流后，所观察代表顶点全部匹配。
主动支撑的驱动力、电离系数和迁移率最大对称相对差分别不超过
3.21e-15、5.12e-13、1.06e-15；其数值没有为消除弱行而重新标定。
接触电场回退及QF reference／increment保持，未通过缩小外电压步长处理源差。

## 五态交叉装配与逐行门

20次交叉装配覆盖五态和四臂：旧基线、本机SRH标量、自主GNU/Linux SRH标量、
以及自主GNU/Linux SRH加相同SG雪崩电流。另做两次完整日志观察重放，确认观察器修正不改变残差。
数字为电子／空穴失败自由行数；每格覆盖2121+2121条自由行。

| 状态 | 旧基线 | 本机SRH标量 | GNU/Linux SRH标量 | SRH＋相同SG雪崩电流 |
| --- | ---: | ---: | ---: | ---: |
| zero | 822 / 1511 | 6 / 30 | 0 / 8 | 0 / 0 |
| first | 0 / 87 | 0 / 2 | 0 / 2 | 0 / 0 |
| before_BV | 0 / 0 | 0 / 0 | 0 / 0 | 0 / 0 |
| after_BV | 0 / 0 | 0 / 0 | 0 / 0 | 0 / 0 |
| last | 0 / 0 | 0 / 0 | 0 / 0 | 0 / 0 |

组合臂五态最大逐行误差／实际绝对装配项约2.86e-10，低于原1e-8门限。
同时保存固定旧分母指标；不加分母floor，绝对支撑为零而差非零仍应失败。
仅修SRH后零偏还显露8条空穴雪崩失败，说明旧SRH余差曾掩盖部分弱行，不能只盯原先4条。

五个旧基线完整JSON逐值复现上轮结果。SRH独立臂保持输运、雪崩、Poisson和NonLocalPath源不变；
组合臂保持输运、Poisson、NonLocalPath、边界与gauge不变，严格人口门也保持。
本轮全行通过仅指上述冻结状态的两载流子自由连续性行，不包括未重新资格化的其他方程或负载。

初始雪崩接线曾将内部DOS重复换算，显式数学参数表拒绝了未登记参数；失败已封存，没有回退或补填原生数值。
初始模板观察器的多个缓冲流还造成两行日志交错，原始日志保留并不用于逐单元资格；
改为完整记录后重放首点和零偏，每臂每态168条记录完整，残差与原运行逐值一致。
