## 配置与实现边界

目标保持安装库BVmethods resistor、T-2022.03-SP2，原版物理／参数和N0 v1门限不变。
本轮使用绑定真实正QS第二耦合系统的同一基准，沿电子人口、电势、三条重点弱行小步方向求值；
没有重新运行五态全轨迹，也没有新增原生作业。网格2600节点、5020个Tri3、4156个Si种子、
2121个自由半导体节点；含负载的独立系统6843阶。300 K，源率cm^-3 s^-1，电流A/μm，电阻Ω·μm。

本地Ubuntu 26.04.1／GCC 15.2、C++20 Release O1、关闭FMA收缩，复用已核验核心库及兼容数学。
Windows UCRT64／GCC 16.2用于独立装配性质测试。HDF5／UMFPACK／SPQR／METIS链接沿用，未调用线性求解。
私有源码、实际操作数、候选和失败数据位于ignored `build-release/bvmethods_n4_sg_srh_assembly_20261018/`。

新通道在私有LiveOperator的当前真实装配态捕获SRH转成double之前的80位速率，
贯穿源体积／归一化、逐节点累加、接触电流和负载行，输出当前绝对残差以及reference/increment。
原double通道保留对照；生产CoupledDDAssembler的公共返回类型和Newton尚未采用新通道。
SG兼容边值进入保精度累加，这不能恢复已在边操作数／乘积中丢失的低位。
另用独立C++双视图重装配显式保留当前兼容值、当前高精度值及其表示差，未冻结参考偏移。

## 1. SRH实际速率到残差的修复

在当前主人口上自主生成统计修正、分子和分母，实际调用点缓存未降精度的速率。
缓存按每次完整状态清空，旧源内容／版本拒绝机制保持；没有读取原生源率填充候选。
独立Python公式核对速率，独立有理数／Decimal装配核对全部6843行及增量。

| 电子人口方向步长 | 原double速率方向失败行 | 新通道对实际增量失败行 | 新通道对意图方向失败行 |
| --- | ---: | ---: | ---: |
| 3e-4 | 192 | 0 | 120 |
| 1e-4 | 230 | 0 | 144 |
| 3e-5 | 259 | 0 | 178 |

上述SRH按2121个唯一自由节点计数，不重复计入电子／空穴两条方程。
原1e-5方向门未变；电势方向的SRH零响应单独登记，不计作非零导数证据。
基准完整RHS最大归一化差1.781e-9，全部6843行通过原1e-8门；人口身份和全部Si源覆盖通过。
这是绑定基准的原生残差对照；新扰动态只取得独立装配／方向检查，不冒充新增原生同态资格。

仍失败的意图方向已逐坐标重建：binary64乘法／加法结果与C++主变量全部一致；
120／144／178条差异的实际方向与意图方向之差均位于独立输入舍入界内。
这些行仍记为意图方向未通过，不能以实际割线替换意图方向的验收。
重点小步方向三档的SRH实际增量也通过；最细3e-12档另有1条意图方向超门，保留单列。
下一步若要消除此项，需要统一主变量reference/increment及各物理视图，而不是再次提高SRH最终减法精度。

## 2. 95条SG失败的分项与求值分层

按旧固定绝对装配预算分解，95条均为电子输运差超门，SRH、雪崩、NonLocalPath变化没有超门行。
最差为电子2401，归一化差约3.276e-4。

| 在当前实际操作数上的隔离改动 | 相对兼容输运变化超过1e-8的行数 |
| --- | ---: |
| 保留原Bernoulli值，仅高精度计算乘积／相减 | 53 |
| 保留原SG参数a，高精度计算Bernoulli及乘积 | 61 |
| 使用全宽候选舍入后的a，再高精度计算Bernoulli及乘积 | 88 |
| 旧完整全宽候选 | 95 |

这是定位控制，不是四个已接受模型。独立分解a的统计修正、带边、DOS和组合舍入，
2401的两条非零差边分别约1.585e-16、−8.873e-16，差异均来自统计修正。
把兼容的`log(r)-eta(r)`求值直接替换为宽精度统计表达式，会改变近零电流实际使用的驱动。
数学表达式等价不足以证明弱行绝对RHS兼容。

## 3. SG表示增量与迁移率支撑

七态每态9070条实际SG项经独立C++兼容求值逐值复核，再分别完成当前兼容／高精度残差装配。
逐态验证`ΔM = ΔC + Δ(M-C)`；表示差随当前状态重算，不从原生误差拟合，也不冻结基准补偿。
高精度候选仍有95条基准RHS失败，因此拒绝晋升。

| 电子人口方向步长 | 兼容SG保精度累加后的导数失败行 | 全宽SG视图导数失败行 |
| --- | ---: | ---: |
| 3e-4 | 145 | 2 |
| 1e-4 | 152 | 4 |
| 3e-5 | 191 | 1 |

导数改善不能覆盖绝对值失败。电势方向仍有逐弱行失败，具体数目见JSON；
全局保精度累加没有解决上游SG驱动、迁移率及输入量化。
重点小步方向的SG三档失败分别为0／2／0，不能将上轮三条雪崩源方向通过扩大为整个输运块通过。

全宽视图的剩余行涉及1735、2594、864、1726、2593。
固定边系数后同方向误差最大约2.93e-15；剩余差几乎全部落在系数变化／导数链。
2594以及较小档1726／2593的支撑跨单元4701的高场迁移率活动分支，必须单列事件侧。
1735粗档未跨开关但局部驱动力变化明显；864两档保持同侧，其差分别约为最终系数舍入预算的8.07／18.05倍，
不能仅归因于最终系数double输出。上游QF／驱动力和迁移率链仍需进一步核对。
