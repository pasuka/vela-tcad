# BVMethods 浓度下限与外推阈值独立验证（2026-10-30）

12项有界对照已在 vela VM 完成。冷启动四组和第一类检查点后续5目标均通过；第二类检查点四组均在首个新目标耗尽40轮预算。浓度下限能阻止本轮保存人口进入极小尾部，并改善该失败态的残差与更新误差，但未解决原联合停止门下的收敛。两项新配置默认仍关闭，未接入全局默认，也未宣称完整BV通过。

使用冻结的2600节点、5020 Tri3 BVMethods网格，300 K、Joyce–Dixon/OldSlotboom、总杂质迁移率、SRH、GradQF AV、BTBT关闭、R=1e7 Ω·μm。核心 potential_density，quasi_fermi SG、自动导数恢复、局部非正候选保留1%、默认精确约束消元、对数人口外推、full_step、enforce_joint。Linux GCC16 Release / 实际启用 oneMKL PARDISO，每进程单线程，至多四个对照并行。

器件残差1e-8、负载残差1e-6 V、原始人口更新RMS<1及原守恒门report/enforce属性保持。各case最多600秒，本轮无超时。冻结源码清单SHA256：`2f0e38c5c20298ce954ea23241649753b1d97071cf32c5cadb99ecb0eeea3496`，含此前未提交算术修复与本次控制；提交基线不等同实际快照。

四组分别为：baseline（两项关闭）、floor（仅下限1e-100 cm^-3）、predictor（仅外推阈值1e-100 cm^-3）、both（两项同时启用）。下限在自由载流子候选更新及既有非正保护后应用；接触规定槽、氧化层零槽不裁剪。外推阈值只保留最近接受态中低于或等于阈值的人口，不抬高人口，不改变电势和电路电压预测。

- cold：冷Poisson起步，外压0→0.100562182394906 V，两类内压上限0.1 V。
- tail01：原0.1 V组检查点，外压9.5005366491799688 V、内压6.5940776821110862 V，新增5个外压目标，各相隔10 μV。
- tail02：原0.2 V组检查点，外压0.73081468048084064 V、内压0.70364338358135825 V，同样新增5个10 μV目标，两类内压上限0.2 V。

续算重新求解导入点，故6个接受点表示导入点加5个新目标，1点表示仅导入点通过。更新累计仅计已接受CSV行，不含失败尝试的工作量。

## 入口修正和排错批次

新增字段见[配置说明](../config_schema.md#opt-in-population-lower-bound-and-predictor-cutoff)。已修正format v2的单位契约：canonicalizer只把cm3键重命名为解析器的m3拼写，数值仍为cm^-3；字段解析必须使用传入的UnitScalingConfig，不能仅按键名除1e6。新增实际canonicalizeDeck→newtonConfigFromJson测试覆盖此路径。旧SI解析路径和直接cm3字段另行覆盖。

早期批次先后被未知canonical键、缺少JD的测试夹具拦截；之后排错批次实际用了1e-106 cm^-3，未纳入正式数值结论，全部保留。正式r4已从保存状态核实物理下限为1e-100 cm^-3。

排错批次还揭示固定10 μV目标的浮点边界问题：持久步长略小于下一段最小步长时，控制器可在启动下一次Newton前停止。正式有界实验仅将最小允许外压步长设为9.99999 μV（留10 pV余量），目标间隔和初始/最大步长仍为10 μV；所有四组一致，未修改生产控制器。tail02因此有一次接近相同目标的重试，不能把末次数据与旧批次首个尝试混用。
