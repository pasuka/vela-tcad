# SimpleMOS 迁移率字段专项校核（2026-09-30）

## 范围与判读规则

沿用已通过工程资格的 n17–n24、Vd=0.05/1 V、Vg=0–2.5 V（步长 0.05 V）共 816 点。Sentaurus T-2022.03 对既有 M60 状态执行八组 Load/Plot，只新增 `eMobility/Element`、`hMobility/Element` 导出，不新增 DC、Newton 或双初始化求解。冻结工程电流 2% 门槛及其它数值门槛均不变。

模型仍为 300 K、Boltzmann、OldSlotboom、PhuMob、Enormal、高场饱和及掺杂依赖 SRH。Vela 采用显式 `element_box_phumob`、`element_distance_gradient`、`element_vertex_partial_layer`、Delaunay-transfer 单元盒几何、signed Si Poisson/SRH 体积及完整 split 状态。此次仅修复 CLI 单元诊断读取 HDF5 时遗漏的网格/参考上下文；云端新诊断程序链接未变的冻结 `libvela_core.a`。冻结求解器和完整 split 边账本没有重算或替换。

手册依据为本地 Sentaurus Device User Guide T-2022.03 第 177–178 页的 Element 输出和第 464 页的迁移率平均定义；查阅文件 `build-release/m79_research/sdevice_ug_local_2022.txt`。原生单元迁移率单位为 cm²/(V·s)，比较时乘 1e-4 转为 m²/(V·s)。网格坐标为 µm，x 为深度、y 为横向。Si、氧化层及两块氮化层电势均检查重载不变性。

必须分清三种量：

1. 原生节点 `eMobility/hMobility` 是节点输出，不能直接作为 SG 边迁移率参考。
2. 原生 `/Element` 单元输出与 Vela 在同一导出状态上算得的单元量可作固定状态公式比较。历史逐单元相对门槛为 1e-7；失败继续保留。
3. Vela 完整 split 生产边量与单元探针重建量单独比较。探针实际使用双精度物理字段，即使 HDF5 包含 low 束也不会恢复它，因此这是状态投影影响检查，不是位级 split 求值。

生产形成关系为：先在每个单元顶点计算依赖 n/p、法向场和高场驱动力的迁移率，再以局部盒节点量 M(T,i) 做单元平均；最后以相邻单元对该边的盒系数 g(T,e) 做边平均：

`mu_T = sum_i(M(T,i)*mu(T,i))/sum_i(M(T,i))`

`mu_e = sum_T(g(T,e)*mu_T)/sum_T(g(T,e))`

原生单元重建的边使用同一已验证 Vela 几何；它不是原生内部边迁移率的直接导出。两者的解释必须保留此限制。

## 节点字段不能代替单元/边字段

把原生节点迁移率端点算术平均后直接对比 Vela 边量，最大表观相对差可达电子 **3.0405（304.05%）**、空穴 **1.8289（182.89%）**。该结果属于不同定义的混合比较，不能作为生产迁移率误差。

同时检验原生单元到节点的三种显示重建假设（相邻单元等权、三角形面积、局部 box 顶点量）均不恒等：电子全局最大相对差分别为 0.404/0.861/0.701，空穴为 0.373/0.758/0.497。未选择“最接近”的候选冒充原生定义。原生节点显示投影的精确形成方式仍是独立缺口；工程比较应优先使用此次已有身份核验的单元量和明确注明几何的边重建。
