# LDMOS 工作日报素材｜2026-09-13

## 可直接用于日报的工作摘要

今日围绕 LDMOS 与 Sentaurus 的物理一致性及求解性能，完成有限空穴接触
复合边界和温度导数验证，统一共享等温与独立电热路径的 Auger 生成开关
语义，并复核 G3/D5/D4。通过固定状态残差及局部场分解，定位出 Poisson
边系数与电荷体积的组合差异，将原生几何口径接入独立四方程电热入口。

新几何及最终优化版本分别完成 Vg=4/8 V、Vd=0–40 V 各31个精确点的完整
D0仿真，均通过原电学及已批准热学门限。相对原生参考，两栅压最大电流
误差降至0.02409%/0.00714%，最大峰温误差降至0.00940/0.04198 K；40 V
最大导带差由0.38763/0.46211 eV降至0.00780/0.02665 eV。

性能侧完成物性准备复用、Newton停滞提前退出、SparseLU结构分析复用，
并通过gprof定位IALMob温度屏蔽根重复求解热点，按精确温度和有效质量复用
求根结果。串行同输入高压点重放的中位墙钟由53.83 s降至20.24 s，减少
62.4%；CPU由44.38 s降至15.11 s，减少66.0%。完整曲线的失败尝试由60次
更新缩短到12次，优化前后全部接受状态、残差和Newton轨迹逐项一致。

最终Release完整CTest 808/808通过，源码、程序及证据输入哈希核对通过；
51个相关源码、配置、测试与验证文档已提交本地分支，提交号28350b6。

## 关键结果

下表顺序均为Vg=4 V / Vg=8 V。B4 R3为本日原几何基线；N1为新几何，
P3在N1上叠加性能优化，两者全部接受状态保持一致。

| 指标 | B4 R3原几何 | 最终N1/P3 |
|---|---:|---:|
| 完整曲线最大电流误差 | 1.7744% / 1.5825% | 0.02409% / 0.00714% |
| 完整曲线最大峰温误差 | 1.50512 / 2.18931 K | 0.00940 / 0.04198 K |
| 完整曲线最大体积加权温度场RMS误差 | 0.95521 / 1.50008 K | 0.00631 / 0.01085 K |
| 40 V最大导带差 | 0.38763 / 0.46211 eV | 0.00780 / 0.02665 eV |

电流相对误差覆盖每栅压30个非零漏压点；零压单独检查严格零电流/热功率。
完整曲线每栅压31点，重复版本验收不累计成更多独立偏压点。

| 性能指标 | 新几何基线N1 | 最终P3 |
|---|---:|---:|
| Vg4 / Vg8完整曲线Newton更新 | 406 / 318 | 358 / 318 |
| Vg4失败尝试内更新 | 60 | 12 |
| 双栅压累计SparseLU符号分析 | 724 | 74 |
| 同输入高压点中位墙钟 | 53.83 s | 20.24 s |
| 同输入高压点中位CPU | 44.38 s | 15.11 s |

串行性能对照每版两次，顺序N1→P1→P2→P3→P3→P2→P1→N1；每次均7次
Newton更新，原状态/残差/轨迹逐项相等。两次测量用于展示本轮实测收益，
不将小幅差异当作统计显著结论。

P3完整曲线求解子进程累计墙钟为1250.68/623.52 s；Sentaurus漏压段日志
Solver总时间为702.96/653.47 s。前者不含父运行器整理、评分与文件输出
开销，完整运行阶段又存在后台负载，且Windows/虚拟机环境不同。
这些数值表明耗时已接近同一量级，不能据此声称同条件已快于Sentaurus。
