## 实施

1. 暴露与生产人口函数共用的`scaledFermiDiracHalf(DOS,eta)`。普通区保持原乘法顺序；η<-700沿用现有`exp(log(DOS)+eta)`，不增加人口下限。
2. 替换耦合装配中10处直接DOS乘Fermi积分的端点/参考人口求值，覆盖电子、空穴、残差参考、Jacobian缓存及扰动辅助路径。同步替换端口电子电流中的两处同类求值，避免求解和报告口径不一致。
3. SG将NaN与合法有限输入产生的指数溢出区分；无效输入继续作为非有限值暴露，合法溢出的既有饱和策略不变。
4. PhuMob人口、QF与电势链式乘积在输入有限且偏导确为零时直接返回零；先校验输入，因此不会用零偏导掩盖非法通量。非零项保持原运算顺序。

冻结库的CarrierStatistics、SG、ContactCurrent对象与其源码构建对象逐字节匹配后才替换。CoupledDDAssembler在原乘子观察器源码上作同一补丁；独立库保留此前阶段捕获。原库、原源码及在运行程序不写入。

困难链的前3次物理装配、正则化前检查及消元输入共9次扫描，A与b全部有限。新错误发生于第三次求解返回后的处理阶段。它与旧链第6次装配NaN属于不同的直接阻断，不能用新链较早退出认定原NaN仍存在。

### 原第6次装配的同冻结态对照

对原失败步首状态直接执行只装配/求解探针，不写回状态；旧库与修复库使用同一父态哈希。旧库在三个矩阵检查阶段均有39个NaN，RHS有限，报`elimination: nonfinite matrix`。修复库三个阶段的A/b均有限，并返回有限方向；实际接受更新数为0。约束消元前41643个残差分量在两库之间逐位一致，最大绝对差为0；比较时已区分残差和取负后的求解RHS。

这项对照直接支持“原冻结态的39个NaN已消除”。探针退出成功不表示器件收敛，不能提升为续算父态。修复方向范数约1.67e20，方向准确性及其非线性效果仍需另行评价。

### 后续逆Fermi阻断已定位

新增独立只读观察器，在原逆Fermi调用前记录非法实参，保留原除法与原函数调用。观察器与无观察器修复链的核心历史、两次迭代及失败存档共6份已比较数值字段逐位一致，均在第三次更新前的原始/推进相对方向换算中退出。

| 实际捕获项 | 数值 |
| --- | ---: |
| 节点/载流子 | 7107/空穴 |
| 人口（内部单位） | 1.368160756855898e-305 |
| DOS（内部单位） | 3.104628932474838e19 |
| binary64人口/DOS | 0 |
| 对原double操作数作100位除法 | 4.4068414828733695e-325 |
| binary64最小正次正规数的一半 | 2.4703282292062327e-324 |
| log(人口)-log(DOS) | -746.8569970072475 |

因此是正且有限的人口在除以DOS时产生不可表示的中间量，随后`inverseFermiDiracHalf(0)`触发保护。此时矩阵已经成功求解，尚未执行第三步人口写回；不是PARDISO消元产生NaN，也不是这一步已将人口写成0。它与原8592端点人口生成下溢属于不同入口，不能把7107直接称作旧39个NaN的首发节点。

这个换算紧接着计算`F'(eta)/F(eta)`；即使只绕过逆函数参数为0的问题，极稀薄区仍可能形成0/0。下一批应整体验证基于实际生产状态η或对数人口的稳定换算和对数导数，而不是单独跳过参数检查。本批未修改此调用链，未增加人口下限。
