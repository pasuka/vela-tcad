本节复用历史U-2022.12、double路径的25/50 mV运行时捕获，不新启动Sentaurus；

原始events、向量、矩阵、CMD和PLT保持不变；复算前后核验哈希。
两个脚本保留RHSmin=1e-10、Digits=5、ErrRef=1e10，但移除了ExtendedPrecision，
使用Save/Load后的单次耦合检查。因此不作为本日原参数80位整链的等价证据。

每组4次接触残差装配，共8次调用，逐次绑定实际R、电压、接触节点及尺度。
接触的21个节点贡献归并成一个独立电压未知量。设s为该次返回的21节点RHS和，
捕获到的电流换算系数为K，则在本构建和配置下：

```
K = 2.3751456577392005e-13 A/µm per native current unit
S = R*K = 0.23751456577392005 V per native contact-RHS unit
Vd + R*I_assembled - Vs = -S*s
```

S由实际Vt、缩放电阻、维度因子和物理R计算，不是对最终输出电流拟合。
8次恒等式的绝对缺陷均不超过约5.3e-18 V。
线性求解前两帧中，接触RHS和与真实PARDISO行的差约3.04e-18、1.95e-18
（原生内部单位）；维数39150，电路行88个非零系数。这里不将内部数值直接标成V。
S依赖构建、单位、器件与电阻，不能推广为所有Sentaurus配置的固定常数。

## 新增消费者采集：double路径已完成局部绑定

在同一二进制身份、输入及本批截止内，先后进行了3组各25/50 mV的独立短程采集，
共6次原生执行，均正常完成、非超时、观察器无错误。分别补充实际ComputeError、
正常路径MaxNorm以及其输入向量/索引集合；早期环境错误没有进入求解，不计入6次执行。
原物理、Math、种子和求解预算未改变，没有将诊断门设成新的原生接受条件。

新增证据如下：

1. `ComputeError`的原始方向指针与同次PARDISO实际返回向量指针相同。
   返回的error分别为2.140029648303528e-5、1.743557865046074e-5，
   与日志停止error按打印精度一致。第三个引用输出分别为2.140029648303528e-10、
   1.743557865046075e-10，二者比值约1e5，与Digits=5的放大一致。
   调用端保存了浮点返回标量；不再只由函数名猜测含义。
2. 本正常路径实际调用`MaxNorm`，未触发另外两个FedorenkoRhsNorm观察入口。
   同一个MaxNorm还会用于方向向量；通过指针及事件时序区分，未把方向最大值误当RHS。
3. 两组RHS归约的索引集合均逐项等于0…39149，正好39150个独立分量。
   线性求解前，归约输入向量与实际PARDISO RHS逐位相同，不仅是范数或系数集合相同。
   对保存输入独立重算最大绝对值，与消费者返回值完全相同。
4. 接触行位于该真实向量的索引13881，线性求解前及更新后的同次装配RHS和均匹配此项。
   因此外电阻接触方程确实参与该路径的RHS评价，未被排除在范数之外。
5. 新增采集的更新后真实RHS最大绝对值为6.460413298482234e-4；
   其中两组接触行为+5.04325979671335e-4、-4.512742419730215e-4，
   对应物理负载线仍为-119.7847661 µV、+107.1842056 µV。
   这两例仍由error<1停止，直接支持“独立强制1 µV并不等价于这条原生停止路径”。

上述结论只覆盖这份double短程配置。它说明接触行计入RHS，以及更新误差分支
可以在其RHS尚未达标时停止；不是“原生没有外电阻方程”，也不是所有配置都应
取消电路精度审计。完整更新误差的每分量参考/计数与原参数80位分支仍未全部核清。
