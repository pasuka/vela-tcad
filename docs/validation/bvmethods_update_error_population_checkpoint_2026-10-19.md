# BVmethods：实际人口采集与精确人口 checkpoint，2026-10-19

承接[被动采集与原位重启比较](bvmethods_update_error_capture_restart_2026-10-19.md)。
本轮补充解析 Jacobian 实际使用的人口身份、实验性内部人口保真存档和完整迭代报告。
只做 report 诊断；生产接受策略、行门、闭合门、物理模型、FMA 路径及 PN2D 配置不变。
未新增 Sentaurus 仿真，未执行 E1–E4。

## 实现与契约

1. `AssemblyPopulationCaptureScope` 只复制解析 Jacobian 已计算的 x/n/p，
   不额外调用人口、残差或 Jacobian。作用域由有容量的 Newton 采集器启用；
   有限差分 Jacobian 不伪称已取得实际解析人口。异常在诊断层捕获。
2. `PopulationCheckpoint.h` 提供实验性的独立 JSON sidecar。
   普通 HDF5 仍保存 SI 人口，sidecar 按 binary64 的十六进制位模式保存内部人口。
   恢复时核对完整物理存档（字段位模式及元数据）、长度/浓度单位、节点数、
   sidecar 摘要以及内部人口向 SI 的正向映射；不匹配则拒绝。
   sidecar 与 HDF5 分开，避免改变公开 schema 或挤占 HDF5 元数据容量。
3. 这只修复诊断 checkpoint 的人口存储往返，不宣称复制全部 DDSolution 字段、
   缓存、历史或线性求解器状态。普通生产读取器不自动消费 sidecar。
4. 私有驱动在求解结束后以独立对象生成每轮 U1/U2/U3 和全部七种分子/分母组合。
   无接受步时 U3 保持无效，人口下溢/不可表示时 U2 保持无效。
   报告采用 Vela 固定内压自由行集合，contact 未知量为零；`complete_equations=false`。
   不将其与原生含接触别名的 6853 个误差条目等同。

sidecar 用于诊断的身份绑定和意外损坏检测，不是防篡改签名，也不改变人口本构。
对于公共存档已有的物理量次正规数归零策略，本轮保留其行为；
实验性 sidecar 可保存原内部人口的次正规值与负零。

## 配置及比较方法

无 Band2Band 的 BVmethods，2600 节点、300 K、Fermi 人口，沿用 BGN/SRH/雪崩/迁移率。
使用 barycentric 体积及原钝角单元，未混入零偏离散对齐控制。
UCRT64 Release core、私有 `-O1` 驱动，UMFPACK 后端及 HDF5 已启用。
内部人口按当前 unit_scaling 单位保存；报告中 n/p 转为 cm⁻³，ψ/QF 为 V。
六态配置的漏极固定内压均为 0.00524437249039996 V，其余接触为 0 V。
`rows0` 指 0 条违规行的种子态，不是 0 V 初始态；本轮不是零偏初始化验收。

本机与 T470p 使用相同程序和九个已核对 SHA256 的输入文件（网格/材料/掺杂及六态）。
每态分别运行 off 两次、capture 两次；其中一次 capture 在结束后计算报告及重启对照。
不把进程退出码 0 当作物理收敛。

L1 检查点优先取实际第二轮开始态；没有第二轮的 285 行态取第一轮拒绝态。
人口直接取自 Jacobian 已使用的数组，ψ/QF 及 packed 坐标由被动快照恢复。
L2 对齐原位第 2 轮起与重启第 1 轮起的共同区间；重启额外的迭代预算不计入匹配资格。

## 当前结果

双机六态共 48 次运行完成，进程退出码均为 0，六态仍全部按原判据未收敛。
每机 off 重复、capture 重复、off/capture 的已记录结果、轨迹及环境相同，
新程序 off 的结果也与上轮封存的同机 off 基线相同。

实际人口与独立重算在合计 172 轮、894400 个载流子节点值上逐位相同。
12 个精确保真 checkpoint 的内部 n/p、ψ/QF reference/increment、packed 坐标、
J/R 及掩码均一致。L2 共同区间合计 162 个事件一致，包含 x/J/R、
人口、行权重、原始/保护方向及已记录的完整线搜索结果。
这些是各机器内部的对应比较，不把历史跨机器 J/R 数学路径差异标为消失。

172 份逐轮账本每份包含 6764 个自由行条目，补充区域、掺杂及各组合的归一化贡献。
按这些序列化条目独立合成 RMS，1204 项组合检查通过；2e-14 相对容差仅用于这项
报告序列化/归约一致性检查，未改变 1e-8 算子门或任何物理/求解门限。
全部 177 项批次核对通过，864 个证据文件已按 SHA256 封存。

## 尚未取得的资格

严格 L1 仍缺逐元素 J 与完整缓存身份；数值 L2 不等于缓存命中历史相同。
当前 off/report 比较覆盖私有序列化的结果和轨迹字段；off 侧没有独立逐轮 J/R 记录，
且该序列化器并未逐位编码完整 NewtonResult 的所有字段，因此不宣称完整无扰动硬门通过。
