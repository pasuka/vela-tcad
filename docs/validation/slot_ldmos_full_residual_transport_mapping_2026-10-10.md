# SLOT 同态完整残差、SG 输运与接触映射检查

日期：2026-10-10。证据：[build/s10mapping](../../build/s10mapping/)。
承接 [SG 电离源核对齐](slot_ldmos_sg_source_alignment_2026-10-10.md)，
本批只作冻结态装配和分析，7 个探针进程全部退出 0，累计约 55.11 秒；
**零次 Newton 接受更新、零个新增合格点，未启动续算，未更改物理或验收门槛。**

## 结果

完整残差还没有达到同一系统的逐项一致，但主要差异已进一步分层：

1. 人口匹配态的最大空穴残差差异集中于 **PolySilicon**，并非 10849 的电离源。
   保留原生 QF 后，多晶硅电子/空穴残差相对 L2 差降至约 2.95/3.10 ppm；
   此时 Vela 重建人口与原生仍差约 4.6 ppm，不能称为所有派生量完全同态。
2. 为精确匹配人口而进行的空间变化 QF 修正，给多晶硅边引入最高约 **0.176 µV**
   的额外 QF 落差。它足以显著改变近零电流区域的残差；不能用人口吻合直接推断输运吻合。
3. SG 边通量按节点方向求和，在全部有效自由载流子行上重建 Vela 实际输运项，
   相对 L2 误差约 1.06e-16 / 1.48e-16。这验证了本次输运观测接口的装配对应关系，
   **不等于已经拿到原生每条边的实际输运系数**。
4. 接触人口在本次冻结装配中仍匹配。打包保留保存态 QF，以边界残差表达与目标偏压的差，
   并非静默投影到偏压；接触 QF/内建势仍有约 0.05–0.147 µV 差异。
5. 原生 QF 对照中的 Si 电子残差还剩 **0.06610%** 相对 L2 差，需要继续分解；
   本批没有证据将它归为行比门槛问题、求导错误或舍入底限。

以上误差都是指定未收敛中间态的残差比较，不是端口电流误差或器件解误差。

## 完整载流子残差：不用拟合尺度

Vela 自动标度由当前材料与掺杂给出：

```
C0 = 1.4797799323493304e21 cm^-3
mu0 = 1417 cm^2/(V s)
VT = 0.025851999786435535 V
C0 D0 = C0 mu0 VT = 5.42077182915092e22
连续性源积分转换因子 = 1e-4
原生 ND = 1.4824351e10 cm^-3
原生残差行单位 / Vela 残差行单位 = C0 D0 / (ND * 1e4)
                                      = 365666721.5415312
```

依据 `UnitScalingSystem.cpp`、`UnitScaling.cpp` 和连续性装配尺度，另用 SG 边的
物理粒子通量与归一化通量独立验证 C0D0（相对差 <1e-12）。原生源项尺度使用上一批
已验证的 `G × 面积 / (ND × 1e8)`。这里比较 `r_native=-RHS1`，不是线性求解 RHS 的同号比较。

|区域/行|自由行数|人口匹配态完整残差相对 L2 差|保持原生 QF 对照|
|---|---:|---:|---:|
|Si 电子|12,306|0.100252%|0.0660950%|
|Si 空穴|12,306|3.42527%|1.38565 ppm|
|PolySilicon 电子|328|210.600 倍|2.95091 ppm|
|PolySilicon 空穴|328|11.1698 倍|3.10162 ppm|

多晶硅相对数很大，其中电子原生残差 L2 只有 46.3451（上述原生行单位），人口匹配态为
9763.2645；空穴分别 25970.2418 和 268905.3866。不能只看大倍数推断器件电流误差。
最大空穴差异节点为 13291、13349、13735 等多晶硅节点；13291 坐标
(-0.00806321, 3.60038058) µm，13349/13735 位于 y=3.920546875 µm。

在“原生 QF”臂，输入 ψ/QF 保持原生保存值，人口由 Vela 本构重新计算：最大人口相对差
电子 4.5467 ppm、空穴 4.5708 ppm。这是一项明确的**映射对照**，不能与人口匹配臂一起
拼成一份“所有量都相同”的证明，也不是建议用原生场替代合格初态。

原生去电离 RHS 与 Vela `flux+recombination` 的差异几乎复现上表，说明本快照的主要
完整残差差异不来自电离项。SRH+Auger 的原生节点观察率按 Si 支撑面积积分，与 Vela
复合项的相对 L2 差为 80.09 ppm；该项绝对差 L2 仅 0.001247 原生行单位。
这仍是观察字段积分，未单独用原生“关闭复合”的 RHS 差验证其完整装配身份，故不据此
把剩余差异全部归因于输运的某一公式。

## SG 输运与源核的两种“同态”

`sg_edge_flux_probe` 导出的 898 条多晶硅内部边中：

|量|电子|空穴|
|---|---:|---:|
|原生 QF 的最大边落差|7.56748 nV|7.31559 nV|
|人口匹配后最大边落差|175.760 nV|175.679 nV|
|两种映射之间最大落差变化|175.760 nV|175.679 nV|

并非每条边都放大同一比例；最大变化可能落在原本近零落差的边上。变化来自本构逆映射的
空间差异，不能用一个全局 QF 平移消除。

SG 边通量的节点汇总必须在**自由有效行**比较：接触行的项探针已经清零输运/源并写入
边界残差，直接将全节点边通量与它相减会得到假差异。限定自由行后，电子/空穴加法闭合
分别为 1.0571e-16 / 1.4792e-16。边观测因此可以用于后续 Si 电子输运分解。

电离源也必须区分：

- 原生 ψ/n/p/QF 直接输入源核时，上一批得到 ppm 级一致。
- 匹配人口而重建 QF 后，自由行上的电子触发源与前者 L2 差 0.046459%，空穴触发源
  差 1.01464%；这两种源再从保存态探针到实际打包装配，分别一致至 8.64e-16 / 1.63e-15。
- 实际完整成对源与原生 RHS 源分量的 L2 差为 0.0464365%，由电子源主导。

例如 10849 空穴行（原生残差单位）：

|项|原生|Vela 人口匹配态|
|---|---:|---:|
|输运+复合|671.735825383|671.738032395|
|电离|−738.133056271|−737.790206756|
|完整残差|−66.3972308882|−66.0521743616|

因此该行本批的完整残差偏差主要是 QF 派生量尚未一致时的电离源偏差；它与整个
空穴块被多晶硅输运差主导是两个不同层级的事实。

## 接触映射检查

`packReferencedSolution` 保留保存态参考量/增量，不投影 QF 到目标边界。当前人口仍然
匹配，但边界方程并未为零。前期检查时提出的“装配前可能投影人口”在本次探针中
**没有发生**；源码 `(void)bcs` 和实际人口数据共同排除了这一解释。

|接触|节点数|ψ 边界残差最大绝对值|保存电子QF相对目标最大差|
|---|---:|---:|---:|
|source|71|0.089233 µV|0.089233 µV|
|drain|21|0.147095 µV|0.147095 µV|
|gate|22|0.097775 µV|0.097775 µV|
|substrate|12|0.054767 µV|0.050303 µV|

独立诊断副本只把接触 QF 投影到目标偏压、保持 ψ 和自由节点不变：接触附近人口改变
约 3.3–3.8 ppm，Si 空穴残差差异增至 9.04208%，多晶硅电子差异也显著增大。
故不能以“先把接触 QF 改对”为完整修复，必须同步处理接触本构和邻边驱动力。

即使 `solved_equation_terms=false`，载流子项接口仍对 Dirichlet 节点清零通量、复合、
电离项；这些零值不是接触反力。已另从边通量和源支撑生成 `contact_flux_source.csv`，
只列粒子通量及源等效电流，不将其误称为完整端口电流或与原生同进程接触反力的吻合证明。
本批未取得新的原生接触反力分项。

## Poisson 与边界分开核对

自由 ψ 行使用固定人口方向的本行 ψ 对角归一化。原生 RHS 本身已很小，直接相对 L2
差约 1148.8 倍，不能据此认定几何仍未对齐。
仅在后处理用已知 q/ε0 常数比例修正电荷/介电比后，归一化 RHS 最大绝对差
4.27e-12，相对 L2 差 2.44e-5；支持剩余主要项为已有常数口径差。
本批不改任何全局常数，也不把这种归一化 RHS 写成物理电压。
