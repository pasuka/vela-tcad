# BVmethods 验证进展与数值问题分析交接

截至2026-10-19。用途：为独立大模型或数值分析人员提供可单独阅读的背景、已验证事实、失败证据及待判别问题。

**当前结论：Sentaurus安装库原版已取得从零纯电压QS的重复参考；Vela仍未取得同物理完整轨迹资格，也没有本算例可认证的击穿电压。NonLocalPath私有开发停留在N4验收，近期关闭整个Band2Band后的对照又确认：基础离散、Jacobian、更新限制和非线性接受本身也存在待解决问题。**

本文件汇总既有证据，不表示本次重新运行仿真。文中“通过”均限定到对应状态、配置和检查范围；单独源项、局部导数或保存态通过，不能替代完整自洽求解。

外压、内压、电流不能混用。负载关系为 `Vext − Vint − R·Id = 0`，其中R为Ω·µm、Id为A/µm；大外压主要降在电阻上，不是器件承受数千伏。

原生日志记录Bank/Rose非线性求解和blocked decomposition线性求解。Vela近期生产路径使用UCRT64 Release、UMFPACK、单线程、HDF5状态保存，主变量为电势与两类准费米势QF。历史增强精度、DensityIntegral(240)、E2/Eparallel、瞬态获取、辅助栅偏或电流控制记录均不能自动成为本原版的资格。

原生场量通常以µm、cm⁻³、V/cm导出，Vela还涉及SI及内部归一化。本文未注明物理单位的残差、Jacobian缺陷和积分源数值均为对应装配内部单位，不能直接解释为A/µm；矩阵比较必须先统一缩放。

原版中的Fermi也不能直接理解为“所有历史精确积分控制均适用”：当前私有对齐记录明确区分原生默认Joyce–Dixon统计路径与专项DensityIntegral控制。参考身份必须与实际运行绑定。[S1][S2]

## 2 两条验证线必须分开

| 验证线 | 解决的问题 | 当前结论 |
|---|---|---|
| A 原版完整物理 | 实现真实NonLocalPath，比较同态人口、输运、源、RHS、导数，最终完成原版QS | N0–N3私有阶段门完成；N4进行中，完整耦合资格未通过 |
| B 无Band2Band消融 | 双方同时删去整条Band2Band，判断不含BTBT时设备方程与求解器是否仍失败 | Sentaurus完成纯QS；Vela仍有非线性停滞，因此不能归因于NonLocalPath一项 |

线B没有用局部E2替代NonLocalPath。近期固定内电压0.00524437249039996 V的失败态研究，属于线B设备诊断，未求解新的外电阻接受点。线A的精度通道主要是私有实际装配候选，尚未整体接入线B使用的生产Newton。

同一偏置不是同一内部状态；保存后的场量不是此前Newton RHS的天然同态输入。原生比较必须绑定RHS1/RHS2、变量、接触reference/increment、单位、方程掩码和支撑。[S3][S4]

## 3 已取得的参考与阶段进展

### 3.1 原生轨迹与击穿电压

含NonLocalPath原版的旧归档及独立重跑，66×33个端量数据逐字节相同，正常达到停止条件；负载、KCL、分量及位移检查通过。独立线性插值BV为6.673594818971575 V，原SVisual显示6.67 V。末点内压7.3747807008 V、电流1.3798941247e-3 A/µm，是停止点而不是BV提取点。[S1]

无Band2Band原生单次完整轨迹也通过，65条端量记录，插值BV约6.67383 V。与含NonLocalPath结果仅差约0.238 mV，插值误差尚未单独证明，不能把小差认作已分辨的BTBT物理影响。[S3]

**历史约6.37 V属于不同参考身份，不是当前2022安装库原版的预设答案；PN2D约19.6 V又是另一个算例。Vela尚无本算例合格BV值。**

### 3.2 NonLocalPath功能阶段

NonLocalPath在这里指动态带间隧穿路径模型：根据带状态寻找路径，进行沿路径和能量窗口的积分，电子与空穴收集到不同空间支撑，再以成对事件账本守恒。单一局部`exp(−B/F)`源或同一个数组同时写入两类连续性方程，不能替代这个功能。

| 阶段 | 已完成范围 | 尚不能认领 |
|---|---|---|
| N0 | 原生版本、参数、双源、温度、导数控制与误差预算冻结 | 完整生产能力 |
| N1 | 配置、单位、带状态、双源和导数支撑的私有接口 | 任意输入均可接受 |
| N2 | 自主路径几何阶段门；后续推进全Si种子、代表身份和边顺序 | 所有事件边界的完整导数 |
| N3 | Si声子辅助私有内核及独立高精度性质检查 | 完整自洽模型 |
| N4 | 实际双源与完整RHS对照、统计与表示、局部及部分完整支撑方向研究 | 全状态完整Jacobian、Newton、负载与全轨迹共同通过 |
| N5–N8 | 部分导数研发已在N4诊断中提前开展 | 正式导数资格、前端能力晋升、原版全轨迹、两平台交付尚未收口 |

不能据阶段数给出可信的百分比进度：目前耗时集中在相消、状态身份和非线性耦合，工作量与阶段数不成比例。[S2]

### 3.3 线A已经解决或明显收缩的问题

- 自主归一化几何、边长计算和代表顶点顺序已在4156个Si单元身份上对齐，历史150个并列单元问题有实证规则；不应仍将“150个并列角都未解决”作为当前任务列表。
- 带状态、默认统计、BGN、SRH人口身份与近零求值、接触雪崩场回退及SG源支撑，已形成同态分项与完整RHS证据。
- 五态34215条独立方程在指定参考数学环境的私有候选中通过1e-8门；另14个原生非零控制的95802条方程通过，最大差约2.852e-10。这些是具名环境和状态下的资格，不能扩展为生产任意状态通过。
- NonLocalPath保精度通道使一组电子人口方向的158条内部响应失败降为零；三档实际方向各1639条非零双源行通过，全部4156种子参与，成对账本不平衡比约6.551e-18。
- 确认精度要贯穿路径点取样、占据差、标量源率和收集累加；仅将最终累加容器改为高精度不足以保留微小响应。

上述局部改善保留了原始binary64通道和失败记录，没有以固定QF偏移或源比例拟合取代原算子。[S4][S5][S6]

原生默认导数、原生显式`NonlocalPath(Derivative=1)`、Vela完整数学导数是不同契约。默认Jacobian可能保留近似项，不能直接要求它等于完整残差导数，也不能把开关关闭解释为已证明所有BTBT导数为零。

当前私有增广系统常用6843未知量（6842物理自由度加1个负载未知量）；生产全节点三变量探针为7800维。比较前必须消除边界／非活动行及缩放差异，维数不同本身不是缺物理项的证据。[S2][S4]

## 5 线B的离散与步长进展

### 5.1 零偏求解收敛不代表跨工具一致

原生产几何的Vela零偏可被自身接受，但与原生相比：电势最大差8.74208 mV；电子/空穴最大绝对ln比0.337894/0.338426；电场峰值归一化最大差33.2223%，均失败。

采用显式诊断组合：逐单元介电系数、`delaunay_transfer`盒规则、半导体`signed_transport`电荷体积后，电势最大差降到0.191881 mV，电子/空穴ln差降至0.00053418/0.000562235，三项场量通过。该组合没有晋升为默认配置。

独立原生几何场恢复从同一原生电势得到的场误差约1e-15；组合控制后的Vela电势经该恢复规则，峰值归一化场误差0.0160044%，但生产ElectricField输出仍约32.5527%。因此电势求解、输出场恢复、以及Enormal等物理消费的场必须分别核对。

独立Poisson重建仍约2.79e-6逐行误差，未达严格1e-8算子门；不能把终态ψ/n/p通过写成完整算子已对齐。[S7]

### 5.2 已实施的最小步修复

几何缩步曾在下一步低于MinStep时直接退出，遗漏MinStep本身。现已修复为：预算允许时补试恰好最小步，该步失败后终止；保留短末段、失败回滚和默认重试预算。115例4400断言、3项相关CTest、9项脚本回归通过。

原默认5次重试仍在0.0003125 V停止。显式增加到12次后，两条360秒诊断扫描分别取得15/19个完整非零接受点；最后完整外压约0.0013997462/0.0012346502 V，仍未到原0.01 V首目标。超时尾部不完整记录已排除。

恰好10 µV外步有正常退出且负载/KCL/行门通过的点，但未取得该点原生同偏置的完整场量资格。因此最小步修复是真实进展，也不能据此宣布原纯QS通过。[S8]

## 6 当前固定偏置设备排障

原生无BTBT在首个外压0.01 V处，内压约0.0052443724904 V，Id约4.7556153426e-10 A/µm。近期Vela诊断直接固定该内压，已移除外电阻迭代变量，仍失败。这证明外电阻控制器不是唯一阻碍。

以下不同保存态属于连续排障中的不同阶段，违规数量不能画成同一条已接受QS轨迹。

### 6.1 Jacobian采样与更新限制

初始重点失败态有285条违规：279空穴、6电子。718空穴的绝对残差约1.23625e-11，是真正主导行之一。

723电子支撑边QF差约7.45e-9～5.33e-8 V，生产Fermi输运Jacobian默认固定差分参数1e-6，扰动会跨越近零驱动力方向切换。诊断缩至1e-8后，五个目标节点15条自身方向通过1e-5门，723独立小方向误差约4.02e-9；完整交叉块尚未因此通过，生产默认未改。

原线性系统的分量后向误差约5.51e-14，低于1e-10门。但718原始QF步约−1.10116 V，被逐分量截为−0.1 V，并重新校正Poisson后，完整连续性方向被改变：

| 载流子 | 当前自由行残差和 | 原始JΔx之和 | 截断后JΔx之和 |
|---|---:|---:|---:|
| 电子 | −1.12673142e-13 | +1.12673142e-13 | −3.87098780e-14 |
| 空穴 | −3.64974308e-14 | +3.64974308e-14 | −1.15404981e-13 |

原方向抵消残差和，截断后两者都朝恶化方向。局部残差下降仍可能被包含全局闭合项的线搜索拒绝；错误名称`carrier_row_convergence_line_search_rejected`不能证明每次试探都直接败于行门。

统一缩放也失败：918空穴的原始QF步约−7.99822e9 V，导致整个向量缩放至约1.25e-11；20轮仍285条违规。增大分量限制到0.5 V只接受一轮，随后265条违规，亦未修复。

918局部残差几乎由约−9.90778e-18的SRH源主导，向负0.1 V几乎无改善；正向约0.930406 V存在实际残差零点。但这是有限分支诊断，超过原更新限制，且不能单独使全系统续算收敛。[S9][S10]

### 6.2 不能把所有弱行按同一种方式处理

当前内部量定义为：

```text
S_i = max(sum_edges |flux_i,e|, |SRH_i|, |Avalanche_i|, 1e-30)
Q_i = max(|SRH_i|, |Avalanche_i|)
ratio_i = |R_i| / S_i
```

本诊断的密度和通量资格入口关闭，源比例限制为0，因此活动自由行主要由`Q_i≥1e-18`选择；被选中行要求`ratio_i≤1e-3`。其他配置可有不同的资格入口，不能把这个简化当作全局规则。

被源资格选中行的尺度至少1e-18，比1e-30下限高12个数量级；初始285条阻断行中没有尺度下限支配行。因此SLOT的“尺度下限支配仅报告”不能直接豁免这些行。

1546/2084/2587电子存在亚ULP更新，但在该285行态中，1546已通过行门、另两条未被源资格选中；它们是表示诊断问题，不是本态的主要接受阻碍。低人口、弱Jacobian、微小更新也不自动意味着可忽略。[S11]

### 6.3 受限修正与动态资格的最新结果

对Poisson/电子块u与局部空穴块z作线性消元，曾构造保持相关线性方程的修正：

```text
du = −A⁻¹ r_u − A⁻¹ B dz
r_h,new ≈ r_h + C du + D dz
```

实际有限步能同时改善718、空穴范数和两类闭合，但违规285→345，新增行失败。冻结原资格集合和线性不恶化约束都不足以保证有限步非线性接受。

一个未满足原闭合门的有限恢复种子，经原求解器25轮后剩21条空穴违规；它不是从合格父态接受出的QS点。围绕这个21行态取得最新结果：

|---|---:|---:|---:|---:|
| 原21行末态 | 21 | 1346 | 0 | 0 |
| 小范围逐点修正 | 11 | 1346 | 0 | 0 |
| 加340/338耦合修正 | 10 | 1346 | 0 | 0 |
| 有限分支恢复 | 5 | 1326 | 20 | 6 |

## 7 目前可以排除的过度简化结论

| 不成立的推断 | 反证或限制 |
|---|---|
| 只要实现NonLocalPath就会收敛 | 双方关闭整条Band2Band，Vela仍失败 |
| 只是外压首步太大 | 恰好MinStep可接受且漏试已修复，但扩展扫描仍未到0.01 V；固定内压设备自身仍失败 |
| 只是UMFPACK没有解好线性系统 | 原始方向的高精度后向误差检查通过；准确求解错误或被破坏的线性化仍可失败 |
| 一律关闭迁移率场导数 | 电子与空穴响应不同，718仍需要场导数 |
| 所有低浓度或微小残差都可豁免 | 原阻断行无尺度下限支配，真实源资格仍成立 |
| 增大限幅或统一缩放即可 | 分量0.5 V仍失败；统一缩放被918巨大更新拖住 |
| 当前违规数0就已经修好 | 退出资格仍失衡，且原求解器4轮后再次失败 |
| 双源守恒或某个Jv通过代表模型整体完成 | 完整RHS、全部方向、事件侧、负载、Newton和全轨迹仍有未通过项 |

## 8 建议独立分析的可检验假设

以下为待判别方向，不是已确认根因，也不是本次新增的实施授权。

| 假设或问题 | 最小区分试验 | 必须保留的检查 |
|---|---|---|
| 逐分量截断破坏有用的耦合方向 | 同一状态分别计算原始、截断、Poisson回代后的JΔx及实际残差；受限求解与事后裁剪对照 | 所有块、行、闭合，不只局部范数 |
| 极度耗尽人口处局部线性化给出不可用方向 | 918及当前极弱行比较分支内导数、正负有限步、正性参数化及局部条件化 | 不用经验密度下限改物理；独立检查源/输运 |
| 变化的资格集合使候选评价不稳定 | 同时记录父态、当前态、试探新增及退出行；比较同一试探在各账本中的绝对/相对残差 | 账本不是擅自放宽或重写生产门 |
| 局部修正遗漏远处非线性影响 | 从340/338、612邻域和7条退出行开始，按实际响应扩展；加入Poisson与电子耦合 | 残差支撑、Jacobian支撑及正性一致 |
| 复读/重线性化状态与停止态存在隐藏差别 | 保存前后绑定人口、归一化主变量、QF reference/increment、缓存版本、J、R和方向；零更新复算 | 初始R相同仍不保证J、缓存和线搜索历史相同 |
| SG有限精度绝对值与微小增量存在表示契约冲突 | 同一实际人口方向，分离当前值、参考值、增量、舍入及事件侧；比较三档可分辨方向 | 不用固定补偿或拟合常数掩盖36条冲突 |
| 455条极小雪崩响应由曲率或链式求值误差导致 | 依据B/F及驱动增量选择同侧非零控制，比较宽指数计算与分阶段链式导数 | 不把下溢为零当作通过 |
