# SLOT LDMOS 局部行下降与邻接阻尼验证

本批把上一份行容差诊断中的手工两节点修正，做成默认关闭、独立调用的 Python
恢复器。`eps_row=0.001`、器件残差、全局闭合和负载线门槛保持原值；不修改 C++
求解器、不把诊断态加入生产账本、不恢复长扫描。重点验证能否在保持原全局条件
的前提下，修复少量载流子弱行，并识别误差向邻行转移时的适用边界。

**结果：三份原失败初值中两份恢复成功，均通过原完整器件资格和实际外压确认；
另一份三轮后仍超标，明确拒绝。已合格对照不产生修正。** 本批生产新增点为 0，
不是连续路径验证，也没有达到击穿电流判据。

## 修正影响与失败边界

p11_r2 自动选中 3588/3591 两条空穴自由度。最终 10 个场与上一批手工半步的
严格态逐值相同。相对本批原初值，仅两个节点的空穴 QF/密度改变，物理 QF
最大改变 6.69152e-9 V；psi、电子 QF/密度和量子势逐值不变。

p11_r0 首轮选中 3588/3591，次轮自动纳入相连弱行 3587，避免把误差反复推到
修正范围之外。仅三个节点的空穴 QF/密度改变，物理 QF 最大改变 1.93038e-8 V；
psi、电子 QF/密度和量子势逐值不变。两个通过态的 SG 漏电流与其各自原初值
逐位相同；离散复合源数组相对 L1 差不超过 4.764e-12，雪崩源不超过 1.386e-20。
这证明本批局部修正影响很小，不构成通用端电流误差上界或 BVDS 精度证明。

p11_r1 的最大行比按 0.003621→0.001811→0.001358→0.001188 下降，
修正范围由 2 个自由度扩大到 6、7 个，选定阻尼逐次减小。它仍不满足 0.001，
故没有输出可供调用者当作合格态使用的 `state_file`。全局条件通过和行误差下降
不能代替最终行资格。该样本还说明：提议更小不保证该初值更容易修复。

较早的一圈邻接版本在 p11_r0 的第二轮找不到可行下降；沿相连弱行扩展后，
相同初值两轮通过。p11_r1 数值轨迹不变，按行排序后按需检查全局条件使本机
实测耗时由 358.8 s 降为 231.9 s。前一版本及全部尝试保留在
[`build/s02neighbor/`](../../build/s02neighbor/)，冻结源码分别在其 `sources/`
和最终批次 `final/sources/`。这些是本次实测成本，不是跨机器的性能保证。

## 实现与验收边界

实现为 [`slot_local_row_repair.py`](../../scripts/slot_local_row_repair.py)。
`Policy.enabled=False`，命令行必须显式加 `--enable-neighbor-repair`。
它不是新的 C++ 收敛参数，也没有自动接入旧生产驱动。

1. 按原 `max(通量绝对值和, |复合|, |雪崩|, scale_floor)` 计算全部有效行的行比。
   修正范围包含全部超标行，并沿网格连接纳入行比不低于 `0.5*eps_row` 的同载流子
   弱行。不会遗漏一条超标行来凑自由度预算；超过 8 个自由度就有界退出。
2. 固定其他自由度，用物理 QF 的中心差分构造局部耦合矩阵。默认差分幅度
   `1e-6 V`、提议 QF 最大改变量 `1e-4 V`。QF 参考量保持不变，增量和密度按
   Boltzmann 关系同步修改。非 Boltzmann、未显式给出残差尺度等未支持配置拒绝执行。
3. 比较 `alpha=1, 0.5, 0.25, 0.125`，要求**全部有效行**的最大行比充分下降，
   不是只检查被修正节点。优先选择全部行通过的试探；否则选择全局条件通过的
   最佳下降试探。最多 3 轮，不增加原 Newton 最大迭代数或超时。
4. 先用行比排序，再对待选试探检查冻结全局条件。没有做全局探针的试探在记录中
   标为 `global_screen=null`，不得选中。已选试探必须保持原归一化块残差不超过
   `abstol=1e-9`，并通过原全局闭合检查；这是本修正器的入口与试探限制，不用
   `stall_floor` 放宽入口。原 `ResidualNorm::normalizedBlockL2` 的显式尺度用于
   计算该量，不能直接拿原始 psi 块范数与 `abstol` 比较。
5. 行比通过仍只是初值。必须重新运行原严格固定内压 Newton、全有效行审计、
   文件绑定验证；随后才在严格 SG 电流派生的实际外压上确认原负载线。候选探针
   或电路复用零残差不能代替器件资格。

`0.5*eps_row`、8 个自由度、有限差分幅度及三轮限制都是显式工程策略，
不是物理误差界或新的验收容差。实际外压确认不等于原提议外压上的独立复现。

## 配置与证据

采用生产失败点 `p11_r0/r1/r2` 的原严格 deck 和各自 Poisson 修复后的初值；
合格对照使用 `p10_r2` 的已合格最终态。偏压直接读取原 JSON，避免手输十进制
数字造成低位变化。各输入是同一父态下不同提议跨度的尝试，不拼接成连续路径。

- 网格：13,881 节点、27,275 三角形；每种载流子 12,634 条有效行。
- 300 K、Si/PolySilicon、原 IALMob 与雪崩配置、原离散测度；参考原点 36 V。
- `abstol=1e-9`、`reltol=1e-8`、`eps_row=0.001`、`scale_floor=1e-30`，
  原全局闭合 0.01、负载线容差 `1e-6 V`、电阻 `1e12 Ω·µm`。
- 使用已有 UCRT64 Release `build/s02merit/runner.exe`，SHA-256
  `20f5e126f06311ba1b7dbbdb0f83b21fba7c9f3d47d0b477ede3d81e5d86bbf3`；
  runner 具备 HDF5 与 UMFPACK 支持，不为 Python 修正器重编译求解器。
  局部小矩阵由 NumPy 求解；本批成功态的严格检查为零更新，不能据此宣称测得了
  完整 Newton 线性求解成本。
- 最终批次证据在 [`build/s02neighbor/final/`](../../build/s02neighbor/final/)，
  包含每个 FD/阻尼试探、完整验收、实际外压确认及冻结脚本。每例最多 360 秒，
  子进程最多 120 秒，四例串行批次总上限 1500 秒。

## 复现入口

在工作树根目录运行，使用全新输出目录：

```powershell
$env:Path = 'D:/msys64/ucrt64/bin;D:/msys64/usr/bin;' + $env:Path
D:/msys64/ucrt64/bin/python.exe -B scripts/slot_local_row_repair.py `
  --base build/s02bvgoal/p11_r2/strict/config.json `
  --state build/s02bvgoal/p11_r2/poisson_post/d/final_state.h5 `
  --runner build/s02merit/runner.exe `
  --output build/local_row_repair_new `
  --enable-neighbor-repair --max-seconds 360
```

默认从 deck 唯一 `bias_points` 值读取偏压；若覆盖 `--bias`，在 PowerShell 中将
十进制字符串加引号，避免 shell 先把数字转换成较短字符串。此独立工具只做局部
修正和原器件验证；本批 `batch.py` 另执行实际外压确认。未开启选项时不读取初值、
不创建输出目录、不启动求解器。

  文件绑定均通过；未安装或升级依赖。

当前适合保留为显式、有界的失败恢复选项，尚不能默认接入长扫描。下一步应针对
10% 点检查修正范围边缘的残差传播，比较提前纳入受影响邻行的策略，再做短连续
路径验证；不以增加 `eps_row`、无界加轮次或跳过原资格来换取通过。
