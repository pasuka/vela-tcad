基态目标支撑边的实际源、电子人口和迁移率与 Jacobian 辅助路径逐值相等。
两条主导边的驱动力及 alpha 在已测试的电子 QF 扰动中不变：

| 边 | 电子场 V/cm | alpha cm^-1 | 责任节点 |
|---|---:|---:|---|
| 366 | 53213.3747532 | 6.31391367006e-5 | 229 |
| 4132 | 45345.7098436 | 1.14067751891e-6 | 1308 |

该场取样下，不支持把当前偏差归因于电离系数切换或基态人口身份不一致。
按逐边两端源积分重建的 229／1308 实际源，按同一方程尺度与源账本相符。
这不证明其他状态、其他分支或任意扰动的人口链均已合格。

当前 QF 载流子截断默认值为 0。关闭另一载流子源复用的 R/J 散列和方向记录与原实现
逐位相同，排除该优化对**本组状态和方向**的贡献，不能推广成全局正确性证明。
原实现开启／关闭诊断记录时，R/J、状态、方向记录和逐行账本逐位相同。

## 带符号电流直接确认跨零

| 组合方向 h | 边 366 两侧电流异号 | 边 4132 两侧电流异号 |
|---|---|---|
| 1e-5 | 是 | 是 |
| 1e-7 | 是 | 是 |
| 1e-8 | 否 | 是 |
| 1e-9 | 否 | 否 |

例如 h=1e-9 时，229 两侧空穴残差方向分别为 −5.395811368e-11 和 −5.395811367e-11；
1308 分别为 6.616397466e-12 和 6.616397466e-12。h=1e-5 时两侧响应则一正一负。
这次结论来自实际带符号电流，未以 QF 差过零代替电流过零。

局部源含 G=A·alpha(F)·|Phi|。在 Phi 非零且不跨分支时：

    dG = A [alpha'(F) |Phi| dF + alpha(F) sign(Phi) dPhi]

本组主导边的 dF 为零，关键是第二项。若中心差分跨过 Phi=0，得到的是跨分支割线，
不能作为当前局部导数；在恰好零点时应分别报告方向导数，不假定存在唯一光滑 Jacobian。
原 Jacobian 的差分系数乘 max(1,|物理势|)，方向 h 作用于缩放主变量，两者须区分。
