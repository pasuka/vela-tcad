# 人口主变量的限制与停止条件审查（2026-10-29）

审查对象为核心`solver.state_variables: potential_density`及标准外接电阻入口。未知量为缩放电势ψ/V0与内部单位的n/p。QF仍由人口派生供GradQF模型和输出使用，其物理梯度不是未知量更新限制。

## 保留的条件

| 条件 | 实际作用与口径 | 处理 |
|---|---|---|
| 有限状态与正浓度 | 自由半导体节点n,p>0；氧化层零槽及约束节点有独立方程 | 保留 |
| 人口正值保护 | 每个Newton候选重查；非正候选局部回退到旧人口的指定比例，或显式选择到边界全局缩步 | 保留，默认1%，本轮未调整 |
| 线性系统精度 | 原系统后向误差与缩放线性残差核验、必要时修正求解 | 保留；不是非线性停止门 |
| 原始人口更新RMS | 以原始δψ/δn/δp及电压方向计算，不以正值保护/缩步后的较小更新冒充收敛 | 保留 |
| 方程残差 | Poisson和连续性方程残差，独立于采用QF还是人口坐标 | 保留 |
| 分块绝对残差 | 各方程块的无穷范数与其原有ceiling比较 | 保留；独立人口Newton启用时替代标量reltol/abstol |
| 局部载流子守恒与全局闭合 | 仍是同一物理方程的诊断；report只记录，enforce仍为硬门 | 保留原配置，不自动改门限 |
| 外电阻负载线 | Vin+RI−Vout，单位V | 保留 |
| 端口KCL与有限电流 | 标准外电阻入口在实际候选状态重算并验收 | 保留 |
| Newton电压修正上限 | coupled的max_inner_voltage_step_V只对标量内压方向设限，并一致缩放耦合方向 | 保留；不是浓度/QF混合限幅 |
| 延续预测内压增量 | 用于选择下一次外压目标，与单次Newton更新和坐标选择分别定义 | 保留现有参数/推导及0.02 V回退 |
| 外压步长上下限、增长、失败缩步、重试/轮次上限 | 控制继续求解/失败退出，不是解已收敛的证明 | 保留 |
| 物理模型适用性 | 当前BVMethods/JD、300 K、模型与网格资格 | 保留；换坐标不扩大物理适用范围 |

残差结构中的phin/phip以及residual_weight_phin/residual_scale_phin等历史字段名，在这里标识电子/空穴连续性**方程块**，不是QF更新大小；换成人口未知量后仍有效，未删除这些残差权重或归一化设置。rawStateUpdateNorm跨坐标分量的最大值只作诊断，不作为人口收敛门。

独立人口Newton目前以方程残差为停止条件，并报告原始人口RMS；外电阻`coupled_update_convergence`支持off/report/enforce/enforce_joint。`enforce`保留残差或RMS的历史语义；`enforce_joint`要求二者，零外压/零内压的无更新初始锚点例外保持原规则。切换坐标不自动改成仅RMS停止。

## 移除与入口清理

人口模式此前已在核心构造器拒绝非零QF电压限幅、混合未知量`max_update`、QF参考与若干旧恢复设置；因此不能把本次审查描述为关闭了此前仍作用于当前BV的QF限幅。

本轮将同一坐标政策用于C++构造及JSON解析，提前拒绝以下组合：

- QF全局/少子电压限幅、QF信赖域及其动态半径、QF参考/重定位；人口模式不创建QF限幅回调。
- 将电势和浓度一起按一个未经单位区分的`max_update`裁剪。
- QF接触多数载流子分支停止规则，以及尚未接入人口Newton的旧merit/stall接受策略。
- 当前人口路径尚未实现的旧行缩放/Gummel恢复/正则化、旧线性均衡、旧有限差分Jacobian选择，以及开启线搜索时的旧block_filter模式。后四类并非数学上不能用于人口坐标，而是不能让配置被静默忽略。

CMD人口模式生成的JSON移除遗留的QF限幅/参考/信赖域/重定位空选项；显式激活时提前报错，不静默丢掉用户要求。既有手写JSON中的零限幅和默认空配置仍兼容。QF未知量模式保留原选项。GradQF迁移率及碰撞电离驱动场继续保留；接触QF物理一致性检查也不因求解坐标变化而删除。

独立Poisson初始化仍由其专用求解路径执行，保留Poisson专用残差/线搜索控制。本轮没有把Poisson初始化的停止条件替换为人口联立条件，也未新增“人口RMS过大即成功”的规则。

## 修正的重复停止门

`solvePopulation`原来始终建立标量`max(abstol,reltol*初始残差)`，同时又通过回调要求`block_absolute_convergence: enforce`，违反权威分块规则替代标量门的现有配置契约。现在该模式用三个原始残差块的`max(块无穷范数/原ceiling)`，以≤1判定，继续保留载流子/全局enforce回调。未启用分块绝对门时，原标量范数与停止逻辑保持不变。该模式报告的标量残差为分块ceiling归一化最大比，物理块值仍在finalBlockNorms中。

这项修正只影响独立人口Newton的显式分块绝对模式。外电阻coupled配置自己的方程容差、RMS、负载线、KCL及各门enforce/report语义保持原值。
