# BVmethods 自主局部迁移率、弱行及 BTBT 实际场对照（2026-10-13）

本轮在 T470p 完成了自主 Masetti／Lombardi／HFS 固定态重算及两次私有 C++ 实际装配。
局部迁移率与原生闭合到约 1e-11，但输运弱行余差仍在。新原生零源观察器确定了本固定态
E2 使用的节点场，并发现 **BTBT 参数未对齐**：Sentaurus 实际导出的 A2/B2 为
3.5e21 / 2.25e7（cm 制），此前 Vela 对照使用 3.4e21 / 2.26e7。
原生节点场配合实际参数能重建 E2 源至约 3.55e-15；自主场恢复和完整 Jacobian 尚未闭合。

接续[逐边／Poisson／源支撑记录](bvmethods_edge_poisson_source_2026-10-13.md)。
详细数值、执行身份及封存收据见[配套 JSON](bvmethods_mobility_weak_btbt_2026-10-13.json)。
本轮完成对照及局部候选，**没有认证完整 RHS、完整 Newton 导数或从零高压纯 QS**。

## 2. 自主局部迁移率与实际残差

从原网格自行寻找 Si/绝缘体界面线段，计算端点最近距离、单元距离梯度、线性电势梯度，
再按原掺杂自行计算 Masetti、Enhanced Lombardi 和 Canali；没有反算或拟合局部迁移率。
距离梯度不强行归一化。原生 HFS 连续三次回调与元素／顶点身份一一对应，六轮 ψ、F、µ 重复一致。

首版诊断脚本漏掉了 Lombardi 的 N0=1 cm^-3 归一化，产生约 2.6% 低场误差；v1 完整保留，
纠正后低场电子／空穴相对 L2 约 1.32e-11／3.57e-11。界面距离相对差约 1.28e-16。

HFS 的独立几何规则为：接触相邻单元使用完整电势梯度；其他单元使用真实输运边界切向
投影后的 QF 梯度；多条不平行边界相交时投影为零；驱动力低于 1 V/cm 时记录为零、µ 保持低场值。
此规则复现电子／空穴驱动力至相对 L2 8.34e-15／1.64e-15。
仅按接触节点回退、忽略切向投影、按节点边界分别投影等候选均另存，未选择误差最小者作为生产默认。

自主 µ 经原生元素顶点盒平均、原生边系数送入此前验证过的私有实际装配入口：

| 共同自由行实际输运 | 相对 L2 | 最大绝对行差 |
| --- | ---: | ---: |
| 电子 | 9.76007213e-5 | 9.71201795e-15 |
| 空穴 | 4.81847108e-4 | 1.06615591e-16 |

与直接使用原生 µ 的实际装配最大差分别仅约 6.54e-23／4.69e-23。
因此本固定态剩余输运差不能再由“没有自主计算局部迁移率”解释。
此入口把新计算的 µ 固定用于本次值对照，**不具有完整 Newton 导数**。

## 3. 弱行、操作数和局部导数候选

保留全部边及 reference/increment 原始十进制栏位，分别检查双精度、端点先相减的扩展精度、
直接 QF 差和 Vt 指纹替换。四路输运结果几乎一致，未消除当前弱行余差：

| 行 | 原生输运 | 扩展精度重建 |
| --- | ---: | ---: |
| 电子 2156 | 6.198930848075017e-11 | 6.199902049869999e-11 |
| 空穴 2515 | 2.252746269366258e-13 | 2.251680113452747e-13 |

9070 条载流子边检查中，双／扩展精度 QF 差没有方向翻转；反向端点 SG 的反对称相对误差
约 1.11e-16。原 152/784/409 与新 2156/2515 的边记录均保留。这只认证重建内部方向一致，
不把未导出的原生边通量假定为已匹配，也不能排除厂商内部未导出的高精度操作数差异。

新增[局部候选工具](../../scripts/bvmethods_local_mobility.py)对实时 ψ/QF 计算局部 µ 及解析偏导，
先减端点再乘梯度矩阵，避免公共偏置参与近零场的点积消去。零法向场返回标量右导数；
与 abs(E·gradDistance) 组合的尖点不认作平滑。

首版对全部单元直接中心差分，跨零法向场时出现约千项表观失败，原结果保留。
后续按法向场符号及 HFS 分支限制扰动，并记录截断误差与浮点分辨率：每种载流子
8312 次 ψ/QF 方向探针中，8172 次可分辨平滑探针全部在独立差分误差界内，
140 次尖点／量化受限探针单列未认证。误差界由两种差分步长之差和机器舍入估计构成，
没有修改任何既有 PDE、弱行或 QS 验收门限。

这仍是固定 bulk/掺杂的局部本构偏导；统计人口链式项、实际装配交叉块、源导数及跨分支
有限步尚未认证，不能将局部检查代替全系统同方向 Jacobian 检查。

## 4. BTBT 原生实际场与参数差异

在 VM 新目录添加 PMI_Recombination 零源观察器，返回零速率和全部零偏导，保留原始
SRH、Band2Band(E2)、Avalanche。它记录原生回调场幅值及 `ReadVector("ElectricField")`。
基线／观察器的 before 和两次 Newton TDR 全部数值数据集逐值一致；首个 debug 的变量、
RHS1/RHS2、矩阵和更新向量也逐值一致。观察器未改变被观察系统。

首次流文件以截断方式打开，只保留末次状态；改为追加后保留 6456=3×2152 条记录。
按坐标和 n/p 双重选择原固定态，人口逐值相同。接触副本不通过坐标末写覆盖原节点。
回调场幅值与 ReadVector 范数最大差 5.82e-11 V/cm。

安装材料文件的 E2 参数与随后独立 `sdevice -P:Silicon` 导出一致：

| 参数 | 本轮前 Vela 对照 | 原生实际导出 |
| --- | ---: | ---: |
| A2（cm 制） | 3.4e21 | 3.5e21 |
| B2（V/cm） | 2.26e7 | 2.25e7 |
| A2（SI） | 3.4e23 | 3.5e23 |
| B2（V/m） | 2.26e9 | 2.25e9 |

以导出参数计算 `G=A2*|E_node|²*exp(-B2/|E_node|)`，全部 2121 个共同自由节点
与内置 Band2BandGeneration 相对 L2 为 **3.55e-15**；沿用旧参数则为 **0.22553164**。
因此本态 E2 场支撑及公式已由原生观察／参数输出闭合，不再仅凭场量名称推断。
这是版本／配置对齐证据，不是拟合；生产全局 BTBT 默认尚未改。

自主恢复原生节点场仍未成功：单元面积平均、原生盒平均、等权、邻边距离及原生 kappa
最小二乘等均保留完整矢量和 E2 误差；不能仅根据某个源范数较小就认证其算子。
本轮新增显式参数的节点 E2 积分／场偏导工具及性质测试，尚缺该场恢复对 ψ 的真实链式导数。
