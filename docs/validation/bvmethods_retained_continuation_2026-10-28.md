# BVMethods：50%人口保护的多偏压续算验证

日期：2026-10-28。承接[保留比例1%／10%／50%同态对照](bvmethods_retained_fraction_2026-10-28.md)。
数值摘要见[配套JSON](bvmethods_retained_continuation_2026-10-28.json)。

## 主实验结论

T470p、C560的50%路径均接受了0.8至1.25 V的8个新增目标，
越过此前0.9115022534811835 V的失败目标，接受点的逐行及全局闭合报告均通过。
固定1.5 V目标未通过预测校正和上一接受态重试，原定至2 V序列没有完成。

从同一健康50%状态切回1%，两机也都接受到1.25 V。因此，早期改进的重要作用是
避免最初检查点形成不良人口尾部；不能把后续进展全部归因于持续使用50%。
这不是从零完整BV通过结果，也不支持直接将50%提升为生产默认。

## 配置、目标与控制

- 300 K；2600节点、2152个Si节点；R=1e7 Ω·μm。
- BTBT关闭，Joyce–Dixon／OldSlotboom，原迁移率、SRH、GradQF AV。
- 复用上轮Release／PARDISO单线程二进制及运行库，逐机校验SHA256。
  没有重新编译核心或修改生产代码。源码、二进制校验值记录在数值摘要中。
- 完整系统7801维、默认约束消元后6765维，relative_population列。
  自适应人口选择、target_normalized排序、自动导数恢复、六项复用保持不变。
- 原物理门、原始人口RMS、1e−10线性后向误差门保持不变。
  逐行及全局闭合保持原来的报告／强制属性，没有新设或放宽门限。
- `local_retained_fraction=0.5`仅改变局部回退；全局到边界分支的
  `fraction_tau=0.99`保持不变。两者不是同一个参数。
- 每个目标最多40轮预测校正，失败后最多一次40轮上一接受态重试。
  每组独立900 s监督上限；实际是否超时由数值摘要单列，不能和数值失败混用。

共同目标列表为：

```
0.8, 0.85, 0.9, 0.9115022534811835, 0.95,
1.0, 1.1, 1.25, 1.5, 2.0 V
```

这是固定目标的有界回放，保留线性外推及接受态重试；不执行完整扫描的外压
自动缩步／增长调度。配置中的步长参数未修改，但不能据此声称两种调度等价。
本轮没有重跑Sentaurus。

主控制包括：

1. **自身1%路径**：从共同入口重现0.7562717828569232 V的1%尾部状态后续算。
2. **自身50%路径**：重现同一目标的健康50%状态，再继续使用50%。
3. **健康50%状态→1%**：从已保存健康状态及上一接受态构造相同后续目标。
4. **健康50%状态→50%匹配重启**：与第三组使用相同归档状态和配置，仅保留比例不同。

前两组的初始检查点迭代逐值复现上一轮记录。后两组用于排除读档与内存续算差异，
其状态字段逐位一致性与仅比例不同的manifest检查在数值摘要中单列。
各组从各自的入口和连续接受态外推，不从失败试探态继续。
两机匹配重启的全部状态字段均逐位一致，manifest只差保留比例；
50%内存续算与50%读档重启在共同目标上的完整迭代记录分别逐值一致。
因此不能将这组后续差异归因为未检查的读档舍入。

## 固定1.5 V目标的新困难

以下为T470p主50%路径，C560结果另见数值摘要。

- 预测校正完成6轮后，第7轮的完整／近似候选均不能通过原线性精度门，
  报告后向误差约2.92e−9／3.05e−9，高于1e−10，停止为无有效人口候选。
- 从1.25 V接受态重试40轮后仍未通过。末轮限制源为空穴节点632，
  α≈1.61646e−5、原始RMS≈2.43852e6，设备残差∞≈0.102136。
- 健康入口切回1%的路径在1.5 V也失败；末次接受态重试由空穴节点654限制，
  α≈1.35496e−6、原始RMS≈2.39946e6。

这与最初节点384电子尾部的局部回退问题不是同一组状态或弱行。
完整与近似候选都出现过线性精度问题，不能把新失败唯一归因于此前已知的
近似矩阵相减消去问题，更不能在未核验新状态导数前判定某个物理公式错误。

### 局部50%不等于全局每步最多下降50%

全局到边界分支对限制节点使用α=τ·c/(−δc)，所以更新后为(1−τ)c。
在原τ=0.99下，这个分支仍可将限制节点降至1%，即使局部保留比例设为50%。
自适应排序选中全局分支时，局部50%候选并没有被应用。

T470p主50%路径在1.5 V接受态重试第40轮，限制节点632的空穴人口从
58281.1755873降至582.811755873 cm⁻³，比例为0.010000000000000118；
实际Δfp≈−0.119049907 V、Δψ≈2.95177e−6 V。
该状态及更新前状态已保存，数据来自HDF5字段，不是仅用日志反推。
因此本轮不能解释成所有人口更新都已限制为保留50%，也没有证明更改τ必然收敛。

## 半步控制与验证边界

为区分0.25 V固定跳变与人口保护比例的作用，额外从50%路径的健康1.25 V接受态
及1.1 V上一接受态构造半步序列：1.375、1.5、1.625、1.75、1.875、2 V。
仍使用50%、原线性外推、原40轮预算及一次接受态重试，未放宽任何门。

T470p在1.375 V用了18轮满足原停止门，但逐行闭合最大比约1.98547，
最低电子／空穴浓度约5.765e−8／5.859e−8 cm⁻³；不能视为弱行平衡通过。
随后1.5 V的预测与接受态重试各40轮仍失败，末限制源转为电子节点533。
因此该半步控制没有解决后续失配，也没有完成2 V目标序列。

C560在1.375、1.5 V分别14、21轮满足原停止门，但逐行闭合最大比约
1.73163、1.98597，均未通过。1.5 V最低电子／空穴人口分别约
7.460e−14／4.057e−42 cm⁻³。随后在1.625 V的预测校正与接受态重试各40轮仍失败，
末限制源为空穴节点710，α≈1.03921e−4、原始RMS≈16514.0。
这些额外接受点不能代替两机共同闭合窗口的通过证据。

|---|---:|---:|
| 原1%尾部继续 | 0／2 | 0.756272／0.85 |

前四组的新增目标从0.8 V计数；半步组从1.375 V计数，不能直接把计数当成同一网格的速度比较。
两机共同通过原停止门及逐行闭合报告的连续新窗口仍为0.8至1.25 V。
所有组均为数值失败或预算耗尽结束，没有监督超时；所有匹配重启及状态字段检查通过。
实验按机内顺序执行，归档下载后校验SHA256，失败系统和状态另行保留。
时长包含入口重放、诊断和状态输出，不作纯求解器性能结论。

本轮只增加有界验证清单、结果分析与记录，没有修改生产默认比例或验收门。
下一项定位应针对1.25 V健康态到1.375／1.5 V试探过程，检查新弱空穴行及节点533的
候选进展、同态Jacobian／RHS与方向导数；同时保留完整和近似系统的线性精度审计。
应将局部保留比例与全局到边界τ分开作同态控制，记录实际被选中的候选；
不能只根据局部参数名称判断实际浓度下降幅度。
尚未以这些结果给出新的击穿电压。
