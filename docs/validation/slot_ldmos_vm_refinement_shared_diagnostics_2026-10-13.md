# SLOT VM 线性精化、共享诊断及大跨度复验

2026-10-13。针对六次近零空穴行线性保护拒绝，新增显式可选的残差精化，
保持原 A、b 和全部线性保护阈值。六份冻结系统均通过；从同一 6 mV 父态
到 13.008 mV 的两种修正方法独立有界复验均达到原 RHS 标准。共享评估的单步配对保持
场量、RHS、原始更新误差、闭合和接触电流一致，实测进程耗时减少约 19%。

本批使用独立 VM 源目录和输出目录，没有替换既有长任务的冻结 runner、
配置、预算或父态。真实远端路径、作业标识、运行脚本和哈希在忽略目录
`build/s13vm_refine/remote_manifest.md` 与证据包中。

## 1. 固定条件及实现范围

- SLOT 13,881 节点、27,275 三角形，Vg=5 V，Vd 物理原点为 0 V。
- 保留 AverageBox、Fermi、有效带边 SG、完整电离和原材料配置。
- 浓度有限步 beta=0.001，电势对数阻尼；载流子正则化和闭合替换关闭。
- PARDISO double，保留所有 ψ，仅消去 2,494 个载流子约束；完整/实际系统
  维数为 41,643/39,149。Linux GCC 16、Eigen、MKL 环境，HDF5 状态支持启用。
- 本批重放和非线性配对统一使用 1 线程；此前原拒绝记录使用 4 线程。
  保存矩阵上的校正从原记录的方向出发，重新装配的运行不能与旧四线程方向
  混称逐位相同。
- 原完整 Jacobian 方向继续计算 U，并通过原系统保护；省略输运迁移率
  QF 梯度直接导数的第二方向用于实际诊断更新。两套 RHS 每步逐位核对。
  没有删除原系统求解，也没有把一套 Jacobian 的数值分解用于另一套。

新增选项均默认关闭，限定在现有 SLOT opt-in 内存入口：

| 选项 | 行为 |
|---|---|
| `linear_factor_refinement_steps` | 0–3 次；long double 累加 b−Ax，用同一 A 的保留分解解修正 RHS，再写回 double |
| `linear_row_refinement_sweeps` | 独立的 0–4 轮通用弱行坐标松弛；与前项互斥 |
| `shared_diagnostics` | 共享同态装配准备；仍显式组装、求解两套 Jacobian；所有端口共用一次原始反力评估 |
| `compact_diagnostics` | 每步标量保留，详细 CSV 在主标准满足、限额结束等审计点保存；相同矩阵用别名清单去重 |

任一精化只有在全矩阵混合误差、块误差、约束误差均通过时才替换方向，
否则保留原方向及原拒绝。未硬编码节点 5615，未放宽阈值。
消元后端保留缩减系统的 solver：相同矩阵重用分解，改变数值、结构或显式
清缓存时重新分解；每个新 RHS 都重新计算仿射约束消元和回填。

## 4. 同父态大跨度有界复验

固定旧 d001 目标 13.008 mV，直接从原 6 mV 父态求解；不再先减半。
每臂最多 25 次更新，软上限 1080 s、进程硬上限 1200 s，随后单独零更新复读。

行校正臂 4 次更新达到 RHS 条件，约 487.63 s；末态 rho=5.361103487×10⁻¹¹，
U=2.5176（未通过 U，但 R 通过），电子/空穴闭合比为 2.3907×10⁻⁶ /
2.3919×10⁻⁶，末步投影 0/0。最小空穴密度约 1.1954 cm⁻³，无影子 QF
盒越界。零更新复读的 RHS 与内存末态完全相同，漏极 SG 电流
2.090390566×10⁻⁶ A/µm。

该一线程重装配首方向的混合比为 13.4540，经一次通用行校正降至 0.45511；
它与原四线程保存方向的 3.40166 不同，不能据此改写旧证据。

保留分解精化臂也在 4 次更新后达到 R，进程耗时 489.24 s，外部零更新
复读另计。末态 rho=5.410408266×10⁻¹¹，U=2.51759694；电子/空穴闭合比
为 2.39073935×10⁻⁶ / 2.39188770×10⁻⁶，边界保持、逆映射误差
2.00×10⁻¹³、末步投影 0/0。漏极电流与行校正臂相同，保存态复读的残差
和漏极电流分别与内存末态完全相同。没有由此声称两臂所有场量逐位相同。

该臂逐行报告仍有 52 条电子、1,360 条空穴行超出 0.001；本批沿用用户已选
R/U 接受口径，不把这些行隐去，也不将 RHS 达标解释为所有局部行达标。
两臂约八分钟的耗时接近，表明线性精化主要消除了不必要的拒绝，而不是
直接显著加速单次非线性更新。与原先零更新即拒绝的大跨度相比，这是
当前目标可达性的改进，尚不足以保证高偏压段都能用同样跨度。
