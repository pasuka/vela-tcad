跨态方向采用已采集的两个实际人口状态之差，2121个电子人口坐标非零；没有改用保存请求的意图方向。
人口采用原生归一化值，参考浓度`1.4824351e10 cm^-3`；NonLocalPath带量用J，双源积分用`m^-1 s^-1`。

## 2. 36条SG共同门冲突的来源

对三态各273条实际边支撑，逐步引入原生的参数、Bernoulli、乘积及长度往返舍入。
各阶段使用相同人口和带状态；下游迁移率传递因子由已捕获的消费值作**观察性分解**，
没有把该商值当作可部署迁移率实现或拟合修复。全部边的原始电流非零，未用零除特判遮盖支撑。

| 逐步加入的求值环节 | 41条目标行中共同门不相交数 |
| --- | ---: |
| 保精度SG参数／Bernoulli／乘积，观察性下游传递 | 0 |
| 换为原生binary64参数`a` | 35 |
| 再换为原生Bernoulli值 | 35 |
| 再引入乘积舍入与相减 | 36 |
| 再引入除边长／乘回边长 | 36 |
| 实际捕获的PDE乘积 | 36 |

第36条由乘积舍入增加，节点为2185。参数`a`阶段的最大方向差约0.08258，
最终约0.08282；长度往返最大原语变化约`2.274e-13`，本批没有新增冲突。
观察性全宽控制的最大方向差约`1.787e-11`。

因此本批冲突的主因已收窄到有效SG参数求值的有限精度，随后是Bernoulli和大数乘积相消；
不能再仅用外电压步长或长度往返解释。上述分解没有消除真实验收失败：
**原36条共同门冲突、三态38／39／38条目标绝对失败，以及旧正QS的95条失败均保留。**
这仍是指定SG算子、状态及冻结预算的结论，不外推成完整RHS无解。

## 3. 雪崩：局部速率、逐单元增量与极小指数

独立重建全部8312个电子／空穴单元源，使用同一人口、QF reference/increment、代表顶点和几何。
本轮只改变电子人口；低场迁移率与该方向无关，采用已捕获的低场值，重新计算高场迁移率、
SG电流、驱动力、雪崩系数及其方向导数。该控制不是任意ψ／人口方向的完整迁移率资格。

发现两个精度断点：实际私有链先把局部`generation`落为double，随后才高精度累加；
即使局部速率保精度，先累加绝对源再相减，也会吞掉远小于同一行背景源的响应。
后一个控制改为先求每个电子／空穴单元的增量，再按固定体积和装配因子累加。

针对上轮1/64步长仍失败的**原50条行**，保留完整入射源支撑后得到：

| 相对原实际正向人口增量 | 通过原方向门 | 失败 |
| --- | ---: | ---: |
| 1/64 | 20 | 30 |
| 1/512 | 47 | 3 |
| 1/4096 | 50 | 0 |

最细档最大方向差`2.098e-6`。2154行在1/64档恢复增量约`−2.64644e-161`，
与独立Jδ的差约`2.244e-10`；原来的零观测没有被按“小到可忽略”改判通过。
缩小同侧步长消除了这组剩余有限步长余项，门限保持不变。

与**上轮C++导数**对照仍是49／50通过；1935行在最细档失败约`4.031e-4`。
其主导电子单元3471的场约1665.854 V/cm，`exp(-B/F)`约`1.186e-321`，位于double次正规区。
先求指数再乘A得到的系数，与宽精度值的比约`1.0008106439`。
仅将该指数舍入效应传播回独立单元Jδ，即与旧C++值相符至`1.928e-9`。
反过来，仅把宽精度梯度存成double并不能产生这项差异；主因是上游指数求值。

这50条控制通过不等于全雪崩装配通过。拓宽指数范围还恢复了许多原double下溢为零的源；
全2121行在1/64档的独立逐单元增量控制仍为1388通过、368失败、365零响应，账本保留。
后续须同时保留当前绝对源、独立增量及一致导数，并明确下溢的表示契约。

## 4. 完整NonLocalPath路径／谱／收集Jv

独立链对全部4156个Si种子重新生成路径、转向／边界处理、能量窗、递归谱求积和两端收集权重，
包含远端支撑。基态加六个扰动态共29092次种子求值全部解析，无路径异常。
带边和QF独立绑定实际C++保精度投影前字段，最大绝对差不超过`7e-98 J`。

| 方向 | 非零双源行通过数 | 零响应行 | 最大方向差 | 分支事件变化 |
| --- | ---: | ---: | ---: | ---: |
| 实际电子人口跨态方向 | 1639 | 3561 | 3.085e-11 | 0 |
| ψ437，中心步长1e-6归一化电势 | 18 | 5182 | 3.725e-10 | 0 |
| p1318，原方向倍率1e-4 | 12 | 5188 | 1.046e-9 | 0 |

行数包含电子和空穴各2600个节点，接触收集也在账本内。电子人口方向的自由行中1627条非零、2615条零响应。
双源Jδ总量守恒差低于`4e-81`；19个种子、306条非零方向从80位升至120位，最大变化约`1.877e-75`。
这些是完整自主源链在指定三个方向上的通过，尚不是完整增广Jacobian／Newton资格，也不覆盖跨事件方向。

自主基态与实际C++双源的逐行相对差最大`4.886e-12`；但沿实际人口方向比较现有C++源变化，
仍有**160条**超`1e-5`门，最大约0.1155。
为区分入口与内部误差，又在相同binary64带状态下重做三态、12468次种子求值：
独立源链对实际带量增量的1639条非零方向全部通过，而实际C++仍有**158条**失败，最大约0.2384。

因此入口投影不是全部差异的充分解释。当前C++内部`sample`、转折点QF插值、`logOccupation`
以及标量源率仍经过double；最终100位收集累加不能恢复这些环节已丢失的响应。
同态投影控制保留了这158条失败，尚未逐环节定量归因，不能把独立完整链通过写成实际装配Jv通过。
