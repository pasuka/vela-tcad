## 已加入的核心接口，尚在验收

- `solver.state_variables="potential_density"`，缺省仍为 `potential_quasi_fermi`。
  首期要求显式 BVMethods 物理 profile 和相应统计／模型。
- 状态布局为 ψ/V0、内部物理单位 n、内部物理单位 p；线性列缩放与状态存储分离。
  氧化层人口槽为零并由精确约束消除。
- Tri3 输运、SRH、AV、Poisson 和端口导数直接使用人口；QF 由统计反函数派生。
  直接矩阵以旧 QF 矩阵的链式变换和独立有限差分作对照。
- 每轮、每个试探 α 都重新检查非正自由人口；正值检查与整体步接受独立。
  保存原始人口方向，误差诊断使用实际更新后人口作分母。
- 核心约束消元通过显式接触／非活动行元数据工作，保留非零 RHS 和回代。
- 状态归档增加人口权威标识，拒绝混用 QF packed 缓冲区；基础输出仍包含派生 QF。
- JSON schema 和 CMD sidecar 显式携带新数值选项；物理模型仍来自 CMD／材料输入。

实现的存在不等于上述全部接口已经完成验收。尤其尚未将检查点通过等同于全程 BV 通过。

## P3／P4：核心求解和两种入口
