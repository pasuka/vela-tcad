# BVMethods 独立 Poisson→联立零偏对照（2026-10-23）

本轮已重新运行 Sentaurus `sdevice -d`，并让 Vela 从自身初值完成同样的
Poisson→联立顺序。**当前生产配置的主要差异已经出现在纯 Poisson 阶段**：
最大电势差 8.742 mV，进入联立后基本不变。显式几何与材料诊断控制把差异降到
0.153 mV，硅区人口通过 1% 门；但同态 Poisson J/RHS 仍未通过算子一致性门。
Vela 增广矩阵经等价消元可由 7801 维降至原生内部的 6843 维；维数一致不能替代数值一致。

机读证据：[本轮摘要](bvmethods_staged_zero_2026-10-23.json)。本轮没有修改生产默认值、
算例模板、验收门限或求解器实现，没有进行 BV 扫描。

## 输入与范围

沿用[当前外电阻交接](bvmethods_external_resistor_handoff_2026-10-23.md)的
**整条 Band2Band 关闭控制**。源为安装库 resistor 分支的对应控制输入，
保留 300 K、Fermi、OldSlotboom、Masetti 总杂质迁移率、Enormal、
GradQuasiFermi 高场饱和、SRH(DopingDep)、Avalanche(GradQuasiFermi)。
它不能替代原版 NonLocalPath 全模型验收，也没有将旧 E2/Eparallel 模板作为原版。

## 顺序和停止状态

原生依次执行 `Coupled(Iterations=100){Poisson}`、保存 Poisson TDR、
`Coupled{Poisson Electron Hole}`、保存联立 TDR；其余 Physics/Math 控制保持输入原样。
本轮轨迹包含 7 次 Poisson 更新、1 次联立更新。原生 Poisson→联立的最大电势变化
只有 `3.7093e-13 V`。原生末次联立按更新误差 `7.2575e-8 < 1` 停止，
其日志 RHS 从 `5.27e-3` 变为 `1.14e-3`；这些量不是 Vela 的残差归一化或停止门。

Vela 调用 `solvePoissonOnly(coldInitial)`，7 次更新收敛，再从自己的 Poisson 解
进入 drain 外电阻增广系统。各控制在联立入口即满足标量残差门，执行 **0 次联立更新**；
生产基线设备残差约 `7.12e-11`，负载残差、内压和 drain 电流均为零。
设备定内压重闭合诊断同样为 0 次更新。

所有 Vela 载流子行在零流下都低于资格地板：5200 行 ignored、qualified 为 0；
电子/空穴全局闭合也都未获有限流资格。因此摘要中的 `physical_accepted` 仅表示
所启用门的 satisfied 状态，**不能解读为有限 RHS 更新、弱行或 BV 的验收通过**。

包括欧姆接触和少子，不剔除不利节点。按全局 node ID 对齐，不拟合电势常数或 QF 偏移。

这组新运行表明：Poisson 电荷体积和局部介电几何是当前场量差异的主要来源，

但这些控制仍保留生产积分统计与原生默认统计近似的不同；余差尚未逐项隔离，
不能据此认领本构完全一致。

## 同态 Poisson J/RHS

独立求解完成后，另将原生第 0、3、6 次 Poisson 装配前电势送入 Vela 的诊断装配，
固定电子/空穴 QF 为零。这些参考电势**不用于初始化或推进上节的独立解**。
所比较的是固定 QF 的非线性 Poisson 导数，包含人口对电势的响应，
并非人口坐标 DD 矩阵中缺少这部分链式导数的 ψψ 块。

两端均为 2600 维。J 按各自对角元作行归一化，统计最大逐行相对 L2 差；
RHS 同样除对角元，再按各自 packed 电势尺度转为 V，避免将行缩放/坐标尺度当成差异。

| 控制 | J 最大逐行相对差（P0／P3／P6） | P0 RHS 相对 L2 差 |
|---|---|---:|
| 生产基线 | `0.133460 / 0.133460 / 0.133460` | `1.18496e-2` |
| 几何＋材料 | `7.48687e-4 / 7.49383e-4 / 7.49383e-4` | `2.81177e-4` |
| 再用旧常数 | `7.47385e-4 / 7.48081e-4 / 7.48081e-4` | `2.80927e-4` |

生产 J 最差节点为 3；几何＋材料后为 1308。
P6 的原生对角归一化 RHS L2 仅 `1.45345e-7 V`，几何＋材料控制的绝对差仍有
`1.38833e-3 V`。因此不能用近零 RHS 的相对数放大掩盖其绝对差，
也不能把此处的差异解释为仅有停止精度或 debug 序列化误差。
**同态算子 `1e-8` 门未通过。**

## 联立矩阵维数与等价消元

| 系统 | 维数 |
|---|---:|
| Vela 设备三块 | 7800 |
| Vela 加 drain 外电阻未知量 | 7801 |
| 原生带标签 debug | 6853 |
| 原生实际内部线性系统 | 6843 |
| Vela 精确消元后 | 6843 |

原生带标签变量为：2600 电势、2121 自由电子人口、2121 自由空穴人口、
11 个 drain 接触 QF 标签。11 个 QF 节点集合与 drain 接触的 11 个节点完全一致；
实际内部系统的额外独立电路未知量为 1，不能把带标签总数当成内部矩阵维数。

Vela 按原生活跃人口节点消去 `2*(2600−2121)=958` 条规定载流子约束，
包括介质无载流子位置及欧姆人口边界；保留电势约束和电路行。
实际使用 `S=A_KK−A_KE A_EE⁻¹ A_EK`、`g=b_K−A_KE A_EE⁻¹ b_E`，
没有仅截取同维子矩阵，也没有清零非零 RHS。恢复方向后的规定约束误差为 0，
生产基线的剩余算子恒等式相对 L2 误差为 `9.64e-17`。

这里只证明等价消元与维数一致。原生人口列和 Vela QF 列仍需完整本构链式变换，
11 个接触标签到内部电路未知量的逐项数值映射也未在本轮比较。
**没有认领完整联立 J/RHS 数值相等，也未测试将原生 J/RHS 直接用于 Vela Newton。**
