# T470p 二进制状态与减少中间落盘验证

## 顺序与范围

用户授权先验证二进制状态文件，再验证减少状态落盘。本轮不更改物理模型、
原块/逐行/KCL门限、外推公式、推进序列或QF上限。生产默认仍为CSV。
使用T470p、MSYS2 UCRT64 Release、UMFPACK/BLAS 1/1，装配结构复用开启，
Fermi节点缓存关闭；沿用冻结D5等温三方程网格、单位、材料、种子和参考曲线。
本资格不涵盖独立D0四方程温度状态格式。

A阶段：文件复用CSV对照与VDS1候选使用同一新程序，双栅压前8点交错串行。
要求原全部尝试轨迹相同、精确点ψ/fn/fp差≤1e-8 V、原数值验收和最终冷读检查通过。
格式往返另外核验低位QF增量、单位转换、参考系平移、损坏文件及旧CSV兼容性。
先通过这一阶段，再进入减少落盘的独立对照，不将不同程序的旧计时混作配对。

## VDS1格式

显式`.vds`扩展名启用写入；通用读取函数检测magic并兼容原CSV。
现有明确命名的CSV函数仍保留。采用无压缩、little-endian、IEEE binary64，不新增库依赖。

| 字节/顺序 | 含义 |
|---|---|
| 0–7 | ASCII `VELADS01` |
| 8–11 | uint32版本，当前1 |
| 12–15 | uint32字段标记：1量子势、2量子类势、4完整QF分裂坐标 |
| 16–23 | uint64节点数 |
| 24起 | 逐列连续float64；各列长度为节点数 |

必选列为psi、phin、phip、electrons_m3、holes_m3。可选列依次为量子势、量子类势、
electron/hole QF增量、electron/hole QF参考值。电势单位V、浓度m^-3；节点编号隐式为
0…N-1。文件不内嵌网格内容或拓扑散列，网格对应关系继续由冻结输入及父状态来源审计保证。

QF四列必须同时存在；量子类势依赖量子势。拒绝未知版本/标记、节点数或长度不符、
截断、尾随字节、非有限值及不一致的QF物理值与分裂表示。不降低到float32。
与当前CSV保持相同的显式策略：非零subnormal写为0；其余有限binary64值不经十进制转换。
文件SHA256必然随格式变化，数值对照比较解码后的字段，不比较不同格式文件的散列相等。

Python预测仍取得独立行字典，字段值可以为数值，避免文本解析；本阶段没有改写为
NumPy向量化预测器。二进制缓存和CSV缓存共享相同容量与最终冷读验收口径。
失败诊断中的旧CSV快照暂保留，不宣称所有输出文件均已二进制化。

## B阶段：减少预测种子落盘

阶段A通过后实现独立`memory_seeds`候选。只取消可重建的外推预测种子文件写入；
求解器每次输出、精确点、参考系转换、失败/恢复快照仍保存。
worker JSON请求可显式携带`initial_state_vds_hex`，作用于该配置中绝对`.vds`
初态路径；载荷上限16 MiB，沿用同一格式/节点数验证。作用域随请求退出（含异常）
销毁，不从上一请求隐式沿用状态，不在响应或日志里重复写入大载荷。
Hex的体积和JSON/管道处理均计入墙钟；减少磁盘文件数不自动意味着更快。

Python不可变种子缓存上限64 MiB，超限将最早种子落盘。数值失败会保存关联种子，
批次异常会全部导出。成功时保存种子散列和来源清单；利用ledger中的两个已落盘
父状态、比例和固定外推规则逐个重新生成并验证SHA256。精确点仍进行文件冷读。
内存种子审计明确区别于落盘文件冷读，不假称所有ledger父路径都存在文件。

相关实现：[内存种子及重建](../../scripts/ldmos_memory_seeds.py)、
[逐请求客户端](../../scripts/dc_worker_client.py)。复用原步长、外推及收敛门限。

## 本轮结论与资格边界

按授权顺序完成两阶段、8条短曲线/64精确点。二进制文件候选取得短点数值资格和
本轮11.54%合计耗时收益；内存预测种子虽数值合格，计时筛选失败。
CSV默认及原模型、门限保持不变。未开展0–40 V完整曲线、跨参考系转换的长轨迹、
重复配对或D0温度状态资格；不能把本轮短点收益直接推广到全部算例。
如继续推进，应先对二进制文件方案补齐完整曲线与重复计时，不继续扩大当前Hex传输候选。

```

`--control binary --candidate memory_seeds --points 8`。不能将两阶段程序的耗时交叉配对。

```
