# BVmethods 逐边输运、Poisson 与 SRH/BTBT 支撑定位（2026-10-13）

本轮在 **T470p（DESKTOP-V2AJOBM）** 完成 19 次固定态探针，确认电子输运主要余差与
边几何和局部迁移率的空间平均有关，SRH 主要余差来自积分体积；Poisson 已分离出介电边、
电荷盒及常数版本指纹。BTBT 的场恢复／取样仍未对齐，全部残差尚未取得资格。
生产 C++、模型参数、模板和验收门限未修改，未推进 Newton、导数或 QS 轨迹。

## 2. 逐边输运：几何与迁移率平均须分别处理

按独立原生元素／全局边编号映射全部 7619 条网格边，保留零耦合、绝缘和接触记录。
4535 条正 Si 耦合边上，旧 `couple/length` 与原生 Si 系数相对 L2 为 0.00519844；
显式原生元素系数路径为 2.06e-17。每条边按原方向加到起点、减到终点，随后应用实际接触替换。
边散度与实际载流子分项闭合：电子最大相对 L2 约 3.70e-12，空穴约 3.06e-14；
全部载流子分项和与实际 residual 逐值相同。

比较以下独立几何平均候选，未按节点 RHS 拟合权重：

`mu_T = sum_i(Measure_Ti * mu_Ti) / sum_i Measure_Ti`

`(kappa*mu)_edge = sum_T(kappa_T,edge * mu_T)`。

局部 `mu_Ti` 来自此前连续三次原生 HFS 回调的已识别元素顶点，元素 Measure 不重新归一到
孤立三角形面积。候选依赖原生局部迁移率，尚未认证 Vela 自己计算这些局部值。
实际 QF reference/increment 从本次装配 trace 按节点映射，分别相减；未使用无定义的
Boltzmann 分解栏位替代 Fermi 状态操作数，也未丢弃近零行。

| 输运控制 | 电子相对 L2 | 空穴相对 L2 |
| --- | ---: | ---: |
| 旧装配 | 11.0533653 | 0.00569311 |
| 只替换原生边几何 | 4.74277845 | 0.00551918 |
| 原生边几何＋元素顶点盒平均局部 µ，私有实际装配 | 9.76007e-5 | 4.81847e-4 |

离线独立边重建与最后一臂实际输运闭合至电子 1.02e-12、空穴 3.90e-15。
电子完整 RHS 相对差约 9.76011e-5，空穴约 4.83766e-4。
仅改为元素三顶点算术平均，电子差仍约 1.08953；边端点算术／调和平均分别约
2.57427／2.68202。因此不能把迁移率模型名称一致当作空间支撑一致，也不能仅改步长解决。

私有新程序关闭迁移率控制后，terms 和 SG 输出均逐字节复现原生几何旧程序结果。
冻结的边 µ 只适用于本固定态；它不随 Newton 状态变化，没有对应导数，不能直接用于轨迹。
最大输运余差转至电子 node 2156（约 9.71e-15）、空穴 node 2515（约 1.07e-16），
单位为 Vela 无量纲连续性行。node 152/784/409 的原分项和全部新弱行均保留。
剩余误差不能因绝对值较小而视为通过，需要继续核对近零算术、局部本构及方向。

## 3. Poisson：边系数、电荷盒和常数指纹

独立求和 `epsilon_r,T * kappa_T,edge * (psi_i-psi_j)`，使用原生盒边系数后，
与实际介电分项相对 L2 约 2.65e-15。仅切换 `cell_material` 而保留旧局部几何不能消除差异。

本轮建立独立于此前左对角尺度的全局 Poisson 单位映射：
原生 VAR*Vt 与物理 psi 最大差约 3.60e-14 V；10602 个共同自由 Poisson 非对角元素除以
`-epsilon_r*kappa` 为同一常数 0.08403361344537813，比例散布小于 4.89e-15。
由变量／方程量纲得到 `F_vela=-RHS_native*1.0170938392658095`，没有按 RHS 逐行配尺度。
因此下列结果不能与上一轮左对角尺度的 7.95% 数字直接混用。

| Poisson 控制 | 同全局单位的实际残差相对 L2 |
| --- | ---: |
| 原装配 | 0.04448295 |
| 原生介电几何 | 0.04377917 |
| 原生介电几何＋Si barycentric 电荷盒 | 0.04363069 |
| 原生介电几何＋现有 mixed-Voronoi 全局节点体积 | 0.00498786 |

现有 mixed-Voronoi 体积不是该网格原生 Measure 的完全替代，尤其不能掩盖钝角转移及材料界面。
离线使用 **Si 原生元素顶点 Measure、显式原生人口和原生掺杂输入** 后，相对差约 1.996e-6。
剩余电荷系数为几乎统一比例；`q=1.602192e-19 C` 与 decimal `eps0=8.8542e-12 F/m`
的版本指纹可把重建差缩至约 2.00e-12（绝对 L2≈3.77e-10）。这仅标记本归档版本的数值规律，
不据此替换生产 CODATA 常数或认定厂商实现。配套 JSON 同时保留先观察比例再检查 decimal
候选的记录，明确该比例不是物理校准或验收门限。

最后一项是离线重建，不是已把原生电荷盒／常数接入生产实际装配。
原 Poisson 分项观察器仍反算人口，与显式人口的实际残差约 1e-10 绝对闭合差保留。

## 4. SRH 与 BTBT 消融

T470p 实际装配分别关闭 SRH、关闭 BTBT、同时关闭两者，分离的两源之和与原分项相对差
5.35e-17；原生 Plot 净源乘 Si Measure 与原生 RHS 消融差闭合至约 9.62e-11。

| 项目 | 相对 L2 | 绝对差 L2（Vela 连续性行） |
| --- | ---: | ---: |
| 原装配 SRH 积分 | 0.01570220 | 7.43e-17 |
| 保留实际 SRH 速率，只换原生 Si Measure | 3.18e-14 | 1.51e-28 |
| 原装配 BTBT 积分 | 0.43786256 | 1.16e-21 |
| 原 E2 单元电场＋原生 Si Measure | 0.39104755 | 1.04e-21 |
| 现有 transport_node_lumped BTBT 实际控制 | 0.67692318 | 1.80e-21 |

SRH 速率本构在本固定态已对齐，主要差异可由体积解释；单纯将几何标记改为 mixed、再使用
现有 transport-node 体积路径并不能替代原生盒积分。

BTBT 尚不能归因于体积一项。用原参数 A=3.4e23 SI、B=2.26e9 V/m 和线性单元电场
独立计算，能复现 Vela 的 barycentric 积分至约 1.31e-10 相对差；换原生盒后仍有约 39.1%
余差，现有节点电场恢复候选更差，保留为失败对照。需要原生实际 BTBT 电场／取样位置输出
继续区分场恢复与本构系数；未据此调整参数。在该近零固定态 BTBT 的绝对量远小于 SRH，
本轮没有验证它在高反偏下的影响。
