## 2. 边界表达式和边界目标不是同一问题

当前人口核心以派生 QF 表达接触方程，并同时规定接触电势。
固定材料统计关系和接触电势后，`fn=Vcontact` 与相应的 `n=n_eq` 表达同一约束流形；
但不在该流形上的有限 Newton 修正可以不同。
例如 Boltzmann 极限中，设 r=n/n_eq：

\[
 \delta n_{QF}=-n\log r,\qquad
 \delta n_{density}=n_{eq}-n.
\]

当 r=1+ε 时，两者一阶相同，差为 O(ε²)。Fermi 情况要使用相应统计斜率；
外电阻接触还必须同步处理电势与内压的导数，不能只替换人口行。
因此，浓度写法可以减少反解和约束非线性，但不是自动纠正材料或规定人口目标。

本轮隔离控制如下；它们是独立诊断回调，没有新增生产 JSON 默认。

| 控制 | 含义与边界 |
|---|---|
| 原式 `raw` | 原核心 QF 约束；直接采用原生同态输入 |
| `own_projected` | 只校正原核心规定行到自身边界；自由节点逐位保持 |
| `neutral_boundary` | 使用相同 Vela 材料／统计的电中性接触目标，直接人口式约束；电势随内压同步 |
| `native_boundary` | 把该原生检查点当前接触人口／电势作为共同冻结目标的控制；不是完整原生边界实现 |

同一输入下，直接人口式控制只替换规定行，**全部自由行原始 RHS 逐位不变**，7 态均核验通过。
它们改变边界修正及随后的轨迹，不能直接消除同态自由方程已有的差异。

冻结完整导数方向，比较“原式”与“相同 Vela 电中性目标的直接人口式”：

| 首态 | 电子方向相对 L2 差 | 空穴方向相对 L2 差 |
|---|---:|---:|
| 保护 i0 | `2.34e-8` | `1.05e-8` |
| 保护 i1 | `9.20e-7` | `5.73e-8` |
| tail02 i0 | `2.33e-8` | `2.18e-9` |
| tail02 i1 | `9.03e-7` | `2.47e-8` |

本轮这些表达式差异，远小于 Vela 与原生某些弱人口方向的差异。
没有证据把失败单独归因为“边界方程使用了 QF”。

## 3. 参考能量／材料逐项核验

当前 QF 派生与独立材料原始量公式在相同 Vela 参数下相符至约 `1e-15 V`；
独立重算的有效 ni 与核心输出一致。没有发现本轮的全局能量原点重复计入。
新增原生输出满足 `EFn+fn=0`、`EFp+fp=0`，能量与势的参考关系一致。

但两工具的材料／常数数值仍不同：

| 量 | 观测 |
|---|---:|
| Vela VT | `0.025851999786435535 V` |
| 原生 VT | `0.025851995266484913 V` |
| Nc 最大相对差 | `9.0513e-6` |
| Nv 最大相对差 | `9.0513e-6` |
| 有效 ni 最大相对差 | `1.2604e-5` |

以 tail02 i0 的同一人口为例，原 Vela 参数反解的接触 QF 最大违约约 `7.41e-7 V`；
仅换 VT 仍约 `8.49e-7 V`，VT 与 BGN 联动重算仍约 `8.63e-7 V`。
同时采用直接测得的原生 Nc／Nv／ni 与 VT，或独立使用原生能带关系，首态接触误差降至约 `2e-15 V`。
这是隔离反解，不向生产求解器注入原生字段，也没有修改全局基础常数。

原生初态本身也存在需要保留的边界仿射量：节点 236 在保护 i0 和 tail02 i0 中，
原生电势行 RHS 约 `2.8669663e-5`，对应物理修正 `7.41168e-7 V`；
该行内压／电势系数比为 −1。原生 i1 的该行 RHS 已为 0。
因此“冻结当前接触值”不能冒充所有阶段的原生真实边界目标；不能删除上述原生或 Vela 的仿射修正。
在后续 i1，按材料反解接触人口与端口电压间还可出现约 `7.41e-7 V` 的偏移，
接触归档人口与原生实际算子取值的时间／重建契约仍需审计，不能靠一个全局电势平移消除。

## 4. 原始 RHS、仿射传播和自由弱行

对每个冻结矩阵，把消元后 RHS 分为自由行原始 RHS、载流子边界仿射贡献和电势边界仿射贡献。
56 组均通过线性叠加自检；没有改变求解矩阵或删除仿射项。

本轮诊断在每个首态固定原 Vela 完整矩阵的带符号对角行尺度，跨边界／线性化控制保持该尺度；
列参考仍为共同首态电压 `|ψ|+VT` 和人口 `|c|+1e10`。原生使用自身对应固定对角尺度。
**这是诊断归一化量，不是绝对安培／库仑残差，也不是日志 RHS 停止门。**
其矩阵差可与上一轮“各自 full／bootstrap 分别除各自对角”的指标不同，不能混表解释。

保护 i1：电子块边界仿射贡献 L∞ 约 `5.18e-6`，空穴约 `2.69e-6`；
Poisson 电势边界贡献约 `5.74e-7`。边界确实能把微小接触违约传向自由行。
但最差归一化空穴差位于节点 311：差约 `7.6745e-2`，该行边界仿射贡献为 0。
因此不能把这个弱行差解释成全部由边界传播造成。

| 同态 | 主要自由弱行 | 诊断归一化差 L∞（相应块） |
|---|---|---:|
| tail02 i0 | 空穴 395／389 | `7.9684e-5` |
| tail02 i11 | 电子 389 | `7.8481e-5` |
| tail02 i11 | 空穴 395 | `7.4650e-5` |

这些最差行的本轮直接边界仿射贡献为 0。它们仍受接触状态改变后的非线性输运、源项和参考量影响；
“本行仿射项为 0”不等于器件与边界无关，也不证明某个物理公式错误。
由于对角尺度可能包含不同有效线性化，上述差也不能独立证明绝对物理 RHS 已有相同数量级偏差。

### 绝对物理单位尝试的资格边界

另外实测原生 NewtonPlot `eContinuityRhs/hContinuityRhs` 与 debug RHS 的共同比例约
`8.043411773861164e-12`，Poisson 对应比例为 `1.602192e-19`；7 态均通过比例一致性检查。
但把当前 Vela 自动参考量推导出的名义物理转换应用到 Jacobian 后，独立尺度自检没有闭合：
Poisson 电势对角比例约 17.0010、电荷列约 17.0009；连续性人口对角也未闭合到 1。

**这项名义安培／库仑换算标为未通过，未作为本报告的物理 RHS 差结论。**
原始探索输出与审计保留在证据中；其中沿用 `_A_per_um` 的旧键也不构成 Poisson 的安培单位声明。
后续需要核实实际运行缩放、原生导出残差及有效线性系统的物理行尺度，再做绝对物理残差比较。

## 5. 核心方向和相对人口 Jv

所有有效方向均由本轮核心 PARDISO、直接相对人口列和精确约束消元得到。
没有把绝对人口列经离线重平衡后得到的极弱行方向作为核心结果。
初轮 SciPy SuperLU 在 tail02 极弱行给出了与核心明显不符的方向，已排除在数值结论之外。
部分核心 trace 的分量后向误差字段未启用而为 null，不将 null 记为零误差。

以原式完整方向对原生方向比较：tail02 i0 的电子相对 L2 差约 2.60%，空穴约 29.44%；
i1 分别约 184 倍、207 倍。规定接触值冻结控制改变了方向，但未形成普遍匹配。

对同一 RHS 用可行的相对人口方向作中心差分，保持自由人口为正；h 从 `1e-2` 降至 `1e-4`。
tail02 i0 在 h=`1e-4` 时，完整导数 Jv 与差分的相对 L2 差：Poisson 约 `9.36e-12`、
电子 `1.11e-5`、空穴 `2.85e-7`，随减小 h 有下降。
这支持该可行方向上的解析导数响应；不是对极弱原始 Newton 有限步、所有单侧分支或原生有效矩阵的全面资格。
