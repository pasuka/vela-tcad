## 已确认的结果

两个器件每个选定截面均有 51 条跨越边。五个沟道截面的相对响应：

| 器件 | min(IV/IS−1) | max(IV/IS−1) | Σabs(F)/abs(ΣF) |
|---|---:|---:|---:|
| n23 | +3.91049e-5 | +4.16545e-5 | 约 1 |
| n24 | +4.00389e-5 | +5.27206e-5 | 约 1 |

这些截面没有明显的有向电流相消，稳定的小比值不是大正负通量抵消后的偶然结果。中心截面和显著载流边的准费米势差分析，实质上缩小了此前“节点场小误差可能被微小边势差放大”的担忧：**在这个求值器所检验的显著沟道边上，放大不是主要现象**。

这足以把精力优先放到原生高精度对照，而不必继续泛泛讨论所有节点的微小势差。

## 仍不能给出正式 Id 的 97% 归因

设生产电流泛函分别为 IV、IS，状态分别为 xV、xS。严格分解为：

```text
IV(xV) − IS(xS)
 = [IV(xV) − IV(xS)] + [IV(xS) − IS(xS)]
```

本次求值器 A 测到的是 `A(xV; muS)−A(xS; muS)`，不是上式第一项。具体差别包括：

- 迁移率冻结为同一原生节点场，未涵盖 μ 随密度、电场、准费米梯度变化的响应。
- 使用节点端点平均迁移率及 cot 权重；生产配置为 `element_box_phumob`、`element_vertex_partial_layer` 和已验证的有效几何策略。
- 诊断对象是沟道电子截面；正式对象为漏极总电流，还涉及源积分、空穴分量及接触求值。
- 采用舍入后的 `phin`；没有重放完整 split 高低位与参考势状态。

绝对通量相差约 10% 不必然使其方向响应错误，但说明该响应尚未针对生产泛函校准。因此接受“固定迁移率的近似 SG 沟道响应约 4–5e-5”；不将其升级为严格的“真实 Id 状态项占比小于 3%”或“其余只能是端口记账”。

逐边比值确实消去了该边相同的非零几何/迁移率乘因子；总电流比值能否保持，需要另看重加权后的全部边、符号和状态相关系数。当前截面条件数约 1 支持当前权重下的稳定性，不能证明任意生产权重改变都无影响。显著边以当前求值器的通量筛选，其 99.98% 覆盖率也属于当前权重。

文字上另有两项小修正：

1. 诊断状态响应为正，而 n23 Id 误差为负、n24 为正；“符号相反”只适用于 n23。
2. 脚本的 `i_d_e` 使用 M60 drain TotalCurrent，而非 eCurrent。n23 两者相差约 3.31e-20 A/µm；不影响截面比值，但电子连续性账本应使用电子分量，并统一源积分节点域与体积。

## 稳定代数交叉检查

利用脚本从各自状态反推 ni 的定义，同一个通量可改写为：

```text
d = (phin_j − phin_i)/VT
eta = log(n_j/n_i) + d
Fij = q*muij*VT*wij*n_i*B(−eta)*expm1(−d)*1e−6
```

本轮仅在内存中替换等价表达式再求值，没有改写用户脚本。中心三截面的约 4e-5 响应保持；外侧 ±.1001 µm 截面的末位略变，十个截面仍处于约 3.83e-5–4.99e-5。

n+ 边的大通量仍存在，而且随代数求值方式变化。此处包含导出势的舍入和求值消减等因素；仅凭 Python 导出场重放，不能称为已复现 Sentaurus 内部 Direct 残差，也不能将这些边统一分类为“纯双精度噪声”。`abs(Δφn)<1e-13` 本身也不是 n+ 掺杂分类标准。

稳定对照输出沿用了原脚本打印标签；其中“pure noise / same class”的原标签不是本次独立确认的结论。

## 下一步判断

保留八次高精度收敛包方案作为优先判别实验。它可以直接检验：原生精度提高后，同一程序的默认 Id、Direct Id、衬底观测差、KCL 和空间状态如何同时变化。无须为了取得“97%”这一尚不成立的精确比例而扩大成 72 次组合。
