# SLOT BVDS浓度坐标：0 V纯泊松与耦合失败定位

## 结论

本批在VM完成独立矩阵导出、同态回代和0 V失败重放。当前浓度方案的失败
没有发生在纯泊松初始化。两臂的泊松电势及RHS一致；转入浓度坐标后，人口
反算QF引入约5e-17 V的起伏，破坏原来的精确等QF状态。随后实际ψ/n/p写回
未能保留原始方向所给出的微小电流修正，真实负载线停在约18.6 µV，超过
原1 µV容差。这一局部机制已有定量账本，不能外推为所有Jacobian导数已正确。

没有修改生产代码、物理模型、人口下限、保护或接受阈值；没有启动新长扫描。
新增程序只链接冻结数值库，原始矩阵、场量、日志与详细分析留在VM。

## 1. 纯泊松：两臂没有可辨别的解差

两臂初始化记录完全相同：8次更新、相同阻尼和残差历史，最终泊松残差L2为
3.099177212727823e-7，legacy停止理由为`poisson_only_contact_basin_converged`。
这不是声称该残差已经小于耦合方程的1e-9门槛。

两份HDF5中的ψ、QF和SI人口字段逐位一致。浓度存档额外保留内部人口；其
复读与SI字段换算可能有约一个ULP的差别，应与存档字段比较分开。实际装配
消费者在本对照中的n/p一致，QF来源不同。

浓度坐标的`Jψψ`仅表示固定n/p下的电势导数，不能当作固定QF的纯泊松矩阵。
Boltzmann情况下，以缩放电势为列坐标，必须计入
`dn/dψ_scaled=n*V0/Vt`、`dp/dψ_scaled=-p*V0/Vt`。
对完整浓度Jacobian作此固定QF变换，再与QF方案的泊松块比较：

| 比较项 | 结果 |
| --- | ---: |
| 标量维数 | 13881 |
| 矩阵相对F范数差 | 1.43283e-16 |
| RHS最大绝对差 | 0，逐位一致 |
| 电势最大差/V | 0，逐位一致 |

因此本次浓度/QF分叉不能归因于两臂纯泊松电势或其电荷Jacobian的大幅差异。

## 2. 耦合入口：等人口不保证保留等QF

原泊松态的电子、空穴QF全为0。浓度主变量进入消费者时，按当前本构从ψ/n/p
反算QF，产生以下差别，节点编号均为零基：

| 项 | 电子 | 空穴 |
| --- | ---: | ---: |
| QF最大绝对变化/V | 4.89517e-17 | 4.92770e-17 |
| 对应节点 | 11973 | 10995 |
| 非零QF节点数 | 12749 | 12751 |
| 连续性RHS最大绝对差/内部单位 | 2.33348e-12 | 2.88107e-13 |

QF方案在该精确平衡态的连续性RHS为0；浓度方案的泊松RHS仍与它一致。
漏端反力则从0变为−2.6306262511182677e-17 A/µm，对应−26.3063 µV负载线差。

另建只读控制：把浓度方案**实际消费的**ψ/QF写入QF方案。该控制复现了相同
漏端反力；电子/空穴输运行、源项及总行账本一致，复合项最大差约2.24e-44。
这比只交换两份原始存档更有辨别力：差异沿人口到驱动量的生成链传入输运，
并不需要假定最后一次通量相减或迁移率值本身错误。

初态最大输运行量约为电子2.33e-12、空穴2.88e-13；复合约2.32e-27，电离约
6.02e-22，均为内部行单位。源项**值**在这些行较小，不能据此排除源项导数。

## 4. 原始方向、实际写回与电流响应

独立单线程重放复现原负载线序列：−26.3063 → +19.9788 → +18.6384 µV，
随后线搜索拒绝。器件方程无穷范数降至2.47094e-12，但真实负载线仍超限。
失败不是行比只报告策略或存档逐字段检查所致。

下表以原始方向`d`、接受阻尼`α`、实际二进制写回量`Δx`、端口梯度`g`
记录精确代数分解：`ΔI = α*g*d + g*(Δx−α*d) + (ΔI−g*Δx)`。
最后一项是实际响应相对解析线性作用的余项，未全部归因为舍入。

| 项 | 第一次接受更新 | 第二次接受更新 |
| --- | ---: | ---: |
| α | 1 | 0.5 |
| 原始方向的线性化电路缺陷/V | 9.22e-21 | 2.57e-21 |
| 原始方向的器件线性缺陷无穷范数 | 2.10e-22 | 3.69e-28 |
| 分量后向误差 | 2.41e-16 | 3.32e-16 |
| `g*(Δx−α*d)` / A/µm | +1.05240e-17 | +8.64379e-18 |
| `ΔI−g*Δx` / A/µm | +9.45481e-18 | +5.20686e-21 |
| 更新后真实负载线/V | +1.99788e-5 | +1.86384e-5 |

第一步写回差对电流的线性作用中，ψ贡献约7.411e-18、电子人口贡献约
3.113e-18 A/µm；第二步分别约8.247e-18和3.969e-19。因此不能把问题只说成
人口写回，也不能仅删除QF低位或增加尾步。贡献突出节点包括10343、10421、
10346、10274、10238等；各项有正有负，单节点绝对值不能当成可相加的因果比例。

这些结果支持：本次原始线性方向在其矩阵上已经解得足够准确，而状态写回
及后续驱动量再生成没有实现相应的电流修正。后向误差小不能证明全部弱方向
前向精度正确，也不能单凭线性回代排除解析导数或分支问题。

拼成一次本日新采集轨迹。8个证据输入哈希在分析结束后均保持不变。

耦合比较去掉重复接触电压别名，并对被消去的载流子约束作仿射回填。设备
子系统为39149维，不含另一个独立电路电压。其行归一化矩阵总相对F差约

最终缩放未在本批独立验证，因此不作该行的定量一致性结论。

这些数值保留常数、本构输入与状态映射差，不能直接归为浓度Jacobian错误，
也不能沿用历史约1e-12的矩阵结论代表当前构建。要闭合跨代码账本，仍需
明确版本绑定的常数对照；本批未证明常数差可以解释全部跨代码差异。
