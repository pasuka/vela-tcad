# BVmethods：被动 Newton 采集与原位重启比较，2026-10-19

承接[人口方向与跨机器检查](bvmethods_update_error_crosshost_population_2026-10-19.md)，
本轮将有容量上限的被动采集接入实际经典 Newton 循环，并在求解返回后计算首轮更新误差。
生产接受策略、行门、闭合门、物理模型、FMA 路径及 PN2D 配置均未改变。
未新增 Sentaurus 运行，未执行 E1–E4。

## 实现边界

- 新增 C++ 私有诊断入口 `experimental::NewtonCaptureScope`，默认没有活动采集器；
  thread-local RAII 作用域结束后恢复旧采集器。没有新增 JSON 开关或前端映射。
- 在生产循环复制已经存在的 x、J/R、行权重、原始线性方向、保护后方向及线搜索结果。
  原始方向在 exact-Dirichlet 修正之前采集，不将受保护方向误标为原始方向。
- 采集不调用人口函数、残差、Jacobian、线性求解器或用户观察回调；复制失败只标记诊断失败。
  默认最多保留 32 轮，超过上限标记截断，不能把不完整记录当成完整通过。
- split、量子势、stall recenter、恢复重入等未经覆盖的状态显式标记 unsupported。
  这里验证的是固定偏置经典 DD 路径，不是全部求解器形式。
- 人口、切向增量、有限更新和实际采用更新均在求解结束后以新建对象计算。
  U3 使用实际线搜索接受态；没有接受态时标记 `NoAcceptedUpdate`，不伪造零误差。

这完成了被动采集入口，尚未完成可提交生产评审的完整 report 功能。
完整逐轮人口报告、逐行区域／掺杂／资格元数据、所有错误路径及增广接触未知量仍需补齐。
线搜索的最佳被拒试步已在内存采集对象保留，当前导出其摘要／merit；
该试步的完整更新误差账本尚未计算，不能将它替代 U3 接受态。

## 实验配置与比较口径

无 Band2Band 的 BVmethods，2600 节点、300 K、Fermi 人口、原 BGN／SRH／雪崩／迁移率，
barycentric 体积及原钝角单元。使用 UCRT64 Release core、私有 `-O1` 驱动，
UMFPACK 后端显式选定；HDF5 state 编译支持已确认。
状态坐标为 7800 维 ψ/QF；report 将人口转为 cm⁻³，电势用 V。
报告使用 Digits=5、ψ 参考值 0.025852 V、n/p 参考值 1e10 cm⁻³；
这里没有将原生日志舍入参考值推广成严格等价契约。

285/21/11/10/5/0 行保存态分别运行 off 两次、capture 两次。
四个控制输入曾请求 `max_iter=3`，但原有 `min_newton_max_iter=20` 将其解析为 20；
实际日志与状态按 20 轮预算解释，不将其报告为三轮控制，也不修改原有最小迭代规则。

比较范围分为两层：

1. 真正关闭采集与开启采集：比较保存的解／最佳解字段、迭代数、残差、门评价、
   history/trace、线搜索记录、退出原因和进程退出码。
2. 两次开启采集：逐轮比较 x、J/R、行权重、原始／受限方向及完整保留的线搜索对象。

关闭采集时没有逐轮 J 的独立旁路记录，因此第二层的重复一致不能冒充
“off 与 report 全部 J/R 已直接逐位比较”。此限制与尚未序列化的 NewtonResult 诊断字段一并保留。
本轮不宣称整个计划的无扰动硬门已经通过。

两台机器各 24 个配对检查进程全部正常退出。每台机器的六态均满足：off 两次记录逐字节一致，
off/capture 的已记录结果逐字节一致，capture 两次的逐轮采集记录逐字节一致，
已记录浮点环境一致。这里的进程正常退出表示诊断完成；六态均仍被原有收敛规则判为未收敛。

Release 的 `test_newton_solver` 全部 144 例／3232 断言通过，
`test_update_error_report` 8 例／59 断言通过。新增集成测试覆盖关闭、零容量、
有限容量和完整容量的求解结果不变；测试使用扰动后的微型 PN 态，确保实际进入 Newton 循环。
未运行全量 Debug CTest。

## 原位 L1 与 L2

对存在第二个实际迭代态的控制，从采集的原位 x 重建状态，写入 HDF5 后复读。
核对全局 J/R、活动／资格集合和原始方向；同时保留文件字段的逐位差异。

21 行态的结果：x、QF reference/increment、全局 J/R、活动／资格集合一致；
文件往返的内部 n/p 分别有 100／96 个值发生末位变化。
原因路径仍是内部浓度→SI→内部浓度的浮点转换。它没有在当前控制中改变重算 J/R，
但不满足用户要求的严格保存人口逐位契约。
逐元素 J、实际缓存身份和原位人口采集仍未完整覆盖，严格 L1 不整体放行。

21 行态另外保留完整 L2 配对：原位第 2–20 轮与复读后的第 1–19 轮，
在本机和 T470p 各比较 19 轮。x、J/R、行权重、原始／受限方向及线搜索逐轮一致，
没有首个分歧。迭代编号仅按重新启动偏移一轮处理，不改变数值比较。
复读运行仍获得新的 20 轮预算；超出原运行末端的额外一轮不算成原位比较。

因此本轮没有复现这条轨迹上“复读后方向改变”的现象。不能将此推广到缓存命中历史、
其他偏置、增广负载未知量、所有保存态的全部历史或原生 QS 预测路径。
285 行态首步被拒，没有第二个接受态，本轮不为它制造一个 L2 通过结果。

## 首轮 report 结果的含义

首轮采用实际自由行：2522 个 ψ、2121 个电子、2121 个空穴，共 6764 项，接触未知量为 0。
`completeEquationSet=false`。原生统计含接触标签且计数不同，两者不能直接声称等价。

同时报告 U1/D1、U2/D1、U3/D0、U3/D2，以及原始分子／实际状态分母组合。
285 行态没有接受更新，所以 U3 及原始分子／接受态分母均为空；
有限人口下溢使对应方程及全局 U2 无效，没有用裁剪人口替代。

5 行态的实际采用步 U3/D0 约为 `5.4132119e-4`，U2/D1 约为 `1719.54`；
原始有限人口更新的最大贡献在空穴350。这是可分辨的非线性控制：
很小的全局切向误差不代表 QF 全步的人口映射接近线性，也不能用 U3 代替原始更新。

小更新指标与行门失败可以同时出现。这是研究终止语义差异的证据，
并不证明残差已平衡、物理门已通过或可以解除原门。
其余保存态的机器可读结果见[同名 JSON](bvmethods_update_error_capture_restart_2026-10-19.json)；
本机 5/0 行态与表中 T470p 的报告数值一致。原始账本只保存在 ignored 证据目录。
最终证据检查 83 项通过，352 个本地证据文件封存。
