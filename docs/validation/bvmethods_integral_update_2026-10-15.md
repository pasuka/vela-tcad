## 积分值与导数的实际顺序

记 R80 为每次基本运算的 binary80 舍入，x_i、w_i 为上轮自主生成的广义 Laguerre 表，
C 为原生 binary64 前因子 2/sqrt(π)。在本批抛物带分支：

```
E = expl(−clip(η, −300, 300))
e_i = expl(−min(x_i, 300))
u_i = R80(1 / R80(e_i + E))
S_i = R80(S_(i−1) + R80(w_i × u_i))
D_i = R80(D_(i−1) + R80(R80(R80(u_i × u_i) × E) × w_i))
F = R80(C × S_last)
F' = R80(C × D_last)
```

本分支的 x^(1/2) 已进入广义积分权重，不再额外乘 sqrt(x)。导数先平方占据因子，再乘 E 和
权重；归一化在累加结束后进行，不能任意交换乘法与求和顺序。
指数参数的 ±300 裁剪由实际指令和逐项采集共同确认；本轮补入私有候选并验证输出。
本样本中未裁剪的大节点指数对最终结果也不产生可见变化，这不构成省略裁剪的通用理由。

| 对照 | 结果 |
| --- | --- |
| 两目标的逐节点指数参数 | 2640/2640 一致 |
| 使用采集指数的积分／导数部分和 | 各 2640/2640 逐位一致 |
| 独立 VM 数学库的节点指数值 | 2640/2640 逐位一致 |
| 自主表＋UCRT 指数，五态积分值／导数 | 334/385、331/385 逐位一致 |
| 上项最大相对差 | 约 1.96e-19、2.13e-19 |
| 自主表＋独立 VM libm 指数，五态积分值／导数 | 各 385/385 逐位一致 |

独立数学库控制由单独 C 程序计算，不从原生积分返回、η 更新或电流缓存拟合结果；输入为本批
固定态的评估参数。表由独立 Release 生成器生成，不读取原生节点或权重。
UCRT 和 VM 的指数末位差保留为平台控制，未引入状态相关修正或统一归一化修正。
这些结果仅覆盖本批 240 点、α=1/2 和实际抛物带分支，不推广为所有材料／分支的数学库等价性。

## 谷求和与接受更新

实际电子为三个零能量偏移谷，各权重为 R80(1/3)；空穴为两个零偏移谷，权重约
0.157248157248157256 和 0.842751842751842744。固定权重和热尺度来自被动材料对象读数，
本轮未独立认证它们从材料质量参数生成的全部路径。

正向值和导数均按谷的原顺序执行 `R80(total + R80(weight × value))`，不重新归一化权重。
自主积分值／导数进入该求和后，五态 140 次材料返回全部逐位一致。

η 修正采用以下顺序，必须保留 log/F' 之后乘 F：

```
r = R80(F / ρ)                    # ρ = R80(population / DOS)
l = logl(r)
δ_raw = R80(R80(l / F') × F)
δ = clip(δ_raw, −limit, limit)
η_new = R80(η − δ)
criterion = R80(abs(δ) / R80(abs(η_new) + tolerance))
accept = tolerance > criterion
```

本批实际 limit 为 5，tolerance 是从 binary64 1e-9 提升的值；电子／空穴分别评估 3／1 次。
检查使用**最后更新后的 η**，分母不是旧／新 η 绝对值之和，也不是单独的残差比。
被动采集的 28 次实际 log 返回与独立 VM libm 相同；由实际操作数计算的更新与判据全部逐位一致。

从原生初值开始，沿已独立验证的积分路径串联五态对照：140 次更新、停止判据和接受决定逐位
一致，最终 70 个 η 端点逐位一致。独立数学 log 控制仍单列：140 次 η 与接受决定相同，但
只有 130 次判据逐位一致。未据此放宽判据或替换实际数学库路径。
