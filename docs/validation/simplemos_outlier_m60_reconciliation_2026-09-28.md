## 1. 修正后的结论

**外部分析的核心数值结论成立：当前 Vela 816 点对照 M60 严格默认端口电流，816/816 点均在 2% 内，最大绝对相对误差 0.1866173947%。** 原始参考仍是 6 点超限、最大 +21.397340%；两套比较应并列保留。

此前 `simplemos_outlier_analysis_2026-09-28.md` 及交接包遗漏了已经完成的 M60，因而把“收紧原生收敛包的判别实验”误列为尚待首次执行。这是证据检索遗漏，本补充报告予以更正；原始归档和原参考不覆盖。

M60 在相同 TDR、物理、接触和配置偏压路径上，收紧 Math 收敛包即可消除这六点的 2% 超限，**这是原生收敛设置造成主要超限的干预证据**。不需要为解释这些超限先修改 Vela 迁移率、SRH 或端口算法。更细的“哪个阱、哪些节点的电子残差通过默认端口算法进入了哪个接触”仍是有支持的机制解释，尚非独立逐节点残差测量。

不能把此结论扩展为：双方没有任何局部物理场/离散差异；全矩阵双初始化完成；所有 M60 点已满足用户文本新建议的参考资格条件；或原生端口 KCL 给出了真实电流误差上界。

## 5. 对机制解释和推论的修订

1. **主因归属可以加强，排他结论不能过强。** “收紧参考收敛包已消除六个大超限”已证实；“不存在物理/离散差异”“候选 SG/SRH 被 1e-5 全面否证”不成立。1e-5 级证据是特定端口分量，816 点总 Id 是 0.2% 级证据，都不是全空间场误差上界。
2. **阱法解释保留明确假设。** 本地手册确认默认方法为关联阱表面电流和体产生项，Direct 为接触表面积分。把 default−Direct 等同于阱内离散残差和，还要求同一状态、相同边通量/源体积及阱分区一致。M58 的同号连通分量是项目拓扑证据，不能不经核对就当成原生内部全部阱标签。
3. **必须比较同一状态的两个观测器。** `Idefault(x_loose)−Idirect(x_tight)` 等于同态观测差加上 `Idirect(x_loose)−Idirect(x_tight)`。因此，用宽松残差和直接预测“宽松默认−严格 Direct”时，还须量化后一个状态变化项。不能把二者混用成独立残差测量。
4. **KCL 残差不是误差条。** n23 的 −0.1866% 小于严格参考 KCL 比例的绝对值 −0.2591%，只能说数值尺度相近；KCL 不是 Id 真值误差的可靠上界或统计不确定度。大端口误差可以彼此抵消，KCL=0 也不能证明局部收敛。
5. **空穴端口和不是原生源积分的独立实测。** 它与 Vela 自有 SRH 积分非常接近，支持净源项接近，但在没有原生逐节点源积分和残差时，不能断言“原生空穴方程全部已闭合、只有电子未闭合”。
6. **更新控制是精度尺度，不是最终误差保证。** 低浓度下 `ErrRef*10^(−Digits)` 给出更新控制尺度；默认约 1e5 cm^-3，M60 为 1e-6 cm^-3。由此可以说明少子相对更新约束弱，不能说电子方程完全没有约束，也不能把最后更新量当成最终密度误差。
7. **有限一致性不约束未计算的初态。** 与一个独立参考相差 ≤0.1866% 并不把另一条未执行的 Vela 初态路径误差也界定为 ≤0.1866%。原定双初始化仍需执行，且保留原冻结门槛，不改成文中新建议的 1e-4 或 2e-3。
8. **统计关联不成为充分条件。** 文中自己的反例已表明“小衬底观测差 ⇒ 小 Id 改变”不是严格蕴含；只能称高命中率诊断线索。n23/Vd=1/Vg=0 的反例不能仅凭端口差就定位内部源/漏阱残差。
9. **复验规模和判别逻辑应修正。** 六器件 × 四 Math 变体 × 三观测器是 72 次运行，而不是 6 条曲线；若加入宽松/M60 对照更多。Digits-only 与 ErrRef-only 相对效果不满足预期、或两变体 Id 相差 >0.5%，均不直接证明机制错误或存在多个不动点；也可能是精度、线性求解或终止条件不同。

## 7. 后续安排建议

本轮完成零求解补证，已有足够证据优先停止围绕六个大超限调整物理参数。

1. 先复用 M60 的 n23/n24 严格空间场，与当前已保存 Vela 状态做同节点比较；确认网格、势参考、密度单位、输出精度，再讨论 φn 梯度和 SRH。
2. 如采纳更严格的参考资格要求，优先只复核第 4 节的四个未通过状态，并保留两个低 NWell 对照。分别收紧停止条件与提高算术精度，保存原结果；不要立即启动 72 次全矩阵组合。
3. 独立补齐既定 Vela 双初始化验证，不因 M60 的 Id 接近而豁免。
4. 如还需区分 Digits、ErrRef、外推的具体贡献，再在少量目标/对照状态做分项干预；按同态端口差与真实节点残差检验阱恒等式。

本报告没有把这些建议作为已执行的新仿真，也没有启用文本中拟议的新门槛。M8/M46 原始比较、M60 诊断比较、参考资格和双初始化四项状态单独记录。
