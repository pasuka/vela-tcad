## 分母时点与保护：必须新增一个组合

观察到的 factor 全部为 1。跨整个轨迹，以下组合复现 **412/412** 个打印 error：

`原始线性更新 δx / [10^(-Digits) × (|保护后的当前 x| + ErrRef)]`，
再按全部误差条目求 RMS。

若原始浓度更新使 `n + δn <= 0`，下一轮 VAR 支持该节点被置为 `0.01 × n_old`。
**误差分子仍采用原始 δn，而不是实际应用的 `n_new - n_old`。**
这不是单独的 U1、U2 或 U3；报告中必须增加具名交叉组合，并保留三类更新的原定义。

| 候选 | 落入日志打印舍入区间的轮数 |
|---|---:|
| 更新前分母、原始更新分子 | 106/412 |
| 原始更新后分母、原始更新分子 | 333/412 |
| 保护后分母、原始更新分子 | **412/412** |
| 保护后分母、实际应用增量分子 | 334/412 |
| 原始更新后分母并将接触去重为一个 | 237/412 |

126 轮含非正原始浓度候选；其中 122 轮有同一 Newton 序列的下一轮 VAR 可绑定，
74 轮能够同时排除上述两种“更新后”替代组合。没有更改原版设置来制造保护动作。
同序列相邻状态核对不跨 Extrapolate 边界。

例如全局调试索引 32 的首轮有 266 个空穴节点触发该保护。日志 error 为 `7.43e3`：

- 原始更新后分母：`5248.5724`，不匹配；
- 保护后分母＋原始分子：`7431.9134`，匹配；
- 保护后分母＋实际增量：`4550.3973`，不匹配。

该轮下一状态与保护重建的最大相对差小于 `8.9e-15`。
不能从首轮 `E=2750` 断言人口映射必然强非线性；原 0.01 V 首轮的平方贡献比例约为：
Poisson 5.279%、接触 5.525%、电子 67.860%、空穴 21.336%。

| 偏置状态 | 重建三轮 E |
|---|---|
| 首个外压 0.01 V | 2750.9667587，80.2377851，0.249963835 |
| 第二个 QS 偏置点 | 472.8243488，2.75894150，0.000121969767 |

上述六轮均落入日志相应精度的舍入区间。结论限定于本次变量形式、网格、接触及 factor=1 轨迹；
没有验证 factor≠1、一般 Bank–Rose 顺序或其他接触形式。
未将低精度 error 打印值套用 `1e-6` 相对门，也未据此宣称 Vela 与原生等价。

  补查包内 26 个 DLL 与本机 UCRT64 安装文件哈希一致；仍需核对实际加载模块及系统运行库，
