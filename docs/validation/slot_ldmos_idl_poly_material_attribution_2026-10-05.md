# SLOT IDL：多晶硅材料映射与阈值区电流偏差归因

日期：2026-10-05。接续 [Bennett–Wilson 门压续算](slot_ldmos_idl_bennett_continuation_2026-10-05.md)。

## 结论与范围

已定位本批 IDL 电流偏高的主要原因：**切换至原生默认 Bennett–Wilson 后，Vela 的
PolySilicon 材料文件仍继承了旧 BVDS/OldSlotboom 的本征浓度与能量参考**。
这组旧量提高了栅下沟道表面势和电子密度；其影响在阈值区明显、强反型区较小。

在独立诊断配置中同步更正多晶硅材料量，六个原有同门压点的最大电流差由 28.8911%
降至 0.0111011%。原 solver、Si 材料、网格、掺杂、迁移率、复合及验收条件均不变。
本批是带完整资格检查的局部材料干预，不是修改生产配置，也不是从新冷平衡态重走全曲线。
诊断状态不追加至旧账本；不能把本报告扩展为 BVDS 或所有材料模型的验证完成。

证据目录：[build/s05idl_attribution](../../build/s05idl_attribution/)。核心汇总为
`analysis.json`、`comparison.csv`、`native_material_identity.json`、`threshold_fields.json`；
配置、父态引用、退出信息和求解日志均分例保存。

## 算例与核验口径

- Vd=0.1 V，源/体接地，Vg 取原生相同门压；300 K、Boltzmann、Bennett–Wilson、IALMob，雪崩关闭。
- 13,881 节点、27,275 三角形。Si 24,272 单元；多晶硅 350 节点、549 单元。
  原生和本地节点坐标已逐值核对，不按不相容的区域副本编号比较。
- 坐标 µm，保存态密度 m⁻³，材料 `ni` 在本例 unit_scaling 下输入 cm⁻³，电流 A/µm。
  电势参考原点为 0 V。本地 UCRT64 Release、HDF5、UMFPACK 默认后端；
  使用冻结 `build/s05idl_bennett/runner.exe`。
- 原门槛：abstol=1e-9、reltol=1e-8、eps_row=0.001、scale_floor=1e-30、全局闭合容差0.01。
  各诊断态经原完整求解器验收，载流子超标行数为0。全局闭合使用原 **absolute** 判据，
  不把 relative qualified=0 表述为相对闭合通过。
- 局部重求每个子进程上限180 s；原生补采在独立目录运行，timeout总上限1200 s。
  原生脚本仍用 ParDiSo、ExtendedPrecision、Digits=5，物理设置不变，只增加场输出和采样点。

## 1. 材料差异的直接证据

原生原有5 V TDR与新增2.5850623691 V TDR均用于核对；后者包含能带与亲和势。
通过能带/载流子恒等关系逐节点重建材料常量，**没有用漏电流拟合参数**：

```
ni0 = sqrt(n*p) exp((phin-phip-BGN)/(2*Vt))
delta = psi - (phin+phip)/2 - (Vt/2) ln(n/p)
n = ni_eff exp((psi-phin-delta)/Vt)
p = ni_eff exp((phip-psi+delta)/Vt)
```

原生热电压为0.025851995266484913 V，仅用于解析原生数据；没有替换 Vela 的物理常数。
多晶硅 ni 在350节点上相对跨度小于1e-10，delta跨度小于1e-12 V。
新增能带场按既有 `prepare_slot_ldmos_energy_reference.derive_reference` 独立重建得到相同结果。

| PolySilicon 参数 | 旧 IDL 配置继承值 | IDL 原生应有值 |
|---|---:|---:|
| Eg / eV | 1.1082092307692308 | 1.1241592307692307 |
| ni0 / cm⁻³ | 1.4638805412559153e10 | 1.0750038488844242e10 |
| 相对 Si 的 intrinsic_reference / V | +0.007927767678211338 | −0.0000400003439281307 |
| Nc / cm⁻³ | 2.8582520073866568e19 | 2.8566532887163142e19 |
| Nv / cm⁻³ | 3.1046289324748374e19 | 3.104628932474834e19 |

亲和势4.0727403846153845 eV一致。Si的能量参考约为0，原生ni0=1.0749878412355793e10
与现有1.0749877484352535e10接近；没有本批多晶硅那样的显著差异。

材料来源可追到 [9月21日多晶硅恢复](slot_ldmos_auger_poly_independent_controls_2026-09-21.md)
与 [能量参考报告](slot_ldmos_energy_reference_and_source_volume_2026-09-21.md)：
那些值对应当时的 OldSlotboom 算例，不能不经重验移植到 IDL。
归档 `poly_native.par` 的 `dEg0(OldSlotboom)=-0.01595 eV`，而 Bennett 为0；
两批实际多晶硅带隙正好相差0.01595 eV。此前 Bennett 映射只补窄化公式而继承旧多晶硅材料，
因此“已补齐模型映射”的范围需要收紧为公式实现与当时配置验证，尚未覆盖这组跨模型材料常量。

本批完整干预更改 `ni`、`intrinsic_reference_potential_V`、Eg。
为隔离因果，Nc/Nv保留旧值；在当前显式ni的Boltzmann路径中它们不决定本次载流子重建。
正式生成新材料配置时应一并记录上表完整DOS，不能据此推断Fermi路径无须更新。

## 4. 空间场、电荷与迁移率

Si沟道表面选取x=0.003～0.006 µm、y=4.02～4.22 µm、净p型节点，共71点。
固定几何ROI用于同坐标比较，不能把全器件无权重节点均值当作有效沟道量。

| 门压 | 原配置表面势差范围 | 更正后的表面势差范围 |
|---|---:|---:|
| 0 V | +1.3825～+4.1922 mV | −0.1563～+0.6676 µV |
| 2.5850623691 V | +0.3104～+7.2581 mV | +0.2819～+3.1840 µV |
| 5 V | +0.0648～+0.2084 mV | +0.1723～+0.3942 µV |

阈值点把上述表面上原生n<1e22 m⁻³的节点作为低电子密度瓶颈诊断集：
原配置势高6.0206～7.2581 mV，电子密度高25.9043%～31.8209%；
更正后势差2.7321～3.1840 µV，电子密度差0.01055%～0.01210%。
这与阈值区电流差的消失一致，支持静电势垒/沟道电荷为主要机制。

在x<0.025 µm、4.02<y<4.22 µm且单元平均净p型的646个Si单元中，
使用**同一套**原生几何顶点面积积分电子电荷绝对值（单位宽度）：
原生7.51262314e-17 C/µm，旧配置7.83296990e-17，更正后7.51275329e-17。
相对差从+4.26411%降至+0.00173244%。整体ROI电荷并不与漏电流一一成正比；
亚阈值电流更敏感于局部瓶颈，不能用4.26%积分差直接替代28.9%电流差。

源n+区与体p+区零门压电势差各约±0.108 µV，说明主要偏移不在Si源/体内建势。
两区域中位电势之差在原生约1.081997580 V，旧Vela仅高约0.216 µV；此为指定近中性ROI的
内建势代理量，不是任意位置的完整二维结势定义。
相反，多晶硅p型接触节点12513旧配置电势高15.94993 mV；n型接触12456仅差−14.37 µV。
这正是错误ni与参考电位在不同掺杂符号下组合响应不同的表现，不能把它当作全器件统一电压平移。

迁移率检查采用现有逐单元IALMob核、生产几何、300 K与原参数，分别代入原生/本地场。
更正后的阈值态相对原生态重放，646单元μn变化范围−1.51e-6～+2.78e-5（相对值），
瓶颈相邻单元范围+1.07e-6～+3.89e-6。
这是**同一Vela核在两种状态上的比较**，不能称原生单元迁移率独立逐项对齐：
本次TDR的eMobility为节点值，而生产使用单元值；直接平均节点显示值再相减会混入投影误差。
本批可确认的是：不改输运参数，只更正多晶硅材料，已消除主要电流差。
