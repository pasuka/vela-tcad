# SLOT BVDS兼容口径下的空穴单侧源项与跨块支撑（2026-10-16）

## 结果

VM已完成冻结态的13组基态/空穴单侧扰动、原生电离关闭对照、两端Auger关闭对照，
以及10276正负扰动后的解析矩阵检查。新增生产合格态和偏压点均为0。

本批最有辨别力的发现是：**10276最大的电子方程—空穴变量差异主要来自平衡附近
Auger复合的开/关分支，而不是该节点的电离驱动力。** 原生基态落在Auger开启侧，
Vela基态落在关闭侧；正负有限扰动离开基态后，两端分别选中相同的分支。
关闭Auger的独立消融消除了这项显著的单侧不对称。不能将此前所有近零源项差异统称为电离导数差。

10849同时存在两种效应：空穴扰动可跨越Auger零产生边界；其电离项还保留极小驱动力的
方向敏感性。当前原生完整残差求差不足以分辨全部极小电离变化，不能据此宣称电离解析导数完全一致。

## 10276：Auger分支定位

本配置`auger_with_generation=false`。当前Vela实现的等价分支为

\[
R_A=C(n,p)\max(E,0),\quad
E=n_i^2\operatorname{expm1}[(\phi_p-\phi_n)/V_T]
\]

（本批Boltzmann口径）。E≤0时Auger值及其解析导数关闭；这不是去掉连续性方程。
实现见`RecombinationModel::augerRateFromExcessProduct`及其导数入口、
`generalizedSrhCarrierState`。本批没有修改这个分支约定。

10276位于Si内，坐标(0.0049448991, 0.36640625) µm，不是接触节点。
原生导出n=1.4769830621e21、p=63.15518327 cm^-3。
两端保存的QF分裂完全相同，为−3.92403052e-20 V，Vela稳定过剩量由此取负。
但以原生导出人口和有效ni作高精度乘积，np/ni²−1=+1.84819e-14；
Vela导出人口同样计算为−2.10539e-17。原生Plot Auger=0.733037 cm^-3 s^-1，
其实际装配的解析方向也处于开启侧。这里仅解释可观察到的分支身份，未声称取得原生内部过剩量源码。
人口匹配到约1e-14仍不足以确保这个零点附近的分支相同。

## 10849：区分复合分支和极小电离驱动力

10849位于源端附近Si/SiO2界面，坐标(0.0049551165, 4.351074219) µm。
Si源项支撑是21241、21242；21242邻接有效电极，21241不邻接。
其基态空穴QF梯度分别约(−0.001090, +0.001957)和(−0.001090, −0.007982) V/m。
氧化物区域副本只用于状态一致性检查，不据此加入氧化物载流子源项。

本配置的电极邻接元素仅将电离系数α的驱动力回退到电场，电流因子仍使用QF驱动力；
其他边界层可使用切向QF梯度。源核含范数/绝对值和密度极值选择，
因此必须区分基态选中的解析分支与跨越分支后的有限差分。

10849基态QF分裂+1.52036e-11 V，np/ni²−1约+5.881e-10。
δ=−1e-7跨到Auger关闭侧，δ=+1e-7保持开启；±1e-10尚未跨越这个复合分支。
以电子行自身对角归一化后的解析相对人口方向，两端均约2.08656e-10；
δ=1e-7的正侧约2.086e-10，负侧约1.216e-10。Auger关闭后不对称消失。

单位为Vela内部残差/相对人口变化。不能把1e-12差分为零认定为解析导数为零。

并记录求差的舍入分辨率；源项极小量的部分方向无法由完整RHS相减可靠分离。

前批ψ方向电离的明显单侧差异与本批空穴方向的极小响应不是同一量级，不能混写。
