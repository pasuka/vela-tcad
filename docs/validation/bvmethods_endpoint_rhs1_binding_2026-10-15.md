## 手册定义与实际端点身份

查阅本地安装的 User Guide T-2022.03（March 2022）：

- 第 232 页式 (41)–(42)：导带／价带由电势、参考电势、电子亲和能及有效带隙确定。
- 第 233 页及第 239–240 页：Fermi 统计和电流本构还涉及统计、DOS 等项。
- 第 306 页式 (155)–(158)：有效带隙为基准带隙减去带隙收缩，电子亲和能亦可含收缩分配。
- 第 1177–1178 页式 (1264)–(1266)、表 187–188：盒离散及元素支撑。

手册定义物理量；内部槽身份另由实际 GetDataEntry 返回对象类型与写入路径确认，
不能仅凭手册或槽名推断。以下槽号仅是本次版本的私有诊断定位，不是稳定 API。

| 旧中性名／槽 | 实际字段类型 | 物理身份及物理单位 |
| --- | --- | --- |
| U／0x50 | PotentialEntry | 静电势 ψ，V |
| W／0x158 | ElectronAffinityVertexEntry | 电子亲和能 χ，eV；包含当前配置的带隙收缩分配 |
| Z／0x168 | BandGapEntry | 基准带隙 Eg，eV；与有效带隙区分 |
| T／0x178 | BandgapNarrowingEntry | 带隙收缩 Ebgn，eV |

物理带边关系为 `Ec = −χ − q(ψ−ψref)`、
`Ev = −χ − (Eg−Ebgn) − q(ψ−ψref)`。
U/W/Z/T 是相应归一化输入，不是 QF reference/increment。
另一个槽 0x100 为温度输入，本态归一化值为 1；首版私有分析中曾误标为 FermiDelta，
后续已更正，不能用该标签判断扩散统计。

对实际有向边 i→j，驱动组合采用逐次 binary80 舍入：

```
e: round80(round80(Ui−Uj) + round80(Wi−Wj))
h: round80(round80(e + round80(Zi−Zj)) − round80(Ti−Tj))
```

这只定义已采到的带边驱动组合；Bernoulli 参数还包含实际统计／温度等操作数。
本轮没有将通用 FermiDelta 字段直接等同人口导数或全部 SG 扩散因子。

## 独立归一化与原始弱行重建

在另一个原生进程中只读 IISScaling 构造及 SetRefMaterial 返回，16 份相关参考量一致：

| 参考量 | 本配置值 |
| --- | ---: |
| 电势 Vref | 0.025851995266484913 V |
| 长度 Lref | 0.0033864920021441317 cm = 33.864920021441317 um |
| 密度 Nref | 14824351000 cm^-3 |

数值直接来自归一化对象，不由目标 RHS 拟合。坐标接口另确认坐标读取带有长度转换；
这些读数和本配置参考长度解释保存在私有证据中，不推广为全局生产默认。

取 `S = Σ(朝目标节点外向的 J_without_mu × 边长_um × 单元κμ)`。
单元 κμ 沿用此前独立支撑审计的物理迁移率和几何系数，逐项参与累加。
本次原生打印 RHS 约定对应电子 `+S·Vref/Lref_um`、空穴 `−S·Vref/Lref_um`；
符号与实际载流子常数及边方向绑定，未对两条 RHS 拟合倍率。

| 目标 | 原始打印 RHS1 | 独立累加／换算 | 相对误差（重建/原值−1） |
| --- | ---: | ---: | ---: |
| 电子 2156 | −0.007796916415739430 | −0.007796916415739432 | +2.693382437011812e-16 |
| 空穴 2515 | −2.833468351009580e-5 | −2.833468351009575e-5 | −1.722698522528083e-15 |

这里电流分项取自原生实际缓存；独立的是支撑覆盖、方向、累加、尺度读取和换算。
不能将该结果描述为仅凭 Vela 人口／材料参数自主生成全部原生 SG 电流，
也不能将相对打印 RHS 的误差等同未打印内部 RHS 的逐位相等。

首版只乘热电压的单位候选失败，已完整保留；补读参考长度后才完成上述换算。
共同倍率不是新迁移率修正、经验 QF 偏移或门限预算。近零电流对人口、带边及舍入顺序
敏感的事实仍然成立，单独导出 QF 相减仍不足以复现原生内部求值。
