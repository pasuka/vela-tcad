## 1. 单元素试验与实际执行

新建一个三节点硅直角三角形，顶点为 `(0,0)`、`(.01,0)`、`(0,.01)` µm，
底边 0–1 为唯一 0 V 接触，均匀施主 `1e15 cm^-3`。这个诊断探针采用 Boltzmann、
无 BGN、300 K、PMI 常数迁移率 `1 cm²/(V s)`；它不替换原 BVmethods 物理。

先在原生上完成一次 Poisson／耦合初始化并 Save；日志的线性方法为 blocked decomposition、
非线性为 Bank/Rose。随后只修改保存态的 ψ 及电子／空穴 QF：三者对自由顶点共同平移
`-F*1e-6 V`，接触端点保持初值，使人口均匀、场可控。后续全部是 Load/Plot，没有继续求解。
单元素使同一源映射至三个节点；`G_model/G_alpha=1` 可直接读出 alpha，不再反算混合单元权重。
零场的单位源为零，alpha 不可辨识，保留为 null，不误记成 alpha=0 的测量结果。

执行七组控制：单位系数、两常数阶跃 1→2、交换阶跃 2→1、原物理系数、全低场系数、
全高场系数、原硬分支 PMI。每组 56 个场点，覆盖 0、低场、`3.4e5–4.6e5 V/cm` 的密集区、
高场及 `-4e5 V/cm` 反向控制。共 392 对 Load/Plot，七次 sdevice 调用均退出 0。

七组的全部 ψ、QF 和人口在对应场点逐字节相同；最大人口相对空间起伏约 `3.13e-15`。
实际 PMI Eparallel 与场目标绝对差不超过 `1.17e-10 V/cm`。
反向场产生反向电流，但 Eparallel 为正，得到同样的过渡响应；不得把该规则用于有符号电场本身。

## 2. 可复现的经验分支表达式

在本次版本、300 K 和已验证的参数范围中，以下表达式复现原生观察：

```text
F <= .95 E0: w = 0
F >= 1.05 E0: w = 1
otherwise:
    u = (F/E0 - .95)/.1
    w = (1 - cos(pi_star*u))/2
alpha = (1-w)*alpha_low(F) + w*alpha_high(F)
pi_star = 3.141592654
```

这里的 `pi_star` 是单元素控制识别出的有限精度特征，**不是对厂商源码常量的断言**。
使用标准双精度 π 时，权重最大差约 `1.18e-10`；上式为 `2.56e-15`。
交换阶跃满足 alpha_step + alpha_swap = 3，最大绝对差 `4.45e-16`。
原物理系数属于独立控制，重建 alpha 的最大相对差为 `9.82e-16`。

例如 E0=`4e5 V/cm` 时，过渡区为 `3.8e5–4.2e5 V/cm`，阈值附近约各占一半。
实际比较保留 a、b 参数线性插值、log(alpha) 插值和硬阈值的全部失败候选，
没有用节点源拟合权重、裁剪越界反算值或调整验收门限。

进一步复用此前独立封存的七个完整网格阈值案例，E0 为
`360000/380000/395000/400000/405000/420000/440000 V/cm`。
逐项检查主变量一致后，以原生 J/µ、代表局部 µ 和原生盒支撑为输入，直接应用上述表达式。
全部 2152 个 Si 节点、4156 个 Si 单元保留；14 个载流子／阈值组合的最大源相对 L2
为 `5.70e-16`。因此 ±5% 宽度也获得独立阈值迁移验证，未重新拟合。

这解释的是固定态源差异，不认证其他版本、温度、参数族或此表达式的 Newton 导数。
新增公共 Python 辅助函数明确标记为诊断；生产 VO 模型及默认仍保持原状。

## 3. 原完整网格的独立 SG 重建

原 BVmethods NMOS：2600 节点、5020 三角形、26 个钝角，Si region 3 的 4156 个单元和
2152 个节点；300 K、外电阻 `1e7 ohm*um`。原物理为 Fermi + OldSlotboom、
Masetti + Enormal + GradQuasiFermi HFS、SRH(DopingDep)、E2 BTBT 和 VO Eparallel。
使用 T-2022.03-SP2、80-bit ExtendedPrecision、DensityIntegral=240 的两个固定态：
首个非零 Newton 更新前近零态，以及此前有限 QF 编码态。

单元和代表顶点来自上一轮三次 HFS 回调的实际顺序；本轮不再做电流指纹匹配或选择最小误差候选。
每个单元由代表点连接另外两点，以人口／QF 的有效带边 SG 边电流解出二维向量；
半导体绝缘边界使用此前验证的切向投影，接触交点保留两分量。
由 ψ 梯度和新重建的电流方向计算非负 Eparallel，再用上述经验 VO 表达式计算源。

所有 4156 个单元都实际计算，未触发原生回调的单元也保留，不用原生激活掩码截断新源。
本轮四组均没有在原生无回调单元上引入正源。表中电流误差覆盖全部有原生回调可比的单元，
源误差覆盖全部 2152 个 Si 节点，含接触。
