# M60 同节点场补证与八次高精度方案审阅

2026-09-28。本轮只读复核用户新增的 `field_compare_response/` 脚本与数据，没有运行仿真，没有改变参考或门槛。

## 已复核的新增场证据

从原始 M60 CSV 和冻结 Vela 节点 CSV 独立连接，n23/n24 各 1482 节点均唯一匹配；不只是四舍五入匹配成功，匹配后的实际坐标最大差为零。各有 907 个自由 Si 节点。统计量来自展示势与物理密度字段，不把展示势当成精确 split 状态。

| 自由 Si 节点最大差 | n23，Vd=.05、Vg=.05 V | n24，同偏置 |
|---|---:|---:|
| abs(Δψ)，V | 1.612735941e-6 | 1.681744311e-6 |
| abs(Δφn)，V | 1.385836761e-7 | 1.404871203e-7 |
| abs(Δφp)，V | 5.349417145e-8 | 5.421455447e-8 |
| abs(nV/nS−1) | 6.378723163e-5 | 6.657446127e-5 |
| abs(pV/pS−1) | 6.357162102e-5 | 6.635202807e-5 |
| SRH 异号/含零节点数 | 4 | 2 |
| Σabs(RV−RS)/Σabs(RS)，不加权 | 8.604512592e-6 | 1.005013375e-5 |

SRH 最后一行是共同节点、不加体积权的诊断量，不是源项体积分误差。对应 SI 速率在两方同单位下计算。异号/零节点为 n23 的 358/364/365/366、n24 的 364/365。

可据此升级结论为：这两个严格状态的势、载流子密度和大部分 SRH 速率高度接近，新增了真实的同节点证据。不能表述为“全部场相对误差均为 1e-5”或“电势最大差亚微伏”：最大 Δψ 为 1.61–1.68 µV，最大密度相对差为 6.38–6.66e-5；SRH 在过零处的相对误差不稳定。

## 空间坐标需要纠正

用户脚本的 `surface nodes y==0 (Si/oxide interface)` 分组标注不正确。按冻结 mesh 的 Si 与 SiO2 共同节点直接求交，两器件均有 21 个界面节点，全部位于 x=0.005045938170817487 µm。该器件 x 为深度方向，y 为横向。

907 个自由 Si 节点中，y=0 的节点有 25 个，x 覆盖 0.005046–0.792021 µm，其中只有 1 个是上述 Si/SiO2 共享节点。因此 (x≈.034–.076,y=0) 的 CNormPrint 更新热点属于体内中线附近，不能称为界面表面热点。全自由 Si 节点统计不受这项分组标注错误影响；后续局部解释应从材料邻接关系定义界面。

## 剩余 Id 差的归属仍应做判别

“场接近，所以 Id 差只能来自端口求值”仍然过强。弱电流对准费米势差及 SG 相消敏感，节点势的绝对差小，不等于边势差的相对误差小。以局部线性关系 I≈G*Δφ 表示，δI/I≈δG/G+δ(Δφ)/Δφ；当 Δφ 很小时，不存在由当前节点场范数直接得到的 0.1% 电流误差上界。展示字段的浮点舍入会进一步限制微小梯度比较。

因此 Vela 是“非常接近状态上的另一个求解结果”，不是严格意义上的同态第三观测器。M60 default/Direct 在这两个目标上有同态不变性证据，Vela 与它们之间没有位级相同状态。

“严格状态端口残差继续主导约 0.1% 的 Id 差”是合理优先假设。要区分它与小状态差/局部输运差，应使用高精度前后同一程序的端口响应，或在同一个可重放精确状态上对比不同求值方法。即使高精度运行中 gap/KCL 下降而 Id 差不变，也不与当前小场差矛盾，而是说明该 gap 不能解释剩余电流差。

复跑用户的 `residual_vs_observer_gap.py`：23 个 sub-fA 点的零截距系数约 −0.371，带符号 Pearson 为 **−0.775**，不是 +0.78（后者只能写成相关系数绝对值）。脚本内部使用 x=−gap、y=Vela−S，但打印标签写成 S−Vela，符号不一致。统一成 x=gap、y=S−Vela 后，系数与相关系数仍分别是 −0.371、−0.775。其幅度不能作为通用端口分配系数或经验电流校正。

## RHS 平台的证据强度

n23 目标严格日志显示：RHS 从 2.02e3 降到 1.53e-2，最后两次打印为同值；step 从 7.03e-6 降到 6.34e-11；最终因 update error=6.1782e-3<1 停止。它强烈提示数值精度/残差求值限制，但只有有限有效数字的日志，尚不能独立证明双精度舍入是唯一原因，或证明任意 Digits 都绝不可能达到 RhsMin。

保持现有双精度时，不宜直接把 RhsAndUpdateConvergence 当成保证通过的办法；应优先测试提高算术精度。定量证明残差精度平台可用同一状态的不同精度残差求值，或固定其它设置的精度对照。CNormPrint 给的是最大更新相关诊断，不是逐节点连续性残差；不能由 max 与整体 error 的大小关系反推出每个节点的残差闭合。

## 对八次方案的判断

四器件 n23/n24/n17/n19 × default/Direct 共八次，是合理的下一批诊断规模。M60 保持为旧对照；新数据另行归档，不替换基线。

本地 T-2022.03 手册 pp.224–225 支持 ExtendedPrecision(128) 为软件 double-double，并列出 Digits=15、RhsMin=1e-15 为可用设置。手册说明 SUPER 通常精度最佳，部分线性后端不支持扩展精度；因此必须从日志确认实际精度和线性后端，不能只看 deck 开关。实际运行时间另测，手册约 10 倍只是一般描述。

需按以下方式解释和记录：

1. 同时变更 ExtendedPrecision、Digits、RhsMin，属于一个“高精度收敛包”干预，不是单独精度因素试验。若还改 Method 或加入 CheckRhsAfterUpdate，应明确作为额外改变；八次内不要按运行结果临时追加参数。
2. abs(gap)/abs(Id)<1e-4、abs(KCL)/abs(Id)<1e-4、abs(Vela/reference−1)<3e-4、Direct/default 漏电流差<1%，可预先记为诊断预期，不视为已经验证的结果，也不自动变成新正式验收规则。
3. 四个未通过候选资格的状态由 n23 的 Vg=0/.05/.10 与 n24 的 Vg=.05 覆盖。记录完整字段、端口分量和停止原因；保留低 NWell 对照。现有精确参考与双初始化门槛不改。
4. 不把“未达到 ±.03%”直接判为模型错误。分别报告默认 Id、Direct Id、观测差、KCL、停止原因、状态变化与 Vela 场差，再作归因。
5. 该八次方案不包含 n20/n21/n22；所以它不能同时实现“全部六个原超限点都有严格原生场”。补齐剩余三个器件的字段应单列范围和运行数。
6. 仅加 File 中的 NewtonPlot 文件名不保证保存目标接受态的最后迭代。手册 p.209–210 说明默认触发与步长减小相关，应显式核对目标步的输出触发、残差变量及缩放。NewtonPlot 是直接证据来源之一，不应声称它是唯一可能的直接测量方法。
