# BVMethods 核心稳定缩放与直接人口列线性化（2026-10-30）

本轮已实现稳定缩放乘积、区分零支撑与缩放范围故障，并接通不经巨大绝对Jacobian的相对人口列接口。Windows相关118项测试、1850条断言全部通过；VM Release/MKL PARDISO预检、三个真实冻结矩阵核心回归及四个实际检查点相对列探针均通过。原0.1/0.2 V组失败态的下一偏压点已各4轮通过，其他窗口仍有非线性失败，尚不能宣称完整BV修复。

接续[弱人口行与新零列定位](bvmethods_weak_population_rows_2026-10-30.md)。本次变更未提交；此前未提交的统计、算术与浓度控制修改均保留。未执行完整BV重跑或更改物理模型/验收门。

## 核心修改

- `ScaledProduct`保留普通binary64乘法路径；仅在中间乘积范围损失时以较宽中间量恢复可表示结果。最终确实不可表示的数仍报错，不截断矩阵条目或删除行列。
- `CoupledLoadLine`的列范数和最终两侧缩放矩阵均使用稳定乘积。报错区分原始零支撑、带权幅值下溢、带权非有限幅值/列尺度；不再将本轮所见inf列尺度称作结构零列。
- `BvMethodsTri3Operator`、SRH、Poisson与规定接触行直接装配J diag(T)。端口电流导数提供相同坐标接口。相对AD不再先除以极小人口形成可能溢出的绝对列，然后才乘回人口。
- `ArclengthSystem`新增完整/近似`jacobianInColumns`回调，标量端口新增`linearizeInColumns`。增广方向与导数恢复模型使用同一基；独立人口Newton的固定电压标量行也已接通。
- 回代后的方向仍是实际n/p增量，继续交给原正值保护与原始人口RMS。状态本身未改成log(n)/log(p)，没有对增量另加电压限幅。

在每次线性化中固定正尺度T，解

\[
(J_xT)\,\delta z+F_V\,\delta V=-F,\qquad
R(I_xT)\,\delta z+(1+RI_V)\,\delta V=-L,
\quad\delta x=T\delta z.
\]

不对T自身求导。仅当完整、近似、端口列回调齐备，且物理列尺度小于sqrt(DBL_MIN)时，极弱列采用相对基；其他列T=1，普通状态使用原装配路径。该阈值只是算术路径选择，既不抬高人口也不是浓度下限/上限。JSON中原`state_variables=potential_density`及独立的下限开关保持原语义。

绝对Jacobian及依赖它的旧诊断/伴随接口继续保留；极弱人口的绝对列仍可能不可表示，要求有限表示的调用方应明确请求相对列并匹配方向坐标。本次验证不等于所有绝对诊断接口、完整Jv及所有有限Newton步均已资格通过。接口与重放用法见[算子契约](../bvmethods_operator_contract.md#direct-population-column-linearization)。
