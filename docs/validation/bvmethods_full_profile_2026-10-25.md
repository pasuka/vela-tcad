# BVMethods Release 完整 BV 扫描尝试（2026-10-25）

本轮完成 Vela 自身状态的完整扫描，达到停扫电流。
Vela 在 `|Id|=1e-4 A/μm` 判据下的内压 BV 为 **6.67049136 V**，由接受点有效夹逼插值得到。
最远的严格残差续算接受态为外压 **13169.2189 V**、内压
**7.34138929 V**、电流 **0.00131618775 A/μm**。
完整数据摘要、失败尝试和文件哈希见[配套 JSON](bvmethods_full_profile_2026-10-25.json)。
自主 Poisson 起步后按已验证重启点拼接的完整路径含 **419 个接受点**，
全部实际满足原始方程残差 ≤1e-8；最大值为 9.81492e-09。

## 模型、目标与实际后端

沿用[显式算子接入验证](bvmethods_production_profile_2026-10-24.md)和
[当前算子契约](../bvmethods_operator_contract.md)：`bvmethods_tri3_qf`、
`fermi_dirac_joyce_dixon`、300 K、2600 节点／5020 Tri3（2152 个 Si 节点），
总杂质 Masetti、Enhanced Lombardi、Canali、OldSlotboom、SRH、自洽
Van Overstraeten AV（GradQF、local AD），BTBT 关闭。保留现有 AV 接触场规则。
输入长度 μm、浓度 cm⁻³、迁移率 cm²/(V·s)、势 V、电流 A/μm。
本轮使用公共 CODATA 常数，没有导入 Sentaurus 人口、源、矩阵或检查点起步。

使用既有 MSYS2 UCRT64 GCC 16.2.0、C++20、Release O3 二进制和同一
`libvela_core.a`；实际构建具备 HDF5／HighFive、UMFPACK／SPQR，负载线走
`direct_bordered`（首选 Eigen SparseLU，保留既有后端回退；本轮未逐步另记最终后端）。
CLI 与核心库的 SHA256 均在 JSON 中记录，和前轮资格二进制一致。

外接电阻 **1e7 Ω·μm**，外压目标 100000 V；`|Id|≥1.3e-3 A/μm` 停扫。
BV 定义为接受点达到 `|Id|=1e-4 A/μm` 时的**内压**，只能在有效夹逼点间插值。
初步长 0.01 V、最小 1e-5 V、最大 2500 V，增长上限 1.41、失败缩小 0.5，
按 Newton 次数调节增长，开启线性外推。只设 0 和最终外压两个强制目标，
未用 0.01 V 的固定输出网格限制自适应步长。

## 从 Vela 自身接受态续算

另用未安装的本地 Release 驱动调用同一核心库及负载线 Newton API，
只读取本轮 Vela 自己的物理 ψ／fn／fp。先尝试割线预测；失败后在同一外压
从上一接受态重试，两者都失败才减半，不沿用失败态。每次仍为 40 次迭代，
保留实际端口 KCL 与负载线检查、0.1 V QF 更新限制及既有物理模型。
它是私有续算实验，不代表 CLI 已新增了这一重试策略。

第一组沿用更新量 OR 残差，从外压 0.218629163 V 续算，新增 5 点，
最后外压 0.263471743 V 的原始方程残差约 1.256e-7，由更新量分支接受。
随后主动停止，改从基线中独立满足残差门的检查点进行第二组续算。

第二组从外压 0.258873255 V 起步，关闭更新量停止分支，
**收紧为只允许原始残差 ≤1e-8**，数值门限不变。新增 14 个接受点；
随后由内压步长控制替代而主动停止，最后外压 0.579299119 V；全部尝试见 JSON。

第三组从第二组外压 0.558798748 V 的自身接受态起步，
继续使用严格残差门。增加预测内压步长控制：由最近两个接受点估计
`abs(dVin/dVouter)`，外压试探步不超过 `0.02 V / abs(dVin/dVouter)`，
并保留原有外压步长上下限、增长和缩步。它没有修改模型或接受条件。
新增 361 个接受点；结束码 0，用时 1595.5 s，结束原因：
**达到预设停扫电流**。
第三组包括重启锚点在内，接受态最大原始残差为 9.48667e-09，
最大实际负载线残差 3.38397e-07 V、最大端口 KCL 3.38397e-14 A/μm。
该续算达到 BV 电流判据。
本阶段仅一次割线起步在 40 次预算内失败；同外压 17.296284941 V 改用上一接受态，
4 次迭代通过，随后完成扫描。失败保留在 JSON 中。

各组续算的起始检查点不同，不能据此将差异单独归因于更新量停止规则。
它们说明可达路径依赖接受态、外推及缩步历史；单次运行不构成所有路径的稳定性保证。

## 失败定位的证据边界

关闭正确器限幅的 CLI 报出 `direct bordered dimensions or current derivative are invalid`。
该校验同时覆盖维数和端口电流导数的有限性，不能仅凭这条合并错误指定根因。
将它最后的**接受态**物理势重新装配后，7801 维系统的 88776 个
Jacobian 条目与 RHS 均有限；账本与残差回读差为零。
这不等同于失败试探态有限，也不能排除物理势重新序列化后的微小方向敏感性。

当前最直接的后续定位对象是本轮 Vela 自身轨迹上的失败试探态及其前一接受态：
保存完整 Newton／线搜索状态，分别检查输运、AV 与端口电流导数的有限性和单侧 Jv，
再核对失败方向与实际残差下降。尚不能将停滞认定为某一个 AV 公式错误。
本轮未通过置零电流、固定方向、平滑范数或放宽门限取得结果。
