## 3. 原生定义积分观测

运行版本 T-2022.03-SP2；手册为本地 T-2022.03 User Guide
`build/s09native_newton/sdevice_ug.txt`，印刷页 327、332、335，公式 195/196/208/209。
原生输入为相同已保存 Vg=5 V/Vd=0 V 状态，本地门压短路径与它不是同偏压比较。
新远程目录为 `slot_idvd_20261009_density_integral` 及
`slot_idvd_20261009_relative_integral`，每臂 90 s 硬上限。

手册提供 `eMultiValley(DensityIntegral)` / `hMultiValley(DensityIntegral)` 与
`Math { DensityIntegral(N) }` 的 Gauss–Laguerre 积分入口。但默认 Multivalley
按谷有效质量计算实际人口，输出 Nc/Nv 本身没有变化不能证明人口本构未变。
本参数文件的三电子谷、两空穴谷均零能移；未打开 NonParabolic。

公式 195/196 为 `n=Nc Σ gi F1/2(η−ΔEi/kT)` 及相应空穴式。
默认公式 208 的权重不保证 Σgi=1；因此 `native_analysis.json` 中 `mv_*` 的
单 DOS 关系余项只能显示与原单谷口径不一致，不能当作积分误差。
`route_analysis.json` 为这些臂明确标注单 DOS 恒等式不适用。

公式 209 的 `RelativeToDOSMass` 按已有 DOS 归一化。对本批零谷能移、抛物带，
Σgi=1，因此该入口在数学上可恢复同一单 DOS 定义积分人口关系，而无需拟合
有效质量、Nc 或 QF 偏移。实际实现及积分阶数误差仍须由导出结果验证。

### 原生实测结果

六个新增臂全部正常退出、零 Newton 更新；原保存态 SHA256 前后不变，上传参数文件
原样保留。前三臂为普通 Multivalley 的解析近似/60点/120点积分，后三臂为
RelativeToDOSMass 的解析近似/120点/240点积分。所有开关只作用于 Silicon；PolySilicon
保持默认，因此不能把 Si 的结论推广到全材料。

以下余项采用原生常数 `VT=0.025851995266484913 V` 和 Vela 定义积分反函数：

`en = φn + Ec + VT Fhalf_inverse(n/Nc)`；
`ep = φp + Ev − VT Fhalf_inverse(p/Nv)`。

它们只检查导出人口、QF 和带边的本构恒等式，不是器件残差。

### 仍未统一的部分

1. **BGN 输出在所有这些切换中逐值不变。** 10849 仍为 0.6457549953946401 eV。
   上批已测定义积分统计修正与此相差 +0.656634 meV；全 Si 最大 +0.692065 meV
   也未被这个人口积分选项消除。因此本批不能称 BGN 的统计修正已经使用同一积分。
2. **Load 会重新建立派生人口及边界。** 归一化240点相对默认，Si ψ 最大变化
   0.349319 mV，n/p 最大相对变化 0.218732% / 1.342138%；QF 导出逐值不变。
   零 Newton 更新不等于固定 ψ/n/p，也不代表切换后的完整器件已自洽。
3. **PolySilicon 未启用新入口。** 其人口及导出场与默认逐值一致，空穴单 DOS 余项
   仍约 4.10093e-5 V。当前 Si 人口关系的改善不能用于声称全器件映射完成。
4. 常数比例差的处理沿用上批的解释，未替换 Vela 常数。本批没有用新原生观测态
   直接计算“同态”10849 源项比值或宣称物理 Jacobian 匹配；其先决条件仍不足。

## 4. 本批结论与后续

新实际 AverageBox 配置可以从新冷态连续建立这三个小门压点，并通过不同步进路径的
同目标复求。结论限于 Vd=0、Vg≤.02375 V；不证明高门压或非零漏压已稳定。

原生端已经找到并验证一个**有版本、公式及积分阶数身份的 Si 人口定义积分观测入口**。
归一化控制臂排除了仅因 Multivalley 谷权重改变造成的表面改善，但 BGN 统计修正和
PolySilicon 仍未对齐。本批没有实现或切换 Vela 的原生近似兼容默认值。

下一步可分开推进：

- 沿本批合格父态继续有界门压建立，维持定义积分 Fermi 与原完整资格；不能混入
  旧 Poisson 配置父态，也不以原生兼容模式作为本地续算的必要前提。
- 对矩阵逐项比较，优先核查 BGN 统计修正的独立数值入口，以及 PolySilicon 的
  归一化积分控制。若只能通过显式函数/参数导出建立兼容映射，须绑定版本、公式、
  温度及掺杂范围并独立验证，不能用常数平移补齐。之后再比较10849源项与元素通量。
