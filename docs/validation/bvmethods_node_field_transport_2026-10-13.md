# BVmethods：节点电场算子、显式 E2 实际残差与输运弱行（2026-10-13）

本轮在 T470p 完成下一步 Q2/Q3 对照。识别出本网格在自由 Si 电势变化、接触和氧化层电势
固定条件下的原生节点场一环响应，并用独立扰动验证；显式原生 E2 参数和节点场接入私有
C++ 实际残差后，BTBT 分项闭合。原生 Jacobian 对照进一步排除了两条指定弱行的主要
输运系数差。**通用几何恢复公式、完整 RHS、完整 Jacobian 与从零纯 QS 尚未通过。**

结构化结果见[同名 JSON](bvmethods_node_field_transport_2026-10-13.json)。前轮证据见
[自主迁移率与实际场记录](bvmethods_mobility_weak_btbt_2026-10-13.md)。

## 2. 原生节点场和 ψ 响应

自由 Si 节点按距离二的网格邻接着色，共 13 色。每色加 1e-5 V；另用不参加识别的正负
编码扰动，幅度为 1e-6 V。接触与其他材料电势固定。最终在**同一 sdevice 进程**中加载
基准、两组编码态、13 色扰动态，再重载基准，共 17 次 Plot，运行退出 0。

直接读取 TDR 的 ElectricField 与前轮原物理零源观察器逐值一致。区域 3 使用原始节点 ID
顺序和交错二维向量，未把接触副本覆盖回原始节点。基准 ψ、n/p、场与前轮完全相同；
末尾重载基准的 ψ、n/p、场及 G 也逐值相同。

| 对照 | 相对 L2 | 说明 |
| --- | ---: | --- |
| 识别算子作用于独立正编码 | 3.4756e-12 | 场增量，最大绝对差 6.31e-11 V/cm |
| 识别算子作用于独立负编码 | 3.5648e-12 | 最大绝对差 9.05e-11 V/cm |
| 原生正负增量的线性对称性 | 5.4401e-12 | 未通过拟合编码态来决定系数 |
| 完整自由邻域 2088 行，自主恢复基准场 | 1.1172e-12 | 使用识别系数乘 ψ 差，无基准场注入 |
| 同 2088 行，由恢复场重算 E2 | 5.0965e-11 | 显式原生 A2/B2 |

实际加载的 ψ 增量与请求值最大差 5.51e-17 V。2088 行的完整一环都属于自由 Si，故可用
`sum_j dE_i/dpsi_j * (psi_j-psi_i)` 自主恢复；其余 33 个自由行涉及固定接触邻域，不能把
尚未测得的固定电势系数当作零。31 个接触节点也未取得可变化接触电势的导数资格。
氧化层电势方向、其他网格和更一般状态仍需独立验证。

这是一份**固定网格的原生黑箱响应算子**，还不是已推导的通用几何公式。9 种邻边最小二乘
权重和 12 种单元梯度加权方式均未通过导数对照。即使自由拟合单元梯度组合，最大相对
余差仍约 0.385；不能把“拟合出的权重”解释为原生恢复算法。

## 3. E2 源与 ψ 链式项

显式使用原生导出参数 A2=3.5e21 cm^-1·s^-1·V^-2、B2=2.25e7 V/cm。
16 个态分别由原生节点场重算 `G=A2 F² exp(-B2/F)`，在全部共同自由节点乘原生 Si Measure
后，相对 L2 最大 **4.93e-15**。本轮没有使用旧 A2/B2，也未校准或放宽门限。

`d(GV)/dpsi = d(GV)/dE * dE/dpsi` 已用识别算子组成。原生正负编码的有限步中心差分与
解析链式方向相对差约 **1.995e-6**。这不是直接认领的导数通过：

- 用同两态的实际原生场计算显式非线性 E2，再取中心差分，与原生中心差分仅差 2.76e-13。
- 在已验证的线性场算子上，把显式 E2 差分步减为 1/2、1/4、1/8、1/16，误差分别为
  4.99e-7、1.25e-7、3.12e-8、7.78e-9，符合二阶截断行为。
- 上述缩步是**独立公式的离线控制**，不是新增的原生缩步输出。全装配 Jacobian、
  接触/氧化层电势链式项及跨分支有限更新没有因此获得资格。

## 4. 私有 C++ 实际 BTBT 分项

T470p 编译私有装配对象，保留上轮自主盒平均 µ、原生人口和原始 reference/increment。
四组真实 runner 分项探针均退出 0；新钩子关闭时 CSV 与上轮逐字节相同。
通过 `no_btbt` 实际消融分离 BTBT，避免把整个净复合项当作 BTBT。

| 实际装配模式 | BTBT 相对 L2 |
| --- | ---: |
| 旧参数、原单元场与原积分 | 0.630054 |
| 显式原生参数、原单元场与原积分 | 0.552429 |
| 显式原生参数＋原生节点场＋Si Measure | 3.8915e-11 |

最后一项最大绝对差 5.85e-32（既有内部连续性残差单位）；电子/空穴相同。
该值控制接入了**实际装配**，但节点场仍为固定值输入，不能冒充动态场算子或 Newton 导数。
完整电子/空穴 RHS 相对差仍约 9.7601e-5／4.8377e-4；近零态 BTBT 本身极小，修正其分项
并没有解决输运余差或 SRH/Poisson 实际盒支撑问题。

## 5. 2156／2515 的逐边与原生 Jacobian 对照

逐元素顶点顺序、原生 kappa、盒平均 µ、原始 QF reference/increment 形成独立逐边账本。
其散度与私有实际输运最大绝对差分别约 7.51e-23／4.69e-23。普通浮点求和与 fsum 的差仅
约 3.88e-26／2.52e-29，不能解释现有余差。

| 项目 | 电子 2156 | 空穴 2515 |
| --- | ---: | ---: |
| 原生输运 | 6.1989308481e-11 | 2.2527462694e-13 |
| 重建输运 | 6.1999020499e-11 | 2.2516801135e-13 |
| 原生减重建 | -9.71201795e-15 | 1.06615591e-16 |
| 逐边绝对和／净值 | 51.3267 | 1.06401 |
| 解释余差所需的统一驱动误差下界 | 4.98e-20 V | 1.67e-19 V |

再读取已归档 `source_noava` 的原生 Jacobian；其主变量与原物理基准逐值一致。按变量名
选择 `eDensity/hDensity` 块，保留额外接触 `QuasiFermiPotential` 块；按原生 ψ 尺度换算
电势列。两弱行 5／4 条非零 SG 边的系数与独立重建值最大相对差分别为
**1.20e-13／3.11e-15**。这给出了不依赖 RHS 反拟合的系数证据。

零 SG 系数的几何边仍保留其原生小交叉项（电子最大约 -4.79e-11），没有抹成全零矩阵。
该局部系数检查没有认证全系统的源/迁移率导数。余差调查重点转向原生内部人口、QF 与
近零电流求值/舍入路径；敏感度下界只是量级判断，不能认定某一种舍入机制就是根因。
尤其 2156 的电子人口约 5.07e20 cm^-3，不能未经检查就按 Boltzmann 状态处理。
