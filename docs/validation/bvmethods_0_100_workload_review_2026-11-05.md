# 0–100 V工作点与Newton工作量复核（2026-11-05）

## 范围与结论

离线复核2026-11-04已完成的N20 automatic baseline/全变量Unit四组冷0–100V。没有查询旧作业、读取日志或重跑仿真。原生为既有T-2022.03-SP2扫描；Vela为U-2022.12兼容常数，版本、路径、终点约束不同，不作单一缩放/常数因果结论。

**0–1V接近原生的是N20 automatic OR，不是AND或Full-only。** 连续0–100V中OR两坐标均13点/13尝试/0失败、58轮；原生13/13/0、63轮。此前单独0–1V强制1V端点的OR为14/14/0、62轮，多一个裁剪端点，不能直接换入连续扫描表。

10–100V也不是所有Vela路径都恶化：OR基线18/19/1、80轮，较接近原生12/12/0、49轮；OR Unit70/92/22、626轮明显变差。AND两臂该段均过密，697/719轮；Unit的AND总量增加主要集中5–10V。

全变量Unit是独立诊断原型，production_qualified=false；原固定方向29/30限制仍保留。四组均到100V、solver0非超时，所有接受态通过适用原AND/OR及独立门；拒绝候选不等于接受态门失败。

### 路径何时开始不同

AND首次尝试事件差在0.2751763V：基线20轮预算失败，Unit19轮内部线性门失败；这次两边都缩步。按外压差>1e-10V定义可辨网格分叉，首次接受网格差在第23个记录：基线1.96725979V、Unit1.81055083V。

OR首次尝试事件差在3.06299981V：基线4轮内部线性失败，Unit2轮原物理线性复核失败。首次可辨接受网格差在第27个记录：基线6.02511933V、Unit6.04229896V。因此10–100V的两条轨迹继承了更早的不同接受态/预测历史，不是同态单个目标的缩放对照。

### 当前轨迹中的bootstrap记录

10–100V实际bootstrap写回数量依AND基线、AND Unit、OR基线、OR Unit为150/197/9/177。其中有限rho且rho<0记录为130/167/5/142，表明实际质量下降值得继续定位。这些是当次轨迹诊断rho，不能直接将它们全部认定为后续失败原因，也不能把trial标签当bootstrap。完整实际模式计数见analysis.json。

OR基线这段实际bootstrap很少（9），Unit为177，模式选择与路径明显不同。现有数据支持“早期分叉—模式/步长选择不同—更多工作量”的关联，但尚未证明一个唯一触发因素。原Unit固定态代数恒等式误差约1e-16，方向门29/30，不能仅凭累计轮数认定漏乘尺度。

## 对“昨天低压接近原生”的准确解释

N20 automatic OR的低压接受点和轮数接近原生；N20 AND在同一连续扫描中为19/21/2、149或148轮，已经明显多于63。另一项Full-only N20仅在0.066819V恢复原生3轮；其完整低压AND为36/47/11、299轮，OR止0.262404V，不能把该单点成功说成全段Full-only已接近原生。

本0–100V四组均为automatic，bootstrap仍会使用；没有一组是Full-only+Unit的0–100V结果。此前单独1V裁剪窗口和本连续窗口必须分别报数。
