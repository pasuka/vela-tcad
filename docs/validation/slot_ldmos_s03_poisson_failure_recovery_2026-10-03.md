## 三阶段同内压诊断

各阶段均重新检查同一组 25,268 条有效行、全接触闭合，并以零 Newton 的 frozen_state
取得 SG 电流。输入态与该次冻结写出态的物理字段摘要一致。

| 项目 | 保存的失败末态 | 一次载流子块修正后 | Poisson 修复后 |
| --- | ---: | ---: | ---: |
| 超标有效行数 | 0 | 0 | 0 |
| 最大行比 | 9.384126e-4 | 3.937010e-4 | 3.937010e-4 |
| 最差行 | 6609 电子 | 3591 空穴 | 3591 空穴 |
| 冻结 ψ 块残差 | 1.004776e-9 | 1.017185e-5 | 9.808157e-10 |
| 按完整器件块尺度归一化残差 | 8.446162e-10 | 8.550470e-6 | 8.244746e-10 |
| 电子全局闭合比 | 1.535749e-6 | 7.756401e-8 | 1.261862e-7 |
| 空穴全局闭合比 | 1.531063e-6 | 7.756400e-8 | 1.262113e-7 |
| SG 漏电流 A/µm | 1.627992196567e-9 | 1.628633995906e-9 | 1.628633995854e-9 |

原失败末态并没有超标载流子行；前批的失败来自 Poisson 模式的停止条件。
完整器件归一化残差使用原 `residual_scales`，不能与 Poisson 单块残差直接混用。
初始冻结诊断的各项通过也不等于已经执行完整器件资格。本批未对未经修正的原失败末态
单独运行严格验收，因此不能断言载流子修正是通过资格的必要步骤。

一次载流子块修正降低了最大行比及载流子块残差，但暂时破坏 Poisson 自洽，
ψ 残差升至 1.017e-5。后置 Poisson 用 **2 次更新**收敛，原因
`poisson_only_contact_basin_converged`，ψ 残差降至 9.808e-10。
这说明本态可以用后续块修正恢复，不能据此前置 Poisson 退出就推断整条组合路径不可用。
也不能把载流子修正后的中间态直接接受。

## 完整资格与外压边界

后置 Poisson 态进入冻结局部修正接口，行已满足，**局部修正 0 轮**。
随后原完整器件验证以 **0 次 Newton、`initial_abstol`** 通过，复核了有效行、
全局闭合和文件绑定；这是完整资格检查，不是电路复用行的占位零值。
严格最大行比 0.0003937010015，电子/空穴闭合比约 1.262e-7。

严格 SG 电流较本次保存初态增加约 **0.03942%**。内压保持相同，电阻为 1e12 Ω·µm，
这一电流变化对应约 0.642 V 外压移动。以严格值计算
`U_actual = V_inner + R × I_SG` 后，原负载线确认通过，记录残差为 0；
该确认使用器件态复用，证明的是已独立获得完整资格的器件态与派生实际外压一致，
不能单独替代器件证明，也不是从独立初值复现。

相对上一批连续路径末点，诊断态电流增加 **10.04336%**，数值上仍在 25% 守卫内。
但两态内压不同；审计中的场差、源项差和 `current_relative_difference` 是相邻偏压变化，
不是同偏压精度或重复性误差。正式路径账本仍停在内压 38.50520523823174 V、
外压 1518.4981359194119 V、电流 1.4799929306811801e-9 A/µm。
