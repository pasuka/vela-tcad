# R7 高压长尾：有限接触行的舍入与代数一致性审计

日期：2026-09-16；分支：`codex/templates-ldmos-phase-a`。

## 结论

已将 Vg=4 V、Vd=30.666666666666654 V 的 5 次 floor 长尾定位到有限
`hRecVelocity` 接触的中性电势约束：温度在相邻浮点数之间变化时，计算出的
中性电势目标跳动；实际 ψ 与该目标留下 8–16 个 ψ 浮点间隔的差异，有限
接触通量将其放大为逐行不收敛。通量求和、体复合抵消和归一化计算的舍入
不是此样本的主要来源。

五个失败的冻结状态仅恢复现有中性接触等式后，原逐行门限和三个电学块
门限全部通过；fn/fp/T 完全不变，所有节点最大 ψ 变化不超过 7.11e-15 V。
这是固定状态诊断对照，不是已经验证的 Newton 优化；生产仍为 R7，原
14 次更新记录和默认算法均未改变，没有认领减少更新或墙钟加速。

## 冻结口径和观测实现

承接[R7 独立局部重表示对照](templates_ldmos_r7_local_rebase_2026-09-15.md)。
在原 Linux 环境用上一轮冻结二进制，从原种子分别重放 9、10、11、12、13、
14 次更新；每段完整历史与原 14 次轨迹前缀逐值一致。保留原 R7 网格、
IALMob 几何、材料/温度模型、编号、SI 单位、连续性体积、有限接触参数和
UMFPACK 后端。Windows 补充第 9 次失败及第 10 次闭合状态对照。

新增 `diagnostic_hole_row_audit_nodes`，只允许零更新的 coupled/provided_state
诊断，记录节点 4634/4635/4636 的：

- 原装配顺序的每条有向 SG 空穴电流、几何权重、迁移率和端点统计输入；
- SRH/Auger 率、源体积乘电荷、完整残差、通量绝对值和、原电流尺度；
- 有限接触通量、中性电势及温度导数、小 eta 差值、平衡密度和 Fermi 导数。

节点实际属于**有限接触的活动空穴行**，不是普通内部行；必须把接触通量
加入分子和通量绝对值和。首版只支持内部行时主动拒绝这些节点，未用于结论。

标准 provided_state 加载会投影有限接触的 ψ；即使 Newton 更新数为零，
也不能据此声称状态未变。本次只读模式显式绕过该初始化投影及 QF 重表示，
严格保留输入。六个 Linux 原始冻结状态、残差与原二进制结果逐值一致。
另用原二进制的标准加载投影做独立对照，再对投影后状态只读观察，避免混淆。

观察器额外进行一次残差装配，检查完整残差和空穴通量绝对值和不变；用记录的
体源→边→接触顺序可逐值还原行残差。此额外观察装配不属于求解循环的计时
计数；本轮没有用其 profile 或子进程墙钟比较算法性能。零更新输出的退出
原因仍为 `frozen_state`，不将其标成生产收敛或完整 D0 验收。

## 排除求和、SG/复合算术与归一化

使用 Decimal 的 70/100 位精度，对捕获的**精确 binary64 操作数**重新计算；
两种精度产生相同的最终浮点诊断值。先只改变各项累加，再分别重算 SRH/Auger
表达式、SG 表达式（含冻结 g、原舍入 QF 差值和重新计算差值的隔离）、有限
接触小差值表达式，最后联合对照。

这不是完整任意精度 Fermi/IALMob/温度物性求解：输入密度、eta、有效态密度、
迁移率、寿命和接触 Fermi 导数仍来自原物理实现。它能区分已捕获操作数的
算术误差，不能替代物性原函数及中性根求解器的独立高精度资格。

Linux 18 个原始观测行的最大逐行比值变化：

| 单项变化 | 最大绝对变化 |
|---|---:|
| 高精度求和及相应分母重算 | 5.94e-17 |
| 源项率求和/乘积重算 | 5.94e-17 |
| 重算 SG，保留原舍入 QF 差值 | 2.49e-15 |
| 重算 SG，包括 QF 差值与 g | 2.46e-15 |
| 重算体复合表达式 | 5.94e-17 |
| 重算有限接触小差值表达式 | 1.10e-16 |
| 联合重算上述算术 | 2.35e-15 |

原失败比为 5.51e-4–1.10e-3，门限为 1e-8。这些变化不足以解释或消除失败。
例如第 9 次更新后节点 4636：原比 0.001100095973193993，高精度联合比
0.001100095973195207，结论不变。其源项约 4.59e-25 A/m，失败残差约
4.22e-11 A/m，不能将其解释为 SRH/Auger 体复合抵消造成的舍入底部。

## 正向定位：中性接触目标与有限通量的放大

节点 4636 的有限接触公式已有小差值分支：

```text
delta = (fp_reference - bias + fp_increment - (psi - psi_neutral(T))) / Vt
I_contact = q * velocity * boundary_length * Nv * delta * (F'(eta) + delta*F''(eta)/2)
```

在第 9 次更新后的状态，接触斜率绝对值约为 47536.6 A/(m·V)，
`psi - psi_neutral = -8.881784197e-16 V`，等于 -16 个 ψ 浮点间隔。
由该差值预估的接触残差为 4.22209511354e-11 A/m，实际为
4.22209511347e-11 A/m，主项相符。

对应逐行分母约 3.84e-8 A/m；原 1e-8 门限对应残差约 3.84e-16 A/m。
因此很小的电势约束误差足以造成明显的空穴行失败，即使原 Poisson 块已通过。
提高求和精度无法消除已经存在于状态中的这一差值。

Linux 实际轨迹中，节点温度在 364.51383967887887 K 与
364.5138396788788 K 之间往返，仅差 5.68434e-14 K；计算出的中性电势在
-0.47189355998047366 V 与 -0.47189355998047455 V 之间往返，差 16 个
ψ 浮点间隔。Windows 单独将节点温度下调一个浮点间隔也复现了该跳变，
而按原 `d psi_neutral/dT` 的平滑预测只有 -2.36e-17 V；温度上调一个间隔时
目标保持不变。已定位到离散中性电势目标及其代数一致性，尚未进一步将
目标跳变归属到能带、统计函数或二分根求值中的某一个具体舍入操作。
