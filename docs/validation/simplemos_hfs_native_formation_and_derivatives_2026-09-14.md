# SimpleMOS HFS 原生形成方式与导数校准

日期：2026-09-14。本轮在已经冻结的 Enormal 曲线之后恢复原生 HFS，完成八个控制点的基准/观察器对照、实际输入偏导和单元复合导数检查。这里只验证 HFS 形成方式和诊断原型；Vela 生产 HFS 路径、自洽双初始化及完整曲线尚未执行。

工况为 n19/n23 × Vd=0.05/1 V × Vg=0.8/1 V，300 K、Boltzmann、OldSlotboom、PhuMob、Enormal、HighFieldSaturation、SRH(DopingDependence)。沿用各自原始 TDR 网格：1480/1482 节点，Si 各 1750 个三角形、942 个顶点；坐标 μm，迁移率 cm²/(V·s)，驱动力 V/cm，电流 A/μm。原生环境为 RHEL 7.9、SDevice T-2022.03-SP2、ExtendedPrecision(128)、Super、Digits=12、RhsMin=1e-20、Iterations=40。这些数值设置用于校准，并不等于原始脚本的默认求解设置。

输入、计算结果与解释分别留档。原生 DC 合格要求退出码 0、版本与正常结束标记、偏压误差≤1e-10 V、KCL/Id≤1e-8；替换观察器要求 Id 相对差≤1e-12、电势绝对差≤1e-12 V、密度相对差≤1e-10、迁移率相对差≤1e-12。没有改变既有 Vela 接受条件。

## 八点原生身份与形成方式

16/16 原生 DC 通过，最大 KCL/Id=2.033e-15。8/8 基准与替换观察器对照通过：Id 完全一致，57 个导出字段完整匹配，电势最大差 1.111e-16 V，密度/迁移率最大相对差分别为 5.303e-16/5.491e-16。该观察器替换原生 Canali 定律，并非零加法探针，因此实际身份校验是必要前置条件。

15,072 个最后调用样本均与最终原生电势、电子和空穴密度匹配，覆盖每点两种载流子的全部 942 个 Si 顶点。单个样本仍是某次单元上下文调用；保留全部邻接候选，不将最小误差对应单元视为唯一身份。

原生默认形成过程得到以下支持：

1. 普通 Si 单元采用线性单元准费米势梯度。
2. `ParallelToInterfaceInBoundaryLayer(PartialLayer)` 默认开启，对具有 Si/绝缘体界面边或外边界边的单元，使用该梯度平行于边界的分量。该默认项在 9 月 12 日预检中漏记，本轮按本地手册第 452–453 页补齐。不能直接使用全域完整准费米梯度。
3. 只要单元具有一个接触顶点，即按默认接触规则换用电场。每个网格有 36 个单接触顶点单元；“必须有接触边才切换”的候选明显不符。接触电场替代优先于准费米边界投影。
4. 数据显示弱场输入存在约 1 V/cm 的置零分支，且作用于接触电场分支。先仅在非接触分支置零的 v1 结果保留；全分支候选另存 v2。切换本身的独立探针见下文。
5. 在每个顶点先形成活的 PhuMob 与 Enormal 低场合成迁移率，再逐顶点施加 Canali 饱和，最后按原生 box 顶点权重形成单元迁移率。既有网格、原生 box 权重和输运几何保持不变。

同时采用上述规则后，15,072 个样本均有邻接场匹配，最大驱动力绝对差 7.690e-9 V/cm。对全部 28,000 个单元/载流子组合独立回放：

| 对照 | 电子最大相对差 | 空穴最大相对差 |
| --- | ---: | ---: |
| 未拟合 PhuMob 数学截断，逐顶点饱和后平均 | 1.383e-9 | 7.356e-6 |
| 同一低场模型，先平均后饱和 | 0.129249 | 0.0142413 |
| 仅作诊断的既有 PhuMob 左根控制 | 两载流子合计最大 2.661e-9 | 同左 |

电子单元结果通过原 1e-7 门槛；空穴的 7.356e-6 仍未通过，继续归入先前 PhuMob 截断缺口。旧左根/G 控制没有重新拟合，不能转成生产参数或覆盖原失败记录。错误平均次序的最大电子/空穴偏差为 **12.9249%/1.42413%**；这是单元迁移率差，不能当成 Id 误差。

## 导数范围与结果

第一层直接使用原生实际传入的 m、F、T，将同一观察器 C++ 头文件编译为独立探针，与 90 位 Decimal 中心差分比较。两档相对步长为 1e-12、5e-13，门槛 1e-10。15,072/15,072 个样本的 μ、∂μ/∂m、∂μ/∂F、∂μ/∂T 检查通过，最大比较差 3.677e-12；其中 7,117 个零场样本另按 300 K、beta>1 的极限检查。温度偏导检查不表示温度方程或非 300 K 器件已通过。

第二层采用独立解析链式原型与 110 位状态中心差分，步长 1e-22、5e-23 V。选择热点 792/1000/1009/1057/1089 的全部相邻单元、每种接触/边界分类代表及 1 V/cm 上下最近单元，两种载流子共 558 个单元/载流子组合。全部三个顶点的 ψ、φn、φp 共 **5,022/5,022 列**通过；非零导数最大相对差 6.227e-30，解析零项的差分结果也通过原绝对门槛。包括：

- PhuMob 电子/空穴密度交叉项及固定掺杂/BGN 下的密度—势链；
- Enormal 全部邻接电势列、距离梯度和边界投影；
- 接触电场与非接触准费米场分支，以及逐顶点饱和后的 box 加权。

令 m 为合成低场迁移率，z=mF/vsat，A=1+z^beta，则平滑分支使用：

```
dμ/dx = A^(-1-1/beta) dm/dx
       - (m²/vsat) z^(beta-1) A^(-1-1/beta) dF/dx
```

低于弱场切换的分支令 dF/dx=0，仍保留 dm/dx。恰处于切换点不能宣称普通导数存在；Enormal 零法向场仍有原有的绝对值非光滑性。此处不是符号软件自动求导的全矩阵证明，也不是原生装配 Jacobian 或生产 Vela Jv 验收。

证据：[实际输入偏导，先导](../../reference_tcad/simplemos_sentaurus2022/hfs_restore_20260912/derivatives_20260914/pilot_summary.json)、[实际输入偏导，其余七点](../../reference_tcad/simplemos_sentaurus2022/hfs_restore_20260912/derivatives_20260914/rest_summary.json)、[单元链式先导](../../reference_tcad/simplemos_sentaurus2022/hfs_restore_20260912/chain_20260914/pilot_summary.json)、[单元链式其余七点](../../reference_tcad/simplemos_sentaurus2022/hfs_restore_20260912/chain_20260914/rest_summary.json)。

## 弱场独立探针

v4 已通过。七档场强为 0.5、0.999、0.999999、1、1.000001、1.001、1.5 V/cm。两次原生 Load/Plot 程序退出 0，14 个导出状态均通过加载资格，ψ 差为零，准费米势最大差 1.428e-31 V，密度最大相对差 2.443e-15；基准/观察器全部字段的最大相对差 4.124e-16。这是固定状态探针，不是自洽 DC 资格。

均匀场检查预先限定到没有接触相邻单元的 868 个节点，所有节点在两种载流子、七个状态上均有完整覆盖。69,076/69,076 个有效调用通过；另有 4,424 个接触邻域调用保留在排除表中，没有作为均匀梯度样本。没有因状态无法匹配而排除的调用。

| 请求驱动力 / V/cm | 原生送入 HFS 的驱动力 | 观察结果 |
| ---: | --- | --- |
| 0.5、0.999、0.999999 | 全部为 0 | 饱和修正为 0 |
| 1.000001、1.001、1.5 | 与请求值一致，误差≤1.7e-10 V/cm | 全部启用饱和 |
| 1.0 | 同时出现 0 和约 1 | 各单元表示与梯度舍入决定所处分支，不能当作光滑点 |

独立原生探针把切换位置约束到 **[0.999999, 1.000001] V/cm**；并不声称黑箱内部等号比较或任意精度阈值已被直接读取。在 1.000001 V/cm，电子相对低场迁移率的最大修正约 -3.0225e-5，空穴约 -3.7913e-6。此分支不是把 F 平滑钳位到 1 V/cm：下侧实际传入的是零。

证据：[加载及身份检查](../../reference_tcad/simplemos_sentaurus2022/hfs_restore_20260912/cutoff_probe_20260914/v4/integrity_summary.json)、[逐档阈值表](../../reference_tcad/simplemos_sentaurus2022/hfs_restore_20260912/cutoff_probe_20260914/v4/threshold_summary.csv)、[探针汇总](../../reference_tcad/simplemos_sentaurus2022/hfs_restore_20260912/cutoff_probe_20260914/v4/summary.json)。

v3 只对状态副本执行七档 Load/Plot，无 Newton 求解。两次程序退出 0、替换观察器字段身份通过，但加载资格失败：接触准费米势被恢复为接触值；预计密度使用了 Vela 的现代 SI 热电压，遗漏已知原生热电压差，非接触密度相对差约 2.03e-7。v3 的失败表和所有输出保留。v4 保留接触原值，密度预测改用此前已独立核实的 q=1.602192e-19 C、kb=1.380662e-23 J/K；不拟合常数，不修改生产常数，门槛不变。观察器改为跨对象追加全部调用，避免 Load 重新创建模型后覆盖前一状态的记录。最初的准备阶段还发现原生 checkpoint 保存准费米势而不保存独立密度数据集，该准备错误及日志也保留。
