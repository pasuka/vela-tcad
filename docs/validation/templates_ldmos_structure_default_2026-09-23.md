# 经典 DC 装配结构复用默认化

## 实现范围

基于本地提交 `3375efc0`，按用户授权将经典 DC Newton 点服务的
`solver.reuse_jacobian_structure` 设为默认 `true`。显式 `false` 清除共享引用。
旧 `diagnostic_reuse_jacobian_structure` 在正式字段缺省时继续生效；两者同时
出现时正式字段优先，以保留既有实验的显式关闭对照。

复用零值稀疏模板、位置映射及边/节点/单元散布表。数值 Jacobian、残差、
载流子与数值分解仍重新计算。精确结构键、输入准备失效和上下文清除机制保持。
缓存限于同一扫描对象串行请求；不同对象不共享可变缓存。
Fermi 节点缓存仍默认关闭，四方程电热入口未接入此项默认化。
物理模型、求解门限、预测及步长策略均不改变。

  上下文清除、关闭后重新开启及扫描对象隔离。检查重新装配与复用的电流、
  更新数一致，并确认 Fermi 节点缓存未启用。
- 既有装配层测试检查不同状态下矩阵与残差精确一致、只读表不被替换请求修改，
  以及温度、几何、编号/单元邻域和约束行变化后的失效重建。
- 完整 CTest 验证共享 DC 默认路径；D5 双栅压前八精确点使用缺省结构选项，
  对照已冻结 HDF5 完整轨迹的前缀，检查字段二进制值、原门限与缓存计数。
