# BVMethods失败增广系统冻结与线性解法对照，2026-10-31

## 结论与范围

本次在vela VM冻结并重放原失败系统。直接原因是该检查点的bootstrap近似矩阵数值退化，原线性精度检查正确拒绝了其方向；恢复流程又在bootstrap线性失败时直接退出，未尝试同态完整Jacobian。相邻外压缩步没有改变这份近似矩阵，因而重复失败。

最有针对性的后续修复是：bootstrap线性精度失败后，在同一状态、同一目标尝试一次完整Jacobian，沿用原线性检查、人口保护与非线性验收；两者均失败才交回外压缩步。本轮仅完成诊断，未实施生产恢复策略、修改默认值或重启完整BV。

本次不同于[此前低偏压局部验证](bvmethods_sg_bootstrap_core_2026-10-31.md)。完整导数的两个同态单步控制通过，不代表完整BV已通过，也不证明所有困难暖态或Sentaurus逐轮矩阵一致性已闭合。

## 最差行：不是只有一个很小分母

线性方程按A x=b审计，逐行分量后向误差为

\[
\eta_i=\frac{|(Ax-b)_i|}{|b_i|+\sum_j|A_{ij}x_j|}.
\]

核心同时要求最大分量后向误差不超过1e-10，以及行缩放后的绝对缺陷不超过`1e-8*max(1,||scaled_rhs||∞)`；本例后者为1e-8。下面数值是冻结增广方程坐标内的量，不直接标成安培或物理浓度。

|---|---:|
| 行号、分块、节点 | 7264，空穴，2064 |
| 是否规定边界行 | 否 |
| 严格非零条目 | 11 |
| RHS | −1.1438206273275166e-29 |
| 绝对缺陷 | 6.143916534153434e-12 |
| 归一化分母 | 1.8687536034649538e-10 |

节点2064的空穴浓度约470.597 cm^-3，电子浓度约2.50833e19 cm^-3；它不是下限节点。该原始方向的空穴增量约−8.46046e6 cm^-3。整个平衡坐标方向的无穷范数约3.13887e65，其他行的缩放绝对缺陷也非常大。因此不能把失败解释成无害的弱行百分比，或删除这一行来通过验收。

## 为什么缩步没有解救，以及恢复缺口

1. 两个失败目标的packed状态及原始bootstrap矩阵逐字节一致；RHS仅第7800行电路项改变。外压减半不会自动修复这份近似矩阵。
2. 当前[CoupledLoadLine](../../include/vela/simulation/CoupledLoadLine.h)每次solve新建bootstrap恢复控制器。在这个新目标，负载线尚未闭合，也未应用两次bootstrap更新，因而尚未触发完整导数探测。
3. 线性求解失败分支只允许“完整导数失败→回到bootstrap”；bootstrap线性失败直接返回。由于第一次方向就不可用，永远到不了“应用两步后再探测完整导数”的条件。
4. 这与停止门是否改为OR无直接等价关系：失败发生在任何实际更新和下一次非线性停止检查之前。不能用放宽停止门或线性精度门绕过。

建议后续独立修复bootstrap线性失败的恢复路径：在同一状态、同一外压尝试完整导数，保留原线性双门、实际人口保护、真实RHS及非线性强制门；限制为一次明确尝试并保留回滚，避免无限模式循环。随后复验本次冻结系统、原困难暖态和多偏压窗口，再评估完整BV。此次没有实现该生产改动，也不能据此断言Sentaurus内部采用完全相同代码。
