# SLOT LDMOS工作日报素材：2026-10-14晚至10-15

范围按10月14日夜间至10月15日本轮分析整理。以下区分仿真完成、研究验证和问题定位；
不将未合格末态计为完整生产结果。10月15日运行中任务数值采用此前已核实快照，并非本报告时刻的实时状态。

## 一、可直接用于日报的工作内容

### 10月14日晚：并行计算与参考结果准备

在Linux计算虚拟机部署SLOT BVDS四组12小时并行试算，对比4线程基线、两点外推、
50 mV起步及外推配合1 V最大跨度。任务使用独立冻结配置、监督截止和状态存档，
保证本机关机、SSH断开后仍能执行并保存退出原因。同时持续收集IdVd和Sentaurus参考结果，
为次日数值问题分析准备逐步日志、状态、残差、矩阵和端口电流证据。

夜间BVDS基线与50 mV起步臂分别推进到5.0191 V和4.9987 V；两点外推臂推进到
29.2217 V后数值停止；最大跨度1 V臂推进到29.2178 V后预算结束。四臂均未达到
1e-7 A/µm的击穿提取电流。原生Sentaurus参考任务已完成IdVd至60 V，BVDS在器件漏压
约38.5222 V、电流约1.0320e-7 A/µm处触发停止。这些参考结果尚不代表Vela全程定量一致。

### 10月15日：IdVd低浓度异常修复与短程复现

完成IdVd连续逆映射失败的定位：6251节点在接受链中反复遭受负浓度提议与0.001比例投影，
空穴浓度最终降至约5.68e-295 cm⁻³，极端动态范围导致Fermi逆映射保护触发。
实现稳定对数增量和稀薄区正向计算修复，保留原误差阈值；实际失败态重放误差降至约8.60e-14。
另行实现默认关闭的临时止降诊断，验证保持的是人口而非固定绝对QF。

通过四臂同态与连续更新对照，进一步定位输运和电离源迁移率导数的线性化不协调：
只省略输运侧导数时，6251实际方向系统的自身对角可能变负；同步处理源内相应链式导数后，
方向转为恢复人口。真实源项和残差保持不变，原始物理方向继续用于更新误差和线性质量检查。
协调臂末态无持续投影、无未释放止降，6251及其邻域恢复平衡。

随后完成1.030 V两条偏压路径复现，并以10 mV热启动推进到1.10 V研究目标。
1.030 V最大空穴QF路径差约0.690 µV，端口分载流子电流比较通过；1.10 V漏电流约
1.48717e-4 A/µm，6251空穴浓度约0.0025304 cm⁻³，追踪邻域最大空穴行比4.95e-5。
这些点通过研究筛选，仍保留诊断身份，尚未完成正式早停流程及1.10 V末点独立路径复现。

### 10月15日：BVDS停滞原因分解与高精度验证

区分夜间任务的预算停止与数值停止，仅对预算结束的BVDS三臂启动独立24小时续算。
基线与50 mV起步臂继续推进；外推加1 V最大跨度臂续至29.221621685 V后也发生数值停止。
同父态热启动/外推和大小跨度对照均复现失败，排除了“只有外推或1 V大步才导致本次停止”的解释。

定位两项独立阻塞：高掺杂Si节点Poisson残差平台，以及源端3598–3599电子QF边差保护。
载流子行比和闭合已通过时，继续浓度块恢复不能解决Poisson问题。
修复binary128 Poisson路径遗漏材料人口前因子的错误，消除多晶硅异常残差；
默认double残差和端口值保持逐项一致。补齐多晶硅恢复时packed QF提示量的同步清零，
避免试探存档不一致。

后续double/binary128局部复验均未新增完整合格点。冻结方向审计进一步证实，
Poisson修正约为1e-15 V量级，在线性系统中有效，却在packed double坐标加法中被量化。
double全步13693个非零修正有10488个未生效，binary128末态全部13693个未生效；
存档复读残差一致到约1e-22，主要损失发生在内存更新。接触边超限约6.01 ppm独立保留，
没有放宽原BVDS验收。

production numerics 15例/1236断言、Poisson charge 11例/1544断言、Newton precision 17例/825断言。
Python packed恢复及续算相关测试通过；最新Poisson证据包187份文件哈希核验一致。
测试组可能覆盖相同功能，不将上述数量简单相加称为新增独立测试数。

性能分析显示，IdVd当前固定25步观察每点约15分钟，原/诊断两系统装配与求解占单步记录成本约68.7%；
线性质量检查与精化约0.10%，详细文件/极值输出约1.6%。后续优化优先共享同态计算，
同时明确研究尾步与正式早停的区别，不将成本直接归因于CSV或PARDISO分解。
