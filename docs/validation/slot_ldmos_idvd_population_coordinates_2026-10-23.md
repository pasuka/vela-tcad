# SLOT IdVd稳定人口坐标换算与8592导数核查

## 范围与实现

本批经授权在VM执行四小时，固定北京时间2026-10-23 10:47—14:47。承接[稳定Fermi输运修复](slot_ldmos_idvd_stable_fermi_transport_fix_2026-10-23.md)，保留其独立修复库；新改动限定于SLOT人口方向/有限更新的η、对数导数及相对逆映射换算。原始数据和分析留在VM，本地保留源码、测试和结论。

配置：13881节点SLOT网格、补偿掺杂、300 K、Vg=5 V、Fermi/effective_band_sg、PhuMob反馈、单线程PARDISO消元保留电势约束。困难目标约0.155955974 V。人口下限、投影、逆映射保护阈值、接受规则及P2影子模式不变，不进入新长扫描。

7107上批实测人口/DOS约4.40684e-325，小于binary64最小正次正规数的一半。此次不通过容差放行，而在正且有限的两个操作数之间采用稳定坐标转换：

1. 正常范围保持原人口/DOS及逆Fermi求值；仅比值进入次正规尾部时用log(人口)-log(DOS)求η。
2. η<-700时F'/F按稀薄极限1求值，避免0/0及次正规舍入；该区逸度修正远低于binary64精度。
3. 相对逆映射同样保留普通路径；极稀薄起点采用log1p增量。若大正增量使终点离开稀薄域，则在可表示的终点调用完整Fermi逆函数，不能继续套用Boltzmann近似。
4. 冻结runner中的生产方向、推进方向以及影子/反事实换算统一使用上述助手。零、负、非有限人口或DOS仍报错，不增加人口下限。

## 8592实际Jacobian加项

观察对象是上批第三次更新前的固定状态，与本批后续迭代态分开标识。独立观察器记录实际散射的缩放系数、源码调用位置及边/单元身份，不改系数或累加顺序。观察器/无观察器的`stabilized.mtx`和`vectors.csv`逐字节一致，包含RHS与返回方向。

对8592、8647、8579、7107四条空穴行重组全部捕获加项，与最终矩阵的最大系数差按该行最大系数归一后约4.44e-17至1.17e-16。8592的242条加项按调用位置分组：
