## Sentaurus 设置的依据

本地 Sentaurus Device User Guide T-2022.03 第 195–196 页说明：

- `LineSearchDamping=1` 为默认值，关闭线搜索阻尼。小于 1 时启用；该值
  是允许的最小系数，实际系数由算法选择，并非每步固定乘这个值。
- Bank–Rose 是另一种依 RHS 变化选择更新大小的方法；超过 `NotDamped`
  指定轮数才激活，默认 1000。
- `Math` 设置可由 `Coupled` 参数覆盖。手册建议扫描中通常优先缩小偏压／时间步。

前轮新运行的 `native/n5_des.log` 明确打印 `LineSearchDamping=1`、
undamped iterations=100、max iterations=20；其 CMD 没有局部阻尼覆盖。
因此该扫描的两种阻尼均不激活，前五个非零点各 3 次完整更新。
公开的 [Synopsys 培训材料镜像](https://ghzphy.github.io/Sentaurus_Training/sd/sd_6.html)
也解释了默认关闭线搜索和日志 factor 的含义。本轮没有重新运行 Sentaurus。

## 修改与控制边界

增加显式 `sweep.external_circuit.coupled_line_search_mode="report_only"`：

1. 从 α=1 开始评估旧 `merit` 规则，记录建议的 `reported_alpha`；没有建议时为 0。
2. 对有限且模型有效的完整步，实际写回 α=1，即使 merit 上升；
   `coupled_damping_factor` 不缩小该模式的更新。
3. 完整步非有限或模型求值抛异常时，正确器失败，不改用一个阻尼试探态；
   外层按原设置重试并缩小偏压步长。
4. 保留独立的器件／内压更新保护及所有终态残差、负载线和物理验收门。

默认仍是 `merit`。该模式额外评估影子试探，有诊断开销，不能将其耗时视为
完全删除线搜索后的性能。补齐已有 `coupled_update_convergence` 的两份 schema；
本轮设 `mode="off"`，仅用 `diagnostic_csv` 记录轨迹，没有启用增量停止准则。
CSV 追加实际／建议 α、完整步 merit、原始与独立保护后的更新大小。

Poisson 初始化沿用原算法，实际 7 次更新的 α 全为 1；零偏联立不需要更新。
全局和少子 QF 固定上限均为 0。独立内压更新上限仍为 0.1 V；
本轮所有实际写回均未触发该保护。最后一个无效候选触发了它，但仍失败，未写回。

## 末接受态的独立方向核验

用本轮自身 HDF5 的 ψ/fn/fp 重新打包，在同一最小外压目标、同材料和
PARDISO 后端下进行单轮审计；没有从人口反算 QF。该审计刻意使用旧 merit
规则采集多个 α 的真实残差，不是另一次成功的完整步扫描。

- 复现原方向：δψ∞=9.916114 μV、δfn∞=10.393152 μV、
  δfp∞=3.405239485 V（节点 152），δVin=9.916114 μV。
- 7801 维原始 bordered 系统无非有限系数；分量后向误差
  2.253525e-16，器件线性缺陷 6.181507e-16、端口线性缺陷
  −1.366369e-13 V。PARDISO 线性系统求解不准确没有得到本次证据支持。
- α=1、1/2、1/4、1/8 的真实器件残差分别约
  15573.8575、176.6282、4.255027e-5、6.645972e-9。
  完整步线性预测仅约 7.60e-12，表明该多伏空穴方向的有限步已远超
  此处线性近似的有效范围。α=1/8 是一个通过旧回溯的试探，
  其负载线仍差 −8.74696 μV，不能计作收敛偏压点。
- 用 Jacobian 绝对对角逐行缩放，原始方向归一为最大 1 mV 后，在
  最大实际扰动 1 μV 时，中心差分 Jv 的相对 L2 差为 1.248166e-8；
  0.1 μV 时为 7.052672e-8，已显现舍入影响。
  单独节点 152 的空穴列在 0.1 μV 扰动时为 9.758052e-11。
- 粗档内建审计的 Jv 相对差约为 1，不能忽略；细化的固定电压扰动结果
  说明粗档数值不能直接解释成局部 Jacobian 错误。原始方向对应的端口
  导数仅约 2.31e-18 A/μm，其电流差分未稳定，端口导数数值验证仍未通过。

这些结果支持首先定位小外压修正为何产生多伏空穴方向，分离弱空穴行、
AV 矩阵贡献与缩放／条件性，核对同态原生状态和端口近舍入电流。
本轮既没有证明完整矩阵已与 Sentaurus 一致，也没有证据支持用固定 QF
限幅或放宽残差门限来宣称修复。
