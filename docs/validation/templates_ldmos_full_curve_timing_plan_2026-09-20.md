| U1 | UMFPACK，主系统跨点复用，1/1 | 重点候选 |
| T1 | STRUMPACK，主系统跨点复用，2/1 | 重点候选 |

这是已验证运行配置的比较，T1 使用两个求解器线程，不是全部单线程算法的
公平复杂度比较。墙钟与 CPU 分开报告；若需等线程比较，另加 STRUMPACK 1/1

同一台 Windows 主机、同一 UCRT64 Release 程序/DLL、相同电源设置和输入哈希；
不并行跑仿真、构建或矩阵回放。显式 OpenBLAS API 固定为 1 并逐服务核验；
STRUMPACK 保留已有 OpenMP 配置核验。其他后端不夸大为已采样内部所有线程池。
关闭昂贵因子统计、矩阵捕获及 gprof，保留相同必要计时和验收输出。

## 3. 先补齐运行入口，再分阶段执行

### P0：运行入口与完整评分准备

当前 `run_templates_ldmos_analysis_reuse.py` 仅接受 2/8 点，固定 D5 且要求同后端
至少两个模式；不能直接追加 `--points 31` 运行本计划。
底层 `run_templates_ldmos_linked_d5.py` 已支持 D5/D4、31 点和两个 worker 模式；
`run_templates_ldmos_isothermal_backends.py` 已有双栅压联合评分，但当前调度
未传递 worker/跨点复用选项。

后续实施应整理一个支持“后端＋线程＋worker 模式”的批次调度入口，复用现有
底层扫压、线程审计、冻结与双栅压联合评分。补充 31 点配置、D4 输入选择、
轮次顺序、失败证据保留及不可变恢复合同测试；先以小网格 worker 测试和已存
结果检查评分/汇总，不为脚本整理重跑整批短曲线。

每轮新建 worker，从该栅压的同一合格零漏压种子重新开始，不从上一轮 40 V
回灌状态或分析对象。保持原步长、外推、重定心、限幅、恢复与精确点截短策略。
物理/构建/输出口径一旦改动，另建批次，不混入同一重复统计。

### P1：D5 六配置完整曲线首轮

- 固定 300 K、原网格 10,241 节点/19,782 三角形、D5 无 IALMob、Auger 不含生成。
- Vg=4/8 V，每档 Vd=0–40 V、31 个精确参考点，保留全部内部推进/失败尝试。
- 先跑 U0/U1/T1 的双栅压（6 条），确认完整曲线与高压跨点复用通过；
  再跑 L1/M1/S1 的双栅压（6 条）。总计 12 条、372 个精确点。
- 第一组 Vg4 顺序 U0→U1→T1，Vg8 反序；第二组 Vg4 为 L1→M1→S1，Vg8 反序。
  记录执行顺序和负载，不根据即时快慢重排。
- 六配置均完成原双栅压联合评分，并以同期 U0 作逐点状态对照。

### P2：重点配置 D5 补齐三轮

U0/U1/T1 预先指定为重复组，首轮合格结果计入三轮，再增加两轮，共增加
12 条完整曲线。重复组总计 18 条，含其他后端首轮的 D5 总量为 **24 条/744 点**。

三轮 Vg4 顺序依次 U0→U1→T1、U1→T1→U0、T1→U0→U1；各轮 Vg8 反序。
各配置各栅压三次测量，报告全部值、中位数、最小/最大值和相对极差。
每轮配对比值单独计算，不能把不同时段各自最快一次拼成加速比。

L1/M1/S1 首轮仅给出筛选结果，不声称重复稳定。若其中有配置更快或明显更稳，
为该配置补齐两轮，并补同期 U1 控制；不要只拿它的一次结果与三轮中位数排名。
此扩展增加曲线数量，须在开始前写明批次安排。

### P3：D4 IALMob 复核（在 D5 结论后开展）

默认保留 U0/U1/T1；如果 D5 证据支持替换候选，则先固定名单并解释选择。
切换到原 D4 IALMob 输入合同，不能继承 D5 曲线资格。

先跑三配置双栅压前 8 点，共 6 条短曲线，检查跨点输入/几何复用及原门限；
通过后各做双栅压完整 31 点三轮，共 **18 条完整曲线/558 点**，采用同样轮换。
只评价入围配置在 D4 的表现，不宣称排除未测后端在 D4 可能更快。

基础方案总量：D5 24 条完整＋D4 18 条完整＋D4 6 条短曲线，合计 48 条、
1,350 个精确输出点。优先交付 D5，D4 可安排为下一批；扩展或补测单独列账。

## 4. 计时、正确性与重复性

主要墙钟沿用昨天口径：从合格零漏压种子检查开始，包含曲线控制器、点服务、
内部恢复、状态读写及运行内验收；不含历史栅压预偏置、输入冻结、额外独立
后审计和双栅压联合汇总。新增阶段耗时单列，避免移动边界制造收益。
这应称为“完整漏压扫压墙钟”，不是从平衡态开始的全流程或 Sentaurus 同条件对比。

CPU 延续既有控制器加点服务记录口径，明确 worker 退出尾部未计入的限制；
不与墙钟相混。采样所有轮次的系统忙碌率和后台 CPU，不要求未知阈值的空载
门槛。记录电源/休眠/人为暂停；这类受中断曲线保留结果但不作为完整连续计时，
从原种子重跑。正常算法恢复成本不能删去，也不能因一次跑得慢就丢弃。

| 维度 | 检查/输出 |
|---|---|
| 电学资格 | 每个接受状态原块残差、逐行闭合和 KCL；31 点电流曲线、Ron、40 V 电流以及双栅压电流比全部执行既有 final 门限 |
| 状态一致性 | 同一栅压 31 点 ψ/fn/fp 对同期 U0 最大绝对差 ≤1e-8 V；同时记录 n/p 差，不私自新增或放宽密度门限 |
| 重复性 | 比较同配置各轮状态、目标序列、逐次 Newton 与回退；差异需定位并披露，不仅比较终态电流 |
| 非线性成本 | 全部 Newton 更新、内部恢复/外层回退、候选与装配次数；分别统计 0–9.333333 V 前缀和后续高压段 |
| 线性成本 | 分析、数值分解、回代的次数/时间及上下文命中/失效；区分纯主系统和混合服务，不把辅助分析计入“主系统只分析一次”主张 |
| 资源 | 墙钟、CPU、求解器进程峰值工作集；STRUMPACK 两线程的 CPU 代价单独体现 |

计时段按已接受偏压进展划分；跨分界的尝试按目标偏压归属，前缀包含零压检查，
内部失败/恢复随其所属尝试计入。整条曲线墙钟以控制器为准，阶段嵌套计时不能
直接相加成总耗时，未归类控制器开销单列。

数值失败立即冻结该配置证据，查明前不继续其重复轮次；其他独立合格配置可继续。
物理或状态检查不通过的配置不能因耗时短入选。三轮只提供初步重复证据，
不承诺统计显著性。只有两档栅压均通过、配对收益方向重复、差距超出观察到的
波动且无新恢复/内存问题，才建议优先配置；波动重叠则报告暂不能区分，必要时
追加完整配对轮次。此为比较决策流程，不变更已有物理验收门限。

仅测 U0/U1 能量化 UMFPACK 跨点复用本身的完整曲线收益。T1 与 U1 的差异
是配置比较；若要独立量化 STRUMPACK 完整曲线复用收益，需另加 T0 普通 worker
的同期配对，不能用昨日短曲线或其他后端 U0 代替。
