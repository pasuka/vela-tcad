# SLOT BVDS补偿掺杂C组29.233 V数值停止分析（2026-10-16）

## 1. 结论

C组（两点外推、最大跨度0.1 V）停止的直接链条已经明确：
Poisson残差停滞使原严格主残差门槛未达标；原停滞接受分支还要求接触多数载流子QF边差不超过5e-11 V。
源端3598–3599电子QF差越过此线，阻止停滞接受。继续缩小外部跨度仍未回到阈值下侧，
8次连续失败后控制器停止。不是磁盘保护、预算耗尽或击穿电流标准触发。

本次为已有记录、HDF5和源码的只读分析，没有新求解、冻结态残差评估或接受动作。
C组未重启，未修改物理、保护或验收阈值；正在运行的六组续算不受修改。

完整Newton最后13次线搜索试探均有限、载流子正性通过，但均不满足充分下降。
最后一步α=1/4096，rho仍为4.0527244883e-9，与当前值相同；目标要求小于约4.0527243894e-9。
三次密度块失败各有20次回溯，全部有限、无depletion或QF裁剪，均未满足其Armijo下降要求。
它们是在已经很小的载流子merit（约1.05e-10～1.36e-10）附近继续打磨失败，不能与人口负值、指数塌缩或线性后端异常混为一谈。

八轮恢复可把载流子残差进一步降至约e-24，却未消除Poisson平台或源端边差超限。
全部活性输运节点的最小电子/空穴浓度，父态约0.76085/0.012807 cm⁻³，最后失败态几乎相同，
不支持把此前IdVd的重复投影和极低人口崩塌解释直接套用到本C组。

[先前不同掺杂状态的Poisson写回审计](slot_ldmos_bvds_poisson_writeback_audit_2026-10-15.md)已有sub-ULP修正丢失的直接证据，
但本次没有对C态重新装配/求解矩阵，也未捕获同一次内存方向写回。故只能说本次平台与既有表示精度问题相符，
尚不能定量断言本C态各项平台贡献均由舍入造成。日志未报告PARDISO分解或线性保护失败，但也不据此宣称所有弱方向已获高相对精度。

失败IV中的电流为占位零值，不能据它与合格父态比较电流变化或校准保护误差。
本次没有生成失败态的完整接触反力新评估，因此也未证明放宽该QF保护对端口或负载线无影响。

## 6. 建议的后续辨别任务

1. 同一合格父态、同一微小目标做热启动/外推配对，保留当前完整资格，判断外推是否参与触发。当前八次均外推，不能归因于外推本身。
2. 在C组保存末态捕获同一次Poisson线性方向、实际packed写回及残差响应，量化表示/求和/线性化的贡献；优先研究相对或补偿电势表示。
3. 对3598–3599边在固定态下导出全部端口分载流子反力、原始源项支撑及负载线，跨阈值做有界扰动，建立接触保护的误差依据；是否调整接受规则应单独确认。

本次不建议仅增加迭代次数、继续机械减半、换线性求解器或直接提高行比门槛。
结论仅限本C组、当前父态链及完整BVDS配置；不声称已完成修复或Sentaurus同偏压定量验证。
