## 1. 结论与统计口径

- 新 IdVd 的主要成本是**每点通常需要六次昂贵的更新**。其反复减半的直接触发是
  首次更新后的固定 `rho > 10` 保护；本批九次都只完成了一次更新，不能称为已经
  观察到长期迭代发散。已保存的 275 次更新均通过线性保护。
- BVDS 的主要成本是**频繁失败的局部恢复、重新求器件态和外电阻确认**。
  恢复标记又使下一步不增长，约 49 mV 的跨度长期保持。
- 两批都因预算结束，不能把最后一点未完成解释为击穿或求解无解。
- 已启动新的 Sentaurus U-2022.12 IdVd/BVDS 冷启动参考，三小时总窗口，包含准备。
  矩阵和物理场导出已经产生；完整路径尚在运行，不提前认定全曲线完成。

## 2. 新 IdVd：减半的直接原因

58次尝试包括47次接受、9次`divergence`、1次超时及1次末尾软截止。
九次`divergence`的跨度为16.4445～18.1649 mV；全部发生在第一次更新后，
`rho=10.9464～13.3838`，触发工具中的固定上限。原始更新误差约2.9e5～4.4e5，
同时有3866～4268个空穴节点触发正性投影，电子侧为0。
这表明首步非线性扰动很大，但未把具体物理项或单个节点归为唯一根因。

控制器只改变漏极接触上的ψ/QF作为热启动种子，内部自由节点仍取上一接受态；
**本批没有两点外推，也没有对实际人口有限步做非线性回溯试探**。
ψ对数阻尼、人口正性处理和线性保护不等于完整的真实残差全局化。
因此不能把这种约17 mV的试探上限理解为器件所必需的物理电压分辨率。
现有数据支持优先检查预测与首次更新，而非再放宽线性保护或更换后端。

PARDISO 使用单线程、保留ψ约束的39149维消元系统；实际更新采用省略输运迁移率
QF梯度直接导数的方向。原系统方向仍用于U和线性质量检查。
275条保存更新含超时尝试的2条进度记录，均通过线性保护；这并不证明未保存的
在途系统也通过。九次首步越限的混合保护值均小于1。

d023是独立的耗时异常：第二次更新原系统“装配与求解”790.42秒，
另一系统35.58秒，整体第二步870.87秒；其rho从7.46658降到0.0324554，
随后外部超时，记录墙钟1268.90秒。不能把这次记为残差发散。
当前计时尚未拆开装配、分解和主机调度，因此不能断言790秒来自PARDISO，
也不能无证据归因于CPU争抢。硬上限检查/进程清理的实际超时也应单列。

## 4. BVDS：恢复成本和增长规则相互作用

累计账本有89次接受尝试，其中86次`recovered=true`。
当前重启目录可枚举500次内部调用记录：334次device、166次confirmation；
该数不包含旧目录保留的早期调用，也不包含每次device里的局部修正/审计子进程。
不能把它当成所有求解器进程的完整数量。
当前目录标量控制器计时合计42238.85秒，中位数463.92秒。

内部事件有84次`device_failed`：79次“bounded correction exhausted”、
2次“density block exhausted backtracking”、3次超时。
外层能在内部恢复后接受，因此这些不是84次整个扫描失败。

冻结控制器的普通自适应分支为：

`next_span = accepted_span * (1 if recovered else growth)`，其中growth=1.4。

最早从25 mV增至35 mV，再至49 mV；随后几乎一直经过恢复，故跨度维持约49 mV。
这是控制器对恢复成本的保守反馈，不是线性精化失败造成的反复外层减半。
该长批次并未启用后来独立验证的BVDS精化开关。

以最后接受尝试a0090为例：

- 标量控制器共6次调用，335.51秒。
- 中间器件试探做满8次局部修正（4次浓度、4次载流子QF），全部未过局部审计。
  修正子调用计时合计约64秒，另有审计、器件重求和文件输出成本。
- 最后一次局部审计：电子超标0行、最大比1.95e-6；空穴仍超标705行，最大比1.72325。
- 例如5525行：通量−3.00712e-17、复合/产生项−4.15780e-17，
  电离−2.77e-32，残差−7.16492e-17（均为该诊断内部口径）。
  此处困难主要表现为弱空穴输运与复合/产生未平衡，不能归因于强雪崩。
- 后续器件态及负载线确认通过，最终电路残差约−1.80e-7 V，保留原1e-6 V条件。

优先工作是：在同一父态对已反复失败的首个内部试探做预测/恢复顺序对照，
并量化多次审计的必要性；在保留器件及负载线最终复验的前提下，再验证让
“成功恢复后的平稳点”适度增步。不能直接跳过705条空穴坏行或删掉外电阻证明。
