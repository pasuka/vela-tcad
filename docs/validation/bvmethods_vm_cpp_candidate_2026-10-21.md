# BVmethods VM 私有 C++ 候选：编译与接入状态

本轮接续[单元迁移率诊断](bvmethods_vm_transport_2026-10-21.md)，目标是把自主 Si 支撑、
单元 Masetti／Lombardi 取样和接触邻近电势高场接入实际残差、端口及导数。
**晚间重连后最终修复版编译成功，十五次对照、五次重复及两次源项控制正常退出。
端口值显著改善，但完整 RHS／全部导数未通过。以下先保留日间失败过程，最新结果见末节。**

## 已核实

- 使用独立源快照和私有 overlay，Linux GCC 16、Eigen 5；配置实际检测到 HDF5／HighFive、
  SuiteSparse UMFPACK 和 METIS。本轮为固定态装配检查，没有执行 Newton 线性求解或完整 QS。
- 沿用封存的 2600 节点网格、300 K、五个非零原生接受态人口及固定内压投影，保留既有
  材料／统计／热电压映射。Fermi、OldSlotboom、SRH 和雪崩保持开启，BTBT 关闭。
- 基线及仅 Si 几何控制各五态正常退出。Linux 基线漏极电流与 T470p 封存值相对差约
  1e-15，未发现平台迁移导致的可见端量偏差。电流单位为 A/um，负载核对使用明确的 drain。
- 端口值来自接触连续性残差求和，端口梯度来自相应 Jacobian 行求和。私有迁移率反馈
  接入相邻单元顶点的电势及准费米势列，保留守恒行符号与原有缩放。

## 接入失败与修复

1. 首版被只允许 PhuMob 的配置守卫拒绝；仅在私有副本中允许 Masetti 候选。

3. 再次编译通过，阶段日志确认装配账本入口已完成；进入 Jv 后，雪崩 Jacobian 内部调用仍
   缺完整 QF 状态，被新增检查拒绝。本轮没有得到可用候选 Jv 或候选五态通过结果。
4. 最新私有修复补入局部扰动态的 QF 向量，覆盖雪崩边电流重建与直接源求值。该版本仍待
   编译及运行验证，不能以代码检查替代数值证据。
