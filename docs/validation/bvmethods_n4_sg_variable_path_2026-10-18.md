有效系数保持不变的三档SG原语方向检查通过；谱增量也已从固定reference率推广为变化路径下的逐状态独立求值。

## 1. SG保精度增量和原语Jacobian

沿实际装配采集9070个唯一边项的a、主人口、DOS、Bernoulli因子、系数与通量，
对10条粗档电子行和2156／2515等共15条目标行拆分增量。
以80位十进制数实现数学SG原语：

`F = coefficient × reference × [n0 B(-a) − n1 B(a)]`。

通量使用对数驱动与expm1避免两个大乘积相减，提供两状态增量和对a、n0、n1、coefficient的解析偏导。
显式链式组合接口要求调用方传入操作数对状态的导数，不把系数视为天然常量。
8个Catch2用例66个断言覆盖边反向守恒、Bernoulli恒等式、平衡、近零人口增量、
四操作数Jacobian及含变化系数的状态组合，均通过；方向检查采用三档步长和原1e-5预算。

实际增量另按人口、Bernoulli变化、系数变化、乘积舍入、减法舍入及外层舍入拆分，
最大分项闭合差约2.124e-67。
该分解保留实际普通精度输入，独立数学原语则使用数学Bernoulli函数；两者角色分开，不能当作逐位相同算法。

## 2. 10条粗档差异确实跨越迁移率分支

对粗档与最小档的变化做两种冻结对照：冻结Bernoulli因子仍保留主要差异；
冻结实际迁移率系数后，差异缩小约3.6至5.4个数量级。
例如节点1760的输运FD粗细差约58.345，冻结系数后约0.000963；
节点2237相应约114.781与−0.004463。
冻结只用于分项归因，没有将冻结迁移率当成新资格配置。

继续采集每态8312个单元／载流子迁移率记录，包括低场值、高场驱动力、截断分支和局部导数。
三态低场迁移率逐值不变；10条目标行的相邻单元均存在跨分支，
每行有1至4个单元从基准低于1 V/cm进入扰动态的高场分支，部分在正负两侧均进入。
例如1760的基准驱动力为截断值的0.354至0.604倍，扰动态最高约1.768倍；
2237的基准约0.00118至0.00161倍，扰动态最高约2.413倍。

这解释了为何系数正负变化的平均值会移动，继而放大人口导数项。
跨分支中央差分不能直接检验基准点的分支局部Jacobian，不能继续将这10条粗档差异一概归为错误导数。
上述分支记录来自当前Vela候选；本轮没有直接证明商用原生具有完全相同的内部截断规则。

## 3. 系数不变时，三档SG原语方向通过

补充h=3e-5，结合h=3e-4、1e-4；目标行相邻边的有效系数在正、负两态均与基准逐值相同。
对实际操作数割线使用自主解析原语Jacobian，与独立保精度原语差分比较：

| 步长 | 10条目标行最大对称相对差 |
| --- | --- |
| 3e-4 | 9.532e-14 |
| 1e-4 | 8.356e-14 |
| 3e-5 | 4.383e-14 |

三档满足原1e-5门，人口、完整源身份和守恒检查也通过。
这里使用的是实际a、人口和系数的操作数割线，不是已完成Γ、迁移率等链式装配的主变量Jv。
它证明原语偏导及组合机制一致，不能替代完整增广Jacobian验收。

## 4. 谱原语已支持逐状态变化路径

不再使用某个基准事件率乘占据增量的固定几何公式。
每个当前状态重新读取实际转折位置、带状态、前因子、两段WKB作用量、横向窗口、积分宽度及端点权重，
独立以80位精度求谱值，再按当前区间和两端Cartesian事件散射双源。
没有要求新旧事件一一匹配，也没有拟合原生源比例。

8态中7态的路径距离或空间支撑权重实际发生变化，带状态也改变；
粗档收集事件33→32的变化被保留，各态Cartesian事件数与普通精度实际账本一致。
独立保精度源与本候选普通精度源的最大加权L1差约4.168e-15，
按绝对成对事件量计算的最大守恒差约2.464e-17。
较小三档的逐行方向收敛差，电子最大约2.535e-7、空穴约1.162e-6，均满足原1e-5门。
筛选源始终被完整装配覆盖门拒绝；这不是新增原生完整RHS或全域源验收。

谱原语同时实现9个操作数的解析偏导，5项性质测试含三档独立差分、热平衡响应、占据符号和输入拒绝，均通过。
几何、转折点及内层WKB操作数仍来自binary64计算；其对主变量的全部导数、递归分段与收集事件边界导数尚未接齐。
因此独立逐状态求值已经摆脱固定reference率，完整路径Jacobian仍未取得资格。

该纯算术性质检查改用1e-70，远严于工程门，未修改源／残差／方向验收预算。
本轮本地求值均已结束，没有新增远端作业。
原始商业数据、操作数、私有代码及构建记录仅存于ignored `build-release/bvmethods_n4_sg_variable_path_20261018/`。

剩余前置项是完整主变量依赖链：Γ／材料统计、迁移率驱动力、变化路径的转折点／WKB／积分收集，以及增广负载和稀疏支撑的散射。
下一项应将这些链式项接入自主Jacobian，保留分支局部和事件单侧控制；
完整残差、Jv及线性方向通过后，才进入真实Newton投影／线搜索接受循环。
