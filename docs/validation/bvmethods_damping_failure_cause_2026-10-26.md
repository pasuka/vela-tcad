# BVMethods：Sentaurus 阻尼配置对齐与扫描失败归因

日期：2026-10-26。代码与前轮工作均在 `codex/sdevice-cmd-frontend` 工作树保留。

本轮将 BVMethods CMD 负载线阶段的隐式默认改为与本例 Sentaurus 相同的
无阻尼完整步。自主 Release 扫描仍停在相同检查点。新增的同态分解确认：
多伏空穴方向主要用于修正上一个已接受态遗留的空穴方程残差，外压增量不是
主因；AV 源残差在弱空穴系统中的投影很强，但去掉 AV Jacobian 不能消除大方向。

## 阻尼配置

本例原生日志为 `LineSearchDamping=1`、`NotDamped=100`、`Iterations=20`。
本轮 Vela 预算仍为既有的 40 轮，低于 100，因此两者本例都不启动线搜索或
Bank–Rose 阻尼。Poisson 的 7 次实际更新也均为完整步。

- 新增 `coupled_line_search_mode="full_step"`：只评估并使用 α=1；
  不执行 `report_only` 的影子回溯。无效完整候选直接失败，由既有外层缩步重试。
- CMD 解析器读取 Math 和局部 Coupled 的 `LineSearchDamping`、`NotDamped`，
  局部设置优先；BVMethods CMD profile 在无显式诊断覆盖时选择 `full_step`。
- profile 对启用原生线搜索或可能触发 Bank–Rose 的设置明确拒绝，
  因为尚未实现原生算法，不能用 Vela 的 merit 回溯冒充。
- 显式 sidecar 仍可选择诊断模式；全局 C++ 默认、PN2D 数值配置保持原值。
  原生 RHS／更新量停止规则仍未全部复现，本轮只对齐阻尼是否启用。

全局及少子 QF 固定上限均为 0。独立的内压更新上限 0.1 V 保留；
所有实际写回均未触发该上限，末次无效候选的保护不构成接受态。
原器件残差 1e-8、负载线 1e-6 V、KCL 验收和行／全局闭合的 report 模式均保留。

手册依据为 T-2022.03 第 195–196 页，以及
[Synopsys 培训材料镜像](https://ghzphy.github.io/Sentaurus_Training/sd/sd_6.html)。
本轮没有新运行 Sentaurus；原生日志沿用前轮显式 PARDISO 运行。

## 同检查点分解

从末态自身 HDF5 的 ψ/fn/fp 重新打包，三种算子的 packed state 逐位一致。
诊断删项仅用于归因，不是物理模型修复或完整 BV 资格。

固定完整 Jacobian，把 RHS 按方程块拆开分别求解，在节点 152 得到：

| RHS 来源 | δfp152（V） |
|---|---:|
| Poisson | −1.31195e-9 |
| 电子连续性 | +7.55279e-5 |
| 空穴连续性 | −3.402544195 |
| 外接电阻负载行 | −0.002770822 |
| 完整方向 | −3.405239490 |

因此外压缩到 10 μV，主要的残差修正方向仍然存在。独立 SciPy/SuperLU
方向与 PARDISO 最大相差 5.41e-9 V；PARDISO 分量后向误差约 2.25e-16。
这些证据不支持把问题归结为线性求解器没有解准给定方程。

固定完整 Jacobian，按残差物理来源分解：AV 项对 δfp152 贡献约
−4.120337973 V，SRH 为 +0.002220697 V，输运／Poisson／负载合计
+0.712877787 V。保持完整 RHS、仅移除 AV Jacobian 后，δfp152 反而为
−3.934720587 V；因此直接关闭 `AvalDerivatives` 不能修复当前问题。
同时移除 AV 源和 AV Jacobian 的诊断模型约为 −0.135201509 V，
仍不是微小修正。仅保留输运的诊断模型约为 −0.135005263 V。

## 弱行尺度与有限更新

在物理电压坐标、Jacobian 对角行归一化下，完整系统一范数条件数估计
约 1.71e19；这个量依赖坐标与缩放，不能单独作为失败根因或误差上界。
固定其他变量的空穴子块条件数估计为 2.25e6，无 AV 时仍约 2.12e6。

节点 321 的空穴 RHS 仅 2.58735134e-12，低于现有绝对残差门，
但 `abs(RHS/Jii)*V0` 为 0.466621 V。它是行尺度诊断量，**不是实际场误差**。
实际完整 Newton 方向的空穴最大值为 3.405239 V。
相应的空穴残差在节点 308、144、311、307 等行对该方向有很大的有符号贡献并抵消；
不能把节点 152 当作唯一出错的源节点。

完整候选的线性预测残差约 7.60e-12，真实残差却为 15573.8575；
下一轮出现约 4.65e9 V 的原始空穴方向，候选无效。
此前同态细小扰动的 Jv 对照已在约 1 μV 尺度降至 1.25e-8 相对差，
说明有限完整步失效不能直接等同于局部导数公式错误。

本例使用 QF 坐标；节点 152 的 dilute 极限相对人口线性增量约为 −131.72。
线性人口候选为负，而完整 QF 更新通过统计正函数重建人口，已经远离
线性近似范围。这是坐标变换的诊断，不是 Sentaurus 在该状态的实跑结果。
末接受态的最小正空穴浓度约 3.63 cm⁻³，本轮没有复现前次接受态浓度下溢。

已经证实的失败链是：绝对残差准则允许接受仍有大弱空穴修正的状态；
下一偏压点主要在修正该遗留残差；AV 源与弱输运块的投影产生多伏方向；
有限 QF 完整更新导致强非线性残差增长并最终越出模型域。
尚未证明 AV 源公式有误，也没有完整复现原生 RHS 归一化、人口坐标有限更新
及状态接受过程，因此仍不能解释为所有原生一致性问题都已闭合。

后续应在相同检查点比较原生人口坐标方向与有限更新，核对弱空穴行的
残差／更新量尺度和 GradQF AV 源，而不是恢复固定 QF 限幅、删掉 AV
或放宽停止门。对判据的任何修订都需另行建立与原生可比较的契约并回归。
