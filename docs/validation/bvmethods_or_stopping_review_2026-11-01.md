# BVMethods：OR停止与历史AND轨迹复核（2026-11-01）

## 结果与范围

已在vela VM独立执行同一二进制的A严格暖态复验。Full+AND耗尽40轮；只将主停止组合改为OR后，Full于3轮接受，原负载线强制门和KCL均通过。初始packed状态与初始RHS的SHA完全相同，Full两次运行从第0至第3轮入口的外压、F、L和各分块更新误差逐字一致。故这个具体失败可以由停止规则差异直接解释，不需要先假设Jacobian或线性解错误。

本轮是暖态隔离与历史数据反事实分析，不是OR完整BV资格。原P1/G2八小时AND扫描继续使用原二进制、配置与时限，未改动或重启。核心已支持两种模式，本轮复用既有开关，不修改全局默认值，不将报告型守恒指标提升或降低为强制门。

## 控制契约与复现

```json

      "coupled_update_convergence": {"mode": "enforce"},
```

`enforce`为OR；`enforce_joint`为AND。残差分支包括设备及电路：F≤1e-8且|L|≤1e-6 V；更新分支要求本次solve实际应用过更新、报告有效且RMS<1。独立负载线enforce及其他强制门仍须满足。候选RMS不是已经应用的更新报告；被拒候选不得当作收敛。目标变化后若完整耦合残差通过，OR可以零更新接受；这与旧C组忽略电路残差、带着巨大负载线误差接受的缺陷不同。

新增工具只复制配置并改变主停止mode，不触碰源配置、物理或其他门：

轨迹分析工具按solve/目标/步长/retry及迭代回退分组；同轮bootstrap/Full复核不会误计为两个solve。工具只判断标量分支资格，不凭不完整CSV宣称全部物理门通过，也不将AND下后续状态拼成新的OR轨迹。

此表统一在标量分析中要求|L|≤1e-6 V，B原始report属性不被改写为原本的强制门。非零点的AND资格要求有效更新RMS；零偏锚点单列。当前逐轮CSV通常不含所有独立物理门，资格须由真实复验确认。35条旧目标有OR资格并不表示新OR扫描会接受35点或完成BV：第一次停止差异就会改变后续外推、Jacobian、步长反馈与目标。

最重要的三条线索：

1. 旧AND末次目标0.855906175147395 V，第1轮已经F=5.30810664488e-9、L=-3.54214401144e-8 V，OR残差分支可通过；当时RMS=170.55。继续AND迭代后最终F在1e-8附近、RMS约0.691而失败。这说明第一次可能分叉远早于末轮，不能只拿末轮RMS推导新轨迹。27次较早资格中26次首次由残差分支触发、1次由更新分支触发。
2. P0 W4 Full与自动+复核各29/33次尝试具备更早的OR标量资格，全部先走残差分支；其中16次在新目标第0轮。对有AND终点的同轨迹记录，更新轮次差合计38。OR可能省去校正工作，但不能把38次直接当作新OR运行节省值。规定目标表造成的33点数量也不会仅因换OR自动消失。
3. 历史实际OR A组仍失败，说明AND不是全部故障的唯一原因。候选报告失效、坏bootstrap方向、模型复核及全局化问题仍需分别核验。小于1的候选RMS而未实际应用的行，旧A/B分别有10/30行，不得计为可接受更新。

## 对此前结论的修正

P0中“G2对A严格暖态有经验性净收益”成立于AND判据；它不足以证明在OR下bootstrap对A仍然必要。本轮Full+OR已提供相反的直接线索：在相同状态与真实RHS下，Full仅3轮就满足OR及其他原强制门。

同时，automatic+OR在RMS约1083时因残差通过而接受，说明OR不仅缓解F略超门的停滞，也可能明显提前结束人口校正。Vela的设备无穷范数及1e-8阈值未等价于Sentaurus的原生RHS范数/尺度；换逻辑不能自动获得与原生一致的停止精度。下一轮应将Full+OR和自动+复核+OR作为同主机、同物理、同入口对照，以完整轨迹、强制门、终态空间量和成本取得资格，保留当前AND基线。不能以这一个暖态宣布删除bootstrap或OR全程已通过。
