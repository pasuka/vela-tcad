# 首帧六个空穴连续性行差异：分析交接材料

数据整理日期：2026-11-04。全部来自已结束、已核验的冻结证据；本轮仅离线整理。

## 1. 问题定义

比较的是Sentaurus U-2022.12导出的首个耦合Newton帧p01_i01，与Vela在同一物理状态重新装配的Full Jacobian。该帧外压目标0.01V，pre内压约为0V；**不是纯Poisson矩阵，也不是0.01V已接受态**。下一轮同一目标的p01_i02作为负对照。全扫T-2022.03-SP2参考与这些U-2022.12冻结帧不是同一版本数据。

算例2600节点、5020三角形，300K，电势/电子浓度/空穴浓度与内压耦合；JD统计、OldSlotboom、总杂质迁移率/Lombardi/Canali、SRH、GradQF AV、BTBT关闭，R=1e7 Ω·µm。Vela使用sentaurus_u2022_12常数。人口下限1e-100；这些节点人口远高于下限。设备packed行0..2599为psi、2600..5199为n、5200..7799为p，内压为7800。节点和行编号均从0计。

## 2. 节点与几何

## 5. 已做对照与能支持的判断

250位AV非线性核，保正相对人口扰动1e-12、1e-20、1e-32、1e-48，逐局部支持列检查，固定生产圆整QF锚时AD/FD加权误差约8e-16..1.2e-15，未见非零列符号冲突。它认证这些AV局部切线对自身算术合同的导数一致性，**不是整个Jacobian、完整输运原语或所有微小分量自然相对误差认证**。

高精度从psi/n/p重建QF，QF仅移动约1.82e-16V，首帧AV切线却改变0.2144%..0.8795%。但相对native整体J差仍为1.53999449753e-3，未消除异常。不能把“存在浮点敏感性”写成“根因已经找到”。

## 6. 仍未知的部分和建议给分析模型的问题

- Sentaurus在接近零的恢复电流、范数方向与非光滑零点采用何种内部切线约定，尚未唯一辨识。数学norm在零点无唯一普通导数，Vela采用零广义切线；不能据此推断native实现。
- 两个界面节点的法向场/距离梯度、邻域场重建是否与四个Si内部点构成不同机制？目前只有几何事实，没有因果资格。
- 原生与Vela的AV电流恢复、驱动力/接触相邻单元替换及Fermi-SG语义是否完全一致，仍待核实。
- 小|ln(cj/ci)|的广义Einstein g相消是另一待查风险；本AV检查没有给完整输运链授予资格，实际边分布尚未知。
- 为什么首帧近似反向的AV行差会在下一轮消失？请提出能同时解释首帧与下一轮、镜像配对及界面/内部差别的可证伪假设；不要只对单帧拟合符号。
- 未证明这六行导致后续0.599873/0.944708V的线性门拒绝；不能从局部矩阵差直接跳到完整扫描失败因果。

建议分析时明确区分：数学模型不同、离散/恢复方式不同、近零范数切线约定、浮点QF舍入、装配映射/单位，以及真正的链式求导错误。使用逐列CSV与两个迭代的原始行共同检验，勿仅比较一个整体范数。
