# BVmethods N4：原生单元射线、双源收集与 RHS1 绑定

日期：2026-10-16。继续用户授权的 N4 差异定位；目标仍为安装库原版。
本轮确认了**单元重心射线与顶点起点候选之间的离散差异**，进一步分离源收集、窗口与表示问题。
N4 保持进行中，未取得原生双源、完整 RHS 或 N5 导数资格；生产 C++、材料、前端接受范围和预算均未改。
前序实现与原生源误差见[N4 报告](bvmethods_nonlocalpath_n4_2026-10-16.md)，
本轮关键值、输入散列及退出码见[机读摘要](bvmethods_nonlocalpath_n4_collection_2026-10-16.json)。

## 同态控制与观察器身份

Sentaurus T-2022.03-SP2，普通 double 路径；均匀场为 300K、12V、210节点／340三角形，
原版末接受态为 2600节点／5020三角形，其中4156个 Si 单元。
原版使用被冻结的 NonLocalPath／GradQuasiFermi 输入，Load 仅用于固定状态诊断，不能作为从零纯 QS 验收。
均匀场另设 400K 的独立积分对照及 MaxTunnelLength=15nm 控制；原控制为100nm。

先 Load、再 Plot、随后 `Coupled(Iterations=1)` 与 `sdevice -d`，保存更新前场量及首轮系统。
BTBT 开／关臂的全部打印变量一致：均匀场606变量，原版6853变量；包括非载流子／负载变量。
只读采集臂与无采集开启臂的名字、变量、RHS1、RHS2、Jacobian、Newton 更新均在打印精度内完全一致。
均匀场检查51个导出数组，原版82个，均一致。这个控制不证明未导出内部量逐位一致。

采集 v2 的均匀场、15nm控制及原版三个运行均退出0，采集器无错误。
开／关臂中原版关闭臂退出2：仅允许一次 Newton 更新而未收敛，但更新前场量和完整 RHS1 已输出，
可用于固定状态源隔离，不能报告为自洽求解通过。初轮采集曾有一个向量参数解释错误；
保留该失败记录，源分配结论使用修正后、无错误且身份复核通过的 v2。

原始商用输出、版本特定只读适配器、作业路径／进程记录均留在 ignored
`build-release/bvmethods_nonlocalpath_n4_collection_20261016/`。
两轮归档分别校验102及61个文件；公开工具只接收已解释的数学数据，不包含原生地址或二进制布局。

## 路径起点及单位

原生均匀场对340个三角形分别计算路径；原版调用4156次，本轮选定9个 Si 单元保留逐单元详情。
340条均匀场路径及9条原版选定路径的几何检查均可独立重放：

| 检查 | 均匀场最大误差 | 原版选定单元最大误差 |
| --- | ---: | ---: |
| 射线零点至三角形重心／单元直径 | 7.55e-15 | 1.02e-14 |
| 射线向量与独立 P1 价带梯度的相对差 | 2.26e-14 | 1.43e-12 |
| 直线路径偏离／单元直径 | 8.85e-15 | 1.02e-14 |
| 弧长与独立长度单位的差／单元直径 | 6.44e-15 | 2.11e-14 |

均匀场有75处不同单元保留同一边界点，弧长相等且坐标一致；审计允许这类表示重复，
拒绝零弧长空间跳变或逆行。重心是**几何射线锚点**，不等于只在重心计算一次源。
当前 Vela 私有候选仍按每个 Si 顶点发起路径，不能将它称为原生同离散。

浓度单位从真实人口／打印密度单独求得 `C0=1.4824351e10 cm^-3`，未用源率拟合。
两载流子在全部非零样本上的归一化相对散布低于 `6e-15`。
2022手册物理常数表的 `epsilon0=8.8542e-14 F/cm`，结合显式2022常数、Si介电常数11.9与300K，得到：

`Vt=kB*T/q`，`L0=sqrt(epsilonSi*Vt/(q*C0))=3.386492002144132e-5 m`（公式统一SI）。

独立检验射线向量为 `-grad(Ev_J)/q * L0/Vt`。
100nm与15nm控制的长度参数分别为0.002952908199301394、0.0004429362298952091，比例0.15；
两控制的路径、收集与源场一致，说明本控制的有效支撑未受这次长度截断影响，不能推广到其他状态。
本轮没有修改 Vela 的全局常数。

## 逐单元双源收集

均匀场记录340次单元源更新，其中315次非零；以同一 Si 盒面积计算每次更新前后的源积分。
空穴源只落在起始三角形内：310次涉及3个顶点，5次涉及2个顶点。
电子源位于下游，涉及2–5个节点：3节点275次、4节点10次、5节点10次、2节点20次。
逐单元两端加权守恒最大差为 `1.553e-14`；原版3个选定非零单元为 `8.65e-16`。
这是原生采集增量账本的闭合，不能替代 Vela 全路径能力门。

分配不是固定三等分，也不是单元 Voronoi 角点面积直接分配。
例如均匀场单元1，按节点0／1／202排序的空穴权重为
`0.3333333333333333 / 0.3352624708432124 / 0.3314041958234543`；
原版源峰值邻近单元979为 `0.4037441388195477 / 0.2737709290844859 / 0.3224849320959663`。
因此，顶点率乘盒面积、单一重心率及单一终点投影均不足以代表原生双源。

捕获的两组节点数组分别与空穴／电子导出源场相符。
显式采用 `L0_cm^2/(C0*Dref)`、`Dref=1 cm^2/s` 的表示转换假设，
两端盒加权差约 `3.6e-16`；该转换由人口／电势单位构造，没有以源率求比例。
原版最后一次选定更新后的全数组也与导出场匹配，但完整逐单元增量仅在均匀场采齐。

两个 N2 未决节点1287、2567相邻的六个 Si 单元571、2655、2667、2722、4682、4683，
本末态各自的双源增量均为零。其余七个被选网格单元不是 Si，未进入此 Si 路径计算。
此结果仅排除**本状态这些起始单元**的非零源贡献，不排除其他路径向角点投影、其他状态贡献，
也未解决 Vela 两处几何歧义；不得据此将所有未决路径静默归零。

## 独立积分假设及仍存差异

固定物理常数、输入带边／QF和几何，不使用原生源调整系数，比较300K空穴总源：

| 独立控制 | 总源有符号相对误差 |
| --- | ---: |
| 每单元重心一次取样 | +3.16363e-3 |
| 顶点梯形取样 | -1.78626e-2 |
| 连续二维单元积分 | -1.23616e-3 |
| 沿重心射线的单元内弦平均积分 | -9.69478e-6 |

最后一项由几何独立求弦，积分截在带边允许范围内，再按三角形面积换算，
不利用采集到的源反推窗口。24阶／48阶结果一致，但仍未过总源 `1e-6` 门。
按射线上起点的 P1 权重分配后，逐单元逐顶点加权L1差为 `7.13184e-4`，
最大归一化权重差 `1.59083e-2`；提高普通求积阶数无法消除。
连续二维 P1 投影的对应差为 `2.24778e-3`，同样不闭合。
这些结果把重点收缩到**沿射线的能量窗口、实际求积／源收集及两端投影**；
尚未证明某种自主规则完全等价，也没有以经验偏移或源比例补偿。

## 原生源场与 RHS1

同态关闭差按 `Delta RHS1 = G[cm^-3 s^-1] * area[cm^2] / C0[cm^-3]` 核对，
两端均为正号，不乘电荷q；全部自由载流子行与非载流子行均纳入检查。

| 状态 | 电子源隔离L1相对差 | 空穴源隔离L1相对差 |
| --- | ---: | ---: |
| 300K均匀场 | 4.03267e-8 | 1.42272e-15 |
| 原版末态 | 9.59578e-9 | 8.28648e-10 |

非载流子 RHS1 行无变化。此表分母仅为绝对源和，**不是**冻结完整 RHS 的绝对装配项和；
打印精度和强输运项抵消仍需单列，不能把均匀场电子差直接解释为新的物理失败，
也不能将原版源隔离近似闭合称为 Vela 完整 RHS 通过。
