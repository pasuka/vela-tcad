# 四方程自热装配结构复用验证

已完成分阶段验证，四方程入口的 `reuse_jacobian_structure` 已默认开启，
显式 `false` 可关闭。原电学、热学与状态门限不变；性能改善小，详见三轮原始结果。

## 范围与冻结条件

候选阶段在 `codex/templates-ldmos-phase-a` 的 `286f5a2d` 上实现默认关闭的
`reuse_jacobian_structure`。C560 执行 Linux Debug 回归；T470p 执行
UCRT64 Release 回归和串行算例对照。沿用 R11 D0 的原网格、SI 单位、
物理模型、UMFPACK、原电学与热学门限；求解器/BLAS 均为 1/1 线程。
不调整 Newton、预测、步长或接触物理。

## 实现

- 四方程与热传导独立保存零值稀疏模板，散布位置每次按行列核对。
- 耦合结构按拓扑及 IALMob 支持单元预留，包括当前恰为零的耦合；
  不是复制首个状态的数值非零元。
- 每次装配独立复制零模板并填值，不共享结果矩阵；只残差请求不触发
  耦合矩阵准备。热传导保持原残差路径，复用其子矩阵模板。
- 四方程结构键包含完整几何/拓扑、支持邻域及约束行布局，固定温度值
  和待求温度变化不重建；改变接触行类型、结构或准备输入时重建。
- 同一扫压上下文跨点复用；明确关闭后释放共享引用，重新启动或恢复进程
  从空缓存开始。符号分析和数值分解继续沿用既有独立逻辑。

## 验证顺序

1. 装配与入口测试：全耦合偏导有限差分；温度和零导数变化；边界与几何
   失效；结果矩阵所有权；跨对象复用；缺省关闭、显式开启/关闭、失败及恢复。
2. 真实代表点：双栅压低/中/高偏压；固定 300 K 和自热各自原门限；
   相同初态开关配对，HDF5 保存后冷读恢复。
3. 双栅压前八精确点开关对照，然后完整 62 点及原生 D0 联合验收。
4. 三轮交错串行完整曲线开关配对，共 12 条曲线/372 点；计时包括
   初始化与整个进程。统计中的装配/更新计数单列漏压推进，不与初始化混合。
5. 只有正确性、稳定性和整体性能支持时才默认化；不继承经典 DC 的加速比例。

执行脚本：`scripts/run_templates_ldmos_thermal_structure.py`，通过
`--stage points|short|full|repeats` 明确选择阶段。`--prior` 是既有 HDF5
资格证据根目录（包含 `final_curves/d0`、`cold300_electrical`、`d0_native`）；
`--runner` 指定本轮 Release 程序，`--output` 必须为新目录。
每阶段失败即停止，不更改历史证据或放宽门限。

证据目录：两台主机各自的 `electrothermal_structure_20260924` 独立目录；
本地行政证据位于 `build/electrothermal_structure_20260924`。
以下按阶段记录冻结候选和最终默认路径的独立资格；不改写历史控制结果。

## 三轮交错串行重复与局部场审计

372 精确点；每轮反转开关顺序，全部从中性状态重新初始化。
6 组原生电学/热学联合验收、186 组开关对照及 248 组跨轮对照全部通过。
同配置跨轮 248 组五类状态数组逐元素数值完全相同；开关最大参考表示差 `1.547e-10`。

Vg8 为 192.760 → 192.667 s。不是显著提速，也不是每一组都加速：
第三轮 Vg8 开启 203.561 s、关闭 202.185 s，开启慢 0.680%。
该轮两者均较前两轮慢，CPU 时间也增长；采样时未见明显竞争计算任务，
不能仅凭此采样确定波动原因，原数据全部保留，不剔除慢样本。

完整 Jacobian 装配均值减少 5.758% / 3.035%，但数值分解相关计时增加
3.657% / 3.651%，抵消了部分收益。该分解计时包含原有符号分析。
Vg8 40 V 代表点矩阵存储位置从 567378 增至 609548（约 +7.43%），
包含潜在耦合的结构零值；此项会影响排序/填充，不能把分解计时变化完全归因于某一个算法。

开启峰值工作集为 653.3–655.9 MB（十进制）；关闭多数为 640.1–641.1 MB，
另有一条为 285.3 MB。记录的是 Windows PeakWorkingSetSize，保留该离群值，
不以简单平均宣称稳定内存比例。

`silicon_thermal_probe` 重新求物性，结果另存 HDF5。这是开关实现对照，

数值正确性与重复性通过，整体计时为小幅改善。按授权继续验证默认开启路径，
