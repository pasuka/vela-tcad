# SLOT 接触保护与参考态相对人口逆映射验证 2026年10月10日

## 结论

相对人口→QF 恢复的零改动恒等性、接触保护及非零增量精度已通过本批检查，但它没有使原生人口匹配态通过 Vela 完整资格。
相较保持接触的绝对逆映射，电子失败行由 143 增至 358，空穴由 4986 降至 4922；电子/空穴闭合仍通过。新增电子坏行主要在多晶硅及其界面。
更准确地保存微小 QF 增量不等于改善局部输运平衡。本方法可作为待进一步验证的恢复组件，不能据此替换生产流程或启动长扫描。

本批使用上一批相同的独立兼容 runner、材料及未合格原生最终 QF 态：

- runner：`build/s10four_stage/compat_source/build-release/vela_example_runner.exe`；材料 `build/s10four_stage/compat_materials.json`。
- 父态：`build/s10qualification_direction/native_final_qf.h5`；SLOT 13,881 节点、27,275 三角形，Vg=5 V、Vd=0.006 V、300 K、原点 0 V。
- AverageBox 实际 Poisson/电荷体积、定义积分 Fermi、Bennett–Wilson、PhuMob/Lombardi/HFS、SRH/Auger、电离及接触回退、effective_band_sg 不变。版本身份沿用 T-2022.03-SP2 / 定义积分 PMI 兼容配置。
- UCRT64 GCC 16.2 Release；原 runner binary64 主状态及既有局部长精度计算不变，UMFPACK/HDF5 已在该冻结构建中启用。VT=0.025851995266484913 V。
- abstol=1e-9、reltol=1e-8、eps_row=.001、scale_floor=1e-30、闭合比 .01 及原接触/QF 条件保持。没有新的 Newton 接受更新或新增合格点。
- 只改变有效自由载流子行；网格接触集合另加显式禁止修改掩码。ψ、DOS、材料、本构输入保持固定。此验证不覆盖 ψ 同时变化的联动更新。
- H5 人口为 m^-3，分项 CSV 人口为内部 cm^-3；位置 µm。下表 Poisson 为自由行 L2，闭合采用原冻结残差泛函，不能当成新的 SG IV 合格解。

## 相对恢复公式

设参考态实际重建人口为 n0，目标为 nt，z0=n0/Nc，η0=F_half^{-1}(z0)。直接计算相对人口变化 r=(nt−n0)/n0，并在增量坐标中求解：

`∫[0, Δη] F_half′(η0+s) ds = z0 · r`

电子 `Δφn = −VT·Δη`；空穴用 p/Nv 且 `Δφp = +VT·Δη`。增量加到父态已有 inc，ref 保持不变。零 r 精确返回零，不对非零小 r 设置忽略阈值。
积分使用同一冻结 Fermi 实现的导数、分段八点 Gauss 积分；求根采用括区与 Newton 组合。它避免相减两个绝对 QF，也避免用绝对人口容差把小变化提前判零。η0 的已有数值逆函数近似仍存在，不能宣称是全精度的解析逆映射。
本次实现仅在新目录的独立诊断辅助程序 `relative.cpp` 中，未改生产源码、CMake 默认或运行配置。所有端到端结果仍通过原 runner 冻结评估。

## 验证结果

### 零改动与非零恢复

- 标量 121 项检查通过。涵盖 η 从 −100 至100、正负1e-12及1e-6相对人口变化、±50%变化、已知有限 Δη 的恢复；最大已知 Δη 恢复误差 2.33702e-14。
- 同一参考人口作为目标时，全部 H5 物理字段逐值不变，载流子分项 CSV 全列与基线逐值一致，目标人口误差为零。
- 所有接触的 QF 绝对字段、ref 和 inc 逐值保持原态。
- 非零制造解：在自由行施加 ±10 µV 内的已知 QF 图样，再用原 runner 正向计算人口作为目标。恢复电子/空穴增量的最大误差为 3.130397e-16 / 3.082471e-16 V。
  恢复后人口最大相对误差为 1.421085e-14 / 7.549517e-15。该制造态仅检验映射，Poisson 残差约4.09，绝非自洽或合格器件态。

## 新增坏行与低位增量

相对映射有358条电子失败行：30条Si、127条PolySilicon/SiO2、201条PolySilicon。与绝对逆映射相比新增216条、修复1条。
其中284个电子、189个空穴自由节点的绝对 QF 字段仍与父态相同，但 ref/inc 保存了非零增量；这些节点均有对应载流子行失败。增量最大约4.43e-16 V，小于5 V附近一个 binary64 ULP。不能仅比较绝对 QF 列认定两态相同。
例如节点13514（PolySilicon/SiO2）绝对 QF 仍为5 V，电子增量为−2.35948e-16 V，电子行比从绝对映射下的0变为1；相邻节点共同参与通量变化，不能仅凭单行归因于自身增量。
增加一个明确的反事实：只删除这些“绝对字段仍相同”的新低位增量，其余保持。此举改变物理 QF 精确和值，并非等值表示变换，也不是生产阈值建议。结果：

- 电子/空穴失败行：202 / 4902；电子闭合比 0.00090829254。
- 自由 Poisson L2：7.426721e-11。
此控制用于判断低位增量对新增坏行是否有实质影响；即便删除后行数下降，也不能据此忽略所有小增量或修改 eps_row。原生人口保存误差、本构残余差与近零 QF 驱动力之间的耦合仍需保留在解释中。

## 后续判断

保留接触和零改动恒等性的设计得到支持；将所有保存人口直接恢复为 QF 的做法仍未得到完整资格支持。人口准确到1e-14并不足以保证近零驱动力处的行平衡。
下一步宜把相对恢复用于具有明确非零物理修正的受限人口方向，在同一父态比较实际行残差、邻行和闭合；不能以“更贴近导出人口”作为接受方向的目标。继续区分多晶硅近零驱动力与漏侧Si残余人口映射，不把删除低位增量、放宽行比或全链路高精度当作已经验证的修复。
