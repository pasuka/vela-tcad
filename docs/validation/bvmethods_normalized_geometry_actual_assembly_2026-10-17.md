# BVmethods：自主归一化与代表顶点规则接入实际装配

日期：2026-10-17。承接[代表顶点核对](bvmethods_representative_order_audit_2026-10-17.md)及
[实际装配记录](bvmethods_nonlocalpath_n4_actual_assembly_2026-10-16.md)。
[结构化证据](bvmethods_normalized_geometry_actual_assembly_2026-10-17.json)保存五态三臂及资格边界。

**自主长度归一化、严格行列式选点和索引交换已接入私有实际残差。**
原始网格加独立参考契约即可复现全部5356个运行时坐标分量、7619条边长度及4156个Si代表身份，包含150个并列单元；候选不输入原生内部坐标或逐单元代表身份。
五态历史基线实际残差重放逐值相同。源及逐弱行复核仍未通过N4完整退出门，N5未开始。

## 范围与参考契约

- 安装库原版BVmethods，300 K、Fermi、OldSlotboom、NonLocalPath、GradQuasiFermi雪崩及外接电阻；2600节点、5020个Tri3，其中Si为2152节点、4156单元。
- 原始TDR坐标为um；私有源接口为m、m^-3，实际核心为um、cm^-3，二维端电流为A/um。
- 本机Windows UCRT64 C++20、`-O1 -DNDEBUG -ffp-contract=off`执行几何探针及固定态残差。HDF5和既有SuiteSparse依赖参与私有链接，但没有线性求解或Newton/QS更新，不认领后端收敛资格。
- 本轮Sentaurus VM仅做只读接口、初始化常量及二进制哈希核对，没有新sdevice求解；复用上轮封存的原版几何快照。T470p/C560未使用。
- 原始商用数据、反汇编、私有参考量、机器及作业信息仅在ignored `build-release/bvmethods_normalized_assembly_20261017/`。本轮不修改生产材料默认、公开配置或发行包。

原生初始化写入固定的参考长度；私有候选独立按参考德拜长度表达式计算：

`L_ref_cm = sqrt((epsilon_relative_ref * epsilon0_ref_F_cm) * V_ref_V / (q_ref_C * N_ref_cm3))`

该式与初始化参考长度逐位相同。参考温度／电压、参考浓度和参考介电参数组成显式、固定版本的归一化契约，与器件材料本构及实际人口统计独立。
没有从网格输出比值拟合长度，也没有把器件当前材料参数重新解释为归一化默认。
当前资格仅覆盖本安装版本的原版300 K配置。

## 坐标转换与C++几何验证

输入取自同哈希的**原始网格TDR**，保留原始double坐标；运行时回算的um字段不替代原始输入。
归一化按以下顺序进行：

`scale_um = 1e4 * L_ref_cm; normalized = original_TDR_coordinate_um / scale_um`

| 独立转换控制 | 与原生内部坐标逐值一致的分量 |
| --- | ---: |
| 原始um坐标除以已换算的长度尺度 | **5356/5356** |
| 原始um坐标乘尺度倒数 | 5030/5356 |
| 坐标先换算cm、再除参考长度 | 4362/5356 |
| 坐标先换算cm、再乘参考长度倒数 | 3511/5356 |

在自主归一化坐标上，C++按坐标差平方和开方求边长，先取倒数再乘坐标差生成单位方向。
严格比较行列式绝对值，相等保留先遇到者，遍历索引交换0与代表索引。
7619条边长度逐值相同；全部4156个Si代表身份及150个并列单元通过。
运行时2678顶点中的78个界面副本通过身份映射核对，实际核心保持原2600节点空间。

## 私有实际装配的三臂对照

同一冻结人口、QF reference/increment、接触及负载状态下，每态执行三臂，共15次进程：

1. 历史代表身份重放，保留此前计算路径，用于检查编译／链接和证据漂移。
2. 自主归一化选点及索引交换；从原始网格和参考契约计算代表顶点，关闭历史身份输入。
3. 在第2臂基础上，用自主归一化坐标的单位方向恢复电流，单列方向求值的舍入控制；物理SG系数与长度支撑保持原契约。

实际残差与分项观察器共同调用同一路径，账本通过。历史重放与上轮五态实际行逐值一致；自主选点主臂的五态实际行也与历史身份重放逐值一致。
运输、SRH、Poisson、接触和NonLocalPath双源在三臂间逐值一致；两个自主臂不读取历史代表身份文件。

三态BV的自主选点主臂结果如下，归一化方向控制只带来末位量级变化：

| 状态 | 电子完整RHS差／Vela绝对项 | 空穴完整RHS差／Vela绝对项 | 雪崩源加权L1相对差 |
| --- | ---: | ---: | ---: |
| 击穿前 | 3.85e-9 | 2.62e-9 | 1.45e-7 |
| 击穿后 | 4.34e-9 | 2.96e-9 | 1.63e-7 |
| 末态 | 9.96e-9 | 6.63e-9 | 3.60e-7 |

分母仍为实际Vela绝对装配项，不是已认证的原生逐弱行绝对支撑。
零偏／首点不因上述三态整体指标而通过。典型失败保持：首点电子2156约3.62e-6，首点空穴2515约21.8%，击穿后电子2156约1.03e-7，末态空穴2156约1.37%。
末态2156的实际雪崩项与原生投影仍明显不同；选点和方向归一化未消除该差异，不能继续把它归因于150个并列单元的代表身份。

严格128 epsilon人口身份门保持：零偏／首点接受，三态BV仍拒绝。
固定态负载RHS1差仍低于7.7e-8 V，但没有增广负载未知量、器件／负载导数或Newton接受检查。
