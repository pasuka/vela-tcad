# SLOT 负载线工具审查与真实算例复验

用户于 2026-09-23 要求继续未完成任务。本轮从已交付的独立器件负载线
工具审查、回归及 Release 真实算例开始。历史监测不等于计算正在推进；
此次实际启动的复验目录为 `build/ll2309a/`。

## 范围和验收

沿用 13,881 节点 / 27,275 三角形 SLOT 网格、300 K、IALMob、投影
SG/GSS-Laux 自洽雪崩；器件求解使用冻结 Release runner 和 UMFPACK。
外电阻为 1e12 Ω·µm，电流使用带符号 A/µm，负载线残差门槛 1e-6 V。
完整 Newton、全局闭合和电子/空穴各 12,634 个有效行门槛保持不变。
原始 AvalDensGradQF 对齐与完整 BVDS 仍未完成。

新工具分别保存合格内部器件点和合格外部电路点；只有负载线闭合且
电路确认态与器件态字节一致才接受外部点。电路复用状态的零残差占位
字段不能代替真实器件资格。确认态若改变，当前工具明确保留为未合格，
不自动继承前一器件态的证明。初始同偏压状态重新求解和审计，允许零次
Newton 更新；新偏压必须有真实累计全耦合更新。

## 审查和回归

第一轮复跑 40 项新工具测试及 38 项既有续算/Poly 测试，78 项通过。
本轮配置 Release preset 确认 HDF5/TDR、UMFPACK 等已安装功能可用；
不把此次 Python 变更声称为新的 C++ 全套测试。

审查发现两个边界问题，并以新增测试复现：

1. 执行环境未完整冻结，尤其缺少 `VELA_LINEAR_SOLVER`、
   `VELA_LINEAR_THREADS`、`VELA_BLAS_THREADS`，可能使恢复批次混用后端。
   Campaign 层也应检查环境，避免绕过 CLI 或运行中改变环境。
2. 中断目录占用编号时，跳过已有目录后没有再次检查总尝试预算，可能
   在预算之外启动额外求解。已有目录保留，不允许覆盖或免计预算。

新增三个测试在修复前出现八处预期失败，覆盖六个环境变量变更、运行中
后端漂移和中断目录超预算。独立副本修复后 43 项工具测试通过；首轮
真实复验和恢复验证结束后才合入正式代码，没有在运行中篡改脚本身份。
正式代码通过三个相关 Release CTest 条目：新负载线、既有续算/Poly、
局部连续性审计；总耗时 25.46 s。没有重复运行无关 C++ 全套回归。

## 首轮真实复验

从昨日外部 37.05 V 合格器件态重新验收，显式目标为 37.075、37.1 V。
命令和完整过程保存在 `build/ll2309a/command.json`、`driver.log` 和
`checkpoint.json`。总预算 80 次尝试、3600 s，单进程 240 s；最大
内部步长 0.025 V，候选修正上限 12 次，主 Newton 上限 8 次。

已复现外部 37.075 V：内部 37.05744113156716 V，电流
1.7558826727053874e-14 A/µm，负载线残差 -4.17057890444994e-8 V。
与昨日该外压点的电流相对差约 29.4 ppm；两者均通过原门槛，但不宣称
逐字段或逐位相同。

首轮最终完成，共 17 次器件/电路尝试，14 个合格内部器件点，外部
37.05/37.075/37.1 V 均接受，耗时约 1162.31 s，没有失败候选。
37.1 V 内压 37.08206994983449 V，Id=1.7930050102906823e-14 A/µm，
负载线残差 -6.260592044782243e-11 V。相比昨日相同外压控制，电流
相对变化 -0.082993 ppm，内压变化 -9.52814e-8 V，最大电势差约
9.52814e-8 V；不将同外压对照写成严格同内压对照。

独立脚本 `build/ll2309_compare.py` 重算每个接受点的全局闭合及全部
有效行，核对保存态/IV/局部项和哈希，并检查外部负载线及电路状态
一致性。结果为 `build/ll2309a/independent_audit.json`。原代码执行
`--resume` 后正常退出，尝试数仍为 17，未重复求解；原始源码另存
`build/ll2309a/source/`。正式代码变更后旧批次的哈希不再匹配，不能
把旧检查点伪装成新代码的可恢复批次。

修复后的独立真实复验放在 `build/ll2309b/`，从昨日合格外部
37.075 V 状态重新验收到 37.1 V；最大内部步长为 0.0245 V，其余
物理和最终门槛与首轮一致。该轮已完成：5 次器件/确认尝试、3 个合格
内部点，内压 37.08207001631134 V，Id=1.7930051141124713e-14 A/µm，
负载线残差 +6.74524613941685e-8 V（+0.0674525 µV）。独立审计通过，
相对昨日外部 37.1 V 点电流变化 -0.0250893 ppm，最大电势差约
2.88046e-8 V。正式代码的恢复检查 exit=0，尝试数保持 5，不重复求解。

因此第 2 阶段的独立器件负载线自动流程及所要求的外部 37.1 V 点已经
验收。本轮没有修复 C++ 联立电路求解器本身的非线性全局化，也不把
替代流程的成功解释为该算法已修好；高压与击穿后支路仍须后续验证。
