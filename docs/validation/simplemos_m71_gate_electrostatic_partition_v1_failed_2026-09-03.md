# SimpleMOS M71 栅控静电分解

M71 分类为 `execution_or_identity_failure`。在 M65 matched-ni、no-BGN 和 M69 冻结状态上，表面势配对代理对剩余 NWell 电流配对增长的中位闭合率为 `36.97%`，代理与电流配对增长的 Pearson 相关系数为 `0.4711`。

氧化层压降与硅表面势是同一栅压分配恒等式的互补项；最大恒等式误差为 `5.551e-17 V`。P1 氧化层边界位移通量相对 Sentaurus 原生 ContactCharge 的最大相对误差为 `170.90%`，用来限定栅电荷观察器资格。该任务不重新打开 HFS、SG、接触提取、BGN、Nc/Nv、网格或收敛调参。
