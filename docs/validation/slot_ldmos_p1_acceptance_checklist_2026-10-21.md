## 范围和状态定义

P1验收的是指标计算、状态绑定、覆盖及观察器不变性，不要求所有样本收敛。
数值停止和续算仍由各样本绑定的legacy配置决定；已经授权的报告模式照原配置解释。
不恢复载流子行比、零更新残差或存档逐字段差异的隐含硬门。

| 验收状态 | 含义 |
| --- | --- |
| 已验证 | 在表中限定的入口、构建和样本范围内已有证据；不外推至其他路径 |
| 实现缺项 | 已核对的接口尚有占位、未接入或缺少约定字段；需补实现与相应验证 |
| 证据缺项 | 已有实现或局部证据，但尚不能证明约定覆盖；不等于代码一定错误 |
| 转后续阶段 | 属于P2标定、跨代码对齐或求解改进，不阻断P1文档和诊断验收 |

以上是工作项状态，不是运行指标状态。指标继续使用`pass/fail/not_evaluated/not_calibrated`；
有值但无标定阈值为`not_calibrated`，缺输入为`not_evaluated`，两者都不能补成0或成功。
已存在的legacy谓词按原结果报告。缺容差的器件审计不能因为输出了数据便标为通过。

4. 对P1-15按已获授权的限定替代建立证据映射，永久保留原1.10 V轨迹未回放说明；12份替代文件已完成核验。
5. 在最终冻结版本对受影响入口做开关配对和相关回归，形成P1-16的总验收记录。

**结项判定：**所有P1范围内的实现缺项和证据缺项关闭，或者经明确确认形成有边界的例外；
不得只因队列结束、进程返回0或影子总标签不是fail便结项。
结构上不存在的指标可记不适用并写明理由；零更新缺方向、未标定阈值等预期缺失不要求伪造数值。
在固定范围内计算和报告正确、legacy不变即可验收；不要求影子标签全部pass。
若保留经确认的例外，结论写“P1限定范围验收完成”，同时列出例外，不称全覆盖。
