## P1：两个非有限矩阵错误

两次原始失败在不同坏状态中均复现：行3289/列689与行2931/列331。Full和bootstrap分别有6、12个非有限条目；独立装配的完整输运、冻结迁移率输运和雪崩Jacobian全部有限，且对应真实输运/雪崩源与owner逐字匹配。所查为自由电子行，不是规定接触行。

SRH采用`γn γp ni² expm1((fp-fn)/VT)`。人口坐标下fn、fp的共同ψ方向均为1，分裂量的ψ导数为精确0。冻结态中间指数先溢出，AD乘法随即得到`inf*0=NaN`：

| 节点 | 分裂量 | 分裂量ψ导数 | 双精度expm1 / ψ导数 | 110位合并结果 | 与n*p恒等式相对差 |
|---|---:|---:|---|---:|---:|
| 689 | 735.9947571 | 0 | inf / NaN | 2.028527406674e46 | −6.53e-13 |
| 331 | 711.9490665 | 0 | inf / NaN | 5.831240868903e33 | −7.53e-14 |

110位复算使用导出的双精度冻结参数；微小恒等式差不等于完整高精度材料模型误差。合并表达式有限，说明中间expm1溢出是可避免的算术问题。重组同时需要保留平衡附近expm1精度、人口/电势方向和源项值的一致性，不能只把NaN导数改为0。
