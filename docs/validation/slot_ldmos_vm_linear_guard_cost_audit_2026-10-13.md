# SLOT IdVd 六次线性保护及双系统开销审计

2026-10-13。6 mV 父态后的六次拒绝均由同一条 Si 界面空穴行的线性混合误差触发，发生在第一个 Newton 更新之前。对保存的方向作独立、单坐标线性残差校正后，六份固定系统均通过原线性保护；这支持先验证残差精化，而不是继续依赖偏压减半。非线性大步能否通过尚未验证。

本批只读原始运行证据，在独立审计目录输出结果；未修改运行中的 IdVd/BVDS 代码、配置、保护阈值或父态，未启动新的非线性求解。

## 六次拒绝的直接原因

下表目标和跨度单位均为 mV，混合误差上限为 1。

| 尝试 | 目标 Vd | 本次跨度 | 原混合误差 | 校正后全矩阵最大混合误差 |
|---|---:|---:|---:|---:|
| d001 | 13.008 | 7.008 | 3.40166 | 0.11506 |
| d002 | 9.504 | 3.504 | 2.18101 | 0.07361 |
| d003 | 7.752 | 1.752 | 5.00329 | 0.16867 |
| d004 | 6.876 | 0.876 | 9.41844 | 0.31733 |
| d005 | 6.438 | 0.438 | 1.78325 | 0.06006 |
| d006 | 6.219 | 0.219 | 1.26930 | 0.04275 |

每份系统都只有一行超过混合误差上限：全矩阵零基行号 33,377，即节点 5615 的空穴方程。六次均记录 `updates=0`、`mixed_linear_guard`，未执行浓度投影、线搜索或第二套诊断线性求解。单次约 75–77 s，六次合计约 455.3 s。随后待试跨度降到 0.1095 mV，仅为原 7.008 mV 的 1/64；恢复任务继承这个小跨度，再按迭代数缓慢增长。

节点 5615 同时邻接 `Silicon_1` 与 `Oxide_1`，不是接触节点：邻接 Si 单元 11060、11070、11073、11076、11077，SiO₂ 单元 24597、24821、24823。其网格坐标原值为 (0.004622821319225472, 4.103760148987475)。六个目标的这个局部状态相同：

| 量 | 数值 |
|---|---:|
| n | 4.06648×10¹⁹ cm⁻³ |
| p | 1.71224 cm⁻³ |
| ψ | 0.583363133 V |
| φp | 7.74003×10⁻¹⁰ V |
| 空穴对角 Jii | +1.1549202145×10⁻¹⁷，内部缩放单位 |
| 该行 RHS | 1.2560553843×10⁻³⁸，内部缩放单位 |

此处对角为正，不能套用此前“负对角导致空穴崩塌”的解释。d001 的主要乘积为自身空穴列 +4.1033×10⁻²⁵、节点 5614 空穴列 −3.8358×10⁻²⁵，并有本节点电子列约 −2.2162×10⁻²⁶及其他邻接项；近抵消后留下 3.3185×10⁻²⁹ 的线性缺陷。

实际保护计算为

\[
 M_i=\frac{|(Ax-b)_i|}{10^{-6}(\sum_j|A_{ij}x_j|+|b_i|)+(10^{-14}\,\mathrm V/V_T)\sum_j|A_{ij}|}.
\]

本行绝对项为 8.93486×10⁻³⁰，d001 相对项仅 8.20805×10⁻³¹，因而得到 M=3.40166。所有块范数误差约 10⁻¹⁶、约束误差 0，并不保证该局部条件通过。PARDISO 均报告 0 个扰动主元、2 次内部精化，不能把这六次拒绝归为已证实的主元扰动。独立 long double 累加重现原指标，排除了“只有统计代码误算才报警”的解释；消元/排序/内部精化哪一步留下该缺陷尚未分离。

## 固定系统的校正诊断

在保存的 A、b、x 上，只作一次

\[
 \delta x_i=-\frac{(Ax-b)_i}{A_{ii}},\qquad x_i\leftarrow x_i+\delta x_i,
\]

其中 i 为超标行对应自由度。校正写回 float64，再用 long double 累加重新检查**全矩阵**，不只检查被修正行。六次校正幅度约 2.55×10⁻¹⁴ 至 1.91×10⁻¹³ V；全矩阵混合误差见上表，块误差仍约 10⁻¹⁶、约束误差仍为 0，六次均满足原线性质量条件。

这是单坐标线性松弛的可行性证据，不是独立高精度方向参考，也不是对真实方向误差的上界。没有将校正方向施加到器件状态，不能据此宣称 13.008 mV 已收敛。正式实现应按超标行通用选择、限制校正轮数，检查其他行是否恶化，失败时保留原拒绝；不能硬编码节点 5615 或直接忽略该行。

`matrix_s` 包含两套装配、求解、线性质量及方向相关处理，不是 PARDISO 纯分解时间。约占端到端 44%；不能据此承诺删除重复计算后加速一倍。

实际入口先构造 `wall_s`，随后才进入 `projectionDiagnostics`：逐节点人口 CSV、行分项 CSV，以及四个接触泛函构建和求值。这部分每步诊断未计入该步 `wall_s`；163.790 s 还包含初始化、输出、最终矩阵快照等。现有计时不能把这 164 s 全归为磁盘 IO，也不能精确给出每个接触求值的成本。

终点保存的 physical/regularized/stabilized 三份矩阵各 21,729,798 字节，SHA-256 完全相同；两项稳定化关闭时保存三份内容可合并，每个此类快照可少写约 43.46 MB，保持名称绑定或明确别名清单。仅做这项磁盘去重的实际提速尚未测量。

## 建议实施顺序与验收

1. **同一目标先做有界线性精化，再决定偏压减半。** 使用原 A、b 计算高精度线性缺陷；优先验证复用分解的残差修正，也可将通用行松弛作为独立对照。先要求六份固定系统全量线性保护通过，再做同父态大跨度有界非线性复验。保留原阈值。
2. **补齐端到端分项计时。** 分开记录原系统、诊断系统、两次质量检查、人口恢复、行/闭合评估、各接触求值、文件 IO、复读。`wall_s` 应覆盖完整单步；不可把遗漏时间当作已测得的装配成本。
3. **共享同态评估与基础数据。** 同一网格/材料/状态只构造必要公共量，显式组装两套 Jacobian 或其差项；RHS 必须逐位相同，方向、人口更新及接受结果与旧流程配对核对。约束后的连续性行与原始接触反力口径不同，不能直接拿前者替代闭合原始行。
4. **减少重复诊断输出。** 每步保留必要投影/极值、R/U、线性保护和失败诊断；详细 CSV/完整矩阵优先在接受点、异常及指定审计点保存。端口计算应尽量从同态原始反力一次取得所有端口，并与现行泛函逐项核对。保持最终文件一致性复读。
5. **保留双方向的语义。** 原始方向目前参与 U 和原系统质量保护，第二方向用于实际更新。直接删去原系统求解会改变停止规则。可研究符号分析复用，但不同 Jacobian 的数值分解不能直接互换。
