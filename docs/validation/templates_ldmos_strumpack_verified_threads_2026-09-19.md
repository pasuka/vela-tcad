## 冻结范围

- UCRT64 Release `-O3 -DNDEBUG`；开启独立 CMake 开关
  `VELA_ENABLE_OPENBLAS_THREAD_CONTROL=ON`，该开关默认 OFF。
- 运行时显式 `VELA_BLAS_THREADS=1` 通过 API 设置并查询。每次共享线性求解
  结束检查 BLAS 线程数；STRUMPACK 同时记录 OpenMP 线程数及活跃嵌套上限。
  该 API 影响进程级库配置，各对照通过独立进程执行。
- UMFPACK：串行稀疏流程、OpenMP=1、OpenBLAS=1。
- STRUMPACK：无压缩 DIRECT、METIS、最大对角乘积匹配/缩放，
  无微小主元替换、无 GPU、无超节点合并；OpenMP=2、OpenBLAS=1、活跃嵌套=1。
- D5 双栅压 Vg=4/8 V，各由对应的合格零漏压种子运行从 Vd=0 V 开始的前八个
  精确点，终点为 9.333333 V；保持原门限和跨后端电势/QF 最大差≤1e-8 V。
- R11 D5 无 Auger 生成、不含 IALMob，300 K；10,241 节点、19,782 三角形，
  输入坐标 μm、密度 cm^-3、端口电流 A/μm。
- 原物理、生产默认后端不变。关闭详细因子统计，保留点服务计时及运行时线程观测。
- 一轮串行配对，共四条曲线、32 个精确点；不认领完整 0–40 V、D4/D0 或重复稳定性资格。

## 运行与核验

```powershell
cmake --preset windows-ucrt64-release -DVELA_ENABLE_OPENBLAS_THREAD_CONTROL=ON
cmake --build --preset windows-ucrt64-release --target test_linear_solver vela_example_runner linear_solver_replay --parallel 2
python scripts/run_templates_ldmos_isothermal_backends.py --output reference_staging/templates_ldmos_strumpack_verified_threads_first8_20260919 --backends umfpack strumpack --threads 2 --blas-threads 1 --points 8 --rounds 1 --profiles D5 --factor-statistics off
```

前置固定矩阵为历史 14 个带原系统的捕获，各后端正反顺序两轮；检查原系统与
求解器输入误差及两个 RHS。曲线的每个非零求解点都要求有线程观测，缺失或
实际值不符即拒绝。旧的“BLAS=1”环境声明不能代替该检查。

构建与测试：Release 线性测试 21 项/499 断言通过，相关 Python 回归 25 项通过。
其中新测试覆盖运行时线程被改变时拒绝、不开开关不改线程、未支持值拒绝，
以及审计缺失或错误运行时证据时失败。

证据目录：`reference_staging/templates_ldmos_strumpack_verified_threads_first8_20260919`。
其中冻结 runner/replay、DLL、源码及输入哈希；`summary.json` 保存线程审计和逐点状态对照。
记录后台负载，不认领独占机器计时。端到端计时包含零压种子检查、漏压扫描、
子进程及父脚本整理；不含此前生成种子及栅压预偏置的时间。
前八点只复核原块残差、逐行闭合、KCL 和跨后端状态一致性；运行器明确记录
`partial_curve: not a full D5 score`，不将其认领为完整曲线联合验收。
