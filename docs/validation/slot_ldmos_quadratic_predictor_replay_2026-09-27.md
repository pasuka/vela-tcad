# SLOT 端口一次/二次预测：Wolfram 核验与历史回放（2026-09-27）

结论：不建议将现有斜率保护直接替换为无约束二次外推。外压参数化的一次模型已经显著减少旧保护的触发；三点二次在本地低压段更准确，但高压尾部误差更大，五点二次在本数据上没有普遍优势。建议一次模型为基础、以已发生的样本外误差选择受约束的二次候选。

## 范围与证据

- Sentaurus 原始曲线：60 个不同外压点，沿用并重新核对上一轮日志/PLT 的 SHA256 与时序对应，55 个共同测试窗口。
- Vela 当前低压曲线：`build/s27native_goal/run/checkpoint.json`，去掉参考系重验造成的重复外压记录后 253 个点；跨参考系窗口排除后 243 个测试窗口，最高物理外压 26.7736365 V。checkpoint 哈希与上一轮已核验快照一致；没有重新逐点运行方程审计。
- Vela 独立高压支路：`build/s26bv/branch_qr/checkpoint.json` 与 `branch_audit.json`，38 个接受点、33 个测试窗口，内部约 38.2→38.52174 V。逐点检查保存态哈希与已存审计的端口、状态绑定，原审计载流子行/负载线门槛通过。本次不是重做完整方程资格审计。
- 两批 Vela 的求解器版本、初始化路径及候选策略不同，分开统计，不拼成一条已验证的 0→BV 路径。R=1e12 Ω·µm，电流 A/µm，温度 300 K，固定端物理偏压零。
- 无新求解、无生产控制器或物理配置修改。产物均为分析脚本、数据和报告。

## Wolfram 数学核验

调用 Wolfram Context 获取外推/步长控制相关文档，并调用 Wolfram Language 内核独立检查非均匀三点二次系数及真实数据案例。Context 没有找到本 TCAD 案例的直接算法结果，不将通用 ODE 文档视为该器件的收敛定理。
采用外压 U 为自变量，在最新状态锚定 Δv=a H+b H²，H=ΔU，并令 ΔI=(H-Δv)/R。令最近两段外压间距为 h1、h2，内压割线斜率为 s1、s2，则三点二次：

```text
b = (s2-s1)/(h1+h2)
a = s2 + h2*b
dv/dU = a+2*b*H
R*dI/dU = 1-a-2*b*H
```

Wolfram 独立符号计算与 Python 实现一致。若要求预测仍在内压/电流均正向变化的支路，需在整个候选区间检查 0≤a+2bh≤1；导数为线性函数，检查区间两端即足够。此条件只约束预测曲线形状，不保证器件 Newton 收敛，也不能证明真实支路不存在回折。
拟合以最新点为原点，横坐标按历史窗口宽度缩放，固定零截距：一次模型用最新三个点加权拟合斜率；三点二次为精确插值；五点二次对较老四点按 1/2/3/4 权重最小二乘，最新点作为严格锚点。不是把五点升成四次多项式。

## 无前视的回放方法

在每个测试点，只用此前历史拟合，将历史实际下一外压步长作为共同已知输入，预测下一内压与电流，再与实际结果比较。因此衡量的是“给定步长的端口响应预测”，不是未知最大收敛步长、不是新算法闭环生成的路径，也不验证计算加速。
所有方法使用同一组满足五点历史的测试窗口。误差统计保留触发保护的原始预测，没有删掉失败模型来美化准确率。电流相对误差分母为 max(abs(实际下一电流),1e-16 A/µm)。
统一候选保护：导数在 [0,H] 超出 [0,1]（数值裕量 1e-12）、缩放设计矩阵条件数超过 1e8、外推长度超过前一步的 1.6 倍。保护次数指给定历史步长下该候选需降级/缩步的次数，不是实际仿真失败数。
已有旧模型按 dI/dVinner 拟合，斜率不一致时取消电阻增步。其保护计数另列；若强迫它在原生的大外压步长下使用降级预测，会出现巨大内压预测误差，那不是现有控制器实际会尝试的步长，因此不拿该误差声称新算法已提速。

### 具体反例

Sentaurus 外压 38.91668872 V、内压 38.49142144 V 起点，下一实际外压增量 0.50977738 V，实际内压仅增加 0.00747393 V。三点二次得到 a≈-0.216135663、b≈-0.921329786 V⁻¹，预测内压反而下降 0.34960978 V，误差 -357.084 mV。
Wolfram 独立数值计算复现该结果；缩放矩阵条件数约 7.65，不是病态线性求解导致，而是局部二次曲线对快速趋于平台的函数作外推时失真。此前三个内压都递增，也不能保证二次外推导数为正。
五点二次并非总更稳：其更长窗口跨过曲率急变区，高压 Vela 的 P95 由一次的 14.889 mV 增至 66.121 mV，最大误差达到 103.216 mV。低压三点二次有改善，但原本误差已为微伏量级，尚不能转化为已证明的 Newton 成本收益。

## 因果混合试验与建议

试验规则固定为：一次模型为默认，查看最近三次已经发生的样本外预测误差；二次候选只有在其误差中位数低于一次的 80%，且本次候选通过形状/条件数/外推范围保护时才获选。联合误差使用 max(abs(δv)/0.02 V, abs(δI)/(0.025*max(abs(父态电流),1e-16)))，仅作算法比较指标，不替代器件门槛。没有用目标点的真实内压、电流选模型。
该启发式并非独立测试集上优化后的最优算法：这里只验证一次固定选择规则是否值得继续试验。它改善了 Vela 低压 P95（6.704→3.763 µV），没有恶化此次高压 P95，但也没有消除 Sentaurus 转折处最大约 289 mV 的预测偏差。

模型选择次数（一次/三点二次/五点二次）：
- Sentaurus 原始：39/14/2。
- Vela 低压：81/117/45。
- Vela 高压：29/2/2。

建议实施顺序：

1. 先把端口预测改为外压参数化，并保留一次模型作为基础；这与提高多项式阶数是两项不同改动，应分开对照。
2. 三点二次仅作为可选候选，用已发生的预测误差和区间导数检查决定是否启用；不要将“拟合通过三点”当作可靠性证据。
3. 形状合理但曲率项过大的候选可先缩短外推距离，再复查；初始导数已经为负时，缩短 H 也无法修复，应降阶/重新估计或调查回折，不强制裁剪成正斜率。
4. 五点二次暂不作为默认。后续可研究按电压跨度/曲率变化调整窗口，而非固定凑五点；新策略须用未参与选择规则制定的区间和独立重算验证。
5. 实际续算仍保留三类独立步长上限、电流增长、成本反馈、完整器件/全部行/闭合/负载线确认及失败回退。预测曲线更准确不等于求解器一定更快。
