# SLOT：同态 double / long-double 方向分层与邻行互换

日期：2026-10-11。证据：`build/s11direction_layers/`。
前序：[三次重线性化对照](slot_ldmos_float80_relinearization_2026-10-11.md)。

## 结论

在同一重新装配的冻结系统上，10280 的空穴方向经正则化大幅缩小，
double 与 long double 仍有差异；但两者经 QF 限幅后均为 −0.05 V。
该节点最终人口完全相同，通量差异来自邻点更新。
仅互换 10281、10307、10308 的空穴 QF 位移，即逐值交换了10280的
通量、残差和行比。这是本冻结态上的受控归因，不是整个器件失败的充分解释。

Poisson 重修正降低了 ψ 块残差，但本次没有消除载流子超标行。
long double 没有改善主导块残差或电子/空穴闭合到原门槛内。
本批零次接受 Newton 更新，新增合格点0，未更改生产默认、物理模型或验收门槛。

- 延续前批 AverageBox及配套体积、实际Poisson路径、Fermi、兼容材料/常数、
  effective-band SG、接触电离回退等冻结配置。详细配置见各臂config.json。
- runner SHA-256：`c70123323bdc7b60fcb99ffd334c308e99e53edaa5ad501fa99bb10bd11034dd`。
- 主父态P：`s11float80_relinearize/A_double/progress/iteration_1.h5`，
  SHA-256 `a332e4893596639da24dd001ef7053cc9d8930d9d4ea30363ac7d0e0bb74caff`。
  它是未合格的诊断父态。补充父态PB为上一批B臂的iteration_1.h5。
- D为` sparselu `，L为` sparselu_long_double `：后者以long double分解double装配矩阵，
  方向返回double；状态、物理装配和Woodbury小矩阵/组合仍为double，不是全链路float80。
- 每层D/L的physical、regularized、stabilized矩阵文件哈希分别相同，
  residual和solve_rhs逐值相同。层间改变正则化/闭合替换是显式诊断消融。
- 人口取新冻结探针重建值，单位cm^-3；HDF5人口通常为m^-3。
  下文通量、源项和残差为装配内部行单位；不是A/µm。方向表已从内部VT单位换算为V。

依次比较：物理系统（正则化0、闭合替换off）、正则化系统（1e-8行和、替换off）、
生产Woodbury系统（1e-8、replace_free_row_sum，替换行13881/27762）。
对各原始方向施加相同的掺杂分类QF分量限幅，再单列
`Jψψ Δψ = −rψ − Jψc Δxc`重修正；每个有限试探重新装配真实残差和人口。
未施加未经限幅的巨大原始方向，也没有执行线搜索接受。

外部试探采用保存态ref/inc构造，ψ右端使用SciPy稀疏乘法，Poisson子块使用相应
Eigen后端。它是受控阶段对照，**不是原生产循环逐位重放**。
试探HDF5保留的density字段明确标记为stale，不用于本报告；人口均来自新探针。

## 1. 正则化、Woodbury和线性精度

10280位于Si内部，坐标约(0.0613671, 0.274805) µm；其含本点一圈节点为
10271/10272/10279/10280/10281/10307/10308。

|原始空穴方向，V|D：10280|L：10280|D：10238|L：10238|
|---|---:|---:|---:|---:|
|物理系统|−51.4063|−51.7138|−405.832|−405.833|
|正则化系统|−0.1522446821|−0.0684250234|−0.9926134223|−1.0166934752|
|再作Woodbury组合|−0.1522446821|−0.0684250234|−0.9926134223|−1.0166934752|
|直接分解显式替换矩阵|−0.1401236943|−0.0685440451|−0.9677016093|−1.0167037427|

10280自身物理对角2.3864122956e-17，正则化后2.3864123439e-17，
只增加2.02e-8（相对值）；10238对角增加0.2019%。
因此方向变化不是本节点对角直接放大数百倍，而是整个系统的正则化经耦合改变了解。
本批未计算条件数或逐耦合路径灵敏度，不能据此指定唯一远端责任行。

Woodbury相对正则化基解在10280仅增加−1.92e-14 V（D）/−2.43e-14 V（L），
但全域最大方向变化约0.784/0.981 mV；不能以单节点结果认定它全域无影响。

同一显式替换矩阵直接分解与Woodbury组合，在10280相差约12.12 mV（D）、
0.1190 mV（L）。这两条数值路径并非逐位等价。直接分解耗时约85.5/176.8 s，
其中因子分解81.1/172.2 s；这些成本不能与含装配和文件导出的整探针直接当作性能比。

|线性残差∞范数|D|L|
|---|---:|---:|
|正则化基系统，返回double方向、扩展累加|8.85e-15|1.25e-15|
|Woodbury最终系统，返回double方向、扩展累加|1.35e-14|1.31e-14|
|直接替换系统，原精度方向、113-bit检查|7.20e-14|8.42e-17|
|直接替换系统，返回double方向、扩展累加|7.19e-14|1.25e-15|

Woodbury组合后，L基求解的绝对残差优势明显减小。当前结果支持进一步检查组合精度，
但没有证明它是非线性停滞主因。所有系统最大分量后向误差均为1，最差为1701的
零RHS边界行：微小非零方向使分子/分母同小而比值为1。
因此保留该指标并同时报告绝对残差，不把它解读成全矩阵有100%绝对误差。

只将D试探的10281/10307/10308空穴位移换成L值，保持ψ、电子及其余节点不变，

未重新修正ψ，未接受更新。它隔离了这三个邻点对目标行差异的作用。
L行比更接近1，但绝对残差反而更大；不能据此称为质量改善。

## 4. 原轨迹分叉尚未完全解释

上一批A在第二次内存更新中10280抬高0.05 V，本次重载A第一次保存态后方向却为负。
重载块残差与原保存记录接近，但这不是逐位相同的内存装配身份。
因此本报告不声称已重现或完全解释上一批原始分叉。

|冻结父态|D的10280方向，V|L的10280方向，V|
|---|---:|---:|
|P：上一批A第一步|−0.1522446821|−0.0684250234|
|PB：上一批B第一步|+0.1306737500|−0.0685028556|

两父态10280的空穴QF相同，ψ仅差1.11e-16 V；但全域电子/空穴QF最大相差
0.00557046/0.0603363 V。该父态切换是全域状态变化，不能称为仅舍入扰动实验。
块范数接近也不保证方向或全场接近。
