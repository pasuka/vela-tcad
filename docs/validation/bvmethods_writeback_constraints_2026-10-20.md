## 完整更新身份

每档 alpha 保留以下量，全部绑定同一 x、J、R、人口及接触状态：

```text
request = alpha * d
y = fl(x + request)
delta_applied = exact(y - x)
delta_logged = fl(y - x)
sum_low = exact(x + request - y)
```

逐分量用精确有理数验证 `y + sum_low = x + request`，并分别保留
`delta_applied` 和已舍入的 `delta_logged`。完整低位方向在线性代数中满足：

```text
J * (delta_applied + sum_low) = J * request
```

这是线性方向身份，不等于已有完整的保低位物理装配器。

初次审计把两个 double 保存态相减当成精确差，断言被新边界余量臂的空穴 835
（设备行 6035）推翻：该分量跨过零点，减法相对舍入误差约 5.91e-17。
修订后从保存的 x、y 精确求差；旧脚本、断言失败和日志保留。
这个反例发生在 Vela 诊断态，不是新取得的 Sentaurus 语义。

不同阶段的失败集合不同，不能只比较总数。全部 13 档逐行记录保留。
大多数 ψ 请求很小，计数多不等于误差贡献大，也没有把这些分量统一清零。

对每条固定行另构造充分条件：

```text
margin_i = bound_i - abs(R_i + (J request)_i)
roundoff_bound_i = sum_j abs(J_ij) * abs(delta_applied_j - request_j)
margin_i >= roundoff_bound_i
```

该条件通过可保证此次写回不破坏该线性行界。全步两臂分别有 191／200 行未获此证书，
两臂全部 13 档均未全部通过。该绝对和上界是保守的；不通过不表示这些行一定实际超界。
未用它修改原行门，未因亚 ULP 幅度豁免失败。

## 最大超界来自哪一段

在同一主变量和原单位下精确分解：

```text
R(y) - [R(x) + J request]
  = J(delta_applied - request)
  + [R(y) - R(x) - J delta_applied]
```

最后一项称为非线性余差；它也可能包含 Jacobian 不一致及残差求值误差。
下表按实际残差符号取向，均除以固定行界，正值表示朝超界方向增加：

| 新边界余量：空穴 722 | −1.025e-15 | 4.9303e-7 |
| 新边界余量：空穴 709 | 6.254e-14 | 1.8572e-7 |
| 新边界余量：空穴 845 | 6.310e-15 | 1.3340e-7 |
| 活跃约束余量：空穴 717 | 8.659e-16 | 6.6132e-9 |

| 活跃约束余量：空穴 706 | −3.669e-16 | 7.4679e-10 |

## 两个候选控制

**电子 SG 低位控制。** 在独立装配器中，将 TwoSum 得到的电子低位送入实际 SG 边循环，
高状态人口、迁移率、统计因子和源项继续冻结。独立装配器关闭低位时与原残差逐位一致。
它不包含 ψ、空穴及完整本构低位链，不能视为完整新物理状态。

| 全步 | 原实际 merit | 电子 SG 低位控制 merit | 固定界超限行 |
|---|---:|---:|---:|
| 新边界余量臂 | 3.58016727927746e-3 | 3.58016727925275e-3 | 10 → 10 |
| 活跃约束余量臂 | 3.84154725508286e-3 | 3.84154725462643e-3 | 15 → 15 |

这两种受限方向与此前 rows5 的原 Newton 方向不同；本轮不能把以前的电子写回主因照搬到
现在的空穴阻断行。两臂全部 13 档均未通过固定界，部分 SG 控制也没有解除主要空穴超界。

**固定电势边界归零控制。** Poisson 列回代在 52 个固定电势节点留下极小请求；
两臂全步最大约为内部坐标的 1.50e-26／2.56e-26，实际写回均为零。
只将这些物理上固定的电势请求归零，两臂全部 26 个已保存试步的 y 逐位不变，
请求预测的严格失败也没有消失。该控制没有清零自由载流子方向，也不涉及 SLOT 齐次块消元。
这是对保存状态的候选身份验证，未另称为 26 次完整求解。
