# SimpleMOS M54 端口共模归因

## 结论

M54 分类为 `direct_shift_mixed`。分析完全复用冻结的 M8 默认和 M53 `DirectCurrent` 端口文件，没有重新运行 Sentaurus 或 Vela。

对每个状态定义 source/drain 共模 `C=(Id+Is)/2` 和反对称输运项 `T=(Id-Is)/2`，并逐点验证 `Delta Id = Delta C + Delta T`。816个状态、3个载流子分量的最大恒等式残差为 `0.000000000000e+00` A/um。

M53目标 n23、Vd=0.05 V、Vg=0.05 V 的总电流共模分数为 `0.933831637`；M53最差点 n24、Vd=0.05 V、Vg=0 V 为 `0.993973408`；全816状态中位数为 `0.430781500`。共有 `42/816` 个状态的共模分数不低于0.9。

目标点 DirectCurrent-minus-default 漏端变化为 `1.336411045911e-15` A/um，其中共模项 `1.438326309569e-15` A/um，反对称项 `-1.019152636579e-16` A/um。最差点相应三项为 `-7.519383306194e-15`、`-7.474067049980e-15`、`-4.531625621386e-17` A/um。
