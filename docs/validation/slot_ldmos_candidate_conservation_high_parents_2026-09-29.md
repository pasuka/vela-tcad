# SLOT 更高偏压父态的候选守恒与修复成本验证（2026-09-29）

## 结果

在本机串行完成三个更高偏压父态的小步验证。候选路径 **3/3** 通过，均无父态
回退或额外密度修正；严格固定内压重闭合均更新 2 次。另从每个原父态直接
求解相同最终内压，独立对照 **3/3** 通过。六份新器件态和六份负载线确认已
重新审计，输入、候选诊断、严格态证据及原 Release 文件的哈希检查通过。

结果支持保留现有显式候选策略和严格重闭合，暂不调整算法或放大步长。
这是三个独立父态的小步抽样，不是一条新完成的连续高压扫描，也未达到击穿判据。

## 试验设计

- 入口为 `build/s29rhsparents/result.json` 中 p41/p96/p156 的合格新状态，
  不是该历史实验中本机缺失的原始失败父态。因此没有把本轮称作原失败重放。
- 三个父态物理内压分别为 38.4607383440、38.4698451893、38.4763244040 V。
  首组外推前点为本地已合格 38.4517560281 V；后两组分别使用前一个所选父态。
  所有父态与外推前点的完整器件、全部有效行、全局闭合、文件绑定和电路确认
  均先重新验证，参考原点统一为 36 V，base 逐值一致。
- 提议外压跨度为 1.534786873、1.692810763、1.415590835 mV。
  保留外推最大比值 1.6、候选 zero-converged-device-RHS、原容差 1e-8，
  以及上批的冻结候选守恒检查和严格重闭合。
- 有限抽样的额外步长保护：实际外压增量不超过 0.01 V、接受态内压增量
  不超过 0.1 V、内部试探上限 0.05 V、电流增量不超过父态的 25%。
  可分辨进展仍用前批显式工程策略，不将它称为已证明的浮点误差界。
- 单候选路径预算 240 s，单独立对照预算 180 s，总预算 900 s；实际全批
  308.4 s 正常结束。始终仅有一项重负载计算，没有连接 T470p。

物理配置保持 300 K、13881 节点/27275 单元、IALMob 完整场导数、自洽
元素密度 GradQF 雪崩、circumcentric 电荷体积、分单元介电耦合及原生输运几何，
R=1e12 Ω·µm。电流单位 A/µm；下表电压已加参考原点。
本地 UCRT64 Release；严格器件使用已归档 runner 的默认 UMFPACK，耦合候选
使用 direct_bordered_qr；HDF5、UMFPACK、SPQR 可用。

  计算、三组独立对照及末尾逐点资格/证据审计。沿用已验证的 `runner_v2.exe`。
- h5py 仍提示编译/运行 HDF5 版本不同；本批读写及哈希复验均成功，没有发生
  环境中断或总预算耗尽。

当前建议保持显式候选选项、冻结守恒检查、严格重闭合与失败回退。下一步宜从
最新合格态做短段连续续算，先保持毫伏级外压步长，观察局部行余量、候选电流
修正和不同初值重复精度，再决定是否调整步长或算法。检查本身没有修正候选
电流公式；三次检查通过也不意味着原始候选可直接进入正式账本。

本批串行计算已结束，没有启动长扫描或恢复定时监测。部分几何仍依赖原生导出，
最高电流仍远低于 1e-7 A/µm 判据，不宣称全部 BVDS 或独立性验证完成。
