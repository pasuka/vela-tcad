# BVMethods 一致统计契约与零偏回放（2026-10-24）

**已建立并验证一套可复现原生默认统计映射的解析候选：正函数、反函数、一阶／二阶导数和 FD-BGN 共用同一关系。** 原始零偏、独立栅压状态及 NoFermi-BGN 控制共六个阶段均通过材料／人口映射检查。匹配原生材料和热电压后，节点 1546 的碰撞电离源降至约 2.34e-24，现有接触电场规则保持原样。

严格区分结果：**统计契约验证通过；当前生产默认路径的零偏平衡尚未获得资格。** 普通 owner 回放仍使用现代常数，其电流未归零；同输入核函数回放也保留约 1e-15 A/μm 的微小终端电流，尚未复现原生日志约 1e-21 A/μm 的近零值。没有用强行置零 QF 代替相同人口回放。

## 实现及资格边界

新增 [JoyceDixonStatistics.h](../../include/vela/physics/experimental/JoyceDixonStatistics.h)，仅提供实验契约，没有加入生产配置分派，默认 `fermi_dirac` 继续使用定义积分。

令 x=n/Nc 或 p/Nv，先定义反函数：

\[
P(x)=\ln x+a_1x+a_2x^2+a_3x^3+a_4x^4,
\]

\[
H(x)=\sqrt{(3\sqrt\pi x/4)^{4/3}-\pi^2/6}.
\]

低段四项系数采用公开 Joyce–Dixon 形式；可参考原始论文 DOI [10.1063/1.89697](https://doi.org/10.1063/1.89697)及 [GSS 项目手册](https://gss-tcad.sourceforge.net/gss_book.pdf)。实现没有复制第三方源码。

求解 `P′(x*)=H′(x*)`，取 `c=H(x*)−P(x*)`，构造低段 P、高段 H−c 的 C1 反函数。计算得到：

- 拼接人口比约 **8.4629603662**。
- 高段 η 偏移约 **0.0137050034664**。
- 低段正函数通过单调反解得到，高段正函数可显式求出；一阶、二阶导数从同一反函数推导。
- 一阶导数在拼接处连续；二阶导数按各段求值，不声称 C2，也不跨拼接点做中心差分。

拼接点由公共公式的斜率相等条件得到，不是逐节点修正量或将原生 n/p 硬编码成拟合表。现有原生人口在低段复现 P，在高段复现 H−c；这是本轮对测得映射的解析验证，不声称已获取原生内部源码或全部范围的分段规则。

私有 Release 回放将当前 CarrierStatistics 翻译单元中的四个原函数统一转向该契约，其余密度、QF 反解、广义 SRH、SG、FD-BGN 仍调用这些原函数。FD-BGN 没有单独用另一个统计近似。私有替换对象链接于冻结 core 之前；未修改生产 CarrierStatistics.cpp 或基础常数文件，未安装此替换库。

## 原生独立控制

沿用 T-2022.03-SP2、300 K，2600 节点／5020 三角形、2152 个 Si 节点，R=1e7 Ω·μm，完整碰撞电离、Band2Band 关闭。新增两组独立原生仿真：

1. `gate_holdout`：仅将 gate 电压从 0 改为 0.1 V，保留默认 Fermi 与 FD-BGN。
2. `nofermi_bgn`：保留 Fermi，仅用 `EffectiveIntrinsicDensity(OldSlotboom NoFermi)` 关闭 FD-BGN 附加修正。

两组从自身初值执行 Poisson→联立，均退出 0；四次新 TDR 导入均退出 0。栅压状态未参与解析候选的建立。连同此前原始零偏的两阶段，共检查六组数据：

| 全部 2152 个 Si 节点 | 六阶段最大差 |
|---|---:|
| 正函数计算的电子浓度相对差 | 3.90e-14 |
| 正函数计算的空穴浓度相对差 | 4.62e-14 |
| 反函数 η 差 | 4.62e-14 |
| 重建电子 QF 与原生输出之差 | 1.34e-15 V |
| 重建空穴 QF 与原生输出之差 | 1.08e-15 V |
| FD-BGN 开启时总 BGN 差 | 5.56e-16 eV |
| NoFermi-BGN 时总 BGN 差 | 4.17e-17 eV |

这些比较固定原生 Nc/Nv、基础材料和 VT=0.025851995266484913 V；开启时按同一反函数计算 FD 附加项，关闭时仅用经典 OldSlotboom。此处核验统计公式及开关语义，没有把 NoFermi 控制当成完整物理验收。

验证范围对应这些场量覆盖的 η 和温度；一般温度、多材料及更强简并范围尚未取得原生资格。单元测试的更宽数学区间检查不等于扩大原生资格。

## 普通 owner 的相同人口回放

保持所有原生 ψ/n/p，在 Vela 中反解 QF，再实际打包、计算 RHS/Jacobian 和一次 Newton 方向。内部状态约零偏，外电路目标仍沿用前轮首个 0.01 V；因此下表是同一个冻结状态的来源比较，不是从零完成的扫描。

| 私有 owner 组合 | drain 电流 / A·μm⁻¹ | 节点 1546 的 AV 行项 | 该节点原始 δfp / V |
|---|---:|---:|---:|
| 定义积分＋原材料（旧基线） | −1.27930195e-5 | −3.45357451e-13 | 1.91328075 |
| 新契约＋原材料 | +8.37472826e-8 | −7.60018229e-16 | −8.74680952e-4 |
| 定义积分＋原生基础材料 | −1.28796071e-5 | −3.46163797e-13 | 1.92220992 |
| 新契约＋原生基础材料 | −3.05104039e-9 | −3.61165354e-17 | 4.15851317e-3 |

新契约明显消除了主导统计差异，但普通 owner 的 VT 仍为现代常数的 **0.025851999786435535 V**。原生基础材料控制只替换了基础 Nc/Nv/ni，不等于所有派生量及常数已对齐。最后一组电子 QF 最大绝对值仍约 1.22e-7 V，不能宣布零偏平衡通过，也不能仅凭源项降低就宣称完整原生方向已一致。

三组新单步回放均退出 0；`coupled Newton iteration budget exhausted` 是刻意只取一次方向的预算结果，不是非线性收敛。所有组合保留相同 AV 接触规则，没有关闭碰撞电离。

## 匹配材料／VT 的核函数控制

为区分上述常数残差，单独显式传入原生材料字段与 VT，使用实际共享 SG／AV 核函数、广义 SRH 和本例相同体积政策重建载流子自由行。所有 2600 节点电势都保留；没有将介质区电势留成零。行项统一以冻结 C0=5.09e20、D0=36.63228369737916 归一化。

此显式核函数回放先用普通 owner 的自身场量作交叉检查：各载流子 **2121 个自由行**的输运、SRH、AV 与 owner 分项吻合，最大分项相对 L2 差约 1.81e-14；drain 电流相对差小于 1e-15。没有用此局部控制声称 Poisson／接触替换行或全 Jacobian 通过。

| 同输入控制 | drain / A·μm⁻¹ | 电子自由行 L∞ | 空穴自由行 L∞ | 节点 1546 AV 行项 |
|---|---:|---:|---:|---:|

关键边 722（1546–2567）的电子电离驱动场始终约 **53190.4584 V/cm**，αn 始终约 **6.25129773e-5 cm⁻¹**。因此源项降低来自电流／平衡关系改善，而非旁路接触电场替代。

### 极小电流与精确平衡参考

原生日志的零偏 drain 电流约 3.897e-21 A/μm；上述相同人口回放仍停在约 1e-15 A/μm。即使直接用原生输出 QF，也未复现其近零电流。这已进入极小 QF 差、场量写回及电流数值求值敏感区；本轮没有唯一分离各项贡献，不能用相对电流误差声称通过。

另外构造独立的精确平衡参考：保持 ψ、材料和 VT，取物理平衡 fn=fp=0，并由新契约重新计算人口。此时 SG、SRH、AV 和全部端口电流均严格为零。相对原生人口的最大变化为：

- 电子 **3.66e-14**。
- 空穴 **3.77e-10**。

原生接受态的电子 QF 最大约 4.59e-16 V，但空穴 QF 最大约 **9.746e-12 V**；空穴人口变化主要由去掉这个非零 QF 决定，符合 `expm1(|fp|/VT)` 的量级，不能全部称为序列化舍入。这与旧统计下置零 QF 会改变人口约 0.1%／0.6% 已有本质的数值差别，但**精确参考仍不是位级相同人口修复**，不能替代前面的回放结果。
