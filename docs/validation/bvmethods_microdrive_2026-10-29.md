# BVMethods微小驱动力与Cn表示差异（2026-10-29）

接续[高精度误差账本](bvmethods_precision_budget_2026-10-28.md)。本轮继续追查6个主导AV矩阵差单元的上游输入，另部署当前数值源码快照的完整BV任务。没有将以下值控制接入求解器。

## 输入及定义

沿用2600节点、2152个Si节点、5020个Tri3网格，300 K、JD／OldSlotboom、SRH、总杂质迁移率、GradQF AV、BTBT关闭。同一原生检查点；源字段与实际Release单元边重放已在前轮绑定。分析7单元、56条定向载流子边，使用80位Decimal精度。

以统一方向，微小驱动力定义为δ=a−ln(cj/ci)。分别记录电势归一化、能带组合、统计值、人口坐标往返，以及QF派生编码的贡献。对QF路径使用由实际节点QF定义的δ；人口SG路径使用由实际ψ、ni、人口、DOS、gamma定义的δ。原生参考由已识别ψ/VT、Cn、BGN/VT、DOS/N0、gamma、人口/N0字段独立组合，不把未识别内存槽当成数据。

每条边的完整差与上述分项之和在80位下闭合，绝对闭合预算1e-70。这里比的是给定binary64原始量所定义的实数表达，不将其冒充已完成的原生完整内部算法契约。

## 主要新结果

两个对称的主导电子边1308→791、2587→2084，在QF路径中的微小驱动力差约2.45257e-14，其分解为：

| 项 | 无量纲贡献 |
|---|---:|
| 电势归一化／物理坐标往返 | +1.90146e-15 |
| 能带组合 | +2.23887e-14 |
| 相同归一化输入的统计差 | −8.88178e-16 |
| 统计人口／DOS坐标往返 | −4.44089e-16 |
| 人口坐标往返 | +3.31061e-17 |
| QF派生编码 | +1.53470e-15 |

再把能带项拆开：

| 能带项来源 | 无量纲贡献 |
|---|---:|
| 本轮ni指数／对数编码与独立BGN表示 | +7.01121e-16 |
| 自主BGN与原生BGN字段输入差 | +3.71262e-16 |
| 原生大Cn偏移相减与半BGN差的表示差 | +2.13163e-14 |
| 总和 | +2.23887e-14 |

因此这两条重点边的主要能带组合差，并非单独由BGN物理公式或剩余高简并gamma解释。公共亲和势数学上消去，但把Cn≈χ/VT+BGN/(2VT)先保存为大数再相减，和直接求半BGN差并非同一浮点路径。**这一结论描述数值表示差，不等于认定Sentaurus物理公式错误，也不意味着应让生产代码人为注入原生舍入噪声。**

人口SG路径对应边方向相反，组合差约−2.29910e-14；该路径不经过节点QF之差，因此没有QF派生编码项。仅改未知量名称或继续替换expm1，不能消除这里的原始量差异。
