# 实际浅沟道状态方向 Jv 差分：缺陷定位到电子连续性–电子准费米导数块

2026-09-05。本轮已完成只读方向差分检查。直接测得的 `λᵀ(Jv−ΔF)` 精确复现此前约 0.3408% 的 Vela 伴随预测缺口；缺陷几乎全部来自 **电子连续性行对电子准费米势的导数块**，空间上集中在沟道界面附近。

本轮资格通过的是“缺陷测量可靠性”，不是 Jacobian 正确性。此前 Vela 双幅度伴随响应校准的失败结论保持不变，M82/M83 未放行。没有修改生产源码、求解器库、端口电流算法或默认配置，没有新的非线性计算和 Sentaurus 任务。

## 输入、方向与方法

基态仍为严格合格 n23、Vd=0.05 V、Vg=0.9 V。分别使用上一轮 ±1e13 和 ±5e12 cm^-3 自洽状态构造 `v=(x_plus−x_minus)/2`。保留全部 ψ、φn、φp 分量；准费米势差使用参考值和增量先做 Decimal 差分，以避免在物理绝对值相减时丢失微小增量。

两方向最大物理分量分别为 1.74853606265295e-5 V、8.742680321944e-6 V。每个方向分别检查 all、ψ-only、φn-only、φp-only，使用 h=1、0.5、0.25，比较 `J(x0)v` 与 `[F(x0+h v)−F(x0−h v)]/(2h)`。另独立导出原正负自洽端点的 `[F(x_plus)−F(x_minus)]/2`。固定电荷与状态无关，故使用原无电荷算子的导数即可。

生成的独立 runner 仅增加读入方向和导出全部行的功能，链接原始核心库。Jv 的稀疏乘加使用 long double 累积；残差沿用原始 double 实现。每例 1,482 节点、三个方程块，输出 53,352 条记录。两个幅度主检查共 106,704 条记录；另有一次 53,352 条记录的开关对照。

执行前已冻结：加权差分步长变化≤1e-3、复现上一轮加权缺口相对差≤1e-3、`λᵀJv=gᵀv` 相对差≤1e-8。微小空穴信号保留输出，不声称其逐行相对差分精度合格。

## 方程块定位

以下为全幅方向、h=0.5 的电流加权缺陷：

| 行块 / 输入方向 | λᵀ(Jv−FD) (A/um) |
|---|---:|
| 所有行 / 全方向 | 3.1645639404762176e-14 |
| Poisson 行 / 全方向 | -2.0017627024475118e-21 |
| 电子连续性行 / 全方向 | 3.164564140652488e-14 |
| 空穴连续性行 / 全方向 | 1.926031977524853e-34 |
| 电子连续性行 / ψ-only | 9.283387141478503e-20 |
| 电子连续性行 / φn-only | 3.164554917493033e-14 |
| 电子连续性行 / φp-only | 9.493606200046495e-32 |

因此缺陷由电子连续性–φn 块主导。该块在 φn-only 方向的非加权差分相对 L2 误差约 2.68021%。相比之下，全系统方向的相对 L2 误差仅约 3.76217e-6，因为 Poisson 块范数主导了总范数；仅用全系统小相对误差不足以证明电流响应预测可靠。

## 空间定位

使用与原生电荷校准相同的浅沟道掩码。下面的“占比”统一以所有行 `|λ_i(Jv−FD)_i|` 的绝对值之和为分母，避免正负抵消导致超过 100% 的误读：

- 浅沟道内占 99.9882%。
- 浅沟道界面以下 10 nm 内占 98.0363%。界面 x=0.005045938170817487 um，x 为深度方向。
- 绝对贡献最大的 30 行合计占 93.4153%，逐行位置和符号见 `top_rows.csv`。

前三个最大贡献行为电子连续性节点 1061、1064、1063，坐标 (x,y) 分别约 (0.00776362,0.0465015)、(0.00646968,0.0465015)、(0.00776362,0.02459227) um。这些是定位线索，不能只挑正贡献节点作为总误差；总绝对贡献约 2.61776e-13 A/um，净贡献约 3.16456e-14 A/um，存在明显抵消。

## Jacobian 场导数开关与源码检查

只读对照将 `solver.mobility.jacobian_field_derivatives` 从省略（当前默认 true）改为 false，其余保持一致。全部 53,352 条 Jv、中心残差差分及端点残差差分记录完全相同。对照证明：本例不能归因于用户遗漏打开该开关，也不能通过单改开关消除测得缺陷。

源码证据：

- `include/vela/physics/MobilityModel.h:162` 的 `jacobianFieldDerivatives` 默认 true；`src/physics/MobilityModel.cpp:671` 读取配置覆盖。
- `src/equation/CoupledDDAssembler.cpp:1398` 起，残差根据输入状态计算 `electronVectorMobilityFields`。
- `src/equation/CoupledDDAssembler.cpp:3508` 起，Jacobian 在基态预计算同一向量驱动场。
- `src/equation/CoupledDDAssembler.cpp:4549` 的 `edgeElectronTransportFlux` 在 vectorQfMobility 分支直接取基态 `electronVectorMobilityFields[e]`。
- `src/equation/CoupledDDAssembler.cpp:4769` 起，局部准费米势扰动用于计算输运导数，但上述向量驱动场在该局部差分中没有随之重算。

这与实测 φn→电子行缺陷相符：**`transport_cell_vector` 高场驱动对准费米势的链式导数是当前明确候选。** 本轮尚未构造补齐该链式导数的 Jacobian，因此数值定位和源码路径一致不等于修复效果已被证明，也未排除该块内的其他小误差项。
