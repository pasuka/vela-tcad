# 原生低压失败：器件/电路响应与恢复资格（2026-11-08）

本阶段完成8份原生冻结矩阵的器件/电路Schur与RHS分块，并聚焦第1次保护后的少子强响应。两边均有相似代数放大链，但具体物理源项、有效偏导模式与共同根因仍未闭合。四导数开关未执行，整个后续队列不标完成；没有新Sentaurus或器件Newton，没有生产改动。

## 1. 恢复资格先行：未跳过失败

拟选原生约2.51 V目标的第1轮入口及其第1次保护后状态，准备同态四开关。准备R1复用助手时存在路径引用错误，监督器1/无自有进程，有界错误只读一次；独立R2修正助手，保留R1。R2在严格输入检查处停止：现有NewtonPlot没有ContactExternalVoltage字段，无法直接取得精确失败目标外压；终态1/无自有进程。没有猜测圆整日志目标，也没有启动任何四开关原生过程。

失败缩半步关系与相邻接受PLT可以约束目标区间，但不能据此声称已经获得逐位原生目标；本阶段未把区间中点当作严格同态输入。即使以后补齐目标，人口/QF往返、接触辅助状态、首次载入态及RHS仍需分别验证，不能用“Load成功”替代资格。

这不阻止已导出矩阵上的纯线性分析，故本阶段继续了不依赖重载的响应定位。

## 2. 冻结线性合同

输入来自[原生诊断补采](bvmethods_native_low_failure_capture_2026-11-08.md)的8份矩阵/向量；16个输入SHA逐项与既有27文件包清单闭合。11个相同电路别名保留一次，构成6843维系统，器件J为6842维；符号统一为A·delta=b。原生坐标为psi/VT、n/CN、p/CN和电路势/VT，VT=0.025851995266484913 V、CN=1.4824351e10 cm^-3，沿用当前300 K已核验尺度，不修改物理模型。

在VM使用SciPy SuperLU、双精度因子/方向，双边平衡及两次原系统缺陷校正；累加使用63位尾数long double。它是导出系统的独立后端重解，不是厂商内部ParDiSo过程或生产求解器切换。分块为A=[[J,f],[r,c]]，a=J^-1 b_device，z=J^-1 f，s=c-rz，delta_lambda=(b_c-ra)/s，delta_x=a-z*delta_lambda。再把器件RHS分为Poisson、电子、空穴三份，电路RHS另列；原生已消元的接触人口不凭空补回。

8帧作业及1帧聚焦作业均监督器/worker0、无owned进程；证据逐SHA核验。包SHA分别为`df4e5f515ad6de274d3235ed1cd118a27dd054497d7371d3de22d94bec2fd1fa`和`114541c6c2b3006ce70f79d47588a1bcf202e79b1b5b3cde5a56cc461e94496b`。本轮不读取成功日志。

## 3. 第1次保护后：电路分母没有接近零

原生第2份矩阵的s≈10964.8846，c≈10884.3831，因此s/c≈1.00739606。Vela对应本地失败状态的s/c≈1.00740359。不同方程行/列尺度下不能直接比较原始s，但此比值显示两者都不是小Schur分母放大。

原生冻结重解delta_inner≈−0.56756828 V；内压方向的分项约为：电子RHS−0.56975361 V，空穴RHS+0.000851646 V，Poisson+0.000001710 V，电路直接RHS+0.001331972 V。Vela此前约−0.37767207 V也由电子RHS响应主导。这里电子RHS的作用经过完整器件J逆，不能直接等同于某一电子物理模型错误。

## 5. 后续轮次与数值资格

原生8份冻结系统的s/c均未出现接近零的抵消；后期s绝对值增大，分子和器件响应也剧增。第6轮电子/空穴RHS对内压约−576/+311 V；第8轮约−1.147e7/+1.012e7 V，两项强抵消后仍得到约−1.33e6 V。不同轮次主导分项发生变化，不能用第2轮一种归因包办整个失败过程。

8份重解的完整系统分量后向误差最大约2.09e-12，分项叠加相对闭合误差最大约6.40e-13；与原生导出方向按固定参考列量加权的相对差约5.46e-10至8.97e-8。后向量小不提供向厂商内部方向外推的前向误差界，也不是原生产绝对精度门验证。所有方向均未写回，不授予冻结帧等价、保护不变、判停等价、RHSMin或生产迁移资格。
