# BVmethods 保精度装配回调与首轮状态绑定（2026-10-14）

本轮取得了原生装配回调中的人口、带边、DOS 和 QF，完成首态身份审计及独立 η 重算。
两条目标弱行的打印 RHS 与旧控制一致；完整 RHS 有四个末位差异，尚未取得全系统逐位
一致资格。弱行输运重建仍不通过，继续 Q2/Q3。
接续[独立 η 与带边对照](bvmethods_eta_band_precision_2026-10-14.md)，
机器指标见[配套 JSON](bvmethods_precision_callback_2026-10-14.json)。

## 配置与采集范围

本地 Sentaurus VM T-2022.03-SP2、ExtendedPrecision（80-bit）、DensityIntegral(240)、
单线程。原 BVmethods 2600 节点/5020 Tri3 网格，Si region 3 为 2152 节点/4156 单元，
300 K、Rext=1e7 ohm*um；沿用源关闭诊断、Fermi/OldSlotboom 与原接触/材料。
长度 um，人口/DOS cm^-3，ψ/QF V，带边 eV；下面的输运量为此前换算的内部无量纲量。
这是同态源关闭控制，不是原全物理纯 QS 轨迹。

新私有 `PMI_Recombination_Base` 回调替代旧零源观察器，`out.r=0`，不写状态数据。
直接记录 Input 的 n/p/T，并通过 ReadScalar 读取 ψ、DOS、带边与 QF；用
`get_value<long double>()` 和 `max_digits10` 输出 21 位有效数字。该输出格式可以保留
本次 long double 返回值，不证明每个派生量的上游计算都具有相同精度。
未将 SDK 或官方示例代码复制进公共源码；私有适配器为自行实现。

原生单步退出 2，为一次 Newton 更新预算结束；不是稳态收敛。采集到三个完整 Si 块，
每块 2152 节点。前两块全部字段的文本值相同，第三块是更新后状态，未混入首态重建。
远端源码、进程号、环境与原始文件仅保存在忽略目录
`build-release/bvmethods_pmi_entry_20261014/`；公开位置使用 `<SENTAURUS_DIAGNOSTIC_ROOT>`。

- 首轮 debug 的全部打印变量与上一轮 native80 基准一致。
- 首轮 RHS1 四个打印值不同，最大绝对差 1.9852334701272664e-22（原生 debug 单位）。
  记录差异，不把它们清零或当作逐位身份通过；具体根因未确定。
- 电子 2156、空穴 2515 的各方程打印 RHS1 均与旧控制一致。

上述身份核对支持本轮两条弱行的局部控制；完整系统的无观察器扰动证明仍未完成。

## 保精度人口、带边和驱动重算

复用 T470p 已验证的独立 100 位 Fermi 定义积分程序，在本机对保精度文本人口/DOS 的
14 个唯一比值反算 η；Decimal 90 位分别计算带边与统计项、再求边差及稳定 SG。
积分误差估计最大约 2.12e-42。使用此前固定 native80 边系数/迁移率，避免同时改变支撑。
热电压继续单列历史常数指纹，未证明它就是原生内部常数，不据此改生产默认。

| 行 | 原生 RHS1 换算输运量 | 带边＋独立 η | 相对差 | 采集 QF 边差 | 相对差 |
|---|---:|---:|---:|---:|---:|
| 电子 2156 | 6.198930848075017e-11 | 4.609346312042351e-11 | −25.6429% | 6.198154929176119e-11 | −0.0125170% |
| 空穴 2515 | 2.252746269366258e-13 | 2.252906510021314e-13 | +0.00711312% | 2.251680113452747e-13 | −0.0473269% |

结论是保精度回调已打通，但提高文本导出精度不足以闭合实际输运值。独立精确统计与原生
DensityIntegral 派生路径、有效带边/热电压及 SG 内部驱动的求值顺序仍需区分。
这些是待检验方向，不能据此断言某个统计近似已经被证实为根因。本轮没有新采集的非零
扰动臂，上一轮非零响应不能替代新回调的方向验证。

## CurrentPlot 失败定位与验证

SDK/current 链接和实际程序均为同一 SP2；可用 GCC 11.2.1 与官方构建 GCC 9.2.0 不同，
仅记录环境差异。入口追踪证明 factory、构造和表头均返回，而正文回调没有进入。
不读状态的常数控制、实际读值控制、去掉求解前独立 CurrentPlot 的生命周期控制均退出
139；字符串 ABI=0 控制也退出 139。故不能把故障归于读人口或 get_value。
官方启动器环境下的调试器捕获到错误处理抛出，未取得足以解释根因的故障位置；
直接启动二进制的库/DATEX 初始化失败另列为环境失败，不冒充采集入口堆栈。

最初带调试信息的编译受现有汇编器限制失败；另一次三个控制在启动阶段超时。
恢复已有 DNS 超时设置后才得到上述有效入口控制。失败证据保留，未安装/升级系统包。
本轮原生有效控制、替代采集及调试日志共 148 文件下载，归档和逐文件 SHA-256 通过。
独立积分与带边工具的 8 项已有数学性质测试通过；生产 C++ 未改，未重建求解器。
