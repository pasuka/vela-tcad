# BVmethods 自主节点场几何、接触方向与近零 QF 控制（2026-10-13）

本轮在 **T470p** 将上轮识别的一环响应还原为由网格独立生成的几何规则，补齐实际接触电压、
主栅氧化层及共享界面方向。六个区域的基准场相对 L2 差均不超过 **1.08e-14**，独立方向
最大约 **5.58e-11**；Si 显式 E2 源积分约 **4.95e-14**。这一步不再依赖原生场值或拟合场系数。

两条近零输运弱行仍未完全闭合。17 组原生源关闭控制证实导出 QF 的路径/精度会影响重建值，
较大可分辨扰动的斜率吻合到约 1e-8；尚不能据此把全部值余差归因为某一个舍入机制。
128-bit 对照在初始化积分阶段超时，没有 RHS 资格。生产 C++、物理默认、模板、门限及发行包未改。

接续[上轮节点场与输运记录](bvmethods_node_field_transport_2026-10-13.md)，数值、输入身份和
收据见[配套 JSON](bvmethods_field_geometry_state_2026-10-13.json)。本轮仍处 Q2/Q3。

## 1. 配置和证据边界

BVmethods NMOS 原网格：2600 节点、5020 个 Tri3，Si region 3 有 2152 节点、4156 单元，
26 条负局部余切边需要转移。300 K，外电阻 1e7 ohm*um；Fermi + OldSlotboom、
Masetti/DopingDep + Enormal + GradQuasiFermi HFS、SRH(DopingDep)、E2 BTBT、VO Eparallel。
坐标 um，人口 cm^-3，电势 V，场 V/cm，迁移率 cm²/(V s)，Measure um²，G cm^-3/s。

原生参考为 Sentaurus T-2022.03-SP2、80-bit ExtendedPrecision、DensityIntegral(240)、单线程。
三组原物理单进程 Load/Plot 共调用 27 次 Plot，均退出 0；17 组源关闭控制使用相同统计和迁移率，
只保留零源观察器，关闭 SRH/BTBT/雪崩以隔离输运。每组只取 Coupled(Iterations=1) 的更新前首 RHS；
该进程退出 2 是迭代预算结束，17 次随后更新不作收敛或 QS 资格，下一组重新 Load。

计算/分析使用 T470p Windows UCRT64 既有 Python/NumPy/HDF5 环境。本轮没有 Vela C++ 编译或
Newton 更新，没有调用 Vela 线性求解器，不能据既有 Release 链接后端认领线性求解通过。
原生 ψ 尺度仍为 Vt=.02585199526648486 V，载流子 RHS 转换因子仍为 7.950490318918128e-9，
没有按新弱行拟合尺度。原生 debug VAR/RHS 为有限位数文本，TDR/PMI 接口为 double，均非内部
扩展精度操作数的无损导出。

## 2. 从坐标独立生成节点场

新增私有审计辅助函数 [bvmethods_geometry_field.py](../../scripts/bvmethods_geometry_field.py)，
复用当前 `DelaunayBox.h` 所述几何转移约束，不接入生产配置。流程如下：

1. 每条单元边生成 κ_Tij=0.5*cot(对角)。负局部贡献只向同区域的另一侧三角形转移，保留全局边和；
   非流形、全局非 Delaunay 或需要负贡献跨材料转移的边直接拒绝。本例自主复现 26 次转移，
   全部单元 κ 与原生相对差 1.27e-15。
2. 单元顶点盒面积由 `M_Ti=(κ_Tij*|d_ij|²+κ_Tik*|d_ik|²)/4` 生成，不强制每个单元重新归一到面积。
3. 对边生成 `w_ij=sum_T(M_Ti+M_Tj)/|d_ij|²`。这里求和包含共享边两侧的全部材料，
   不能仅保留 Si 单元。
4. 节点使用加权最小二乘：`H_i=sum_j w_ij*d_ij*d_ij^T`，
   `E_i=-H_i^-1*sum_j w_ij*d_ij*(ψ_j-ψ_i)`。非 Si 节点取全局一环；Si 节点只取 Si 一环。
   输出在共享 Si 节点处继承该 Si 节点场，不能为每个氧化层区域独立套用 Si 恢复规则。

这同时解释此前常见边权/单元梯度平均失败，以及 Si 边界约 1.93% 的余差。
本轮保留线性/二次多项式、面积、角度、局部/全局体积等失败候选；简单截断负余切的自主场
仍差约 0.455%，不能替代转移规则。仅用 Si 邻域处理全部绝缘层和仅用全局邻域处理全部节点
也均失败；两种对照保留在 `analysis_extra.json`、`insulator.json`。

| 独立几何恢复检查 | 相对 L2 差 |
| --- | ---: |
| 全 Si 2152 节点基准场 | 2.20e-15 |
| 主栅氧化层 region 0 | 1.55e-15 |
| 侧氧化层 regions 1/2 | 4.32e-15 / 3.19e-15 |
| Nitride regions 4/5 | 1.07e-14 / 9.31e-15 |

E2 使用已导出的原生参数 A2=3.5e21、B2=2.25e7（cm 制），不是修改 Vela 的全局材料默认。
固定网格下几何算子为线性，ψ 列可由同一规则直接生成；性质测试包含生成算子后的 E2 链式
方向差分。本轮尚未将该动态场和导数接入私有实际 C++ 装配，也未认证完整耦合 Jacobian。
本例几何资格不外推为任意网格、非 Delaunay 边界或异质结资格。

## 3. 接触和氧化层方向

初版直接扰动接触 ψ 时，Load 只保留漏极 11 个节点的变化，源极/衬底固定接触会重置；
初版氧化层掩码只含 regions 1/2，不能声称覆盖主栅氧化层。原始输入和结果均保留，最终以
后续包含 region 0 的控制及实际 `ContactExternalVoltage` 保存字段控制为准。

- 漏极节点编码正负方向：Si 场相对差约 3.1e-13 / 3.5e-13。
- 源极真实外电压 ±1e-6 V：11 个 Si 接触节点生效，Si 场最大方向差 5.58e-11。
- 衬底真实外电压 ±1e-6 V：9 个 Si 接触节点生效，最大方向差约 2.87e-11。
- Si/主栅氧化层界面 56 个节点编码正负扰动：Si 场差约 1.4e-12。
- 主栅氧化层/全部绝缘层独占节点扰动以及栅极真实外电压方向：Si ψ 不变时 Si 场增量严格为零，
  绝缘层场由全局/Si 节点覆盖规则复现。六区域全部新方向的最大相对差 5.58e-11。
- 最后重载基准，六区域 ψ/QF 输出逐值相同。

这些都是固定态 Load/Plot 的场恢复方向。栅极扰动后没有重新解 Poisson，因此 Si 场增量为零
只说明该恢复算子的直接支撑，不能解释为栅极对自洽器件没有影响。

## 4. 两条弱行：独立 QF 与源关闭 RHS 控制

在原生模型中分别施加自由节点 QF 归零、共同平移和弱节点 ±1e-18、±1e-15、±1e-12 V 的扰动。
独立重建继续使用已认证的边几何和局部盒平均 µ，不根据节点 RHS 拟合电流或偏置校正。
接触 QF 按 Load 后实际边界值保留：自由 QF 共同平移并不是带固定 Ohmic 接触的全局规范变换。
首版忽略这个边界条件的 seed-flat 重建已单独保留，最终分析已修正。

| --- | ---: | ---: |
| 原生输运 | 6.1989308481e-11 | 2.2527462694e-13 |
| 导出状态重建 | 6.1999020499e-11 | 2.2516801135e-13 |
| 原生减重建 | -9.71201795e-15 | 1.06615591e-16 |

更直接的精度证据来自未改变的载流子：空穴归零控制中，电子人口和 ψ 的 TDR double 值逐位相同，
原生电子 RHS 在 debug 输出精度下逐值相同，但导出电子 QF 最大变化 2.02e-19 V，2156 处变化
1.35e-19 V，重建弱行差会因此改变符号。电子归零控制中，未改空穴也有最大 1.08e-19 V 的导出
QF 变化。不能把某次导出 QF 当成内部 SG 驱动的无损表示。

这些结果支持近零算术/状态表示是重要来源：可分辨扰动斜率吻合、原生零驱动仍有余值、导出
QF 存在路径差；但尚未获得原生内部人口/QF 的无损操作数，也没有通过 128-bit 值对照，
故仍不宣布两弱行完全解释或已修复。没有把归零余值当作经验偏置从实际 RHS 中扣除。

## 5. 精度超时、验证和后续

128-bit 使用原生日志确认的 double-double ExtendedPrecision(128)，保持 DensityIntegral(240)
及物理参数不变。480 s 和一次 180 s 有界复核均退出 124，均在首次 Load 前，没有矩阵/RHS。
复核在 60 s 时读取的调用栈落在 `DensityIntegral<dd_real>::Compute`、
`ClassMultiValleyDensityParam::dDirect`、`BuiltinPotentialEntry::Compute` 的初猜积分计算中，
不是 QS 步长失败；没有沿用上一轮许可证/DNS 超时解释。尚不能仅据这次栈断言是成本高还是
积分迭代异常，失败归档保留；未降低积分配置或换物理以获取通过。

- 本机和 T470p 各 28 项相关性质测试通过；前两轮 122+330 项远端封存文件全部未变。
