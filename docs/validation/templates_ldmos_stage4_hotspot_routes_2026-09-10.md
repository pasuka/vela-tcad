# LDMOS 前 8 点：三个主要热点的优化途径分析

本轮基于已完成的 gprof、同源码非插桩 Release 计时及当前源码进行分析，未修改求解器。
结论是：**先消除复合状态和边上静态物理量的重复计算、按需构造散布表；
随后用固定矩阵专项实验选择 SparseLU 分解优化方案。** 数值分解的收益空间最大，
但现有证据尚不足以断言更换排序或后端会更快。

## 证据、范围与收益预算

分析对象为 Vg=8 V、Vd=0–9.33333333333333 V，含 0 V 的前 8 个精确参考点。
沿用已合格 0 V 状态、原自适应子步/严格再求解、全部原验收门限。
300 K，Fermi–Dirac、OldSlotboom BGN、SRH/Auger、vector QF 高场迁移率和接触电场回退；
量子、表面迁移率、雪崩、热关闭。网格 10241 节点、19782 三角形、30022 边，5723 硅节点。
电势 V、几何 μm、密度 m⁻³、电流 A/μm；Eigen SparseLU/COLAMD、L2 行列均衡。

当前 121 个源码/构建输入与前轮 Release 快照一致。以下优化预算采用 **普通 Release
`-O3 -DNDEBUG`**，不使用插桩时间估算生产收益。内部总时间 1219.333 s；子进程墙钟合计
1235.173 s。此前 gprof 的 29.95% / 24.21% / 17.26% 属于另一种计时环境，并不矛盾。

| 热点 | 普通 Release 时间 | 占内部总时间 | 假设该阶段耗时减少 25%：内部总时间减少 |
| --- | ---: | ---: | ---: |
| SparseLU 数值分解 | 397.748 s | 32.62% | 99.44 s / 8.16% |
| Jacobian 装配 | 290.518 s | 23.83% | 72.63 s / 5.96% |
| 残差计算 | 184.408 s | 15.12% | 46.10 s / 3.78% |

三项合计约占 71.57%。表中是成本预算，**不是已测得或承诺的收益**。
三项若同时减少 25%，内部总时间约减少 218.17 s（17.89%），不包括优化新增成本。
边上物理、节点源和模式构造包含在 Jacobian 中；连续性诊断、密度校验等另有调用，不能重复叠加阶段预算。

## 1. SparseLU：优化数值分解和填充，不重复建设缓存

### 已确认的成本来源

[LinearSolver::solve](../../src/solver/LinearSolver.cpp) 已实现稀疏结构匹配、符号分析缓存、
矩阵数值逐位比较及完全相同矩阵的数值分解复用。本轮 1612 次求解全部进行了数值分解，
没有数值分解缓存命中；符号分析实际执行 429 次，命中 1183 次。
符号分析及缓存检查仅 16.098 s（1.32%），因此单纯再加缓存不是主要方向。

完整符号表下的 gprof 将大部分线性成本定位到 `factorize`、`panel_bmod`、`gebp_kernel`、
`gemm_pack_lhs`。这些内部矩阵更新是数值分解成本的重要组成，而非 JSON 解析。
内部观测的填充比均值为 12.085、最大值 12.795；L、U 非零项均值合计约 298.76 万。
这些均值包含主耦合矩阵和辅助系统，不能当作单个主矩阵的统计。

主 Jacobian 为 30723×30723，固定结构非零项 265211；实际非零系数均值约 226325，
约 14.66% 的结构槽位在平均观测中数值为零。**数值为零不等于永远不需要的结构项**。
现有计时没有区分主耦合分解与 Poisson 修正分解，应先补齐该分组数据。

### 优化路径

**L1：固定矩阵回放，测清内核和填充。优先作为分解优化的实验基础。**
在实际行权重和 L2 均衡之后捕获 A、b，同时保存缩放向量、结构/数值哈希和所属 Newton 步。
选起始低压、4 V、9.3333 V，以及内部困难点约 6.4333 V、7.5667 V 的代表矩阵；
只使用本次 8 点范围内已有轨迹，辅助 Poisson 系统另列。
在独立 Release 小程序中分别计时结构分析、数值分解、三角求解，记录填充比与内存。
当前没有现成的主 Newton 矩阵导出入口，这属于下一轮实现任务，不能把配置文件当作已冻结矩阵。

**L2：局部参数及可用后端对照。中等风险，收益待测。**
本机 Eigen 的内部默认值为 panel_size=16、relax=1、maxsuper=128。
可在隔离实验中选择少量面板/超节点参数组合，控制线程和输入，筛选有价值的组合；
这些是受保护的内部参数，不是项目现有 JSON 配置，不能依赖稳定公共 API 的假设。
硬件向量化编译选项也可单独实验，但必须约束部署 CPU、检查舍入影响，不开启 fast-math。

UMFPACK 是适用于非对称稀疏系统的对照候选，需实际测量本组矩阵。
[官方 UMFPACK 用户指南](https://github.com/DrTimothyAldenDavis/SuiteSparse/blob/dev/UMFPACK/Doc/UMFPACK_UserGuide.tex)
支持这一算法定位；当前安装和源码已确认存在辅助入口，但 `VELA_LINEAR_SOLVER=umfpack`
尚不能切换主 Newton 流程。现有 `solveUmfPackSystem` 每次创建求解器，且使用独立的枢轴策略，
不能直接当作生产后端：需要持久实例、符号/数值阶段计时、失败处理、缩放和线性残差核对。
上一轮 AMD 排序在低压检查点达到 180 s 超时，COLAMD 约 4.150 s，故不再把 AMD 作为默认首选。

**L3：固定自由度消元及结构图精简。中高风险，先验证代数等价性。**
纯绝缘节点的两个载流子自由度在当前实现中被固定；按网格节点分类估算，
9036 个载流子未知量是待核查的消元候选，30723 维可能降至约 21687 维，再考虑接触约束。
实际数量必须由矩阵行结构和约束确定，不能直接根据材料标签删除自由度。
对于已知修正量 Δx_C，应解 `A_FF Δx_F = b_F - A_FC Δx_C`，再恢复完整向量。
固定行 RHS 不一定为零，参考势和缩放也必须保留。
被固定行可能本已很便宜，所以“维度少约 29%”不是速度提升估计。
同时可以审计按模型永远不使用的结构槽位；不能逐次 prune 数值零而破坏符号缓存和必要耦合。

**暂不优先：**冻结变化中的 Newton/Poisson 矩阵、近似复用旧 LU、未经结构条件检查换 LDLT、
直接调整枢轴门限。这些会改变数值方法。
本地 SparseLU 调用的是内部面板/矩阵内核；不能仅设置线程数或链接 BLAS 就声称该路径获得多核加速。
[Eigen 官方并行算法列表](https://libeigen.gitlab.io/eigen/docs-nightly/TopicMultiThreading.html)
也没有把 SparseLU 列为可直接通过 OpenMP 开启的并行算法。

## 2. Jacobian：现有缓存之外还有三类具体机会

普通 Release 中，边上物理 167.753 s（Jacobian 的约 57.74%），模式构造 67.162 s
（23.12%），节点源项 41.421 s（14.26%）。源码入口为
[CoupledDDAssembler](../../src/equation/CoupledDDAssembler.cpp)。

**J1：共享 SRH/Auger 复合状态，先做。**
节点源项先构造 `srhState` 和 `augerState` 计算导数，随后调用 `nodeRecombinationRate`
重新构造相同输入的复合状态计算复合率。
`generalizedSrhCarrierState` 内部对电子、空穴分别求逆 Fermi–Dirac，重复成本并非几个乘法。
该节点阶段记录约 2.193 亿次 Fermi half 和 6364 万次 inverse Fermi half 调用。
可以引入一次节点评估结果，在同一状态下供复合率、导数和诊断消费。
当前量子关闭，SRH 电子密度与输运密度还有合并机会；必须比较实际输入并保留
`sentaurus_default`、量子密度耦合和经典 Auger excess-product 分支，不能在所有模型中强行合并。
同一改动也可以帮助残差的复合源计算。

**J2：按需生成固定散布表，先做。**
`rebuildFixedJacobianPattern` 每次无条件构造 `fixedJacobianAvalancheScatter_` 和
`fixedJacobianCellScatter_`。本算例雪崩和 element-QF 电流关闭，实际相应消费路径没有执行。
其中单元表每次初始化 19782×81=1602342 个槽位，213 次进程内重建都会付出成本。
建议依照实际消费路径惰性构造，保留模式本身、贡献顺序及缺槽报错。
**不能按名字删除 `avalancheStencilNodes` 或向量梯度灵敏度：vector-QF 高场反馈也使用这些数据。**
本算例中的无用表只占模式构造的一部分，不能把全部 67.162 s 作为可节省时间。

**J3：进一步减少边上扰动计算和散布查找。**
当前 Fermi 输运通量对每种载流子的 4 个端点变量作中心差分，即通常 8 次扰动通量评估，
还有向量高场反馈及接触回退的附加贡献。端点缓存已经存在，命中 2.885 亿次、未命中
3.528 亿次，命中率约 44.99%；不能把“新增端点缓存”列为尚未实现的工作。
可将已知扰动组合整理成固定槽位，减少每次线性扫描 8 个缓存条目的查找开销；
进一步共享端点状态须包含真实浮点输入及相对参考势，不能只按节点 ID 跨边复用。
保持原中心差分步长、运算顺序、接触反馈和非端点单元顶点耦合。
向量高场附加顶点的散布仍可能回退到 `fixedJacobianOffset` 哈希查找，
可预存其索引；该函数 gprof self 为 13.96 s，不能把它当成全部 Jacobian 成本。

解析/自动微分替换端点中心差分是后续较高风险路径。
须完整覆盖 Fermi、BGN、量子、截断函数、零场、接触回退和参考势不变性，
并且区别“离散残差的正确导数”与“原有限差分近似值”。先完成复用优化再评估是否必要。

## 3. 残差：优先降低每次计算成本，再考虑减少试算次数

4528 次残差调用中，4312 次对应线搜索试算（约 95.23%），其余 216 次为其他调用。
1390 次线搜索中有 1284 次成功、106 次整轮失败；106 不是被拒绝的候选总数。
每次 residual 遍历 30022 条边，合计约 1.359 亿次边访问。
残差阶段还记录 5.301 亿次 Fermi half、1.037 亿次 inverse Fermi half 调用。

**R1：将已有边静态缓存复用到 residual/连续性诊断，先做。**
Jacobian 已使用 `EdgeAssemblyKernel` 的 Poisson 耦合、材料对数/漂移偏移及低场迁移率。
残差仍调用 `edgeEpsilon`、两次通用 `detail::edgeMobility`，并重新计算相同材料比值的对数；
连续性诊断也存在同类重算。通用迁移率路径还会访问相邻单元、区域和掺杂。
建议统一只读静态边数据，保持原表达式的浮点运算顺序；高场迁移率仍按当前状态计算，
表面迁移率启用时保留原回退，不能把状态相关场强或完整迁移率当作常量。
介电耦合、材料参数、温度、掺杂或模型变化时必须失效。

**R2：共享节点复合状态及候选密度，先做小范围复用。**
复合状态复用采用 J1 的同一机制，避免维护另一套物理公式。
线搜索先算 residual，其中已计算 n、p；随后 `hasPositiveFiniteCarriers` 又计算一遍 n、p。
可以让本次残差评估返回受同一状态绑定的载流子有效性，供验收读取。
必须保留非有限值、半导体正密度、绝缘体零密度的原判定；不能仅用 residual.allFinite 替代。
可以进一步在 residual、Jacobian、连续性诊断之间复用同状态的密度/梯度，但先限定同一次
Newton 求解上下文、完整输入逐位匹配，并隔离反馈替换、参考势平移和量子外循环。

**R3：减少不需要的动态准备。**
残差无条件构造完整物理参考系的 phinPhysical/phipPhysical 数组，
而当前边 SG/vector-QF 正常路径直接使用局部增量与参考势梯度。
可按实际模型需求延迟构造这些数组；保留雪崩、element-QF、电势反馈替换等消费者。
先给密度、梯度、边通量、复合源和边界处理补充分段计时，避免凭代码行数估计收益。

**R4：减少线搜索试算，作为独立数值策略实验。**
平均每轮约 3.10 次试算，可以研究上一轮阻尼作为初始猜测、预测器或其他受控策略。
但候选通常是不同状态，缓存整份 residual 不会消除这些试算；成功的残差已通过
`r = ls.residual` 复用，没有“每个成功步后再重复算一次残差”的通用浪费。
改变初始阻尼/推进策略会改变 Newton 轨迹，应独立比较总成本及原数值门限，不能混入逐位等价的缓存优化。
不通过减少参考点、放宽门限、关闭局部行/KCL 检查获得加速。

## 建议的执行顺序和验证

| 顺序 | 具体交付 | 原因与准入条件 |
| --- | --- | --- |
| 1 | 节点 SRH/Auger 状态复用（J1/R2） | 源码确认存在同输入重算；局部复用，验证率、导数、非平衡 excess product 与当前曲线一致 |
| 2 | residual/诊断复用静态边缓存（R1） | 复用已有实现，保留所有动态场和模型失效规则 |
| 3 | 雪崩/单元散布表按需构造（J2） | 减少当前进程启动后的模式准备，保证向量高场所需模板不受影响 |
| 4 | 固定矩阵回放及分解分组计时（L1），再选 L2 | 数值分解收益空间最大；先有同矩阵、同缩放的可解释实验，再接入胜出方案 |
| 5 | 扰动槽位/向量反馈索引预存、候选状态动态复用（J3/R2/R3） | 依据新增计数和分段耗时选择；不可跨参考势或模型误命中 |
| 6 | 固定自由度消元、解析导数或阻尼策略（L3/J3/R4） | 较高风险、可能改变轨迹，单独制定并验证数值接受标准 |

上述是分析建议，不是已执行修改或已验证加速。

每一项先在固定检查点上做预热及 ABBA/BAAB 普通 Release 对照，统计墙钟、CPU、阶段耗时、
Newton 更新、试算数、回退及再求解成本；然后仍只完成本次 8 个精确参考点。
缓存/按需准备类改动优先要求 108 个接受状态逐位一致、原轨迹和全部门限不变。
后端、排序、消元或导数变更允许研究不同舍入/轨迹，但须单独报告，检查实际未缩放方程
`A Δx-b` 的归一化线性残差、局部行、KCL 和参考曲线误差，不能仅看 solver.info()。
相关实现必须增加或更新数值性质测试（Fermi/BGN、vector HFS、接触回退、参考势/量子失效），
共享线性接口变动还需完整 Release CTest。原门限不因性能实验而放宽。
