## report 的独立算术原语

新增 [UpdateErrorReport.h](../../include/vela/solver/experimental/UpdateErrorReport.h)，仅有 off/report，默认 off。
调用者显式提供各行变量、单位、更新类别所对应的分母状态及活动掩码；
原语按活动行数合成 RMS、保留逐行归一化贡献、方程计数和最大贡献节点。
它不接收求解器回调或可变装配器，不计算 Newton 方向，不参与接受判断。

无效更新、无法表示的值和 no_accepted_update 不生成伪零误差；
下溢造成非零更新退化为零时标为无效，不静默裁剪。
使用缩放平方和避免大有限贡献平方溢出，分母求值也避免 abs(x)+ErrRef 溢出。

[性质测试](../../tests/test_update_error_report.cpp)覆盖计数加权、接触单独计数、默认关闭、
固定分母切向线性性、有限负向人口上界与切向反例、无效／拒绝步、极值和下溢，
以及实际 Fermi 人口函数在同时改变 psi 与 QF 的三档方向导数。
该测试只验证人口函数原语，**不代表已核实完整装配器的所有状态依赖和分支**。
不将这些单元检查称为 NewtonResult／轨迹开关逐位一致硬门。
前端 W201、生产配置解析和模板均未改变；用户 JSON 暂不能启用完整 report 功能。

验证：Release 构建成功，新增 5 项 Catch2/CTest、31 条断言全部通过，包含下溢反例。
本轮未运行全量 Debug CTest；这些原语没有接入求解循环，不能以单元测试替代后续完整硬门。
