# SLOT 重复正性投影与迁移率导数恢复对照（2026-10-13）

## 范围与当前结论

用户授权使用本机与 T470p 验证改进建议。本批固定 Vg=5 V、Vd=6 mV，
从同一零漏压父态的热启动种子出发；未启动新偏压扫描。

1. 原更新流程会在 R/U 已达标时保留大量重复空穴正性投影。不能把这种停止解释为
   低密度场量已恢复，也不能仅凭总 Id 近似不变排除其影响。
2. 简单的“投影后按住、原始方向转正即释放”活动集并未解决问题：释放后重新
   求解会再次给出负人口提议，形成释放/再投影循环。
3. 在首步后的冻结态，6220 的负自身导数与原物理残差的中心差分吻合；输运项
   主导该负导数。仅略去输运 Jacobian 中迁移率对 QF 梯度的直接链式导数，
   能使该对角和方向翻正，且原残差/RHS 逐位不变。
4. 这一非精确 Newton 方向在短程连续重线性化中恢复了空穴人口。它仍是明确标记的
   诊断选项，不修改生产默认，不把诊断末态自动纳入生产父态历史。

本批不以固定 QF 盒作为物理定理；不修改 R/U 阈值，不取消线性、正性、逆映射、
保存态一致性保护，也不以活动集约束后的方向计算“变小”的 U。

## 冻结态导数：局部机制已得到直接验证

固定 A 第一次更新后的状态、完整原物理。略去迁移率的直接 QF 梯度链后：

- 137条负空穴对角全部转正；原残差和 solve RHS 逐位相同。
- 矩阵变化仅涉及载流子 QF 列，ψ 列变化为0；源项 AD、人口与 ψ 链保留。
- 负空穴人口方向数从3426降至2919，不能把对角转正等同于全系统方向恢复。

因此**此状态、此节点**的负导数是原非线性输运响应，不是符号编码错误；不能
据此宣称所有负对角、全部原生/Vela差异或所有偏压失败都已解释。

## C：不改残差的有界重线性化

每步保留原系统装配、原方向及U，另装配仅省略直接输运迁移率QF梯度链的矩阵。
两套残差及RHS逐位核对，两次线性求解均须通过现有混合误差保护。
这属于非精确Newton，不是冻结非线性迁移率，不改HFS物理或电离源。
