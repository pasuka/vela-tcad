# PN2D 零偏分阶段对照：Poisson → 联立求解（2026-10-23）

## 结果

按用户指定顺序复核后，**在材料参数和物理常数相同的诊断条件下，独立初始化的
Vela 与 Sentaurus 零偏终态一致**。先前直接冷启动联立的控制保留为额外压力测试，
不再将它混作正常 Poisson 初始化后的结果。

| 比较阶段 | 电势最大绝对差 | 电势 RMS 差 |
|---|---:|---:|
| 各自独立求解的纯 Poisson 终态 | 9.96398e-9 V | 4.26385e-9 V |
| 各自从 Poisson 终态进入联立阶段后的终态 | 1.55431e-15 V | 8.12885e-16 V |

联立终态电子/空穴浓度的最大相对差分别为 **8.45e-14 / 8.37e-14**。
这些结果属于零偏平衡点，不提供有限电流、有限 Newton 更新或非零外压资格。

## 输入与阶段身份

- 同一 PN2D：1943 节点、3680 三角形，300 K，Anode 外压 0 V，Cathode 接地，
  外电阻 1e7 Ω·μm。网格 SHA-256 为
  `920b55f739477e37154aa7d33af5db08bded38377d675172a6f77c7027e8d287`。
- Sentaurus 沿用已经退出码 0 的专用零偏任务：先 `Coupled { Poisson }`，再两次
  `Coupled { Poisson Electron Hole }`。debug index 0–4 为纯 Poisson 的五次线性求解；
  index 5 是第一轮联立更新前的状态，即 Poisson 的实际终态；最终 TDR 是两次联立调用后的状态。
- Vela 使用原输运/原切线实现的归档核心库，未使用前轮实验性的高场候选或混合切线。
  链接 map 确认 NewtonSolver 和 CoupledDDAssembler 均来自该基线库，实验核心库的
  对象引用数为 0。两侧常数使用前轮已说明的原生旧常数隔离层。
- 主控制使用从原生材料字段计算的材料 oracle；它只统一材料输入，没有导入原生电势、
  电子/空穴人口或非零态来启动 Vela。原材料作为另一个独立控制保留。
- 全部既有物理模型保持：总杂质迁移率、高场饱和、OldSlotboom、SRH 和 VanOverstraeten。
  Vela UCRT64 Release、单线程、UMFPACK 显式选择，HDF5/UMFPACK 已检测。

Vela 的独立主序列为：构造自身 cold initial → `solvePoissonOnly` 迭代至原门限 →
以该解作为完整设备/电阻增广系统的初值，在 0 V 求解。另做固定内压的设备联立复闭合控制。
输出的冷初值和两阶段终态均保留，没有以“导入原生同态后装配”替代独立求解。

## 阶段 A：纯 Poisson

纯 Poisson 的独立未知量为 1943 个电势。电子和空穴仍按固定 QF 下的 Boltzmann
统计关系随电势变化，因此电荷项包含 `dn/dψ`、`dp/dψ`。没有把人口冻结成常量，
也没有将原生人口坐标联立 Jacobian 的电势子块直接冒充纯 Poisson Jacobian。

Vela 以原 `abstol=1e-9`、`reltol=1e-8` 完成六次 Poisson 更新，最终残差 L2 约
`3.62e-13`。在原生纯 Poisson 的三个指定状态上，固定 QF 后作独立装配比较：

| 原生纯 Poisson debug index | Jacobian 最大行相对 L2 差 | RHS 差 L2（自身对角归一化） |
|---|---:|---:|
| 0 | 6.77e-15 | 2.18e-13 |
| 1 | 9.74e-15 | 1.05e-12 |
| 4 | 9.21e-15 | 9.79e-13 |

原生从 Poisson 终态到最终联立终态的电势最大变化为 `9.96399e-9 V`，与两侧
Poisson 终态的差几乎相同；Vela 的 Poisson 结果已经与原生最终联立电势吻合。
这支持将约 10 nV 的阶段 A 差异归于两边停止语义/精度不同，不能要求相同迭代次数。

## 阶段 B：从各自 Poisson 结果进入联立系统

Vela 将自身 Poisson 解送入真实设备/电路增广系统，外压 0、R=1e7 Ω·μm。
初始完整设备残差约 `2.24713e-14`，已低于既有 1e-8 标量门；内压、电流和负载残差
均为 0，所以 **接受发生在迭代入口，Newton 更新次数为 0**。
固定内压的设备联立复闭合也以 `initial_abstol` 在入口接受。

原有载流子行门和全局连续性门未放宽。此平衡态中全部 3886 个载流子行低于资格
下限，qualified count 为 0；全局闭合的两类载流子也未进入有限流资格。
所以它验证了零偏状态和入口接受，不能代替有限 RHS 更新、逐分量线性闭合、
实际方向写回或大电流电阻反馈的测试。

## 材料对照仍需保留

相同旧常数下，原材料控制也独立完成了 Poisson 和联立入口接受，但仍有偏差：

| 原材料控制 | 结果 |
|---|---:|
| Poisson 终态电势最大差 | 6.90110e-6 V |
| 联立终态电势最大差 | 6.90110e-6 V |
| 联立终态电子/空穴浓度最大相对差 | 5.33751e-4 / 5.33751e-4 |

因此，先收敛 Poisson 能明确拆开问题，但不能自动消除材料换算差异。
主控制的吻合仍以材料和常数已对齐为前提；本轮没有将材料 oracle 宣称为已完成的
生产材料转换器修复。

## 当前入口的初始化设置

源码已经支持 `sweep.initialization.poisson_max_iter`：

```json
"initialization": {
  "mode": "poisson_block",
  "poisson_max_iter": 80
}
```

该预算默认 **0**，表示旧的单次 Poisson 块更新；只有正数才执行完整非线性 Poisson
初始化。当前 PN2D 模板仅有 `mode: poisson_block`，不能仅从该名称推断已经迭代收敛。
本轮探针显式执行完整 `solvePoissonOnly`，没有修改全局默认或暗中放宽门限。
后续正常顺序的验证应明确使用完整 Poisson 初始化；直接冷启动联立的尾部问题仍作为
单独诊断记录，见[高场跟进](pn2d_zero_hfs_followup_2026-10-23.md)。
