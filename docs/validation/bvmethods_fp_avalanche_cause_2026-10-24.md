# BVMethods 首轮空穴 QF 大方向：碰撞电离源定位（2026-10-24）

对[共同范数报告](bvmethods_common_norm_updates_2026-10-24.md)首轮峰值继续分解，已经确认：**节点 1546 的伏特级空穴方向主要由 RHS 中的电子碰撞电离源驱动**。SRH 和迁移率高场导数控制均不能消除它。

对象仍为相同冻结初态：2600 节点/5020 三角形，300 K，R=1e7 Ω·μm，首个外压目标 0.01 V，但更新前内压约零。原版同名物理、完整碰撞电离、Band2Band 关闭；UCRT64 Release，direct_bordered/Eigen SparseLU。十组进程均退出 0，均只提取一次 Newton 方向；不是完整扫描验收。数值与验证见[JSON](bvmethods_fp_avalanche_cause_2026-10-24.json)。

## 先纠正峰值比较的含义

原表两侧分别取各自全局峰值，约 1913/4.913=389 倍，峰值位置不同。在**同一个节点 1546**，Sentaurus 共同 FD 口径下 δfp=0.609601 mV，Vela 为 1913.280 mV，相差约 3139 倍。

节点 n≈1.19745e20、p≈265.731 cm⁻³。空穴非简并，局部切线近似为 `δfp=δψ+Vt·δp/p`。原生 δp/p≈0.02358，Vela 原始方向对应 δp/p≈74.01。因此大方向不能用“换算单位不同”解释；同一少子人口对源项和方向非常敏感。实际迭代随后受到 0.1 V 限幅。

## RHS 与 Jacobian 的贡献

在此前 6765 维共同电压坐标和行归一化下，固定 Vela Jacobian：

| 节点 1546 的方向 | δfp / V |
|---|---:|
| Vela 自身 RHS | 1.913280415 |
| 换入原生 RHS | 0.000871837 |
| 原生原始方向 | 0.000609601 |

按 `δV−δS = AV⁻¹[(bV−bS)−(AV−AS)δS]` 分解，RHS 差贡献约 **1.912408579 V**，Jacobian 差贡献约 **0.000262235 V**；重建绝对缺陷约 3.82e-11 V。该归因采用 Vela 作为参考矩阵；这是冻结线性系统诊断，不是非线性策略或算子资格。不同 RHS 块存在强抵消，不能将单块的巨大中间贡献独立当作物理误差。

## 空穴弱行由什么组成

以下均为相同装配器残差单位，不能直接比较不同求解器的原始单位：

| 节点 1546 的分项 | 有符号值 |
|---|---:|
| 空穴输运 | +4.38858844e-20 |
| SRH | −2.48187376e-23 |
| 碰撞电离 | −3.45357451e-13 |

碰撞电离项绝对值约为输运净项的 **7.87e6 倍**。它在绝对量上很小，但相对于此处约 266 cm⁻³ 的少子输运和切线很大，因而提出伏特级 QF 方向。

| 单独诊断控制 | 节点 1546 δfp / V | 该处碰撞电离残差 |
|---|---:|---:|
| 原配置 | 1.91328075 | -3.45357451e-13 |
| 关闭 SRH | 1.958320014 | -3.45357451e-13 |
| 关闭碰撞电离 | 2.020674269e-06 | 0 |
| 冻结迁移率场导数，仅改 Jacobian | 1.920607289 | -3.45357451e-13 |
| 饱和速度设极大，保留表面迁移率 | 1.915323164 | -3.45425184e-13 |
| 只关闭电子电离系数 | 2.020674269e-06 | -2.65130417e-37 |
| 只关闭空穴电离系数 | 1.91328075 | -3.45357451e-13 |
| 改为单元 QF 梯度驱动 | 2.020674269e-06 | -3.9147877e-307 |

只关闭电子电离系数即可消除异常；关闭空穴电离系数无效。因此是**电子电离产生的电子–空穴对，进入了空穴连续性 RHS**，不是空穴电离本身主导。关闭 AV 后全部节点的最大空穴方向约 4.328 mV，恢复到与原生相同的毫伏量级，但个别节点仍未数值对齐。

## 上游链条：导入态电流与接触邻域驱动场

匹配原生 ψ/n/p 后反解得到的 Vela QF 并不平坦。节点 1546 的 fn≈−1.0974 µV、fp≈−2.0259 µV，邻近接触节点存在更大的偏移。Vela 由此得到 drain 电流约 **−1.2793e-5 A/μm**，而原生对应零偏初态电流接近零。

将 Vela 输入 QF 统一置零的平衡态控制中，输运、SRH、碰撞电离以及端口电流均归零。这个控制会改变人口：最大电子约 0.109%、空穴约 0.592%；不能把它说成相同人口下已经修复，也不能据此认领导入等价。更换已导出的 Nc/Nv/ni 本身仍不能消除原先的异常。

碰撞电离还有接触邻域的驱动场替代分支：`edgeHighFieldDrivingField` 在边属于接触邻近单元时返回电场，而非 QF 梯度。AV 的 `edgeQuasiFermiCoefficientField` 调用该分支；`cell_gradient` 则使用单元 QF 梯度。在边 1546–2567 上，电场约 **5.319e4 V/cm**，电子 QF 梯度仅约 **1.075e2 V/cm**。Van Overstraeten 电离系数对驱动场呈指数敏感，这个差别足以使后一种系数近乎零，而前一种非零。

以上两项共同构成当前已验证链条：**导入原生人口后，Vela 的本构/输运没有将其解释为相同平衡态，产生非零电子电流；接触邻域电场替代激活电子电离；产生的空穴源压过极弱少子输运，提出巨大 δfp。**

源码定位：`include/vela/equation/AssemblerUtils.h` 的 `edgeHighFieldDrivingField` 与 `edgeQuasiFermiCoefficientField`。单元梯度控制同时改变梯度恢复和旁路接触电场替代，仍不能单凭这一控制认领“只去掉 fallback 就完成修复”。非平坦重建 QF 的具体本构公式来源也尚未唯一隔离。

本轮仅进行来源诊断。BV 修复应保留碰撞电离，分别对齐平衡态本构/电流、接触邻域驱动场及其 Jacobian，然后重新运行自身迭代和 BV 验证。上述结果针对导入同态回放，不能直接声称是此前 Vela 自身扫描的唯一阻塞原因。

## 验证

十组独立单步控制退出 0；基线复现此前原始方向。所有检查节点的分项和复现完整空穴残差；电子/空穴电离系数分离、零 QF 的源项观测、共同线性分解一致。平衡态源项观测发生在线性求解前；其中一组材料/零 QF 控制的线性逐行后向误差约 8.3e-7，未用其方向认领线性精度通过。完整原始输出、配置、源码、Release 二进制与哈希保存在 ignored `build-release/bvmethods_fp_cause_20261024/`。
