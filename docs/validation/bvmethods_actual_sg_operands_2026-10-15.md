## 记录身份与单位

私有只读记录覆盖目标弱行所有非零边：电子五条、空穴四条。
另外三条唯一边的两个相邻单元系数均为零，没有进入活动迁移率分支；
其原生样本和网格支撑仍保留。原生覆盖仍是全部 24 条元素边／12 条唯一边。
每条活动边在 residual 和分项装配中记录的人口、QF 参考／相对值、ψ、系数及电流逐值相同。
边电流求和再归一化后复现目标实际 residual，最大相对差低于 2e-14。

关闭新记录的私有 runner 逐字节复现旧 rows.csv；开启记录也逐字节相同。
最终批输入 JSON 和完整 H5 状态的前后哈希相同，包含接触 reference/increment，
没有为闭合弱行改接触、人口或 QF 文件。

实际对象输出：人口内部单位为 cm^-3（每内部单位为 1e6 m^-3），长度内部单位为 um。
`C0=5.08999999999998230528e20`、`D0=36.6322836973791581272`；
原始打印 RHS 转入本 Vela residual 约定的系数独立为
`Nref × 1e4 / (C0×D0) = 7.9504903189181256e-9`，并取 RHS 的负号。
该值使用上轮原生参考量及本轮实际 C0/D0，不由目标行反算。
这些是归一化 residual，不标作终端 A/um 电流。

## 原生逐边电流与 Vela 系数

在本固定态实际调用路径，令 `a` 为采集的 Bernoulli 参数，`N` 为原生内部人口，
`c=−1` 表示电子、`c=+1` 表示空穴。独立 Fraction 模拟得到：

```
f = round80(round80(Ni × B(−a)) − round80(Nj × B(a)))
J_without_mu = c × f × Lref_um / edge_length_um
```

使用实际函数返回的 B 值和独立几何长度，24/24 个电流重建通过，最大相对差 7.13e-16。
三项 ties-to-even 自检、24 项交换端点／Bernoulli 值后的反向差分符号检查通过。
参数 a 已包含原生统计／带边路径；本结果没有自主生成 a，也没有证明统计模型全局一致。

对 Vela 九条活动边：实际人口与原生人口换到相同单位后最大相对差 6.12e-17；
实际 `coef/(Vt×1e4)` 与相邻单元 κμ 之和的最大相对差 1.04e-15。
在这两条弱行及冻结迁移率配置下，没有发现新的几何／迁移率系数余差足以解释原差异。
此结论不覆盖其他节点、动态迁移率导数或源项。

## 实际装配中的固定输入控制

只替换目标节点相邻活动边的电流求值，同时接入 residual 和分项装配；
使用 Vela 原有几何、迁移率、行归一化和边方向。表中为实际目标 residual 相对原始
打印 RHS1 换算值的误差，没有修改验收门限。

| 实际装配控制 | 电子 2156 | 空穴 2515 |
| --- | ---: | ---: |
| 原私有 QF 平衡 SG | +1.566724680e-4 | −4.732694170e-4 |
| 原生人口／B，binary80 逐次乘减 | −7.148270673e-15 | −2.768654669e-15 |
| 原生归一化人口先舍入 binary64，B 保留 binary80 | +1.657217352e-3 | −4.157223835e-4 |
| 同一原生人口／B，100 位乘减 | −7.802036706e-7 | −2.602930201e-6 |
| 原生人口／参数，100 位重算 B 及乘减 | −7.636850449e-7 | −2.602111236e-6 |

原私有 SG 的同输入 Decimal100 对照延续上轮结果：电子变化约 −2.07e-25、
空穴约 −4.8e-28（本 Vela residual 单位），未消除原差异。
因此“把当前内核全部提高精度即可复现原生”不成立。

binary64 控制舍入的是原生归一化人口，再换到 Vela 单位；它与 Vela 现有物理人口
的舍入位置不同，不能把该控制误差直接当作生产 Vela 的人口误差。
同理，100 位乘减相对原生 binary80 结果存在微小差异，不说明高精度数学值本身错误。

## 驱动余差的定位

原私有 SG 从实际 QF 增量构造平衡指数 δ；原生的相同指数可在诊断上由
`δnative = a − log(Nj/Ni)` 表示。后一式使用已采原生参数／人口，属于诊断恒等式，
不是可用于近零电流生产实现的稳定自主算法。

九条活动边的 δ 差处于约 7.0e-20 至 8.62e-18。例：

| 有向边 | Vela QF 指数 δ | 原生参数／人口的有效 δ | 差值 |
| --- | ---: | ---: | ---: |
| 电子 1553→2156 | 6.217248938e-13 | 6.217270473e-13 | −2.153492233e-18 |
| 空穴 2514→2515 | −1.332267630e-14 | −1.332889050e-14 | +6.214209112e-18 |
| 空穴 2515→2517 | 1.909583602e-14 | 1.910446005e-14 | −8.624026435e-18 |

这些极小绝对差作用于近抵消的电流；不能以人口／系数约 1e-16 的相对一致，
推断弱行也应达到同样相对误差。原生 80 位乘减控制闭合两行，说明本批弱行差已定位到
有效驱动及数值表示／求值路径，尚不足以认定为新增物理模型不一致。
原生带边、统计字段如何自主生成该参数的完整精度链仍待验证。
