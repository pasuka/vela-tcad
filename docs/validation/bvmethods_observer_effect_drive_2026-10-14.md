## 四个 RHS 变化的触发条件与采集修正

所有控制保留旧 `bv_field_observer` 零源回调，再增量加入新零源回调。以下比较均为原生基准
首态的全部打印变量/RHS1；最大末位变化 1.9852334701272664e-22（原生 debug 单位）。

| 新回调操作 | 完整 RHS1 与旧基准 | 变化 |
|---|---|---|
| 不读状态；仅记录 Input 人口 | 一致 | 无 |
| 只读 ψ；只读 DOS；只读带边 | 一致 | 无 |
| 单独读电子 QF；单独读空穴 QF | 一致 | 无 |
| 同一回调读取电子、空穴两个 QF | 不一致 | 四个空穴行 |
| 完整字段正序/逆序读取 | 不一致 | 相同四个空穴行 |

变化仅涉及 hDensity 节点 318、405、424、425。两条目标弱行 2156/2515 没有变化，
故这四项观察器效应不能解释现有弱行重建余差。具体 SDK 内部缓存或浮点实现根因未证明，
不能只凭这些控制断言某一内部机制。

修正方案将两种 QF 的采集拆到两个独立原生进程：电子进程省略空穴 QF，空穴进程省略
电子 QF；两边均保留人口、ψ、DOS、带边和旧零源回调，不改物理模型。两进程各执行基准、
电子 ±1e-12 V、空穴 ±1e-12 V 五个 Load 首态。

T470p 复核十个系统的全部打印变量和完整 RHS1，均与原始对应基准逐值一致。
两路的公共字段也与此前采集值逐字一致，单独采到的 QF 与原双 QF 采集值相同。
因此，本轮解决了采集身份项；返回的标量相同，仍不足以证明原组合读取没有装配影响。

## 人口末位差异的独立解释

五个首态原先均有一个空穴人口在“21 位文本直接转 binary64”时与 TDR 不同。
T470p 用独立 C++ 程序先恢复 binary80，再转换 binary64，全部 n/p 与 TDR 逐值一致。
差异在节点 2068，文本 `601.33840458302273646`：

```text
恢复 binary80：0x9.655a86bb2398cp+6
文本直接转 binary64：601.3384045830227
binary80 再转 binary64：601.3384045830228  = TDR
```

这是转换顺序造成的末位舍入差异，不是人口状态或材料差异。前期状态匹配中容许的一个
binary64 ULP 只是识别候选块的控制；最终人口身份已通过原精度恢复逐值核对，没有放宽弱行门限。

## 原生参考接口与非零方向

单独导出原生登记的 `eQuasiFermiEnergy`、`hQuasiFermiEnergy`，全部 2152 个 Si 节点均满足
能量值等于对应 QF 的负号。这两个字段是等价参考，不能当作独立内部 η 或 SG 驱动接口。

T470p 对五个保精度状态的 18 个唯一人口/DOS 比值执行独立定义积分反算；未调用 Vela
统计近似。积分相对误差估计最大约 2.12e-42。Decimal 90 位独立形成带边项与统计项。
拆分采集的公共输入逐字一致，原积分结果可复用；用拆分 QF 又独立重算了实际 SG 控制。

| 非零控制，按请求 ±1e-12 V 的中心响应 | 电子相对原生 | 空穴相对原生 |
|---|---:|---:|
| 独立带边＋η 重建 | −4.20e-9 | +1.37e-9 |
| 拆分采集的 QF 边差重建 | −1.15e-8 | +5.28e-9 |

请求幅度与实际采集 QF 变化分别记录，没有把它们强行设为相等。实际两端 QF 变化约
1.99999994288e-12 V / 1.99999996530e-12 V；该节点的 DOS 与带边在正负臂保持不变。
独立 η 的驱动增量与实际采集 QF 增量差约电子 +7.33e-9、空穴 −3.91e-9（相对量）。
热电压仍采用单列的历史常数指纹；由响应得到的温度电压只作诊断观测，不用于修正残差、
拟合常数、改默认或建立新验收门限。本轮没有独立取得原生内部 SG 有效驱动。

近零基准仍不通过：拆分 QF 重建电子差 −0.0125170%、空穴差 −0.0473269%；
带边＋独立 η 基准仍差 −25.6429% / +0.00711312%。非零方向接近不能代替近零值或全系统资格。
所选首态的 ψ、DOS、带边转 binary64 均与对应求解前 TDR 一致；基准 QF 返回值与 TDR 有
约 1e-19 V 的绝对差，零附近不使用 binary64 ULP 比值解释大小。
