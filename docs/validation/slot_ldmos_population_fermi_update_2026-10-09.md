# SLOT 同态人口更新与 Fermi 逆映射对照

日期：2026-10-09。证据目录：`build/s09population_map/`。

## 结果

人口有限更新能够改善 10849 的空穴恢复及 Poisson 自洽，但**本批不能接受为恢复步骤**：全人口更新新增 4376 条空穴超标行，总超标行从父态 8332 增至 9431；原始 22 条失败空穴行无一通过。缩为四分之一步、仅替换空穴更新均未解决此问题。

没有修改物理、生产限幅或最终门槛；0 次 Newton 接受更新，0 个新增完整合格点。四个冻结探针均成功，累计 39.09 s，执行脚本墙钟 45.37 s；没有启动后续非线性恢复或长扫描。

## 同态与配置

起点为上一批 `s09second_step/two_updates/progress/iteration_1.h5`：Vg=5 V、Vd=0.006 V 的首个接受 Newton 迭代态，**该父态本身未合格**。所有试探从同一父态及其同一稳定化线性方向产生，没有导入原生人口或更换初态。

网格 13881 节点；每种载流子有效行 12634。电压原点 0 V。冻结求解器仍为 `build/s09gate_resume/runner.exe`，沿用其 AverageBox、配套体积、Fermi、Bennett–Wilson、完整目标物理及接触电离回退。已有方向来自 UMFPACK 解出的稳定化系统，正则化 1e-8 及闭合替换不变。
abstol=1e-9、reltol=1e-8、eps_row=0.001、闭合 0.01、QF 最终资格均不变。

本批编译的 `fermi.exe` 只是链接当前 `CarrierStatistics.cpp`、`Material.cpp` 的统计函数计算器，不是新求解器。冻结求解器对试探态重建的人口与目标一致性另行验证，避免把当前源码与冻结二进制直接视为相同。

## 变量变换与有界更新

令 F 为代码中的 Fermi–Dirac 半阶积分，ηn=F⁻¹(n/Nc)、ηp=F⁻¹(p/Nv)，gn=F′(ηn)/F(ηn)、gp=F′(ηp)/F(ηp)。300 K 下 Vt=0.0258519997864 V。

同一原始方向转换为相对人口方向：

```
yn = δn/n = gn (δψ − δφn)/Vt
yp = δp/p = gp (δφp − δψ)/Vt
```

这是当前同态、固定温度及材料参数下的链式变换。对有效行构造变换 T，保留边界/规范未知量原坐标，验证 `S T y = rhs`。原稳定化矩阵 S 的正则化一起变换，**没有在密度坐标中重新定义正则化，也没有实现新的密度 Newton 求解器**。
变换后的全局相对线性残差为 7.61e-15，重建原始 QF 方向最大差 2.27e-13 V。因此仅改变线性坐标不会把 10237 的负人口方向自动变成正方向。

有限试探采用：

```
q* = q × clip(1 + α yq, 0.01, 100000)      q 为 n 或 p
ψ* = ψ + α δψ
δφn* = α δψ − Vt [F⁻¹(n*/Nc) − ηn]
δφp* = α δψ + Vt [F⁻¹(p*/Nv) − ηp]
```

保留分离的 QF 参考量，更新增量字段。固定掺杂下内禀参考项在差分公式中相消，不以 Boltzmann 公式代替 Fermi 逆映射。
试探额外限定 |δQF|≤0.35 V、|δψ|≤0.001 V。任何超限即停止该试探，不静默放宽；实际最大 QF 变化 0.26275 V，人口上限未触发。
0.01 正性下限仅为本批显式诊断策略，不是生产默认，更不是最终资格变更。

四臂为：

- `qf_cap_existing`：上一批实际第二步，现行分量限幅及 Poisson 重修正，作为对照。
- `density_both_1`：电子和空穴均按上式更新，α=1。
- `density_both_025`：同上，α=0.25。
- `density_hole_1`：只替换空穴更新；电子保留现行限幅方向，ψ 使用原始方向。

人口臂不另做 Poisson 重修正，真实 ψ 残差作为评价项。对照臂的重修正改变 ψ 方向最多 7.89e-10 V；因此各臂并非只改一个标量 cap，而是明确比较两种有限更新策略。

10849 的相对人口方向为 +25549.8，人口有限更新将其恢复到 1.61e12；通量项由现行第二步的 0 变为 +2.773e-7，对应电离项 −2.441e-6，开始形成部分抵消，但仍远未平衡。不能仅凭人口更接近原生值认为该点通过。

## 新增失败行的范围

全人口 α=1 的 4376 条新增空穴失败行：Si 4048 条，多晶硅 328 条。1912 条原始人口方向为正、2464 条为负，**没有一条自身触发 1% 人口投影**。因此不能把新增失败全部归因于本行正性截断。

按 |净通量|、|复合项|、|电离项| 中最大项分类，4290 条由净通量主导、86 条由复合项主导，电离项主导为 0；这是项幅值分类，不是因果分解。
新增失败的父态人口跨 1.249 至 2.174e20 cm⁻³，范围并不限于极低密度。新增行比中位数约 0.03181，90% 分位约 0.84678，只有 18 条处于 1e-30 尺度下限，不是单纯舍入噪声现象。
这些事实支持进一步检查更新空间不一致和邻接通量传播；尚未单独分离 SG 与 HFS 的责任。

## 判断与下一步

本批证实：Fermi 人口有限更新可以在有限 QF 幅度内实现大人口恢复，并保持更好的 Poisson 自洽；但沿原稳定化方向全域应用，仍破坏大量健康空穴行。单纯改坐标、正性投影或四分之一步不足以构成可用恢复策略。

下一步应保留本批人口映射，**比较带真实邻行保护的连通子域人口更新**：覆盖 10849 及受影响邻域，同时针对 10237 的负方向做耦合重求，避免把两种机制用同一人口投影处理。需逐次重算原物理残差、全部行与闭合；只有实际质量改善才允许少量恢复更新。此建议未在本批自动实施。
