## 配置与证据边界

安装库原版BVmethods，300 K、默认人口统计、普通精度、Fermi、OldSlotboom、NonLocalPath、
GradQuasiFermi及外电阻。沿用2600节点／5020个Tri3网格，其中Si为2152节点／4156单元。
原生保持完整`Load → Plot → Coupled(Iterations=1)`顺序，冻结首个正偏置态；
两次最终采集均退出0，完整变量、RHS1和Jacobian与既有首轮系统逐值相同，操作数重复一致。

本机Windows UCRT64 C++20，私有探针使用`-O1 -DNDEBUG -ffp-contract=off`，
HDF5及已检测SuiteSparse链接依赖保持；本轮只重算实际残差，没有线性求解、Newton或QS更新。
T470p/C560未使用。源接口为m、m^-3，核心几何为um、人口为cm^-3，二维端电流为A/um。
归一化人口与物理人口的单位转换独立核对；残差与求解器RHS的符号分别处理。

本轮只增加私有诊断、对照与文档，没有修改生产模型、公开前端、发行包、原版物理配置或固定预算。
原始商用数据、反汇编、采集地址、实际机器和作业记录、失败尝试均封存在ignored
`build-release/bvmethods_nearzero_sg_20261017/`，不进入公开源码或报告。

## 原生绝对输运支撑

两个弱行各捕获6次实际单元装配，每行包含12项逐边贡献、合并为6条支撑边。
36项实际边乘积还包括这些单元中不直接连接目标节点的边，可独立检查完整局部三行。
所有局部加法与外层节点加法逐值重建；加上实际源增量后，装配残差与打印RHS1按负号闭合。
该符号转换由连续性方程后处理独立确认，不是用误差拟合出的修正。

| 首点弱行 | 闭合误差／原生绝对输运项与净源增量 |
| --- | ---: |
| 电子2156 | 1.69e-17以内 |
| 空穴2515 | 3.73e-19以内 |

这里的原生分母为实际执行的逐边乘积绝对值之和，加各次**净源增量**的绝对值。
它是保守支撑下界；尚未逐项拆开同一次源增量内部的SRH／雪崩／非局部源，
因此不宣称全源绝对分解或其他状态的原生完整分母已取得资格。
原有Vela真实绝对装配项分母继续保留，不能换分母掩盖失败。

## 人口、有效参数和舍入的隔离控制

最终捕获24组普通双精度SG生产操作数，覆盖12条唯一边及重复单元身份。
Bernoulli输入、输出、人口、乘积相减和除以边长的返回均绑定；
24组SG参数可从采集到的温度、DOS、带状态差和统计修正操作数按原顺序逐值重建。
这仍使用了原生中间操作数，不能替代自主带状态／统计参考生成。

Plot电流入口的直接输出与PDE装配消费的电流具有不同尺度和系数，不能直接比较二者数值。
本轮通过固定Vela几何／迁移率／单位映射，将该组SG括号接入**实际输运装配**，
再与RHS1中的逐边贡献独立对照：九条非零合并边的最大误差／原生绝对边项为1.19e-15。
零权重边保留在原生账本，未用其零贡献掩盖缺失。

| 实际装配控制 | 电子2156误差／原Vela绝对项 | 空穴2515误差／原Vela绝对项 |
| --- | ---: | ---: |
| 既有自主QF稳定表达式 | 3.62295e-6 | 2.17934e-1 |
| 导入原生人口／Bernoulli，双精度乘积与相减 | 1.62176e-16 | 3.36040e-16 |
| 同操作数，仅乘积与相减改为扩展精度 | 9.67427e-8 | 6.04349e-4 |
| 同Bernoulli，人口改用Vela冻结人口归一化 | 1.62176e-16 | 3.36040e-16 |

固定弱行门仍为1e-8。使用当前实际Vela分母或上述原生保守支撑分母，双精度导入控制也通过，
扩展精度控制仍失败。七次本机实际装配均退出0，Poisson、SRH、雪崩、NonLocalPath双源、
边界与规约项逐值不变。电子电荷电流与连续性通量的双重负号已显式映射；初版错误符号控制作为失败证据保留。

九条非零边的冻结物理人口除以参考人口后，与原生SG实际消费的人口逐值相同，
替换人口的实际装配也逐值相同。因此，本轮这两个冻结弱行的余差不能继续归因于人口值本身；
这不等于其他状态的严格本构人口门已通过。

原生有效SG参数与“同人口对数边比＋QF reference/increment驱动”的高精度表达式
最大差约1.57e-14；对极小但非零驱动，该差可达到驱动的约1.43倍。
保持Bernoulli不变而只改变乘积精度也会重新超门，说明有效参数的生成顺序和后续舍入均需对齐，
不能仅提高精度、修改经验QF偏移或放宽弱行门。
