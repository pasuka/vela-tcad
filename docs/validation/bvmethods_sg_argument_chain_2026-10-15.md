## 已确定的参数组合

实际读取的统计字段为 e/hLogFermiGammaEntry；静态计算入口确认其定义路径涉及
人口／有效 DOS 的比值取 logl，再减 η。定义上 `Γ=log(F_1/2(η)/exp(η))`，
不是通用 FermiDelta 字段，也不能将带边驱动与最终参数的比值直接解释为唯一扩散因子。

令 `d` 为上轮已逐位确认的带边组合，`D` 为有效 DOS，`c=−1` 为电子、`c=+1` 为空穴。
本次标量、等温、归一化温度为 1 的路径在实数算术下为：

```
a = c*d + log(Dj/Di) + Γj−Γi
```

实际运算依次舍入 DOS 比值／对数、Γ 边差及两次加法，最后乘载流子符号。
[审计辅助程序](../../scripts/bvmethods_sg_argument_audit.py)保留该顺序，使用精确有理数
模拟 64 位有效数字的 ties-to-even，以独立 100 位 log 作数学控制。
它不接入生产求解器，不模拟 IEEE 指数上下界或厂商 logl。

基准和四个非零首态均为 24/24 个参数逐位重建，交换端点后均逐位反号。
**这仍使用原生 Γ 中间量，不能称为自主生成全部统计量。** 本批各边 DOS 比例为 1；
非均匀 DOS 只有独立数学性质测试，没有新增原生资格。非等温、量子及各向异性路径不在范围内。

## 独立统计候选与表示控制

T470p 复用已校验源码／哈希的 100 位定义积分程序，从实际人口／DOS 比值独立反算 η。
共 18 个不同比值；逆残差低于 1e-34，积分误差估计的相对量低于 1e-32。
这些是定义积分的自检，不替代原生 DensityIntegral(240) 的数值求值路径。

| 基准控制 | 结果 |
| --- | --- |
| 使用原生 Γ 构造 a | 24/24 逐位相同 |
| 原生 η，经独立 log／减法重建 Γ | 22/48 个端点样本逐位相同；最大 Γ 差 4.34e-19 |
| 独立定义积分 η 与原生 η | 最大绝对差 1.54e-14 |
| 独立 Γ 候选生成 a | 最大绝对差约 1.35e-14，未逐位闭合 |

五态合计的 η 往返为 158/240 个端点样本逐位一致；样本包含重复节点，不能当作独立
节点数。静态定义吻合不足以证明实际 logl、统计反算及缓存求值时序逐位相同，
上述末位差的全部来源尚未确定。没有添加经验偏移、拟合常数或改变门限。

用同一人口、固定单元 κμ 和既有行换算检查基准弱行：

| 参数／Bernoulli 控制 | 电子 2156 相对差 | 空穴 2515 相对差 |
| --- | ---: | ---: |
| 捕获的 B，binary80 乘减（传递控制） | +4.26e-16 | −1.35e-15 |
| 已逐位重建的 a，独立定义 B 舍入到 binary80 | −2.20e-6 | −1.35e-15 |
| 独立定义积分 Γ／a／B | −25.62% | −1.92e-5 |
| 原生 η 往返 Γ，再独立生成 a／B | +3.33e-5 | −1.51e-5 |

表中使用原生字段和冻结系数的离线复算，不是新的 Vela 实际装配资格。
不同表项替换范围不同，不能将百分比相减直接解释为单一模型的独立误差。
电子 −25.62% 是近抵消电流的相对差，不表示人口或材料参数有同样大小的物理错误。
已相同的参数 a 也不能保证厂商 Bernoulli 求值与独立数学舍入产生相同末位。

## 可分辨的非零方向

对每个载流子的 ±1e-12 V 种子分别比较对应元素边。仅在原生参数响应超过
1024 个 binary80 ULP 的边上计算方向相对差；这是分辨率筛选，不是放宽原弱行门限。
两载流子各 12 条元素边（各六条唯一边）均可分辨。

| 独立定义积分候选对照 | 电子 | 空穴 |
| --- | ---: | ---: |
| 最大原生参数响应 | 6.34e-11 | 8.70e-13 |
| 参数方向最大相对差 | 6.84e-9 | 9.05e-8 |
| 固定支撑下弱行电流方向相对差 | −5.64e-9 | +4.85e-10 |

使用原生 Γ 的参数组合在四个非零态仍逐位一致。独立统计候选的方向较近，
但基准值未闭合；不能以方向通过或定义积分误差小，代替近零绝对值资格。
此处没有认证全系统交叉块、动态迁移率导数或 Newton 更新。
