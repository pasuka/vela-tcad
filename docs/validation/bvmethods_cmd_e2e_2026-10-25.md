## 第一步：独立 JSON

从既有独立合格配置和当前 TDR / PAR 转换器组装两阶段 JSON，没有调用 CMD 阶段生成器。
第一阶段独立执行 Poisson 初始化（100 次预算），再作零偏联立求解；第二阶段只读取
自身第一阶段状态，进行负载线扫描。没有导入 Sentaurus 人口、源项、矩阵或原生检查点。

材料取当前 PAR 导入器输出，没有沿用旧完整扫描中的原生 DOS / ni 诊断覆盖值。
Si 的 Nc=2.85827787833203e19、Nv=3.104657033455896e19、
ni=1.463899277199692e10 cm⁻³。因此不能将本轮与旧扫描的差别仅归因于续算控制。

零偏成功；扫描自然结束码 1，耗时约 1422.14 s，共 13 个接受点（含零偏）。
最后接受点：外压 **0.21426249670046663 V**、内压 **0.19119787157253917 V**、
Id **2.306462799848334e-9 A/μm**。
最大接受原始残差为 9.75253410562833e-9；实际负载线残差最大约 5.2623e-9 V，
端口 KCL 最大约 5.2620e-16 A/μm。

最后失败试探外压为 0.21427249670046664 V，已到 1e-5 V 最小步长，
40 次预算耗尽。原始方程残差 3.3098918929843413e-10 已通过，
负载线残差 **−4.213848441875223e-6 V** 未通过。
全程记录了 39 次 Newton 尝试，其中 26 次失败。这个结果没有达到击穿电流判据，不能给出新 BV。

最后失败尝试的第 39 轮，原始内压方向为 4.194579338424419e-6 V，
设备更新限幅后变成 1.7044619818644055e-8 V，比例约 **0.00406349**；
随后线搜索接受 α=1。最大原始 packed 更新在索引 5542，即空穴 QF 块的节点 342，
数值约 951.934（这是 packed 坐标量，不能直接当成 V）。节点的 donors≈1.04585e18、
acceptors≈1e18 cm⁻³，净掺杂为 n 型。

[负载线 corrector](../../include/vela/simulation/CoupledLoadLine.h) 先保存原始方向，
再调用设备更新限制，最后进行回溯；[设备回调](../../src/solver/NewtonSolver.cpp)
为保持 bordered 方向而统一缩放设备与内压更新。本轮原始内压方向远小于
0.1 V 正确器限制，观测到的缩放来自 QF 限制。它解释了这个试探态的负载线推进缓慢，
但尚未解释为何空穴 QF 原始方向巨大，也不能据此判定 Jacobian 或 AV 公式有误。
本轮未取消该限制、改变方向或放宽停止门。

## 第三步：CMD 实际执行

实际调用同一 CMD，去掉 `--check`，由正式编排器重新完成输入导入、JSON 生成和自主初始化。
完整运行重新生成的两阶段 JSON 与 `--check` 快照逐字节相同。
两个 CMD 调用的前端压缩包 SHA256 也相同。

HDF5 原生 `h5diff` 核对零偏 `/fields` 全部 10 个数据集与单位属性，精确差异为零，
包括 ψ、fn、fp、n、p、QF 增量及参考量；五个 VTK 状态场各 2600 个节点也精确一致。
HDF5 整文件字节哈希不同，未将其作为状态数值不一致的证据。
另外，扫描 13 个已保存接受态的上述五类 VTK 基础场，全部 2600 个节点逐值精确一致。

CMD 全调用用时约 **1574.875 s**，自然结束。其 13 个接受点（含零偏）、39 次 Newton 尝试
（含 26 次失败）与独立 JSON 全部一致。完整接受行除输出 VTK 路径外逐字段相同；
所有尝试的外压、步长、重试号、内压、收敛标记、方程残差和负载线残差逐值相同。
最终保存 HDF5 `/fields` 全部数据与单位属性也经 `h5diff` 核对为零差异。

最后失败试探与第一步相同，未触发电流停扫条件，`goal_reached=false`；
`--exit-on-failure` 正确报告失败。它没有把部分 I–V 当成完整流程成功。
本轮排除了这两种 Vela 入口之间的配置 / 状态转换差异；共享求解链中巨大 QF 原始方向的
来源尚未唯一定位。没有新 Sentaurus 运行或新矩阵导出，不能据此扩展原生算子一致性结论。
