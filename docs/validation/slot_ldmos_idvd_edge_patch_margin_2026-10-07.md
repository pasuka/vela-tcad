# SLOT IdVd 阻塞边缘子域与预测收缩余量对照（2026-10-07）

## 1. 结果

已完成同父态的三个连通子域、两档预测余量，以及紧凑边缘子域两次重新优化缩步。**8 次真实试探全部被原诊断接受保护拒绝；局部接受更新 0、新合格点 0。** 保留父态及其 147 条超标行，没有把被拒态接入续算。

此次定位到两个不同问题：

- 健康邻行 4034/4036 的有限步长预测误差较大。重新优化并缩步后误差明显减小，但最小试探的空穴行比仍为 **0.00101695/0.00186713**，未满足 0.001。
- 目标 4046 空穴行的绝对残差虽然减小，行比尺度下降更快，导致行比从 **1.630014** 上升。用父态尺度构造的最小二乘目标不能保证真实行比改善。

加入全局块/守恒的预测余量有作用边界：它没有同时解决健康邻行的非线性预测误差、以及现有坏行的尺度变化。因此不恢复长扫描，不放宽门槛，也不据本批失败断言物理方程无解或 Jacobian 错误。

## 2. 固定身份与方法

父态为上一批 seed 链两次接受后的诊断态 [seed1_t1.h5](../../build/s07balance/seed1_t1.h5)，尚未合格。Vg=5 V，Vd=2.3683165070229464 V，300 K，电势原点 0 V；13,881 节点、27,275 三角形、25,268 条有效载流子行。

Fermi、Bennett–Wilson、Si PhuMob/Lombardi/HFS、SRH/Auger、成对电离及接触电场回退均不变。最终 abstol=1e-9、reltol=1e-8、行比 0.001、闭合比 0.01、QF 边界不变。

使用冻结 `build/s07e1/runner.exe` 评估真实残差和守恒，`build/s07e3/runner.exe` 捕获完整物理矩阵；内部电势导数除以 VT 转成对 V 的导数。三子域都在同父态使用同一矩阵，未复用旧状态的矩阵。SLSQP 使用列尺度平衡，只有方向优化改变，物理残差和源项不变。

每个子域均为 21 个相连的非接触 Si 节点，联动 ψ/电子 QF/空穴 QF 共 **63 自由度**。接触节点排除，子域外所有场保持不变。更新后按 Fermi 关系重新计算人口；密度存档 m⁻³，电势 V。探针离散残差使用装配归一化单位，不将它们当作 A/µm。

### 2.2 显式收缩余量

对于父态归一化残差 `b_k=r_k/||r_k||₂` 和预测改变量 `D_k d=J_k d/||r_k||₂`，约束改为：

`||b_k + D_k d||₂² + θ ||D_k d||₂² ≤ 1`，k=ψ、电子、空穴。

分载流子守恒失配使用同样形式：

`|(m + Dm·d)/|m||² + θ |Dm·d/|m||² ≤ 1`。

比较 θ=0 和 θ=0.25。余量随预测改变量平方增加，零步仍可行；**不是固定保留 25% 的残差余量**。它作用于三个块和两个绝对守恒失配，健康邻行沿用原预测保护 max(父态行比,0.0005)。真实闭合比仍需独立评估，因为源/通量分母会变。

方向目标除了上一批的分块残差与守恒平方和，还加入全部 147 条父态坏行的尺度化残差均方项；所有子域使用同一组父态坏行。这一项鼓励改善坏行集合，但不等价于逐条真实行比下降。

六个主对照使用 ψ/QF 箱上限 **0.3125/3.125 mV**。缩步补充保持紧凑子域、θ=0.25，分别重新求方向，箱上限降至 **0.078125/0.78125 mV**、**0.01953125/0.1953125 mV**；没有直接缩放之前已选方向。

真实接受条件保持上一批：三个块分别不恶化、两个绝对失配及闭合比分别不恶化、无新超标行、三块归一化平方和有严格下降。比较使用 1e-10 相对舍入余量，未改变最终资格门槛。

## 4. 预测误差与行尺度分离

[neighbor_prediction_check.json](../../build/s07edgeguard/neighbor_prediction_check.json) 使用捕获矩阵与实际增量重新计算每条行的线性预测，并与真实行探针在同一父态尺度下比较。

### 4.1 4034/4036 不能只由分母改变解释

两条行父态行比分别约 3.51e-16/7.89e-16；每次预测都落在负的父态尺度比 −0.0005 附近。

主箱的真实行尺度约为父态的 11.85/9.48 倍；最小箱仍为 1.557/1.172 倍。即便固定父态尺度，真实残差也明显偏离预测，故不是单纯分母效应。

缩步后误差减小与有限步长非线性相容，但每档方向都重新优化，不能据此拟合固定方向的误差阶，也不能排除导数/装配路径差异。尚未做同一方向 ±h 的中心差分核对。

### 4.2 4046 的绝对残差改善不等于行比改善

|状态|空穴残差绝对值|行尺度|真实行比|
|---|---:|---:|---:|
|父态|2.863831689e-8|1.756937133e-8|1.630014|
|紧凑主箱 θ=0.25|2.814042371e-8|1.692869055e-8|1.662292|
|紧凑最小箱|2.863767318e-8|1.754837467e-8|1.631927|

这三态的行尺度由通量绝对和主导。主箱中通量绝对和下降，而电离项绝对值约保持在 1.115e-8。最小箱的绝对残差虽略降，尺度也下降，行比仍升高。

本批目标对坏行采用父态固定尺度，并以集合均方计量，因而容许某个原有坏行真实行比变差。新增坏行保护不会禁止既有坏行继续变差。这是当前诊断目标与逐行资格之间的差别，不是放宽资格的理由。
