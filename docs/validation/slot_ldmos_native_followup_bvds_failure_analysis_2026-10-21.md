# SLOT原生补偿掺杂对照与BVDS电路失败分析（2026-10-21）

本轮读取VM既有结果、日志和冻结源码，并复算数组相等性、电流变化及负载线；
未启动新增求解，未修改物理模型、生产配置或接受规则。原始数据和机器可读分析
留在VM，本地仅保存结论。远程任务身份、具体目录见用户本地执行记录。

## 结论与适用范围

1. 新原生IdVd采用补偿掺杂，消除了此前参考使用净掺杂造成的主要输入失配。
   人口重建接近并不意味着残差或完整收敛判据已经对齐。
2. 原生BVDS在25/50 mV的DirectCurrent开关改变输出电流，但本批捕获的
   矩阵、RHS、方向和最终场量数值不变。尚未直接识别内部电路电流缓存。
3. Vela失败存在两层：内层返回的电流沿电路评估序列大幅变化；外层允许
   “括区宽度足够小”单独返回成功，随后独立负载线验收拒绝该结果。
   0.05 V另因第26次电路评估的内层软时限退出。

本批IdVd为Vg=5 V、Fermi及既有PhuMob/Lombardi配置；BVDS为补偿掺杂、
Boltzmann/IALMob及既有源项配置、外电阻1e12 Ω·µm。两类模型不混用。
Vela回放使用pardiso_mkl_eliminated_keep_psi；回放为导入态装配，非重新收敛解。
原生文本导出的相等性不等同于已核实内部全精度CSR逐位相等。

## 原生BVDS：输出电流与电路电流不能混同

分别读取25、50 mV两组default/DirectCurrent文件：每组system_0的8个数组
以及final_fields的6个数组均数值相等（含NaN同位判定）。两组均一次耦合更新。

用输出电流试算f=Vd+R·Id−Vs：

|器件漏压|默认输出代入f / V|DirectCurrent输出代入f / V|
|---|---:|---:|
|约25 mV|+5.06496e-9|−1.19785e-4|
|约50 mV|+2.17296e-8|+1.07184e-4|

这支持本批开关影响端口输出口径，而非捕获到的求解方程。不能据DirectCurrent
代入值认定原生电路求解失败，也不能仅凭默认值更接近零就宣布内部缓存身份已确定。
仍须绑定AreaFactor/二维宽度约定、实际外电阻方程缩放及运行时电流输入。

## Vela扫描：直接停止原因

四次尝试均从同一0 V父态出发；载流子行资格及闭合采用该批既有报告模式。
没有非零接受点，最终因连续失败/最小外电源步长条件停止，而非12小时预算耗尽。
根求解配置为残差容差1e-6 V、括区电压容差1e-8 V。

|外电源目标 / V|最后器件Vd / V|最后负载线残差 / V|直接结果|
|---|---:|---:|---|
|0.2|0.199999999999|+58.93252655|外层报告成功后被负载线检查拒绝|
|0.1|0.099999999999|+1.311095e-4|同上|
|0.05|尝试0.0991293729361|未完成；前一次约+4.86561e-2|第26次电路评估内层soft_time_limit|
|0.025|0.0268357289773|+1.396933e-3|外层报告成功后被负载线检查拒绝|

冻结源码BoundaryControl.cpp与本地对应文件SHA256一致。第256—259行使用：

```cpp
if (std::abs(residual) <= config.residualTolerance ||
    width <= config.voltageTolerance) {
    result.converged = true;
    return result;
}
```

按已记录评估序列复原，0.2/0.1/0.025 V最后评估前括区宽度分别约
1.689e-11、1.655e-10、5.459e-9 V，均小于1e-8 V。
因此这些“成功”可由宽度条件解释，并不证明负载线残差达标。

更上游的异常是内层电流沿评估序列不稳定：

- 0.2 V首个器件求解电流约2.0792e-16 A/µm；最后返回5.8933e-11 A/µm。
  最后一次为零更新initial_stall_residual_floor，闭合报告未通过；它不是
  对稳定电流的微小浮点差异过度检查。
- 0.025 V评估中，Vd≈0.026835729 V时先返回2.498e-17 A/µm；附近后续
  评估曾返回约−3.3004e-10 A/µm。状态、路径、停止理由均需绑定后再归因。
- 0.05 V初始括区残差约−67.12和+0.05013 V，假位法试探长期贴近正端。
  第26次内层运行11次更新后软时限退出，总目标耗时约3289秒；尾部阻尼出现
  1/256、1/64、1/32。它是局部时限失败，不是已证明的不可解或硬发散。

端口电子漂移和扩散分量约为±0.10686 A/µm，存在强相消，但仅凭相消不能
将全部误差归为舍入。实际状态失衡、停滞接受、反力/泛函口径与重算路径须分别核对。
