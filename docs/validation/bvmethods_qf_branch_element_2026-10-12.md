# BVmethods 端点 QF、阈值分支与元素源支撑对照（2026-10-12）

本轮完成三机实际参考值／增量对照、七组电离阈值消融及两种迁移率位置的元素源重建。
**QF 参考值重排没有消除主要 RHS 差异；最大内角代表顶点规则能解释已唯一识别的主要回调，
但不能重建完整源。** 原生空穴电离分支的阈值响应已确认，具体过渡公式仍未识别。
继续 Q2/Q3，尚不能认证唯一 SG／源算子或从零高压纯 QS。

接续[上一轮精度与源积分记录](bvmethods_sg_precision_source_transfer_2026-10-12.md)。
数值和身份见[配套 JSON](bvmethods_qf_branch_element_2026-10-12.json)。
原始证据：`build-release/bvmethods_qf_branch_element_20261012/`；此前封存目录保持原样。

## 1. 配置与执行范围

- 原 BVmethods NMOS 网格：2600 节点、5020 三角形（26 个钝角），其中 4156 个 Si 单元，
  Si region 3；300 K，外电阻 `1e7 ohm*um`。坐标 µm，原生人口 cm^-3，Vela/H5 人口 m^-3，
  电场 V/cm（Vela 内部 V/m），二维端电流 A/µm。
- Fermi + OldSlotboom、Masetti + Enormal + GradQuasiFermi 高场迁移率、SRH(DopingDep)、
  E2 BTBT、VanOverstraeten Eparallel。保持生产模型、常数、门限及 PN2D 配置束。
- 固定首个非零 Newton 更新前态，采用前轮 integral 统计、逐节点 ni/Nc/Nv、
  `Vt=0.02585199526648486 V`、`q=1.602192e-19 C` 的私有同本构诊断控制。
- 本机及 T470p Windows UCRT64、C560 Ubuntu 26.04.1 LTS 均编译私有 Release C++ 对象，
  每台执行 18 次最终装配导出：三种实际参考值 × 原 SG／有效带边 SG × terms／SG／population。
  本机另执行 12 次默认装配器的原态／复制态身份控制。
- Sentaurus T-2022.03-SP2 执行 14 次成功的固定 Load/Plot（7 个阈值，各内置／观察器一组）。
  采用 80-bit ExtendedPrecision 和 DensityIntegral=240；没有重新求解 PDE。
- HDF5 状态读取实际可用；本机链接记录包含 UMFPACK/SPQR 支持，但本轮仅装配，环境指定
  SparseLU，**没有线性求解或 UMFPACK/PARDISO 比较**。私有 C++ 位于忽略的构建目录，生产 C++ 未改。

## 2. 实际装配器参考值和舍入路径

输入 H5 的两个载流子 reference 都是零，但默认 `contact_basin` 装配器会重新打包：
电子实际参考值为 `0` 和 `4.975540973036571e-6 V`，空穴为零。
原 SG CSV 中的 `electron_qf_reference0/1` 等列只在 Boltzmann 分解可用时填写；本次 Fermi
状态对应可用标志为零，不能把这些列的零占位值当作实际参考值。

因此新增私有直接追踪，读取装配器 reference 和实际打包增量 `x*potentialScale`，
并在三机逐值检查覆盖生效。最终控制为：默认 contact basin、强制零参考值、逐节点物理 QF
作为参考值、自由节点公共参考值 `2^-10 V`。后面三组才是实际参考值替换。
接触的输入 QF/reference/increment 位值保持；没有用自由接触人口替换规定 QF。

原始输入与无改动复制输入，在默认装配器、两种 SG 和三类输出下，**六对 CSV 逐字节相同**。
证据中的 `noop` 输入名表示 H5 复制态；启用覆盖后它是“零参考值”控制，不能称为默认装配器的无变化控制。
初版只改 H5、未覆盖装配器的结果，以及误把两种实际参考值当作同一控制的失败检查均保留；
最终身份检查依据实际追踪，不使用 Fermi CSV 占位列。

端点对照分别计算：双精度绝对 QF 相减、相对端点重新锚定后转回双精度、long-double
直接组合 reference/increment 后相减。本机 long-double 尾数为 63 位，较宽结果也不是精确算术。

| 实际参考值控制 | 电子完整 RHS 相对默认的变化 L2 | 空穴完整 RHS 相对默认的变化 L2 |
| --- | --- | --- |
| 零参考值 | 1.58648e-15 | 5.78377e-21 |
| 逐节点 QF | 1.98476e-15 | 2.68539e-20 |
| 公共 `2^-10 V` | 1.82398e-7 | 3.80279e-9 |

这里是前轮固定左行尺度下的 L2，**不是相对物理误差或新门限**；每个载流子的全部 2121 个
共同自由行均保留，11 个原生 QF／电路别名行仍未认证。表中采用原 SG；有效带边 SG 结论相同。

公共参考值在 H5 较宽 reference+increment 和中引入最多电子 `9.56e-20 V`、空穴
`5.42e-20 V` 的变化，实际归一化打包还会舍入。实际端点较宽 QF 差相对默认最大变化为
电子 `3.07e-19 V`、空穴 `1.39e-17 V`；人口最大相对变化约 `7.33e-15`。
默认电子端点的双精度锚定／较宽直接差最多相差 `4.24e-22 V`。

这说明近零输运对参考值打包敏感，但逐节点／零参考值控制没有改变主要差异：
默认电子完整 RHS 差 `0.0152770365`、空穴 `1.09084990e-5`，公共参考值后仍为
`0.0152770322`、`1.09081129e-5`。不能把公共参考值的微小改善视为输运算子修复。

## 3. 跨阈值电离分支标定

固定同一主变量和物理模型，只把诊断参数中两载流子的 E0 设为下表七个值；
每组内置结果和硬切换 PMI 观察器分别导出。所有组的 ψ、QF、n、p 逐值一致，14 次运行／导出均退出 0，
下载的 481 个文件逐项哈希核验通过。生产 E0 仍为 `4e5 V/cm`。

| E0（V/cm） | 空穴观察器对内置源相对 L2 差 | 内置空穴源相对 E0=400000 的变化 |
| --- | --- | --- |
| 360000 | 0.606610% | 2.568101% |
| 380000 | 0.266083% | 0.692551% |
| 395000 | 0.072834% | 0.076057% |
| 400000 | 0.073294% | 0 |
| 405000 | 0.086809% | 0.038548% |
| 420000 | 0.086648% | 0.209772% |
| 440000 | 0.014975% | 0.363488% |

电子两支系数相同，源随 E0 不变，观察器对内置源差约 `4.84e-16`；空穴曲线确认阈值参数
确实参与原生源计算，误差集中位置也随阈值移动。结合前轮两支系数相同后差消失的控制，
支持低／高场分支处理差异，但**还不能判定具体平滑、插值或内部场取样公式**。
本轮没有拟合平滑宽度，也没有以改阈值来消除默认模型误差。

首版尝试通过 Tcl 读取未提供的 element/element_vertex 物理字段，14 组均因
`undefined Element-RegionWise ElectrostaticPotential` 退出 5；Tcl catch 不能捕获这个原生中止。
该批次 467 个文件及失败日志另存。零散返回的可疑元素密度不用于任何结论；成功批次恢复了
已验证的数据位置。查阅本机手册及已安装 PMI 接口只用于确定可用范围，没有归档专有 SDK 头文件。

## 4. 代表顶点和逐元素源重建

以原有独立 J/µ 指纹匹配为条件，检查密度、ψ、QF、盒 Measure、局部编号及几何规则。
在先前定义的主要回调范围内，最大内角顶点覆盖全部**已有唯一身份**的回调：

| 状态 | 电子命中 | 空穴命中 | 其中几何并列：电子／空穴 |
| --- | --- | --- | --- |
| 原近零态，80-bit | 862/862 | 1772/1772 | 22 / 34 |
| 编码有限 QF 态，80-bit | 1150/1150 | 570/570 | 27 / 35 |

这只是条件规则，不能反向把弱电流或原有歧义回调认定为唯一身份。最大 Measure 规则存在真实反例，
并非只差舍入：编码电子单元 3750 的已匹配代表为节点 2087，而最大 Measure 节点为 2088。

随后对全部 4156 个 Si 单元独立执行两条关联边的有效带边 SG、接触例外和绝缘投影。
最大内角有 150 个并列单元；全部保留，并按所有并列代表计算源的上下界，未任意选一个顶点。
电离力分别采用正向投影 `max(0,E·J/|J|)` 和绝对投影；后者尤其在编码态明显恶化。
有限激励唯一主要回调的正向力误差约电子 `9.59e-15`、空穴 `4.03e-15`；
近零态相应为 `7.64e-7`、`1.13e-7`，弱电流舍入尾部仍在。

对源大小分别测试“导出的单元迁移率”和“代表节点迁移率”两个明确假设：
`G=alpha(F)*mu*|J/mu|/q`，再以原生每个 element-vertex Measure 积分到节点。
每个 `(element,local_vertex)` 恰用一次，不重新归一化或删小源；相同原生硬分支观察器作为
源参考，避免把内置分支过渡差混进几何验证。下表是原生积分值落在候选上下界**之外的部分**
相对 L2，不是单个候选预测的误差，也不是验收门限。

| 状态／载流子 | 单元迁移率假设 | 代表节点迁移率假设 |
| --- | --- | --- |
| 近零态电子 | 2.35721% | 0.34582% |
| 近零态空穴 | 0.60526% | 1.19337% |
| 编码态电子 | 1.96181% | 2.25950% |
| 编码态空穴 | 1.14439% | 1.46856% |

两种假设都不能包住完整原生源。因此代表顶点、源实际使用的局部迁移率及源放置关系尚未共同确定，
**唯一逐元素源重建未通过**，不能把已匹配的 J/µ 或力直接当作完整源资格。
积分 CSV 使用 `G[cm^-3 s^-1] × Measure[µm²]` 的原始数值；相对比较的统一单位因子抵消，
不能把它不经换算直接作为 Vela RHS。
