# 当前 SimpleMOS 物理量差异与 Jacobian 实现复盘

2026-09-06。本轮只读复核当前源码及封存证据，重新统计四个严格工作点的节点场、SRH 和迁移率范围，以及 M66 完整曲线的分区间误差。无新增求解、模型修改或生产代码修改。

**结论：高 NWell 的平滑 Id 差异尚未解决；沟道电势偏差主要为 mV 量级，准费米势差及梯度也有可测差异。当前迁移率不是常数。正式 Jacobian 含迁移率的部分状态偏导，但仍缺向量准费米驱动场的链式导数；隔离程序已补齐并通过指定方向校准。实现混合了手写解析导数与数值中心差分，不能称为全符号解析、全分支完整验证。**

## 1. 比较范围与进展

NWell 在本 deck 实际为背景 Boron：低/高为 1e17 / 2e17 cm^-3。当前定位分支采用 matched-ni、no-BGN、Boltzmann、SRH，与早期含 BGN 原始支路分开解释。n19/n23 分别为低/高对照，网格 1480/1482 节点。

| 已完成事项 | 当前可支持的结论 |
| --- | --- |
| 深关断端口 burst 定位及原生收敛收紧 | 早期尖峰主要是极小电流下的端口残差可见度；不代表所有深关断点已获得最新严格资格 |
| ni 约定匹配及 M66 16×51 点曲线 | 消除一部分 NWell 配对增幅，仍有平滑电流差 |
| 固定状态 SRH、电荷、SG 与端口汇总 | 同状态局部 SRH/电荷公式一致，边通量汇总闭合；不证明两程序内部空间离散一致 |
| 严格重闭合及 Jacobian 缺项诊断 | 四点状态可接受，向量高场链式导数缺项影响灵敏度预测，基本不改变自洽电流 |
| 校准后输运分解、局部守恒扰动 | 准费米失衡相关输运是主要观察量；指定沟道边连续性源已校准，漏接触边净响应未校准 |

完整 Id–Vg 曲线仍引用 M66 历史冻结结果。本轮没有把 0–1 V 的每个点重新作严格求解与全场导出。下文场统计对应 n23 的两个代表点：低 Vd 为 (Vd,Vg)=(0.05,0.9) V，高 Vd 为 (1,0.8) V；不是相同 Vg 的 Vd 扫描，也不是全电压区间场误差包络。n19 两个控制点的同类统计一并写入 CSV。

## 2. 电流差异覆盖哪些区间

| --- | ---: | ---: |
| 0–0.5 V | 13.85% / 515.00% | 12.10% / 146.33% |
| 0.55–1 V | 14.22% / 16.00% | 12.17% / 14.49% |
| 1 V 单点，跨四器件 | 11.65% / 13.47% | 9.00% / 10.11% |
| 1.05–2.5 V | 1.21% / 11.93% | 1.29% / 8.46% |

深关断最大百分比不可隐藏，也不能和较大电流下的平滑差作相同解释。两个最差点均为 n24：低 Vd、Vg=0.05 V 的原生/Vela Id 分别为 6.2503e-17 / 3.8439e-16 A/um；高 Vd、Vg=0.1 V 为 6.6829e-16 / 1.6462e-15 A/um。它们来自旧 M66 曲线，尚无本轮严格重闭合后的逐点替代证据；不能用这张表声称新的物理尖峰已经确认。

## 3. 电势、准费米势及载流子浓度的实际差异

按原生 Si 节点 ID 对齐，没有插值或任意平移电势零点；Vela 准费米势由 reference+increment 重建。定义 `delta=Vela−Sentaurus`，RMS 为共同 Si 重心面积加权的 `sqrt(sum(A delta²)/sum(A))`，max 为所选节点最大绝对差。电势使用绝对 V/mV 差，不用受零点影响的百分比。

浅沟道定义为距 Si 表面不超过 0.05 um、横向 |y|<=0.125 um 的 Si 节点，共 186 个；包含边界节点，统计范围与排除 Dirichlet 的扰动支持概念不同。

| 浅沟道物理量 | 低 Vd：RMS / max | 高 Vd：RMS / max |
| --- | ---: | ---: |
| 静电势 psi，mV | 0.9293 / 3.3847 | 1.1249 / 4.6127 |
| 电子准费米势 phi_n，mV | 0.2035 / 0.6017 | 1.5253 / 7.2386 |
| 空穴准费米势 phi_p，mV | 0.000557 / 0.004226 | 1.6528 / 7.2180 |
| log10(n_V/n_S)，dex | 0.015667 / 0.056867 | 0.021394 / 0.087502 |
| log10(p_V/p_S)，dex | 0.015612 / 0.056862 | 0.026730 / 0.100612 |

浓度的 max 绝对对数差对应最大倍数偏离尺度约为：低 Vd n/p 均 1.140 倍；高 Vd n 为 1.223 倍、p 为 1.261 倍。这是较大者/较小者的倍数尺度，不能直接当作全部节点的正向相对误差或平均误差。

全 Si 域的结果用于对照，避免只给局部较小数值：

| 全 Si 物理量 | 低 Vd：RMS / max，mV | 高 Vd：RMS / max，mV |
| --- | ---: | ---: |
| psi | 1.2294 / 13.8074 | 1.5553 / 13.8074 |
| phi_n | 0.04034 / 0.60174 | 1.0991 / 17.8805 |
| phi_p | 0.01480 / 0.39850 | 0.6574 / 11.1166 |

全域 psi 最大值在节点 35，坐标 (深度方向 x, 横向 y)=(0.170798,-0.3) um，位于浅沟道范围外。高 Vd 的 phi_n / phi_p 最大值在节点 792 / 1114，其原生电子/空穴浓度仅数千 cm^-3；全域准费米最大差不能直接代替电流敏感度。全节点原值及峰值位置已保留。

最近两条焦点边也须区分“势值”和“势差梯度”：沟道 320–324 的电子准费米势差，原生/Vela 为 3.306084/3.472089 mV（低 Vd）、8.974757/9.457042 mV（高 Vd）。同几何的 SG 状态电导代理原生态/Vela态为 1.024895 / 1.029840。漏边 1091–1092 的势差仅约 1e-10 V，电导代理只差约 4.2 ppm；其中可出现明显相对梯度差，不能简单归因为 SG 公式错误。该电导代理不是 Sentaurus 导出的原生边算子。

在 Boltzmann 路径，n=ni exp((psi−phi_n)/Vt)、p=ni exp((phi_p−psi)/Vt)。因此 mV 量级势垒组合差可以对应可见浓度变化；Id 又取决于空间电导、准费米失衡和完整自洽反馈，不能用一个全局 psi RMS 直接计算电流误差。

## 4. 生成复合差：同状态公式与各自状态必须分开

目前只有 SRH 激活，Auger、碰撞电离及带间隧穿未启用。这里的原生 `srhRecombination` 为带符号净复合率，负值为净产生；没有独立导出的总生成 G 和总复合 R，不能将净率拆成已测得的两个正量。

将各自状态的 SRH 净率用同一 Si 重心面积积分为 `q∫R dA × 1 um`：

| 指标 | n23 低 Vd | n23 高 Vd |
| --- | ---: | ---: |
| 原生净积分，A/um | -7.412869e-18 | -9.144618e-17 |
| Vela 严格态净积分，A/um | -7.326536e-18 | -9.048094e-17 |
| Vela−原生，A/um | +8.63336e-20 | +9.65238e-19 |
| 全 Si `∫|R_V−R_S|/∫|R_S|` | 3.0451% | 1.2251% |
| 浅沟道同一 L1 指标 | 1.6136% | 1.1141% |
| 原生 / Vela 峰值绝对率，cm^-3 s^-1 | 1.970873e16 / 1.972467e16 | 4.524506e16 / 4.524515e16 |

这些是**各自自洽状态**导致的 SRH 场差。此前将相同 Sentaurus 原始 n/p/ni 代入经典 Vela SRH，四点归一化 L1 最差仅 2.37e-16；广义公式最差约 5.97e-8。二者不矛盾：公式相同仍可因状态不同得到百分比级局部率差。

本轮按照当前广义 Boltzmann SRH 公式重算 Vela 率，用准费米劈裂的 expm1 形式避免 np−ni² 消减，再与已有生产 carrier-term 探针核对；n23 的归一化 L1 分别为 7.16e-15 / 2.23e-16。比较两程序时统一使用 Si 重心面积，不冒充原生内部体积；核对 Vela 装配项时则使用它实际的 all-cell 体积。旧配置和探针某些 `*_m3` 键名承载内部 cm^-3，已按 `UnitScalingConfig::concentrationToInternal` 的实际行为处理，restart 的 n/p 列才是显式 SI。

当前两点 SRH 净积分差比约 1e-9 A/um 的 Id 差小约 9–10 个数量级。校准权重下的电子 SRH 电流投影也仅约 8.84e-20 / 9.68e-19 A/um，空穴项更小。现有证据不支持 SRH 局部公式作为这两个点 Id 差的主因；这不覆盖深关断电流仅 1e-17–1e-15 A/um 的所有点。

## 5. 迁移率不是常数

配置为 `phumob_field_lombardi`：PhuMob 掺杂/电子/空穴散射与屏蔽，Lombardi 界面场散射，高场速度饱和；高场驱动力为 `quasi_fermi_gradient`，离散为 `transport_cell_vector`。T、掺杂和几何在当前 Newton 状态变量之外固定，psi/phi_n/phi_p 通过 n/p 和场影响迁移率。

当前 n23 导电边的迁移率范围如下，单位 cm²/(V·s)。这是 Vela 实际边迁移率范围，不是对原生节点迁移率的误差统计。

| 载流子 | 低 Vd：最小 / 中位 / 最大 | 高 Vd：最小 / 中位 / 最大 |
| --- | ---: | ---: |
| 电子 | 37.62 / 540.72 / 807.84 | 37.62 / 301.37 / 807.72 |
| 空穴 | 113.93 / 186.42 / 280.78 | 29.83 / 158.83 / 280.97 |

从校准的三因子输运账本看，迁移率相关投影分别为 -6.863e-11 / +4.985e-11 A/um，约占总 Id 差的 -3.06% / +4.94%，随漏压反号；准费米失衡相关项约占 +102.36% / +70.75%，其他项抵消。它们是同一 Vela 算子跨状态的分配，不能当作已经确定的模型错误贡献。

## 6. Jacobian 有哪些偏导，怎样计算

当前未知量为缩放后的 psi、phi_n、phi_p；n/p 由统计关系导出。若边通量 `F=mu(x) H(x)`，其完整状态导数应为 `dF/dx=mu*dH/dx+H*dmu/dx`。需要的是对当前未知量的链式导数，固定掺杂/温度不应凭空增加未知量列。

| 部分 | 当前正式实现 | 当前资格 |
| --- | --- | --- |
| Poisson 介电耦合 | 固定边耦合系数手写装配 | 当前模型中材料、几何固定 |
| Poisson n/p 电荷 | 统计函数导数及链式法则手写装配 | 当前 Boltzmann 活跃范围内有解析关系 |
| SRH | 对浓度、过剩乘积及简并因子手写导数，再链到三种势 | 当前 SRH/Boltzmann 路径有对应项 |
| 常迁移率 Boltzmann SG 分支 | Bernoulli 函数及指数的手写解析导数 | 代码存在；当前 PhuMob 分支不走此纯解析路径 |
| 当前 PhuMob 输运 | 对边端点六个势变量的通量作中心差分；重算 n/p 和迁移率 | 包含密度/屏蔽相关迁移率导数，也包含端点势相关项 |
| Lombardi 额外邻点 psi | 对表面场模板中的额外节点做中心差分 | 有对应场依赖项，不能据此宣称所有场链完整 |
| 单元向量准费米驱动场 | 正式代码在基态预计算后，端点差分时沿用缓存 | **已确认缺少该驱动场对端点及相邻单元 phi_n/phi_p 的链式贡献** |
| Dirichlet 接触 | 约束行替换、对角置 1 | 需与参数直接端口项的定义区分 |

正式代码入口虽名为 `jacobian="analytic"`，实际是“专用装配路径”，不代表所有元素都是解析式。当前边通量中心差分步长为 `1e-6*max(1,abs(potential))` V。另一配置 `finite_difference` 会走残差层面的数值 Jacobian，是不同入口。

`jacobian_field_derivatives` 默认 true；PhuMob 的密度导数无论该开关都保留。但开关为 true 不能补救已缓存的 vector drive 链缺项。源码依据：

- [迁移率依赖判定](../../src/equation/CoupledDDAssembler.cpp#L176)、[向量场预计算](../../src/equation/CoupledDDAssembler.cpp#L3508)、[差分内使用缓存场](../../src/equation/CoupledDDAssembler.cpp#L4550)。
- [电子端点中心差分及表面模板](../../src/equation/CoupledDDAssembler.cpp#L4755)、[空穴分支](../../src/equation/CoupledDDAssembler.cpp#L4858)。
- [Poisson 电荷导数](../../src/equation/CoupledDDAssembler.cpp#L5365)、[SRH 链式装配](../../src/equation/CoupledDDAssembler.cpp#L5487)、[局部 SRH 导数](../../src/physics/RecombinationModel.cpp#L295)。
- [默认模式名称](../../include/vela/solver/NewtonSolver.h#L169)、[迁移率开关](../../include/vela/physics/MobilityModel.h#L162)。

这些解析部分是源码中的手写公式。没有证据表明该求解路径由符号代数系统统一生成，当前活跃路径也不是统一自动微分。仓库其他模型具有 local AD、finite-difference 或 frozen 选项，不应把那些未启用分支与本算例混为一谈。

## 7. 隔离补项是否证明 Jacobian 完整

隔离程序额外加入 `(F/mu)*dmu(E_vector)/dphi_k`，固定 psi/n/p，对两侧相邻单元准费米势扰动后重建驱动场，以 1e-7 V 中心差分求导，覆盖电子和空穴完整单元模板。这仍是数值补项，不是生产源码中的全解析修复。

已完成 n19/n23 × 两个 Vd、两档浅沟道电荷扰动：原预测误差为 0.3408%–4.1557%，补项后八个幅度全部通过，最大相对误差 5.56e-8。实际方向 Jv 投影缺陷显著下降；随后 n23 指定沟道边连续性扰动四个幅度也通过，最大预测误差 8.58e-8。

**这些验证只覆盖既定状态、源项和方向，不能证明整个矩阵每列、每个状态、每个物理分支及截断切换点都正确。** 正式代码仍有已知缺项；隔离程序是局部资格已建立，通用完整性尚未建立。漏接触净响应仍不合格，也必须保留为验证边界。

补项开关对自洽电流最大相对影响约 1.14e-9，原约 +14.33% / +12.26% 的跨程序差不变。原因是本次仅改变 Newton 导数，物理残差和端口定义未变；在本次均通过接受检查的解附近，它主要修复步进和灵敏度，不能自动修正物理解差。

当前合理的后续安排是：对生产化 Jacobian 修复做独立完整性审计（场重建全部邻接列、电子/空穴交叉块、分支及步长收敛），并继续用已校准沟道方向追查局部 Poisson/输运耦合如何形成状态差。若要回答整个 0–1 V 的物理场误差曲线，需要先补齐统一工况和严格资格下的逐 Vg 场导出。此次复盘没有启动这些新增仿真。
