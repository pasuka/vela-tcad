## NonLocalPath 独立参考

实现位于 [test_nonlocalpath_phonon.cpp](../../tests/test_nonlocalpath_phonon.cpp)。
Charon 用户手册附录 B 的带—陷阱模型提供独立参考思路；
其式 (187)、(188) 的 Airy 电光函数并不等同于当前声子辅助带间隧穿内核。

| 新控制 | 独立关系／覆盖 | 结果 |
|---|---|---|
| 两端不等坡度三角势垒 | 直接积分两段平方根及倒平方根；四组坡度、1／7／31 个不均匀分段 | 作用量、交叉点、倒平方根积分相对 1e-12 通过 |
| 固定路径占据与窗口 | 单独／组合扰动两个 Fermi 能和两端窗口；三档步长 | 解析对数导数与 Richardson 差分相对 1e-8 通过 |
| 零窗口单侧 | 精确零源及从 W>0 一侧进入的有限源导数 | 三档无量纲窗口指数、两端分别通过 1e-8 |
| 固定几何带状态缩放 | 同时验证作用量、倒平方根积分、前因子、有限窗口的链式导数 | 三档组合导数 1e-8 通过 |
| Airy 数学参考 | 正性、独立积分恒等式、导数、渐近重叠 | 积分 1e-11、导数 1e-8；领先渐近项误差随 y 增大而减小 |

不等坡度势垒取 A u 与 B(1−u)，固定质量时
u*=m_c B/(m_v A+m_c B)。直接积分给出
S=2L/(3ℏ)[√(2m_v A)u*^(3/2)+√(2m_c B)(1−u*)^(3/2)]，
没有调用生产根求解或积分原语构造参考。

固定几何、零起点带能、固定质量下，将全部带能和初始梯度乘 λ：
S∝√λ、I_v/c∝λ^(−1/2)，含初始梯度的前因子∝λ^(3/4)。
因此 d ln|G|/d lnλ =
3/4−S−[s_v/expm1(s_v)+s_c/expm1(s_c)]/2。
该控制覆盖可变化带状态，但没有覆盖路径转移、收集事件或完整非局部 Jacobian。

Airy 参考采用 F(y)=Ai′(y)²−y Ai(y)²，
独立检查 F(y)=∫_y^∞Ai(t)²dt 及 F′(y)=−Ai(y)²；
领先渐近式 exp(−4y^(3/2)/3)/(8πy) 仅按其近似性质检验，
未要求它等于精确函数，也没有将 Airy 模型接入声子内核。

最初占据／窗口控制的最粗中心差分有一次约 3.8e-8 相对偏差。
保留失败日志后，用 Richardson 消除主导截断误差，未放宽 1e-8 门。
本地 CTest `nonlocalpath_n3_phonon` 通过；T470p 运行相同 Windows 可执行文件通过。
这不是 Linux 或不同数学库的跨平台资格。

## 实际 SG 与统计人口链

两条候选方向各重复两次；每臂采集基态及 ±2^(−k)，k=0…12，
包括 722／717／709／845／712／706 的实际边支撑。
保留 QF reference/increment，以保存的正反状态计算实际写回方向。
每态验证被动采集前后残差逐位相同；关闭迁移率场导数的诊断配置也保持残差逐位相同。

在实际操作数上，以 80 位 Decimal 独立重建
F=C g B(−dψ/(V_T g)) p_j expm1(−Δφ_p/(V_T g))，
并对固定 C 的人口、g、Bernoulli 参数、驱动分别求链式导数。
实际双精度通量与该重建的最大相对差为 9.80e-15；
逐边散射复原目标 SG 行通过 1e-14 检查。

对所采样的非简并端点，以独立交错 Fermi 级数计算 F_1/2 及导数。
基态 η 范围约 −77.39…−27.48；所有采样态的人口最大相对差
3.10e-16、一阶导数最大相对差 2.48e-16。
这排除了**这些端点**明显的人口值／一阶统计函数误差，不能推广为全部 Fermi
分支、所有状态映射、缓存或远端支撑已对齐。

固定迁移率有限差分复用基态 C，其他操作数仍来自扰动态；

这将问题收缩到生产固定迁移率 Jacobian 的求值／差分模板，
但尚未通过逐列原始操作数证明具体是哪次舍入或缓存调用造成。

722 的固定部分已吻合；反馈对自身尺度的误差较小，但相消后完整导数仍失败。

统一关闭场导数会删除重要反馈，不构成可接受候选。

目标两行全部支撑在所采样状态上，没有检出 g 割线／中点分支、QF 差符号、
