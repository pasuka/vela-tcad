## 4. 接触反力与 SG 电流：源项没有从原始方程中消失

源码路径和数值对照一致：

- `CoupledDDAssembler.cpp` 在 Dirichlet 替换之前向节点连续性方程装配 R/G；边界替换后的诊断 CSV 把对应项清零，不能用这些零判断原始反力无源项。
- `ContactCurrentExtractor::computeDetailed` 是 SG 通量求和；`computeFromResidual` 与 `makeArclengthContactCurrentFunctional` 使用未施加 Dirichlet 替换的残差。
- 为导出原始接触行，独立诊断配置清空偏压边界列表，但保留网格接触掩码；配对控制均设 `quasi_fermi_reference=none`。不运行 Newton，不把此配置当作器件边界变更实验。全部自由行的通量、复合、电离及人口在两臂逐值相同。

设接触支撑体积上的净源电流 S=q(R−G)，电流符号采用该批 conventional terminal 口径，则同态：

\[
I_e^{reaction}=I_e^{SG}-S,\qquad
I_h^{reaction}=I_h^{SG}+S.
\]

成对源在电子/空穴分量间转移，在总电流中相消。CLI 的 `contact_current_extractor_hole` 储存符号与本表 conventional hole 相反，分析显式取负。

|---|---:|---:|
|电子|-2.542087993897e-4|-2.541842711936e-4|
|空穴|-9.520240522700e-8|-1.197306013485e-7|
|总电流|-2.543040017949e-4|-2.543040017949e-4|

source 接触 qG=2.452819612155e-8、R=0；drain 接触 qG=4.199738718275e-13。逐接触反力总电流与同口径边通量总电流差不超过 5.43e-20 A/µm。
另从三角形坐标、正系数 cotangent 顶点权重和 αµn|∇QF| 独立复算全部接触源：2.452861609542e-8 A/µm，相对源探针差 2.22e-16，支撑权重误差/单元面积最大 4.08e-15。

因此，上一批只统计自由源时的约 26% 原生账本差，不能证明 Vela 装配漏源；其中存在边通量/接触反力及支撑范围混比。Sentaurus 全节点源积分与端口的一致性仍是数值证据，**并未取得其内部接触装配代码或逐行反力导出**，不宣称两软件所有边界实现已完全等价。
该失败态的原始反力空穴端口和约 −1.19731e-7，原生旧基线约 −1.32692e-7 A/µm，仍差约 9.77%；两者状态不同，此数值不能单独归因于某个模型参数。

## 6. 对初始化与源加载的决定

1. 保留目标接触电离回退物理及原门槛；当前接触源支撑、反力恒等式和重点 HFS 输入没有给出删除源项或改 HFS 默认值的理由。
2. 先在热点及其连通邻域建立 **Vela 状态方程一致的空穴初值**。若借用原生密度，必须用 Vela 的 Fermi/BGN 状态关系反解 QF，再测完整 Poisson、源项及邻行；本批不把直接重建后的 P 组当成这种恢复的完成。
3. 不采用固定 λ=1/64 作为温和起步。此前旧态 10848/10849 的新增源与旧通量比例意味着，要使 λΔG 不超过旧输运，λ 分别约不超过 6.95e-10 / 1.84e-10。它只是初态尺度估算，源会随状态改变，不是建议用亿分之一步长完成加载。应先建立输运人口，再按新态源/输运尺度和实际行质量自适应选 λ；中间模型态仍不计生产点。
4. 下一批应优先定位约 0.3 mV 的密度/QF 映射差，并对一个连通热点初值做有界冻结残差检查，之后才启动加载求解。当前结果未证明局部非线性障碍已消除，亦未产生 float80 或放宽行比的新依据。
