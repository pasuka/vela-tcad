## 实现与偏导验证

实现包含体/二维库仑散射、屏蔽 F/G、掺杂团簇、反型/积累项、体/二维
声子组合、密度相关粗糙度指数和界面距离衰减。没有把 Enhanced Lombardi
重命名为 IALMob；已有模型默认值及历史证据不变。

耦合 Jacobian 对 ψ、电子和空穴准费米势的扰动同时更新浓度、界面场和
高场驱动，覆盖相邻单元场的依赖，并传播到雪崩源项。当前表面路径使用
局部中心差分，不能称为纯解析偏导或符号自动微分。

本轮未知量是等温的 `(ψ, φn, φp)`。对任意参与该边或其相邻单元的未知量
`x`，传输项 `F = μ F_SG` 必须保留乘积法则：

```text
dF/dx = μ dF_SG/dx + F_SG dμ/dx
dμ/dx = μ_n dn/dx + μ_p dp/dx
       + μ_Fdrive dFdrive/dx + μ_Fnormal dFnormal/dx
```

Boltzmann 情形 `dn/dψ=n/Vt`、`dn/dφn=-n/Vt`、`dp/dψ=-p/Vt`、
`dp/dφp=p/Vt`；Fermi 情形必须使用相应统计函数的响应，不能沿用这些
指数导数。边端点平均的两个模型值都要求导，重建场所涉及的第三顶点也
不能遗漏。缩放未知量还需乘电势单位因子。雪崩源若依赖载流子电流，同样
继承 `dμ/dx`。本轮温度、施主、受主、网格几何是固定输入，不是 Newton
未知量；这并不声称已实现热输运或动态杂质电离的 Jacobian。

- 模型性质测试：3 用例、23 断言通过，包含补偿掺杂、两类载流子屏蔽、
  载流子交换对称性、远界面极限、单位一致性、高场速度极限和拒绝未知参数。
- Jacobian：最初 2 用例、450 断言通过，覆盖向量/边 GradQF、电场、
  接触参考、势缩放、Fermi 统计和两种雪崩源映射。随后新增 element-edge
  雪崩路径时发现约 100.69% 差分误差：残差在共享硅顶点的氧化层单元
  中计算了非零雪崩，Jacobian 则排除了该单元。统一半导体作用范围后，
  3 种源路径、两组差分步长通过，并新增氧化层零源项及非活动行检查。
- 最初用低注入状态检查弱交叉块时，双精度大残差相减出现 38 项失败。

  任意微小交叉项都能在双精度下保持同样的相对精度。
- Python/CLI：新增 4 用例，加上审计及续算共 22 用例通过。验证参数单位、

  来自残留的 NewtonSolver 旧对象：Ninja 为该对象记录 `#deps 0`，未因

  同一组测试全部通过。首次失败日志和 GDB 堆栈仍保留，没有作为数值失败统计。
- 用户要求数值运行使用 Release；720 项 Debug 结果用于回归验证，后续

## 固定状态模型回放与空间限制

`prepare_slot_ldmos_ialmob_probe.py` 提取 2 V TDR 的全部 12,410 个 Si
节点及原参数；`ialmob_point_probe` 调用生产模型并导出各散射分量。
`compare_slot_ldmos_ialmob_probe.py` 检查支持集和有限值并报告差异。
原生字段名称是 `eEnormal`/`hEnormal`（metadata 区分大小写），不是缺失字段。
电场投影控制与原生法向场回放分开保存在 `build/i7p`、`build/i7n`。

原生法向场回放的绝对相对误差中位数：电子 0.3457%、空穴 0.2343%；
P95 为 8.3165%、5.9871%，最大为 70.7933%、66.0068%。不得仅凭中位数
宣称严格对齐，也不能把这些局部迁移率差直接解释成相同大小的端电流差。

官方说明 Sentaurus 为单元的每个顶点计算模型，然后默认按单元平均。
当前本地表面传输路径使用边端点迁移率平均、单元中心距离/法向场；两者
存在已知离散差异。导出的节点场与节点迁移率还经过各自平均，非线性模型
和平均运算不可交换。仅关闭高场饱和的 `ialmob_lowfield2.cmd` 单因素控制
已经完成，`build/i7l` 的低场回放中位数误差为电子 0.2547%、空穴 0.2158%，
P95 为 3.8527%、3.8565%，最大为 46.4466%、30.1834%。因此高场驱动
解释了部分局部差异，但低场空间平均等因素仍需继续核对。

离线把节点模型值做三角形算术平均、再以面积权重回投到节点后，中位数
降至电子 0.03689%、空穴 0.02721%，但 P95 仍为 3.1659%、3.4361%。
这是支持空间平均影响的诊断，不是已证实的 Sentaurus 内部输出算法；
不能根据误差更小就直接改变生产平均规则。证据为
`build/i7l/element_averaging_control.json`。

生产路径另修复 IALMob 在有限界面端点外的法向：改为真实界面距离的
梯度（端点外为径向），而不是无限延伸直线的法向。缓存和非缓存路径
保持一致；既有 Lombardi 几何语义未变。新增折角网格性质测试并运行
44 项相关 Release CTest，全部通过（5.91 s）。该修正仍使用单元中心
距离，并未完成原始单元顶点平均。冻结程序运行的 `ir2/is3/is5/is10`
等结果先于此修正；`build/in2` 是独立 2 V 自洽对照，不能混作同一条扫描。
该对照已通过：Id 为 `8.8425574366608805e-16 A/um`，变化
`-0.00011855%`，最大局部行比值 `7.564825733e-6`。因此修正必要，但
不是剩余约 4.58% 端电流差的主要原因。

新增自洽单因素 Sentaurus 对照保持原 IALMob 系数和其余 deck 不变。
2 V 关闭高场饱和使 Id 增加 `0.07851869%`；仅把两类迁移率平均改为
`ElementEdge` 使 Id 变化 `-0.00095361%`。因此在 Sentaurus 端，这两项
开关不能解释百分之几的端电流差；也不能把离线节点迁移率误差的下降
当作相同大小的电流改善。最终目标仍是原始默认 Element。
证据：`sentaurus_ialmob_noav_10/mobility_averaging_controls.json` 和两组日志。
