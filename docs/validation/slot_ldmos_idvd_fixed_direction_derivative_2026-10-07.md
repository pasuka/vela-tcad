# SLOT IdVd 4034 与 4036 固定方向导数核对（2026-10-07）

## 1. 结论

在本次父态与固定方向上，**4034/4036 空穴行的中心差分收敛到解析 Jacobian 方向导数**。最小 h=1/4096 时，相对差分别为 **2.57e-6、3.03e-6**（2.57、3.03 ppm），末段步长误差阶约为 2。

先前大步试探的主要问题是本方向上很强的有限步长通量曲率，不能据该大步误差认定 Jacobian 错误。两条行的二阶响应几乎全部来自通量，复合项贡献很小，电离项在这两行上可忽略。

本批只有冻结态探针，**Newton 接受更新 0、新合格点 0**。物理模型、门槛、账本不变；未重新开始长扫描。这不是整个 Jacobian、全部物理模型或全部节点的普遍正确性证明。

## 2. 身份与核对方法

固定父态：[seed1_t1.h5](../../build/s07balance/seed1_t1.h5)。固定方向：[edge_compact_m25_delta.csv](../../build/s07edgeguard/edge_compact_m25_delta.csv)，来自上一批包含 4046 的紧凑子域、θ=0.25 对照。**本批各档始终使用这一个方向，未重新优化**。

该方向联动 21 个非接触 Si 节点的 ψ/电子 QF/空穴 QF，共 63 变量，h=1 时方向所在的 ψ/QF 箱为 0.3125/3.125 mV。这里 h 是对保存方向的无量纲系数，不是 V。

Vg=5 V、Vd=2.3683165070229464 V、300 K、原点 0 V；13,881 节点、27,275 三角形。Fermi、Bennett–Wilson、Si PhuMob/Lombardi/HFS、SRH/Auger、成对电离及接触电场回退保持原配置。存档电势 V、人口 m⁻³，残差为装配归一化量。

使用 `build/s07e1/runner.exe` 进行真实项评估，解析 J 来自同父态冻结 `build/s07e3/runner.exe` 导出的 `build/s07edgeguard/initial_matrix/matrix/physical.mtx`。矩阵为正则化/闭合替换前矩阵，内部电势导数除以 VT=0.025851999786435535 V。目标两行是自由载流子行；不用接触替换行或零 RHS 候选代替物理残差。

重新评估父态基线后，构造 `x±h d`，h 依次为 1、1/4、1/16、1/64、1/256、1/1024、1/4096。每态根据 ψ 和 QF 重建 Fermi 人口，保留分离参考量/增量表示，未接受求解更新。一次全行探针同时提取残差、净通量、通量绝对和、复合项、电离项；复合项是合并项，本批未拆出独立 SRH/Auger 导数。

比较：

- 解析方向导数 `a=Jd`。
- 中心差分 `D(h)=[r(x+h d)−r(x−h d)]/(2h)`。
- 正/负单边斜率，识别大步不对称与非线性。
- 偶次差 `E(h)=r(x+h d)+r(x−h d)−2r(x)`，以及通量/复合/电离分项。
- 用存档里实际可表示的 ψ 与 QF 增量差重算 `Jd_actual`，排查写出舍入。

另记录 4046 空穴、4034/4036 电子和 10848 空穴作为对照，但结论重点限定在两条目标空穴行。

## 4. 大步误差的定量解释

令 s₀ 为父态行比尺度，取最后一档偶次差估计 `c=E(h)/(2h² s₀)`。局部展开为

`r(x+h d)/s₀ ≈ r(x)/s₀ + (Jd/s₀) h + c h²`。

两条行父态残差已接近零，且 `Jd/s₀≈−0.0005`。测得：

|行|总二阶系数 c|通量贡献|复合贡献|电离贡献|
|---|---:|---:|---:|---:|
|4034 空穴|−0.60890160|−0.60891588|+1.42724e-5|−4.20e-73|
|4036 空穴|−0.47843144|−0.47843816|+6.71845e-6|−9.46e-103|

即本方向局部响应近似为：

- 4034：`r/s₀ ≈ −0.0005 h −0.60890 h²`。
- 4036：`r/s₀ ≈ −0.0005 h −0.47843 h²`。

在 h=1 时，线性模型只给出 −0.0005，而真实父态尺度化残差为 −0.602611/−0.479738。二阶项足以解释绝大部分差异；该展开只在局部具有依据，不将它作为整器件全局二次模型。

本批分项表明曲率来自通量整体，**尚未进一步分离 SG 非线性与迁移率/场驱动力各自的贡献**。不能据此把它全部归因于 HFS，也不能将 4046 的电离源项机制照搬到 4034/4036。

父态两行主要是净通量与复合项抵消；电离项极小。中心差分分项加和与总残差导数吻合，最大相对加和误差分别约 3.02e-12/3.19e-15。

## 5. 对恢复策略的含义

本父态、方向下无需先修改解析 Jacobian。应把健康邻行在有限步长下的真实非线性响应纳入恢复步选择，例如用实测试探误差或局部二阶信息保护 4034/4036，而不是只要求线性预测留在 0.0005。

这仍不能解决 4046 的全部问题：上一批已经观察到它的残差分子下降但行尺度下降更快。健康邻行保护与 4046 的真实行比改善必须同时检查，不能以二阶模型预测通过代替真实全行、全局闭合及完整器件资格。

本批的正负缩放只用于导数诊断，不构成新方向优化、合格步长选择或恢复路径验证。没有从差分结果直接批准新的续算点。
