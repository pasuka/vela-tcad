## 固定方程单位后，有限 RHS 对齐

修正了一处比较口径：分别除以各自 Jacobian 对角，只适合考察各自归一化系统。
当两个 Jacobian 不同时，它会将导数差异混入 RHS 差异，不能直接解释成物理残差不同。

以先前低场同态控制中已吻合的算子，独立标定 native/Vela 的方程行单位比，并固定到
所有后续迭代。载流子行单位比均约 `24710.88096377`；电路约 `421026.81018387`，
自由 Poisson 行约 `0.9831932773`，等价变换后的接触势行为 1。
这不是每个新状态重新拟合对角，也没有平移 QF 或拟合物理参数。

使用公共方程单位后，直接冷启动的 index 1（外压 0、内压约 `2.50444e-12 V`）中，
保留完整高场、SRH 和 VanOverstraeten 雪崩的电子/空穴 RHS 相对 L2 差为
**`2.35992e-11 / 2.87887e-11`**。原先自身对角归一化下的数值仍保留为独立指标，
不再将它等同于公共单位下的物理 RHS 差异。

## 本构与导数控制

隔离候选先在各节点按总杂质计算 Masetti 低场迁移率，再作单元 box 体积平均和边的
几何加权。高场部分显式保留 Canali 饱和：单元 P1 QF 梯度、真边界的切向投影、
接触单元的完整电场回退，以及既有 1 V/cm 分支。它是待验证候选，不能仅凭复用已有
helper 就认领 PN2D 原生资格。

完整切线控制补齐每条边的所有相邻单元顶点列，包含 `dμ/dF × dF/dψ` 或
`dμ/dF × dF/dQF`；同时在固定迁移率 SG 部分使用稳定的掺杂 BGN 电势导数。
后者修正了原型中较后零偏状态的电势方向差分误差：电子/空穴约 `7.71% / 5.49%`
降至 `3.37e-9 / 3.78e-9`（scaled step=1e-6）。

有限 RHS 的 index 1 上，三个输入块、三个输出块的方向差分在 step=1e-5 的最大
相对块误差约 `3.23e-6`，低于既有 1e-5 方向检查门。不同步长和其他状态全部保存；
近零交叉块受消减影响，部分步长仍失败，没有把某一个成功方向扩张成全矩阵资格。

原生 Newton 切线与完整残差导数仍有差别。一个经验隔离切线采用冻结高场迁移率的
输运 Jacobian，不加入 Vela 雪崩 Jacobian；**它只替换诊断矩阵，原来的完整 RHS、
参数导数、端口、状态和物理接受评估继续使用原问题**。对应三态的完整 RHS 导出与
未替换切线的控制逐位相同，未通过关闭物理源项取得残差一致。

| 同态 | 电子矩阵最大行相对 L2 差 | 空穴矩阵最大行相对 L2 差 |
|---|---:|---:|
| Poisson 初始化后，index 5，内外压均 0 | 3.60e-14 | 3.78e-14 |
| 直接冷启动 index 1，有限 RHS | 7.56e-14 | 6.74e-14 |
| 直接冷启动 index 5，较后迭代 | 3.59e-4 | 6.37e-2 |

前两行是实际数值吻合的经验约束，不能推出原生内部在所有状态都“关闭了雪崩导数”。
最后一行表明本构平均/驱动契约尚未闭合，不能将这个近似切线晋升为模板。
另行试验先平均相邻单元梯度向量、再统一做高场修正（面积权重和边 box 权重两种），
index 1 矩阵差反而扩大至电子约 1.21、空穴约 0.859，index 5 空穴仍约 6.32%。
这两个候选被保留为失败控制，没有替换单元候选或生产设置。
index 1 的载流子最大逐分量线性后向误差仍约 `2.54e-7 / 5.76e-6`，未过 1e-10 门；
近零 Poisson 行还会给出最大误差 1。因此没有生产方向替换或写回接受资格。

## 状态序列化传播

新增 [精度工具](../../scripts/native_debug_precision.py) 直接解析每个 VAR 的原始 token，
保留尾零和指数。例如 `-1.56139203128890E+01` 的末位量化单位为 1e-13。
在按最近值舍入的条件下，以半个末位量化单位为半径，在公共坐标中传播 `|J| r`。
这是**一阶状态序列化估计**，不包括非线性余项、材料误差及装配运算误差，也不证明
输出器内部一定采用该舍入方式。

| 原生材料 oracle 控制 | 电子 RHS 差 L2 | 空穴 RHS 差 L2 | 电子/空穴一阶半径 L2 |
|---|---:|---:|---:|
| 主零偏同态 | 3.43e-6 | 4.10e-6 | 1.70e-5 / 1.70e-5 |
| 直接冷启动 index 0 | 7.47e-8 | 8.96e-8 | 2.09e-5 / 2.09e-5 |

这两态所有载流子行的差异都在各自一阶半径内。主零偏仍有 66 个 Poisson 行超出
该逐行估计，不能宣布全系统均已由序列化解释。原边平均控制的有限 RHS index 1
有 991 个电子行和 991 个空穴行超出范围，排除了以输出精度解释原本构差异。
没有增加分母下限或放宽既有验收门。
