## 已确认的权重依赖与舍入顺序

原生以顺序初猜生成根，初猜混合 binary64 和 binary80 运算；Laguerre 多项式递推、导数、
Newton 修正及权重运算采用逐次 binary80 舍入。根修正的绝对停止值为约 1e-15，最多 10 次；
本批实际每根 4–9 次，未耗尽迭代预算。该停止值与上一轮 η 反算的约 1e-9 控制分开记录。

令 z_old 为最后一次多项式评估坐标，P、P_prev、D 分别为 L_n、L_(n−1) 和导数：

```
z_new = R80(z_old − R80(P / D))
G = R80(exp(R80(lnGamma_approx(n+α) − lnGamma_approx(n))))
w = R80(−G / R80(R80(n × P_prev) × D))
```

节点保存 z_new，权重仍使用 z_old 上的 P_prev 和 D，未在保存坐标上重新评估。
本批最大的已存坐标修正约 9.37e-16；微小坐标差可通过多项式／导数放大到权重。
归一化使用已识别的固定 14 项 Lanczos 系数及实际对数／指数路径，未按表总和重新归一化。

独立 Release 诊断生成器只输入阶数和 α，保留已识别的固定算法系数与混合精度顺序；
不读取原生节点、权重、η、a 或 B，也不拟合状态相关常数。它显式确认 x87 控制字和
64 位有效数字。在本机和 T470p 上均得到：

| 检查 | 结果 |
| --- | --- |
| 根迭代总数及逐根计数 | 1538，240/240 相同 |
| 节点／权重 | 各 240/240 逐位一致 |
| 最后一轮 P_prev／D | 各 240/240 逐位一致 |
| 首根两次 lnGamma 返回 | 逐位一致 |
| 240 次归一化指数因子 | 逐位一致 |
| 公共有理数舍入审计的五个代表根 | P_prev／D／权重一致 |

生成器源码、编译参数和哈希保存在本轮 ignored 证据目录。
新增[公共多项式／权重依赖审计](../../scripts/bvmethods_laguerre_rounding_audit.py)，
以精确有理数模拟有限有效位数，显式区分评估点和更新根。
本批通过范围为 n=240、α=1/2；不推广为全部阶数、材料或硬件的厂商数学库等价性。

## 归一化及误差来源分离

用独立 100 位数学控制评价 Γ 比值和 2/sqrt(π)，得到：

| 项目 | 差异 |
| --- | ---: |
| lnGamma_approx(240.5) − 定义值 | −9.94819e-16 |
| lnGamma_approx(240) − 定义值 | −1.00673e-15 |
| 两者作差并取 exp 后的 Γ 比值相对差 | +1.19150e-17 |
| 原生 binary64 归一化前因子相对差 | −1.35907e-17 |
| 逐次多项式舍入与同一旧坐标 100 位评估的权重最大相对差 | 4.93292e-14 |
| 同一算法因子下，旧坐标／保存坐标的 100 位评估权重最大相对差 | 7.23917e-14 |

分项最大值可能来自不同根，不直接相加。Γ 两个约 1e-15 的绝对误差在作差时大幅抵消；
权重差异还包含多项式递推舍入及最后评估坐标，不能全部归因于归一化因子。

以下控制保持自主生成的节点，分别改变权重评估方式；没有强制令表总和等于 1：

| 控制表 | 归一化权重总和减 1 |
| --- | ---: |
| 原生顺序自主生成 | +3.87502e-15 |
| 在保存节点重新以 binary80 评估权重 | −2.33628e-16 |
| 在原最后评估坐标用 100 位评估 | +3.58734e-15 |
| 在保存节点用 100 位评估 | −2.88433e-16 |
| 上项再使用数学 Γ 比值及前因子 | −2.86757e-16 |

刷新 binary80 权重改变 109/240 个值，单个权重最大相对变化约 1.31e-13。
这些是诊断控制，不作为生产权重修复；原生生成顺序的偏差已被无拟合地复现。
