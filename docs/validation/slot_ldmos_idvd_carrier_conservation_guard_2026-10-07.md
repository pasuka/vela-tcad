# SLOT IdVd 载流子残差与守恒保护诊断（2026-10-07）

## 1. 结果

已把三个残差块、分载流子守恒失配和闭合比纳入独立诊断保护，并完成同物理、同 63 自由度子域的有界验证。**两条独立初值链共接受 3 次局部诊断更新，所有接受更新均满足真实残差与守恒不恶化、无新增超标行。**

从最初人口种子出发的两步对照，将 ψ/电子/空穴块残差分别降低约 26.28/3.55/1.13 倍，电子/空穴闭合比从 1.01577/0.203125 降至 0.425919/0.101903。原有 147 条超标行仍在，最大行比仍为 1.630014，**新增合格点 0**。

本批修正了上一批“只要 ψ 主导的局部范数下降即可接受”的缺陷；尚未解决完整器件收敛。生产物理、门槛、账本均未改，未恢复长扫描。

沿用 [上一批联动修正](slot_ldmos_idvd_guarded_coupled_repair_2026-10-07.md) 的配置：Vg=5 V，Vd=2.3683165070229464 V，300 K，电势原点 0 V；13,881 节点、27,275 三角形，25,268 条有效载流子行。密度存档为 m⁻³，电势增量为 V。

Fermi、Bennett–Wilson、Si PhuMob/Lombardi/HFS、SRH/Auger、成对电离及接触电场回退不变。原 abstol=1e-9、reltol=1e-8、行比 0.001、全局闭合 0.01、QF 边界不变。未冻结迁移率、删除源导数或放松资格。

两个初值：

- `last`：[上一批末态](../../build/s07joint_guard/c2_t0.h5)，ψ 较好但载流子与守恒恶化的诊断态。

身份文件：[identity.json](../../build/s07balance/identity.json)。没有生产 C++ 变更；局部约束优化使用 SciPy SLSQP，真实残差使用冻结 C++ 探针，不能将局部优化器成功标志当作整器件 Newton 收敛。

## 3. 新的方向约束与接受规则

### 3.1 分块目标，避免 ψ 独占权重

对当前父态三个完整残差块，分别定义预测量

`b_k(d) = (r_k + J_k d) / ||r_k||₂`，k=ψ、电子、空穴。

局部目标为三个 `||b_k||₂²` 与两个归一化守恒失配平方之和；附加每块 `||b_k||₂≤1`。因此不能通过牺牲一个载流子块换取 ψ 改善。归一化每次以该父态为基准，跨步比较仍看真实物理块残差与闭合值。

电子/空穴失配 `m=接触通量−积分源`，源由非接触节点复合及电离项构成。已按当前实现核对 `m = −Σ有效自由行 r_i`；相应方向导数由这些物理 Jacobian 行求和获得。每次父态求和与独立守恒探针的失配一致到 1e-10 相对范围内。

预测约束为 `|m + Dm·d|≤|m|`。这约束绝对失配，**不能保证闭合比不增大**，因为真实源/通量尺度也会变化；因此闭合比在试探后的真实评估中另作必需检查。

保留健康受影响邻行预测保护（上限 max(初态行比,0.0005)），以及 ψ/QF 信赖箱：1.25/12.5 mV 或 0.3125/3.125 mV。候选 QF 与 ψ 改动后重新计算 Fermi 密度。

### 3.2 真实接受条件

每个实际试探都重新做全部有效行审计和独立守恒探针，必须同时满足：

1. ψ、电子、空穴块残差分别不增大。
2. 电子和空穴的绝对守恒失配分别不增大。
3. 电子和空穴的闭合比分别不增大。
4. 不新增行比超过 0.001 的有效行。
5. 三个真实块范数的父态归一化平方和小于 `3−1e-5`，排除零步。

“不增大”比较仅使用 1e-10 的相对舍入余量，是本批诊断比较容差；没有改变最终器件资格门槛。线性约束不满足、优化失败或无可验证改善的方向，不执行真实试探。任何诊断接受态仍不能入生产账本。

### 4.2 变量标度与预测约束的局限

last 链第二步出现零步/优化线搜索失败，因此补做同父态、同矩阵、同目标和约束的列尺度平衡对照。仅在优化器内部改变变量坐标，保持实际 V 增量箱不变。

两档都重新找到非零、满足预测约束的方向，说明先前零步不是可行集只剩零点的证明。但是两次真实试探均被拒：

这与有限步长非线性曲率、约束模型误差相容，尚不证明唯一原因或支撑范围无解。补充批墙钟 82.04 s，未接受新态。[补充 summary.json](../../build/s07balance_scaled/summary.json)。

### 4.3 尚未解决的部分

两链末态最大行比都为 1.630014，最差是子域外 4046 空穴行；随后是 4045、4044、10837、4041 空穴行，均不在本次可变的 21 节点集合中。当前结果支持对子域覆盖及阻塞边缘作进一步检查，不能据此认定只扩范围就能成功。

本批没有完整 Newton 资格通过态，未跨任何新的生产路径目标。守恒比虽然下降，仍远高于 0.01。
