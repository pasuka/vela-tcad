# SLOT 混合精度三步重线性化对照

日期：2026-10-11。Vg=5 V、Vd=5 mV、原点0 V，使用同一冻结父态和求解器，
比较 double 与 long double 线性后端在真实 Newton 更新中的效果。

**long double 在三步内减少了部分超标行，但没有明显改善主导块残差、最大行比或
全局闭合。两臂均未通过完整资格，新增合格点0；默认配置保持不变。**
两臂都是到本批三次更新上限后停止，不能据此断言更长迭代必然不收敛。

## 固定条件和预算

- A：`VELA_LINEAR_SOLVER=sparselu`；B：`sparselu_long_double`。
- 冻结求解器沿用上一批 `build/s11float80/runner.exe`，SHA-256
  `c70123323bdc7b60fcb99ffd334c308e99e53edaa5ad501fa99bb10bd11034dd`。
- 同一父态 `build/s10initial05/v5_qf.h5`，SHA-256
  `9db915c19425d3936fab2895751a7569c7381e2cc4a753321e52c7166463a9ff`。
- 同一13881节点SLOT网格、材料和掺杂，完整物理、Fermi/effective_band_sg、
  AverageBox、接触电离回退均不改变。输入文件哈希写入contract.json。
- 保留回溯merit线搜索、分量QF限幅及Poisson重修正、1e-8载流子行正则化、
  `replace_free_row_sum`；没有切换到Bank–Rose，也没有更改接受准则。
- abstol=1e-9、reltol=1e-8、eps_row=0.001、闭合容差0.01及其它原资格不变。
- 两臂串行，每臂最多3次更新，软/硬截止360/450秒，总兜底1000秒。
  为避免解析器把3自动提升到24，将 `min_newton_max_iter` 同样设为3；
  这是诊断迭代预算下限的修改，不是残差或行比门槛的修改。

两份配置除输出路径外完全相同，后端通过进程环境选择。
long double 仅覆盖共享线性求解器的分解/回代；装配、状态、Woodbury小矩阵
和修正组合仍为double。B后端目前不缓存分解，因此耗时包含精度与缓存策略的差别，
不是纯粹的硬件浮点指令速度比较。

## 方向处理与局部差异

两臂每步均α=1、仅一次线搜索试探，没有发生回溯缩步。
每次都重新装配自身新态上的残差/Jacobian；后两步的矩阵不要求彼此相同。

|步数|A原始方向范数|B原始方向范数|A处理后范数|B处理后范数|A/B处理改变自由度数|
|---|---:|---:|---:|---:|---:|
|1|699154.85|699312.12|118.12|116.91|16463 / 12792|
|2|27573.05|27569.13|119.22|117.42|16848 / 13906|
|3|9274.84|9983.71|72.64|73.44|14147 / 9829|

这里“处理改变自由度数”使用现有 `cap_changed_dofs`：比较原始与处理后方向，
包括Poisson重修正及数值微差，并非单纯撞到载流子限幅上限的节点数。
请求非零但实际更新为零的自由度数A为26/25/81、B为25/28/80，未出现显著改善。

末态最大ψ差仅3.28e-15 V，但最大电子/空穴QF差分别0.7218 mV/0.163475 V。
最大空穴差在10280节点：

|量|A|B|
|---|---:|---:|
|HDF5人口，m^-3|1.016497947e8|1.823249226e5|
|换算人口，cm^-3|101.6498|0.182325|
|行比|1.002779|1.003620|

该行两臂都未通过，B人口反而更低。说明更精确的线性分解不保证每一条低密度行
都沿更好的非线性路径前进。它也阻止了“电流近似相同，所以全场近似相同”的推论。
密度取自带 `m^-3` 单位属性的HDF5；进度JSON的 `density_m3` 在本批实际仍是
内部cm^-3数值，差1e6，未将该错误标签直接用于单位换算。

## 审计和判断

实际总运行约227秒；两臂各3次接受更新，均因预设迭代数退出（退出码1），
未触发时间截止或异常退出。保存final.h5的数值字段与各自第三次接受态逐值相同。
runner、父态、网格、材料、掺杂哈希未改变，没有恢复续算或写入生产账本。
本批没有修改C++源码和默认值。

记录审计通过：配置单因素检查、初态字段及指标一致、输入哈希、完整超标行清单计数、
每臂不超过3次更新、末态绑定。它不是独立数值复求，也不是Sentaurus定量对照。
完整逐步结果及集合比较分别保存在iterations.csv和audit.json。

本批将上一批“线性残差改善”的证据推进到了“部分真实超标行减少”，但未显示
主导残差和闭合的改善，故仍不支持把long double设为生产默认，亦不证明完整
float80装配无效。首次成本观察B约多17.6%，不作为跨工况性能承诺。

下一项有辨别力的工作是对10280等分叉节点，在同一冻结态上比较两种线性方向，
分开量化正则化、Woodbury组合、QF限幅与Poisson重修正对人口和邻行的影响。
应以真实行质量和闭合改进为继续依据；不能从少数坏行减少直接推到长扫描。
