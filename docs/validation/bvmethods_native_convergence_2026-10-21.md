# BVmethods 原生前五个非零接受点：Vela 收敛规则复核

## 结果及更正

把当前无 BTBT 控制的 Vela 强制规则应用于原生接受态的实际方程操作数，**五个点均被拒绝**：
局部载流子行门、电子全局连续性闭合都未通过；空穴全局闭合通过。
原生 `.plt` 的负载线和端口 KCL 五步均通过。完整相对残差、停滞保护和 Vela 线搜索过程
尚未完成同口径绑定，不填成通过，也不因缺失这些检查而掩盖已确定的强制门失败。

必须更正上一轮报告：当时把 `C0*D0` 当成 SI 粒子尺度，遗漏 TCAD 内部单位的
`currentDensityAM2PerInternal * lengthMPerInternal = 1e4 * 1e-6 = 0.01`。
正确的原生到 Vela 行系数为 `7.950490318918126e-9`，不是 `7.950490318918125e-11`。
原生单位中的源资格 floor 因此从错误的 `1.2577840609660368e-8` 更正为
`1.2577840609660366e-10`。共同缩放不改变单行 r，但会改变源资格集合和集合内的最大值。
上一轮“第 2～4 步行门通过”撤回；原始数据、旧统计和旧报告在 ignored 目录保留。

证据：format_version 2 加载器将 `parseUnitScalingConfig` 交给 Newton；当前 checkpoint
浓度单位为 `1e6 m^-3`、长度单位为 `1e-6 m`，与 `PhysicalUnitSystem::tcadInternal()` 一致。
当前 `C0*D0=1.8645832401965927e22` 已与私有实际装配元数据绑定。

## 检查范围

沿用上一轮已封存的 15 套 6843 阶线性系统、五个实际接受态的 21210 条自由载流子行、
逐元素执行操作数及完整端量轨迹；本轮离线复算，没有新启动 VM 或 T470p 求解。
原生物理为无 BTBT 的 Fermi/OldSlotboom、掺杂／表面／高场迁移率、SRH、雪崩和外电阻；
2600 节点、5020 三角形、4156 个 Si 单元。原生日志线性求解器为 blocked decomposition、
非线性为 Bank/Rose，线程数 1。

这是**把 Vela 规则施加于原生操作数**的检查，不是宣称这些态已经在 Vela 的 barycentric
离散、QF 人口映射及边界实现中完成重新装配或重新收敛；也不替代 NonLocalPath 原版全物理验收。

## 逐项判定

| 规则 | 当前设置／语义 | 五点判定 |
|---|---|---|
| 电子局部行门 | 源资格 `1e-18`，r <= 0.001 | 全部不满足 |
| 空穴局部行门 | 同上 | 全部不满足 |
| 电子全局连续性 | 源资格 `1e-14`，闭合比 <= 0.01 | 全部不满足，均有资格 |
| 空穴全局连续性 | 同上 | 全部满足，均有资格 |
| 主绝对残差分支 | 归一化三块范数 <= 1e-18 | 原生自由行投影下界已超限，全部不满足此分支 |
| 主相对残差分支 | 当前三块范数／初始三块范数 <= 1e-8 | 未最终判定：需初态、Poisson、约束及内压未知量的同口径绑定 |
| 停滞残差分支 | floor 1e-9，或 Poisson 停滞保护等附加条件 | 不能仅凭小残差宣告通过；强制行门及电子闭合失败已阻断所有这些接受分支 |
| 固定接触 QF 分支守卫 | `contactMajorityQfBranchDropLimit_V=0` | 未启用，不算数值通过 |
| 分块绝对残差上限 | `block_absolute_convergence.mode=off` | 未启用 |
| 更新误差 E<1 | 原生终止条件；当前 Vela off/report 不据此接受 | 原生五点满足，但不属于当前 Vela 强制终止门 |
| 迭代预算 | max_iter=20 | 五点各 3 轮，在预算内；不是充分收敛证据 |
| 已导出变量和残差有限、自由人口为正 | 实际导出及受保护更新重建 | 五点满足此数据检查；不替代 Vela 重新求人口 |
| QF 限幅／Poisson 回代／线搜索 | QF 0.1 V；merit 包含全局项 | 未判定 Vela 是否会接受相同原生步骤，需要其实际方向／试步流程 |
| 外电阻负载线 | 输出端量 `|Vout-Vin-RI| <= 1e-6 V` | 五点满足 |
| 端口 KCL | 输出总电流，`|sum I| <= max(1e-12,1e-5 max|I|)` A/um | 五点满足 |
| 完整 Jv／同态 RHS 一致性 | 1e-5／1e-8 算子验证契约 | 不是本轮单态终止规则；不得用原生矩阵线性后向误差代替 |

主绝对和相对残差是“或”，不是每个都必须通过。但主条件、局部行门、全局闭合及启用的
分支守卫是“且”。当前两个强制门失败已足以判定不接受，无需将未知的相对分支强行填为失败。

全局门严格按 `evaluateGlobalContinuityClosure`：

\[
g_c=\frac{|\sum_{\rm contact}F_c-\sum_{\rm free}S_c|}
{\max(|\sum_{\rm contact}F_c|,|\sum_{\rm free}S_c|,10^{-14})}.
\]

分母使用**接触通量代数和的绝对值**，不是各端口电流绝对值之和。
两个很大的相反通量抵消后，净源很小，微小绝对不闭合也可对应很大的 g。
五态净源在当前行单位下约 `2.93e-11` 到 `3.42e-10`，均超过 `1e-14` 资格阈值。

接触通量从同一全局边账本重建；自由行源从同一原生实际源数组积分，不用 `.plt` 替代。
独立检查 `contactFlux-integratedSource = -sum(free residual)`，其差相对于总通量累加尺度
小于 `4e-18`，远小于本轮不闭合量。读取的最后一轮 RHS2 与更新后实际载流子残差
符号相反，五态十个块的相对 L1 差小于 `1e-12`，因此没有拿更新前 RHS1 充当终态残差。

下界只取非负的两个自由载流子 L2 项；本原生投影初始两块小于 1，所以默认块尺度取 1。
它不能用于宣称完整 Poisson／约束映射已通过，也不能直接给出 Vela 自己初态的相对残差。
原生是有独立内压未知量的增广系统，当前 Vela 生产外电阻路径的固定内压设备内循环
采用另一初始边界状态；重启态的相对范数分母也不同。直接拿日志 `|Rhs|` 相除会混淆这些身份。

## 输出电流与方程通量的区别

若将 `.plt` 各载流子端口电流代入闭合式，五步都约 `1e-5`，会通过 1% 门。
但 Vela 当前实现使用装配器的通量与源，不是 `.plt` 输出字段。
上一轮发现的单端口约 `1e-5` 相对差，在端口相消后的净量上可以成为 10%～57% 的差异。
这不是“电流本身有 57% 误差”，也不能仅据此宣布原生电流已做某一种修正；
其输出收集与装配身份仍待查。两种账本都保留，不把其中一种替换成另一种以通过门限。
