# SLOT 行比容差、局部修正与 PETSc 参数对照（2026-10-02）

## 结论与资格边界

本次证据不支持把生产 `eps_row=0.001` 直接放宽到 0.002。
它对本点漏极电流确实比实际可观察到的差异更保守，但并非不可达到：
只修正 Si 节点 3588/3591 的空穴准费米势 5.706/6.692 nV，即可在
**全部原器件门槛下通过**，并重复得到相同结果。阻塞与局部弱行修正、
邻接耦合以及整体 merit 的协调有关，不能仅归为容差数值过严。

这是独立诊断：生产账本、生产配置、求解器、原证据均通过哈希不变检查；
正式新增接受点 **0**，长扫描和监测保持停止。诊断通过的器件态没有执行
实际外压确认，也没有进入续算账本，不称为完成击穿。

证据：[汇总](../../build/s02rowtol/final_analysis.json)、
[容差及 ULP 分析](../../build/s02rowtol/analysis.json)、
[脚本](../../build/s02rowtol/run.py)、[阻尼局部对照](../../build/s02rowtol/damped/summary.json)。

## 算例、输入及预算

- 输入是 `s02bvgoal/p11_r2/poisson_post/d/final_state.h5`，即最后失败尝试的
  严格求解初态；基准 deck 是该尝试的 `strict/config.json`。
- 物理内压 38.505116014951696 V；参考原点 36 V。固定内压诊断关闭外电阻求解，
  派生外压仍按 `U=V+1e12*I` 计算，单位 V、A/µm、Ω·µm。
- 300 K，13,881 节点、27,275 单元；电子/空穴各 12,634 个有效物理行。
  保留 observed-geometry IALMob、原生输运耦合、碰撞电离、体积和接触配置。
  本实验没有解决原生几何依赖，也不建立模型独立性。
- 使用已有 UCRT64 Release 诊断 runner `build/s02merit/runner.exe`，SHA-256
  `20f5e126f06311ba1b7dbbdb0f83b21fba7c9f3d47d0b477ede3d81e5d86bbf3`。
  使用现有 HDF5 状态及默认直接求解后端（该构建启用 UMFPACK，运行入口清除
  `VELA_LINEAR_SOLVER` 覆盖）；没有使用 PETSc 求解，也没有重新编译。
- 主批上限 1200 s，针对性补批分别上限 600/400/400 s，串行执行，单次求解
  ≤120 s、冻结探针 ≤60 s。实际四批墙钟分别 306.48/66.33/80.07/97.75 s，
  合计约 550.63 s；67 个子进程累计 517.65 s，最长 39.32 s，0 次超时。
- 保留 HDF5 2.2.0 运行库与 h5py 2.1.1 构建版本不匹配警告；本批未发生
  I/O 失败，状态重复和哈希核对通过，但这不消除该环境警告。

## 1. 同一初态，只改变行比容差

其他物理和停止参数不变，统一固定内压；下表的“通过”仅针对对应诊断容差。

| eps_row | 严格求解结果 | 接受 Newton 更新 | 解释 |
|---|---|---:|---|
| 1e-4 | 失败，3 条行超标 | 0 | 线搜索拒绝 |
| 5e-4 | 失败，2 条行超标 | 0 | 线搜索拒绝 |
| 1e-3 | 失败，1 条行超标 | 0 | 复现生产停止 |
| 1.25e-3 | initial_abstol 接受 | 0 | 仅接受已有初态 |
| 2e-3 | initial_abstol 接受 | 0 | 仅接受已有初态 |
| 1.25e-3 重复 | initial_abstol 接受 | 0 | 场和电流逐值相同 |

三个放宽试验的 SG 漏极电流均为 `6.127421940431984e-10 A/µm`，
物理场、源项及原行比没有改善。另用**原 0.001** 重新审计保存态时，仍有
节点 3591 空穴行超标。因此不能以放宽后的成功标志或零电流差证明精度。

继续一次/两次全载流子修正加 Poisson 修复后，电流相对初态分别变化
−0.76499%/−5.03784%，最大空穴行比分别恶化到 0.02510/0.03383。
两者均不通过原资格，不能当作更准确参考解。
从上一合格态独立启动同一内压，接受 5 次 Newton 更新后仍有 4 条行超标，
最大行比 0.03874；故本批尚未取得独立初始化的同分支复现。

## 2. 局部行及表示敏感性

节点 3591 坐标 `(0.00820661, 4.41977539) µm`，为 Si 有效空穴连续性行。
其残差 `−5.594594515066507e-21`，尺度 `4.5389498819842354e-18`，
行比 `0.0012325746396258485`。尺度由碰撞电离项主导，远高于 `1e-30` 下限。
方程项沿用无量纲组装单位，不能直接标为 A/µm。

同态冻结重评估两次，残差逐位相同。保持其余文件字段不变，分别对该节点
物理 ψ、权威空穴 QF 增量作 ±1/±10 ULP 扰动：

| 坐标 | 1 ULP / V | 所测最大残差变化 |
|---|---:|---:|
| ψ | 7.10543e-15 | 1.18614e-29 |
| 空穴 QF 增量 | 1.69407e-21 | 1.15556e-32 |

使原态恰好通过原相对阈值所需的额外绝对容许量为 `1.05564e-21`，约为
所测最大 ULP 响应的 `8.9e7` 倍。**不支持把该超标归为上述坐标的表示底限。**
这仅是两种坐标、一个节点的敏感性测量，不是全部边运算舍入误差的严格上界。
未导出全部边公式相消前操作数，不能据此宣称所有浮点误差已被排除。

## 3. 原门槛下的针对性对照

使用冻结行残差的中心差分（QF 扰动 ±1e-6 V）构造局部导数。
先修节点 3591，其残差下降，但邻接 3588 行比上升到 0.002135；
再对 3588/3591 做两节点线性修正，完整步仍有邻接行超标（0.001069）。
这说明逐节点残差不能各自独立消除而忽略邻接通量。

最后仅采用该两节点修正的 **0.5 倍阻尼**：

| 指标 | 结果 |
|---|---:|
| 3588 空穴 QF 修正 | +5.706172e-9 V |
| 3591 空穴 QF 修正 | +6.691520e-9 V |
| 最大电子行比 | 3.157674e-6 |
| 最大空穴行比 | 6.162872e-4 |
| 全有效电子/空穴行 | 各 12,634，均通过 |
| 实时全局电子/空穴闭合比 | 7.241248e-7 / 7.240950e-7 |
| 原完整 Newton 验证 | initial_abstol，0 更新 |
| 相同修正种子重复验证 | 原完整资格通过，场和电流逐值相同 |

上述 0 更新是**局部修正之后**的完整验收；两次均生成并重新核对原器件资格和
文件绑定证明，不是 frozen_state 的 `converged` 标志代替设备验收。
空穴密度与 QF 依 Boltzmann 关系同步；最大逐点密度变化约 `2.5884e-7`。
更紧的 5e-4/1e-4 验证仍失败，因此本批未证明这两个门槛可达或更有收益。

原始不合格态与该原门槛通过态的比较：

- 内压相同；SG 漏电流均为 `6.127421940431984e-10 A/µm`，在输出精度下相同。
- ψ、电子 QF、电子密度逐值相同；仅两个空穴 QF 改变，最大约 6.692 nV。
- 组装复合源的有符号总和相对变化约 `2.072e-12`，逐行差的相对 L1 为
  `1.632e-12`；碰撞电离总和在本计算精度下相同，逐行差的相对 L1 为 `5.507e-21`。
- 派生物理外压为 `651.2473100581501 V`，未做负载线确认，不能当作扫描已接受点。

本次得到“同内压、相同计算电流”的局部对照，**没有另做目标电流求根**。
主批分析中的等电流内压偏移是历史割线推算，已明确标为估计，不能冒充独立
同电流验证。在此次阻尼对照中电流差为零，也不意味着真实误差严格为零。

## 4. PETSc 是否有类似参数

查阅的是官方当前文档，不把不同误差定义的数值直接对应。

| PETSc 接口/参数 | 定义 | 与本行比的关系 |
|---|---|---|
| `SNESSetTolerances` / `-snes_atol` | 函数残差范数的绝对容差 | 不按每个节点的通量/源项归一化 |
| `-snes_rtol` | 相对于初始残差范数的下降 | 不是每行局部守恒误差百分比 |
| `-snes_stol` | 更新量相对于状态范数 | 小更新不自动证明局部方程满足 |
| `SNESSetConvergenceTest` | 自定义收敛函数 | 可加入 Vela 类似的逐行、块及闭合检查 |
| `TSSetTolerances` | 分量级绝对/相对容差向量 | 用于时间积分局部截断误差；仅可借鉴形式 |
| `TSErrorWeightedNorm` / `VecErrorWeightedNorms` | 绝对+相对容差加权误差范数 | 可选 infinity 范数；不是 SNES 自动启用的本行比 |

官方来源：
[SNESSetTolerances](https://petsc.org/release/manualpages/SNES/SNESSetTolerances/)、
[SNESConvergedDefault](https://petsc.org/release/manualpages/SNES/SNESConvergedDefault/)、
[SNESSetConvergenceTest](https://petsc.org/release/manualpages/SNES/SNESSetConvergenceTest/)、
[TSSetTolerances](https://petsc.org/release/manualpages/TS/TSSetTolerances/)、
[TSErrorWeightedNorm](https://petsc.org/release/manualpages/TS/TSErrorWeightedNorm/)、
[VecErrorWeightedNorms](https://petsc.org/release/manualpages/Vec/VecErrorWeightedNorms/)。

结论：没有找到 PETSc 默认选项中与 Vela `eps_row` 完全等价的参数。
`-snes_rtol 0.001` 不能作为替换值；当前 Vela 也不使用 PETSc 后端。

## 5. Wolfram 数学核算与可选判据

已调用 Wolfram 上下文工具和 Wolfram Language evaluator；数值结果归档在
[`wolfram_result.json`](../../build/s02rowtol/wolfram_result.json)。未让 Wolfram
“认证”本算例精度；它完成的是给定公式的计算。

现有尺度 `S_i=max(sum|flux_ij|, |R_i|, |G_i|, floor)`，残差比是
归一化方程不平衡，并不直接界定电流或状态误差。局部线性化在 Jacobian 可逆时有
`delta_x ≈ -J^{-1} r`；端口目标的伴随估计满足 `J^T z = grad(I)`、
`delta_I ≈ -z^T r`。这些一阶关系需要分支正确、线性化可靠；折返附近尤其不能
把小残差直接换算为小物理误差。本批没有计算端口伴随误差界。

可研究的形式是保留全有效行的混合阈值：

```
eta_i = |r_i| / (a_i + tau_rel * S_i),    max_i eta_i <= 1
```

其中 `a_i` 必须来自独立测得的数值底限或明确的绝对物理误差预算，不能根据
失败残差倒推一个刚好通过的值。Wolfram 的
[ScaledVectorNorm](https://reference.wolfram.com/language/tutorial/NDSolveVectorNorm.html)
提供类似的绝对+相对容差形式，但其用途是误差控制，并非本 PDE 的资格依据。
本次额外容许量 1.05564e-21 远高于所测 ULP 响应，**没有依据把它设为数值噪声容差**。

两个不宜直接替换的选项：

1. 把分母改成所有项绝对值之和：该行分母增至原来的 1.99877 倍，行比变成
   0.000616667，原态立即通过；只是改变归一化，不代表物理误差下降。
   方程项允许独立扰动时这种形式可解释为分量误差尺度，但物理通量和源项相互
   关联，不能据此直接宣称是整个非线性模型的严格后向误差。
2. 把逐行最大值改成全行 RMS：单个 1.23257 倍超标行对 12,634 行 RMS 的贡献仅
   0.01097，可能被大量合格行稀释。这里仅计算该行贡献，非全部行 RMS 的值。

建议优先保留 `eps_row=0.001`，把改进放在**满足原全局条件的局部行下降与
邻接修正阻尼**，而不是单改数字。若后续需要验收参数变更，再建立跨偏压、
跨电流的容差敏感性和底限数据，并把端口目标误差检查作为补充，不能删除局部
守恒要求。本次两节点修正仅证明单点方法可行，尚未集成生产或验证连续稳定性。
