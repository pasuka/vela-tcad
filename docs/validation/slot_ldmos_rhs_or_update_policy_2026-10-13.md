# SLOT RHS 或原始更新误差停止策略（2026-10-13）

## 范围与规则

按用户明确选择，仅当前 `simulation_type: slot_population_memory` 入口默认采用
`population_memory.acceptance_policy: primary_only`：

- R：整体 RHS 范数 ≤ 1e-10。
- U：原始、未投影/未阻尼的物理归一化更新 RMS < 1。
- R 或 U 任一达标即可停止。闭合与边界阈值仅报告，不再否决。
- 数值有效性、浓度正性、混合线性误差、逆映射误差 < 1e-7、保存态残差一致性仍须通过。
- 零更新重读 RHS 是否达标单列，不作为第二次 RHS 门槛。

这不是所有器件的默认 Newton 变更。物理模型、边界方程、接触 QF 更新掩码和
正常配置的闭合阈值保持原样。`primary_with_guards` 显式保留原严格策略。
Python 公共帮助函数的默认值仍是严格策略，旧调用者须显式选择新策略；不改写冻结批次。

输出中的 `qualified` 指所选策略，另以 `strict_qualification_satisfied` 标记是否同时
符合原闭合/边界要求。不能将新策略通过解读为旧完整资格或 Sentaurus 全场对比通过。

## 固定条件

本机 MSYS2 UCRT64 Release，SLOT 13881 节点网格，完整审计系统维数 41643；
PARDISO 严格消元、单线程。AverageBox、Fermi、有效带边 SG 及原目标物理保留；
浓度投影 beta=0.001，电势对数阻尼尺度 0.0259 V，载流子正则化和闭合替换关闭。
人口内部单位 cm^-3、保存文件 m^-3，电势/QF 为 V，端口电流 A/µm。

采用已有冻结中间态各重放一次更新，无新偏压路径、无远程连接或计时器启动。
