## 算例背景与问题定义

本算例研究二维 SLOT LDMOS 在关断条件下的漏端高压阻断及碰撞电离过程。
Vela 联立求解 Poisson 方程与电子、空穴连续性方程，雪崩产生项参与自洽求解。
物理源极、栅极、SLOT 和衬底接触均为 0 V，扫描漏极；温度固定为 300 K。
本任务目标是找到首个完整合格且 `abs(Id)>=1e-7 A/µm` 的状态，另设物理
外压 200000 V 停止目标。本轮 s30/s01 尚未跨过电流判据，不能将其当前最高
内压报告为 BVDS；历史 s26bv 已跨过判据，两者必须区分（见下方修订核对）。

漏端串联电阻采用宽度归一化数值 `R=1e12 Ω·µm`，电流单位为 `A/µm`。
定义器件内部漏源电压 V、供电外压 U，有

```
U = V + R I
ΔU = ΔV + R ΔI
```

在光滑且可用 V 参数化的局部分支，`dV/dU=1/(1+R dI/dV)`。靠近陡峭支路时，
内压变化可以很小，外压增加主要落在电阻上；不能把外压当作器件耐压。
在停止电流 1e-7 A/µm 处，电阻压降就是 100000 V。该等式本身不保证任何
有限步长的 Newton 收敛，也不证明当前离散分支与参考软件完全一致。

当前父态电阻压降为 110.7981497799 V，电流仍比停止判据小约 903 倍。
约 149 V 外压并不意味着器件承受 149 V；本态器件内压约 38.5051 V。
所有本文电压均为物理电压，除非明确标为求解坐标：当前 `potential_origin_V=36`，
漏极求解坐标约 2.5051 V，其余接触坐标为 −36 V。比较不同参考系必须补回原点。

## 范围与实现

新增默认关闭的完整状态切线预测。未修改暂停中的长程扫描、步长反馈公式、
物理模型或最终资格门槛。本批四个结果来自同一父态，是独立对照点，不能拼接
为连续路径，也未写入生产账本。

结论：实现和有界对照已完成，四个对照点资格复核通过；切线组局部推进效率
较高。但0.1 V切线末点的独立同内压复验在240秒预算内未通过，所以尚不能
认定已完成独立复现，也不推荐立即恢复长程扫描。

此前的耦合候选 Newton 已包含器件状态、内部漏压和电路方程的增广 Jacobian。
此次新增的是把它用于**下一个外压点的完整状态初值预测**，并非首次加入
外接电阻导数。x 表示完整内部状态，V 是内部漏压未知量，U 是给定外压参数；
U 的导数贡献移到右端，不能误解为又增加一个无约束供电电压未知量。

对器件方程 F(x,V)=0、电路方程 V+R I(x,V)-U=0，在父态求解

```
[ F_x   F_V     ] [dx] = [  0  ]
[ R I_x 1+R I_V ] [dV]   [dU  ]
```

这里 dU 使用目标外压与同一电流泛函评估的父态外压之差。器件右端为零，
这一步是切线预测，不是器件残差校正。返回的状态与内压一起交给原耦合 Newton。
不能把候选块残差满足容差解释为全部有效载流子行已经合格。

候选后仍按以下顺序判断：候选守恒检查 → 多晶硅平衡态恢复 → 固定内压严格
器件重闭合及必要的局部修正 → 全部有效行/全局闭合/文件绑定 → 计算实际
`U_strict=V_strict+R I_strict` 并确认负载线。这里最终接受的是严格态实际外压。
设候选电路残差 `r_c=V_c+R I_c−U_proposed`，则完整偏差关系为

```
U_strict − U_proposed = (V_strict − V_c) + R (I_strict − I_c) + r_c
```

因此提议跨度、候选内压跨度、严格实际外压跨度必须分开记录。负载线复用态
残差为零不能代替严格器件资格；候选守恒通过也不能代替全部行通过。

- C++：`CoupledLoadLineNewton::tangentPredict` 复用完整增广矩阵求解，支持
  电流对状态和显式内压的导数；不依赖器件单独 Jacobian 可逆。
- 仅从候选器件容差内的父态预测；内压限幅及器件限制器作用于完整增量，随后
  进行有界 merit 检查。无效输入、线性失败或不能改善初值时返回原父态及原因。
- 配置：`sweep.external_circuit.coupled_state_predictor="tangent"`，默认 `none`。
  单一新目标也执行预测，不需要先求旧外压。日志输出实际更新、阻尼、内外压导数。
- 驱动：`--candidate-state-predictor tangent`，默认仍为 `secant`。切线模式从
  合格父态出发，不叠加 Python 割线状态外推。身份记录 `bordered_tangent_v1`；
  切换策略应使用新目录及重新验证的父态，不能原地改变旧账本身份。
- 后续候选守恒、poly 恢复、严格重闭合、全部行资格、负载线确认和失败缩步不变。

### 反馈收缩机制：已验证的控制问题

最后 40 个接受尝试中，反馈最小因子为 growth=1.4 的有 33 次、耗时项的有
7 次；全体接受尝试中成本因子小于 1 的有 23 次。最后五次增长观察均为 clean，
stage=2、multiplier=1、failures=0；增长等级已经是上限，但实际增长仍很小。

最后一次提议跨度 0.02603221514 V，实际跨度 0.01767003064 V，比值约 0.679。
该次受耗时项 1.34864 限制，下一跨度为 0.02383044619 V；即使采用最大 1.4，
也仅为原提议的约 0.950 倍。这确认“实际跨度 × 增长上限”的反馈在该情形会
持续压小提议。最后 40 步比值中位数为 0.6820，但范围为 0.6504～2.3018，
并非每步都精确服从同一系数。

误差解释必须保留符号和完整偏差等式。若固定内压严格重闭合使
`I_strict<I_candidate`，电流差与提议跨度近似同阶，则实际外压推进会缩小；
取绝对偏差 ce 只能描述幅值，不能独立推出缩小方向。本报告前文的
`ΔV + RΔI + r_c` 等式继续适用，不省略候选电路残差。切线预测可能降低这种
偏差，但没有替代对反馈规则的修复。

### 底限判断仍需哪些证据

已核实初次失败 15 行均为 PolySilicon 或其 SiO2 界面的电子行，尺度均为
1e-30；因此当次比值门槛等价于对应行口径的 1e-33 绝对残差限制。
这说明问题集中在极小通量的多晶硅有效行，**尚不能证明其全部为舍入噪声**。
`flux_abs_sum` 也未必包含 SG/Bernoulli 重构中相消之前的全部操作数。

同样，ψ 块若保持接近某数值，并不证明其为不可达的表示底限；块范数与最终
收敛范数还可能有不同缩放，不能将 `block_psi>abstol` 单独当作“abstol 不可达”
的证明。应按实际状态表示、约束和装配测量可实现扰动，并核对停止逻辑。

冻结失败态若漏电流与严格态相近，只能增加端口一致性证据，不能据此宣称
“物理上已收敛”：仍须看所有接触、积分源、场量和局部残差。最终资格不变。
建议只读比对之后再申请/执行有界探针，测量实际边操作数、ULP 扰动响应和
Poisson 导数尺度；`|∂r/∂ψ|·ulp(ψ)` 是敏感性估计，不是完整舍入误差上界。

U4 的中心差分应优先在同一连续负载线分支上求 U±h 的独立合格状态，比较
`[V(U+h)−V(U−h)]/(2h)`，做 h、h/2 尺度与解误差检查；原有两个正向
实验点不是父态的中心差分。接近折返时固定 V 差分可能混入参数化病态。
对非对称、缩放依赖的 Jacobian，“最小特征值相对误差”不是充分诊断，
宜结合方向导数一致性、后向误差及适当缩放的条件估计。

若令 p=dV/dI、a=dV/dU，则 `a=p/(R+p)`、`dI/dU=(1−a)/R`。
小负 a 可以对应可穿越的回折；`a→1` 意味电流对 U 不敏感，提示电流选点
可能困难，不能单独判失败；`|a|` 很大可能提示 `R+p≈0` 的负载线参数化
困难。这些信号不应统称为“电流参数化失效”，需与实际线性残差和分支证据
联合判断。离散曲线支持局部 S 形结构，仍不能据粗采样证明区间内每个 V
都有且仅有三个器件解。
