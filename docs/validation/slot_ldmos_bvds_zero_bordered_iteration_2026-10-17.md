PARDISO的系统为 **39,150维**，与本批原生耦合系统一致。实际线性接口捕获与

1. **首次Poisson初始化第0次系统**：新原生运行的初始ψ/n/p，经Vela自身本构
   逆映射得到同人口QF，再作只读Poisson装配比较。不是Vela独立冷态求解结果。
2. **加载原生保存冷态后的耦合冻结系统**：复用已保存并核对的同ψ/n/p映射态，
   装配Vela完整电路系统并尝试一次更新。它不是上项Poisson初始化末态；不跨阶段配对。

第二项的导入态没有Vela冷态资格。人口一致也不保证QF驱动力和边界目标一致。
本批没有切换先前实验性的原生常数兼容模式，Vela与原生热电压口径仍有差异。

## 增广方程与严格消元

求解方程为

\[
F(x,V_D)=0,\qquad V_D+R I_D(x,V_D)-V_S=0,
\]

对应矩阵与RHS：

\[
\begin{bmatrix}F_x&F_{V_D}\\R I_x&1+R I_{V_D}\end{bmatrix}
\begin{bmatrix}\Delta x\\\Delta V_D\end{bmatrix}
=-\begin{bmatrix}F\\V_D+R I_D-V_S\end{bmatrix}.
\]

电流行来自未替换边界的完整连续性反力，含源项；不是补一个单位对角元。
本坐标中固定x时接触电流没有额外显式电压依赖，电压通过器件边界列及未知量作用。
有限差分检查：接触电流方向解析值−0.0167227387415555，两个中心差分分别
−0.0167227387374159、−0.0167227387373928，约2.5e-10相对差。

首次简单消元留下39,192维，原因是漏极21个节点的两类QF约束与电路电压耦合。
随后补齐严格仿射代入：若约束为`a dx_i + c dV = b`，则
`dx_i=b/a−(c/a)dV`；将常数和电压项代入每个保留器件行及电路行，最后回填。
没有删除电路耦合项或修改电阻。

| 项目 | 数量 |
|---|---:|
| 全部电势未知量，均保留 | 13,881 |
| 有载流子材料支撑的节点 | 12,760 |
| 其中固定接触人口节点 | 126 |
| 非载流子材料节点 | 1,121 |
| 每类消去的约束 | 1,247=1,121+126 |
| 每类保留的载流子自由度 | 12,634 |
| 电路电压未知量 | 1 |
| 最终后端维数 | 13,881+2×12,634+1=39,150 |

逐节点核对：两类保留载流子节点集合与原生一致。因此此前把全部1,247条都称为
“绝缘节点约束”不够准确，还包括固定接触人口约束。

39,192/39,150两次重放的完整物理矩阵、完整稳定化矩阵和RHS逐位相同。
原始电路方向差1.47e-17 V；完整方向最大差4.8633e-6内部坐标单位。
局部弱行仍对后端运算次序敏感，不能仅凭小电压方向差声明全场完全等价。
