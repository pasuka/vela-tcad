**独立 AverageBox Poisson 配置已建立，新冷态通过原完整验收。**
此前剩余的 8.214 ppm 电荷/介电比例差可由两边物理常数取值完全解释到本次测量精度，
没有修改 Vela 全局常数，也没有放宽门槛。

## 1. 8.214 ppm 差异的来源

Vela `include/vela/core/PhysicalConstants.h` 使用现代常数。Sentaurus T-2022.03
用户手册的内置 Schottky 电阻示例给出其旧常数；Charge 默认值也列出了相同电荷。
使用这些独立来源数值，而不是拟合四个观测点：

|常数|Vela|原生手册|
|---|---:|---:|
|q，C|1.602176634e-19|1.602192e-19|
|真空介电常数，F/m|8.8541878128e-12|8.8542e-12|
|kB，J/K|1.380649e-23|1.380662e-23|

预测电荷/介电比例：

```
(q_vela / eps0_vela) / (q_native / eps0_native)
    = 0.9999917858093547
    = 1 - 8.2141906453 ppm
```

与前批 10237、10238、10849、5350 的测量比值最大差为 1.80e-12。
只在后处理中用该比例换算电荷项，归一化 RHS 的剩余差为：

|节点|换算后 RHS 与原生之差|
|---|---:|
|10237|−8.54e-13|
|10238|+2.47e-13|
|10849|−3.26e-13|
|5350|−3.38e-14|

这里仍沿用前批人口坐标下的 `b/Jii`，不是物理电压，也不是完整 Newton 方向。
这支持已查四个节点的几何/电荷支撑在常数口径换算后吻合；不等于全器件所有源支撑
已经逐项审计。**未对求解器 RHS 乘拟合系数，也未把旧常数写回生产代码。**
复算：`constants_audit.py`、`constants_audit.json`。

## 2. 独立配置与新冷态

配置：[`slot_ldmos_idvd_average_box_aligned_control.json`](../../configs/regression/slot_ldmos_idvd_average_box_aligned_control.json)。
保留旧配置作为对照；新的实际 Poisson 组合为：

```
mesh_geometry.cell_box_policy = average_intersection
mesh_geometry.poisson_permittivity_policy = cell_material
discretization.poisson_permittivity_coupling = edge_mean
discretization.poisson_charge_volume_policy = material_local_box
solver.recombination_volume_policy = material_local_box
```

`edge_mean` 在这里是进入普通装配路径的开关；`cell_material` 随后选取每单元介电
常数乘 AverageBox 系数，并不是把 Si/SiO2 简单平均。已补充配置文档消除名称歧义。
相对旧冷态配置，目标物理中的变化仅为去掉有符号 `per_cell` Poisson 覆盖。

## 3. 原生 DOS 与 Fermi 近似的有界观测

新远程目录 `slot_idvd_20261009_fermi_observe`，两个臂均加载同一个已保存
Vg=5 V/Vd=0 V 种子，只执行 Load/Plot，**零次 Newton 更新**：

|原生臂|唯一物理数值选项差异|墙钟|退出|
|---|---|---:|---:|
|default|原有 `Fermi`|49.56 s|0|
|wuensche|`Fermi(-WithJoyceDixon)`|45.50 s|0|

每臂上限 60 s，种子前后哈希相同，下载及两次 TDR 导入均通过哈希/退出检查。
新增输出 `eEffectiveStateDensity`、`hEffectiveStateDensity`，不使用注释中的 Nc300
作为实际生效数值。手册将 `-WithJoyceDixon` 说明为旧 Wuensche 近似；本批没有取得
默认近似的完整实现公式，不能仅凭名称复制一套未经验证的近似到 Vela。

### DOS 直接对照

Si 全部导出节点：

- Nc = **2.8566532127079047e19 cm⁻³**；
- Nv = **3.104628932474838e19 cm⁻³**。

与 Vela 输入逐值一致；PolySilicon 的相对差也仅为约 1e-15。
两个原生臂之间 DOS、掺杂和 QF 均不变。因此，先前约 0.25 mV 的热点电子关系差
不能继续归因于未读取的有效 DOS 数值。

### 多点关系检查

采用原生 VT = 0.025851995266484913 V、直接导出的带边和 DOS，独立计算
`phi_n + Ec + VT*Fhalf_inverse(n/Nc)`；若采用同一个定义积分，这应为零。
BGN 使用原 Bennett 基础项加定义积分统计修正，浓度统一 cm⁻³。

|Si 节点|定义积分 BGN − 原生默认 BGN，meV|电子带边关系余项，µV|
|---|---:|---:|
|10848|+0.588562|+1.02022|
|10849|+0.656634|+251.697|
|10850|+0.662506|+120.584|
|11404|+0.692065|+0.000368|

11404 虽然局部电子人口并非最强简并，BGN 统计修正仍受其高施主/受主输入控制；
不能将人口关系误差和掺杂统计修正视为一个常数偏移。使用原生 VT 后，这些检查点的
空穴带边关系余项已到约 1e-16 V；此前 nV 级差中确实含有常数口径成分。

整个 Si 区默认近似的最大电子关系余项约 **0.349319 mV**，定义积分 BGN 余项
最大 **0.692065 meV**。旧 Wuensche 臂分别增大到 **34.5999 mV** 和 **40.0960 meV**。
这定位的是可观测的数值本构口径，不是对原生整体仿真精度的判决。

### “零更新”不等于切换后同态

原生切换近似后，Load 自动重新施加接触内建势：自由节点 ψ 逐值不变，但 Si 接触 ψ
最多改变 **19.6926 mV**；人口随新本构重建，Si n/p 最大相对变化达 75.25%/78.21%。
因此不能把两个臂的通量/电离之差当成固定 ψ/n/p 下的导数变化，也不能把旧 Wuensche
观测态记为完整器件解。它是统计近似影响 BGN、边界及人口关系的对照证据。

### 独立积分排除本地反函数实现误差

在 10847/10848/10849/10850/11404 的 n/Nc = 0.6767～17.6011 范围，
用 SciPy 自适应积分计算归一化 F1/2，并用括区根求解其反函数，与冻结 Vela 标量
工具比较。等效 QF 差最大 **9.74e-15 V**，远小于原生默认余项。
这支持“定义积分与原生近似口径不同”，不支持为消掉观测差直接修改 Vela 数学函数。
证据：`native_analysis.json`、各材料逐节点 CSV、`quadrature.json`。

## 4. 本批边界与后续顺序

已解决：实际 Poisson 路径冲突、已查节点常数比例差来源，以及有效 DOS 是否一致。
已验证：新几何配置可从零状态通过冷平衡完整资格。
尚未解决：与原生默认近似逐点一致的 BGN/人口/QF 映射。

因此本批 **没有再次把 10849 的源项/Jacobian 当作同态对象相除**，也未用不匹配的
输入来论证需要修改生产 SG/HFS 导数。前批总导数有限差分证据继续有效，适用范围
仍是 Vela 自身重建态。条件式的生产 SG/迁移率精确分解暂未实施，不绕过端点诊断
对元素路径的保护，也未做稳定化消融。

下一步有两个应分开的工作：

1. 用这份新冷态建立少量门压点，验证实际 AverageBox 算子的连续路径；保持默认
   定义积分 Fermi 和原资格，不把原生近似切换当作改进的必要前提。
2. 若要求矩阵元素逐项匹配，先形成有明确公式/版本身份的原生近似兼容模式，或在
   原生端验证同一定义积分口径；这属于显式本构数值映射。未取得该身份前，不用单点
   调整 ni、Nc 或 QF 常数平移“校准”全器件。随后再复核 10849 源项及必要的元素通量分解。
