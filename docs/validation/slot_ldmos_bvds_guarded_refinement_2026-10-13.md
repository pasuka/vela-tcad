# SLOT BVDS：有界线性精化移植与虚拟机验证（2026-10-13）

## 结论

已将有界线性精化接入普通三变量 Newton，提供默认关闭的
`solver.linear_factor_refinement_steps=0..3` 开关，并在 Linux VM 验证。
保留 BVDS 原物理、正则化、闭合行替换、行比与全局闭合验收。
没有移植 IdVd 的 R/U-only 接受方式，也没有省略迁移率导数。

本批证明了精化功能和原资格兼容，但**没有获得新偏压合格点，也没有证明能加速
当前 BVDS**：失败目标的原线性方向已经满足所有线性保护，精化未触发，最终仍因
闭合线搜索拒绝而停止。当前长任务没有切换求解器或配置。

## 配置与范围

- SLOT 网格 13,881 节点；本批普通 Newton 三块系统为 41,643 维。
- Linux GCC 16、Eigen 5、UMFPACK，单线程，binary64 矩阵与方向；线性缺陷以
  `long double` 累加。没有开启全链路 float80。
- 栅、源、衬底及 SLOT 接触均为 0 V；温度 300 K。下文目标电压是器件漏端内压。
- 沿用旧 BVDS 的 IALMob、碰撞电离及外部 AverageBox 数据，未换成 IdVd 的
  PhuMob/Lombardi 配置。材料、掺杂、网格与源项支持文件绑定到原输入。
- 原 `carrier_regularization_scale=1e-8`、`replace_free_row_sum` 保留。
  非线性 `abstol=1e-9`、`reltol=1e-8`、行比 0.001、闭合 0.01 及边界保护保留。
- 外电阻为 `1e12 Ω·µm`；旧击穿提取标准为 `|Id|=1e-7 A/µm`。
  本批仅做指定低压目标复验，没有取得击穿点。

## 实现

1. 先执行原来的直接/Woodbury 线性求解。
2. 用实际含正则化和闭合替换的矩阵 `A`、右端 `b` 检查方向。不能用替换前的
   物理矩阵评判替换后的方向。
3. 仅当检查不通过时，计算高精度缺陷 `b-Ax`，解修正方程，最多三次。
   修正后必须同时通过全部线性检查才替换方向；否则保留原方向并报线性失败。
4. 不改变残差、Jacobian 系数、限幅、线搜索或最终非线性资格。

线性检查沿用已验证的混合指标：各行
`|Ax-b| / (1e-6*(|b|+|A||x|) + sum(|Aij|)*1e-14/Vt) <= 1`，
各变量块范数后向误差 `<=1e-12`，单元素约束行的物理电势误差 `<=1e-14 V`。
这是本开关附带的显式线性方向保护；旧 BVDS 最终资格没有因此放宽。

启用闭合替换时，第一次修正需要对显式替换后的矩阵分解，随后修正复用该分解。
不能声称直接复用了未替换的 Woodbury 基础矩阵分解。

该开关限定于普通三块 Newton 内层；不表示新增了带电路未知量的增广系统精化。
外部负载线仍由原控制器确认。暂拒绝与 MP100 固定次数精化、split-state、行缩放
或线性均衡同时使用。每次检查写出 `VELA_LINEAR_FACTOR_AUDIT`。

## 固定系统试验

在原父态、漏端目标 1.7740603793058118 V 上做零接受更新的矩阵导出：
41,643 维，739,298 个非零元，两个闭合替换行索引为 13,881 和 27,762（零基）。
它是冻结态线性探针，不声称与完整续算经过边界初始化后的首个系统逐位相同。

| 检查 | 混合误差指标 | 结果 |
|---|---:|---|
| 原方向 | 3.21046e-9 | 已通过 |
| 人为将方向乘 0.999 | 500.250074 | 不通过 |
| 对人为误差进行一次精化 | 1.28597e-9 | 全部保护通过 |

精化后的三块范数后向误差为 `2.89e-17 / 1.72e-17 / 1.52e-17`。
计时器记录一次分析、一次分解、两次求解以及一次分解缓存命中。
人为扰动仅用于验证修正能力，没有作为非线性试探或生产初值使用。

## 同父态、同目标对照

两臂使用同一新编译 runner，差别为精化上限 0 或 3。新点诊断不进行偏压重试；
随后为较小目标补齐原有最多八次 `density_then_qf` 恢复和多晶硅恢复流程。

| 目标内压 | 关闭精化 | 开启精化 | 判读 |
|---|---|---|---|
| 1.7250638516493606 V，新偏压验证 | 零次 Newton 更新，资格拒绝 | 相同 | 整体残差已达标，但没有新偏压要求的实际耦合更新；不是线性误差 |
| 同一较小目标，保留最多八次局部恢复 | 最终仍为零耦合更新，资格拒绝 | 相同 | 恢复后行质量改善，不能据此跳过原证据条件 |
| 1.7740603793058118 V | 7 次接受更新后闭合线搜索拒绝 | 相同 | 共 8 次线性方向检查均通过，实际精化 0 次 |

较大目标开启精化时混合指标范围约 `2.58e-10..1.71e-9`，最大块后向误差
`2.61e-15`，约束误差 0；远低于线性保护阈值。
两臂终态均有 4,261 条载流子超标行，最大行比约 1.95106；电子闭合比约
1.00006，不能通过原 0.01 闭合要求。
完整单臂用时约 80.61 / 81.13 s；虚拟机还有其他任务，单次结果不能作为性能基准。

另从已有 1.7250638516493606 V 合格态做**同偏压重验**，两臂均通过器件、
文件绑定和外部负载线确认：

- `Id = 8.415751989777383e-16 A/µm`，两臂一致。
- 外部电压 `1.7259054268483383 V`，两臂一致。
- 超标行数 0，最大行比 `7.91316e-7`；QF 越界数 0。
- 全局闭合走 absolute 分支并满足；不能因单载流子 relative-qualified 标志为假误报失败。
- 两臂均为零次更新。这是同偏压资格与负载线复验，不是新点或不同初值独立复求，
  也不用于证明精化能改善非线性收敛。

## 后续判断

保留精化为可选线性保障，当前证据不支持因此替换在跑 BVDS 长任务。
本例下一步应围绕较大目标的电子闭合及真实线搜索试探分解问题；同时单独核对
零更新候选与新偏压耦合更新证据的关系。不要用增加精化次数、放宽验收或追加长扫描
代替这些分析。
