# SLOT LDMOS：35 V 伴随定位与 H1 冻结控制（2026-09-26）

## 结论与阶段决策

本批执行已授权的 35 V 工具校验、伴随定位与 H1 单因素冻结控制。结果支持优先
调查 Poisson/界面离散，但**不支持把 H1 电荷体积策略直接作为雪崩源差异的修正**。
H1 未满足计划要求的加权源差下降至少 50%，Si 界面残差改善也未达 5 倍。
因此没有触发 S3 的获胜变体独立重收敛，没有推进 38 V 或恢复高压支路。

依据：[修订计划](slot_ldmos_iic_loop_gain_localization_plan_2026-09-26.md)、
[前批 IIC 预算](slot_ldmos_iic_source_budget_2026-09-25.md)。

| 项目 | 本批结果 | 解释 |
| --- | --- | --- |
| 正向/伴随线性校验 | UMFPACK 通过 | 普通 SuperLU 路径未通过，不能仅凭小后向误差接受 |
| 两方向、两步长差分 | 源梯度及三个方程块达到目标 | 使用 QF 参考值/增量保留亚 ULP 扰动；不是全 Jacobian 穷举证明 |

## 1. 工具校验

捕获文件的 `b` 与 CSV 残差逐元素满足 `b=-r`，`x*potential_scale` 与 CSV 的
物理电位步一致，且 `raw_step_norm=step_norm`。输入状态在运行前后 SHA-256 不变。
电子/空穴行差分提取的总源均为 `2.5737380622349067e-15 A/µm`（原生自洽冻结态），
与 observable 输出一致。`g=-c*sum(J_SC-J_IIC)`，采用既有独立单位系数 c；未靠反算
新单位系数消除不一致。

使用同一无穷范数定义后向误差（矩阵使用精确诱导无穷范数，而非以单独一范数冒充
二范数上界）。原生基态正向/伴随后向误差约 `4.66e-19 / 1.28e-19`，
`g^T dx` 与 `-w^T r` 的绝对差约 `1.11e-31 A/µm`，通过混合判据。
一范数条件数估计约 `1.39e24`，为估计值，非严格上界。

首轮 SuperLU 行列缩放所得内积差约 `1.63e-19 A/µm`，约为预测值的 0.8%；
后续长双精度残差迭代精化未改善。该路径被拒绝，保留在
`rejected_superlu_refinement/`，最终不采用。UMFPACK 的转置求解使内积校验通过，
同时复现捕获的正向步，不修改生产求解器。

差分采用 Si 范围 Newton 方向和热点混合方向、1e-6/5e-7 V 两个步长。首轮绝对 QF
写入使重掺杂区微小扰动被舍入，电子块误差约 1；不能以 Poisson 主导的全局范数
掩盖此失败。改用已有 HDF5 QF 参考值/增量表达后：

- 源梯度相对误差最大约 `2.36e-8`，目标 `1e-3`。
- Poisson 块方向相对误差最大约 `2.10e-6`；电子块约 `5.83e-5`；空穴块约 `2.99e-8`，
  均满足 `1e-4` 目标。没有据此排除其他方向/分支的导数问题。
- 一次确定性的 +ULP 噪声试验，其加权影响约 `-9.95e-29 A/µm`；该测试不代表
  原生自身收敛或 4.8 ppm 密度关系误差的严格上界。

## 2. 本地剩余误差及自洽归因

实际状态差（扣除冻结源核差）为 `2.2823383727246714e-17 A/µm`。
原生端单点预测为 `2.0402607435e-17 A/µm`，低估 10.61%；本地端估计高估 22.28%。
两端估计不是数学上的包夹。

沿原生冻结态的未截断诊断步计算 0.25/0.5/1 倍试探状态。整步试探源为
`2.5945291886450483e-15 A/µm`，仍未当作合格状态。进一步在整步试探态捕获系统，
使用两段估计

`w0^T [F(x1)-F(xS)] + w1^T [F(xV)-F(x1)]`。

结果为 `2.1090502850e-17 A/µm`，低估 7.59%。这是单点线性化未过门后的诊断细化，
保留原单点失败；不能将它解释为完整高压线性模型已验证。

| 方程块 | 有符号份额 | 绝对份额 |
| --- | ---: | ---: |
| Poisson | 94.88% | 79.35% |
| 电子连续性 | −2.54% | 15.82% |
| 空穴连续性 | +7.66% | 4.83% |

全部行正/负贡献约 `+6.4880e-17 / -4.3790e-17 A/µm`，抵消指数 C=5.153。
Si 界面有符号份额 112.32%、绝对份额 38.10%；超过 100% 源于其他区域的抵消。
热点窗口占有符号份额 63.03%；栅侧边缘窗口占绝对份额 52.25%。高权重行包括
介质节点 13323 和 Si 界面节点 8401、8402、10492、8311；已输出全部逐行与前 50 行。

分项组装和闭合核验后，介电通量项的两段贡献约 `1.86491e-17 A/µm`；
分项和与全部行估计相差约 `2.08e-30 A/µm`。这支持 H2 作为后续候选，
但介电通量项会随状态响应变化，不能直接等同于介电系数装配错误。

本地已接受态的原始 Newton 步使源积分相对变化仅 `-3.96e-12`；0.25/0.5 倍步
响应接近线性。电子/空穴残差显著缩小，Poisson 保持约 `8e-10` 的底限，第二步
未满足计划要求的所有块再缩小 10 倍。因此不声称完整 S0.1 判据全部满足或存在
严格误差上界；但现有源加权结果不支持该点迭代残差是 0.887% 源差的主要贡献。

充分性，不等于证明 global 几何物理上更正确。后续 H2 的 2×2 控制应同时保留两种
电荷体积，以检查交互项。

## 4. IIC 与源分布诊断的限制

原生 IIC 态上的线性系统内积校验通过，但以 `J_IIC` 求得的源差预测为
`-9.67512e-20 A/µm`，实际两状态源差为 `+1.54283e-19 A/µm`，符号不符。
0.25/0.5/1 倍试探源分别为 `1.1750213974e-15`、`1.1750097210e-15`、
`1.1750144633e-15 A/µm`，非线性变化明显，整步仍未恢复实际局部 IIC 终态。
因此该项没有通过，不能声称归因在 IIC 与自洽态上已统一闭合。

将既有 IIC 空间源差作为等效注入，原生自洽切线上的状态诱导源响应约
`+4.16561e-18 A/µm`，为实际自洽状态差的 18.25%；直接源差约 `1.56782e-19 A/µm`。
这是敏感性试验而非独立因果分摊，不与逐行归因相加。符号按
`delta_r=-delta_s/c`、`delta_S=-w^T delta_r` 实现，即状态诱导项为正的
`sum((w_n+w_p)*delta_s)/c`；修正了计划中这一处遗漏的双重负号。

本地合格基态的伴随 alpha 总源对数灵敏度估计约 3.56883；本批未完成 A_scale
逐节点线性缩放及 ±alpha 重收敛检查，仅保留为待验证诊断，不视为 S4.2 完成。
