# SLOT稀薄区映射修复：独立有界验证

本批授权：四小时，固定截止2026-10-22 19:16北京时间。原始数据、构建和分析留在VM。

## 设计与顺序

1. 用独立100位Fermi逸度级数检验接近完全耗尽的有限人口更新；先记录原增量算法的失败。
2. 增加默认关闭的 `population_memory.dilute_log_inverse`。只在起点和目标约化人口均不超过1e-12时使用稳定对数比；域外逐位调用原函数，不修改CarrierStatistics生产函数。
3. 对数比用准确稀薄起点及逸度修正求增量，避免O(z)增量相减后的误差被1/(1+rel)放大。该适用域是算法选择边界，不是人口下限。正性、逆映射1e-7及legacy接受规则保持不变。
4. 复用冻结核心，独立编译runner；原runner、重编译关闭、开启做同父态有限更新比较。先复现10356保存步首，再验证完整目标；记录全部退出类型，不把修复映射等同于收敛。
5. 开关重复与低偏压独立样本补充P2影子证据。只有通过既有生产检查及复读的状态才允许少量相邻点，最多25更新/目标、900秒软上限，所有子进程服从总截止。

## 判读边界

保存的失败步首仅用于机制重放，不自动取得父态资格。P2指标仍未标定；缺失字段记未评估。
记录源码/构建/输入哈希、开关、后端、线程、实际映射分支次数及端口结果。
比较开关时使用相同诊断设置；诊断开关对旧程序的影响另列，避免把观察器变化混入修复效果。

## 已验证结果（阶段记录）

- Linux vela-gcc16独立构建成功；23项载流子统计及映射测试、1208断言通过。
  新回归先在旧算法上失败，再在修复后通过；另外覆盖域内大幅人口增加、极小正更新及域外逐位回退。
- 同一保存步首，旧runner与新runner关闭开关均在10356空穴行触发逆映射保护，
  相对重建误差3.2338214450700065e-7，保存数值场逐位一致。
- 开启修复的三次独立单线程重复均完成一次实际更新；场量、核心历史、端口结果逐位一致。
  该步全器件最大映射误差3.802618220305476e-10（最差节点转为10353），低于保留的1e-7保护。
  实际使用对数映射3567次，另7383次候选由既有小切向更新算术接管。
- 三次均按预设max_updates=1退出，未获父态资格。RHS=3.2986541144490665e-9，
  原始U=568.2588953734513；映射修复并不证明方向或整个偏压目标已收敛。
- 从原目标准备态运行的完整关闭臂，完成4次更新后再次触发映射保护；完整开启臂仍在运行。
- P2实际阶段文件已开始回放；首个完整更新链的文件/支撑检查通过，指标仍为not_calibrated。
  这只验证捕获覆盖，不能当作数值收敛或器件验收通过。

配置身份：原补偿掺杂SLOT网格13881节点、Fermi统计、300 K、Vg=5 V，
单线程 `pardiso_mkl_eliminated_keep_psi`，约束消元后39149维；复现目标Vd=0.15595597396240235 V。
人口在本运行器内部按cm^-3计、存档按m^-3计；端口电流A/um。保持原物理方向、RHS或原始U停止语义。

实现使用输入population/DOS的稀薄区对数逆得到自洽起点，并求对数比增量；
