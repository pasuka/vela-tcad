# SimpleMOS HFS 显式生产候选与八点复验（2026-09-14）

## 范围与结果

本轮承接 HFS 原生形成方式校准，接入显式生产候选，检查实际矩阵 Jv，再按资格顺序执行八点双初始化自洽对照。原生输入来自已完成的 `hfs_restore_20260912` 八点基线；本轮无需新增 SDevice 仿真或上传文件。

本轮已完成：显式生产候选、相关回归、固定状态公式对照、八点分支内实际矩阵 Jv、**16/16 合格状态与 8/8 双初始化**，以及 **8/8 密度/SRH 重建**。全部 DC 首次尝试合格，无失败、无重载。八点最大 Id 相对误差 **0.006626328%**。原有限幅度 Jv 失败和局部物理场差继续保留；HFS 完整 0–1 V 曲线与原始全部工况尚未验证。

工况为 n19/n23 × Vd=0.05/1 V × Vg=0.8/1 V，300 K、Boltzmann、OldSlotboom、PhuMob、alpha=0 的 Enormal、HFS、掺杂相关 SRH。沿用 M8 网格、材料、常数、signed Si Poisson 电荷体积、原 SRH 体积与已验证的 box 几何。网格每个器件有 1,750 个 Si 三角形、942 个 Si 节点；总节点数 n19 为 1,480、n23 为 1,482。

生产工具链为 Windows UCRT64 / C++20 / Release；本轮 DC 使用 Eigen SparseLU/COLAMD 和四次线性迭代修正。构建检测到 UMFPACK/SPQR 支持，不等于本轮使用它们求解 DC。网格输入为已有 JSON；物理字段由此前原生 TDR 导出取得。

电势单位 V，端口电流 A/µm；本组 `unit_scaling` 的内部浓度与迁移率分别为 cm⁻³、cm²/(V·s)。状态 CSV 的密度列为 SI m⁻³，历史探针中部分 `*_m3` 标签实际保留内部 cm⁻³，分析时显式处理。

## 显式实现

新增组合：

```json
{
  "model": "phumob_field_lombardi",
  "edge_averaging": "element_box_phumob",
  "doping_concentration_basis": "total_impurity",
  "surface": {"discretization": "element_distance_gradient"},
  "high_field_driving_force": "quasi_fermi_gradient",
  "high_field_gradient_discretization": "element_vertex_partial_layer",
  "jacobian_field_derivatives": true
}
```

- 各顶点先计算 live PhuMob 与 Enormal，再做 Canali 饱和，随后进行单元 box 积分和边几何平均。没有先平均低场迁移率再饱和。
- 非接触单元采用对应载流子的线性准费米梯度。PartialLayer 对真实半导体边界投影到边界切向；两个非平行边界的交集为零投影。
- 单元含任意接触顶点时，优先采用完整电势梯度的模。
- 两种分支都在原始驱动力低于 1 V/cm 时关闭饱和。上一轮原生实验将阈值夹定在 [0.999999, 1.000001] V/cm；这里实现显式 1 V/cm 候选，不声称获得原生闭源比较指令。
- 残差、解析 Jacobian、split 高精度求值及端口使用一致的几何和形成顺序。链式导数包括全部相邻顶点的两种载流子密度偏导、Enormal 电势偏导，以及 HFS 的电势或准费米梯度偏导。
- 修复 split 端口漂移/扩散诊断使用低场迁移率的问题，改用实际边迁移率；此前端口总电流不受此诊断问题影响。非线性单元混合没有唯一等效边驱动力，因此相关 split 边/端口字段为 NaN，旧单驱动力分解探针明确拒绝此 profile，使用 `element_box_probe` 检查单元形成方式。

保持全局默认和既有数值接受门槛。该候选只在当前 300 K、alpha=0 范围使用；不将其推广到未验证温度、物理模型或全局默认。

## 已完成的独立检查

8 个相关测试程序全部通过，共 209 个测试、8,268 项断言：`element_box_transport`、`production_numerics`、`split_dd_runtime`、`split_dd_state`、`sg_flux`、`mobility`、`newton_solver`、`permittivity_assembly`。本轮没有运行完整 CTest 集合。

新增 HFS 控制网格检查 60 个矩阵列 × 两种载流子浓度情形 × 三个步长（1e-7、1e-12、1e-25 V），逐行相对门槛 2e-6，保留弱交叉项；同时检查 cutoff、接触/边界/内部单元、分拆不变性和端口一致性。

八个真实原生状态的 558 个独立公式样本全部通过，生产单元迁移率相对独立高精度公式最大差为 **2.9309887850e-14**。这只证明公式移植一致性，不是自洽电流误差。

另对全部 28,000 个单元/载流子样本比较原生迁移率：电子最大相对差 **1.3826380041e-9**，空穴 **7.3550933488e-6**。空穴保持上一轮未拟合 PhuMob 截断底差异，仍不满足历史 1e-7 单元迁移率门槛；没有用新的拟合消除或重分类此项。

## 实际矩阵 Jv 与步长资格

对每个真实状态检查节点 1000 单独扰动，以及节点 320/792/1000/1009/1057/1089/1091 联合扰动，各自覆盖 psi/phin/phip，并输出全部残差行。初始幅度为 1e-6 与 1e-20 V，逐行相对门槛 1e-4，无弱项剔除。

首轮 1e-6 V 挑战出现失败，原始结果保持失败。独立几何审计发现该幅度有 **51 次 HFS 截断分支切换**；在追加的 1e-10、1e-12 V 两个幅度下，HFS 与 Enormal 符号切换均为零。不能将跨分支有限差分直接当作该状态切向导数的检验。

追加资格事先记录于 `step_convergence/contract.json`：每个失败方向都重算两个较小幅度的全部行，两者都必须通过原 1e-4 相对门槛，且原 1e-20 V 全部行必须通过。源码、二进制与 DC 门槛保持冻结。该步长研究只放行分支内的实际矩阵 Jv，不宣称跨阈值全局光滑，也不将原 1e-6 挑战改记为成功。

最终八点分支内资格 **8/8 通过**。初始 288 个分组、4,992 个非零条目中保留 99 个 1e-6 V 失败条目；原 1e-20 V 的全部行均通过，最大相对差 1.4875214413e-9。对 29 个失败方向追加两个步长，全部行通过，最差相对差 7.5588095375e-6。该最差项为 n23、低 Vd、Vg=0.8 V 的电子 1058 行：步长从 1e-10 减至 1e-12 V 时，相对差降至 7.5665418390e-10，呈现二阶差分的步长收敛。没有修改生产矩阵来消除大步长非线性。

## 八点双初始化自洽结果

采用冻结的 `split_dd_state`、稳定残差范数比较、微小更新累积、精确 Dirichlet 步和四次线性修正。两条路径分别从已合格 Enormal 状态及原生 HFS 势场生成的 Vela 一致状态启动，保持原来最多一次同偏置重载的协议；本轮没有使用重载。

16 个状态全部合格、8 个全场双初始化全部合格。最大载流子逐行比值 **7.8046685915e-8**（门槛 1e-6），最大端口相对差 **4.4408920985e-16**（门槛 1e-8）。双初始化最大 Id 相对差 **1.7186252421e-12**，最大势场差 **2.08169825e-9 V**，最大密度相对差 **8.0523687274e-8**，分别满足原 1e-6、1e-6 V、1e-4 门槛。独立全局连续性和 KCL 检查也逐态通过。

## 原生与 Vela 物理场差

密度按保存的高/低位状态独立重建，8 点与输出密度完全一致；SRH 公式与生产积分源项的最大归一化 L1 差为 **3.5447892231e-16**。以下使用同一组正 barycentric Si 体积比较物理量，SRH 的归一化 L1 以原生绝对速率积分为分母。这些是描述性场差，不新增物理场验收阈值；SRH 电荷等效积分不是 Id 误差或向漏端的响应预测。

高 Vd 剩余峰值仍有定位价值：电子准费米势最大差在节点 **792**，约 **4.1899 mV**；空穴峰值在节点 **795**，约 **1.5183 mV**。例如 n23、Vd=1、Vg=0.8 V，节点 792 原生电子密度约 8.179e3 cm⁻³，Vela 约 6.956e3 cm⁻³，差约 **−14.954%**；节点 795 空穴密度差约 **−5.712%**。这些局部低密度场差仍存在，不能因 Id 已很接近而记为消失。

原沟道对照节点 1000/1009 的 n23 电势差约 0.90–1.30 µV，高 Vd 电子准费米差不超过约 2.02 µV，空穴准费米差不超过约 20.40 µV。逐节点原生/Vela 六项物理量、体积加权 RMS 与 SRH 对照完整保存在 `fields/nodes.csv`、`fields/fields.csv`、`fields/srh.csv`。

## 结论与后续边界

本轮所要求的显式 HFS 生产接入、分支内实际矩阵 Jv 和八点双初始化对照均完成，数值门槛未改。保留三项边界：原 1e-6 V 跨分支挑战的 99 条失败、原 PhuMob 空穴单元截断底差异、以及高 Vd 局部低载流子密度场差。未将公式精度或八点电流结果解释为任意方向、任意偏置或全部物理场已经验证。

下一阶段先补当前 HFS 统一实现下的低 Vg 控制，形成十六点双初始化，再扩展四条完整 0–1 V 曲线及原始全部工况。节点 792/795 邻域可作为后续局部场差对照，避免以当前极小 Id 差替代场量核对。本轮未提交或推送分支。
