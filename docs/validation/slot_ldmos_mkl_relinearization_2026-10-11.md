# SLOT：PARDISO / SparseLU 连续重线性化对照

2026-10-11。工作点 Vg=5 V、Vd=0.005 V，300 K，原点 0 V；SLOT
13,881 节点、27,275 三角形。两臂均使用 Vela 的 QF 方程装配和原更新策略。

**三步对照已完成，新增完整合格点为 0。** PARDISO 末态超标行比 SparseLU
少 880 条，但最大行比、空穴闭合和整体残差几乎不变。后端影响部分弱行轨迹，
本批没有证明仅更换线性求解器即可恢复完整非线性收敛。

## 实现与固定条件

新增显式选择的 Windows `pardiso_mkl` 共享线性后端，默认后端不变。
通过 `VELA_MKL_RT_DLL` 绝对路径装载 oneMKL；无 MKL 编译或链接依赖，
未选择该后端时不加载 DLL，加载/求解失败报错，不静默回退。
沿用共享层对精确稀疏模式与数值的缓存及失效处理。

- 同一新构建 runner：`build/s11mkl_relinearize/runner.exe`，SHA-256
  `fba02b89507e05963dd15ae0067fd3aadfe1be9e1bda97e39528a53204c2e71e`。
- 同一父态 `build/s10initial05/v5_qf.h5`，SHA-256
  `9db915c19425d3936fab2895751a7569c7381e2cc4a753321e52c7166463a9ff`。
- 配置源 `build/s11float80/sparselu/config.json`；材料
  `build/s10four_stage/compat_materials.json`。网格、掺杂、材料、源码、DLL
  和 runner 均由 `contract.json` 绑定哈希，运行后核对未变化。
- 保留 AverageBox 配套几何/体积、Fermi `effective_band_sg`、Bennett–Wilson
  及统计修正、PhuMob/Lombardi/HFS、SRH/Auger、电离及接触电场回退。
- 保留 `unit_scaling`、1e-8 载流子正则化、`replace_free_row_sum`/Woodbury、
  QF 分量限幅和 Poisson 重修正、merit 线搜索；未添加严格边界消元。
- 保留 abstol=1e-9、reltol=1e-8、eps_row=0.001、闭合=0.01 与 QF 条件。
  仅将诊断迭代上限及其最小迭代预算设为 3，不更改接受资格。
- A：`sparselu` double；B：`pardiso_mkl` double。矩阵、状态和返回方向均
  为 binary64。后端选择涵盖主系统、Woodbury 辅助 RHS 和 Poisson 辅助求解，
  不能把本批结果归因于其中某一次子求解。
- oneMKL 2026.1，DLL 位于 `C:/Program Files (x86)/Intel/oneAPI/mkl/2026.1/bin/`。
  LP64、实非对称 mtype=11、一基 CSR、METIS、缩放和匹配、主元扰动参数 13、
  最大两次精化。两臂线程请求均为 1；MKL 每次调用设置并恢复线程局部配置。
  参数含义见 [Intel PARDISO 文档](https://www.intel.com/content/www/us/en/docs/onemkl/developer-reference-c/2026-0/pardiso-iparm-parameter.html)。
- 每臂最多 3 次接受更新、软截止 360 s、硬截止 450 s；串行总上限 1000 s。
  实际共 209.16 s，均以 `iteration_limit` 停止，不是超时或崩溃。

两臂初始 HDF5 数值场及残差指标完全一致；首步 `physical.bin`、
`regularized.bin`、`closure_system.bin`、`assembled.csv` 哈希全部相同。
第二、三步在各自状态上重新装配，因此不是继续固定同一矩阵的线性对照。
这也不是上一批 Sentaurus 人口坐标矩阵的直接重放。

## 局部方向及线性误差

10280 空穴方向（V）；“原始”包括原正则化/闭合系统的线性方向，
“接受”是经过原更新处理后的实际位移。

| 更新 | SparseLU 原始 / 接受 | PARDISO 原始 / 接受 |
|---|---:|---:|
| 1 | -305.379042 / -0.05 | -306.075627 / -0.05 |
| 2 | +0.0806392 / +0.05 | -0.0685243 / -0.05 |
| 3 | +0.0134751 / +0.0134751 | -6.0457909 / -0.05 |

第二步已出现相反方向，但两臂父态此时不同，不能直接宣布某个后端在同一系统
上错号。末态该节点空穴行比仍分别为 1.002779/1.003618，均未通过。
HDF5 人口换算为 cm⁻³ 后分别为 101.65/0.182325；其 QF 差 0.163475 V。
现有 progress 诊断 `density_m3` 字段仍输出内部 cm⁻³ 口径，本表以 HDF5
`holes_m3 / 1e6` 为准，没有更改既有证据字段。

主要阻塞节点 10238 两臂每步均接受 -0.05 V，三步后的 QF 和人口相同，
空穴密度约 0.329464 cm⁻³，行比均为 1.88756。这里的原始方向差被限幅掩盖，
有助于解释为何部分弱行改善，但最大行比和空穴闭合基本不变。
两臂末态最大电势差只有 3.28e-15 V，不能据此推断载流子场也相同。

用扩展累加精度在保存的 binary64 闭合系统上计算 `A·dx-b`：

| 更新 | SparseLU 相对 L2 线性残差 | PARDISO 相对 L2 线性残差 |
|---|---:|---:|
| 1 | 4.703e-15 | 1.732e-15 |
| 2 | 5.903e-15 | 3.276e-15 |
| 3 | 8.346e-15 | 4.101e-15 |

分量后向误差使用 `abs(A·dx-b)/(abs(A)·abs(dx)+abs(b))`。首步两臂最大值
都为 1，例为空穴节点 13477，但对应绝对缺陷分别仅 2.10e-20/3.30e-32
内部单位。这说明极弱行上的比值必须连同分母和绝对缺陷阅读。
该核对不是独立高精度方向参考，也不能把小整体线性残差视为所有弱方向准确。

## 后续判断

PARDISO 可作为显式诊断后端继续使用，本批不支持替换默认后端，也不支持放宽
行比或闭合。三步预算只回答早期重线性化行为，不证明继续迭代必然失败。
下一项有辨别力的比较是固定第二步同一父态/矩阵，用两后端及已有高精度参考
核对 10280 邻域，再区分线性方向差和状态反馈；同时单独跟踪 10238 的持续
限幅与源/输运平衡。不能把上一批原生人口矩阵重放的良好结果直接等同于本 QF
迭代路径已经恢复。
