  温度 300 K，坐标 µm，状态/人口探针密度 m⁻³，原生密度 cm⁻³，电流 A/µm，外电阻 `1e7 Ω·µm`。
- 复用修复迁移率后的 Release 核心；36 次本机只读导出选择 SparseLU/COLAMD、单线程。
  HDF5/UMFPACK 可用；本轮没有进行非线性求解或新扫描。
- 原生 `sdevice -d` 第 8/11/13 次更新前状态对应 zero/first/second；QF、DOS、带边来自同帧导出，
  不再使用更新后的 QF。原生导出密度与 debug 人口最大相对差小于 `4.0e-14`。
- 比较 6764 个共同自由器件行：2522 个 ψ、2121 个电子、2121 个空穴。
  排除受约束 ψ 和原生电路别名；接触邻边通量仍完整保留。
- 所有控制使用**固定的基准 Vela 人口变换后对角**作为左尺度，原生使用原始自身对角。
  控制之间不再更换分母，也不将旧人口变换用于新状态 Jacobian。
  下文载流子 L2 位于 `n/Nref`、`p/Nref` 坐标，`Nref=1.4824351e10 cm⁻³`；不是相对物理误差。

三个实际算子控制每态各导出完整矩阵/RHS、载流子分项、SG 边及人口：

| 控制 | 保持内容 | 有意变化及资格边界 |
| --- | --- | --- |
| baseline | 原生 ψ、自由人口；Vela 反算 QF；规定接触 QF | 与上一轮基准导出逐文件一致 |
| all_population | 原生 ψ、全部半导体人口，包括接触 | 接触 QF 也用反算值，违反规定电压；仅用于定位 |

另构造冻结人口、迁移率和 Fermi 退化割线的输运反事实：使用实际生产 SG 核，
替换内部 QF、再替换接触 QF，同时平移有效带边漂移项以保持原人口关系。
保留 all_population 的显式源分项，分别汇总所有边的有向散度。
这是人为分离算子输入的诊断，不能当作同一生产状态或原生 SG 支撑认证。
生产核重放边通量的相对 L2 最大 `5.55e-15`；边到节点散度重放最大 `8.31e-15`。

## 2. 同人口 QF 和接触差

first 的自由行反算 QF 与原生 QF 绝对差：

| 载流子 | 中位数 | p95 | 最大值 |
| --- | --- | --- | --- |
| 电子 | 6.854 µV | 19.195 µV | 191.666 µV |
| 空穴 | 6.802 µV | 6.981 µV | 178.173 µV |

按带边基准、DOS、热电压及原生反算近似四项逐节点作**带符号**分解，
三个状态的最大闭合差 `3.33e-16 V`。这些分项会互相抵消，最大值或 L2 不可相加。
电子原生反算近似项最大 `304.730 µV`，DOS 项最大 `79.124 µV`；
空穴反算近似项约浮点舍入量，差主要出现在带边基准项，不能统称为 Fermi 近似误差。

baseline 自由人口误差小于 `3.4e-13`，但规定接触 QF 下人口最大相对差：
电子 `0.135158%`，空穴 `0.692342%`。
all_population 将接触人口误差降到约 `7e-15`，代价是接触 QF 偏离规定电压最多
电子 `191.881 µV`、空穴 `178.367 µV`。因此不能用放开接触的控制作正式修复。

直接换 native_qf 后，自由人口最大变化为电子 `0.136456%`、空穴 `0.691586%`，
first 的 Poisson RHS 差反而从 `1.24746` 增至 `11.65989`。
这排除了“直接复制原生 QF 即完成同状态对齐”的解释。

## 3. 完整载流子 RHS 分解

first 的完整 RHS 差 L2：

| 控制/反事实 | 电子 | 空穴 |
| --- | --- | --- |
| baseline | `1.02361157e8` | `15149.6323` |
| 全部人口匹配，含接触 | `2.63388942e7` | `21.89759` |
| 冻结人口/迁移率，内部及接触均改原生 QF，源仍冻结 | `0.0183320` | `0.0122587` |
| 原生 QF 的实际 Vela 算子，人口随之改变 | `0.0152968` | `1.09982e-5` |

zero/second 有相同的大差变化趋势，完整逐行结果全部保留。
电子基准最大绝对差节点 2364 的问题首先属于 QF/接触组合，不是仅靠迁移率顺序能消除。
只改内部 QF、仍保留反算接触 QF 时，大差会重新出现；内部和接触必须作为共同契约检查。

脚本输出四个带符号向量，使完整差严格分为：接触人口、内部 QF 输运、接触 QF 输运及未解释余项。
三个状态最大相对闭合差约 `2.1e-16`。该分解依赖明确的控制顺序，分项范数不可当作可加占比。
每个实际算子控制均核对 SG 散度、全部源/边界/gauge 和完整 RHS；最大内部闭合差 `1.08e-14`。

## 4. Poisson 完整残差控制

固定原生 ψ 和人口，先更换电荷盒，再更换原生单元边系数，最后使用一个独立矩阵电荷系数的尺度：

| first 控制 | Poisson RHS 差 L2 |
| --- | --- |
| 当前基准 | `1.24746395` |
| 仅原生半导体盒体积 | `0.309521291` |
| 原生盒及单元边系数 | `1.31210358e-4` |
| 再用原生矩阵电荷尺度 | `3.78471e-11` |

节点 243 的原生电荷 Jacobian 系数确定 `q/ε` 在两套约定下的相对尺度
`1.0000082142581175`，不是由 RHS 拟合，也不能从该组合单独断言 q 或 ε 的取值。
其余 2120 个共同半导体行的系数最大相对偏差 `6.89e-15`。
同一尺度应用于三个状态的完整自由 Poisson 残差后，差 L2 为 `3.75e-11～3.79e-11`。
原生单元边系数控制解释盒体积替换后剩余的介电通量差。

这是矩阵几何与尺度对**残差**的独立交叉检查，生产默认几何和常数保持原值；
不能将离线候选的结果转授生产全 Jacobian 或 PN2D BV 模板。
