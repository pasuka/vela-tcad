# LDMOS Poisson 一致初始化对照

日期：2026-09-15；分支 `codex/templates-ldmos-phase-a`。
本轮执行用户授权的 Poisson 一致初始化验证，前置证据见
[伪瞬态接受准则验证](templates_ldmos_pseudo_acceptance_2026-09-15.md)。

**结论：本轮对照完成，尚无可晋级候选。** 两档 Poisson 准备均通过；它显著
改善 G 接受的试步质量，并让模型误差控制走到近稳态，但最终仍受原载流子
逐行门限阻塞。R7 原种子仍各 15 更新通过；加准备后 Vg4 总计 24 更新通过、
Vg8 总计 16 更新失败。不能把此预处理接为默认加速，原 R7 和验收门限不变。

## 范围与实现

仅使用原八代表点清单中的两个冻结难点：Vg=4 V 的 `vg4_p11` 和 Vg=8 V
的 `vg8_p9`，Vd 均为 5.333333333333333 V。原网格、SI 几何/物性/接触参数、
参考输出及最终门限保持不变。本轮新增实验运行/分析脚本和回归；没有修改数值
核心、生产默认、质量矩阵、密度投影或接受准则。

直接复用上一轮冻结的 Windows UCRT64 GCC 16.2.0 Release/UMFPACK EXE
及匹配的 16 个 DLL，逐一验证哈希；同时核对原源码清单中的 161 个
`src/`、`include/`、`examples/` 文件均未改变。每个仿真进程的 OpenMP 和
OpenBLAS 各设一线程。这是本机代表点诊断，没有新增同 VM 性能资格。

1. 原输入只切换到已有 `solve_mode=poisson`，固定输入 QF 和温度求解 ψ。
   预处理最多 60 次尝试，保持原 Poisson 门限。此时内部载流子/温度约束
   行通过不能算作原完整电热系统通过。
2. 只将状态、QF 参考值和电势原点复制回原始完整配置，恢复有限空穴交换、
   中性接触及其他原边界，执行零次 Newton 的耦合重装配。
3. 检查原边界下 Poisson 加权块≤5e-8、QF 保持误差≤1e-14 V、温度保持
   误差≤1e-12 K，并检查审计没有改变状态。失败的预处理不进入后续矩阵。
4. 合格准备状态分别进入 R7、PTC+V1 原稳态接受、G+SER、G+模型误差控制。
   每组仍使用原 60 次耦合尝试预算，原物理/逐行/块/电流/热平衡门限及
   相对原参考状态的 ψ/fn/fp≤1e-8 V、T≤1e-7 K 检查全部保留。

各变体都计入完整预处理与审计成本；不能把新增预处理预算藏在原 60 次
耦合预算之外。实际每档预处理和审计各运行一次、供四个候选复用，报告中
每个候选均加回其完整成本。点与变体串行执行；开发、分析和一次回归检查
产生同机活动，单次墙钟只作诊断，不据此认领稳定加速。

初始 tau 仍按原 `median(abs(Mii/Jii))*1` 规则计算；行尺度仍由各次求解
自己的初始 Jacobian 固定。因此初态改变也会影响这两个派生量，本轮没有
额外锁死数值 tau 或跨实验行尺度。不能直接比较两条轨迹固定范数的绝对值；
只报告各自最终/初始比及原物理块/逐行门限。

| 原边界恢复后的 Poisson 加权块 | 7.42458e-9 | 7.27752e-9 |
| Poisson 更新/分解 | 5 / 5 | 5 / 5 |
| 预处理及审计总装配 | 7 | 7 |
| 最大 ψ 改变量（V） | 0.150306 | 0.157479 |
| 最大 fn/fp 保持误差（V） | 4.44e-16 / 4.44e-16 | 4.44e-16 / 4.44e-16 |
| 温度保持误差（K） | 0 | 0 |
| 耦合审计状态改变量 | 全部为 0 | 全部为 0 |
| 预处理＋审计墙钟（s） | 4.2750 | 4.4105 |

原边界审计的电子/空穴加权块分别为 0.0362180/0.0717095、
0.0887570/0.0853959，均不合格；温度残差 L2 为 1.65129/3.26197。
所以本轮是 **Poisson 一致初始化**，并非 ψ、T 两组代数方程全部一致。
固定 QF/T 调整 ψ 也会改变载流子密度，不能称作“只消除 Poisson 残差且不
影响载流子初态”。

### 初态对轨迹的实际影响

- G 接受首步 alpha 从 0.138792/0.048223 变为两档 1；模型误差从
  0.266265/0.319244 降为 0.0127336/0.00222325。对应初始 tau 仅由
  7.41412e-14/7.78122e-14 变为 7.41695e-14/7.78200e-14 s。
- G+SER 每档 60 次全部为 alpha=1、没有映射回退；耦合试算从 397/415
  降至 60/60，但 120 次接受均伴随稳态 F 增加。最终/初始固定尺度 F 比
  为 6.63812/12.3010，SER 仍逐步减小 tau，未到所需稳态。
- G+模型误差控制能增长 tau，固定尺度 F 最终/初始比降至
  1.00478e-13/5.05887e-13。原种子下对应比为 11.0845/2.80334。
  每档前 24 次由 G 判据接受；后续进入原近底部规则。
- 本轮两个新准则合计 168 次实际 G 试算，全部决策与记录范数的 Armijo
  判据一致；这是日志决策复核，没有独立重装配全部历史候选。

## 后续定位边界

本轮证明 Poisson 初态对伪瞬态的阻尼、模型误差与轨迹有实质影响，不能将
它归为无关因素；也证明仅闭合初始 Poisson 并不能保证原门限下稳态收敛。
固定 QF 准备还可能让 R7 的载流子初态变差，不能无条件作为通用预处理。

下一项最直接的诊断是冻结这两个近稳态失败状态，在原门限下分别隔离
伪时间质量项、密度反算和 QF 参考表示，检查改回 R7 QF 更新/重装配能否闭合
逐行残差。两档终态物理状态几乎与参考一致但逐行比仍超限，提示需要检查
近零电流行的数值分辨率与更新映射；本轮没有将具体实现唯一归因为舍入。
若设计近稳态切换，须连同前处理和全部失败成本重新验证，不能只计最终
修正的几次更新。本轮未执行该切换、完整代数初始化、前八点或完整曲线。
