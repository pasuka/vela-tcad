# LDMOS 带区间保护的局部标量 Newton 求根验证

日期：2026-09-16。分支 `codex/templates-ldmos-phase-a`，源基础为 `d2fd6ff`
及上一轮尚未提交的[Newton/装配成本改动](templates_ldmos_newton_cost_2026-09-16.md)。
本轮用户授权验证带区间保护的标量 Newton；既有本机 VM 上传、下载和仿真
授权沿用。修改前五个相关源文件及哈希另存于本轮 `prior_sources.tgz` 和
`prior_sha256.json`，未覆盖上一轮证据。

## 对象与范围

这是中性初始化/接触目标内部的标量方程
`f(psi)=n(psi)-p(psi)-(Nd-Na)=0`，固定当前偏压、温度与掺杂，使用原 Fermi/BGN
模型和已有 `dn/dpsi-dp/dpsi`。不是器件四方程 Newton 的变量、线搜索或终止
规则变更。局部求根次数、每次求根的密度评估次数、外层 Newton 更新须分别
统计。

独立开关 `diagnostic_neutral_root_newton` 默认 false。本轮与根缓存、局部
QF 裁剪隔离，只在冻结 R9 接触配置上切换此开关。先做局部物性/导数检查，
再检查两档 Vg 各 4 个原种子代表点，Linux 两轮反向顺序复测。代表点通过
不自动取得从零初始化后的前 8 点跨步、完整 62 点或新版本恢复资格。

## 算法及保护

- 原 `bias +/-1.5 V` 根区间和 `n-p > Nd-Na` 严格比较保持不变。
- 在当前区间内用原密度导数提出 Newton 点；导数须有限且正，点须严格
  位于区间内，移动不超过当前区间宽度的一半，否则选二分点。
- Newton 点因舍入未移动时，可向区间另一侧探测一个相邻浮点数。连续
  邻点行走被禁止；若未闭合则继续二分/保护 Newton。
- 仅当区间中点已等于某个端点时结束，不以放宽电中性残差结束。最多
  70 个候选迭代，未闭合则重新执行原 70 轮二分；所有成本记录。
- 若返回根附近的浮点间距小于原区间宽度除以 `2^70`，原固定轮数方法
  本来就未达到相邻浮点数分辨率，此时也回退原 70 轮，保留其有限预算的
  舍入约定。最终 `dpsi/dT=-(dn/dT-dp/dT)/(dn/dpsi-dp/dpsi)` 保持。

`neutral_root_iteration_counts` 依次记录密度评估、Newton 提案、二分选择
（含原二分轮数）、邻点提案、原算法回退。候选最初的中点另算一次密度
评估；实际计算成本使用第一项，不把提案数当作器件 Newton 更新。
该开关允许在中性初始化及栅压预偏置使用，已增加对应运行器回归。

## 首次边界失败及修复

初版在本征/完全补偿、约 300 K、零偏压附近出现 8 个温度导数比对失败，
差约 `7e-17 V/K`：固定 70 轮与一直收缩到相邻浮点数使用了不同的最终舍入
位置。记录保留在 `numerical_initial_failed.log`。加入上述基于区间分辨率
的原算法回退后，同一检查全部通过，未放宽测试门限或终态门限。

定向网格包含本征、n 型、p 型及完全补偿共 7 种掺杂，200/300/相邻300/
450/600 K，-40/-1/-0/+0/0.375/40 V，共 210 个主状态及温度微扰。
检查电中性、与原根/导数的一致性、温度有限差分、错误输入和计算量。
原有完整算子及热电耦合用例一并运行。

## 复现入口与结论

在已有冻结 R9 证据根与 Release 探针可用时，显式选择两种配置；输出目录
须是新的独立目录。`--evidence` 使用既有运行器要求的完整基线证据结构，
不是本轮仅包含代表点的下载目录。

```text
python scripts/run_templates_ldmos_newton_cost.py --evidence <R9-evidence-root> --probe <Release-probe> --output <new-directory> --variants baseline neutral_newton --repeats 2
python scripts/analyze_templates_ldmos_neutral_root_newton.py --matrix <new-directory> --output <audit.json> --repeats 2
```

候选已完成局部物性、初始化回归及八个真实原种子代表点的配对验证；原门限
未改变。它有效减少每次局部求根的计算量，整体时间收益较小。推荐 R9 与
通用默认均保持不变，候选默认关闭；本轮未进行从零初始化的前 8 点跨步及
完整双栅压 62 点验收，不能继承旧程序的完整曲线资格。若继续评估晋级，
须先完成这些轨迹及恢复验证，再作完整边界重复计时。
