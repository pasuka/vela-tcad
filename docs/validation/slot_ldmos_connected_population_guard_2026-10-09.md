# SLOT 连通子域人口更新与真实邻行保护对照

日期：2026-10-09。证据：`build/s09connected_population/`。

## 结果

完成 12 个同父态冻结试探，没有一个同时通过目标行改善、邻行、残差块与闭合保护；0 次接受更新、0 个新增完整合格点。

局部化避免了上一批全域人口更新新增数千条空穴失败行的问题，但产生了新的**电子行**阻塞：10849 一圈子域沿现有方向更新，空穴行比降至 0.88564，却新增 6 条电子失败行；扩为三圈新增 18 条。局部联动最小二乘在一圈可以不新增失败，但目标空穴行没有改善。10237 的局部重求也没有建立空穴源/输运平衡。

本批所有实际新增失败行，在父态线性预测中已经超出 0.001。因此这批结果首先指向**求方向时对健康行只作软惩罚不够**，不能全部归因于有限步长曲率；此结论不排除其他方向中的非线性困难。

## 变量差异及同态范围

用户提醒的区别明确保留：Sentaurus 导出的 Newton 系统使用电子、空穴人口；Vela 保存态及当前系统使用电子、空穴 QF。
本批没有直接比较两者矩阵元素、变量增量或误差范数，也没有把 QF 增量当作人口增量。

所有试探起于 Vela `s09second_step/two_updates/progress/iteration_1.h5`，Vg=5 V、Vd=0.006 V、原点 0 V。这是**未取得完整资格的首个 Newton 迭代态**，不是新的合格父态。
利用本态 Fermi 链式导数，将局部 QF 方向转成相对人口坐标，有限更新后通过同一统计函数逆映射回 QF：

```
yn = δn/n = gn (δψ − δφn)/Vt
yp = δp/p = gp (δφp − δψ)/Vt
g = F′(η)/F(η), η = F⁻¹(q/DOS)
q* = q (1 + α yq)
δφn* = α δψ − Vt [F⁻¹(n*/Nc) − ηn]
δφp* = α δψ + Vt [F⁻¹(p*/Nv) − ηp]
```

参考量不变，写入分离 QF 增量；冻结装配器重新计算人口并核对目标，所有试探的相对误差检查均通过 1e-8 上限。没有移植原生内部算法，也没有在 Vela 生产求解器中改用人口未知量。

几何子域包含边界/绝缘节点，接触偏压和非有效载流子变量不更新，因此变量数不是节点数的三倍。
对每个子域比较：

1. **截取现有方向**：将上一批稳定化全局方向转为人口坐标，仅保留本子域变量，再施加本批幅度界，α=1。
2. **局部联动重求**：使用首步后原物理矩阵（含边界/规范方程、未加入载流子正则化和闭合替换），构造局部人口变换 T。以其全部非零行支持集求解有界最小二乘，允许 ψ、电子人口、空穴人口联动；测试 α=1，失败后测试 α=0.25。

局部优化目标是 `min ||W (Jphys T y + r)||₂`。载流子行权重取父态原行比尺度的倒数（保留 1e-30 下限）；ψ 行权重取 `1/max(|rψ|,1e-9)`，随后列均衡、BVLS 有界求解。ψ 权重是诊断方向选择，不是最终验收标准。
最小二乘为软目标，**不是逐条健康行硬约束**；真实邻行保护在冻结装配后执行，这是本批明确的对照边界。
局部重求不等同于把原稳定化矩阵换个坐标：它同时限制子域并针对原物理方程重新优化。

人口倍率界：电子 [0.5,3]，空穴 [0.5,50001]；|δψ|≤0.001 V，|δQF|≤0.35 V。截取方向先投影到上述人口界，避免继续使用上批 1% 下限。局部重求在同样界内优化。子域外所有更新分量为零，连通性和外域冻结均已检查。

## 真实接受保护

全部 12634 条电子有效行及 12634 条空穴有效行重新评估，不仅检查子域行。试探须同时满足：

- 目标空穴行比至少改善 1%；
- 父态合格行没有新增超过 0.001 的行；
- 除目标行外，已有失败行的行比不恶化；
- 三个残差块及两种载流子闭合比不恶化。

后三类数值比较中使用 1e-6 相对裕量（失败行比较另有 1e-12 数值余量），仅用于诊断的“不恶化”判定，原 0.001 行比及最终闭合 0.01 门槛不变。未通过保护的试探即拒绝，不进入下一迭代。

## 线性预测能否预警

由每个试探的实际人口倍率反构造原一阶人口增量，再通过 Fermi 链式关系形成线性 QF 方向，计算 `r + Jphys δx`；预测行比使用父态尺度，实际行比使用重新装配尺度，两者不混称。

所有试探实际新增的电子失败行，在该线性预测中均已超过 0.001：例如 10849 一圈截取为 6/6，三圈联动为 20/20；10237 一圈联动为 3/3，三圈联动为 17/17。并非只在有限步长装配后才暴露。

局部最小二乘的加权范数可以下降，但以牺牲少量健康行换取其他行改善。四个局部优化均正常返回（一个无约束解已在界内，其余以相对目标变化终止；记录的最优性指标约 2.4e-15 至 7.2e-10），它们不构成“原器件没有可行恢复方向”的证明。

## 后续判断

当前最有辨别力的改进是把新增失败所对应的健康电子行约束**显式加入方向优化**，同时要求目标空穴行预测改善，并继续用实际装配结果守护。如果受当前子域和幅度界限制而不可行，应记录可行性及阻塞行，而不是继续扩大软权重或重复缩放一个不能改善目标的方向。
实际保护仍不可省略：线性预测不是最终资格。本批不支持放宽门槛、仅增大子域或直接恢复长扫描。
