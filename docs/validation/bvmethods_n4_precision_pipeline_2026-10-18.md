# BVmethods N4：统计舍入、保精度源装配与一致导数

日期：2026-10-18。承接[SG共同门及完整非局部方向](bvmethods_n4_sg_avalanche_full_jv_2026-10-18.md)。
机器可读结果见[配套JSON](bvmethods_n4_precision_pipeline_2026-10-18.json)。

本轮进一步定位SG统计链，将保精度雪崩源、分项增量和导数接入私有C++装配，
并使NonLocalPath本次电子人口方向的158条内部响应失败降为零。**N4仍未收口**：
SG当前绝对值／可微方向共同门和完整耦合验收仍保留。绝对门`1e-8`、方向门`1e-5`均未修改。

## 1. 状态与实现范围

沿用安装库BVmethods resistor、T-2022.03-SP2、300 K，Fermi／默认Joyce–Dixon及OldSlotboom，
原迁移率、GradQuasiFermi雪崩、NonLocalPath及固定`1e7 Ω·μm`外电阻。
网格2600节点、5020个Tri3，其中4156个Si单元、2121个自由载流子节点，6843个增广未知量。
使用`accepted_0053`的Load首RHS，内电压约6.674544666648 V、外电压约1026.926046296 V。
人口参考浓度`1.4824351e10 cm^-3`；非局部带量为J，双源积分为`m^-1 s^-1`。

本轮Ubuntu 26.04 WSL恢复可用，实际私有C++候选采用GCC 15.2、Release配置（`-O1 -DNDEBUG`）及`-ffp-contract=off`；
复用已验证的核心对象及数学兼容库。构建具备HDF5、UMFPACK、SPQR和METIS支撑，本轮未调用线性求解器。
宽精度主链采用Boost 80位十进制，binary64入口保留已验证的最近舍入。
独立核对使用Windows Python Decimal，主要累加110位；没有新增原生仿真。

结果指私有实际求值中的保精度装配通道，尚未替换生产Newton。原始binary64通道和失败账本均保留。
旧`source_detail.accumulation_digits=100`字段描述最后的十进制容器；本轮模式3／4的源计算及累加实际为80位，
没有把这一旧字段当作100位求值资格。

## 2. SG参数的统计舍入

三态各273条支撑边共1638个端点的Gamma值与此前绑定重放逐值一致。
同一人口／带状态下逐阶段替换求值环节，继续采用已捕获下游传递作观察性归因：

| 累积引入的环节 | 41条目标行中的共同门冲突数 |
| --- | ---: |
| 保精度统计与SG控制 | 0 |
| `n/DOS`的binary64舍入 | 31 |

| 实际log值 | 35 |
| Gamma相减舍入 | 35 |
| Gamma边差、带边差及最终参数加减 | 35 |

这些是累计阶段计数，**不是互斥的原因分组**；η、log和Gamma阶段存在失败行的进入与退出。
本批后面的带边差和最终加减没有新增冲突。273条边的参数响应中，2条被量化为零、2条符号反转；
基准参数最大绝对表示差约`2.194e-15`。近零电流相消会放大这一小差异。

结合上一轮乘积舍入新增的2185行，实际36条共同门冲突仍保留；观察性分解未当作可部署迁移率修复。
三态目标完整绝对失败仍为38／39／38条，旧正QS的95条失败也未重新取得资格。

## 4. 雪崩源与导数

保留全部8312个电子／空穴单元源的当前驱动力、SG电流、迁移率及指数系数，
在局部源率层先求当前值减参考值，再按相同盒权重和归一化因子累加增量。
源身份、节点或面积、归一化不匹配时直接拒绝，不用一个固定偏移补偿当前绝对值。

首版候选暴露出进一步的转换问题：宽精度alpha／斜率过早转为double，使1232、1244、1935三行的导数消失。
第二版将链式乘积和导数累加也保留宽精度，并导出独立宽精度导数通道。
第二版原始操作数、保精度绝对RHS及原始RHS与首版逐值相同；仅导数通道改变。
原50条行与独立数学导数全部一致，最大差`3.611e-12`。
1935行匹配响应约`−2.818075338e-324`，相对差约`9.77e-17`，没有按下溢为零豁免。

| 实际正向人口增量倍率 | 原50条通过／失败 | 全2121自由行通过／失败／零响应 |
| --- | --- | --- |
| 1/64 | 20／30 | 1388／613／120 |
| 1/4096 | 50／0 | 1545／455／121 |

最细档原50条最大方向差`2.098e-6`。上述增量由C++分项源差直接生成，再与同态第二版宽精度导数对照，
不再仅凭独立源公式判定通过。基准操作数逐值相等，绑定了分项差与第二版导数的状态身份。

全自由行仍有455条失败，其观测增量和Jδ均非零、同号，且全部小于binary64最小非零数；
最大观测响应约`4.905e-728`，单位为归一化连续性残差。430条在细化后误差下降。
更宽的指数范围显露出原double表示不出的响应；这些行仍按原方向门保留失败。
目前不能把455条全部归为有限步长曲率，也不能用下溢或小量门限改判通过。
