# SLOT PARDISO 近零行线性误差保护核查

## 结论

本次 6 mV 配对提前停止，主要由新增的统一分量后向误差硬保护对近零平衡行过度敏感引起。
0.85985 这个数可以用高精度独立求和复现，不是统计程序算错；但它不是整个线性解的相对误差，更不能解读成解错了 86%。
未发现约束消元、RHS 修正、回填或 Vela 的 MKL 调用封装错误。
PARDISO 在这些极弱行上确有比 UMFPACK 大的微小误差，但同方向有限步重放没有显示实质性的本步物理差异。
结论限于本父态、固定矩阵和首次有限步；尚未完成 PARDISO 的连续非线性复验。

本次只生成独立诊断结果，未修改冻结续算配置、生产求解器或验收规则，未恢复 60 V 扫描。

## 对象和方法

- Vg=5 V，Vd=0.006 V，父态为新冷平衡及门压建立路径的 5 V/0 V 合格终态。
- 使用 `build/s12drain/results/d000_1_matrix/data/` 与 `ref000_1_matrix/data/` 的 Vela 装配系统；不是 Sentaurus 导出矩阵。
- 物理配置、AverageBox、Fermi、有效带边 SG、完整源项与本轮冻结输入相同。
- UMFPACK 与 oneMKL PARDISO 均为 binary64、严格代数消元；正则化和闭合方程替换关闭。
- 全系统 41643 行，661966 个保存条目；2620 个对角单项约束自由度消元后为 39023 行。
- 独立复算采用 NumPy long double 求和，并用既有 Boost `cpp_bin_float_quad` 工具复核保存的 binary64 数据。
- 本机 oneMKL 直接 API 重放约简系统；另外评估有限次数残差修正。所有这些都是固定线性系统，不生成新的漏压合格点。
- 将两份保存方向各重放一次相同的浓度有限步，再做零更新真实残差和闭合评估。UMFPACK 重放的全部 HDF5 场数组与远端保存的第一次更新逐位相同。

矩阵及 RHS 哈希相同：

```text

SHA256 de6e72b4c354da88fcbf02c6f1e5f6458f849317300f86b6a4d590741ea79986

4d9fe92aba64976fffe50c8b86820bb91bb790ce906ea7c3e2c2300a40df5a8a
```

## 误差数值及所在区域

所用分量后向误差为

\[
\eta_i=\frac{|(Ax-b)_i|}{(|A||x|+|b|)_i}.
\]

它衡量按该行现有数值量级的相对后向误差，不是方向的前向误差。
下面的残差和 RHS 均为内部缩放坐标，不能直接当作 A 或 A/µm。

| 指标 | UMFPACK | PARDISO |
|---|---:|---:|
| 最大分量后向误差，long double 求和 | 2.1361e-16 | 0.8598548430 |
| 线性相对 L2 残差 | 8.7038e-15 | 8.3135e-15 |
| 最大绝对线性残差 | 1.1097e-13 | 1.0353e-13 |
| 分量后向误差超过 1e-6 的行数 | 0 | 248 |
| 约束行误差及回填误差 | 0 | 0 |

quad 独立求和仍得到 PARDISO 最大值 0.8598548430395852349262，最大行不变；该结果排除了 binary64 残差统计求和造成此数量级的解释。

248 条行全部位于多晶硅及其氧化层界面：

| 支撑材料 | 电子行 | 空穴行 |
|---|---:|---:|
| PolySilicon | 123 | 32 |
| PolySilicon/SiO₂ | 83 | 10 |

Si 区域及其界面对应自由度的最大分量后向误差为 1.8542e-11。
这 248 条行的最大绝对线性残差仅 8.9898e-31；两后端在这些自由度上的方向差最大 3.0648e-17 V。

| 节点及变量 | 材料 | 分量后向误差 | 绝对线性残差 | 与 UMFPACK 的方向差 V |
|---|---|---:|---:|---:|
| 12647 电子 QF | PolySilicon/SiO₂ | 0.859855 | 8.4686e-32 | −5.6449e-18 |
| 13482 空穴 QF | PolySilicon/SiO₂ | 0.623094 | 1.0501e-31 | 2.3019e-17 |
| 13638 电子 QF | PolySilicon | 0.528726 | 1.6638e-31 | 7.7316e-19 |

最大行 26528（零基编号，节点12647电子QF）的 RHS 为 3.7313e-46，分母为 9.8489e-32。
PARDISO 的该分量方向约 −5.6449e-18 V，UMFPACK 约 9.7518e-28 V。
方向都接近零，但两者相除形成的分量相对指标差异巨大。
全系统最大原始方向差为 2.1573e-8 V，位于节点10237；它不属于触发保护的248条行，不能与这些行的差异混为一谈。

## 消元及独立 API 核查

`src/solver/LinearSolver.cpp` 仅消去数值上恰为对角单项的方程，并使用实际对角与 RHS 计算固定增量。
本系统所有 2620 个固定增量恰为零，因此自由行 RHS 的仿射修正也是零。
全系统、自由行和约简系统的最大误差同为0.8598548430，固定行和回填误差均为零。
因此本次最大误差不是遗漏非零边界增量、回填索引或仿射 RHS 修正引起。

独立 Python/ctypes 直接调用 oneMKL，对同一约简矩阵/RHS 使用与 C++ 后端相同参数，
得到的完整方向与远端保存的 PARDISO 方向逐位相同，最大差为0。
这也核对了 CSC 到 CSR 转换、索引口径以及本次调用参数的实际效果；未证明其他状态的所有调用均无问题。
默认调用报告2次内部精化、0个扰动主元。

有限精化诊断结果：

| 固定系统诊断 | 最大分量后向误差 | 超过1e-6行数 |
|---|---:|---:|
| 默认 PARDISO | 0.859855 | 248 |
| 外部真实残差修正1次 | 0.0114209 | 28 |
| 外部真实残差修正2次 | 6.6556e-6 | 3 |
| 外部真实残差修正3次 | 7.5116e-6 | 6 |
| 外部真实残差修正4次 | 2.5742e-6 | 2 |
| 内部精化上限改8，实际4次 | 约1 | 49 |

外部修正仍使用相同矩阵，只以 long double 求和得到的真实残差作为新 RHS。
它显著减少超标行，但并非单调，也未在4次内满足全部1e-6硬门槛。
单纯增加内部精化次数也不保证此近零行相对指标改善，不能据此直接修改默认参数。

## 首次有限步的真实影响

两份保存方向均使用原始浓度有限步、相同 Fermi 逆映射、正性投影、电势对数阻尼和接触保护。
每臂仅构造一个诊断试探态，不进行新的 Newton 重线性化或资格提升。

| 指标 | UMFPACK方向 | PARDISO方向 |
|---|---:|---:|
| 真实整体残差 | 1.432162216094526 | 1.432162216094515 |
| 电子闭合比 | 1.000000440907307 | 1.000000440907307 |
| 空穴闭合比 | 0.029083462469821 | 0.029083462469829 |
| 漏端电流 A/µm | −5.631135974778665e-4 | −5.631135974778598e-4 |
| 电子/空穴行比超标数 | 4342 / 9454 | 4342 / 9454 |
| 空穴正性投影数 | 3628 | 3628 |

两个首次试探态都尚未合格，不能把表中电流当作6 mV最终电流。
此前 UMFPACK 主路径在第5次更新才按更新误差及原闭合保护通过。

试探态相互最大差：ψ=2.9976e-15 V，电子QF=3.0779e-15 V，空穴QF=1.4238e-12 V；
漏电流相对差1.1937e-14。人口逆映射保护在两臂均通过。
这说明导致本次保护停止的0.85985，没有在已检查的首次有限步中表现为明显的物理偏差。
仍不能从单步相近推断整个非线性路径或最终低密度QF全场必然一致。

## 后续建议

1. 把近零平衡行的分量后向误差与其绝对残差、方向误差尺度共同报告；不要再仅凭所有行统一的相对最大值判定严重线性失败。
2. 在独立对照中设计有量纲依据的混合线性误差保护，并保留整体线性残差、真实试探、闭合和边界保护；本报告未为新容差给出通用物理误差界。
3. 保持原非线性资格，在同一父态完成 PARDISO/UMFPACK 的少量连续更新与最终配对，再决定恢复扫描。原失败记录保留。
4. 不将这次近零多晶硅误拦截推广到此前 UMFPACK 大线性误差个例，后者仍须独立检查。
