# SLOT BVDS 实际SG操作数、目标行及接触反力回代（2026-10-17）

## 结论

在VM完成修正诊断口径下的冻结态回代。3588、3603、6522、12508、13812邻域的
23条有效边、46个边/载流子组合全部覆盖。实际原生SG标量、迁移率乘法及局部累加
均能由捕获的操作数重放；电子、空穴各12,634条自由行与真实PARDISO入口RHS逐位对应。

主要区别是近零通量对人口与驱动量操作数的敏感性，而非所查边存在大的几何或
迁移率系数偏差。另确认：原生默认端口电流与接触反力不是同一积分口径；启用
`DirectCurrent`的零更新输出与捕获的原始接触反力一致。6522仍有极小源项/装配余量
未完成直接分项解释，不能把全部差异归结为浮点抵消。

本批没有修改生产源码、物理、边界或验收，没有启动偏压扫描，新增合格偏压点为0。

## 冻结态与证据身份

网格13,881节点、41,155条原始边，采用原始活性补偿掺杂；300 K、Boltzmann、

Sentaurus U-2022.12、binary64、单线程PARDISO；Vela沿用修正后的split诊断和
生产稳定通量表达。原生实际入口矩阵为39,150维。本次原生受控运行只采集第一次
线性调用之前的操作数；后续脚本输出不进入本次同态比较。

- 新捕获的CSR行列、系数、实际RHS和返回方向，与上一批冻结系统五份二进制逐字节一致。
- 调试导出与实际入口RHS经辅助变量映射后的相对差约1.069e-15；直接捕获的完整方程
  向量与实际RHS另作逐位核对，不依赖调试文本精度。
- 默认端口零更新导出与捕获前状态，经TDX转换的GRD、DAT分别逐字节一致。TDX明确

## 1. 从真实操作数回代到有效边

采集96条SG标量记录，含重复调用；它们不是96条独立边。实际迁移率应用136次，
逐次捕获加载的标量系数，并核对三分量输出均等于输入乘该系数，全部精确一致。
23个单元的电子/空穴贡献按首次装配去重，共46个单元/载流子记录。

原生缓存倍率恰等于SG核除去的归一化边长，不能把它误作待拟合的全局缩放。
随后实际系数是扩散系数D=μVt，单位cm²/s；单元几何权重为无量纲d/l。
同一全局边的系数是各相邻单元D·d/l之和。Vela导出的迁移率使用cm²/(V·s)，
比较时显式乘Vt。没有拟合接触行倍率或修改电阻。

|量|所查有效边最大差异|
|---|---:|
|实际人口相对差|4.844e-14|
|SG自变量绝对差，无量纲|1.954e-14|
|几何权重相对差|1.500e-10|
|有效迁移率相对差|1.419e-6，约1.42 ppm|
|迁移率、Vt与权重乘积相对差|1.419e-6|
|净通量差/左右绝对乘积之和|1.068e-14|

最大系数相对差位于3588–3589空穴边；其对应净边电流差仅约7.61e-40 A/µm。
零权重边的原生标量可能被计算，但实际装配乘积为0；它们不计入23条有效边，
也不据其未使用的诊断默认值推断方程差异。

采用160位十进制精度进行固定顺序的替换账本：原生乘积算术→Bernoulli求值→
驱动量输入→人口输入→迁移率/几何→Vela稳定求差，验证所有阶段之和闭合到最终差。
该顺序分解不是唯一的因果分配；人口与驱动量两项通常明显抵消，不能分别当成独立误差。
高精度对照固定捕获的迁移率，不是另行实现完整迁移率模型或其导数。

### 多晶硅近零流的例子

以下边电流按统一电荷常数比较；表中原生电流为捕获乘积的回代值。

|空穴边|原生 A/µm|Vela A/µm|差值绝对量 A/µm|
|---|---:|---:|---:|
|13651–13812|约−1.152e-17|−5.022e-21|1.151e-17|
|13812–13813|约4.915e-18|4.544e-22|4.915e-18|

第一条边的几何权重完全相同，D·权重相对差约1.47e-16；人口相对差约2.29e-14。
但左右SG大乘积抵消后，净量非常小，不能用净量作分母宣称整体模型存在数量级误差。
固定同一组实际操作数时，原生binary64乘积/求差可精确重放；改变操作数后才出现
上述分叉。Vela稳定表达式与同输入高精度直接表达式也一致到很小的绝对余量。
这些证据支持优先追查操作数生成与平衡关系保持，不支持仅靠增加线性求解精度解决。

## 2. 从有效边回代到目标行与源项余量

必须区分电流符号与全局连续性方程符号：原生电子全局向量对局部电流取负，空穴取正。
统一后，电子/空穴各12,634条自由行均满足“全局方程向量=−实际RHS”，差异逐位为0。
接触约束行不用于计算反力。

## 3. 接触反力与原生端口输出口径

核对安装版《Sentaurus Device User Guide》U-2022.12，正文第254页及Math参数表
第1584页：默认电流包含接触相关掺杂阱的表面电流与阱体积产生项；`DirectCurrent`
使用接触表面积分，默认关闭。混合模式电路节点电流始终采用DirectCurrent。
本批独立器件脚本的`#DirectCurrent`是注释，不能将默认PLT电流直接与接触节点反力混比。
第309页另说明金属接触的默认积分区域；本批不把接触局部对照推广为所有金属模型的建议。

独立执行两份零更新Load/CurrentPlot：一份保持默认，另一份只启用DirectCurrent。
没有Coupled/Newton更新；物理与保存父态相同。
