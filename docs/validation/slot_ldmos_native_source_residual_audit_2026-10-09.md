# SLOT 原生电离支撑与固定人口电势差分（2026-10-09）

本批完成了原生运行时输入观测、源项RHS拆分及固定人口ψ中心差分。主要结论：

1. 21241/21242的原生支撑面积与Vela一致；10849的源率乘节点支撑面积可由实际
   RHS差值验证，上一批Plot源差不是单纯显示插值造成的。
2. 原生默认SG电流重建与Vela逐顶点人口×完整QF梯度源核不同；21241还有界面投影差。
   21242的α接触电场回退一致，不能将它作为余下差异的解释。
3. 原生同态重新装配后的ψ跨块导数也很大，并通过自身残差差分。
   上一批连续迭代中的稀疏矩阵不能直接作为这个状态的完整物理Jacobian参考。
4. 没有修改生产模型或门槛，没有恢复长扫描，新增Vela合格点0。

Vela只读取上一批冻结探针结果，未启动新求解，未改变生产配置、账本或资格门槛。

固定人口 ψ 扰动时同时平移本节点 ψ、电子QF、空穴QF，并检查实际矩阵变量的人口不变。

## α与电流因子不是同一设置

T-2022.03用户手册第494–496页说明：
`Avalanche(GradQuasiFermi)`选择α的驱动力；默认电离电流由SG边通量重建。
`Math { AvalDensGradQF }`是另外的电流近似设置。当前原生基准未开启后者。
本地手册证据：[sdevice_ug.txt](../../build/s09native_newton/sdevice_ug.txt)。

Vela显式 `phumob_element_density_grad_qf` 源核逐顶点使用
`M_k α μ n_k |∇φ|`。源项支撑面积已相符，电流重建仍未相同；
不能把新增原生DensGradQF诊断臂视为更改默认模型的批准。

|10849节点源率，cm⁻³s⁻¹|原生默认SG|原生DensGradQF诊断|Vela原生QF冻结探针|
|---|---:|---:|---:|
|电子|1.53545518150e26|7.80734105760e25|1.90324968786e26|
|空穴|2.28417294595e21|4.24469680816e18|1.15984473060e22|

显式开启DensGradQF也不自动等同于Vela的逐顶点人口/迁移率/梯度组合。

在10849/21242，观测到原生 `currentWoMob`：电子(-485.876763,3694.82127)、
空穴(-0.0490759109,0.511569314)，单位为A·V·s/cm⁴。
α分别2383.96293976和130.179981161 cm⁻¹；PMI公式给出的dα/dF分别
0.0626247047521和0.00565600932402 V⁻¹（不是直接导出的内建偏导）。只使用有效二维分量。

替换α的PMI显式实现同一van Overstraeten–de Man公式，先执行零更新身份比较。
ψ、QF、人口和节点迁移率逐位相同；电子源L2相对差1.25e-19、空穴5.84e-16。
空穴极小值约1.3e-303处出现double/扩展精度下的尾部差异，未宣称全场源率逐位相同。

## 近零QF梯度的单列限制

上一批快照0原生电子QF梯度约1e-12 V/cm，而同人口Vela重建后约0.03–0.04 V/cm。
这是近零驱动力下对本构/表示微差敏感的情形，不能用除以近零量的相对误差判断模型。
接触处α回退至有限电场，电流因子的范数在精确零点不具唯一线性导数；非接触处
α随小驱动力指数衰减又是另一种极限。不能把两类源核的零梯度行为混为一谈。
本批差分对象为快照1，未将其结论外推为精确零梯度处的导数证明。

## 源拆分及最终审计

### 将Plot与实际RHS连接起来

从同一保存态分别启用完整电离、仅电子触发电离、仅空穴触发电离、无电离，
只比较每个进程首次装配的RHS。四臂初始ψ/n/p逐位相同。
电子/空穴两个连续性块的源分量加法闭合L2相对误差分别2.72e-14和3.08e-13。

|10849行的源分量|仅电子源RHS差|仅空穴源RHS差|完整源RHS差|
|---|---:|---:|---:|
|电子方程|738.122075824130|0.010980447339989|738.133056271470|
|空穴方程|738.122075824128|0.010980447339989|738.133056271469|

在原生行尺度下，差值等于
`G_node × M_node / (ND × 1e8)`，其中ND=14824351000 cm⁻³，
M_node=7.126343291999615e-6 µm²；系数6.745657870621116e-19。
10848也符合相同系数。10849的电子源比例误差约5e-15以内，空穴约4.1e-11，
后者受两个较大RHS相减的精度限制。10847极小源在RHS相减中不可分辨，未把零差称为无源。
这在所查自由行上验证了运行时节点源的面积加权口径，不能外推为全部Plot字段都等于装配量。

### 两单元的源分量重建

增加仅观测的HFS替换PMI，ψ/QF/n/p逐位不变；节点迁移率L2相对差低于6.1e-17，
电离率L2相对差低于5.9e-16。原生日志注明采用单元最大顶点体积角的best vertex，
本次α回调在两单元均选10849，恰为两单元面积最大的顶点。

|21241 / 10849|0（导出的数值口径）|3.36881505136e-65|

## 建议的下一步

优先在独立配置中实现与原生默认相符的SG电流源重建，明确代表顶点选择、界面投影、
接触α电场回退、迁移率取值及AverageBox源支撑；不能只在现有密度×QF梯度公式上改常数。
先用本批同态分量、实际RHS及固定人口ψ导数作回归，再有界自洽求解。
保留当前源核作为显式对照，不静默替换物理，不改行比/闭合/QF资格。

矩阵对照一律补独立重装配及差分身份，不继续用旧迭代快照的小系数推断Vela导数有误。
原生迭代内部何时使用哪种线性化尚未定位；本批只证实状态/RHS相同而矩阵不同。
近零QF梯度处仍应另做受控表示与方向扰动，不能将本快照的非零梯度导数结论直接外推。
