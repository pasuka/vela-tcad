## Γ 的真实计算与消费

两个载流子各有一次目标计算入口，共 14 个唯一端点；逐项取得人口、有效 DOS、η、
实际除法结果、`logl` 返回和 Γ 写入。实际路径为：

```
ρ = R80(population / effective_DOS)
L = 实际 logl(ρ) 返回值
Γ = R80(L − η)
```

`R80` 是 64 位有效数字、round-to-nearest/ties-to-even 的独立控制。
`info float` 的 TOP 标记提供逻辑 ST0 的原始 80 位值，并确认控制字为扩展精度／最近舍入。
旧 GDB 的 `maintenance print raw-registers` 在未取浮点寄存器时显示 invalid，
因此没有用该列解码浮点值；保留原日志，以实际 `info float` 的完整十六进制为准。

- 14/14 个实际除法结果与独立有理数逐次舍入一致。
- 14/14 个 Γ 写入与“实际 logl 返回减同次 η”的逐次舍入一致。
- 24 条元素边、48 次端点消费的人口／DOS／η／Γ 与对应计算／写入逐位相同。
  这排除了本首态、这些支撑边上的旧 Γ／新人口混用；不推广到全部节点或后续 Newton 态。
- 独立 100 位数学对数舍入与实际 logl 返回在 11/14 个端点一致；电子 2156 相差 +1 ULP，
  空穴 2515、2523 相差 −1 ULP，绝对值均为约 2.1684e-19。
  这解释了上一轮使用原生 η、却重算数学 log 后不能逐位还原 Γ 的现象，不能将其归因于缓存错位。

本轮没有把采集的 logl 返回作为自主统计实现。η 仍由原生提供；
上轮独立定义积分反算与原生 η 的约 1.54e-14 最大差异尚未被消除，本轮没有重新执行该积分反算。

## Bernoulli 实际分支与独立重建

新首态 24 个实际调用全部进入小参数级数分支，`|a| <= 0.007201`，
未进入指数分支。实际使用成对结果及导数，而非分别计算两个数学表达式后各舍入一次。

新增[独立统计舍入审计](../../scripts/bvmethods_statistics_rounding_audit.py)，在 `|x| <= 1/2`
控制域内求和 `S(t)=(exp(t)−1)/t` 和 `−S'(t)`，每次基本运算单独舍入；
两和均不再变化时停止。由 `B(t)=1/S(t)`、`B'(t)=−S'(t)/S(t)^2` 及成对恒等式
`B(−t)=B(t)+t`、`B'(−t)=−1−B'(t)` 生成四输出，保留乘法和加减的舍入位置。
辅助程序不接入生产求解器，不模拟 IEEE 指数边界或厂商 log／exp；其他原生分支未认证。

| 控制 | 结果 |
| --- | --- |
| 新采集首态，实际 a → 独立舍入级数 | 24/24 组四输出逐位一致，共 96 个值 |
| 上轮基准及 e/h ±1e-12 V 四种子 | 120/120 组四输出逐位一致，共 480 个值 |
| 五态固定人口／元素系数的边电流及弱行求和 | 与采集 B 的同顺序控制完全一致 |
| 独立数学 B／B' 各自一次舍入 | 输出最大绝对差约 2.17e-19，不能逐位替代成对级数 |

四个非零种子沿用已验证的原始输入，本轮只离线重算 Bernoulli；没有新增四次原生扫描。
这补齐了上述样本范围的 Bernoulli 表示／求值顺序，仍使用原生 a，不能称为自主 SG 或全 RHS。

以下仅相对于相同人口、相同单元 κμ、相同累加顺序的采集 B 控制；是弱行表示误差，
不是终端电流、物理模型误差，也不是完整残差验收门限：

| 基准候选 | 电子 2156 相对差 | 空穴 2515 相对差 |
| --- | ---: | ---: |
| 实际 a＋独立成对级数 | 0 | 0 |
| 实际 a＋独立数学 B 各自舍入 | −2.19952432e-6 | 0 |
| 原生 η＋独立数学 log＋成对级数 | +3.54794221e-5 | −1.51371672e-5 |

因此 Bernoulli 与 logl 的末位影响可分别复现；正确的数学函数一次舍入和原生操作顺序
在近零相消电流中并不等价。没有用经验 QF 偏移、拟合常数或放宽弱行门限完成资格。
