# SLOT BVDS补偿掺杂冷态后的非零漏压验证（2026-10-15）

## 1. 结论与范围

从刚通过原完整资格的新补偿掺杂冷态出发，25、50、100 mV三个器件漏压目标全部完成。
实际接受路径为0→25→50→75→100 mV；5次目标尝试中4次接受、1次失败减半。
控制器运行850.99秒（约14分11秒），完成目标后正常退出，未耗尽一小时预算。

本批固定Vg=0 V，属于BVDS短验证。没有启动长扫描，也没有改变物理或验收阈值。
直接50→100 mV失败，而50→75→100 mV通过，说明小跨度与恢复流程在本区间有效；
该结果不能证明高压区稳定，也不是不同路径合格末态的独立复现或Sentaurus定量一致性。

## 4. 50 mV大跨度失败的证据

50→100 mV的首次完整耦合求解运行21次更新后，以`carrier_row_convergence_line_search_rejected`退出。
Poisson块范数1.21278e-10，电子7.50476e-13、空穴3.80950e-14；7460条载流子行超标，最大行比1.88314，闭合满足。
