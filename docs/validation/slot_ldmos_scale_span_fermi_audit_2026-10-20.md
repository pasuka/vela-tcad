## 4. Fermi 表示与高精度 SG 回放

比较保留 QF reference/increment 的原状态与独立副本：
副本把 QF reference 改为已保存物理高位、increment清零。
这是一项**改变状态表示所保留信息**的诊断，不是数学上等价的无损重编码。
两态分别作 SG 导出、源/输运分项和零更新生产求值，共6项正常退出。

在328个目标节点邻域回放1,638条边/载流子记录，采用100位十进制；
人口、迁移率和几何输入固定为实际导出的 binary64 值。
生产有效带边形式为

```
d = +Δφn/Vt（电子）或 -Δφp/Vt（空穴）
a = log(n1/n0) + d
F = coef * n1 * B(a) * expm1(d)
```

Fermi 修正经实际人口比进入该形式，未使用 Boltzmann 人口近似。
由于此处 a 按该恒等式重构，`δ_eq = log(n1/n0)-a = -d` 是代数关系，
不能用其相等证明整个独立人口—驱动生成链已正确。
