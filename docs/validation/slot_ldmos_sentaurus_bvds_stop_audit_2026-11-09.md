# Sentaurus SLOT BVDS逐工作点停止原因审计，2026-11-09

## 范围与结论

本次只读审计VM中2026-10-14完成的U-2022.12完整BVDS参考轨迹；没有启动新求解。
该历史运行不能自动代表当前Vela配置，也不替代2026-11-09原参数零偏压采集。
脚本启用ExtendedPrecision、Digits=5、RHSmin=1e-10、ErrRef(Electron/Hole)=1e10，
单线程ParDiSo，最大耦合更新25次，外电阻1e12 Ω·µm，drain供电目标2e5 V。
运行日志明确报告80 bit (long double)，不仅依据脚本声明判断精度。
日志指纹SHA256：`2bd3aba1b2ab8fff14ff870053f721f99ae7ffcd747b4331816b55ac8b3f3b43`。原始日志及完整结构化审计留VM。

共75次内层求解尝试：63次error<1成功（含2次冷初始化、1次QS零点、60次非零点），
8次因RHS增长超过1e10倍失败，4次因25次更新上限失败。
63次成功的末步RHS均大于1e-10，范围5.19e-8至1.61；日志error范围1.84e-12至0.929。
因此这条轨迹实际使用更新误差分支停止，而非RHS与更新误差同时满足。
60个非零接受点使用3至21次更新，其中34点使用4次。成功末步factor均为1，
此项只描述日志步长，不证明不存在其他保护。

全扫描最终因drain电流1.0320e-7超过BreakCriteria的1e-7而结束。
最后接触表外电源约1.032e5 V，器件漏压约38.52 V；没有到达2e5 V供电目标。
末态表为日志打印精度，不能据其反推微伏级负载线误差；默认输出电流也不能
未经身份核查便代替外电路实际组装电流。

## 能得出的结论与限制

日志中的error是原生归一化更新误差，不能直接等同于Vela的SLOT U或载流子逐行通量比。
RHS仍使用原生内部尺度，也不能直接套用Vela物理残差阈值。
本次证明实际停止分支，不证明所有局部行、分载流子电流或负载线误差达到了Vela附加检查。
