## 逐单元与接触支持集审计

对原 Vela 合格态及原生导入态分别做回退关闭/开启四臂冻结评估。
每臂 145,632 条记录（24,272 单元 × 3 节点 × 2 载流子）。

- 205 个接触邻接 Si 单元与网格接触节点支持集完全对应。
- 回退开启只改变接触邻接支持上的 α 驱动场；其余单元源项逐字符串相同。
- 四臂配对的密度、迁移率与源测度不变，隔离了 α 的场选择作用。
- 接触处为 |E|，其他位置为 |∇φn/p|，场选择最大相对核对误差 4.33e-16。
- 新探针关闭回退时，对先前生产源项导出最大相对差 1.80e-11。

以下为产生率积分乘 q 后的等效电流，单位 A/µm；本配置将原始 `source_integral`
乘 1.602176634e-31。e/h 分列指电离的触发载流子，不能误当作只向该载流子方程加源。

| 冻结输入 / 回退 | 电子触发 qGe | 空穴触发 qGh |
|---|---:|---:|
| Vela / 关 | 9.53734e-13 | 3.13304e-14 |
| Vela / 开 | 1.22300e-7 | 3.24193e-14 |
| 原生导入 / 关 | 1.13919e-12 | 2.51747e-8 |
| 原生导入 / 开 | 1.20442e-7 | 2.04074e-11 |

开启后电子触发源成为主项，空间热点回到源接触附近，与原生的主要特征一致。
但原生显示电离率用共同 Vela 箱体权重重积分为 1.38060e-7 A/µm，
与原生导入态上的 Vela 回退源仍约差 12.7%；原生显示量并非其装配源支持的直接证明。
因此结论是“重要映射差异得到验证”，不是“源项完全一致”。

节点 10848/10849/10850 的 Vela 开回退箱体平均电离率分别为
5.65e27 / 7.62e28 / 3.90e28 cm^-3 s^-1。
10850 是接触节点，应比较 Dirichlet 替换前源项，不能与替换后的零方程项混用。
详见 [support_audit.json](../../build/s06contact/support_audit.json)。
