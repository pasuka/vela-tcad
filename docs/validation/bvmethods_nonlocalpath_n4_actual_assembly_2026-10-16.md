# BVmethods N4：兼容统计、实际装配与逐弱行推进

日期：2026-10-16。**冻结 SRH／Poisson 账本修复已验证；原版兼容固定态候选已接入实际装配，但完整 RHS／逐弱行门仍未通过，N5 未开始。**
承接[差异定位记录](bvmethods_nonlocalpath_n4_rhs_diagnosis_2026-10-16.md)，
[结构化证据](bvmethods_nonlocalpath_n4_actual_assembly_2026-10-16.json)列出五态与资格边界。

## 1. 本轮范围与实际改动

目标保持安装库原版：普通精度、Fermi、OldSlotboom、NonLocalPath、GradQuasiFermi 雪崩、
外接电阻。网格为2600节点、5020个Tri3，其中Si占2152节点、4156单元；300 K。
源接口使用m、m^-3和粒子线积分，TCAD核心使用um、cm^-3；端电流为A/um。
本机Windows UCRT64 Release执行固定态装配，没有设备Newton／QS更新。
HDF5与SuiteSparse依赖在既有构建中可用，固定态探针不选择线性后端。

生产核心只修改诊断契约及观察器：

1. 普通SRH使用实际输运人口，包括显式冻结人口；`sentaurus_default`仍保留独立的量子SRH人口。
   实际残差与连续性分项因此使用同一分支，未替换既有SRH物理公式。
2. 新增具名的冻结人口Poisson观察器，同时保留原四参数观察器的“仅诊断人口映射”语义。
3. 累计每条介电边的绝对贡献，避免将相消后的净介电项当作分母。
4. Poisson观察器复用实际边系数，并按实际装配顺序先缩放端点电势、再相减。
   原先“先相减、再缩放”会在有公共偏置的近零场产生不同舍入。

原版近似统计、独立BGN选择、SRH盒体积、Gamma输运、局部迁移率、逐元素雪崩及负载控制
仍在独立ignored候选中。现有高精度Fermi、材料默认、前端E106和发行包没有变更。
商用原始数据、回调顺序、私有近似系数、二进制符号与连接记录仅保存在
`build-release/bvmethods_nonlocalpath_n4_actual_20261016/`。

## 2. 两条统计契约与SRH支撑

人口与OldSlotboom必须分别选择：人口使用显式原版默认近似；BGN的多数载流子能量修正
独立使用300 K原版默认逆函数，不随人口定义积分开关切换。
交叉控制保留高精度人口／原版BGN组合，电子人口仍有约2.19e-3差异；这不是一个统一的
“精度开关”可以替代的契约。私有对象不会发布新的生产配置值。

接入实际人口求值后，五态最大人口绝对log比低于9.7e-14。
SRH由Si单元的自主Delaunay转移盒面积投影；首点和三态BV与原生SRH的加权L1相对差
低于5.8e-14。零偏极小速率仍保留相消差，不作相同相对精度声明。
冻结连续性账本最大余差低于3e-16；修复舍入顺序后，冻结Poisson账本低于3.1e-16。

严格源入口的128 epsilon身份检查没有放宽：零偏／首点接受，三态BV仍因人口末位差拒绝。
“重建很接近”不能改写为“绑定的源状态已接受”，也没有用重命名状态或经验QF偏移绕过检查。

## 3. 实际Gamma输运、局部迁移率与源取样

候选在实际残差和分项观察器中共同使用有效带边Gamma边电流，并保留QF reference/increment。
局部迁移率自主计算Masetti体相、距离梯度Enhanced Lombardi、部分边界层HFS及盒平均。
借用现有元素几何构造器只生成距离和边界梯度支撑，体相评价没有切换为PhuMob。
雪崩从同态人口／QF重建逐元素SG电流，分别计算电子／空穴贡献，再映射至节点盒。
NonLocalPath双源在全部统计／输运控制中逐值相同。

同一网格的历史HFS回调记录给出4156个单元的代表身份，电子与空穴顺序相同；
代表点均在最大内角处，但150个单元存在并列。比较以下独立控制：

- 三个固定局部顶点：全部保留，不按源误差择优。
- 自主最大角规则：并列时使用明确的首个候选，三态BV雪崩投影相对L1仍约9.5e-4至1.12e-3。
- 已记录回调顺序：只输入几何身份，不输入原生迁移率、电流、力值或源系数；
  旧／当前三角形节点集合与坐标逐项核对。它仍不是全部自主规则，也未完成原版回调重新绑定。

使用已记录顺序及自主物理求值的控制得到：

| 状态 | 电子完整RHS差／Vela绝对项 | 空穴完整RHS差／Vela绝对项 | 雪崩投影相对L1 |
| --- | ---: | ---: | ---: |
| 击穿前 | 3.85e-9 | 2.62e-9 | 1.46e-7 |
| 击穿后 | 4.34e-9 | 2.96e-9 | 1.63e-7 |
| 末态 | 9.96e-9 | 6.63e-9 | 3.60e-7 |

分母是实际Vela绝对装配项，不是已经认证的原生逐弱行分母。
全局接近仍掩盖局部失败：首点空穴2515约21.8%，击穿后电子2156约1.03e-7，
末态空穴2156约1.37e-2，均未满足逐弱行门。

末态空穴2156的差额已进一步拆到**空穴雪崩贡献**；该处电子雪崩贡献为零，
输运与SRH的主要抵消关系已对齐，不能再将整项余差笼统归为导出QF误差。
增加电子／空穴源观察后，实际三类RHS逐值不变。
GradQuasiFermi沿重建电流方向投影的替代控制没有消除该局部差，
反而使三态全局雪崩投影误差增至约0.18%–0.23%；该候选被保留并拒绝晋升。
需要绑定原版实际局部空穴驱动力、源电流和收集支撑后继续区分。

## 4. Poisson常数与独立负载行

2022手册的PMI示例列出真空介电常数8.8542e-14 F/cm。
与现有CODATA常数分开控制后，原先约1.38e-6的介电系数差被解释；
三态BV的原生矩阵介电绝对项／自主几何对照在约5e-11内一致。
五态Poisson RHS差在Vela绝对项尺度下低于1.34e-13。
该常数仅用于私有兼容控制；生产常数未改。
零偏／首点从打印变量重建原生逐边增量仍有相对表示差，不认领全部原生绝对边项资格。

候选增加一个物理负载标量行，使用同一冻结实际残差的无接触行替换反力计算漏电流，
对照**更新前RHS1**电路行，而非更新后PLT电流，也不将11个QF别名行直接求和或除以副本数。
逐元素迁移率接回后，五态负载行差低于7.7e-8 V；此前末态约442 V的差异显著缩小。
但设备接触电势仍冻结，新增标量行没有成为增广Newton系统的独立未知量；
其设备耦合导数、KCL及非线性接受检查不能由此认领通过。
