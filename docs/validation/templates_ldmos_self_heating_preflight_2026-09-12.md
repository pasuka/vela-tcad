# LDMOS 独立自热阶段输入审计

本页是实施前的范围及输入审计，不是自热验收通过报告。
当前 D4/D5 资格均为 300 K 等温；Vela 尚无接入的晶格热方程，
IALMob 耦合实现也明确限定 300 K。

## 已核实输入

来源是原生 `D0-original/IdVd.cmd`、`Siliconc100.par`、实际资格网格，
以及本地 T-2022.03 用户指南。当前状态参见
[验证索引](templates_ldmos_current_status.md)。

| 项目 | 审计结果 |
|---|---|
| 热边界 | `th_lat`，103 个节点、101 条边 |
| 外部温度 | 300 K |
| 表面热阻 | 原值 0.005 cm² K/W = 5e-7 m² K/W |
| 对应换热系数 | 2e6 W/(m² K) |
| 硅热导率 | Formula=0，κ(T)=100/(-0.0393+0.00155T+1.82e-6T²) W/(m K) |
| 硅 κ(300 K) | 约169.64 W/(m K) |
| 硅体积热容 | 1e6(0.31+0.00622T-6.77e-6T²+2.48e-9T³) J/(m³ K) |
| 硅 cL(300 K) | 1.63366e6 J/(m³ K) |
| 氧化层热导率 | T-2022.03-SP2 `sdevice -P:Oxide` 导出，Formula=1，1.4 W/(m K)，温度多项式高阶系数为零 |
| 氧化层体积热容 | 1.67e6 J/(m³ K)，温度多项式高阶系数为零 |
| 热方程选择 | Solve 中加入 Temperature；Physics 未含 Thermodynamic |
| Peltier | 未显式启用，不应擅自增加 |

用户指南 p.248 方程71说明：仅加入 Temperature 时求解默认晶格热方程，
并不自动切换为完整热力学电流/热方程。简单使用 J·E 作为所有热源的替代
也不能直接认领原始 D0 物理等价。具体热源项、复合热、载流子能量项及其
离散方式应逐项映射。表面热阻单位依据用户指南热接触边界说明。

`th_lat` 是热接触，不应加入电学 KCL 端口集合；不能把其节点自动当成
电势 Dirichlet 边界。2D 单位宽度积分必须让体热源、边界热流和电功率使用
同一宽度约定。没有热接触的边界拟采用绝热条件，实施前与原生默认规则核对。

## 待确定的物理范围

原始 D0 同时含电子/空穴量子势声明和源漏空穴接触复合，D4 没有这些项。
因此直接用 D0 电流差解释自热会混入其他模型差异。已向用户提出两个范围：

1. 在合格 D4 经典基线上仅新增自热原生对照，优先隔离热效应。
2. 先补齐 D3/D2/D1 的物理差异，再比较 D0 完整物理。

此选择仍待答复；当前不把任何一个范围视为已批准的最终物理合同。
性能优化、高压闭合及等温差异诊断可以独立继续。

## 实施与验收草案

先实现独立热传导组装器及单位测试，再连接电热耦合。至少覆盖恒温零源、
一维解析温升、Robin 边界、界面热流连续、全域热平衡、SI/TCAD 缩放。
稳态阶段不把体积热容误用为比热，也不据此声称瞬态功能通过。

耦合阶段需要温度相关材料、统计、SRH/Auger、低场/高场及 IALMob 路径，
明确热方程 Jacobian 与电学导数，并先检查冻结 T=300 K 时复现等温资格。
原电学块、逐行及 KCL 门限继续保留；热方程残差需要单独定义单位及尺度。

原生对照先做零功率、一个中等偏压和40 V 热点，再扩展双栅压31个精确点。
保存端电流、峰值温度及坐标、温升剖面、边界热流、全域发热与热平衡。
拟采用归一化热平衡及温升误差作为新门限，但具体数值尚未批准，不能把
已有电流误差门限直接套在温度上，也不能边运行边放宽门限。

原生材料库 Oxide.par 与 `sdevice -P:Oxide` 导出均已取回；后者于
2026-09-12 在虚拟机独立目录 `thermal_parameters_20260912_r1` 生成。
输入哈希及单位换算见
`reference_staging/templates_ldmos_followup_20260911/ialmob_perf_r5/thermal_inputs_r1/manifest.json`。
这些文件是诊断证据，没有覆盖原参考参数或运行自热曲线。

本阶段仍需范围选择及热验收门限定稿。已有热参数、网格及电学输入无需
用户重复提供。
