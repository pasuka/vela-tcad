# BVmethods 自主初值、谷权重及统计值链（2026-10-15）

本轮完成所选 Q2/Q3 初值与谷权重任务：独立候选从人口／DOS 和固定材料参数出发，自行生成
η 初值、谷权重、积分表并执行接受迭代。在独立 VM libm 下，五态 70 个初值和最终 η、
140 次材料积分／导数及更新判据逐位复现；两条固定系数弱行的基准和非零响应均闭合。

完整 RHS 和原始纯 QS 仍未认证。**

## 材料质量到谷权重

当前 VM 的 `sdevice -P:Silicon` 导出与实际材料对象共同确认：

| 谷 | 主质量 | 简并度 | 能量偏移 |
| --- | --- | ---: | ---: |
| 电子 Delta1／2／3 | ml=0.914、mt=0.196，三个方向排列 | 各 2 | 0 |
| 空穴 LH | 0.16、0.16、0.16 | 1 | 0 |
| 空穴 HH | 0.49、0.49、0.49 | 1 | 0 |

十进制材料参数先按 binary64 解析再提升到 binary80；直接把十进制视为无限精度实数会改变
末位。无应变抛物带控制按以下关系独立生成：

```
r_i = R80(g_i × sqrt_R80(R80(R80(m1_i × m2_i) × m3_i)))
S = 按谷顺序逐次 R80 累加 r_i
d_i = R80(r_i / S)
```

归一化对应现有 `RelativeToDOSMass` 设置，积分权重总和保留前序生成值。
结果为三个 R80(1/3)，以及约 0.157248157248157256、0.842751842751842744；五个权重均逐位一致。
补充原生采集覆盖四份电子及两份空穴材料对象，主质量排列、零偏移及实际权重全部绑定，
六份对象共 16 个权重逐位复现。

材料库电子 alpha=0.5 仍保留；本批实际积分的非抛物项为零，候选沿用已确认的抛物带分支。
本轮通过范围不覆盖应变或激活非抛物项后的权重／积分关系。

## 从人口统计独立生成初值

原生当前近似反函数在本样本使用两条分支：低密度为 `log(ρ)` 加四阶密度多项式，高密度为
`sqrt((ρ × A × B)^p − D) − E`。分支边界约 8.462960366222438；固定系数及其原始精度来自
静态指令和常数区核对，未按本批 η、电流或弱行拟合。

实际电子 ρ 约 17.60–17.81，使用高密度分支；空穴约 0.03220–0.03221，使用低密度分支。
候选保留 Horner 顺序、每步 R80 舍入、原 `powl/logl` 输入精度以及随后对谷分区和的修正：

```
η_raw = 原分支近似反函数(ρ)
Z = 逐次 R80 累加 R80(d_i × expl(offset_i))
η_initial = R80(η_raw − logl(Z))
```

即使本批偏移为零，也保留 Z 的实际舍入；不直接把它强制设为 1。
随后从自主初值开始重新执行积分及 Newton 接受迭代，保留前序确认的 limit=5、约 1e-9 的
停止控制、更新后 η 尺度判据和最后一次接受更新。没有以原生中间 η 作为在线迭代输入。
本批未覆盖极稀薄分支或跨初值分支边界的控制；独立程序的诊断输入域显式限制为 0.01≤ρ≤40。

## 自主候选与平台控制

| 检查 | 独立 VM libm | UCRT |
| --- | ---: | ---: |
| 自主积分节点／权重 | 各 240/240 | 各 240/240 |
| 自主材料谷权重 | 5/5 | 5/5 |
| 原始近似初值／材料修正后初值 | 各 70/70 | 各 43/70 |
| 最终接受 η | 70/70 | 51/70 |
| 材料正向值／导数 | 各 140/140 | 85/140、94/140 |
| 停止判据 | 140/140 | 65/140 |
| 接受决定／迭代次数 | 140/140、70/70 | 140/140、70/70 |

表中均为逐位一致计数。VM 候选的全部 140 个评估 η、更新 η 和停止判据也相同；
完整串联复现 240 次 Γ 消费、120 个 a、480 个 Bernoulli 值／导数及 120 个边反向控制。
固定系数弱行相对同顺序原生操作数求和的基准和 e/h 非零响应差均为零。
这些弱行量不作为终端 A/µm 或完整跨求解器 RHS 报告。

UCRT 初值及最终 η 最大绝对差均约 8.67e-19，保持相同接受决定和迭代次数；
其基准电子／空穴弱行相对差仍为 +7.02401e-5／−1.58435e-5，
电子非零弱行响应相对差约 −1.09e-8、空穴为零。完整自主计算同时包含初值、指数和对数等
平台路径差异，不能把这些弱行余差全部归因于单一初值函数。
Windows 路径未据 Linux 控制的通过结果取得基准资格，门限未放宽。
