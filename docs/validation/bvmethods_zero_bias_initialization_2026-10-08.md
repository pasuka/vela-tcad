## 2. 失败原因和最小修复

原脚本先执行 `Coupled(Iterations=100){Poisson}`，再执行完整 Coupled。
前端将两个 initial 语句合并后仅输出 `initialization.mode=poisson_block`；
运行器该模式原本只计算一次 Poisson Newton 更新，100 次 Poisson 预算被丢失。
首步后 Poisson 残差约 280.237，尚未平衡就进入载流子求解。

输出诊断复现与首轮固定 SparseLU 基线的失败迭代、失败原因、残差及线搜索次数逐项相同。
原始 A 完成 1 次 Newton 更新后发生 carrier_invalid，原始步最大量级约 `1.893e83`。
C 的最终原始线性相对残差虽约 `2.38e-14`（Windows）/`6.84e-14`（Ubuntu），
限幅后的线性残差 L2 却约 `1.60e-5`/`1.34e-5`，13 次回退仍不下降。
分量后向误差达到 1，极小的范数后向误差受巨大原始步影响，不能据此断言线性系统条件良好。

先保留原物理完整求解 Poisson 的具名对照，两平台均收敛；随后 20 次预算的耦合 Newton
直接接受平衡态。集成第一版仍使用 Gummel 交接，虽通过低电流闭合预算，但一次 Gummel 更新
扰动了少数载流子：空穴 QF 最大约 0.00420 V、两平台空穴密度最大相对差约 0.3937%。
该版作为对照保留，最终采用保持 Poisson 状态的暖启动 Newton。

最终改动：

1. 前端在合并初始化阶段时保留独立 `poisson_max_iter`（本例 100），并用暖启动 Newton
   接收已收敛的 Poisson 状态；后续 Coupled 预算仍为原来的 20。
2. `DCSweep` 的显式非零初始化预算从 cold state 完成非线性 Poisson，失败即中止，
   不写出可交接的初始化状态；报告预算、迭代和残差，包括失败报告。
3. 既有 JSON deck 的预算默认 0，继续保持一次块更新行为。未改 Newton/Jacobian、材料、
   网格、物理默认或验收门限。七个受影响的前端初始 deck golden 同步保留阶段预算和交接方法。

接口详见[当前配置说明](../config_schema.md)。独立只有 Poisson 的 cold-start 路径、
多个异质 initial 语句的完整逐语句语义不在本轮修复资格内。

## 4. Jacobian 审计与剩余边界

对失败前初始态、失败末态及修复接受态，采用 psi/phin/phip、热点节点 129/1446 与全体
非接触节点方向；扰动为 `1e-4/1e-6/1e-8 V`，比较解析 Jv 和中心有限差分及选定行。
没有用全局大 Poisson 项掩盖小载流子块差异，也没有把接近零的不可分辨信号认证为通过。

同一接受态的只读消融定位了两个边界：

- full 模型下 `phin_hotspot_1e-6 → phip@1560`，解析导数约 `+0.00123877`，
  中心差分约 `-0.00123999`（内部残差/V）；正扰动残差约 `-2.47998e-9`，
  负扰动残差保持约 `-6.28e-22`。关闭雪崩的探针中该交叉导数均为 0。
  这将差异定位到零电流 Eparallel 雪崩分支；其 `max(E·J/|J|,0)` 在零电流处有方向/单侧敏感性。
  因而不能把这里的多节点中心差分直接当作唯一光滑 Jacobian 的证明，尚未修复或认证该分支的
  有偏置线性化。关闭模型只用于固定态诊断，未用于接受运行。
- 空穴热点 Jv 的最大相对差约 0.651%，在去除全部源项后仍存在；消融显示差异在 Poisson 块：
  解析变化约 `9.66e-18`，double 残差差分为 0；空穴输运块自身误差约 `1.97e-31`。
  这符合大量电子电荷掩盖极少量空穴扰动的数值分辨限制，不能据此判定空穴输运导数错误。

这些边界保留在配套 JSON 和源项探针归档。此次确认并修复的是 Poisson 阶段执行不足；
未修改雪崩驱动力/电流截断、Jacobian 平滑或任何物理模型。后续外电阻控制器对照需继续记录
预测方向、实际线性步、源项分支和有偏置方向导数。
