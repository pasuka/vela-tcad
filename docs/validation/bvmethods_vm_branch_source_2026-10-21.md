# BVmethods VM：符号一致的局部分支源导数

本轮按用户请求，在 vela VM 上验证雪崩源的电流符号／分支事件候选。
六次实际装配运行正常退出，结果已取回。指定电子 QF→空穴方向在五态三档均低于
1e-5；完整方向资格仍有未决项，未进入 Newton 接受循环。
归档 SHA256、117 文件清单和冻结账本检查通过，共 178/178 项证据检查。
机器可读数值见[汇总](bvmethods_vm_branch_source_2026-10-21.json)。

## 候选与边界

沿用[上一轮源链证据](bvmethods_vm_qf_source_chain_2026-10-21.md)，对
`G = A alpha(F) |I|` 的非零基态 `I0`，仅在 Jacobian 的扰动求值中使用
`sign(I0) I` 延拓绝对值分支。实际残差继续使用 `|I|`。
因此基态值保持相同，局部导数包含

    dG = A [alpha'(F) |I| dF + alpha(F) sign(I) dI]

源系数、场和收集权重仍随扰动重算；本候选不是全部链式项的解析实现。
扰动跨零时的延拓源可能为负，仅用于当前分支导数，不作为物理源或接受态。
候选只允许 Raw 电流代理；不推广至重建电流等其他配置。

基态恰为零时，保留原绝对值计算并记录零点事件；此处不能由中心差分证明唯一光滑
Jacobian。电流跨零另行记录，QF 场、系数和收集分支仍需用实际响应判断。

## 本轮检查

- 本地 UCRT64/C++20 Catch2：3 个测试、44 项断言通过；覆盖基态值、边反向不变性、
  变化电流与系数的乘积导数、跨零割线反例及零点单侧响应。
- VM 同样通过 3 个测试、44 项断言；同一可执行文件完成首态关闭／开启对照，
  随后开启候选运行其余四态。实际配置为 Release，沿用私有构建的 `-O1 -DNDEBUG`。
- 每态 19 个方向／步长组合：局部 ψ、电子和空穴 QF，远端 ψ 与载流子 QF，
  以及含内压变化的全局方向。记录完整三块 Jv、明确 drain 身份的端口与负载方向。
- 每态复核人口、残差、源分项、端口、掩码及固定资格行账本。不可分辨响应单列，
  不将舍入估计替代通过门限；目标边事件记录不代表全部网格事件已获资格。

共完成 114 个方向／步长样本，其中候选五态 95 个。与前轮各自同态相比，
六次运行各八份状态／账本文件逐字节相同；这是冻结态不变性，不能替代 Newton 过程的
report 无扰动验证。此次没有运行 Newton 迭代或重新求解出新的接受态。

沿用无 BTBT、2600 节点、300 K、Fermi/OldSlotboom、SRH＋雪崩及已有私有支撑控制。
人口按内部 TCAD 单位解释为 cm⁻³，端口为 A/μm，外电阻为 1e7 Ω·μm。
VM 配置确认启用 HDF5 状态归档和 UMFPACK；严格原生 QF reference/increment 身份缺口保留。

## 五态结果

下表列出局部电子 QF 方向 h=1e-9 时的空穴块相对误差。h 作用于缩放主变量，
与 Jacobian 内部以物理势定义的列差分系数不是同一个量；内部列差分仍保留原 1e-7，
没有依赖上一轮的经验 1e-12 系数。

| 0.0100000 | 0.00524437249 | 4.94065e-8 | 1.00410e-7 |
| 0.0235533 | 0.0132947890 | 6.25006e-8 | 5.80156e-7 |
| 0.0419226 | 0.0261074638 | 6.69739e-8 | 5.90682e-7 |

| 0.1005622 | 0.0786636613 | 7.33972e-8 | 2.10986e-6 |

三个细档为 h=1e-9、3e-10、1e-10。首态关闭候选时，h=1e-9 的空穴块相对差为
0.988004824；开启后降至 4.94065e-8。首态节点 229 的 Jv 为 −5.395811234e-11，
实际正／负单侧响应为 −5.395811368e-11／−5.395811367e-11；
1308 对应为 6.616395803e-12 与 6.616397466e-12／6.616397466e-12。
这些数值属于缩放后的方程方向，不能直接解释为端口电流。

主导边 366／4132 在细档保持电流符号；粗档 h=1e-5 跨零，相对差仍为约 0.96～0.99。
后者是局部导数与跨分支割线的差异，不将其强行拟合为一致。
“主导边同分支”不等于所有边同分支：358 为零电流且采集源为零，945 在首三态的
h=1e-9 仍有电子电流跨零，首态电子源约为 1e-287～1e-286（内部源积分）。
这些事件继续保留，不以总量通过为由删除。Jacobian 记录的事件数包含重复装配调用，
不是独立物理边或失败行的数量。

全局耦合方向（含内压）在五态、h=1e-5／1e-6／1e-7 下三块均低于 1e-5，
最大相对差为 9.16241e-7；同组负载方向最大相对差为 4.96989e-11。
负载方向检查不等于增广 Newton 线性求解或接受循环已经完成。
