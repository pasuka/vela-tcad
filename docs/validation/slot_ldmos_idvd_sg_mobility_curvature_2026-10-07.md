# SLOT IdVd 4034/4036 的 SG 与迁移率曲率分解（2026-10-07）

## 1. 结论

在上一批同一父态与固定方向上，两条空穴行的局部通量曲率主要来自 **固定有效迁移率后的 SG 因子**：4034 占约 **98.77%**，4036 占约 **98.15%**。迁移率自身与交叉项合计约 1.23%/1.85%。因此，不能把这两行的有限步长预测失败主要归因于 HFS 迁移率变化；仅滞后迁移率仍会保留绝大部分曲率。

这里的 SG 因子包含 Fermi 人口、势差与广义 SG 通量的全部非迁移率依赖，并非单独的 Bernoulli 函数；迁移率是边上的完整有效 PhuMob/Lombardi/HFS 迁移率，尚未细分到具体子模型。交叉项独立列出，未任意分摊。

15 个冻结探针全部成功，累计子进程 76.78 s；**Newton 接受更新 0、新合格点 0**。未改变物理、门槛或生产账本，未重启扫描。这是两条健康邻行的曲率归因，不是对全部失败行（尤其 4046、5350）的统一解释。

## 3. 分解定义与口径核对

当前通量实现中，边空穴通量对有效迁移率 μ 显式线性。记 `F(x)=μ(x) S(x)`，以探针导出的 `F/μ` 定义 S。几何及装配缩放固定。μ=0 的边在全部三个态下 F 也为 0，贡献显式置 0；未在零迁移率处作除法。

在父态 0 与试探态 ± 之间，恒等分解为：

`F±−F0 = μ0(S±−S0) + S0(μ±−μ0) + (μ±−μ0)(S±−S0)`。

三项分别为 SG 因子变化、迁移率变化、交叉变化。分别对正负试探取偶次差，再按节点的边方向求和：

- `c_SG = Σ sign·μ0(S+ + S− − 2S0)/(2h²s0)`。
- `c_μ = Σ sign·S0(μ+ + μ− − 2μ0)/(2h²s0)`。
- `c_交叉 = Σ sign·[(μ+−μ0)(S+−S0)+(μ−−μ0)(S−−S0)]/(2h²s0)`。
- 三者之和等于 `c_flux = [flux+ + flux− − 2flux0]/(2h²s0)`。

其中 s0 为上一批父态行比尺度，不随试探改变。4034 为 1.84234112954e-11，4036 为 2.30214262114e-12；这些系数是有符号残差响应，不是非负行比，也不直接表示试探资格。

该方法是**同一组真实全物理冻结数据的代数分解**，没有关闭模型后重求另一条路径。局部光滑极限对应 `μ0 S''/2 + S0 μ''/2 + μ' S'`。有限 h 下公式仍是恒等式，但偶次差可能含更高偶次项。

每态的 incident edge flux 按 node0 正、node1 负求和，与上一批独立载流子项探针的行 flux 核对。全部对照的最大差仅为父态尺度的 **8.24e-16**；父态二进制浮点求和与原记录一致。因此没有把另一个装配口径的迁移率拿来解释这些行。

后处理采用 60 位 Decimal 对已输出的 17 位有效数字 CSV 作代数运算，以减小后处理相消误差；**这不是高精度器件求解**，不能恢复原 binary64 评估已丢失的信息。

## 6. 对后续策略的含义与限制

1. **本方向的邻行保护需要处理 SG 的有限幅度非线性。** 仅修正迁移率导数或冻结迁移率，不能消除这里约 98% 的曲率。这个结论不等于 SG 实现错误，也不否定别的低密度失败行可能受迁移率反馈主导。
2. 下一步可在已有连通子域中，对上述四边保留完整非线性 SG 响应构造内层约束，或用实测曲率限制方向；每次试探仍重新评估全物理迁移率、真实载流子行、全局闭合与 ψ，最终门槛不变。固定迁移率只能作为内层近似，不能把其终态当作原方程合格态。
3. 4034/4036 的线性预测是很大分项相消后的微小 Jd；上一批 Jd/s0≈−0.0005，而二阶项系数约 −0.61/−0.48。因此“解析方向导数正确”并不保证有限步长的邻行约束可靠。
4. 尚未把 SG 因子内部的人口指数、Fermi 修正及势差分别分开；未证明新方向、恢复路径或新步长可获接受，也未解决 4046 行尺度变化问题。不得从本批直接恢复长扫描。
