# 默认迁移：5–10 V缩步及线性拒绝检查

日期：2026-11-07。连续0→10 V扫描、失败入口配对、独立质量报告和终态证据核验已完成。以下只对本轮独立候选和冻结合同负责，不授予生产默认或原生判停等价资格。

## 方法与范围

继[0–1 V首次分叉检查](bvmethods_defaults_low1_2026-11-07.md)，复用原独立二进制及已通过30组冻结方向门的最低一次原系统缺陷校正。原坐标/全变量Unit两臂均开启校正；每个新目标从Full起步，仅在实际浓度保护写回后下一轮省略迁移率和AV偏导，RHS与SRH偏导保留。没有启用旧automatic/bootstrap控制器。

两臂从同一零偏冻结耦合起态连续扫到10 V，不强制1 V或5 V端点，保留物理预测及自适应历史；(5,10] V为主分析区间。与上一阶段未经1 V端点裁剪的自然前缀比较，而不是拼接两个不同5 V末态。

2600节点/5020 Tri3，300 K、JD/OldSlotboom、总杂质迁移率、SRH+GradQF AV、BTBT关闭、R=1e7 Ω·μm，U-2022.12兼容常数及匹配材料。全变量Unit为ψ/VT、n/C0、p/C0、Vinner/VT，C0=5.089999999999982e20 cm^-3、VT=0.025851995266484913 V；设备行沿用原Unit归一化，电路电压行除以VT。两坐标入口沿用同一次Unit往返合同。

N20、初步0.01 V、最小10 μV、最大2500 V、增步1.41、失败步长乘0.5；无额外内压限幅。1%正性保护及floor1e-100不变。近似E<1或映射RHS无穷范数<1e-5判停，其他物理质量按既定诊断配置报告。原绝对线性门1e-8、分量后向门1e-10及有限性门保留，不放宽；映射RHS的近根原生等价性仍未取得。

两组单线程PARDISO并行，各进程安全上限43200 s，构建/旧验证不计入。没有重新构建、重跑已完成预检、修改生产核心或新Sentaurus求解。计时包含通常初始化及诊断审计/捕获开销。

## 定位结果与解释边界

本轮5–10 V不是N20耗尽或F已过后的E尾段平台：原坐标唯一失败是6.714290968200222 V的线性门拒绝，消耗3次实际写回；Unit自主路径在该区间无失败。两侧该区间均为67次Newton/实际写回，因此少一个接受点和一次失败不等于总迭代下降。全0–10 V分别为233和234次Newton，也未显示全变量Unit带来一致的工作量减少。

原坐标该次失败前最后接受外压5.8011128492476995 V，下一名义步长0.913178118952523 V。失败后严格减半到0.4565890594762615 V，重试6.257701908723961 V以9轮接受，步长规则实际执行正确。

失稳链可以从已保存状态直接观察：

1. 预测入口已偏离根：F=9.56884，物理负载残差3.14582 V。首次Full更新的rho=1.02147，将F降至1.22650，但保护284个电子和545个空穴。
2. 下一轮实际省略迁移率/AV偏导，内压方向−2.38842 V，rho=−993.649，仍以alpha=1写回，F升到31.6635。这一步的线性缺陷1.12257e-11、分量后向误差9.28720e-17均已过原门，不能把后续发散全归给不精确线性解。
3. 再下一次省略偏导更新给出约+4927.53 V内压方向，保护1419/1549个电子/空穴，试探内压达4931.51 V、F达262868。随后线性绝对缺陷11749.2远超1e-8，未执行第四次写回；这才是本attempt直接终止原因。

上述内压是失败attempt的试探状态，不是已接受物理工作点，也未被写成IV接受点。缩步后使用原接受历史重试。

本事件路径的CSV mode仍标full/configured_full_derivatives，但实际偏导省略由独立Scope实施；以assemblies.omitted及保护事件为准，不能用这个标签断言全部偏导已参与。对照被测UnitKernelNewton的full_step分支，模型质量记录本身是report；旧bootstrap/Full候选审查依赖automaticDerivativeRecovery，而本候选使用Full起步加保护后事件省略、automatic=false。因此这一分支的负rho没有自动转为同态Full重试。本轮只定位和记录，不启用新守卫、不更改接受策略。

把同一个6.71429 V失败入口交给Unit，前三次写回及保护/省略序列同样导致失稳；第四次线性尝试因分量后向误差约1.52999e-5超过1e-10拒绝。两坐标都失败，说明Unit自主路径避开了这个失败入口，不能称“缩放消除了该入口的失稳”。Unit自身较早的2.510535 V失败入口也在两坐标下各一次写回后拒绝；这一组是预先约定的无5–10 V失败时的较早入口对照，不冒称第二个5–10 V样本。

线性门拒绝是直接终止原因；入口、保护后省略与全步策略构成观察到的前置链。这里未隔离预测误差、各个物理导数或“省略”本身的独立因果贡献。5–10 V内，原坐标/Unit的负rho写回分别10/15次，后者仍无失败，亦不能把负rho次数直接当作失败次数或唯一根因。

原物理回代审计拒绝次数为0，表示已返回给该回调的方向通过；在内部线性门先被拒绝的候选没有进入该回调，不能记成“失败方向也已通过”。逐区间没有独立分解次数/逐attempt耗时账本时不补造；上表只报告性能文件实际提供的全进程分解数。
