# BVmethods：同本构诊断态的实时雪崩与 SG 支撑核验

日期：2026-10-10。接续[同人口 QF/接触分解](bvmethods_qf_contact_transport_split_2026-10-10.md)。
输入身份、逐组结果、两平台复验与封存信息见[配套 JSON](bvmethods_consistent_state_sg_source_2026-10-10.json)。

## 1. 结论和边界

已建立包含接触的同本构诊断态，实时重算 Vela 电流、迁移率和雪崩，替代上轮冻结错误源的控制。
有限激励支持原生有效带边的两边 SG 重建，并定位到**接触与绝缘边界交点不能作切向投影**的诊断例外。
编码激励显著减少代表元素歧义，但全局唯一支撑、完整 RHS 和弱空穴行仍未对齐。

生产材料、统计、SG、几何和门限未改。私有本构探针位于忽略的证据目录，不是可发布修复。
仍为 Q2/Q3；原始从零高压纯 QS、Q4 和全部交叉块未验收。

## 2. 配置和执行

- 原 BVmethods 网格：2600 节点、5020 三角形，含 26 个钝角单元；未删除钝角或弱行。

- Vela 现有 Release 核心配置 SparseLU/COLAMD、单线程，构建有 HDF5/UMFPACK；本轮只导出固定态算子，没有新 Vela PDE/QS 轨迹。
- 原生 T-2022.03：Fermi、OldSlotboom、Masetti/Enormal/高场饱和、SRH(DopingDep)、BTBT(E2)、VanOverstraeten(Eparallel)。
  输入为此前 first 更新前 Save。`DensityIntegral(240)` 是明确的诊断统计控制，不替换正式默认或转授旧轨迹资格。

新执行 11 次原生 Load/Plot，退出均为 0。另三组 `-d` 分别为全物理、去雪崩、去 SRH/BTBT，
各允许一次 Coupled 迭代，退出 2 是设置的诊断预算。只取其第一轮更新前 VAR/RHS。
三组主变量逐值相同，debug 人口与 before Plot 相对差小于 `4.7e-15`。

11 个原生 QF/电路别名行不参与共同器件行比较，其闭合仍不合格，不能宣称完整原生矩阵已认证。

## 3. 同本构和接触控制

原生带边、DOS 与有效本征浓度相互闭合，电子/空穴独立反推的带参考差约 `2.1e-15 V`。
私有探针使用原生逐节点 ni/Nc/Nv、原生热电压及 integral 状态 ψ/QF，由装配器实时重建人口与全部源项。

| 全部半导体节点，含接触 | 电子 | 空穴 |
| --- | --- | --- |
| 人口最大相对差 | `3.43e-13` | `2.15e-13` |
| 同人口反算 QF 最大差 | `3.60e-14 V` | `1.26e-14 V` |

激励保持接触 QF，接触导出误差不超过 `3.7e-16 V`。默认统计切到 integral 时，
接触平衡 ψ 重算，最大变化 `0.305010 mV`；自由半导体节点 ψ 不变。
因此不是跨统计“全部 ψ 固定”的控制；两边最终比较使用同一个 integral 状态。

私有 NewtonSolver 对象由显式诊断环境变量控制，正式源码/库不变。
关闭覆盖时 baseline/native_qf 的分项、SG、人口六个文件与前轮封存证据逐字节相同。
私有差异、构建记录、本构输入和 9 次导出日志均入归档。

## 4. 实时雪崩和完整残差

两侧均使用前轮 first 基准的**固定左尺度**；没有将旧人口变换用于新状态 Jacobian。
下表是固定尺度下 RHS 差 L2，不是物理电流、相对误差或新接受门限。

| 与本轮原生 integral 第一轮 RHS 比较 | 电子 | 空穴 |
| --- | --- | --- |
| 前轮反算 QF 基准的雪崩分项差 | `0.0100996` | `0.0122587` |
| 同本构态实时重算的雪崩分项差 | `1.70388e-6` | `3.21040e-6` |
| 同本构态的输运分项差 | `0.0152765` | `1.04243e-5` |
| 同本构态的完整残差差 | `0.0152770` | `1.09085e-5` |
| 原生雪崩项自身范数 | `4.88779e-9` | `7.25706e-9` |

旧冻结源的大差已被排除，剩余雪崩仍远大于原生项，不能宣布源支撑对齐。
SRH/BTBT 等合项差约电子 `1.49e-10`、空穴 `2.92e-10`；完整差以输运为主。
SG 散度、源分项和完整残差在 Vela 内部闭合，相对差小于 `2.6e-17`。
所有弱行保留：固定左尺度后，再按当地人口/Nref 归一化的最坏空穴差仍在节点 152，约 `−4.45376`。
源项相减高于 64 ULP 的电子/空穴行分别为 1077/1201；其余行也保存。64 ULP 只标记可分辨性。

## 5. 有限激励、接触投影和唯一性

在 integral 统计下执行 x/y 50 mV、确定性编码 ±1 mV 的自由节点 QF 激励。
逐单元枚举三个代表顶点，仅按电流向量匹配，场和 α 作为独立闭合检查。保留全部候选，不以 argmin 冒充元素身份。

| 两边 SG，不加 Gg，接触端点修正后 | 电子加权向量误差 | 空穴加权向量误差 |
| --- | --- | --- |
| x 50 mV | `3.36e-13` | `4.83e-13` |
| y 50 mV | `5.94e-13` | `7.16e-13` |
| 编码 +1 mV | `6.88e-14` | `2.92e-13` |
| 编码 −1 mV | `3.92e-14` | `2.57e-13` |

带 Gg 的候选在 y 激励的电子/空穴误差约 `2.37e-4 / 6.17e-6`，编码激励也有可分辨差。
这支持有限激励下原生有效带边 SG 不使用该 secant 因子；不能直接据此改变全局 Fermi 输运默认。

初版两处编码激励未匹配点是 drain 节点 1287、source 节点 2567，均为接触/绝缘交点。
原生保留法向电流，初版诊断却作绝缘投影。仅取消**接触代表顶点**的投影后，
分别匹配单元 571、4683，相对差约 `4.4e-14 / 2.8e-14`。初版失败和修正后的所有候选均保留。

以峰值电流 `1e-8` 作“主要回调”展示分组，全部尾部仍保留。
指纹分辨率为 `1e-8·|J| + 1e-12·J_peak`，只用于候选计数，不是求解门限。

- 编码 +1 mV：电子 1150/1150、空穴 570/570 个主要回调各有一个候选。
- 编码 −1 mV：电子 1169/1177 个唯一，另 8 个有多个候选；空穴 581/581 个唯一。
- y 激励仍有电子 68、空穴 84 个主要回调具多个候选；弱近零电流不能证明唯一性。
- PMI 没有元素 ID，不同激励回调数也不同，不能按序号配对；坐标集合交集不能证明同一次元素回调。

追加局部状态标签后，integral、正/反编码三组全部回调在该顶点的 ψ/n/p/QF 与导出值逐值相同。
两处旧异常不是该顶点状态错配；标签仍不暴露邻点状态和元素 ID。全局唯一 SG 支撑尚未认证。
