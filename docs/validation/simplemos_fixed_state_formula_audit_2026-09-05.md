# SimpleMOS 四工作点固定状态公式、离散与 BJT 电流恢复对照

2026-09-05，`codex/simplemos-sdevice-validation`。

**已完成用户要求的 n19/n23 × 两个 Vd 四工作点对照。未找到可据此修改正式端口电流算法的候选，高 NWell 的 Id–Vg 差异仍未解决。** 本轮结果支持继续定位自洽状态的形成过程；SRH 局部公式、空间电荷代数公式和端口边通量汇总没有表现出足以解释现有电流差的异常。

执行了 36 次只读生产代码探针：4 次固定状态 SRH，以及 8 个状态各一次端口电流、SG 边通量、迁移率和 VTK 导出。没有新增非线性求解、Sentaurus 任务或曲线扫描，没有修改生产物理、求解器、端口算法或默认绘图算法。分析脚本再次运行时复用相同配置的探针输出，未重复执行求解。

## 1. 输入与比较定义

| 器件 | 体掺杂标签 | Vd (V) | Vg (V) |
|---|---|---:|---:|
| n19 | 低 NWell | 0.05 | 0.90 |
| n19 | 低 NWell | 1.00 | 0.80 |
| n23 | 高 NWell | 0.05 | 0.90 |
| n23 | 高 NWell | 1.00 | 0.80 |

采用 M65 matched-ni/no-BGN 基线、M69 的原始 Sentaurus 场和 M80b 的一致映射状态。这些是诊断分支，不能直接替代有 BGN 的生产分支结论。执行前核验上游证据，冻结 388 个输入文件哈希。Sentaurus 与 Vela 节点坐标按 1e-10 um 门槛核对，按节点 ID 比较，不插值。

- `baseline`：原始 M65 restart CSV，保留准费米参考与增量。
- `sentaurus`：M80b 映射状态，保留 Sentaurus 的电势/准费米势，按 Vela 的 ni/Vt 重建 n/p。这不是原始 n/p。
- 固定状态 SRH：直接使用 Sentaurus 原始 n、p、ni_eff，另设重建浓度和广义公式对照。
- 原始浓度 SG：独立密度形式诊断，明确记录热电压约定和大项相减的精度限制，不作为自洽解。

BJT 的 SRH 探针要求全网格节点，SimpleMOS 导出只在 Si 上提供载流子场。本轮在新目录为非 Si 缺失行提供 n=p=ni=1、势及 SRH=0 的平衡占位值；所有这些行均从分析中排除。原始 Si 行未改变。SRH 主比较只用 Si 三角形的重心体积；signed-Si 和 all-cell 权重单独列账。原探针 JSON 中的全域积分不作为本文主指标。

## 2. 原始物理量代入局部公式

### SRH 与空间电荷

同一组 Si 原始 n/p/ni_eff 代入 Vela 生产复合算子：

| 比较 | 四点最差结果 | 含义 |
|---|---:|---|
| 经典 SRH 与 Sentaurus 节点 SRH，归一化体积加权 L1 | 2.37e-16 | 节点局部公式在舍入精度内一致 |
| 广义 SRH，原始 n/p/ni_eff，同一 L1 | 5.97e-8 | 远低于冻结的 1% 诊断筛选值 |
| QF 重建浓度 + 生产 ni + 广义 SRH，同一 L1 | 1.63e-7 | 状态常数差产生的 SRH 变化很小 |
| matched-ni 与原始 ni_eff 的最大对数差 | 0 dex | 本轮四点原始 ni_eff 与诊断材料一致 |
| QF 重建浓度与原始浓度的最大差 | 2.284e-6 dex | 必须保留这种状态约定差，不能宣称完全相同 |
| `p-n+ND-NA` 与导出 SpaceCharge 的相对 L2 | 1.90e-14 | 本导出字段为净数密度，代数关系闭合 |

Si 重心体积下的 Sentaurus SRH 净积分约为 -7.41e-18 至 -9.14e-17 A/um。积分采用明确的 q × rate(cm^-3 s^-1) × area(um²) × 1e-12 换算，负号表示本算例净产生。相同节点场配相同体积的一致性，不证明 Sentaurus 内部源项体积离散与 Vela 相同。

证据：`fixed_state_formula_audit/srh.csv`、`identities.csv`。完整 Si 节点账本保存在忽略的本轮 build 目录。

### SG、迁移率及端口汇总

8 个基线/映射状态上，将生产 SG 的电子与空穴边通量按接触节点方向求和，复现漏端电流的最大相对误差为 **2.22e-16**。物理粒子线通量转 A/um 使用 q×1e-6，符号直接遵循生产 ContactCurrent 与连续性通量定义，没有拟合符号或比例。

活跃电子边（相对该状态峰值 1e-6）上，生产通量与已有高精度参考的最差相对 L2 为 **1.14e-8**。生产迁移率限制器的独立代数重建误差最大 **2.23e-16**。这些是 Vela 内部一致性检查，不是原生 Sentaurus 边迁移率/边通量的等价性证明，也不保证每条极弱边都具有同样精度。

使用导出节点迁移率的端点算术平均，替换相同固定状态的电子边迁移率，漏电流变化仅 **-0.0174% 至 -0.0179%**；只替换空穴迁移率的变化在舍入尺度。此操作是明确的节点到边代理实验，不是恢复了 Sentaurus 的内部边平均规则，且替换后的状态没有重新求解，不能直接采用为修正。

证据：`terminals.csv`、`mobility.csv`、`substitutions.csv`。每条边的浓度、势、几何权重、Bernoulli 分解和迁移率保存在本轮 build 目录。

## 3. 直接代入原始浓度时发现的混用问题

原始 n/p 与 Vela 的 Vt 差别很小，但漂移/扩散大项相减会放大不一致：

| 器件 / Vd | 原始 n + Vela Vt 相对映射电流变化 | 原始 n + 已核验源 Vt 的变化 |
|---|---:|---:|
| n19 / 0.05 | -0.01468% | +0.000424% |
| n19 / 1.00 | -0.009766% | +0.000422% |
| n23 / 0.05 | -1.8794% | +0.000793% |
| n23 / 1.00 | -3.5768% | -0.000879% |

补充对照执行前单独冻结了 `thermal_control_contract.json`，使用 M80b 已由源状态关系反推并核验的 Vt≈0.02585199526648491 V；只改变独立密度形式计算中的 Vt，保持几何和 Vela 迁移率。没有修改材料或求解器常数，没有以 Id 拟合 Vt。

混用时 n23 的 KCL/Id 达到约 3.83% 和 7.42%，因此不能把电流表面改善解释为修正有效。源 Vt 对照把电流变化降到 8.80e-6 相对量以内，支持上述百分比变化主要来自热力学约定混用。剩余变化包含常数差与原始双精度浓度大项相减的敏感性，不能据此归因生产常数错误。作为精度控制，即使使用一致重建浓度，直接密度形式相对稳定 QF 路径也有最大 1.13e-6 的漏电流差。

证据：`substitutions.csv`、`thermal_control.csv`。此处只对电子密度形式做替换；空穴通量保持原样，没有把这一实验描述为全 DD 热电压干预。

## 4. BJT 式先单元、后节点电流恢复

在同一状态、同一 SG 通量上，同时导出原直接恢复和 cell-first 恢复。掩膜固定为 Sentaurus 对应载流子电流峰值的 1e-6，只使用 Si 节点；候选零值不会从对数误差统计中被悄悄删除。

四点 × 两种状态 × 两种载流子，共 **16 组 A/B，P95 幅值误差全部改善**。但电子矢量相对 L2 在 **8/8 组均变差**，空穴则在 8/8 组改善。

下面仅列 Sentaurus 一致映射状态上的电子结果：

| 器件 / Vd | P95 幅值误差：直接 → cell-first (dex) | 矢量相对 L2：直接 → cell-first |
|---|---:|---:|
| n19 / 0.05 | 0.9994 → 0.1835 | 0.0541 → 0.1640 |
| n19 / 1.00 | 1.0329 → 0.1785 | 0.0565 → 0.1562 |
| n23 / 0.05 | 1.4526 → 0.1667 | 0.0552 → 0.1690 |
| n23 / 1.00 | 1.3003 → 0.1650 | 0.0546 → 0.1653 |

P95 对较弱节点也敏感，矢量 L2 更受大电流区域影响，二者的取舍必须一起保留。不能只引用 P95 改善就替换全局默认。此开关只输出额外 VTK 向量，不改变状态、连续性装配、SG 边通量或端口电流；因此也没有修复 Id–Vg 的效果。

证据：`vectors.csv`，32 行方法结果、16 组 A/B。

## 5. 对当前 Id 差异及空间定位的约束

复用并核验 M80b 完整 DD 伴随账本，限制在本轮四点；这是既有线性归因的整理，没有冒充新求解。精确分解为：

`I_V(u_V)-I_S(u_S) = [I_V(u_V)-I_V(mapped u_S)] + [I_V(mapped u_S)-I_S(u_S)]`。

| 器件 / Vd | 状态项占总电流差 | 映射目标项占总差 | 映射目标项相对 Sentaurus Id |
|---|---:|---:|---:|
| n19 / 0.05 | 97.26% | 2.74% | 0.1326% |
| n19 / 1.00 | 96.79% | 3.21% | 0.1327% |
| n23 / 0.05 | 99.08% | 0.92% | 0.1318% |
| n23 / 1.00 | 98.91% | 1.09% | 0.1335% |

在这四个选定点，electron_transport 是最大的单独伴随分项；0.05 um 深度分区内，沟道贡献为正，体区为负，高 Vd 漏侧也为负。高 n23 的沟道电子项分别为 +2.099e-9、+1.345e-9 A/um，漏侧为 +1.573e-10、-3.118e-10 A/um。这再次说明不能把沟道局部响应直接当作端口净变化，需要保留高 Vd 的抵消反例。

这些项是 **Vela 算子对两个不同状态的反应**；电子输运项大仍不等于 SG 输运公式有错。Poisson 介电/电荷离散改变也可能通过状态改变，引起大的电子输运反应。本轮局部电荷公式闭合，未排除界面控制体、介电权重和边界状态形成的影响。

证据：`dd_case_ledger.csv`、`dd_component_ledger.csv`、`dd_spatial_ledger.csv`。
