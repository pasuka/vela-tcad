# SLOT 电位参考与续算工具交付（2026-09-24）

已实现固定、显式参考原点的候选转换与串行续算入口。本轮范围是工具及必要
验证，没有启动 3.125→5/10 V 扫描，也没有改变 10 V 原参考系复验失败的结论。

## 实现

- `scripts/slot_reference_frame.py`：同步变换电势、分离 QF、接触电压及原点，
  保留微小 QF 增量余项；非输运接触辅助方程跟随目标端电压，内部非输运 QF
  保持零；父状态不改写、目标不覆盖、转换输出始终未验收。
- `scripts/run_slot_ldmos_reference_frame.py`：参数采用物理漏极电压，输出同时
  记录求解器电压、物理漏极电压及 Vds；物理资源和工具哈希可追溯。仅准备
  不宣称完成；`--run` 调用既有完整 Newton 驱动，不增加旁路接受条件。
- 可选前一锚点支持显式不同来源原点。先复验前一锚点，再在相同目标参考系
  复验当前锚点，成功后才预测并推进；前一锚点失败即停止。原点不随电压自动变更。
- 拒绝不完整偏压来源、错网格/原点、非有限值、非输运节点非零密度和未覆盖的
  接触/材料/外电路配置。旧无偏压元数据的迁移态不会根据文件名获得推断资格。
- 新回归模块加入 CMake 的既有 `slot_ldmos_noavalanche_continuation` 测试入口。
  另保留前轮残差探针文档 `.csv`→`.h5` 的说明修正。

完整命令、参考系语义和恢复方法见 [状态接口文档](../state_archive.md#explicit-slot-reference-frame-continuation)。

## 后续限制

这实现了下一阶段可用的固定参考系入口，尚不支持任意材料/接触或外电阻
参考系转换。原来的通用 `state_archive.translate` 行为未改变，SLOT 应使用
本入口处理辅助接触约束。恢复时仍须确认最新有效状态和参考系，使用新目录。
后续可从本地合格 3.125 V 点在选定参考系中推进 5/10 V，继续逐点完整验收。
