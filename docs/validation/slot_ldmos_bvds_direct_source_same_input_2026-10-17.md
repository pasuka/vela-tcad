# SLOT BVDS 6522生产源项与多晶硅同输入算术核查（2026-10-17）

## 结论

已在VM完成冻结态核查，解释了上一批6522约2.23e-36 A/µm的源项余量。
它不是由“整行减输运”凭空产生的估计：实际源项数组、支撑体积乘法及散射写回
均已直接采集并回放。该点源项由SRH主导，体积和寿命不是约794倍差异的来源。

原生密度输入对应的近平衡过剩量，与Vela从QF构造的稳定过剩量不同。
固定原生n、p、ni，将主导SRH的乘减提高到180位后，源项仍约为Vela的787倍；最后一次binary64
乘减只解释其中约0.89%的原生源项。不能仅用“最后一减的抵消误差”解释整个差异。

多晶硅18个边/载流子组合的同输入算术也已完成：13651–13812空穴边的差异主要
保留在操作数的平衡关系中；栅接触附近部分电子边则更受Bernoulli和乘积求差影响。
两类情形不能套用同一个精度解释。

本批未修改生产程序、物理、边界或验收，未启动扫描，新增合格偏压点为0。

原生SRH复用了内部名为`SRHCDLRecombinationEntry<double>`的计算类，条目标识559；
类名不表示本脚本增加了CDL陷阱模型。Auger条目标识665。输入脚本和参数文件身份
保持不变，Physics仍是上述组合。

相反；不是端口总电流，也不是默认PLT电流。

### 缓存证据修正

Auger生产输出和装配输入直接共用数组指针。SRH区域生产缓存与最终装配缓存是
两份不同数组；6522的值逐位相同，零更新采集也重现相同值，但本批没有直接捕获
两者之间的内部复制/聚合调用。因此不声称“SRH生产与装配是同一指针”。
这修正了采集过程中的初步表述；最终归因由实际装配数组、实际分子/商及写回支持。

## 3. 源项差异来自何处

Vela该点的稳定SRH分子采用

\[
 X_V=n_i^2\operatorname{expm1}[(\phi_p-\phi_n)/V_T].
\]

本点电子、空穴人口前因子均等于ni，故上述关系在当前配置成立；不能不加检查地
推广到不同本构或不同前因子的节点。

从实际packed高低位、QF参考和人口前因子独立重建得到：

- QF差约2.01807e-19 V，除以Vt为7.80626e-18。
- 稳定分子约1689.5535 cm^-6；按原生Nref²归一化为7.68813e-18。
- SRH速率约1.6808047e-4 cm^-3 s^-1，Auger约1.64384e-13 cm^-3 s^-1。
- 用独立支撑面积积分得到2.8099909047395744e-39 A/µm，与Vela实际源项相对差
  2.20e-16。没有通过改变源项尺度来对齐。

|对照|源项绝对量 A/µm|相对Vela|
|---|---:|---:|
|原生实际binary64操作数与算术|2.231832e-36|794.249倍|
|固定原生n/p/ni，SRH乘减提高到180位，Auger保留实际值|2.211992e-36|787.188倍|
|Vela当前QF稳定表达|2.809991e-39|1|

固定原生输入精确计算的np−ni²约6.05195e-15，接近其实际6.10623e-15，仍远大于
Vela稳定分子。因此主要差异已经存在于人口/本征浓度与QF表达的平衡关系中。

以同一物理浓度单位比较，原生n、p、ni相对Vela分别约为−3.36806e-14、
+4.03937e-14、+2.87966e-16。它们满足独立核对的恒等式：

\[
 \log\frac{n_Np_N}{n_{i,N}^2}-\frac{\phi_{p,V}-\phi_{n,V}}{V_T}
 =\log\frac{n_N}{n_V}+\log\frac{p_N}{p_V}-2\log\frac{n_{i,N}}{n_{i,V}}.
\]

左侧两个近平衡量分别约6.14493e-15和7.80626e-18。人口自身虽非常接近，微小
过剩量却未保持相同。这与原生密度主变量、Vela QF主变量及导入派生量的表示边界
有关；本批未进一步锁定原生人口生成器内部哪条指令贡献了这些偏差。
不能由此宣布原生物理模型错误，或单凭该极小绝对源项解释BVDS全部不收敛。

原生与Vela的q相差约9.591 ppm，仍按既有口径单列；它不是794倍差异的原因。

## 4. 多晶硅固定原生人口/驱动量的算术对照

覆盖指定多晶硅邻域18个有效边/载流子组合。固定同一组原生binary64人口、SG
自变量及扩散/几何系数，依次比较实际原生运算、固定舍入B的精确乘积、精确B的
180位直接求差，以及等价稳定表达。

对统一方向的无量纲SG表达，有

\[
 n_iB(-a)-n_jB(a)=n_jB(a)\operatorname{expm1}[\log(n_i/n_j)+a].
\]

两种180位表达按左右乘积尺度归一化，最大差1.912e-179；这是独立算术恒等式检查，
不是新增生产内核选项或完整非线性复求。以下使用统一q进行局部边电流对照：

|边/载流子|原生实际 A/µm|同原生输入、180位直接/稳定 A/µm|Vela实际 A/µm|
|---|---:|---:|---:|
|13651–13812空穴|−1.151610e-17|−1.154926e-17|−5.021944e-21|
|12508–12509电子|−1.846922e-19|−6.208892e-21|0|
|12507–12508电子|0|−1.305176e-19|0|

第一条边的平衡对数缺口约−1.69551e-14。同输入提高求差精度后它仍保留，说明
该边不能只靠更换最后的乘减算术达到Vela结果。第二、三条边则显示明显算术抵消
敏感性；原生打印为0也不表示同输入精确SG必为0。

直接用binary64计算`log(n_i/n_j)+a`，还可能把细小缺口舍成0。因此“使用log/expm1”
本身不保证保持微小驱动力，必须核查该组合量从何生成、以何种精度保存。
将人口微调至精确零平衡所需的相对扰动也单列在账本，只是敏感性分析，未输入
生产计算，不能当作材料常数校准或强制零流策略。

## 后续判断

保留Vela稳定源项表达，不为匹配原生极小余量而调整ni、寿命、体积或验收阈值。
下一项应区分“同人口”和“同QF”两种比较：捕获同次原生人口生成的实际电势、
QF/带边及ni输入输出，核对近平衡关系如何在主变量转换与缓存中保存；同时在
有限非零驱动力下比较源项值和一致的导数。6522不应再被列为未解释的散射余量。

多晶硅继续按边分类操作数偏差与求差偏差，不以更接近0或更接近原生打印电流
直接判优。端口比较仍明确区分默认阱积分与DirectCurrent/接触反力。
本批不证明完整Jacobian、Newton路径、长扫描或击穿电压已经一致。
