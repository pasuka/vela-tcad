# 三帧冻结线性方向影响与RHS/Jacobian归因（2026-11-05）

## 结论与范围

完成p01_i01、p01_i02、p02_i03三个已有导出系统的离线线性求解、约束回代与代数归因，实际计算在Vela VM执行。没有应用方向，没有器件Newton、新BV或Sentaurus，也没有修改生产源码、物理、常数、门或默认后端。

主要结果：**首帧公共方向差由Jacobian项主导；下一帧RHS/J项有抵消；近根p02_i03由RHS项主导。** 首帧全块L2方向差很小，但六个少子空穴点可有明显局部原始方向差，不能只凭整体范数下结论。近根参考方向接近零，绝对差小与相对差大同时成立。

这是指定原生导出系统为参考的线性归因，不证明厂商内部机制或后续扫描失败因果。常数/稳定SG末级求值/扩大ULP集合不继续排查；若继续，只沿已经量化的局部AV切线和接触RHS/约束合同寻找新增原生证据。

## 1. 共同坐标、基底与后端

原生冻结数据U-2022.12，Vela为相同兼容profile Full算子，**不是bootstrap**；三帧共有的6843个物理状态分量转换后逐位一致。T-2022.03-SP2全扫描数据不参与本轮归因。

物理未知量psi/Vinner以V、n/p以cm^-3计。原Vela7801维消去958个指定/非活性人口约束，再消去78个指定电势；原生6843维只需消去这78个电势约束，得到同一6765维自由系统。人口、内压列使用既有固定映射；Vela行乘SP=11.7/11.9、SC=125778384.10557051、SL=421026.8101838678，不按本轮结果重拟合。符号均为J*delta=b；负载L=inner+R I−outer，b_load=−L，R=1e7Ω·µm。

双方使用同一SciPy1.18.1 SuperLU（显式splu），COLAMD、diag_pivot_thresh=1、Equil=false；应用相同固定native对角行尺度和共同物理列参考C（abs(state)+VT或1e10 cm^-3）。数值线性修正上限3，未增加器件迭代预算。此后端选择仅用于受控线性诊断，不是生产PARDISO替换资格。

## 2. 代数归因与数值闭合

先用已知解的两套小系统核对符号和分解，再求三帧实际系统。共同缩放基底下deltaV/deltaS/eb/eJ的12次求解均通过沿用既有数值要求的诊断检查：缩放绝对缺陷<=1e-8*max(1,||b||inf)，分量后向误差<=1e-10。该基底不等于生产内部所有缩放，因此不把它写成生产线性门或厂商门认证。
