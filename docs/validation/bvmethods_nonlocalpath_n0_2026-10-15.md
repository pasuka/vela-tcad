原生使用普通精度，原版线性方法为blocked分解；独立小网格以各自日志登记实际线性方法。

原生进程正常结束，65个QS状态及65份器件保存态已取回。

## 控制设计与身份纪律

建立0.12μm×0.02μm的三段Si结构：均匀掺杂`1e15 cm^-3`，或左侧p型／其余n型
`1e18 cm^-3`非均匀结；另有上方氧化层的平面界面结构。三网格尺寸为0.005、0.0025、
0.00125μm。均匀高场种子偏压12V，非均匀结种子1.8V；这些是隔离BTBT的控制，不是原版器件。

通过`sdevice -d`保存完整变量、RHS与Jacobian。参数和导数两臂只在完整变量映射、
数值相同的原生打印首态下比较，不能只绑定两条弱行。变量相同仅证明打印精度身份，
不声称已恢复原生隐藏精度。原版加载末态控制包含6853个打印变量；小网格均匀结构606个。
这些是新模型／加载上下文的实际系统数量，不沿用旧E2诊断的矩阵维数。

本轮发现并纠正以下控制误用，原始失败／不合格记录保留：

- `LineSearchDamping=1e-30`是最小线搜索系数，实际仍接受factor=1的Newton更新。
  一次迭代后的Plot不能作为RHS1首态源；这些运行仅保留首轮变量／RHS／矩阵对照资格。
- `Coupled(Iterations=0)`在本次实际运行中仍执行一次更新，不能按名字认领零更新。
  无更新源控制改用`Load`后直接`Plot`，并单独核对其与实际首态的表示及派生量关系。
- 输入Physics声明400K而Load的是300K保存态时，实际TDR仍为300K。
  那组三个所谓400K试验不具备温度控制资格；必须从零建立真实400K保存态。
- 低场先导不足以分辨源对Jacobian的影响，后续重复控制被具名中止／替代；原版采集正常完成。
  VM Python3.6兼容与提早取回未完成归档的脚本问题已修正，不作为模型失败。

## 参数与导数阶段结果

Apath加倍、Bpath增加、Ppath分支、Rpath、最大路径长度、选区及跨区开关均有独立输入。
在打印首态相同的条件下，均匀高场源关闭使372条RHS记录变化，最大差约0.0295894；
原版加载末态源关闭使1268条RHS记录变化，最大差约9219.32（均为原生打印／缩放单位）。
源关闭不是正式原版基准，只用于分离分项。

普通直接Coupled上下文中，开启NonlocalPath Derivative=1与默认臂的首态／RHS完全相同，
但打印Jacobian未检出变化；小网格三轮Newton控制亦如此。不得因此认定完整数学导数为零。
小网格实际Super矩阵的首轮对照也未发现变化，避免只凭具名块打印下结论。

继续进入QS正偏置步后，606个变量与RHS均在打印精度下相同，开启非局部导数改变
**10768个Jacobian条目**，最大绝对变化约0.0128287（原生缩放单位）。
Strategy=1与默认收集策略Strategy=2的三组变量／RHS／矩阵逐值相同，排除了本次策略切换的混淆。
后续Newton状态开始分离，不能继续把那些矩阵称作同态对照。

| 残差行／状态列 | ψ | n | p |
| --- | ---: | ---: | ---: |
| 电子连续性 | 3146 | 1067 | 1167 |
| 空穴连续性 | 3135 | 1157 | 1096 |

其中10025个变化条目的行列节点不同，尚需按几何邻接单列超一环支撑。
Poisson块无变化。首版导数接口因此必须覆盖ψ、n、p及两载流子交叉块，不能复用E2的ψ-only差分。
初始化矩阵不能代替QS偏置步矩阵；非局部结构／历史收集需随求解上下文登记。
此处确认开关与交叉块真实生效，完整数学导数准确性仍由N5独立同方向有限差分验证。
正QS步的这组导数证据来自独立Si小网格；原版加载终态探针只绑定初始化矩阵。
不能将小网格结果改称原版每个电压步的完整Jacobian资格，后者仍归N5。

### 无更新源及真实温度控制

改用Load后直接Plot，三个300K控制的物理态逐值相同。Apath加倍使全部源积分精确加倍；
将MaxTunnelLength设为`1e-7 cm`（1nm）使源为零，符合路径到达端点前被截断的规则。
不是靠Newton更新后状态的变化推断参数响应。

从零建立400K种子后，导出温度为400K；保存／加载回转出现`400.00000000000006 K`，
仅按四个binary64 ULP识别表示误差，300K绝不能据此通过400K身份检查。
在相同400K物理态下，将Ppath从0.037eV改为0.0185／0.074eV，源积分比值分别为
`1.0459893033702452`／`0.9007866902069033`。
它们与`[1+2Nop(T)]/[1+2Nop(300K)]`的参考归一化一致，采用手册示例的声子常数时约达浮点精度。
300K下A/B派生分支的归一化会掩盖正Ppath的影响，不能据此断言任意正值或任意温度均等效。
Ppath=0的直接分支仅作为原生控制；首版Vela仍不因此认领直接过程。

平面氧化层／Neumann边界、固定斜向、选区与跨区控制已取得非零响应及同态RHS证据。
尚未取得原生逐路径内部坐标，不能宣称每一次镜面反射或接触端点的离散身份已完全复现；
这部分由N2解析几何与逐元素支撑验证继续补齐。

独立按手册式(515)–(516)反算微观参数，分别测试未收缩300K带隙及计入OldSlotboom常数
`dEg0=-0.01595eV`的带隙。后者明显接近原生：非均匀结首态RHS最大差约`3.30e-12`，
前者约`4.18e-8`；均匀结构后者约`1.24e-6`，前者约`1.58e-2`。
这组CODATA2018控制尚未闭合，因而继续核对常数策略与材料参考带隙；不能把运行态密度相关BGN
直接塞进A/B标定带隙，也不能通过经验常数拟合通过。

进一步对照手册pp.1357–1358的公开常数示例，使用显式旧常数集复核转换；
这里声子统计使用`kB=1.380662e-23 J/K`，不能直接借用既有SG诊断的`1.380665e-23`。
同时保留CODATA2018与旧常数两种具名假设、失败差值及输入来源；生产全局常数未改。

最终采用手册公开的`q=1.602192e-19 C`、`h=6.626176e-34 J·s`、
`m0=9.109534e-31 kg`、`kB=1.380662e-23 J/K`，参考带隙为
`1.1082092307692308 eV`（含OldSlotboom常数偏移，不含运行态密度相关收缩）。
独立转换的微观参数与A/B派生分支，在300K均匀场、300K非均匀结、400K均匀场的
**同一无更新物理态**下，全部双源加权L1相对差最大约`3.2644e-10`。
未拟合质量、Cpath比例或经验QF偏移。这个结果限定于本版／本输入模式及这些控制，
不宣称逐位复现或证明所有材料的内置常数都相同；N3仍须验证实际路径积分和完整装配。
后续参数兼容应限定在NonLocalPath派生链，不能据此替换Vela全局CODATA常数或其他物理模型。

## 冻结的验收预算

完整可机读定义见[版本化N0契约](contracts/bvmethods_nonlocalpath_n0.v1.json)。
这些是评价未来Vela候选前固定的**同网格工程一致性目标**，不代表实验测量准确度或跨网格物理误差。
不是根据Vela候选反调门限；本轮尚无Vela NonLocalPath候选。

| 层次 | 冻结门限与含义 |
| --- | --- |
| 解析／光滑积分 | 独立参考相对误差≤1e-8；另做积分阶数／区间细化 |
| 成对事件 | 电子／空穴不平衡除以绝对事件量≤1e-12；零事件不得隐藏非零源 |
| 同态双源 | 积分相对误差≤1e-6；包含全部节点／尾部的盒加权L1≤1e-5 |
| 极小源 | 每载流子绝对事件电流低于1e-40A/μm时双方都需低于该值；保留符号和非零控制 |
| 完整RHS | 各块及每条弱行的差除以绝对装配项和≤1e-8；不得用全局范数掩盖弱行 |
| 完整导数 | 可分辨方向Jv相对误差≤1e-5，至少三个差分步长；拓扑切换单列，不硬套光滑门 |
| 线性方向 | 分量式L1后向误差≤1e-10 |
| 同偏置自洽场量 | 电势最大差≤1mV；所有正Si人口对数比≤ln(1.01)；电场盒加权L1及峰值归一化最大差≤1% |
| 曲线／BV | BV内电压差≤0.5%；逐点漏极电流差≤2%与1e-12A/μm绝对下限；插值误差不得超过其预算的10% |
| 负载／守恒 | 原负载1e-6V、KCL相对1e-5及绝对下限1e-12A/μm、位移比例1e-6、分量相对1e-8均保持 |

源门限高于已测原生舍入／观察器差，但低于粗网格到细网格的变化，因此严格限定为相同冻结网格。
三网格控制的总电子源积分约为`7.87943e-13`、`7.87515e-13`、`7.87132e-13 A/μm`；
它们是网格敏感性证据，不是用来放宽同网格门或证明跨网格收敛阶数。
自洽场量／曲线门是分项严格门之外的工程目标，不可替代源、RHS与导数检查。
BV仍按1e-4A/μm内电压提取、扫描停止1.3e-3A/μm；目前阈值括号约12.5mV，
Q4必须另行验证插值误差或补密采样，不能仅拿括号宽度当作已通过的插值误差。
原生状态未绑定、单位／支撑未明确或参考精度不足时记未取得资格，不使用这些数值强行过门。
