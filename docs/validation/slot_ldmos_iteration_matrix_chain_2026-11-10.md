## 已完成采集与初步结果

原生正常退出，观察器无错误，共捕获19份成对的A、RHS和返回方向：纯Poisson 8份、
耦合11份。受控原生路径通过上述全部目标，包括Vela失败的供电目标。

首三份纯Poisson系统中，调试文本与同次80位后端入口矩阵的相对Frobenius差约
8.6×10^-16～1.4×10^-15，RHS与方向也在文本输出舍入范围内匹配。
Vela与原生各自按行对角元归一后，内区矩阵相对Frobenius差约1.73×10^-12，
RHS相对L2差约1.7×10^-13～1.3×10^-12。此处为固定QF的标量Poisson合同，
不是直接取独立人口耦合矩阵的ψ块。

19份原生系统均完成单线程binary64固定矩阵回放。后期耦合方向与原生80位方向的
整体相对L2差约1.4×10^-4～1.35×10^-3。此实验同时将A和RHS舍入至binary64，
不能将差异全部归为PARDISO实现；弱方向仍须按绝对量及物理响应单列。
分量后向误差为1的行保留其绝对缺陷，并用100位乘积求和复核选定行，不能只凭比值定性。

## 已完成的归因与限制

1. 对有对应NewtonPlot快照的系统，分别做同QF与同人口标签的QF装配回代；
   人口再生成误差单列，不称为精确同操作数。
2. 对全部系统增加当前生产电势—浓度算子回代，人口作为独立权威存储量。
   纯Poisson使用固定QF的人口切向；耦合系统使用独立n/p列。
3. 有7份系统没有对应NewtonPlot初态。只以同次VAR中的ψ/n/p及已核对单位做浓度合同回放，
   明确文本舍入与接触人口来源；同QF比较记为未评估，不借用其他终态冒充。
4. 在独立源码副本中记录Vela每次增广装配的A、RHS、方向、行列尺度及步首状态，
   捕获原先未导出的最终绝对线性精度拒绝入口，已在编译及相关回归通过后完成有限邻域回放。
5. 相同原生脚本完成无观察器配对，逐迭代debug字节一致。

全部11份耦合系统完成了当前生产浓度算子的只装配回代；与8份纯Poisson一起，
覆盖本次19份系统。4份有配套耦合初态TDR的系统另完成同QF和同人口标签对照，
其余7份仅做有文本舍入限制的浓度合同，不宣称已获得原生实际QF缓存。

匹配供电后的电路RHS通过诊断电压行的仿射供电项恢复，并在统一列坐标后按各自对角元归一。
这与直接混用零供电/非零供电RHS不同；但尚未独立认证原生原始电流行的内部单位与归约。
电路Jacobian的主要块相对差约2.5×10^-10，不能据此宣称电路RHS或真实电流已经对齐。

本批尚未完成失败根因闭合。现有结果支持优先检查耦合输运/源项、状态合同及弱方向精度，
不能由纯Poisson接近就认定完整耦合系统已对齐，也不构成放宽线性门或恢复长扫描的依据。

## 失败入口的直接证据

从同一检查点直接进入0.07209765376 V目标，捕获11次增广系统，精确复现此前失败时的
器件电压0.066683649719306473 V、器件残差0.021022544106312598和负载线残差
0.00020853563381693918 V。最终拒绝来自缩放线性绝对缺陷，非分量后向误差门：

| 量 | 数值 |
| --- | --- |
| 最差缩放行 | 25364，电子节点11483，Si |
| 该行未缩放绝对线性缺陷 | 3.96870528886×10^-28（原线性方程单位） |
| 行尺度 | 4.07740375085×10^19 |
| 缩放后缺陷 | 1.61820138308×10^-8 |
| 绝对线性门槛 | 1×10^-8 |
| 该行分量后向误差 | 4.39758371591×10^-17 |
| 全系统最大分量后向误差 | 7.75244476833×10^-16 |

不能把该行绝对数值直接称为A/µm，也不能仅凭线性门超标约62%就认定放宽即可解决。
第一个目标更新的E约122.95，已保护1149个电子、264个空穴分量；此后E扩大至
765441.10才到最终线性拒绝，说明非线性路径在此前已经失稳。

另一个先重解父点的对照捕获10次系统，并在父点重解时失败，说明复读后的再求解路径
与直接推进必须分开，不能用这个对照替代原失败轨迹。

失败目标原生状态的浓度合同下，行对角归一后的块相对Frobenius差为：
电子自身约1.91×10^-5，空穴自身约4.58×10^-6，电子←空穴约8.11×10^-4，
空穴←电子约6.97%。这些相对量仍需同时考虑块的绝对范数、近平衡人口—驱动配对及
文本状态舍入，不能单凭6.97%宣布本构导数错误。初次非零供电更新还出现较大的
自块差异，重点行包括6218、6216、6450；后期重点转到3588、3591、3601、3603。

无观察器原生对照正常退出，与采集运行的完整debug文件逐字节相同。独立诊断构建
的相关回归通过47例、744条断言；只装配分支不写回更新、不接受偏压点。
