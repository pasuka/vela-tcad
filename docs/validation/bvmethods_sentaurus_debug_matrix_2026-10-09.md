## 导出了哪些矩阵

原生文件包括 `debug`（50,500,835 字节）、`super.debug`（20,494,763 字节）、
零偏和两个指定非零点 TDR、完整 `.plt` 与日志。
总共 14 次线性系统：7 次初始 Poisson，1 次初始耦合、1 次 QS 零偏，
10 µV 点 3 次，23.553333 µV 和 24.1 µV 点各 1 次。
`-d` 的输出粒度包括 Newton 迭代，并非每个电压只有一个矩阵。

| 系统 | 维度及变量 |
| --- | --- |
| 原生 Poisson | 2600 个电势变量 |
| 原生 `debug` 耦合标签 | 2600 电势 + 11 接触准费米标签 + 2121 电子密度 + 2121 空穴密度 = 6853 |
| 原生实际 `super.debug` | 2600 电势 + 1 外电阻接触未知量 + 2121 电子密度 + 2121 空穴密度 = **6843** |
| Vela 原始器件装配 | 2600 psi + 2600 phin + 2600 phip = **7800**；外电阻由外层控制器处理 |

原生载流子去掉了 31 个硅接触节点的独立密度未知量；Vela 保留全网格槽位及约束行。
原生 11 个接触标签对应同一个漏极电压，不能把标签计数当成独立未知量数。
标签矩阵中的接触部分不能直接当成线性求解器的最终接触行，简单合并标签也不能完成其变换。

`debug` 提供 VAR、RHS1、JAC、SOL 和更新后 RHS2。
`super.debug` 提供实际送入线性求解器的稀疏矩阵、RHS 和解向量。
已解码后者的一基 MSR 行指针/列索引、对角元、上下三角独立系数；不假定矩阵对称。
实际回代满足 `J * SOL = RHS`。Vela 的 RHS 则显式导出为 `-F`。

14 次原生系统的相对线性后向误差为 **9.33e-17～1.51e-15**，定义为：

`sum(abs(J*SOL-RHS)) / sum(abs(J)*abs(SOL)+abs(RHS))`。

未使用 `max(1, norm)` 地板。该结果证明解析和原生线性解闭合，
不能单独证明非线性收敛门限、离散误差或 Jacobian 与真实残差的方向导数一致。

## 接受态与弱行比较

以下内电压来自原生 `.plt` 与 Vela 前轮接受态；相同外电压并不意味着相同内电压或物理状态。

| 外电压 | 原生内电压 | Vela 内电压 |
| --- | --- | --- |
| 0 | −9.18447e-17 V | 0 V |
| 10 µV | 4.9756084796 µV | 4.4173485962 µV |
| 24.1 µV | 11.9920607183 µV | 10.6458101169 µV |

节点 790 坐标 `(0.03125, 0.15890625) µm`，零偏对照：

| 物理量 | 原生接受态 | Vela 接受态 |
| --- | --- | --- |
| psi | 0.5248910353 V | 0.5352021338 V |
| 电子密度 | 6.3997492132e25 m^-3 | 6.4077198055e25 m^-3 |
| 空穴密度 | 3.1936807900e8 m^-3 | 1.4420569482e8 m^-3 |

在外电压 24.1 µV，节点 790 的 Vela 空穴准费米势为 9.39890 mV，
原生为 8.13541 µV；空穴密度分别为 2.07347e8 和 3.19320e8 m^-3。
这是弱行状态与更新行为仍存在差别的证据，不能只归因于外电压步长。
电势参考、材料统计映射、输运离散和接受策略尚须拆分，不能由此单独认定某条导数公式错误。

原生密度块与 Vela 准费米块的原始对角元不能直接相除。
为观察局部形状，将原生空穴列按链式法则乘以对应密度，得到对 `log(p)` 的灵敏度，
再除以本行对角元；Vela 空穴准费米块也除以其对角元。
节点 790 附近为空穴少数载流子区，`log(p)` 与无量纲 phip 的对应仅用于非简并近似诊断。
零偏四个主要邻居的归一化值：

| 列节点 | 原生 log(p) 行 | Vela phip 行 |
| --- | --- | --- |
| 786 | −0.0397226 | −0.0312565 |
| 789 | −0.497101 | −0.595424 |
| 802 | −0.363225 | −0.262580 |
| 821 | −0.0959994 | −0.106767 |

包含所有列后，相对 L1 形状差分别为 **10.93%、8.58%、8.24%**（零偏/首点/末点）。
这些数值使用原生最后一次更新前矩阵与 Vela 接受态矩阵，
**不是同一物理状态的全 Fermi Jacobian 误差，也不作为合格门限**。
完整变换仍需载流子统计导数、接触消元、行缩放、全部交叉块和匹配状态；没有宣称逐项认证完成。

## 新线索：原生负密度更新的实际处理

对每个自由载流子节点比较 `VAR + SOL` 与最终 TDR，得到可重复的观测关系：

```text
若 old_density + SOL > 0：保存 old_density + SOL
否则：保存 0.01 * old_density
```

零偏没有触发；首个非零点最后一次更新有 **5** 个空穴节点触发；末点有 **28** 个。
全部保存密度仍为正，负更新节点的保存值/旧值为 0.01。
按该关系重建全部 2121 个空穴节点，最大相对偏差分别约
4.89e-15、4.85e-12、1.24e-14。
正但小于旧值 1% 的更新仍可保留，因此不能误写为统一 `max(new, 0.01*old)` 地板。

这是原始调试量与 TDR 支持的**更新行为推断**，没有访问或断言 Sentaurus 私有实现。
它说明原生密度变量也会出现使密度变负的 Newton 方向，随后进行局部修正；
线性解准确和非线性更新可接受是两个不同环节。
后续可据此构造 Vela 的密度空间更新对照，再用原严格 PDE/连续性/负载/KCL 门限检查。
本轮没有把此观测直接移植为默认策略，也没有宣布原始纯 QS 修复。
