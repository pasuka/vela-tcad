## 实际 E2 链式项

解析项使用模型的 `generationRateDerivativeField`，与同一几何 dE/dψ 组合，经实际装配的
单位/行缩放和接触约束进入 Jacobian。源隔离控制只保留实际 E2 残差及其链式项，避免用
两个较大的完整矩阵相减认证微小源导数；关闭 E2 时隔离残差严格为零。

| ψ 扰动幅度 V | 实际解析 Jv 与同方向中心差分的相对差 |
| --- | ---: |
| 1e-4 | 2.76e-3 |
| 2.5e-5 | 1.73e-4 |
| 2.5e-6 | 1.73e-6 |
| 6.25e-7 | 1.08e-7 |
| 1.5625e-7 | 6.81e-9 |

缩步呈二阶；冻结场导数对照缺失该项，相对差为 1。完整矩阵相减与隔离解析项仍差约
1.81e-5，故只据可分辨的隔离结果认证本 E2 链式项，不扩大为完整 Jacobian 通过。

## 弱行与固定操作数精度

七个对应态分别运行原 SG 和 100 位十进制 SG，共 14 次实际探针；所有输入 H5 的接触
reference/increment、物理 QF 和 ψ 保持逐位相同，全局 reference 也保持不变。
100 位控制只提升当前内核求值精度，不能恢复输入或原生内部状态已经丢失的位数。

| 基准弱行 | 电子 2156 | 空穴 2515 |
| --- | ---: | ---: |
| 原生减实际输运 | -9.71202e-15 | 1.06616e-16 |
| 提升 SG 内核精度后的值变化 | -2.07e-25 | -4.80e-28 |
| 六条边求和的浮点舍入量级界 | 4.24e-24 | 3.19e-28 |
| ±1e-12 V 同方向斜率与原生相对差 | 1.70e-8 | 2.26e-8 |

这排除了当前固定输入下 SG 内核求值/行求和是该大余差的主要来源，不能排除输入表示、
原生内部人口/QF/统计回算路径或尚未识别的值本构差。原生零驱动仍有小余值，未扣经验偏置。

电子归零的原生旧控制同时改了漏极接触，而本轮 Vela 按要求保留接触，漏极 QF 差约
4.98e-6 V；该臂整体向量比较失败，不具有整体验收资格，仅作 2156 源极邻域的局部诊断。
该邻域导出接触 QF 还有约 8.97e-20 V 的噪声，不能声称无损内部态一致。
完整失败数值保留在本地摘要，未混入整体通过结论。
