# SLOT 固定矩阵的高精度方向参考

日期：2026-10-11。此批针对同次内存装配捕获的第二个 Newton 系统，检验
double/long-double 原始方向的实际误差。固定矩阵、RHS、模型和门槛，不装配新物理
状态、不接受 Newton 更新、不进行非线性续算。新增合格点 0。

## 结论与适用范围

113 位和 160 位二进制尾数计算、各两轮残差精化，以及独立的 75 位十进制残差复核，
共同给出稳定的数值参考。A 系统的 10280 空穴方向约 **−0.0685226696725 V**：
原 double 方向为正，与参考异号；long double 同号且明显更接近参考，仍不是精确值。
结论限于已捕获、含原正则化和闭合替换的线性系统，不能外推为整个非线性器件已收敛。

## 身份、精度和方法

沿用[同次内存捕获报告](slot_ldmos_in_memory_direction_capture_2026-10-11.md)的
Vg=5 V、Vd=0.005 V、300 K、原点 0 V、SLOT 13,881 节点、41,643 维系统。
A_on/B_on 分别来自 double/long-double 原轨迹的第二次装配，二者是不同父态；
只在各自固定系统内部比较后端误差，不把 A 与 B 的差值当成单纯精度误差。

输入为 `build/s11memory_capture/{A_on,B_on}/progress/linear_2/` 中的
`regularized.bin`、`closure_system.bin` 与 `assembled.csv`。矩阵系数由 binary64
无损读入；RHS 的 17 位十进制先还原 binary64 再精确提升，避免把文本小数当作
一个新 RHS。输入与代码 SHA-256 见 `build/s11highprec/contract_v2.json`。

令 A 为正则化基础矩阵，S 为捕获的闭合替换矩阵，b 为捕获的实际 RHS。
在高精度中构造 `S=A+U Vᵀ`，U 只选择两条替换行（索引 13881、27762），
V 从已提升精度的 S、A 相减得到。通过

`y=A⁻¹b; Z=A⁻¹U; x=y−Z(I+VᵀZ)⁻¹Vᵀy`

求解 Sx=b。基础分解、三角回代、小矩阵和组合全部使用相同高精度；再以 S 的
完整稀疏乘积重算 r=b−Sx，解 Sδ=r 并更新 x，两轮精化。实现是独立离线程序，
使用 UCRT64 g++、Eigen SparseLU/COLAMD 与 Boost.Multiprecision `cpp_bin_float`。
113/160 指有效二进制尾数位数，不是十进制位数，也不是 Vela 生产标量类型变更。

原 64/80 对照向量直接复用上一批同矩阵重放证据。原 80 后端仍会将解回写 double，
Woodbury 组合也为 double，因此下表比较的是实际已有路径与高精度参考，不能称为
仅改变一个浮点标量、其余每项运算均完全相同的性能对照。

*该列仅排除已由矩阵和 RHS 精确识别的 `x_i=0` 单位行，绝不排除一般弱物理行。
这些严格零行的参考解会有极微小绝对误差，其分量比仍可能为 1。完整指标、被单列
行数及最大绝对缺陷全部保存在 `audit.json`、`residual_check.json`，没有修改方程。
线性后向指标与生产载流子行比不是同一判据。

B 的原 long-double 向量在非单位行中仍有一个比值 1：空穴节点 12511 的绝对缺陷
和分母均约 1.36×10⁻⁴⁰。该项保持在统计中，单列绝对尺度，不把它与 10280 的
有显著方向误差情形混为一谈，也不据此改动验收规则。

A 系统 10280 空穴线性方程上，double 的分量后向指标约 0.324，而 long double
约 1.09×10⁻⁴。先前极小的全局范数后向指标掩盖了这个弱行的实际线性缺陷；
不能仅用它把分叉归结为“残差同样准确、只有前向误差不同”。高精度参考同时改善了
弱行线性残差与方向精度。这里仍不涉及重新装配后的非线性残差。

这是跨精度稳定性与残差支持的数值参考，不是区间算术认证或严格前向误差上界；
没有测得整个系统的条件数。尤其不能因为原低精度全局后向误差小，就断言每一个
弱方向都准确。本次直接比较已显示反例。
