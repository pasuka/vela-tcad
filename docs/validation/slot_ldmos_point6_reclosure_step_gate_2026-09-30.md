# SLOT 第6点重闭合与增步质量检查（2026-09-30）

## 结论

已完成较松独立态的有界重闭合，以及同父态 8/10 mV 外压试验。
原电流复现差经一次载流子修正及完整器件复验消除。两个试验点均通过最终
资格，但 10 mV 点的空穴行比超过增步质量线，因此没有执行计划中的
12.5/15/20 mV 档位，也没有启动扩大上限后的连续扫描。
这属于质量保护停止，不是器件不收敛或击穿判据达成。

## 配置和执行边界

- T470p 主机名无法解析，最近地址连接超时；沿用已授权的本机串行方式。
  使用现有 Release，单重负载；未修改 C++、生产驱动、物理配置或最终门槛。
- 300 K，其他端口物理电压均为 0 V；R=1e12 Ω·µm，数值参考原点 36 V。
  13,881 节点、27,275 三角形；IALMob、自洽 QF 梯度雪崩、外心体积、
  原生输运耦合受控配置；HDF5 状态、原 UMFPACK 后端，未启用全程序扩展精度。
  原生几何依赖仍存在。
- 冻结沿用 `build/s30matched/driver/` 的已验证脚本，保存文件及运行器 SHA-256。
  新目录 `build/s30rc6/`、`build/s30expand2/`；旧证据及生产账本保持不变。
- 原门槛：abstol 1e-9、reltol 1e-8、全部有效行比 1e-3、全局闭合 0.01、
  负载线 1e-6 V。增步质量另要求候选误差/闭合 ≤0.005、行比 ≤0.0009。
- 同外压反馈、外推、进展守卫、候选守恒、严格再闭合均开启；内压接受上限
  0.1 V、试探上限 0.05 V、实际电流增长上限 25%、外推比率 1.6 不变。
- 为使 CLI 可以检验超过 10 mV 的初始提议，试验静态外压下限参数设为
  0.02 V；实际接受上限为 max(0.02 V, 0.25 R|I_parent|)=约0.089335 V，
  与此前 0.01 V 下限下的有效接受上限完全相同。各试验提议另受自身上限约束。
  每个试验都从相同六点合格历史与空的增长质量历史开始，避免跨试验污染。

## 有界重闭合

检查对象为上批独立第6点，物理内压 38.48887036519928 V。
普通同偏压重启执行零次 Newton 更新，电流差不变。随后只进行一次现有
carrier-only 修正，恢复多晶硅平衡并通过完整器件资格及负载线确认。
修正后的完整验证和额外同偏压重启均无需 Newton 更新；不能写成额外执行了
一次完整 Newton 更新。此诊断态不作为增步试验的新父态。

| 指标 | 原独立态/普通重启 | 修正并完整复验后 |

| 最差载流子行比 | 9.990317e-4 | 1.902632e-4 |
| 电子全局闭合比 | 7.491357e-5 | 1.206428e-14 |
| 空穴全局闭合比 | 2.556221e-11 | 5.227856e-15 |

本点结果支持原差异来自可进一步消除的剩余收敛误差，不构成通用误差界。
重闭合共耗时74.05秒。

## 同父态增步试验

共同父态：内压38.48887036519928 V、外压38.84620991180742 V、
Id=3.573395466081372e-13 A/µm。两点分别从该父态出发，不能拼成两步连续路径。

| 指标 | 8 mV 提议 | 10 mV 提议 |
| --- | ---: | ---: |
| 候选电流相对严格态差 / % | −0.325596 | −0.423628 |
| 候选电子闭合比 | 0.00325620 | 0.00423679 |
| 严格最差行比 | 0.000376942 | 0.000989201 |
| 严格最差行 | 电子3603 | 空穴3595 |
| 严格电子全局闭合比 | 1.16390e-12 | 3.50178e-8 |
| 实际电流增长 / % | 2.46156 | 3.09633 |
| 物理内压 / V | 38.4892673706 | 38.4893666218 |
| 物理外压 / V | 38.8554030276 | 38.8577705751 |
| Id / A·µm⁻¹ | 3.6613565699e-13 | 3.6840395329e-13 |
| 接受步骤耗时 / s | 48.10 | 49.58 |
| 完整最终资格 | 通过 | 通过 |
| 增步质量 | 通过 | 行比超出0.0009，停止升档 |

本批10 mV点的限制来自空穴节点3595，坐标约(0.00820661, 4.424355469) µm；
此前常见的电子节点3603仍存在，但本点电子最大行比仅0.000650443。
不应将两个载流子/节点混为同一阻塞。

两次 CLI 均因预设单次尝试数量用尽而结束，外层 worker 正常退出，含父态与
结果审计共159.69秒。无整步数值失败、候选恢复或门槛放宽。
8 mV是本批满足增步质量的最大实测提议，不是证明的安全上限；10 mV仍可得到
合格态。本轮不据此修改生产上限。

## 独立同内压复算与下一步

从共同原父态独立求解10 mV试验的目标内压，4次Newton更新后通过完整资格及
负载线确认，耗时43.00秒。路径解/独立解−1为−3.29000e-8（−0.00000329%）；
Si电势最大差7.10543e-15 V，总雪崩源相对差−3.32538e-11。
独立解电子闭合比2.13666e-9，最差电子行比0.000910471、节点3603；
空穴最差行比0.000357868、节点3595。它也通过最终资格，但略超增步质量线。

建议下一步只对上述两个节点做有界的停止精度/局部修正成本对照，量化是否能以
少量额外更新稳定留出行比余量，再重试12.5 mV。当前没有证据要求更改物理模型、
增加程序精度或放宽验收条件，也尚不能将10 mV质量问题归因于浮点底限。
