# SLOT LDMOS 验证日报素材（2026-09-27）

整理日期：2026-09-28。以下区分实际仿真、工具验证与离线分析；本次整理未启动求解器。

## 可直接用于日报的正文

完成 SLOT LDMOS 外电阻扫描的数值失败处理与低压恢复验证，完善基于合格父态的状态外推、成功后自适应增步和失败回退流程。在保持物理模型、完整 Jacobian 及验收门槛不变的条件下，从原合格低压路径恢复至 0.8 V，完成 2 V、3 V 验证，并继续推进至外压 **26.773637 V**、内压 **26.767866 V**，漏极电流 **5.77022×10⁻¹⁵ A/µm**。

开展外推与自适应的计算效率对照：在 1.5→2 V 区间，完整 Newton 更新由 **176 次降至 74 次**，减少约 **58.0%**；新增器件合格点由 20 个降至 10 个，需局部修正的器件点由 15 个降至 4 个。终点电流相对差约 **4.24×10⁻⁸**，表明两条路径终点结果一致。该指标为实际求解工作量，不能直接等同于墙钟时间加速比例。

完成默认关闭的端口步长控制功能，将外压上限、接受态内压增量上限及内部试探步长上限分离，结合局部斜率、电流增长、预测偏差和计算成本限制步长。在 **331 个历史窗口**上比较一次、二次、限幅切线及受约束有理模型；有理模型在 Vela 高压数据上的内压预测误差 P95 从 **14.889 mV 降至 1.374 mV**，原生数据则以限幅切线的 P95 更优。结果支持继续验证“限幅切线＋受约束有理候选”，但尚未证明其能扩大实际可收敛步长或缩短总仿真时间。

扫描于 **21:42** 因 Windows 拒绝替换检查点文件（WinError 5）退出，属于环境/文件访问中断，不能判为器件数值发散或达到击穿。当前新配置从 0 V 至统一击穿电流判据的完整路径尚未完成。

## 存在问题与下一步建议

1. 查清并改善检查点原子替换的文件访问问题；已有有限重试仍未避免末次中断，实际占用者尚未确定。恢复前需核验末态及工具身份。
2. 冻结端口步长策略，用独立前向区间验证较大步长；保留内外压限制、电流增长限制、失败回退和全部验收条件。
3. 接续完成新配置低压至击穿电流判据的全路径，再开展全曲线精度和击穿插值敏感性核对。
4. 当前受控模型仍依赖原生导出的部分输运几何资源，本地几何独立性尚待验证。此前高压支路结果不能代替本轮完整扫描。

## 配置与验收口径

300 K；13881 节点；电子、空穴各 12634 个有效载流子行；源极、栅极、衬底、SLOT 接触为 0 V；外电阻 1e12 Ω·µm。采用当前受控 IALMob、自洽雪崩和几何配置，Windows UCRT64 Release / UMFPACK，串行重负载。

电流单位 A/µm，外压与内压均报告物理电压（含参考系原点）。完整器件、全部有效行、全局闭合、状态绑定及独立负载线确认分别验收；局部行比门槛 1e-3，负载线残差门槛 1e-6 V。电路复用态的零残差不替代器件资格。
