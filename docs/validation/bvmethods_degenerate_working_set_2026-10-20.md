## 退化处理改动

沿上一轮已导出的同一矩阵，把负梯度投影到零点的 285 条活跃不等式形成的切锥：

```text
p = -g - A^T λ
minimize ||A^T λ + g||², λ >= 0
A p <= 0
```

这里 A 的每一行是活跃不等式的单位外法向。全部原不等式继续参与验证，未因线性相关而删除。
采用以下私有修复：

1. 工作集代数使用 Boost.Multiprecision 的 100 位十进制精度规格。
2. 当被动集解出现非正乘子，执行比值检验，选出离开变量并单独将其置零。
3. 不再以“最大乘子 × 固定比例”批量丢弃小乘子；保留真正的小正乘子。
4. 每次交换后继续审计全部法向，分别核对投影的对偶、可行性和互补性；
   原单位筛选及真实装配继续作为独立的失败检查。

本次投影 236 次处理、182 次工作集交换后结束；记录到的最小 Cholesky 主元约 4.00e-49。
小主元解释了普通精度工作集面临的数值困难，但本轮同时改变精度、法向缩放和离开规则，
没有声称已通过单变量消融证明某一项是唯一原因。

| 投影核验 | C++ 高精度记录 | 独立 110 位 Decimal 复算 |
|---|---:|---:|
| 最大切锥违反量 | 3.28e-83 | 3.45e-83 |
| 乘子负值违反量 | 0 | 0 |
| 互补性残量 | 6.95e-67 | 7.48e-67 |
| 目标方向斜率 | −2.04874416e-4 | 同一值 |

独立核对同时验证了投影关系 `g·p = −||p||²`。这些是高精度近似解的数值证据，
不是把非零违反量定义成精确数学零，也不是改变任何物理门限。

## 三臂验证

**端点臂**：沿投影方向，以原正则化二次模型选步，并受全部原线性界限制。
转换成 double 后，电子 835 在线性筛选中超界 1 ULP。

**新边界余量臂**：将端点步乘以 0.99，给首次碰到的新边界留出余量。
原有活跃约束仍可能位于边界，不能将这一步称为全部约束的严格内点。

**活跃约束余量臂**：改为投影到 `A p <= −1e-12`，再受全部原界限制并乘以 0.99。
这里的 1e-12 是单位法向坐标上的实验性内侧余量，不是修改物理门限。
该投影在 495 次处理中结束，投影向量范数约 2.41e8，随后线性界将步缩至约 6.85e-9；
说明统一内侧余量的数值代价很大，不能直接部署为默认算法。

余量臂独立复算的仿射可行性违反量约 7.55e-72，正确的互补性
`λ_i (A_i p + 1e-12)` 约 4.50e-44。其私有原始 `projection.json` 的
`complementarity` 沿用零界的 `λ_i A_i p`，不适用于这个仿射问题；
应读取另存的 `independent_kkt.json`，本报告不将旧字段解释为仿射 KKT。

## 精确操作数审计：double 筛选通过仍不够

对导出的 binary64 操作数使用 Python Fraction 做**精确有理数**运算，没有比较容差。

这些数值低于 double 行比值在 1 附近的分辨率，因此可以同时出现“double 行比值为 1”
和“精确操作数复算略大于 1”。全部失败均保留，不能按末位误差豁免。
三列是在不同已舍入操作数上的检查，不应把不一致简单归为物理算子改变。
当前已定位到高精度投影→double 坐标→子空间映射→主变量请求这条链上的可表示性问题。
这里的 d 是请求方向，仍须另查 `x+d` 的实际写回增量；本轮未证明写回保持全部精确可行性。
