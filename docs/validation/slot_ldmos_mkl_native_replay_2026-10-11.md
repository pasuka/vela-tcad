# SLOT 原生矩阵的 oneMKL PARDISO 重放对照

2026 年 10 月 11 日。工作点 Vg=5 V、Vd=0.005 V，300 K；同一 SLOT 网格
13,881 节点、27,275 三角形。本批使用已保存的 Sentaurus float64 第零次系统，
没有重新运行 Sentaurus，也没有启动连续 Newton 或电压扫描。

**oneMKL PARDISO 已能在本机调用。** 原生矩阵原样输入后，五线程、两次迭代精化
的电势、电子人口、空穴人口方向相对原生 SOL 的块 L2 差分别为
1.95e-12、2.78e-13、2.55e-13。相同人口有限步在 Vela 方程中评估后，
PARDISO 与原生 SOL 的超标行集合完全相同。这证明本冻结系统的线性及首步重放很接近，
不等于完整 Vela Newton 已收敛，也不证明两端所有迭代状态的离散系统完全相同。

## 输入和调用口径

- 原始数据：`build/s10native64/native/double64/matrices/snapshot_0.npz`、
  `vectors_0.npz`，对应原始 `debug`、`idvd.cmd`；输入 SHA-256 已绑定。
- 系统 39,149 × 39,149，608,096 非零元；变量顺序为 13,881 个电势、
  12,634 个电子人口、12,634 个空穴人口。保留原生缩放和边界行。
- 求解 `A x = RHS1`。原生 SOL 的相对残差为 5.918e-14；代入 RHS2 的相对
  缺陷约 39.13。不能把 RHS2 作为本次实际右端项；两者最大绝对差约 3.336e9。
- 不添加 Vela 正则化、闭合替换、额外缩放或边界消元；不先变换为 QF。
- `C:/Program Files (x86)/Intel/oneAPI/mkl/2026.1/bin/mkl_rt.3.dll`，
  运行时版本 2026.1，Product Build 20260612；LP64、实非对称 `mtype=11`、
  一基 CSR。Python ctypes 仅作独立调用接口，没有新增生产 LinearSolver 后端。
- PARDISO：METIS 排序，缩放与匹配开启，主元扰动参数 13；主臂五线程、
  最大精化两次，实际两次，报告扰动主元数为零。补充一线程和零精化对照。
  完整 `iparm` 输入与输出保存于各臂 JSON。
- SparseLU：复用已保存的 C++20/Eigen COLAMD 诊断程序，double 53 位有效
  二进制精度、long double 64 位有效二进制精度；同一未缩放矩阵、同一 RHS。
  这不是经消元、均衡或精化后全部 SparseLU 配置的性能结论。

原生 `debug` 非零数据以 **15 位有效十进制数字**导出。本批求解的是这些导出数据
重新装载后的系统，不是可逐位访问的原生内存系统；原生 SOL 也不能视作该舍入矩阵
的精确解。Sentaurus 内部 PARDISO 的库身份、版本和全部参数仍未确认与 oneMKL 相同。

下表是方向相对原生 SOL 的块 L2 差；人口单位为原生归一化人口。
long double 在进入 binary64 状态路径时转为 double，完整精度残差另表核对。

| 后端 | 电势方向 | 电子人口方向 | 空穴人口方向 |
|---|---:|---:|---:|
| PARDISO 五线程 两次精化 | 1.948e-12 | 2.780e-13 | 2.551e-13 |
| PARDISO 一线程 两次精化 | 2.162e-12 | 3.063e-13 | 2.828e-13 |
| PARDISO 五线程 无精化 | 9.072e-13 | 1.573e-13 | 9.840e-14 |
| SparseLU double | 2.389e-6 | 2.079e-7 | 3.150e-8 |
| SparseLU long double | 7.968e-10 | 2.032e-11 | 1.969e-12 |

五线程 PARDISO 最大电势方向差在 5944，折算为 1.269e-14 V；电子、空穴
最大绝对方向差分别在 10515、13291。10280 空穴方向为：原生
-0.0227529060516528、PARDISO -0.02275290605165405，相对差 5.49e-14，
符号相同。10849 空穴方向相对差 1.66e-11。完整逐节点结果见 `directions.csv`。
这些方向是原生人口坐标，不能与此前 Vela A 系统的 QF 方向直接混用。

SparseLU double 的最大电势误差在约束节点 10345，约 2.108e-7 V；
long double 最大在 10420，约 1.030e-10 V。原生这些电势增量为零。
PARDISO 主臂全部 126 条单对角约束行的最大方向泄漏约 2.96e-31 内部单位。

## 独立残差审计

使用独立 C++ 程序以 Boost 113 位精度累加原始矩阵与求解方向，计算
`max_i |(Ax-b)_i| / (sum_j |Aij xj| + |bi|)`，同时输出自由行结果。

| 方向 | 线性相对 L2 残差 | 自由行最大分量后向误差 |
|---|---:|---:|
| 原生 SOL | 5.918e-14 | 3.875e-10 |
| PARDISO 五线程 两次精化 | 3.073e-15 | 4.275e-9 |
| PARDISO 一线程 两次精化 | 3.430e-15 | 5.019e-8 |
| PARDISO 五线程 无精化 | 5.466e-15 | 9.938e-1 |
| SparseLU double | 6.754e-15 | 5.706e-4 |
| SparseLU long double 完整精度 | 3.018e-18 | 5.641e-8 |

全部行的严格最大分量比均为 1：齐次单对角约束中只要存在极微小非零方向，
其残差和分母相等。该指标没有隐藏，须与上述约束方向的绝对误差共同解释。
PARDISO 主臂最差自由行是 5355 空穴行，绝对缺陷约 3.58e-19，分母约
8.38e-11。无精化最差行是 6400 空穴行，缺陷约 1.35e-8。
**全局方向接近或全局残差小，均不能代替弱行审计。**

本环境 NumPy 的 long double 文本转换会先丢失到 double 精度，因此完整 long double
残差以 `audit_linear.cpp` 直接读取原 C++ 文本的结果为准；`comparison.json`
中的 Python long double 残差属于已舍入方向。有限状态试探本身使用 binary64，
两者口径明确分开。没有把这种读取损失算作线性求解器错误。

## 同规则人口有限步

原生第零次人口与电势作为共同父态；用定义积分 Fermi 逆映射使 Vela 人口匹配，
父态 QF 调整最大电子 1.63e-11 V、空穴 3.38e-14 V。每臂按相同规则更新：
人口加上线性方向；非正提议改为旧人口的 1%；电势直接加上线性方向；
恢复对应 QF。小人口变化采用相对逆映射，大变化用完整逆 Fermi 差。
没有额外 QF cap、Poisson 重修正或线搜索，所有末态仅为未接受诊断试探。

按该人口规则重建原生下一次保存变量，三个块相对 L2 差为
2.30e-15、1.07e-15、2.09e-15；原生方向有 3,526 个非正空穴提议，电子为零。
这为本次首步规则提供了数据核对，但不是对原生所有场景更新算法的完整复刻。
各臂映射后实际人口与目标人口最大相对差低于 3.5e-13。

| 方向来源 | Vela 整体块残差 | 电子超标行 | 空穴超标行 |
|---|---:|---:|---:|
| 共同父态 | 73.72046 | 12626 | 12416 |
| 原生 SOL | 1.05054674244 | 5264 | 11368 |
| PARDISO 五线程 | 1.05054674244 | 5264 | 11368 |
| SparseLU double | 1.05069349973 | 5265 | 11365 |
| SparseLU long double | 1.05054672028 | 5264 | 11367 |

PARDISO 与原生 SOL 试探的电子、空穴残差向量相对差分别 8.799e-12、
3.553e-10；新增或消失超标行均为零。两者试探电势最大差 1.28e-14 V，
电子 QF 最大差 1.10e-12 V，空穴 QF 最大差 9.62e-11 V。
两者电子/空穴闭合比分别约 1.0000005/1.0009981，仍未达原资格。

这些是**第一步**，不是原生最终收敛态；首步未合格不能用来判定多步 Newton 必然失败。
本批新增生产合格点为零，原验收门槛未修改。
