# SimpleMOS 弱交叉块与少数载流子场验证

2026-09-06。承接[上一轮 Jacobian 与全场验证](simplemos_jacobian_and_fullfield_followup_2026-09-06.md)中两个明确的资格缺口。旧门槛、84 对场导出、旧失败记录及旧封存清单保持不变。

**两项验证已执行完毕。33 个弱交叉块全部获得稳定参考，原偏导步长另检出两个高漏压超差项，细步长隔离对照全部通过。少数载流子完成 20 次 DC 试算，仅两态通过新增全行门槛；八个偏压均未获得完整四初始化认证。既有高 NWell 电流差尚未解决，正式算法及 M82/M83 不放行。**

**工况与边界。** 使用同一 n19/n23 原网格，节点数 1480/1482，背景 Boron 1e17/2e17 cm^-3；matched-ni、no-BGN、Boltzmann、SRH，PhuMob + Lombardi + 向量准费米梯度高场迁移率，电流为 A/um、宽度 1 um。运行环境为 Windows UCRT64 Release、SparseLU。弱块复核复用此前四个严格端点态：低漏压为 Vd=0.05 V、Vg=0.9 V，高漏压为 Vd=1 V、Vg=0.8 V，以实际配置中的接触偏压为准；少数载流子另取 Vg=0.35/1 V、Vd=0.05/1 V，共八个偏压。此次复用已取回的 Sentaurus 导出，没有新增远程任务。

**弱交叉块：33 项均获得稳定参考，但原偏导步长有两项真实超差。**

本轮先冻结全部 33 个目标及门槛，再执行四个只读配置。Poisson 的 phi_p 列只对空穴电荷作差，避免先与介电项及掺杂项相加；连续性行先对对应 SG 边通量及 SRH 分别作差，再以 long double 累加到两端节点。基础分项重构与原残差的尺度归一化误差最大为 2.57e-16，通过冻结的 1e-10 检查。密度、电荷体积和归一化系数独立换算，保留原方程及接触行。

外部物理扰动覆盖 1e-3 至 5e-8 V，共 14 档。以 `R(h)=[4D(h/2)-D(h)]/3` 外推，并要求相邻外推结果相对变化 <=1e-4。合格候选中选择步长变化最小者，选择过程不使用被检验的 Jacobian；全部步长结果保留。矩阵门槛仍为相对误差 <=1e-3。内部输运数值偏导系数分别取原 1e-6 及隔离对照 1e-7/1e-8，向量场链式补项均开启。

这四项的外推参考相对步长变化为 3.36e-6–3.58e-6。细步长对照的全部 33 项最大矩阵相对误差为 3.26e-6；原步长两个高漏压失败保留。其余 29 个弱交叉项在分项差分后与矩阵一致；其中 Poisson 组的整残差差分与分项参考最大相差 8.89%，说明直接对已累加残差作差会掩盖弱电荷导数。不能把以前的差分不稳定一律解释为 Jacobian 漏项。

两个高漏压失败中，最大绝对导数差分别落在 n19 空穴行 1087、n23 空穴行 1088。表中百分比是整列对应方程块的 L2 相对误差，不能直接换算为端口 Id 改善幅度。

本轮新检出两项与上一轮四个稳定超差项是不同的列—方程块组合。两轮共同支持局部输运数值偏导步长存在问题。底层迁移率和边通量仍以 double 求值；long double 累加不是任意精度物理模型。这里只补齐所选局部邻接列中的 33 项，不能推出全器件所有列、所有偏压和非光滑分支都已完整。正式源代码没有采用这些隔离对照，也不能把正式 Jacobian 宣称为全符号解析式。

**少数载流子：独立冻结新增门槛。**

新增诊断检查所有正密度、非接触的 Si 电子/空穴连续性行。每个状态检查 1814 行，即每种载流子 907 行。行尺度 floor、源项/通量排除门槛及其相对系数均为零，密度纳入阈值为 1e-300，仍要求 `abs(row residual)/row scale <=1e-6`；零尺度行单独标为未解析，不能靠零 floor 自动放行。独立探针仍执行原 global 闭合及 KCL/Id<=1e-8；旧载流子门槛在相同输出态另行只读检查。

原 Newton 停止条件和 max_iter=200 均保留；使用已经独立对照过的隔离向量链式补项及输运步长 1e-7。32 份初值和配置在计算前已冻结：每偏压分别取既有 Vela 态、原生一致映射态、Vela 自由 Si 节点空穴准费米势 +0.05 V/-0.05 V 的状态。偏移时保持电子、电势和接触不变，空穴浓度按 Boltzmann 指数关系同步改变。

初始化不变性必须由四种初始化均获得合格最终态后认证；任意两态全自由 Si 节点的 psi/phi_n/phi_p 最大差 <=1e-6 V，密度最大对称相对差 <=1e-4，Id 对称相对差 <=1e-6。这里对称相对差为 `abs(a-b)/max(abs(a),abs(b))`。失败态的差值只作诊断，不能据此断言收敛物理解存在多解。

计算中首个未偏移 Vela 态即未通过全行门槛，因此另外冻结了执行顺序补充：先筛查八个偏压的 Vela/原生两种基础初始化，只有二者都通过才继续该偏压的正负偏移。数值门槛、迭代上限、物理方程及原 32 份配置没有改变。

执行顺序补充冻结时，首偏压正负初始化仍在运行；实际停止原调度器前，它们已各达到 200 次并失败。实际中断的是后来已启动的 n19、Vd=0.05 V、Vg=1 V 的 Vela 和 hole_plus 两次尝试，准确命令记录在 interrupted_processes.json。Vela 尝试由新筛查从同一冻结初值重启。已完成的首偏压正负失败均保留；被中断且没有完整输出的尝试不计作收敛或不收敛证据。screen 的 deferred 标记表示未满足后续资格前提，不会抹掉此前已完成的试算。

最终完成 20 次 DC 试算和 40 次只读行/全局闭合探针；另有上述两次中断尝试。32 个冻结初值中，20 个取得完整输出，12 个因基础初始化资格不足没有完成后续偏移重算。所有完成态均核对了 1814 行覆盖，未发现零尺度活动行。完成不代表收敛：18 个失败态中，14 个因全行线搜索拒绝停止，4 个达到 200 次迭代仍未满足全行门槛。

表中行比值门槛是 1e-6。16 个基础初始化试算中，14 个未通过；其中 12 个只出现空穴超差，n23 高漏压 Vg=0.35 V 的两个状态还出现电子超差。浅沟道空穴在这些失败态中也有 30–136 行超差，问题不只存在于沟道之外。

20 个输出态中有 18 个通过只读旧行门槛、带 floor 的 global 闭合和端口 KCL；其中 16 个仍未通过新增全行门槛。该数量取自 `qualification.csv` 的 `legacy_post_gate_satisfied`，不能与同时绑定本轮 DC 退出码的原始 `legacy_qualified` 字段混用。旧事后检查通过不使本轮失败的 DC 试算变成合格状态。

首个 n19、Vd=0.05 V、Vg=0.35 V 的 Vela 初值试算在第 5 次迭代因全行线搜索拒绝结束；201 个超差行全部为空穴行。此时旧行探针的最大比值为 1.42e-11，KCL/Id=3.40e-15，均通过原事后门槛。新增门槛下最差的空穴行是节点 41，p=119.238 cm^-3；内部残差约 -1.202e-29、尺度 2.033e-29，比值 0.591，远高于 1e-6。小的绝对残差和端口闭合不能替代这一逐行检查。

逐行 CSV 中的浓度统一用导出 SI 状态除以 1e6 得到 cm^-3，并与探针值逐行核对。原 JSON 的 `carrier_density_m3` 名字在此配置下承载内部 cm^-3 数值；汇总显式改名并保留原值及说明，避免扩大百万倍的单位误读。这里的残差/尺度属于求解器内部连续性行，不能直接当作端口安培数。

对于 n23、Vd=0.05 V、Vg=1 V，Vela 和原生两种基础初始化都通过新增全行门槛；两者最大 psi/phi_n/phi_p 差分别为 1.11e-16、6.25e-17、1.73e-17 V，密度最大对称相对差 7.32e-15，Id 导出值相同。这只认证这一对合格状态的相互一致，完整四初始化结论仍按上表执行。

该工况的 hole_plus 在 200 次后仍有 95 个电子、119 个空穴超差行；hole_minus 在第 0 次迭代的线搜索被拒绝，初值 KCL/Id 约 506，属于明确未闭合的初始状态。两者不能用于认证初始化不变性。八个偏压的完整四初值合格数因此为 **0/8**；这项结果指出求解和资格验证的缺口，没有证明收敛物理解存在多解。
