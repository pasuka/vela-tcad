# SLOT 六条电子行有界修正与 merit 对照（2026-10-02）

## 结果

同一失败初值上的 QF 载流子修正与密度坐标修正，均消除了原六条超标电子行。
直接接完整 Newton 会重新出现局部行失败；改为先做 2 次 Poisson-only 更新、
再执行完整器件验证，两种路径均通过原器件、全部有效行、全局闭合及文件绑定检查，
并通过各自派生实际外压上的原负载线确认。

这证明本状态上的有界分块修正可行，尚不等于同目标外压独立复现或生产策略验证。
两组返回共同目标外压的额外确认均在 120 s 内未完成，未将超时判作无解。
修正后实际外压约 **171.358984170 V**，相对共同目标低约 **0.103785498 V**，
必须使用修正后的电流重算进度，不能沿用修正前的耦合负载残差。
新增账本点 **0**；未恢复长扫描、未改变门槛，未达到击穿电流判据。

## 配置与对照设计

使用 [上批独立路径](slot_ldmos_s02_repeat_loadline_2026-10-02.md) 的
`build/s02repro/independent/poisson/d/final_state.h5`，不是已通过的 repeat 状态。
物理内压固定为 **38.50512193650067 V**，电位原点 36 V；
共同目标物理外压 **171.46276966785024 V**，外电阻 `1e12 Ω·µm`。
输入 SG 电流 1.329578322023488e-10 A/µm，对共同目标的派生负载偏差 +184.471 µV。

网格 13,881 节点 / 27,275 单元，沿用 IALMob、自洽雪崩、原生输运几何和
原载流子统计配置。每种载流子有效行 12,634；电流单位 A/µm。
MSYS2 UCRT64、本机串行，使用上批冻结 Release 诊断 runner；本批不新增源码或编译。
载流子块通过现有 `newton_block_step_probe` 求解；Poisson 和完整 Newton 使用该 runner
原线性求解实现。本批不是新的 bordered 耦合求解器或线性后端对照。

保留最终 `abstol=1e-9`、`reltol=1e-8`、行比 `1e-3`、尺度下限 `1e-30`、
全局闭合 `0.01`、负载线 `1e-6 V`。候选阶段依照现有修正 helper 关闭
carrier diagonal floor，采用物理载流子 Jacobian；完整验证恢复原配置，未放宽资格。

两种候选均从同一输入出发、各只做一次载流子块修正，ψ 固定。
修正作用于完整载流子块，不是仅修改六个节点，也未掩蔽其他行。
QF 模式沿用配置限幅；密度模式沿用正密度限制和冻结行尺度 merit 回溯。
每个候选先做完整行审计、冻结块评估和 SG 重放，再直接执行原严格 Newton。
直接路径失败后，在同一批剩余预算内各追加一次 Poisson-only 修复对照，最多 12 次更新，
随后重新执行原严格验证；没有循环增加修正次数。

总墙钟上限 1200 s，补充对照继承原截止时刻，未重置预算；求解子进程上限 120 s，
冻结评估 60 s。所有输出在 `build/s02sixrows/`，原 `s02repro` 保持只读。

## 局部质量改善与全局 merit 的差别

原六条电子行：13879、4639、10752、10750、4638、10805，行比为 0.001059～0.007250。
一次修正后，六条行比均降至约 **1.2e-13～1.8e-12**；全部电子/空穴行也通过。

| 同进程块评估 | 输入 | QF 修正后 | 密度修正后 |
|---|---:|---:|---:|
| ψ 块 L2 | 9.64576e-10 | 1.63328e-6 | 1.63329e-6 |
| 电子块 L2 | 5.84681e-13 | 3.01926e-13 | 6.23691e-14 |
| 空穴块 L2 | 4.38642e-11 | 1.37175e-13 | 7.97712e-14 |
| 按原显式块尺度归一化的范数 | 8.10824e-10 | 1.372933e-6 | 1.372945e-6 |
| 全部行超标数（电子/空穴） | 6/0 | 0/0 | 0/0 |

范数按源码 `normalizedBlockL2` 计算，使用显式尺度
ψ=1.189625、φn=8476.074054、φp=3518.300497 及原权重。
这里比较的是同一探针进程内修正前后残差，不能混称为耦合电路 merit；
也没有假定探针修正已经被完整 Newton 线搜索接受。

两个候选的 ψ 保存场逐值不变，最大 φn/φp 改变约 38.8～38.9 µV。
载流子改变导致电荷改变，Poisson 残差增大。因此“局部行显著改善”与
“完整方程范数下降”在这一步不同步，不能用单一范数下降要求判定修正是否值得恢复，
也不能以局部行通过直接跳过 Poisson 自洽和最终资格。

## 直接完整 Newton 对照

| 候选 | 严格 Newton 接受更新 | 最终超标电子/空穴行 | 停止原因 |
|---|---:|---:|---|
| QF | 1 | 32/0 | carrier_row_convergence_line_search_rejected |
| 密度坐标 | 3 | 1/1 | carrier_row_convergence_line_search_rejected |

两者末次均有 13 次不满足下降条件的线搜索试探，未发生单次求解超时。
QF 路径电子最差行 13291，比率 0.0268941、scale=1e-30；
密度路径电子行 13645 比率 0.00110364、scale=1e-30，
空穴行 3588 比率 0.00108974、scale=1.41623e-19。
这些终态问题已不同于输入的六条电子行；不能说“六条行一直没有修好”。
保存的失败态仍未合格，冻结电流不提供额外接受资格。

## 先 Poisson 修复再完整验证

两种修正态均经 **2 次 Poisson-only 更新**后，再以完整 Newton 原资格检查。
完整验证均以 `initial_abstol`、0 次更新通过；全量行审计与文件绑定再次通过。
0 次更新表示组合修复已提供满足原门槛的初值，不是额外独立求解成功的证据。

| 指标 | QF → Poisson | 密度 → Poisson |
|---|---:|---:|
| ψ 块 L2 | 9.39555e-10 | 9.44916e-10 |
| 电子最差行比 | 3.10066e-6 | 2.98171e-6 |
| 空穴最差行比 | 7.55836249e-4 | 7.55836289e-4 |
| 电子全局闭合比 | 2.98289e-7 | 6.72645e-9 |
| 空穴全局闭合比 | 2.98285e-7 | 6.73049e-9 |
| 严格 SG 电流 / A·µm⁻¹ | 1.3285386223369225e-10 | 1.3285386223369275e-10 |
| 派生物理外压 / V | 171.3589841701929 | 171.35898417019342 |
| 自身实际外压确认 | 通过 | 通过 |

两种电流相对差 3.77e-15，最终 ψ/φn/φp 最大差分别为
2.284e-12 / 2.919e-8 / 2.932e-8 V。两臂共享输入和大部分算法，
不能冒充不同父态的独立复现，也不能凭端口电流一致推导所有场量逐值一致。
空穴最差行仍约为门槛的 75.6%，本批没有验证更大步长或连续多步的质量余量。

实际外压确认使用原 `confirm` 和 `validate_confirmation`，绑定已通过的完整器件证明，
检查电流及保存态未改变、负载线满足 1 µV。电路种子复用行的零残差只说明电路确认，
完整器件/行/闭合资格仍来自严格证明。共同目标确认另行记录，不能用实际外压通过替代。

## 后续判断

本批支持研究默认关闭、次数受限的“载流子修正 → Poisson 自洽 → 原严格验收”恢复入口。
相较直接完整 Newton，这个顺序在当前输入上保留了局部行改善；尚未证明通用优越性。
先验证该组合在少量相邻父态的成功率、实际外压漂移及全部尝试成本，再考虑接入生产。
若目标仍是同一指定外压，需针对修正后的电流偏差做有界端口校正并重新执行全部资格；
本批不通过放宽 1 µV 容差把不同外压点称为同目标复现。
