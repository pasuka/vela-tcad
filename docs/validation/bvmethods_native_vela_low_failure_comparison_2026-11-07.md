# Sentaurus约2.51 V与Vela约2.43 V失败过程对照（2026-11-07）

结论：两边均缩步，但直接终止原因不同。原生在8轮后因RHS相对初值增长超过1e10倍终止；Vela在1次实际写回后，下一原始方向被原物理绝对线性精度门拒绝。Vela巨大空穴方向已定位到器件块对空穴RHS的响应，不是接近零的电路Schur分母。现有原生归档不足以证明两者具有相同的保护事件、有效矩阵或上游物理根因。

本轮只分析既有失败记录，并在Vela VM做五帧冻结双精度矩阵的纯线性分解；无新器件Newton、无新Sentaurus、无状态写回或生产改动。未扩展精度/ULP扰动试验。

- 原生：Sentaurus U-2022.12自适应0–100 V冻结参照。N20、Digits=5、ErrRef(n,p)=1e10 cm^-3、RhsMin=1e-5、Extrapolate、增长1.41/缩步2、单线程ParDiSo。日志注明Bank/Rose非线性求解器。

- 同一器件网格2600节点/5020 Tri3、300 K，JD/OldSlotboom、总杂质迁移率、SRH+GradQF AV、BTBT关、R=1e7 Ω·μm。器件残差仍沿用既有归一化。

原物理绝对门主导行5817=5200+617，即自由空穴node617。巨大方向放大矩阵映射、方向舍入及求解缺陷；先前已确认RHS共享计算合同，无再次重复RHS误算。此前原坐标重解/同态Full及有界缺陷校正仍未安全通过联合原门，详见[绝对精度定位报告](bvmethods_defaults_absolute_precision_2026-11-07.md)。本轮不放宽该门、不将它改成report。

## 4. 巨大方向来自哪里：五帧器件/电路分解

原物理审计基底为`[psi/VT,n(cm^-3),p(cm^-3),Vinner(V)]`，7801维。将实际冻结矩阵分为

\[
\begin{bmatrix}J&f\\r&c\end{bmatrix}
\begin{bmatrix}\delta x\\\delta\lambda\end{bmatrix}
=\begin{bmatrix}b_d\\b_c\end{bmatrix},\quad
a=J^{-1}b_d,\quad z=J^{-1}f,
\]
\[
s=c-rz,\qquad \delta\lambda=(b_c-ra)/s,\qquad
\delta x=a-z\delta\lambda.
\]

使用同一冻结PARDISO后端求器件块；高精度仅累计缺陷与Schur标量，矩阵、分解和输出方向仍为双精度。RHS分为互斥的规定行、自由Poisson、自由电子、自由空穴和电路五份，分别求响应后相加。这是指定冻结矩阵下的线性归因，不能据此声称某个物理源项或厂商内部合同已识别。

|冻结系统|s|δλ(V)|node617 δp(cm^-3)|
|---|---:|---:|---:|
|失败目标第1步前Full|1.08287729|+0.0486195930|−2.95632924e5|
|失败目标保护后，实际省略偏导|1.00740359|−0.377672066|+8.96744236e12|

|前一目标末轮对照，省略偏导|1.00739927|−2.98249535e-11|+2.78451153e4|

具体结论：

1. **不是小Schur分母放大。** 实际失败态s≈1.0074；其node617固定内压器件响应a≈8.967442319329e12，而电路项−zδλ仅+42877.49 cm^-3，约占总方向4.78e-9。
2. **该节点的大空穴方向由空穴RHS驱动。** 空穴RHS分块给出约8.967442319758e12 cm^-3，其他分块远小。这里是完整器件J的逆响应，仍包含电子/电势/源项交叉耦合，不能缩写为“空穴对角项错误”。
3. **内压大方向则主要由电子RHS响应驱动。** 其δλ分解约为：电子−0.38559923 V、空穴+0.000733305 V、Poisson+0.000001948 V、电路直接RHS+0.007191911 V，规定行近零。总和约−0.37767207 V。不能把它简单归咎于负载线RHS本身。
4. **省略偏导不是巨大方向的充分解释。** 同一状态换Full后node617仍有8.83e12量级方向，且原门未获通过。另一方面缩步对照仍省略偏导，却比失败态该节点方向小约2.04e7倍。因此状态/入口及器件响应必须纳入解释。
5. **保护后的状态与强放大相邻，但因果未全部闭合。** 实际先有非正候选和大范围保护，随后该状态上两类矩阵均产生巨大方向。这不等于已证明1%投影本身导致该器件响应；尚不能唯一指认AV、迁移率、SRH或某一条边，也没有计算条件数/最小奇异值来证明矩阵奇异。

诊断质量：各器件块解分量后向误差约8.3e-17至9.8e-17，重组完整系统最大后向误差1.153e-12，各分块相加自然尺度相对闭合误差≤1.07e-14。失败省略态Schur重组的原物理绝对缺陷仍为1.7487e-8；Full反事实为2.4066e-7，**未获原绝对精度门资格**。新分解改变消元/舍入次序，与既有捕获方向不逐位相同：失败态δλ相差约4.35 nV。小后向误差不是前向等价误差界；本轮只使用稳健的量级/分块结论，不宣称冻结方向等价、保护影响消失或判停不变。

## 5. 缩步原因是否相同

|问题|当前证据支持的判断|
|---|---|
|是否都出现大更新/发散征兆？|是。原生RHS、E及step最终爆增；Vela保护后下一方向极大。|
|直接终止机制是否相同？|否。原生RHS增长终止；Vela第二次写回前原物理绝对线性精度拒绝。|
|是否都是预算耗尽或更新误差卡在1附近？|否。本样本8轮/1次写回终止，E远大于1。|
|是否触发同样的浓度保护和同样的偏导省略？|本原生失败目标数据不足，未知；不能用其他样本证明。|
|巨大方向是否都是同一器件块/同一物理项造成？|Vela本轮已定位器件空穴RHS强响应及电子RHS的内压作用；原生缺矩阵/方向，尚不能比较。|

最合理的收口是：**共同上游失稳现象得到支持，直接缩步原因不同，相同上游物理根因尚未证明。** 不能以原生也缩步来豁免Vela精度门，也不能以Vela先拦截就认定其物理解更正确。

若要继续做因果闭合，新增原生证据应只针对本失败目标：逐轮pre/raw/post、局部保护集合、有效矩阵与RHS、原始方向及线性残差；并在同一入口下比较。现有零偏/最终TDR不能恢复该失败入口，不从邻近偏压拼造。当前有界分析已完成，不自动启动新原生扫描、缩步重放、扩大ULP试验或修改门限。
