# SimpleMOS M67 剩余势垒分解

M67 分类为 `residual_qf_barrier_material_but_not_complete`。在 Sentaurus 控制节点固定后，`phin` 与 `psi` 分量严格重构 `phin-psi`；8 个 NWell 配对的势垒代理对剩余电流增幅的中位闭合率为 `68.94%`。中位电流增幅 `0.037029 dex`，势垒代理 `0.023524 dex`，其中准费米分量 `0.004484 dex`、电势分量 `0.018960 dex`。

该结果是状态观测量分解，不把热发射式势垒代理当成完整漂移扩散电流因果模型。机器报告：`reference_tcad/simplemos_sentaurus2022/residual_barrier_partition/m67_residual_barrier_partition_report.json`。
