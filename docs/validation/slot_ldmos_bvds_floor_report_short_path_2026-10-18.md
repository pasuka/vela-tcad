# SLOT BVDS：弱行仅报告的显式接受策略与短路径验证

用户明确授权：尺度下限支配的弱行仅记录，不阻碍后续仿真。本批在独立配置中
启用该策略，继续使用2026-10-18北京时间19:23的原截止；不启动长扫描。
本批已结束：50→75→100 mV通过新策略及独立零更新复读；直接50→100 mV
在540秒单点硬上限前未通过其余资格，保存失败态停止。未进入长扫描。

## 策略边界

配置为 `solver.carrier_row_convergence.floor_limited_action: "report"`，默认仍为
`"enforce"`。只有原资格策略选中的有效载流子行，且
`max(abs(fluxAbsSum), abs(recombination), abs(impact)) <= scale_floor`、下限为正，
才适用弱行报告规则。浓度高低本身不是这项分类的判据。

全部超标行仍保留在`violations`中。弱行的`blocks_acceptance=false`，
`blocking_violation_count`只统计其余超标行，`satisfied`表示阻断行数为零。
弱行也不再作为Gummel局部恢复的目标。原尺度、eps_row、方程、方向计算、
闭合、接触边界及数值有效性检查不变；不会把这一修改称为物理误差已被证明可忽略。

本批沿用上一批冻结的补偿掺杂、300 K Boltzmann/OldSlotboom、IALMob兼容、
AverageBox及split状态口径。正则化0、闭合替换保留、PARDISO四线程，
接触电压高低位修复启用，共同／相对坐标实验不启用。
常数头文件、输入父态和runner哈希独立保存；不覆盖旧批次资格记录。

## 验证顺序

1. 构建并执行载流子行单元测试和有界接口回归。
2. 对此前75 mV完整步候选做零更新复读，仅改变弱行接受策略；这不计为新扫描点。
3. 从此前合格50 mV父态重新计算75 mV并复读。
4. 通过后分别计算50→75→100 mV和50→100 mV；记录端口电流和存档场量差。
5. 每点最多25次更新、软480秒、硬540秒，复读上限210秒，全部受固定截止限制。
   任一目标未满足剩余资格则保存失败态停止，不以弱行免阻断替代其他保护。

本轮为明确授权的接受策略变更；其结果应标注“弱行报告策略”，不能回写成
原严格逐行规则合格，也不能据此宣称与Sentaurus定量一致。

## 直接50→100 mV对照的限制

同后端、同物理和同接受策略下，直接路径运行540.0085秒后由控制器按硬上限终止，
退出码124。没有最终资格JSON，因此不把它表述为求解器自行宣布数值失败。
最后完整进度快照为第20次更新，内部累计时间482.7448秒：

- 整体残差3.3597545995328e-14，最大行比1.3424532380873373，`qualified=false`。
- 保存的3251条超标行中，3212条尺度大于1e-30；其余39条属于下限支配范围。
- 最大行是10221空穴：残差-1.210782791112231e-20、尺度9.019180383797174e-21。
  该尺度远高于下限，仍受原0.001行比门槛约束。
- 电子/空穴闭合比分别约2.01887e-5、2.01857e-5；限幅改变12595个自由度，
  线搜索alpha=0.5。较大跨度仍有明显非线性迭代负担，不能归因于下限弱行。

因此尚无两份合格100 mV末态可做路径场量复现。本批没有执行已准备的同供电
增广电路对照；其前置条件是两条路径都合格。也未启动后续长扫描。
合理后续是保留此策略和原非弱行保护，优先使用已成功的25 mV跨度及失败减半；
另行核查直接路径的非弱行方向/限幅，不扩大弱行免阻断范围。
