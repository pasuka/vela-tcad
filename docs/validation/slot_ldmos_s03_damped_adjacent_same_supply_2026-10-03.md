# SLOT 半步阻尼相邻点与同外压验证

2026 年 10 月 3 日。承接[载流子阻尼对照](slot_ldmos_s03_carrier_damping_comparison_2026-10-03.md)，
本机串行完成有界验证。**两步 10% 电流增长通过原完整资格和目标外压确认，首点的不同初值
同外压复现通过；第三点第二次端口校正因局部修正范围超过上限停止。**
本批试验账本新增 2 点，生产账本不变；未达到 1e-7 A/µm，不报告 BVDS。

关键修正是半步的放置位置：直接用半步替代未收敛候选的基础载流子修正失败；
先按原全步流程恢复并通过完整资格，再追加半步修正、Poisson 修复和完整验收，前两点可用。
第三点失败发生在基础恢复阶段，尚未进入追加半步阶段，不能记作半步修正失败。

## 2 直接半步替代失败及同初值全步对照

[直接半步试验](../../build/s03dampadj/summary.json)首个目标为 1829.6468324186194 V。
在同一耦合候选、poly 恢复及前置 Poisson 态上，用已限幅载流子步 α=0.5 更新 QF 增量坐标，
同步重建 Boltzmann 密度，保持参考坐标与 ψ 不变，再作 Poisson 修复。

| 同一载流子完整试探态的处理 | 超标电子/空穴行 | 最大行比 | 结果 |
| --- | ---: | ---: | --- |
| α=0.5，再作 Poisson | 247 / 0 | 0.0569723 | 所需修正 407 DOF，超过 8，停止 |
| α=1，再作 Poisson | 0 / 0 | 0.000357766 | 原完整资格及实际外压确认通过 |

半步最差电子节点为 13879，其次为 4639、10837。此时全局闭合约 8.35e-7/8.86e-7，
仍不能代替局部行资格。全步对照直接复用同一份完整载流子试探态，没有重新生成不同方向。
其 I=1.791780608404071e-9，实际外压 1830.2858559456536 V，比目标高 0.639023527 V；
只是实际外压合格诊断态，不是同目标通过点。

结果表明，在这个未收敛种子上，一次半步留下了基础恢复不能接受的行误差。
不能把前批“合格态附近半步抑制交替”的观察推广为所有恢复阶段统一使用半步。
证据复核见 [control_audit.json](../../build/s03dampstage/control_audit.json)。

## 3 分阶段半步与端口校正

在新目录冻结如下试验流程，未修改生产默认：

1. 原耦合候选 → poly 恢复 → Poisson → 原完整载流子步 → Poisson → 原局部修正和完整器件资格。
2. 仅从已合格态追加一次 α=0.5 载流子修正，再作 Poisson、原完整器件验收及有效行审计。
3. 用严格 SG 电流计算实际外压并确认；未达到固定目标时，有界调整提议，重新从该臂合格父态求解。
4. 固定目标残差≤1e-6 V 后，单独执行目标外压确认，再写入本批试验账本。

端口校正第一步用单位响应，其后用割线；响应范围 [0.2,5]，单次提议校正≤0.01 R I_seed。
原局部修正最多 3 轮、8 DOF，首轮启用已冻结的邻行预测规则。
任何恢复态、半步态、电路零残差态均不能跳过完整器件资格。
