## 3. 原生复现与负载线诊断

原 cmd/par/mesh 未改动。本轮原生退出码为 2，墙钟 341.16 s，接受点数 84。

| 末态量 | 数值 |
| --- | --- |
| 外电压 | 14099.8112219938 V |
| 内电压 | 7.16025522412325 V |
| 漏电流 | 0.00140926509667693 A/um |
| 全轨迹最大负载残差 | 1.2396e-9 V，低于 1e-6 V 门限 |
| 高电流点最大相对 KCL | 6.4338e-15，低于 1e-5 门限 |
| 位移及分量闭合 | 所有接受态通过既定门限 |
| 停止原因 | Newton 超过 20 次迭代，重试后归一化步长 9.4920e-11 小于 MinStep |

原停止电流、原生停止声明和成功退出均未通过。`Good Bye` 和最终 TDR 的存在不能覆盖这一失败。
最后一次实际求解的归一化步长为 `1.8984e-10`，对应外电压增量约 `1.8984e-5 V`；
日志只显示六位小数的 t，不能从其 `t=0.140998` 文本恢复精确失败目标或失败内电压。
`*_min_des.tdr` 属于迭代诊断态，未作为接受态使用。

在末段，从 13998.9545 V 到 14067.8445 V，外电压增加 68.89 V，内电压减少 2.1694 mV；
相邻接受态有限差分给出 `dVouter/dVinner≈−31755.5`。最后区间该值约为 −5.5034。
负载恒等式 `ΔVouter=ΔVinner+RΔI` 仍闭合，说明内电压回落不是漏掉串联压降。
有限差分间距越来越小，会放大求解和输出噪声；这些结果支持折返/近奇异耦合调查，
没有证明严格折点、无根、唯一性或动态稳定性。

代码核对还发现两项适用边界，均未据此改默认：

- `solveMonotoneBoundaryRoot` 明确要求递增标量残差；观测到的原生下降区间不满足这种支路描述，
  但还没有同一区域的有效 Vela 态，不能认定它已经导致本轮 Vela 失败。
- 默认标量电阻路径按 `bias_points` 或 `start/stop/step` 枚举外目标；前端虽输出
  `initial_step=0.01 V`、`min_step=1e-5 V`，外电阻路径并不使用普通电压扫描的自适应控制。
  耦合模式使用独立 `coupled_*outer_step*` 配置。原 cmd 的步长语义与外电路执行方式需进一步对齐，
  当前零偏失败发生在扫描之前，不能把这一映射差异当作已实测的主因。

## 4. 最小修复和数值候选

A 修复 parser 对 `Eparallel` 的映射：原先输出 `electric_field_parallel`，C++ 配置器拒绝它；
现在输出现有受支持的 `eparallel`，继续使用载流子电流方向投影公式。
更新 IR/两个 stage golden，并把已有 p 型接触实 runner 测试扩展到 Eparallel，仍检查密度与准费米边界性质。
没有添加 C++ 别名或改变模型选择。

| 候选 | 主要变化 | 初轮 Windows 结果 |
| --- | --- | --- |
| A | 仅接口键值修复 | 输入已进入求解；Gummel 7 次后，Newton 完成 1 次更新，在第 2 次尝试因 `carrier_invalid` 失败；原始步范数约 2.68e83 |
| B | stage 0 使用直接 Newton、contact-majority 参考及 0.1 V 准费米更新限制；仍为 20 次预算 | 完成 20 次更新，`max_iterations`；Poisson 残差约 3.36e-10，电子残差约 3.53e-5 |
| C | 在 B 上仅把 stage 0 预算增加到 200 | 完成 52 次更新，在第 53 次尝试因 `line_search_non_decrease` 失败；13 次线搜索未获接受步 |

C 的初轮 Ubuntu 对照同样完成 52 次更新后失败。Windows/Ubuntu 的电子残差约为
`1.184366234e-5` / `1.184366228e-5`；这不是正式跨平台通过门，仅用于报告相同失败类别。
残差热点包括硅区节点 129/1446，位于 x=0、y≈±0.01765625 um。
需要进一步审计零偏态和源项/载流子 Jacobian；当前诊断没有完整逐次线搜索历史或可接受场量态。

明确固定 SparseLU/COLAMD 的追加对照中，两平台 A 都在完成 1 次 Newton 更新后因载流子无效失败；
C 在 Windows 完成 43 次、Ubuntu 完成 51 次更新后均因线搜索不下降失败。
两平台各完成八项相关回归；A/C 的解析后 stage 0 配置逐项相同，原输入字节哈希相同。
迭代数和末端残差存在平台/后端敏感性，没有正式跨平台数值通过资格；失败类别保持一致。

失败 CSV 的 `points=1` 包含一次失败尝试，`converged=0`；其中输出的零终端电流不是有效接受解，
不能用它声称 KCL、停止值或电阻闭合通过。所有候选均未执行 Load、瞬态、辅助栅或电流模式切换。
预算增加未放宽收敛门限，且没有改全局/前端默认。

## 5. 材料、场量和验证边界

审计完整同版本 Silicon/Oxide/Nitride 默认转储及原 `Scharfetter.taumax=1e-7 s` 覆盖，
覆盖转换报告声明的全部 108 项数值参数：100 项原值相同，8 项原值不同，无缺失条目、无 lossy 项。
差异解释为：三个 Si 温度指数在 300 K 的因子均为 1；Si Auger.H 所属模型未启用；
Oxide/Nitride 各两项 beta/Tpar 差异在 alpha=0 时不影响带隙。没有为贴合曲线改材料默认。
绝缘材料完整转储含当前严格参数 IR 不支持的 HydrogenAtom/SHE 嵌套语法；
本轮仅提取有行号/原件哈希的 Epsilon、Bandgap 审计段，未放宽前端解析器。

已有 13 kV SAV 的 `Extrapolation_eDensity/hDensity` 含两个历史分量，不能充当接受态密度。
本轮因此在 VM 对已有正向和反向 SAV 执行仅 Load/Plot 的具名诊断，补齐实际场量。
它们是支路检查，不能用作从零轨迹资格。原路径末态使用接受轨迹结束后的最终 TDR；
不使用不收敛迭代的 min TDR。场量结果及各文件哈希见配套 JSON。
