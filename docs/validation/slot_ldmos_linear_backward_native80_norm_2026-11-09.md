# SLOT线性分量精度门及80位完整更新计数，2026-11-09

## 直接增广线性分量检查的准确含义

该检查校验本次线性系统Ad=b的返回方向d，发生在非线性试步和状态写回之前。
A为本次组装坐标中的增广矩阵，包含器件方程和外电阻接触方程；用数值行列
平衡之前的矩阵/RHS复算，而非只检查分解器内部缩放后的系统。

每行定义：

```
r_i = (A*d - b)_i
s_i = |b_i| + sum_j |A_ij*d_j|
beta_i = |r_i| / s_i
beta = max_i beta_i
```

分母为0时，该实现记对应分量误差0。缺陷与分母由Boost
`cpp_dec_float_100`复算；这不将原本的浮点矩阵、分解和方向变成100位求解。
公式入口为`LinearRefinement.h::highPrecisionDefect`。

`CoupledLoadLine.h`中当前硬门为beta≤1e-10，来自Vela代码，不是
Sentaurus脚本的RHSmin，也不是载流子非线性行比。
浓度路径尝试精化修正，默认有最多3次修正预算，可能因修正不改善而提前结束；
只有通过原矩阵的分量门及缩放缺陷门后，才将方向交给更新保护和写回。

本次62.6 mV外电源尝试报告beta=6.892859e-6，约为硬门的68929倍。
这是无量纲后向误差，不是6.89e-6 V/A，也不等于解向量的相对误差。
它回答“方向对这份输入线性方程是否足够自洽”，不认证Jacobian物理正确性，
也不能保证病态弱方向的前向精度。失败同样不能直接归为PARDISO实现错误。

日志只有最大比值，没有保存该失败步的完整A、b、d、最差行及绝对缺陷。
因此尚不能区分近零分母、相消、尺度或实际修正求解误差；需要冻结系统证据。
本轮仅解释此门，未将其改为report、放宽阈值或重启失败扫描。

## 原参数80位核查的实施范围

沿用本批16:40:20截止，复用绑定的U-2022.12程序与原始零偏压输入。
分别保持BVDS/IdVd原物理和原阻尼设置，执行Poisson→首次耦合；不扫描新偏压。
原生观察器独立核对long double消费者布局、16字节存储步长、10字节x87有效内容。
其索引结构与double版本不同，未直接沿用double偏移。

采集实际MaxNorm输入/索引、ComputeError原始方向和返回值、变量到对象映射、
分组计数、归一化平方和及未放大平方和，随后独立回放全局RMS并与返回值比较。
同时与原80位基线的CSR、矩阵、RHS和方向比较有效80位内容，排除填充字节。
全部原始输入、采集与分析留在VM，本地只保留结论及忽略目录中的执行配方。

## 实际完成结果

两类原生进程与调试器均退出0，非超时，观察器无错误；BVDS约47秒，IdVd约208秒。
两者均完成8次纯Poisson更新和1次首次耦合更新，共18次ComputeError与56次MaxNorm记录。
未启动新偏压扫描。原输入哈希不变，原生实际运行在15:22:57全部结束。

每次MaxNorm输入的有效80位值独立解码并取最大绝对值，56次均与原生返回值完全相同。
18次更新的全局RMS用实际分组平方和及实际计数重建，最大相对差分别为
BVDS 4.006e-20、IdVd 3.962e-20。这里是高精度数学重建与x87返回值的比较，
不将其宣称为所有逐条x87指令的逐位回放。

首次耦合系统的CSR行列索引与既有80位冻结基线相同；A、RHS和返回方向的
每项10字节有效80位内容也全部相同，忽略另外6字节填充。这项检查支持观察器
没有改变所采首次耦合轨迹，不能外推到所有偏压或全部缓存阶段。
