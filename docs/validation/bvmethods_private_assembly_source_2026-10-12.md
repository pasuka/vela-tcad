# BVmethods 私有实际装配源与完整 RHS 对照（2026-10-12）

本轮已把已识别的 VO 过渡、代表顶点局部迁移率取样及元素顶点盒支撑接入
**私有实际残差装配**。逐元素源与装配源闭合至约 4e-16，分项和与实际载流子残差逐值一致。
源选择已真实改变 RHS；完整残差仍未对齐，因此不进入导数、Newton 更新或 Q4 轨迹验收。

## 1. 配置、入口与独立性

BVmethods NMOS 原网格：2600 节点、5020 三角形、26 个钝角；Si region 3 的 4156 单元、
2152 节点。300 K、R=1e7 ohm*um。保留 Fermi + OldSlotboom、Masetti + Enormal +
GradQuasiFermi HFS、SRH(DopingDep)、E2 BTBT、VO Eparallel 的固定态。

只复制现有 C++ 源至 ignored build-release 目录，重编私有 CoupledDDAssembler、NewtonSolver
并链接上一轮有效带边 SG 私有对象；生产 C++、默认、参数及门限未改。
新增 `scripts/bvmethods_private_element_source.h` 是未被任何生产 CMake target 包含的诊断核，
固定适用于本次 300 K／原物理系数。它在选定的 double 或 long double 路径中保留 reference
和 increment 分别相减的操作数，再计算有效带边 SG、二维代表电流、边界投影、非负 Eparallel
和 E0 ±5% 升余弦 alpha 混合。经验 pi=3.141592654 仍仅为版本指纹，不断言厂商源码。

实际 `residualImpl` 与 `carrierContinuityTermDiagnosticsImpl` 两处均接入相同控制。
原生人口作为固定态对照明确注入这两条路径，其他项继续由 Vela 计算。
人口控制与源控制分开，包含 off、population_only、double、extended 四臂；
近零态另外复用上一轮节点参考和公共参考两个 QF 控制。每台机器共 18 次探针：16 次载流子／SG
及 2 次显式同人口 Poisson 实际残差导出；Vela 非线性更新为零。

**独立性边界**：ψ、人口及实际 packed reference/increment 用于独立重算 J 和 F；
代表身份、该代表局部 µ、元素顶点 Measure 仍来自此前独立原生追踪。
没有把原生 G 或 J 直接写入装配器，也没有重新匹配最小误差身份。
这不认证生产迁移率取样或生产输运散度已一致。

## 2. 确认控制确实影响实际装配

初版私有控制只替换了备用源分支；现有 solved-equation 探针实际强制走 SG 雪崩源，
因此该版虽导出正确逐元素结果，装配源仍旧。失败源码、local_v1、analysis_v1 和 C560 v1 结果保留。
修正为在两条实际路径选择源时优先应用私有控制，再完成本机和两平台 v2 运行。

- 关闭控制时，近零 terms、SG、populations 三份输出均逐字节复现此前封存结果。
- 两条实际路径逐元素 J、F、alpha、G 完全相同；由 G*Measure、明确 TCAD 单位及 C0/D0
  独立计算的装配源与实际分项相对 L2 不超过 4.2e-16。接触替换后的源按实际边界归零。
- 全 2600 行载流子分项和与实际 residual 逐值相同；全 4156 Si 元素、2152 Si 节点保留。
- 输入状态在各源臂保持相同，接触边界项保持不变。QF 经实际 packed 缩放后与原生绝对值
  最大差约 6.94e-18 V，逐元素原始 reference/increment/drop 全部保留；未将其误称为无舍入。

## 3. 固定态源与弱电流

以下为 double 路径；long double 给出同量级结果。电流仅比较实际原生回调记录的向量，
未回调元素的电流是未观测量，不能当作零。全部元素仍参与预测及源积分。

| 状态／载流子 | 有原生记录的 J 相对 L2 | 节点内置 G 相对 L2 | 实际装配源积分闭合 |
| --- | ---: | ---: | ---: |
| 编码／电子 | 1.32e-15 | 3.83e-14 | 3.37e-16 |
| 编码／空穴 | 8.08e-16 | 2e-14 | 3.69e-16 |
| 近零／电子 | 5.22e-08 | 7.05e-08 | 3.65e-16 |
| 近零／空穴 | 3.92e-05 | 1.03e-08 | 3.83e-16 |

所有已记录原生方向均未发现与私有电流的反向翻转，也未在原生无回调单元引入正源。
这不能证明所有未记录向量的方向一致。逐元素误差、方向翻转 CSV（零条也有表头）及弱行明细均保留。
近零电子未加权力的差异仍约 5.47%，空穴约 6.79e-5；总源接近不能覆盖这些弱电流差异。
节点参考臂未消除差异；公共参考臂电子节点源相对 L2 约 3.66e-7，略差于原操作数路径。
仅把本次算术扩展到 long double 也未明显改善，仍需定位上游舍入／取样／支撑。

## 4. 同精度原生完整 RHS

旧完整矩阵参考来自双精度 Load；其 ψ 与本轮最大差 3.43e-14 V，人口相对 L2 约 2e-13，
不能直接代表本轮相同近零状态。保留旧比较，另在 VM 新目录复用本轮相同 seed、网格和
等效原 HFS，使用 T-2022.03-SP2、ExtendedPrecision 80-bit、DensityIntegral(240)，
对完整、无雪崩、无 SRH/BTBT 三臂执行 `sdevice -d` 的单次迭代探针。
三臂均退出 2，日志明确为 `#iterations larger than 1`；这是显式预算终止，不能记为求解通过。
采用其更新前首轮 RHS；原生线性方法 blocked decomposition，非线性 Bank/Rose。

三臂首态 ψ、n、p、电子／空穴 QF 与本轮固定态逐值相同，各消融臂之间也相同。
166 个下载文件全部通过 SHA-256 复核。原生完整减无雪崩 RHS 与原生 Plot 源乘盒支撑闭合：
电子相对 L2 7.75e-11、空穴 3.09e-13；分别标记 1126、1244 个大于 64 ULP 的可分辨行，
其余行保留，不以筛选消除弱行。

载流子物理换算使用一个全局、非拟合的单位系数：
`F_vela = -RHS_native * ND*1e4/(C0*mu0*V0)`。
ND 由同首态人口／debug 密度变量独立验证为 14824351000 cm^-3，两载流子一致，
比例散布小于 5e-15；C0=5.09e20 cm^-3、mu0=1417 cm²/(V s)、V0=.025851999786435535 V。
系数约 7.950490318918128e-9。另保留此前固定左对角尺度对照，不能将其误称为物理误差门限。

每载流子保留全部 2121 个共同自由行；下表为同单位的相对 L2：

| 载流子 | 原源完整残差差 | 新源完整残差差 | 输运散度差 | 新雪崩积分项差 | SRH/BTBT 等差 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 电子 | 11.0538 | 11.0534 | 11.0534 | 2.81e-07 | 0.0157022 |
| 空穴 | 0.183757 | 0.00569371 | 0.00569311 | 2.81e-07 | 0.0157022 |

空穴完整残差差从约 18.4% 降至 0.57%；电子差仍明显。参考本身是近零残差，
相对数不等于 IV 或物理场误差，不用作新增验收门限。
新源完整残差绝对差 L2：电子约 2.925e-9、空穴约 9.842e-15（Vela 连续性无量纲行单位）。
节点 G 和积分 RHS 使用不同盒权重，故 1e-8 级节点源误差与 2.81e-7 级积分源误差并不矛盾。
旧空穴 node 152 的主要错误源项被消除后，固定左尺度最大余差位置转至 node 409；
电子仍为 node 784。全部逐行分解以及 node 152/784 的专项记录在配套 JSON／CSV。

Poisson 的 2522 个共同自由行也未对齐：此前固定左尺度的相对 L2 约 7.95%，
绝对差 L2 约 1.437。该数与载流子表尺度不同，不能混用。
补充同人口控制后，此处实际 Poisson residual 使用显式原生人口，分项观察器仍用原反算人口，
因此二者约 1e-10 的绝对闭合差保留为观察器边界，不声称分项逐值一致。
