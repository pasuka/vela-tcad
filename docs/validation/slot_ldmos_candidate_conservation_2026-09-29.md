# SLOT 候选守恒检查与严格重闭合（2026-09-29）

## 结论

已实现默认关闭的冻结候选守恒检查，并在本机串行完成归档复验及一个完整
外电阻小步验证。候选守恒通过与否均不能替代严格器件重闭合。
原始失败候选的电子失配复现为 **30.1766%**；修正外推配对后的候选仍为
**4.6710%**。严格重闭合后，两类载流子全局闭合、全部有效行及负载线确认通过。

本批是守恒检查的功能验证，不是新的高压长扫描或击穿判据达成。

## 实现及口径

- 新增 `NewtonSolver::evaluateFrozenGlobalContinuityClosure`：冻结保存态的
  准费米势参考场及 increment，包含接触节点；采用未作 Dirichlet 替换的
  物理连续性项。电子/空穴接触集合取实际边界条件，不把所有命名接触一概计入。
- CLI 类型 `newton_candidate_conservation_probe` 写 JSON；使用原始
  `global_continuity_closure.mode=enforce` 和原容差。进程成功仅表示诊断完成，
  `satisfied` 表示守恒检查结果，`device_qualified` 恒为 false。
- `--candidate-conservation-runner PATH` 为 SLOT campaign 显式选项，默认关闭。
  诊断可执行文件、协议、脚本及物理输入纳入身份和哈希绑定；检查输入执行前后
  一致，校验结果有限性、协议、门槛及判定算术。证据/环境异常不会伪装成守恒失败。
- 检查位于原始耦合候选生成后、多晶硅恢复前，外推路径和父态回退路径均覆盖。
  守恒失败标记为 `conservation_failed_repair_required`，保留证据及初值，
  随后执行原有严格固定内压重闭合。候选电流不作为返回的合格电流。
- 即使候选守恒通过，也必须通过完整 Newton、全部有效载流子行、全局闭合、
  文件绑定和独立负载线确认；没有新增绕过最终资格的路径。
- 原耦合 IV 文件中的占位闭合字段未被改写。新的独立 JSON 是候选检查证据，
  原占位字段仍不能作为资格证明。

通量/源/失配字段使用装配器连续性单位，不是 A/µm；闭合比为无量纲。
相对分母为 max(|接触通量|, |积分源|, source_floor)，低源项时沿用绝对判据。
本次相对容差 0.01、source_floor=1e-11、绝对容差 1e-12，均未更改。

## 归档冻结对照

最终证据：`build/s29conserve/v2/frozen_summary.json`，各子目录保存 config、
result、summary、stdout/stderr 及绑定。比值如下（不是百分数）：

| 状态 | 电子闭合比 | 空穴闭合比 | 守恒检查 |
|---|---:|---:|---|
| a0080 合格父态 | 8.95854e-13 | 6.75872e-13 | 通过 |
| a0081 原始候选 | 0.301766 | 1.32317e-13 | 未通过 |
| 同候选多晶硅恢复后 | 0.301766 | 1.32466e-13 | 未通过 |
| a0081 严格态 | 3.76826e-6 | 6.10235e-15 | 通过 |
| 上批修正外推后的候选 | 0.0467103 | 4.22769e-9 | 未通过 |

这验证了守恒失配确实存在于候选态，且多晶硅恢复未消除该失配；没有据此
认定浮点噪声、物理微分电导或整个 Jacobian 的具体错误机制。

  **12 个测试、298 条断言通过**。新增用例覆盖两类载流子接触低于绝对值 ULP 的
  increment、实际通量非零、失配识别和输入不变。

  `test_slot_loadline_step_control`、`test_slot_bounded_recovery`，**46/46 通过**。

## 后续边界

该检查约增加一次 2.6 s 的冻结装配，未证明能够减少候选失败或加速扫描。
下一步可在少量更高偏压父态检验修复成本及成功率，再决定是否调整候选算法。
当前仍使用部分原生几何，不宣称完整模型独立性或 BVDS 验证完成。
本轮全部串行作业已结束，没有重启长扫描、T470p 仿真或定时监测。
