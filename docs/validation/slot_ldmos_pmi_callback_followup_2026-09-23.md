## 幅值与接触分支

手册 1260 页给出 `currentWoMob` 的单位为 A·V·s/cm^4，同时建议
模型只使用其方向。此次在固定 300 K、零参考密度配置独立核对幅值：

```text
D = 2*n_min*n_max/(n_min+n_max)
currentWoMob = -q_eff * D * grad(phi_qf)
q_eff = 1.602192e-19 C
```

非接触界面层使用切向梯度；接触元素保留完整梯度，alpha 的驱动场
仍可回退到电场。不能混同 alpha 驱动场与产生率所用电流。

`q_eff` 是此次回调反映的有效单位比例，未从公共头文件读得，也未修改
Vela 的 SI 常数。用现代 SI 电荷重构时约 9.59 ppm 的系统差异，
用仓库旧 PN2D 对照常数 1.6021918e-19 时仍有约 0.125 ppm 差异。
上式比例得到本次大量回调及两种源项回放的支持；不将它推广为所有
Sentaurus 版本或所有物理接口的统一常数。

接触/界面重叠元素 3177、21242、24271 的回调直接排除了统一切向
投影。使用完整梯度后，全部 10,960 条空穴向量的最大相对差为
5.923e-13；电子 99% 分位为 2.460e-13。电子有 10 条接触回调仍超过
1e-6，最大 1.607e-4；它们的保存态准费米势均接近 10 V，而顶点间
差仅 1.776e-15 或 3.553e-15 V。全部差异位于保存双精度准费米势的
半 ULP 经梯度矩阵传播所得误差界内。这与保存态精度限制相容，不能
据此证明它是唯一原因，也不能声称这十项达到机器精度。
