## 材料派生链：已确认的换算差异

参数为 `Eg0=1.16964 eV`、Varshni `Eg(T)=1.1241592307692307 eV`、
`dEg0(OldSlotboom)=-0.01595 eV`。原生导出的 `BandGap` 为
`1.1082092307692308 eV`；掺杂相关 `BandgapNarrowing` 单独导出。

电子 DOS Formula 1 的横向质量使用 `a × Eg(0)/Eg(T)`。原生结果对应：

```text
mt = a × (Eg(0) + dEg0) / (Eg(T) + dEg0)
me/m0 = [(6 mt)² ml]^(1/3) + mm
```

当前转换器 `scripts/vela_sdevice/materials/__init__.py:evaluate_semiconductor`
先用未加 `dEg0` 的带隙求电子质量，之后才将其折入 ni 指数项，因此少了这条影响链。
已有 `test_sdevice_materials.py` 的闭式期望沿用了同一假设，不能当成原生一致性证据。

| 300 K 材料量 | 当前转换（CODATA） | 原生直接导出/推导 |
|---|---:|---:|
| Nc，cm⁻³ | 2.856679145191179e19 | 2.858252007386657e19 |
| Nv，cm⁻³ | 3.104657033455896e19 | 3.104628932474839e19 |
| 不含掺杂 BGN 的 ni，cm⁻³ | 1.463489815323541e10 | 1.463880541255885e10 |

隔离使用旧常数及修正后的质量公式得到 `Nc=2.858252006826842e19 cm⁻³`、
`ni=1.463880540969170e10 cm⁻³`，距原生约 `1.96e-10`；没有拟合接触 QF 偏移。
进一步使用原生直接导出的 Nc/Nv/BandGap、由 Boltzmann 公式计算 ni，作为材料 oracle，
用于隔离剩余装配问题；这不等于完成生产转换器修复。

主零偏对照中接触 QF 约束最大偏差：原配置约 `6.97224 μV`，质量公式加旧常数控制
约 `5.06e-12 V`，原生派生材料 oracle 约 `1.11e-15 V`。因此此前主要接触偏差有
明确材料来源，不能归因于初始解或通过任意 QF 平移掩盖。

## Jacobian：剩余差异来自迁移率离散取样

下表为主零偏同态下，各块按自身对角归一化后，最大行相对 L2 差。

| 控制 | Poisson | 电路 | 电子 | 空穴 |
|---|---:|---:|---:|---:|
| PN2D 总杂质配置，原材料/常数 | 2.31e-12 | 2.80e-11 | 4.66076% | 3.04510% |
| 原生材料/常数，保留原边平均及高场模型 | 4.66e-14 | 8.31e-17 | 4.66077% | 3.04510% |
| 单元平均总杂质后求迁移率，隔离控制 | 4.65e-14 | 9.87e-17 | 2.16231% | 1.18207% |
| 节点迁移率按单元 box 体积及边系数加权，**低场隔离** | 4.65e-14 | 2.11e-16 | 3.60e-14 | 3.78e-14 |

“对杂质浓度求平均后计算迁移率”与“先在各节点计算迁移率、再按几何权重平均”不等价。
最后一行使用现有 `masetti + element_box`，并要求 `cell_material` 几何和
`element_box` 输运；**它没有保留完整高场路径，不能作为同条件全模型验收结果**。
它只确认低场取样/平均契约足以解释这组零偏载流子矩阵差异。

直接冷启动 index 0 的对应低场隔离差为电子 `1.05e-14`、空穴 `1.10e-14`。
外压仍为零的 index 1 已有显著非平衡 RHS；保留高场模型、原导数设置、对齐材料后，
电子/空穴矩阵最大行差仍达 `1.31 / 2.24`，RHS 相对 L2 差约 `0.332 / 0.205`。
单独打开现有高场 Jacobian 导数没有使其一致。因此低场结论不能外推到全部零偏迭代。

## RHS 与外来 Newton 方向：尚未通过

所有 RHS 差均在相同人口坐标、5762 维及等价行操作后，按各自对角归一化计算。
主对照原生电子/空穴 RHS 的 L2 范数约 `7.30e-9 / 8.18e-9`，本身已很小。

| 主零偏控制 | 电子 RHS 差 L2 | 空穴 RHS 差 L2 |
|---|---:|---:|
| 原材料/常数 | 1.87528e3 | 1.87528e3 |
| 修正质量公式、旧常数 | 1.36192e-3 | 1.36192e-3 |
| 原生派生材料 oracle | 3.42948e-6 | 4.09859e-6 |

oracle 将主要偏差降低约九个数量级，但剩余差仍大于上述原生近零 RHS；这里不以
增大分母下限宣布通过，也不在缺少误差传播界时将全部剩余差认领为舍入。
冷启动 index 0 的 oracle Poisson RHS 相对差为约 `4.38e-15`；电子/空穴 RHS
差仍约 `7.47e-8 / 8.96e-8`，其原生 RHS 接近零，需单独处理序列化及装配精度。
index 1 的有限载流子 RHS 明显不一致，证明不能只凭平衡态接近零就认可完整算子。

脚本还将 Sentaurus 实际 Newton 方向代入 Vela 线性系统，报告逐分量后向误差。
当前配置不满足 Vela 线性闭合要求。**原生 J/RHS 能求出原生方向，不代表将其直接
移入 Vela 就满足线性或非线性收敛要求**；尚未进行生产迭代替换，也未取得其资格。

下一步仍限定零偏：以完整高场模型建立节点—单元—边的迁移率和导数契约，使用
有限 RHS 的零偏迭代检验；同时量化 debug 状态序列化误差对近零 RHS 的传播。
完成 J、RHS、方向写回及物理接受的对照后，才恢复外压步进。
