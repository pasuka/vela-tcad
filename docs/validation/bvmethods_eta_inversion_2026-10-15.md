## 原生反算及停止条件

目标路径为 η 数据入口 → 多谷材料统计对象 → `diraci` 初值 → 积分正向值／导数 →
对数密度形式的 Newton 修正。电子包含 3 个谷，空穴包含 2 个谷。
`diraci` 是本路径的初值，不能将其返回直接当作最终 η。

| 项目 | 观测 |
| --- | --- |
| 每个电子端点 | 3 次材料正向值／导数评估 |
| 每个空穴端点 | 1 次材料正向值／导数评估 |
| 实际相对 η 更新停止阈值 | 约 1e-9 |
| 电子 2156 基准最后接受的 η 更新 | 约 +3.82352e-12 |
| 电子 2156 基准最后停止比值 | 约 4.71e-13 |
| 空穴 2515 基准最后接受的 η 更新 | 约 −4.73146e-16 |

原生先接受最后更新，再返回 η。实际停止比值由更新幅度及局部 η 尺度构造；
它不是目标人口相对残差。最后评估发生在更新之前，不能把其人口残差当作返回 η 的人口残差。
本轮逐位核对停止点的返回 η 与实际写入值。

## 积分定义及权重表示

实际积分使用 240 点、α=1/2 的广义 Gauss–Laguerre 表。两种载流子、五态共十份表逐位相同。
在已采集的参数和等温抛物线控制下，独立重建其正向核为：

```
F(η) = C × Σ w_k / (exp(−x_k) + exp(−η))
```

其中原生 C 为约 1.12837916709551255856；使用采集的节点、权重及 C，
五态全部 385 个实际积分函数返回值的最大相对差约 2.67e-19。
这是**采集表条件下**的核重建，不是自主生成原生积分表。

新增[独立广义 Laguerre 统计审计](../../scripts/bvmethods_laguerre_statistics_audit.py)：
NumPy 特征值只提供初猜，100 位 Decimal 用 Laguerre 多项式及导数逐根细化，自主生成归一化权重。
不导入原生表或拟合原生结果。独立定义积分仍由既有 Boost 100 位 Gauss–Kronrod 程序提供；
本轮新增 36 个正向查询，积分误差估计相对小于 1e-32，已有 18 个人口比值的反算参考继续复核使用。

| 原生表与自主 240 点表的比较 | 结果 |
| --- | ---: |
| 原生归一化权重总和减 1 | +3.87502e-15 |
| 节点最大绝对差 | 2.97713e-17 |
| 归一化权重最大相对差 | 7.23990e-14 |

未将原生权重强制归一化，也未向 η／QF 添加经验修正。
原生运行始终使用 240 点；480 点仅作为独立离线收敛控制。

## η 误差分解

令 η_math 为定义积分的根，η_240 为自主高精度 240 点积分的根，η_table 为采集表及 C 的根。
四者使用完全相同的人口／有效 DOS 比值，各自严格反算同源正向算子：

```
η_native − η_math = (η_native − η_table)
                  + (η_table − η_240)
                  + (η_240 − η_math)
```

| 五态各项最大绝对值 | 数值 |
| --- | ---: |
| 原生 η − 定义积分 η | 1.54271e-14 |
| 原生 η − 采集表严格根 | 1.84493e-18 |
| 采集表根 − 自主 240 点根 | 2.08334e-14 |
| 自主 240 点根 − 定义积分根 | 3.61783e-14 |
| 自主 480 点根 − 定义积分根 | 1.93890e-20 |

这些最大值可能来自不同端点，不能直接相加。
电子 2156 基准的三项分别约为 −1.845e-18、−2.07840e-14、+2.89812e-14，
合计 +8.19537e-15。空穴 2515 的有限阶积分项约 2.77e-52，采集表表示项约 −3.96095e-15，
停止／求值项约 +1.17e-20。

以独立定义积分评价最后原生更新，
`(F_native_last − ρ + F_math_returned − F_math_last)/ρ` 最大约 9.48e-20。
这是同一最后评估／接受更新的差分控制，不冒充对返回态原生积分函数的再次调用。
上述表根分解与正向控制共同表明：本批主差异来自有限积分与权重表示，
仅收紧停止阈值不足以对齐两条近零弱行。扩展精度舍入及 `logl` 仍需分别保留。

## 自主候选的基准及非零方向

从真实人口／DOS 自主反算 η，再按上轮确认的逐次 binary80 比值／数学 log／Γ／a 组合和
成对 Bernoulli 级数计算。没有使用原生 η、a 或 B 替代自主候选；几何／κμ 保持旧固定态控制。
另列采集表严格根，作为依赖原生表的诊断控制。以下弱行差相对同顺序的原生 B 求和，
不是终端电流或完整 RHS 验收结果。

| 基准候选 | 电子 2156 相对差 | 空穴 2515 相对差 |
| --- | ---: | ---: |
| 定义积分严格根 | −2.56223e-1 | −1.92411e-5 |
| 自主 240 点严格根 | −4.64095e-4 | −1.92411e-5 |
| 自主 480 点严格根 | −2.56223e-1 | −1.92411e-5 |
| 采集 240 点表严格根（条件控制） | +2.47776e-4 | −2.47577e-5 |

480 点更接近定义积分，但不会自动复现原生 240 点有限积分及其表示。
采集表的严格反算根也不能替代原生逐步舍入的接受值；本批近零电流对 1e-18 级 η 差仍然敏感。

e/h ±1e-12 V 控制中，自主 240 点目标 η 响应的相对差约 −4.58e-9／−7.15e-10；
各载流子 12 条元素边的可分辨参数响应最大相对差约 1.37e-8／0，
固定系数弱行响应差约 −1.13e-8／0。可分辨性要求仍为超过 1024 binary80 ULP，
仅用于方向控制，不替代既有验收门限；空穴本批舍入后响应相同也不代表全部导数已经认证。
**方向接近不能代替基准通过，三个自主候选均未取得完整 SG／RHS 资格。**
