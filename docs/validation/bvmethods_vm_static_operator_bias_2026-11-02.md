# Vela VM：原生首五点Jacobian与RHS偏差的系数定位（2026-11-02）

本轮已把首五点静态偏移的主要来源缩小到**Poisson电荷/介电系数组合，以及DOS/热电压/本征浓度的跨工具统计约定**。它们同时解释了n+区的净通量、表面少子修正，以及经AV切线放大的主要矩阵差异。不是继续把接触目标或SRH导数单独列作原因。尚未唯一反推出原生内部使用的各个绝对物理常数，也未提出可直接采用的生产参数修复。

所有实际装配在vela VM的独立目录完成，复用修复核心；只读已有U-2022.12原生归档，无新Sentaurus。生产源码、材料、物理模型、门限、40轮预算、保护规则和夜间T1/T2/T3/A1e/T4计划均未修改。诊断材料副本中的参数替换明确属于反事实，不称为原生产模型不变的效率对照。

## 1. 先排除单位映射误差

原生debug的VAR+SOL与独立NewtonPlot实际post态核对：五点电势最大差约1.33e-15 V；每点电子、空穴各2121个自由人口，浓度相对差最大5.11e-15。原生VT=0.025851995266484913 V、CN=14824351000 cm⁻³的转换没有产生9 ppm浓度比例误差。没有以重新拟合坐标尺度消掉残差。

## 2. 只由Jacobian识别系数，不用RHS调参

对低扰动邻接载流子列提取局部比值，消去公共行缩放、几何和迁移率幅值。人口坐标下，电子取 `−n J(row,n)/J(row,ψ)`，空穴取正号；近平衡输运对应 `VT·r·η′(r)`。保留条件和原始逐行结果见ignored脚本及JSON，不将此恒等式无条件用于含显著源/迁移率响应的所有行。

只用p02_i03的97个电子节点、344个空穴节点识别DOS，VT由原生归一化与独立人口切线共同支持。RHS、更新RMS和其余四个偏压点均未用于识别。

Poisson比值在p02_i03全部2121个可比半导体自由行一致，最大到最小散布约1.73e-14。它严格识别的是电荷源与介电通量的**有效系数组合**：不能只凭该比值判定q、ε0、εr、源体积或长度约定中的某一项。将所有εr在独立材料副本除以该比值，五个i03帧的行归一化Poisson矩阵差都降至约2.2e-15，提供跨点验证。

## 4. 主要矩阵差异通过AV被放大

五个i03帧中，按既定6765维共同自由系统、物理列尺度和各自对角行归一化口径，约99.989%–99.992%的矩阵差异平方范数集中于四个空穴行：229、1308、1546、2587。它们位于近表面源/漏侧，人口约200–300 cm⁻³，**不是1e-100下限节点**。

在p02_i03对六个空穴行、两列ψ做分项中心差分，步长1e-5到1e-10 V。四个主差项几乎全部来自AV；SRH的ψ偏导为0，输运响应小得多。步长到1e-10 V时差分/Full切线比约0.999978–0.999989，随步长缩小表现出截断误差下降；较大的1e-8 V尚有约10%–17%差，因此不能用过大的差分步直接判Full导数错误。本轮为binary64多步长检验，不冒称高精度全行严格证明。

进一步直接装配AV分项，原参数下源项与生产诊断逐位闭合，最大差为0。AV系数、迁移率、网格与人口不变，只用识别的DOS/VT及一致ni重新构造QF关系和相应人口切线，再替换同一冻结矩阵中的AV分项。不是Full减大项后重建微弱矩阵，而是直接取得两份AV装配。

源码中AV使用 `αn(E)·µn·||jn|| + αp(E)·µp·||jp||`，驱动场和粒子流都依赖QF。实验证明这些微小统计系数差足以显著改变受检AV切线；不能据整体矩阵差较大就认定SRH导数仍错误。

## 结论边界与执行核验
