# SLOT LDMOS IdVd 收敛问题技术交接

日期：2026-10-06。用途：交给未参加此前讨论的大模型或数值仿真研究人员，辅助分析物理映射、局部载流子行、网格和 Newton 全局化问题。

## 1 需要解决什么问题

Vela 是 C++20 的二维半导体漂移扩散与 Poisson 求解器。本算例使用与 Sentaurus 相同的 SLOT LDMOS 网格，目标是在 Vg=5 V 下完成 Vd=0～60 V 的 IdVd 扫描，并核对电流与内部物理量。

目前原物理配置的最新合格诊断点为 **Vd=2.3683165070229464 V，Id=2.5430367196428835e-4 A/µm**。门压建立路径已完成，60 V 漏压路径尚未完成。固定偏压处能出现整体残差、全局电流闭合很好，但局部连续性方程行不合格的情况；继续推进常消耗大量线搜索和缩步成本。

最近发现接触邻域碰撞电离系数 α 的驱动场映射存在重要差异。独立开启接触电场回退后，源侧空穴显著恢复，但三次有界重求仍未取得完整合格态。最后诊断态有 **30 条行超标，最大行比 1.74683，原门槛 0.001**。

请围绕以下问题给出可证伪、按成本排序的诊断建议：

1. 接触源映射修正与局部弱行病态之间有什么可检验的联系？
2. 为什么整体残差下降、全局闭合通过时，局部行比和物理场差仍可恶化？
3. 逐分量限幅、Poisson 重修正、全局闭合投影、merit 线搜索是否存在相互干扰？
4. 两个轻微钝角单元是否真正影响了当前装配权重，如何隔离几何因素？
5. 下一项最低成本且最有辨别力的实验是什么？

**当前不是 BVDS 外接电阻扫描。** 本问题没有外压负载线，没有 36 V 原点平移，也没有 1e-7 A/µm 的击穿判据。旧 BVDS 恢复经验不能直接视为本 Fermi/PhuMob IdVd 组合的验证结果。

## 3 算例和模型

- 网格：13,881 节点、27,275 三角形，其中 24,272 个 Si 单元。原生节点与 Vela 坐标逐值对应，比较不涉及空间插值。
- 本文重点工作点：Vg=5 V、Vd=2.3683165070229464 V、Vs=Vb=0 V、300 K。
- 区域：`Silicon_1` 为 Si；`Oxide_1` 为 SiO₂；独立 PolySilicon 与 Nitride 区域。栅下 p 体区的实际掺杂来自逐节点掺杂文件，不应拿配置中的区域平均值代替。
- 模型：Fermi 统计、Bennett–Wilson 带隙窄化及 Fermi 修正；Si PhuMob、Lombardi 和准费米梯度驱动的高场饱和；Si SRH/Auger、van Overstraeten 碰撞电离；PolySilicon 独立常迁移率材料分流。
- 原生：Sentaurus T-2022.03、ParDiSo、5 线程。Vela：Windows UCRT64 Release、HDF5、UMFPACK、binary64。
- 单位：物理坐标 µm、电流 A/µm；HDF5 物理密度 m⁻³，原生节点 CSV 密度 cm⁻³。本配置的内部密度使用 cm⁻³。

## 4 行比和求解策略的准确含义

对有效载流子连续性行，当前代码按以下形式计算尺度与比值：

```text
S_i = max(abs(fluxAbsSum_i), abs(recombination_i), abs(impact_i), 1e-30)
rho_i = abs(residual_i) / S_i
要求 rho_i <= 0.001
```

以上量必须使用同一装配单位和同一载流子行口径。`fluxAbsSum` 是诊断器返回的通量绝对值和；它不能直接充当浮点误差界所需的“所有最底层相消前操作数绝对值和”。活动行还经过连续性有效性及密度/源/通量资格筛选。当前密度下限参数为 1e-200，不应擅自删除弱行。

`0.001` 是工程验收门槛，不能解释为每个节点密度相对误差小于 0.1%，也不与 Sentaurus 的 Digits/ErrRef 一一对应。原生本批 Digits=5、RHSmin=1e-10、ErrRef(e/h)=1e10。

`local_ad` 表示所选电离源核的局部自动微分，不能宣称全系统由符号代数精确推导。局部测试通过也不能代替当前失败态、完整模型组合和主导方向上的 Jacobian 检验。

整体范数是求解器的缩放/归一化指标，不等于每条物理残差的最大值；独立重启可能改变归一化基准。下面不同进程的范数不要直接拼成一条连续收敛曲线。

## 7 接触电场回退的冻结对照
