# BVmethods N4：2693谱增量、输运分项及RHS一致方向候选

日期：2026-10-18。承接[源精度、分块与耦合检查](bvmethods_n4_ordered_closure_2026-10-18.md)。
统计见[JSON汇总](bvmethods_n4_kernel_linear_candidate_2026-10-18.json)。

本轮将2693的小步长源误差定位到占据／谱率增量的有限精度求值，并分离出n块10条差异的输运变化。
打印系统经过独立行列缩放与迭代改进后通过线性门；使用候选自身RHS重求的方向改善三个残差块、负载及KCL。
但部分弱行的绝对残差仍变大，尚未完成自主Jacobian和实际求解器接受循环。
N4继续，N5未开始；生产源码、模型默认、门限和发行包未改。

## 配置与边界

保持安装库T-2022.03-SP2原版BVmethods物理、300 K和1e7 ohm·um固定外电阻。
2600节点、5020个Tri3，其中4156个Si单元；6843维增广系统，人口参考14824351000 cm^-3，电流A/um，内部源SI。
本地Ubuntu 26.04.1、GCC15.2、C++20、Release O1、禁用浮点收缩，沿用私有MPFR binary64标量环境。
复用已有HDF5／UMFPACK／SPQR／METIS构建；C++状态求值没有调用线性后端。
独立方向控制使用SciPy SuperLU，作用于封存的原生显式非局部导数打印矩阵；本轮没有新增Sentaurus作业。
因此该方向控制不等于Vela已经实现自主完整Jacobian。

## 1. 保留原始输入，重放2693的谱增量

在已绑定正QS人口上，只扰动电子446，保留原已验证的初始reference。
对0和五档双向扰动采集种子2693的31次谱求值、16个接受区间、两端权重、实际节点带状态、路径插值及占据操作数。
两版观察器共22次筛选求值，实际人口、源和事件结果逐值相同；与此前完整源中的2693贡献也一致。
筛选源继续被完整装配覆盖门拒绝，没有用它替代完整RHS。

采用80位十进制独立重放三层控制：

1. 保留实际binary64端点en／ep，提高占据及谱率reference/increment的求值精度。
2. 在上述基础上，提高路径内准费米能插值精度。
3. 再提高节点到路径的带权准费米能取样精度。

几何、带边、端点位置、积分区间和两端权重均保持原值。
每个接受事件以自主实际基准率为reference，按高精度占据对数增量计算变化，避免先重新形成大绝对谱率再相减。
未用原生源率拟合比例或读取原生导数生成候选；原生矩阵方向只用于外部比较。

| 步长 | 旧完整源FD误差 | 保留原端点、改进占据／谱率增量 | 再改进节点及路径插值 |
| --- | --- | --- | --- |
| 3e-3 | 1.365e-6 | 1.406e-6 | 1.406e-6 |
| 1e-3 | 3.683e-7 | 1.562e-7 | 1.562e-7 |
| 3e-4 | 1.311e-6 | 1.439e-8 | 1.407e-8 |
| 3e-5 | 1.273e-5，失败 | 1.269e-9 | 1.626e-11 |
| 1e-5 | 6.822e-5，失败 | 1.139e-9 | 7.887e-12 |

三层控制五档均满足原1e-5方向门。仅提高占据／谱率增量精度已消除本控制的小步长超门，说明不能把主要误差归于路径拓扑或插值本身。
插值精度仍有可测贡献，但小于谱率绝对值形成及差分路径的影响。
该实验没有单独分离每次log、exp和最终窄化的全部责任。
原失败结果保留；80位控制只适用于本轮固定几何、固定其余系数的方向，不是可部署的任意扰动内核。

## 2. n块10条差异的变化来自输运

对上一轮h=1e-3时高于保守分辨估计的10条电子行，按实际SG、SRH、雪崩和NonLocalPath原始项分别求增量。
节点为1760、1900、1910、1928、1929、2004、2137、2237、2270、2271。
使用h=1e-3、3e-4、1e-4及实际坐标割线，不在分母加入经验下限。

从粗档到最小档的变化几乎全部由SG输运分项贡献；雪崩及NonLocalPath变化为零，SRH变化量约1e-21及以下。
例如节点1760，粗档完整FD与原生Jv的差约58.3438，输运FD从粗档到最小档变化约58.3451。
节点2237相应两量约114.7852和114.7808。
这解释了这些粗档超门随缩步移动的主要分项，排除了将其变化归给2693非局部源的解释。

原生逐物理分项Jacobian没有直接取得，因此不能据分项FD声称某个原生输运导数条目已被证明错误。
SG内部人口、Bernoulli和迁移率求值的非线性截断／舍入仍须继续分离；完整Jv没有因此通过。

## 3. 打印系统精度与独立线性控制

保留此前打印解回代的7条超门行及精确求和结果，最大约2.153e-9。
原始文本最多16位有效数字，但这本身不足以确认打印系统与原生内部求解调用的全部身份。
未把该回代失败自动等同于商用求解器内部失败，也未用其他系统的通过结果替换它。

对同一封存矩阵做独立SuperLU求解：未经缩放的控制即使迭代改进仍有弱行超门，失败保留。
加入行列缩放并使用逐行稳定求和的残差迭代改进后：

- 原生打印RHS：最大逐行回代误差约1.655e-16，0条超过1e-10。
- 候选实际RHS：最大约2.162e-16，0条超过1e-10。

未改变矩阵条目或门限，缩放后结果映射回原坐标检查。
这证明该打印系统存在满足工程线性门的方向；没有据此反推原生内部容差或打印格式的唯一责任。

## 4. 使用候选实际RHS后，块指标改善，逐弱行尚未证明

新的私有方向控制保留参考矩阵，改用自主候选在同一状态实际计算的RHS，避免直接沿另一套微小残差的解向量更新。
执行基准、完整、半步及四分之一步四次完整增广求值；另对完整步做两次不同状态版本重放，残差和双源逐值一致。人口、源身份和守恒通过。
没有将参考矩阵称为自主Jacobian，也未执行实际C++ Newton接受循环。

完整步相对基准：

| 项目 | 结果 |
| --- | --- |
| Poisson残差L1 | 0.06480倍 |
| 电子残差L1 | 0.995996倍 |
| 空穴残差L1 | 0.373517倍 |
| 负载绝对误差 | 1.2925e-7 V，通过1e-6 V门 |
| KCL绝对误差 | 1.2511e-14 A/um，通过原门 |

半步、四分之一步的电子残差反而增大，未据缩步自动判定更安全。
重点电子2156和空穴1317的绝对残差改善，但空穴2515由约0.009438增至0.011492，2423／2432也有增大。
这些行的绝对装配项尺度差异很大，例如2515约1.465e11，必须连同尺度解读，不能只看残差比值。
也不能把同态RHS比较的1e-8门直接当成所有非线性行必须逐步单调下降的规则。
当前能认领的是块L1、负载与KCL共同改善，尚未证明逐弱行和实际求解器接受契约通过。
