# SLOT 从本地平衡态开始的外电阻扫描

本任务接续新输运配置的 BVDS 判据对照，目标是用同一配置补齐从 0 V 到
`|Id|=1e-7 A/µm` 的可重复路径。当前是执行记录，不把已启动等同于完成。
高压既有结果见 [BV 支路报告](slot_ldmos_native_transport_bv_branch_2026-09-26.md)。

## 顺序与验收

1. 固化冷启动、外电阻候选、独立器件复验、负载线确认和恢复入口。
2. 新配置从本地 Poisson 平衡态起算；全程外电阻 `1e12 Ω·µm`，300 K，
   其余物理端子 0 V。首次 Poisson 解仅为候选，须完整 Newton 与局部审计。
3. 完成全曲线同内压/同电流对照及判据附近有限精度敏感性实验。
4. 验证本地几何生成，另开展更远的击穿后扩展；不能替代前三项的验收。

使用原网格 13881 节点、24272 个 Si 三角形、36681 条 Si 输运边。
当前受控配置依赖原生导出的输运边系数、IALMob 几何和雪崩几何；
“不使用原生保存态起算”不等于“已经摆脱原生几何数据依赖”。

## 可复用入口

仓库配置为 `configs/regression/slot_ldmos_native_transport_bv_control.json`，
物理参数及全部资源哈希与既有高压基准一致，使用相对资源路径。
它是外电阻驱动的独立器件复验基准，不应把其中 `external_circuit.enabled=false`
理解为整条路径无电阻；驱动负责标量负载线闭合或启用耦合电路候选。
当前正在运行的目录仍冻结此前基准文件，未在运行中替换输入。

`scripts/run_slot_ldmos_bv_campaign.py` 接收显式基准配置和 Release runner，
冻结资源及辅助工具哈希。每次仅执行一个子进程。低压使用已审计的 Python
标量负载线控制器及独立器件恢复；38.4 V 以上外电阻耦合候选采用
`direct_bordered_qr` 优先策略，随后独立完整器件复验，必要时沿用有界
密度/QF 修正与受守护 Poly 恢复，再确认电路状态与器件状态一致。

最终门槛保持原设置：载流子行比 `1e-3`、全局闭合 `0.01`、
负载线残差不超过 `1e-6 V`，每类 12634 个有效载流子行。
候选通过和电路复用态的零残差均不提供独立器件资格。

低压标量控制求解提议外压，包围区间端点保护距离显式设为区间宽度的
`1e-6`，避免小电阻压降导致多次无必要二分；通用控制器原默认 `0.05` 不变。
高压外压为自适应坐标：记录提议外压，独立复验后按 `Vout=Vin+R*Id`
确认实际外压，保留二者差值。不能把实际坐标闭合写成提议坐标精确求解。
近零电流不使用相对增长限制；正电流超过 `1e-13 A/µm` 后要求增量
为 `(1,2]` 倍。失败缩步最多连续六次，不以不收敛认定击穿。

参考系转换同时变换状态与接触元数据，并独立重收敛；转换本身不授予资格。
恢复使用 `--resume`，输入/资源/工具哈希必须一致，所有已接受状态重新核验。
开发修正驱动自身时，可显式加 `--accept-driver-update`，只允许主驱动文件变化，
保留旧身份清单；runner、物理资源、辅助模块和判据变化仍拒绝恢复。
被打断的在途尝试保留，后续使用新目录；不覆盖既有证据。

在 worktree 根目录、匹配 UCRT64 DLL 路径的 PowerShell 中：

```powershell
$env:Path = "D:\msys64\ucrt64\bin;D:\msys64\usr\bin;$env:Path"
$env:OMP_NUM_THREADS = '1'
$env:OPENBLAS_NUM_THREADS = '1'
$env:MKL_NUM_THREADS = '1'
python scripts/run_slot_ldmos_bv_campaign.py --repo-root . --runner build-release/vela_example_runner.exe --base-config build/s26bv/base.json --output build/s26full2 --max-seconds 28800
```

首次执行使用不存在的输出目录，恢复同一请求增加 `--resume`。
今后新运行可将 `--base-config` 换为上述仓库配置；不能在已有运行的恢复命令中
替换配置文件。资源依赖位于本地证据目录，缺少它们时应先恢复原始资源。
当前执行证据在 `build/s26full2/`，工具诊断和交接证据保留在 `build/s26full/`；
生成输出不纳入版本管理。由于此次修改了辅助控制器，按哈希保护规则使用新目录
重新冷启动，未借助放宽工具身份规则继续旧路径。

## 当前验证

- 当前新入口与既有外电阻工具相关 Python 回归合计 **54/54 通过**。
- 本地冷启动 Poisson 完成；新配置 0 V 完整器件、全部有效行和电阻确认通过。
- 正偏压路径仍在计算，尚无本轮完整 0→BVDS 结论。
- 低压 QR 候选首步线搜索失败，一次后续尝试主动中断。可执行程序的
  nested scalar 控制也遭遇少数载流子行拒绝；转为已有 Python 标量控制器，
  使器件子问题可以使用同一套有界密度/QF 恢复。配置分支曾残留耦合专用选项，
  已修复并补充对应回归。各次失败、配置拒绝、中断保留独立记录。
- 未修改 C++ 物理核、容差或模型默认值，未重复全量求解器回归。

截至本轮阶段检查，`s26full2` 已接受 0 V 及约 0.025/0.05/0.075/0.1 V
五个外电阻状态。0.1 V 点内部漏压 `0.0998687787432403 V`，实际外压
`0.1000000300170081 V`，电流 `1.3125127376781924e-16 A/µm`。
起算来自新配置的本地冷平衡态；每个接受点均有独立器件与全部有效行证明。
工具在一次接受点后检测到自身版本变化并按保护规则停止，随后显式接受
主驱动更新、重新验证所有既有状态，再从该合格点继续。该停止属于受控
工具交接，不能记为器件数值失败。

后续起步步长为 0.1 V（原初始步仍为 0.025 V），3 V 以上为 0.25 V，
高压按电流选点；任何失败仍受有界缩步约束。使用过的参考原点
0/5/15/25/35/36 V 按阶段调度，每次转换在本轮配置下重新收敛及审计。

从已授权虚拟机只读下载 `bvds_external_resistor_final.plt`，共 61 点，从
外压/内压 0 V 开始，末点电流 `1.09038441104817e-7 A/µm`。
曲线 SHA256 为 `ff50b2a1547a5cdd95c1505efa418804c5da47f8eb4a2cf5ac2ecbc678745646`，
与远端 `sha256sum` 一致；远端 deck 与本地冻结原始参考 deck 的 SHA256
也一致。未在虚拟机启动新求解。

这份原始全曲线在线性电流插值下给出 BVDS `38.520901203613384 V`。
此前 394 点显式 Derivatives 续算参考为 `38.52090148256024 V`，两者差约
`0.279 µV`。两条曲线应保留各自来源，不能将高压续算曲线当作原始 0 V
起步曲线。全曲线新结果尚未完成，不在此宣称本轮 Vela BVDS 已通过。
来源与包围点见 `build/s26full2/native/manifest.json`。
