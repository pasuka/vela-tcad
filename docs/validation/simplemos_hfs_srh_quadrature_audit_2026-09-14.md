# HFS 十六点 SRH 源积分与端口守恒审计

日期：2026-09-14。本页为 [十六点验证](simplemos_hfs_sixteen_point_validation_2026-09-14.md) 后、冻结实现完整曲线计算期间的只读审计。没有修改生产代码、SRH 体积或运行自洽修复候选。

## 结论

**十六个 HFS 控制点的原生 SRH 节点场，用已有 signed Si 体积积分，均与原生空穴端口总和吻合。** 按已有原生常数约定 q=1.602192e-19 C 换算，最大相对差 4.996e-15。空穴端口求和条件数最大仅 1.003897，避免了强反型时从大电子电流相减提取微小净源项的消减问题；电子端口求和及其条件数另外保留。

当前 Vela SRH 使用 `all_cell` 体积。其直接积分与 Vela 空穴端口和最大相对差 3.985e-13，证实了 Vela 内部闭合，但它不是原生 SRH 的积分体积。n23 高 Vd 四点，以原生 SRH 节点场计算的 `all_cell` 结果比原生实际净生成量低约 1.544%–1.610%。

这是已观测的源装配差异及守恒账本，不等于修改 SRH 体积后的漏端口响应已经校准。当前冻结实现的完整曲线继续保留为基线；后续候选应单独改变 SRH 源及相应 Jacobian 的积分体积，先验证同扰动和双初始化，不得用全局 mesh 体积改写替代独立源策略。

## 方法与单位

复用相同冻结 HFS 程序下的 32 态/16 点资格、16 个已重建的 SRH 节点场，以及本轮高精度原生逐点 PLT。原生只有 SRH 生成复合，没有新增 Auger、雪崩等源项。比较：

- 原生 `sum(contact hCurrent)` 与 `q_native * sum(R_native[i] * V_signed_Si[i])`。
- Vela 端口由接受边的粒子线通量独立重构，电子乘 −q、空穴乘 +q；合成后与生产各端口总电流核对。
- Vela `sum(contact hCurrent)` 与 `q_Vela * sum(R_Vela[i] * V_all_cell[i])`。
- 保留 barycentric Si 与 all_cell 的原生固定状态对照，以及把同一个 Vela 场改用 signed Si 的固定状态源差。

R 单位 cm^-3 s^-1，面积 m²，结果 A/μm；密度的 1e6 换算与单位厚度 1e-6 m 抵消，所以最后积分乘 q。Vela q=1.602176634e-19 C 保持。两套 q 只用于各自结果的单位/常数约定核对，没有修改 Vela 常数，也没有把约 9.59 ppm 的常数差拟合成 1.56% 的体积差。
