## 两处表示差异及修复

首先区分QF输入本身的精度。原输入从TDR电压生成能量，再由能量反算电压，
五态分别有103／456／735／649／655个节点／载流子的QF值发生末位变化。
进一步从电压除以热电压，还可能损失原始归一化QF的末位。
这些转换在一般量级下很小，但会影响接近严格人口预算的节点。

其次区分人口映射和SRH核的浮点求值链。SRH使用自主有效本征浓度和统计因子，
人口反算则应保持原始参考能量与带状态的关系。直接把SRH本征浓度代入人口的对数式，
或将大带边先相加再相减，虽然在实数算术下等价，普通双精度下不能互换。

本轮以原材料参数在物理单位下生成参考能量，再归一化。参考关系为：

```text
Eref = [chi0(T) + (Eg0(T) + Vt*log(Nc/Nv))/2] / Vt
eta_n = [(psi* - QFn_ref*) - dQFn*] + (chi* - Eref)
eta_p = [dQFp* - (psi* - QFp_ref*)] + [(Eref - chi*) - Eg_eff*]
```

这里chi0／Eg0指未加入当前节点BGN的参考带状态，包含原配置的温度与模型带隙修正；
节点chi和有效带隙仍由已验证的自主材料／BGN链生成。星号表示归一化量。
最后自主反解同一默认JD近似，乘以相应DOS得到人口。
没有从人口拟合QF、添加经验偏移、导入原生eta／Gamma／人口解作为正向反算目标。

新私有输入明确保存原始归一化QF、主电势及坐标原点，增量单独传递；
保留接触reference／increment，校验原输入SHA、节点数、密度标尺及物理QF一致性。
参考能量由自主公式生成，与五态被动读取的原生参考逐值相同；原生读取只用于核对。
原始QF作为同态输入，未被当作Vela自主生成的模型输出。

## 完整RHS映射和独立负载

严格入口返回的实际残差与同一原生首轮super-system逐行映射。
原生独立未知量为2600条Poisson方程、两组各2121条自由连续性方程及1条电路方程，共6843条。
11条带节点标签的QF记录是电路别名，不能求和或当作11个独立负载未知量。

| 方程 | 每态行数 | 五态最大归一化逐行差 |
| --- | ---: | ---: |
| Poisson自由行 | 2522 | 1.330e-13 |
| Poisson接触约束 | 78 | 7.368e-17 |
| 电子自由连续性 | 2121 | 9.232e-11 |
| 空穴自由连续性 | 2121 | 2.852e-10 |
| 独立外电阻负载 | 1 | 1.863e-15 |

全部使用原1e-8门限，不混合不同方程单位求整体范数。
PDE分母为绝对装配项之和；接触约束使用电势与规定值的绝对和；
负载使用内电压、R乘器件电流及外电压的绝对和，均不加floor。
首点一个Poisson接触约束保留3.55e-15归一化绝对差，其余状态接触约束逐值相同。

负载按同一实际器件残差生成端电流，独立计算内电压加R乘电流减外电压，
对照原生更新前唯一电路RHS，保持既有电流／电压转换与符号。
五态最大负载差4.39e-11 V；这是同态残差匹配，不是负载残差已收敛为零。
负载行仍是独立计算的标量，尚未接入Vela增广未知量及对应Jacobian。

## 非零方向、证据与限制

实际探针对每态4个节点、两载流子和两种非零步长作中心差分，共80组人口方向控制。
最大同方向导数差约1.30e-9，低于本轮2e-6局部数值测试预算；
原固定态源用于这些新状态时全部被严格入口拒绝，未复用旧源冒充扰动态。
这证明人口函数可响应新增量，不构成完整PDE的Jv或Newton验证。

4个Catch2用例、921个断言及18项证据检查通过。
完成10个成功原生被动采集、15次成功实际装配；两个五态采集组保持完整变量、RHS1和矩阵身份，
最终组的完整super-system也与原基准相同。早版观察器将不适用空字段纳入消费，5次失败保留；
修复观察器后重新采集，无求解数据写入。两次私有探针编译失败及简单归一化失败候选同样保留。
远端本轮诊断无遗留活动进程，既有封存证据未改。

当前通过的是**私有冻结数学控制下的严格人口入口和完整RHS映射**。
