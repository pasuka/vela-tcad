# SLOT 外电阻候选策略小范围对照（2026-09-29）

## 结论与范围

在 T470p 上完成同父态对照、严格最终资格复验和同内压独立求解。
本样本中，**仅放宽候选器件残差没有收益；保留原候选容差，仅将已经收敛的
器件块线性右端置零，可以通过原来失败的大步**。最终器件、有效载流子行、
全局闭合及负载线门槛未改变。尚未将该策略写入生产驱动或续算 ledger。

这是一个父态附近的局部试验，不是最大可接受步长搜索，也不是新的完整 BV
扫描。之前 155 个新增点的全量最终审计不在本次审计范围。

## 失败记录与重放

a0126 提议外压步长 0.0014038681162750859 V。预测态先在起点外压重闭合：
初始器件残差 0.00942025，一步后为 2.60747e-10，已经低于 1e-8；负载线
残差却在 1.21352e-6 → 1.21273e-6 V 附近停止。最后提议内压更新约
1.33e-15 V，线搜索 alpha=0。回退至合格父态后，起点通过，但目标点停在
-1.1685646e-6 V，最终提议内压更新约 1.28e-16 V，alpha=0。

严格大步重放复现了上述数值。这里观察到的是带边框 Newton 方向/负载线
修正停滞；不能由极小内压更新直接证明浮点底限或 Jacobian 错误。
`raw_state_update_inf` 是状态坐标范数，未当作物理电位更新解释。

仅提高候选容差上限到 5e-6（activation_ratio=100，关闭右端置零）时，
实际有效容差约 4.64e-6，失败的内压、器件残差、负载线残差和方向与严格
版本一致。这排除了“本例仅需宽松候选残差门槛”这一解释。

## 对照结果

| 策略 | 提议外压步长 (V) | 最终资格 | 本次墙钟时间 (s) |
|---|---:|---|---:|
| 原严格大步 | 0.0014038681163 | 预测态与父态回退均数值失败 | 126.15 |
| 仅候选容差上限 5e-6 | 0.0014038681163 | 同上，无改善 | 125.88 |
| 容差上限 5e-6 + 已收敛器件右端置零 | 0.0014038681163 | 完整通过 | 69.94 |
| 原严格小步，内存恢复后重放 | 0.0007019340581 | 完整通过，复现历史结果 | 49.27 |
| **原容差 1e-8 + 已收敛器件右端置零** | **0.0014038681163** | **完整通过** | **58.87** |

右端置零保持完整 Jacobian，只在器件块已满足当前容差时抑制该块残差
右端，让电路修正沿局部切线进行；越出容差后仍恢复普通器件残差修正。
最后一组 `max_equation_tolerance=1e-8`，因而没有放宽候选容差。

两组置零结果的 Id、Si 势场、电子/空穴/总雪崩源均完全相同；严格小步
结果也与历史成功点完全相同。这里的“相同”指比较量相同，不泛指 HDF5
所有元数据字节相同。

大步最终内压 38.47121454483905 V，Id=1.743944994873477e-13 A/µm，
实际外压 38.6456090443264 V。小步最终内压 38.471091472108846 V，
Id=1.737854751541875e-13 A/µm，实际外压 38.644876947263036 V。
本样本大步的实际外压推进量约为小步的 2.028 倍。

**实际外压与原提议外压必须区分**：大步差 +40.5254 µV，小步差
+10.3624 µV。独立器件重闭合后，沿既有流程按 Vout=Vin+RId 计算实际
外压，再独立确认负载线。负载线零残差是对此实际外压的证明，不能声称
最终严格态在原提议外压 1 µV 内闭合。所有实际步长与电流增长限制另行通过。

## 同内压独立验证与剩余误差

从原合格父态直接求解大步对应内压，未用置零组终态作初值；保留原严格
器件门槛，3 次完整 Newton 更新后通过，耗时 32.12 s。与置零组比较：

| 比较量 | 结果 |
|---|---:|
| 内压 | 完全相同，38.47121454483905 V |
| Id 相对差（置零结果 / 独立结果 − 1） | +4.50001e-5，即 +0.00450001% |
| Si 势场最大差 / RMS | 7.1054e-15 / 2.4759e-15 V |
| 总雪崩源积分相对差 | +7.0388e-14 |
| 总雪崩源节点 L1 相对差 | 2.6710e-13 |
| 实际外压差 | 7.8474 µV |

两种初值下全部有效行均无违规；最大行比为 2.0951e-4（置零组）和
6.2885e-4（独立组），均小于 1e-3。全局电子闭合比为 1.2039e-8 与
4.5023e-5，空穴为 9.0653e-14 与 1.7591e-12。分别计算实际外压后的独立
负载线确认残差均为 0；完整器件资格另有证明。

势场和源项几乎相同，但端电流差与电子闭合误差同量级。电流的这点差异经
大电阻放大，已经超过 1 µV。因此当前数据支持改善候选修正路径，不支持
把“负载线残差 ≤1 µV”解释为不同初值之间的外压精度保证，也不能声称
端电流完全一致。进一步精度定位应检查端电流与电子闭合/停止误差。

## 环境中断、验证与后续边界

首次严格小步在独立器件复验时抛出 `std::bad_alloc`，随后被证据检查拦截；
这次环境失败没有计为数值不收敛。确认 T470p 的 SimpleMOS 只读查询

查询，未结束 SimpleMOS 求解器。可用物理内存恢复至约 12.7 GiB 后重试成功。
首轮 exit=1 保留，收尾轮 exit=0。另有既存 h5py/HDF5 版本警告；本次
状态读取、完整资格审计及归档哈希校验均成功，未改变环境依赖。

墙钟时间跨越了内存压力变化，且同机存在 SimpleMOS 负载，不能用这些
单次数据宣称稳定的加速倍数。可信的局部收益是：相同父态、相同提议大步、
相同物理与最终门槛，原策略失败而仅右端置零策略成功。

已完成候选注入边界的轻量检查（只对 enabled coupled_newton 注入，严格
器件/普通确认配置不变），没有修改 C++ 或生产 Python 驱动，因此未重建
求解器或重复全量回归。最终 `audit.json` 重新计算并验证 4 份合格器件与
电路证明，记录物理身份、文件绑定和原生产检查点不变。

建议下一批将“原容差 + 已收敛器件右端置零”作为显式、默认关闭的候选选项，
先在另外少量父态验证成功率和成本，再考虑正式续算。保持独立严格重闭合、
全部行、全局闭合、实际外压确认和失败回退；不提高默认容差。本次试验已
结束，未自动恢复长期 BV 扫描或定时监测。
