# BVmethods SG 支撑、边界投影及迁移率顺序接续定位（2026-10-10）

本轮确认一项生产实现差异：原生高场迁移率以 **Masetti + Enormal 的低场结果**为输入，
Vela 当前非 PhuMob 路径则先高场饱和、后表面散射。同一原生输入下，仅交换组合顺序，
局部空穴迁移率最大相差约 **2.88%**。同时，固定准费米势激励证明两边 SG 重建配合
绝缘边界切向投影可复现原生观察电流，三边最小二乘候选仍有百分比差异。
这些是差异定位证据；**完整 RHS、全部 Jacobian 交叉块和原始从零高压纯 QS 尚未认证**。

接续[本构、几何及源项复核](bvmethods_constitutive_geometry_rebaseline_2026-10-10.md)。
机器结果、运行退出码、文件身份和归档收据见[配套 JSON](bvmethods_sg_support_followup_2026-10-10.json)。

## 1. 配置与状态身份

仍用原 BVmethods NMOS：2600 原始节点、5020 三角形（26 个钝角），Si region 3，
SiO2 region 0/1/2、Nitride region 4/5；300 K，坐标 µm，二维电流 A/µm，
外电阻原值 `1e7 ohm*um`。模型为 Fermi、OldSlotboom、Masetti、GradQuasiFermi HFS、
Enormal、掺杂 SRH、E2 BTBT、Eparallel 雪崩。

Sentaurus T-2022.03-SP2 在已授权 VM 执行。SG/迁移率观察均为固定首个非零 Newton
更新前 Save 的 **Load/CurrentPlot/Plot**，没有在修改后的模型下求解 PDE。
PMI 电离观察器返回 alpha=1，仅捕获不含迁移率的源电流和驱动力；不能用其电离速率
冒充原 VanOverstraeten 模型。SG 单位采用 cm、cm^-3、V，回调电流无迁移率因子。
原生常数使用 Vt=`0.02585199526648486 V`、q=`1.602192e-19 C`。

本轮共 13 个原生观察运行和 13 组对应 TDR 导出，最终均退出 0。三批下载清单逐文件核验。
未启动 T470p/C560 的新 PDE 扫描；先前两平台短程资格仍保持上一轮范围。
Vela 生产求解后端、材料和门限未变，没有新跑全仓 CTest、提交、推送或换包。

## 2. 原生盒体积与边系数是同一套几何

对全部 5020 个单元（包括钝角）验证：

`M_i = (kappa_(i,i+1) h_(i,i+1)^2 + kappa_(i-1,i) h_(i-1,i)^2) / 4`。

最大相对差 `1.78815e-14`，最大绝对差 `5.20417e-18 µm²`。
原生 κ 与元素顶点 Measure 可以闭合；不能把 Measure 逐单元强行归一化到三角形面积。
现有 Vela `cellBoxNodeMeasures` 已有对应公式，本轮未注入原生 κ、切换几何默认或
移植 PN2D 的非钝角原子配置束。

新增只读辅助函数 `box_measures_from_coefficients`，覆盖坐标平方单位、正系数体积转移
不重新归一化、非法输入拒绝；辅助脚本测试共 **6 项通过**。

## 3. SG 固定激励、边界分支与精度

八组观察分别为原双精度、ExtendedPrecision、自由 Si 节点的 x/y 方向 1 µV 及
50 mV 仿射 QF 激励、x 50 mV 加 DensityIntegral(240)、x 50 mV 改 Boltzmann。
只修改电子/空穴 QF，自由 ψ 保持逐值不变，接触不施加激励。输出 QF 与指定值的
自由节点最大偏差约 `1.39e-17 V`；未激励基准与上一轮观察主变量逐值一致。
Save 中通用 `QuasiFermiPotential` 不是可直接当成电子 QF 替换的字段，失败准备证据保留。

候选沿每个代表顶点的两条边计算：

`delta = sign * (QF_j-QF_i)/Vt`，`a = log(c_j/c_i) + delta`，

`J_edge_without_mu = -sign*q*Vt*c_j*B(a)*expm1(delta)/h`。

电子 sign=+1、空穴 sign=-1。由两条边的单位切向投影解 2×2 系统重建电流。
边界控制包括 Si 外部自然边界及 Si/绝缘体边界的切向投影；含接触的单元保留完整方向。
电场同样投影，独立检查 `max(0,E·J/|J|)` 与原生 Eparallel 回调。
另列直接双精度 Bernoulli 相减、对数割线 Gg 和三边单元最小二乘控制。

下表为全部匹配回调的电流加权相对 L2；按坐标从相邻单元候选中选择最小电流误差，
**仍是乐观匹配，不是唯一元素/分支映射或完整连续性通量认证**。

| 固定状态/候选 | 电子 | 空穴 |
| --- | --- | --- |
| 原双精度，两边 + 边界投影 | `7.28e-5` | `3.80e-2` |
| 同一 QF，ExtendedPrecision，两边 + 边界投影 | `2.71e-8` | `3.94e-5` |
| x 50 mV，两边，无边界投影 | `2.81e-1` | `3.49e-2` |
| x 50 mV，两边 + 边界投影 | `4.20e-13` | `5.27e-13` |
| y 50 mV，两边 + 边界投影 | `6.26e-13` | `7.22e-13` |
| y 50 mV，对数割线 Gg + 同样投影 | `2.37e-4` | `6.17e-6` |
| y 50 mV，三边最小二乘 + 同样投影 | `3.98e-2` | `7.23e-2` |

x 50 mV 加 DensityIntegral 后，两边候选仍约 `3.34e-13/4.83e-13`；
Boltzmann 控制约 `2.23e-15/4.66e-13`。有限激励支持本配置的有效带边 SG、两边重建
及边界投影，不支持额外加入所测试的 Gg 候选。不能据此推断所有原生 SG 选项都无 Gg。
三边最小二乘与两边代表顶点的差异也不能作为 PN2D 配置束的单项替换依据。

原始弱激励中，高掺杂单元 QF 差可小至 `1e-16 V`，相减/人口反算精度会放大相对尾差。
ExtendedPrecision 显著改善，但原双精度尾差仍保留；本轮未把弱电流点删掉或放宽门限。
峰值电流 `1e-8` 的 major 分组和误差分位数仅描述可分辨性，不是验收阈值。

为避免过度解释，另试按最大盒体积限定代表顶点：x 激励吻合，y 激励电子加权误差却
约 **9.26%**，ExtendedPrecision 基准约 **1.71%**。因此，最大 Measure 不能独自决定
原生代表顶点，完整 SG 支撑映射仍需继续定位。全部限定控制及失败尾部另存。

## 4. Masetti/Enormal/HFS 顺序得到直接回调验证

以同一 x 50 mV 状态分别关闭 HFS、Enormal、两者，三组 ψ、n、p、电子/空穴 QF
与完整观察逐值相同。单靠绘图节点或单元迁移率反推非线性组合顺序仍受插值影响，
因此增加两组 HFS PMI 观察器，记录 HFS 的实际低场输入、F 和输出 µ。

该诊断替换只用于 Load/Plot，使用原生 300 K Canali 参数。与未替换的原生结果相比，
主变量逐值相同，节点及单元 µ 最大相对差约 **`6.05e-16`**，身份检查成立。
随后按坐标、ψ、n/p、温度、F、界面距离匹配完整/取消 Enormal 的回调：

| 项目 | 电子 | 空穴 |
| --- | --- | --- |
| 唯一完整回调/匹配数 | 11638 / 11638 | 11381 / 11381 |
| 匹配低场体迁移率歧义范围 | 0 | 0 |
| Enormal 已降低 HFS 输入的回调数 | 9546 | 9682 |
| `Canali(surface_low,F)` 与原生输出最大相对差 | `4.44e-16` | `4.44e-16` |
| 交换为先 HFS 后表面散射的最大相对差 | `1.283e-4` | `2.882e-2` |

例如空穴 `(x,y)=(0,0.04634765625) µm`，F=`121372.927916 V/cm`：
体迁移率 `128.780786`、表面低场迁移率 `80.797630`，原生最终 `41.993444 cm²/(V*s)`；
先 HFS 后 Matthiessen 表面散射预测 `40.783134`，低约 2.88%。
这是**顺序这一项在相同原生输入下的贡献**，不等于已测得 Vela 完整迁移率总误差。

生产源代码的 Masetti 路径在 `MobilityModel.cpp` 先调用 `fieldLimit` 再调用
`lombardiLimit`；PhuMob 路径先 Lombardi、后 HFS。后续最小修复应统一正确的低场→高场
组合及其导数，并用两个散射机制同时显著的物理回归验证，不能只调整高场步长或拟合参数。
本轮定位任务没有实施生产顺序修改，也没有宣称这一个差异已解释全部 QS 失败。

节点 µ 的盒加权算术/调和平均和重心平均均不能精确重建原生单元 µ；其支撑不能通过
任选一种平均确定。此部分零偏/首点/末点全部误差 CSV/JSON 保留。
