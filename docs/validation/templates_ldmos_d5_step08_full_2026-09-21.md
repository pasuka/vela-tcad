## 候选与历史保护

首版 v1 全程固定 QF 上限0.2 V；它在 Vg4、Vd≈1.433333 V 异常退出：
`equilibriumCarrierState: failed to bracket charge-neutral potential`。
尚未进入中高压。该版本同时改变了低压原有的小 QF 上限，不能据此判断
中高压大步长无效。失败目录 `step08_full_v1` 和日志保留，不覆盖或混入成功计时。

v2 保留低压设置后通过前8精确点，但在12.8 V出现162次更新及内部恢复；
随后无可信历史，漏压步长缩到0.1 V，QF上限仍为0.2 V，在12.9 V发生同样异常。
它证明仅限制漏压步长不足以保护无外推恢复步。`step08_full_v2` 独立保留。

v3 采用分段合同并补齐无预测回退：

1. 0–9.333333 V：完全沿用原最大步长0.2 V、原低压预测保护及 QF上限=实际步长。
2. 超过9.333333 V：外层最大步长0.8 V；有可信预测时 Newton QF上限独立固定0.2 V。
   无预测/恢复时 QF上限回到 `min(实际漏压步长, 0.2 V)`，零压和参考系检查沿用原小上限。
3. 预测仅使用本条曲线已接受、同一参考系的状态。历史跨度≤4/3 V、
   外推比例≤2；优先合格的最近精确输出历史，否则选择跨度最接近当前步长的
   合格接受状态。不同历史可能影响结果，所以不能只把收益归为步长。
4. 内部密度恢复后丢弃其之前的高压预测历史；跨参考系不混用历史。
   无可信历史或当前重试时不预测，继承无预测0.1 V上限与原失败减步恢复。
5. 精确输出点仍截短；若最近历史跨度过短，可选更早的合格历史，不能忽略比例保护。

这是一项独立 Python 延续候选，不改变生产默认或冻结二进制。
程序与配置来源、种子散列、历史散列、每次更新及内外恢复均有证据记录。
