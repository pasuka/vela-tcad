# BVMethods bootstrap线性失败同态完整导数恢复，2026-10-31

## 实现及范围

按[冻结增广系统诊断](bvmethods_frozen_linear_failure_2026-10-31.md)补齐生产核心恢复路径：自动恢复模式的bootstrap增广线性求解失败后，在同一packed状态、同一内压、同一目标外压、同一真实RHS和电路方程上，尝试一次完整Jacobian。

- 第一次失败不应用方向、不进行人口保护、预测或外压缩步，也不额外消耗一次Newton更新预算。
- 完整重试仍经过原分量后向误差1e-10和缩放绝对缺陷门；成功后仍经过原人口保护、恢复候选选择、物理和停止门。
- 两份矩阵均失败立即返回正确器失败，保留两种失败原因，由原延续控制决定缩步。
- 同一未更新状态最多有一次bootstrap线性失败触发的完整探测。候选无效、恢复拒绝或退回bootstrap均不续发机会；实际应用更新后才重置，避免空转切换。
- 原普通完整导数策略及自动模式的正常周期探测保持。没有增加强制首步、放宽验收门或改变SG冻结默认值。
- trace保留`bootstrapLinearFailureReason`，模式原因记录`bootstrap_linear_failure_restore`，耦合updates.csv末尾追加`bootstrap_linear_retry`。旧列次序保持。

实现位于[CoupledLoadLine](../../include/vela/simulation/CoupledLoadLine.h)及[DerivativeRecovery](../../include/vela/solver/DerivativeRecovery.h)，相应[配置参考](../config_schema.md)已更新。共享核心人口Newton通过同一负载线服务获得修复。
