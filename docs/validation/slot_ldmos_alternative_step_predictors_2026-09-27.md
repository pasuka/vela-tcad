# SLOT 更合适的端口与步长预测方法（2026-09-27）

本轮在同一批 331 个历史窗口上补充比较限幅端点切线、三点有理函数、log(U) 拟合、log(I) 隐式拟合。结果支持优先研究“限幅切线基础模型 + 受约束有理候选”，而不是继续增加多项式阶数。此结论为探索性离线比较，未修改生产控制器，未启动仿真。

## 数据与比较口径

沿用 `build/s27quadratic_replay/analysis.json` 的 55 个原生、243 个 Vela 低压、33 个 Vela 高压测试窗口；本轮重新核对该文件引用的输入及分析源码 SHA256。物理端口量与原点转换沿用上一轮已绑定的数据，高低压 Vela 支路不合并成完整验证路径。
每个窗口只用当时已有的点，给定历史实际下一外压增量，预测下一内压和电流。任何方法不适用时退回相同的三点一次模型，并计入全部误差，不删除不利样本。部分历史实际外压步长超过拟议控制器的外推上限，仍保留作为压力测试，不能当作控制器实际会接受的步长。
因此结果测量的是响应预测能力，不是最大可收敛步长。也未复现新策略的闭环轨迹，不能直接换算加速倍数。所有候选在相同已见数据上比较，尚缺独立前向验证。

## 候选模型

1. **限幅端点切线**：用最近两段非均匀割线计算端点导数，在历史正向支路上对预测导数限幅，再作一次外推。它借用了保形端点导数的思路，没有向区间外延伸整个三次样条。若已观察到内压反向，标为不适用并退回基础模型，而不将反向样本改写为正向。
2. **三点局部有理函数**：最新点锚定 `Δv=a H/(1+b H)`，H 为外压增量，电流由 `ΔI=(H-Δv)/R` 得到。分子分母各一次，形式类似 [1/1] Padé，但系数来自三个离散样本，不是由高阶导数构造的严格 Padé 展开。它能表示逐渐饱和的内压趋势。
3. **log(U) 一次拟合**：`Δv=c log(1+H/U0)`。本数据的低压内压近似随外压线性变化，这一坐标不匹配，误差显著恶化；不建议全程使用。
4. **log(I) 隐式模型**：`q=log(I/I0)`，拟合 `Δv=c q`，由 `H=c q+R I0 expm1(q)` 用有界二分解 q。c≥0、I0>0 时该标量方程单调。它不是额外的器件求解，只是便宜的端口近似计算；低电流或非单调历史不能直接使用。

统一使用 R=1e12 Ω·µm，内压/外压 V、电流 A/µm。

三点有理在 Vela 高压段的 P95 比一次降低约 90.77%，最大误差从 28.958 mV 降至 2.040 mV；限幅切线最大误差为 6.081 mV。原生数据则限幅切线的 P95 更优，所以没有证据支持一个模型在所有区间都最好。

有理模型的优势是预测偏差减小，而不是本轮已经证明保护触发次数更少。

## Wolfram 独立核验

Wolfram Language 核验了两点增量确定有理系数、导数 `a/(1+b H)^2`、以及电流上限方程。真实 Vela 高压例子：父态外压 38.9026539873 V、内压 38.4910451010 V，得到 a≈0.03486127609、b≈2.122961751 V⁻¹。
给定历史外压增量 0.3525574106 V，有理模型预测内压增加 0.00702936285 V；Wolfram 独立结果与 Python 一致到约 1e-14 V。该历史步长超过最近外压步长的 1.6 倍，按本文统一保护仍应缩步；计算值仅作模型核验。
有理近似可能出现虚假极点，必须检查过去拟合区间至候选终点内分母不变号且远离零，以及预测导数是否符合当前支路。[Wolfram 官方关于伪极点的说明](https://reference.wolfram.com/language/ref/PadeApproximant)。本轮采用最小分母 1e-3、缩放矩阵条件数 1e8 的诊断门槛；它们是启发式设置，非物理收敛定理。

## 如何转换成步长建议

对于上述有理候选，求满足以下约束的最大预测 H，再叠加增长因子和成本反馈：

```text
H <= 外压硬上限
0 <= a*H/(1+b*H) <= 接受态内压增量上限
0 <= (H-a*H/(1+b*H))/R <= 允许电流增量
1+b*h 在拟合区间和候选区间远离 0
0 <= a/(1+b*h)^2 <= 1  （适用正向支路时）
```

令 Q=R*允许电流增量，电流约束的边界化为 `b H²+(1-a-b Q)H-Q=0`。在已验证的单调无极点区间内，可以用有界二分/Brent 寻找允许步长，不依赖对不稳定二次求根公式的直接计算。此处最大值仅属于近似端口模型，不是器件的最大可收敛步长。
以上例采用 25% 电流增量额度、0.2 V 内外压上限，允许的模型步长约为 **0.10591677 V**，对应内压增加 **0.00301455 V**、电流增加 **1.02902e-13 A/µm**。虽然历史实际步长更大，当前电流保护仍会限制它；更准确的预测不会自动取消这些约束。
内压试探上限依然独立传给求解器。每个校正态仍须满足实际增量、完整 Newton、全部载流子行、闭合及独立负载线确认，拒绝后回到原合格父态缩步。

## 建议

近期最值得验证的组合为：**限幅端点切线作为基础，受约束三点有理模型作为候选，用最近已完成步骤的样本外预测误差决定是否启用候选，并结合修正成本限制增步。**
它比增加多项式次数更符合当前高压曲线形状，而且只需端口历史、小型代数运算和一维有界求根。规则需先冻结，再做独立区间前向试验，避免反复在同一批数据上调参获得过于乐观的结论。
log(I) 可作为电流增长控制的辅助坐标，但本轮全曲线结果不如限幅/有理组合，不建议作为唯一默认预测器。单纯 log(U) 不适合当前低压段。
若下一阶段需要直接评估内部状态变化、而不只是端口趋势，仍应研究完整 Jacobian 的参数切线和预测/校正误差控制；真实回折再考虑伪弧长。端口历史方法不能替代这些能力。
