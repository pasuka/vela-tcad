# BVmethods 硬约束秩、电子块结构与投影对照，2026-10-20

## 结论与范围

本轮在 T470p 完成 rows285 的矩阵导出和独立投影对照，各重复两次。已定位上一轮
活动集返回零方向的直接原因：第 21 次处理遇到近线性相关的阻断约束，私有原型主动退出。
这不是最优性证明，也不能据此断言不存在可行下降方向。

本态不满足 SLOT 式“零 RHS、无外部列耦合”的电子块消元前提。独立非负最小二乘投影
得到非零下降候选，但投影未收敛，原单位线性约束和实际装配的固定行界均未通过。
没有采用任何候选，没有改变生产求解器、物理、接受策略或验收门限。

## 活动集为什么停止

导出了完整稀疏 J、R、160 列耦合映射 D、JD、目标矩阵、缩放及全部双侧约束。
独立重算 J×D 与导出 JD 一致，约束在原单位和优化器坐标间的转换已核对。

| 项目 | 结果 |
|---|---:|
| 停止原因 | `dependent_blocker` |
| 已加入工作集 | 20 条，数值秩 20 |
| 新阻断约束 | 索引 1209，对应空穴节点 1087，设备行 6287 |
| 长双精度正交化后的相对余量 | 2.2173e-15 |
| 独立最小二乘重建的相对余量 | 2.2722e-15 |
| 阻断约束与组合的仿射界差 | 0 |
| 组合系数最小值 | −0.0147071 |

原型以 1e-12 的**内部秩判定阈值**停止加入该方向；此值不是物理验收门限。
独立分析支持其在当前数值精度下近线性相关，但没有证明严格数学依赖。
组合中含负系数，因此即使对应超平面相关，也不能直接认定这条不等式冗余并删除。
应检查保持不等式可行性的工作集交换及乘子，而非继续加入近相关行或清零物理方向。

缩放后目标 Hessian 含已声明的 1e-12 对角正则，特征值约为
9.99999947e-13 至 1.96573613；列缩放范围为 6.79105e-13 至 1。
这说明实际问题存在很大的数值尺度跨度，尚不能单凭此将失败归因于某一种线性求解器。
原零点仍有站立性残量 8.2351e-3、对偶非负性违反量 47.8989，不能称为最优解。

## 独立投影与真实装配

从可行零点的 285 条活跃不等式出发，以非负最小二乘构造目标负梯度到切锥的投影候选。

末段采样的投影残量不再改善。

- 切锥最大违反量 2.3381e-9，互补性残量 4.5679e-3。
