# SLOT 有界恢复与实际外压续算（2026-09-28）

本次按用户授权修复控制流程，并在 T470p 验证。物理模型、网格、Release

## 实现

- 默认关闭 `--actual-outer-continuation`，必须配合端口步长控制。内压低于
  38.4 V 时只做一次外推器件求解、必要时一次合格父态回退，由上层负责缩步。
  完整器件资格通过后，用实际内压及电流计算供电坐标，再独立执行电路确认。
  原提议、实际外压与差值均记录，不宣称原提议已精确通过。
- 保留外压/内压实际增量、电流增长、单调性、最终目标越界、器件全部有效行、
  全局闭合及 1 µV 负载线门槛。复用态的电路零残差不替代器件验收。
- 失败尝试记录父态哈希、外推父态哈希、模式及内压；相同输入且电压相差
  不超过 1e-9 V 的失败不重复求解。环境和证据错误不转为数值重试。
- `--candidate-max-seconds` 给整个候选修正链独立时间预算；全局截止仍优先。
  `--corrector-stagnation-passes 2` 在两次完整验证均线搜索失败、载流子及
  闭合已通过、Poisson 残差相对变化不超过 1e-4 时提前返回失败。
  此判断仅提前结束无效修正，不接受失败态、不声称达到舍入底限。
- 默认行为保持；新选项进入冻结身份。跨策略采用新目录和独立复验父窗口。
