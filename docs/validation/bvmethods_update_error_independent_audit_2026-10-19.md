# BVmethods：独立 J/R 校验与完整结果位模式，2026-10-19

承接[实际人口与精确 checkpoint](bvmethods_update_error_population_checkpoint_2026-10-19.md)。
本轮只补 off/report 的取证及无扰动对照，不改变接受策略、物理模型、行门、闭合门、
1e-8 算子门或 PN2D。没有新增 Sentaurus 运行，也没有执行 E1–E4。

## 实现

- `NewtonAuditScope` 是独立于 report 采集器的有界、默认关闭观察入口。
  从实际 Newton 循环复制 x/J/R、行权重、原始及保护后方向和完整 LineSearchResult，
  不读取 report 的副本，不额外计算人口、残差或 Jacobian。拷贝异常在诊断层捕获。
- `ExactValueBits.h` 使用已安装 Boost.PFR 遍历聚合的全部声明字段，
  完整覆盖 NewtonResult 的 20 个顶层字段及嵌套字段，包括此前 JSON 遗漏的
  quantumLike、失败诊断细项、完整轨迹和量子外循环历史。
  浮点数直接编码 binary64 位模式，保留正负零、次正规数、无穷大及 NaN payload。
  新增不支持的字段类型会触发编译错误，避免静默遗漏。
- 编码包括向量元素、稀疏矩阵形状/存储项顺序/值及压缩标志，不比较对象 padding、
  地址或分配器容量。这是求解后的比较格式，不是新 checkpoint 或公开存档格式。
- 私有驱动在求解完成后用独立对象计算七类更新误差组合，保存并恢复浮点环境。
  原求解器在诊断前后分别进行一次哨兵装配，检查 x/J/R 是否改变。
  本轮没有将私有驱动配置提升为公开 schema/前端功能。

## 配置及七臂控制

无 Band2Band 的 BVmethods；2600 节点、300 K、Fermi 人口，BGN/SRH/雪崩/迁移率沿用。
使用 barycentric 体积及原钝角单元；没有混入零偏离散对齐控制。
漏极固定内压 0.00524437249039996 V，其余接触 0 V。
`rows0` 表示 0 违规行种子，不是零偏态；六个标签均不表示本轮末态的违规数。
报告中人口单位 cm⁻³，ψ/QF 为 V，装配维持既有内部单位。
UCRT64 Release core、私有 `-O1` 驱动，UMFPACK/HDF5 实际启用；使用已有 Boost 1.92。

本机和 T470p 使用同一二进制及九个 SHA256 一致的输入文件。
每个状态按以下顺序运行，每条控制使用独立进程：

| 控制 | 独立校验器 | report 采集及离线报告 | 次数 |
|---|---|---|---:|
| plain_off | 关 | 关 | 2 |
| audit_off | 开 | 关 | 2 |
| audit_on | 开 | 开 | 2 |
| plain_on | 关 | 开 | 1 |

先验证无观察器基线自身复现，再检查校验器的影响，最后用独立 off 证据比较 report。
plain_on 检查 report 在没有校验器时的结果，避免共同观察器掩盖结果变化。
完整结果以二进制文件直接比较；每轮矩阵、方向及线搜索以全位编码的 SHA256 比较。
历史基线仅比较上轮已经记录的 JSON 字段，不倒推上轮未保存的字段也已逐位一致。

## 结果

双机共 84 次运行全部正常结束，924 项批次核对通过。
每机先通过无观察器基线两次复现，随后七臂的完整 NewtonResult 位模式一致。
独立校验覆盖合计 172 个机器/迭代位置、688 份事件记录；
x/J/R、行权重、原始/保护方向及完整线搜索均与 off 对应值一致。
完整线搜索编码也保留最佳拒绝步的 x/R、阻尼、merit 和拒绝原因。
报告副本与独立校验器一致，516 份逐轮报告及人口检查通过，报告数值与同机旧证据一致。

报告前后的哨兵 x/J/R、舍入模式及 MXCSR 一致，七臂已加载模块的摘要一致。
生产求解自身可设置浮点异常状态位；本轮比较 off/on 的相同阶段，
没有把“求解前后所有异常标志不变”当作条件。离线诊断通过 fenv/MXCSR 恢复环境。

六态仍全部按原判据未收敛：

T470p report 11 例/104 断言，Newton 采集专项 2 例/157 断言。
包含特殊浮点位模式、遗漏字段反例、诊断容量耗尽及异常隔离控制。
未在本轮重跑完整 CTest 或 Linux 验证，不据此宣称所有求解分支均获资格。

报告中的无接受步 U3、下溢/不可表示 U2 仍保持无效，不把它们替换成零误差。

## 资格边界及下一步

本轮资格仅覆盖上述六态、同一机器内、经典 Newton 的私有诊断链路。
不覆盖 split/量子/recenter/recovery 分支，也不宣称跨机器 J/R 差异已经消失。
固定内压六态没有增广负载未知量，不能据此放行完整外电阻 QS。

严格 L1 的逐元素 J 和完整缓存身份、L2 的缓存命中历史仍未覆盖。
哨兵装配相同证明对应数值输出未变化，不能替代这些内部身份检查。
生产 report 配置/前端映射、原生 0.01 V 态的完整回放、全部异常路径也未整体验收。
既有逐行账本仍需补当前态行门资格/比值、耗尽区定义及最佳被拒试步的完整误差。

下一步先补逐元素/缓存契约与剩余行账本，再进行隔离静态回放；
E1–E4 接受策略实验仍需另外授权。
