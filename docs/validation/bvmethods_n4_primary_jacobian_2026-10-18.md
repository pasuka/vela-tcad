# BVmethods N4：自主主变量链式Jacobian与精度阻断检查

日期：2026-10-18。承接[实际SG与变化路径谱原语](bvmethods_n4_sg_variable_path_2026-10-18.md)。
统计见[JSON汇总](bvmethods_n4_primary_jacobian_2026-10-18.json)。

本轮将统计／QF、Lombardi、Canali、边系数、SRH及逐单元雪崩链式项接入私有自主Jacobian，
并加入Poisson、接触约束与局部电流负载散射。形成6843阶、93787个非零项的**局部部分矩阵**。
NonLocalPath的变化几何／转折点／WKB／积分收集导数仍缺失，部分精度控制也未过门；
因此完整Jacobian、Jv及线性方向未取得资格，没有进入真实Newton投影／线搜索循环。
N4继续，N5未开始，生产源码、模型默认、发行包和验收门限未改。

## 1. 已接入自主依赖链

SG数学原语仍为 `F=C*Nref*[n0*B(-a)-n1*B(a)]`。
这次直接从基准主变量生成Jacobian，不再把实际a、人口、系数的扰动态割线作为链式输入。

- 统计链使用实际JD兼容统计的解析η导数；稀薄人口下直接求多项式统计修正的导数，避免`1/n-η'(n)`相消。
- 保留初始QF reference与当前increment；对物理QF的ψ／人口依赖显式换算Vt和DOS。
- Lombardi法向场、Canali高场驱动力及低场迁移率链组成单元顶点导数，随后按实际盒面积和边几何权重组成边系数导数。
- 高场1 V/cm截断保留原分支；不平滑截断，不将跨分支中央差分视为光滑导数资格。
- 9070个唯一SG边项散射成输运矩阵，去除显式零后57630个非零项；四次基准生成结果一致。
- SRH包括两个统计平衡因子、分子／分母和物理单位链；雪崩包括SG重建电流、驱动力、平滑电离系数及代表点迁移率导数。
- 局部源导数共10464项：2152个SRH节点项及8312个单元／载流子雪崩项。
- Poisson包含介电边、主人口电荷及接触约束；局部电流回耦到独立内电压负载行。共同SRH／雪崩项在电子、空穴电流差中先作代数抵消。

本矩阵没有读取商用参考矩阵，也没有使用经验人口偏移或导数拟合。
矩阵阶次完整不表示算子导数完整：文件及资格标记明确排除NonLocalPath导数。

## 3. 原始方向的精度问题仍保留

沿原有接近公共电势移动的ψ方向，三档存在41／49／62条光滑输运行差值高于当前舍入估计且超1e-5。
换用实际存入binary64的主变量割线作隔离控制后，分别剩1／0／0条。
这说明主变量落地舍入在相消方向中会放大；实际割线检查不能资格化原计划方向。

电子人口方向最粗档有1条同类输运失败，小两档没有；空穴人口方向三档没有同类失败。
仍有超1e-5但差值低于舍入估计的行，均留在逐行账本，未将“暂不可分辨”算作严格通过。

SRH的独立高精度解析控制通过，包括近统计平衡状态；实际普通精度FD仍有近零分子／响应量化问题。
例如电子方向三档有516／572／604条源专用相对差超1e-5，部分FD为零而解析方向非零。
不能用完整残差的大输运舍入预算将这些源专用失败改判为通过。

雪崩在电子及ψ方向均保留空穴1546／2084／2587三条差值高于完整残差舍入估计的失败。
电子方向2084三档差约2.406e-3／8.331e-3／1.114e-2；按实际主变量增量复核后仍超门。
这些行已下钻到实际相邻单元和电子／空穴源贡献；尚未证明余差仅来自主变量存储，
QF／有效SG驱动内部求值、相消和源链仍需继续分离。
所有极小／下溢样本及跨高场分支行单列保留，没有新增密度或源门限。

完整局部方向检查也保留Poisson在公共ψ方向的12／27／17条失败及载流子弱行；
分项与完整行的舍入估计来源不同，没有用较宽分项估计将完整Jv改判为通过。
另实现从基准链式项直接求作用的80位因子化Jacobian，并与存储矩阵的普通／保精度乘加对照。
四个方向、各三档的失败行数未减少；仅提高Jacobian乘加精度不足以修复当前实际残差方向问题。

## 4. NonLocalPath缺项不能忽略

ψ437局部方向中，完整FD与当前部分矩阵Jv的电子块对称L1差约4.8315%，空穴块约0.02151%。
这里对称L1分母为`sum(abs(FD))+sum(abs(Jv))`。
独立减去实际NonLocalPath源增量后可核对已接入的局部项；该减法仅用于归因，不能作为完整Jv资格。

上轮谱原语偏导和当前状态谱值控制继续保留，但变化路径几何、转折点、内层WKB、
窗口递归分段、端点收集权重以及远端主变量稀疏散射尚未全部组成Jacobian。
原收集事件两侧证据保留；本轮新增的Canali阈值控制显式分开三档左侧值和右侧导数。
没有用冻结路径、补零远端导数或参考矩阵填补这些缺项。
