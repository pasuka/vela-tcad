# LDMOS 有限接触代数一致性候选验证

日期：2026-09-16。分支：`codex/templates-ldmos-phase-a`。

## 结论与资格范围

默认关闭的接触一致性候选已实现。Windows/Linux Release 各四个高压点、两轮
基线/候选配对，共 32 次求解全部通过原代表点门限；各平台重复轨迹逐值一致。
Linux Vg=4 V、Vd=30.666666666666654 V 从原种子实际完成 **14→9 次 Newton 更新**，
消除了前次审计定位的五次接触行长尾；不再只是固定状态投影的推断。

每轮四点总更新 Windows 44→40、Linux 45→40。代数校正单独记录，不计作
Newton 更新；其准备、完整重装配和子进程时间均计入成本。
Windows 两轮总墙钟均较短，Linux 两轮优劣反转，**尚未证明稳定墙钟加速**。
R7 生产默认、物理参数、原门限及停滞规则均不变；未运行前 8 点或完整曲线，
不转移原 R7 的 62 点资格，不启用 F2 R-B。

前置证据：[接触行舍入审计](templates_ldmos_contact_row_roundoff_2026-09-16.md)。

## 实现合同

入口 `diagnostic_near_steady_contact_consistency=true`：

1. 仅允许带 QF 参考的 `provided_state` 四方程 QF Newton；与密度映射、PTC、
   NLEQ_ERR 型阻尼、Jacobian 刷新实验、NGMRES、两个近稳态 QF 实验互斥。
2. 原缩放残差范数 `<1e-9`、原三个电学块均通过、原逐行门限未通过，且存在有限
   空穴接触时，每点只尝试一次。已收敛或没有有限接触的点不做准备/重装配。
3. 在副本中，仅令有限空穴接触的 ψ 等于既有 `neutralPotential(bias,T)` 的当前
   温度目标；fn、fp、两组参考、T 和内部节点保持不变。空穴仍是自由未知量。
   不改变接触物理式及其温度 Jacobian，也不以旧温度的根替代当前根。
4. 非零修正且最大 ψ 变化不超过 1e-8 V，才完整重装配残差/Jacobian/行缩放。
   这个上限是候选保护，不是替代终态门限。原残差、全域逐行和电学块门限全部
   通过才接受并终止；否则丢弃副本，保持原状态、装配、缩放、参考和停滞历史，
   按原剩余迭代预算继续 Newton。没有把本来不合格的状态标记为成功。
5. 输出触发迭代、节点数、最大电势修正、前后残差/逐行比、重装配及接受状态、
   含准备/重装配的事件时间。事件时间与装配计时重叠，不能再重复相加。
   外层接触数、电流守恒、热平衡、温度及参考状态一致性仍独立检查。

实现：[点求解器](../../src/simulation/ElectrothermalSimulation.cpp)；
运行/核验入口：[配对脚本](../../scripts/run_templates_ldmos_contact_consistency.py)；
配置定义：[schema](../config_schema.md)。

## 验证及证据

- Windows：9 个定向 C++ 用例，5065 断言；36 项电热运行器 Python 回归通过。
- Linux：同 9 个定向 C++ 用例，5008 断言；36 项电热运行器回归通过。
- 数值测试覆盖不同温度的接触代数目标、沿中性约束的温度链式导数抵消、
  亚浮点自由空穴扰动仍产生非零交换；没有把自由空穴固定到接触偏置。
- 运行器测试覆盖已收敛不触发、已一致但行仍失败的普通回退、实验互斥拒绝。
  另构造温度推进后接触 ψ 不一致、其他自由空穴行仍不合格的情况：确实重装配
  后拒绝候选，Newton 历史、状态、参考、残差、门限和停止原因逐值保持；
  多计一次装配，分解次数不变。
- 两平台 32 次原种子完整代表点轨迹；下载后重新核验运行库、输入/输出、参考、
  源码哈希、基线保持、重复轨迹、前缀及原代表点资格。未运行完整 CTest。
