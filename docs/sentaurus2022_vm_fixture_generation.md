# Internal development: generating Sentaurus 2022 evaluated fixtures

The licensed Sentaurus 2022 VM is reachable through the configured `sentaurus`
SSH host. Repository CI does not require a license and consumes only reviewed,
frozen artifacts.

This workflow is internal development/test infrastructure. It is not part of
the public product runtime, and end users must not need Sentaurus or access to
the licensed VM to use the default offline frontend.

1. Keep the owned SDE source in the local checkout; it is hash-sealed before
   upload and is never replaced by a VM copy.
2. Generate an isolated official oracle with the Release-tree runner:

   ```powershell
   D:\msys64\ucrt64\bin\python.exe `
     scripts\run_sentaurus2022_sde_fixture_vm.py `
     --source reference_tcad\pn2d_sentaurus2018\source\pn2d_sde.cmd `
     --fixture-name pn2d_sentaurus2022 `
     --run-id T2022_03_SP2_oracle_v1
   ```

3. Review `sde.stdout.txt`, `sde.stderr.txt`, exit code, SDE version and every
   hash in `manifest.json`. The runner fails if the evaluated log is merely the
   two-form `set!`/`load` log or if any required geometry/mesh oracle is absent.
4. Preserve the original owned `.cmd`, `.log.eval`, version/provenance manifest,
   expected `device_ir.json`, `_bnd.tdr`, `_msh.cmd`, and selected golden sample
   values. Do not commit license tokens, VM paths, unrelated generated plots, or
   private third-party decks.
5. Re-run the offline-static path against the frozen `.log.eval`; its Device IR
   must match the reviewed evaluated IR except for `source` provenance.

T-2022.03-SP2 was observed to log only `(load "...")` when a wrapper toggles
`evaluate-log-file` and then loads a second file. The runner therefore creates
an isolated wrapper containing the toggle followed by the byte-for-byte owned
source. The separately copied source and wrapper are both hashed. This is
required for a variable-expanded command stream on the licensed VM; it does
not change the committed source.

At minimum generate four fixture families: ABA/BAB multi-region overlap;
`insert-vertex` plus partial edge contact; constant Replace/LocalReplace/
NoReplace; and directed line-baseline Gaussian Positive/Negative/Both plus
NoEval. Hash changes require fixture review, not automatic golden replacement.

The frozen PN2D oracle under `reference_tcad/pn2d_sentaurus2022_oracle` was
generated by Sentaurus Structure Editor T-2022.03-SP2. It contains the official
evaluated log, boundary TDR, mesh command and mesh TDR plus their hashes. The
official mesh contains 1943 points, 3680 elements and 3 regions. SDE also
reports that the owned 2018 deck's `sdegeo:define-2d-contact` calls are obsolete
and should be migrated to `sdegeo:set-contact`; the oracle intentionally
preserves that warning instead of hiding it.
