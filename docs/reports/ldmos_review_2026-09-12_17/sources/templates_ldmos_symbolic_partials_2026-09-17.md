# IALMob 显式高场偏导与低场符号生成候选

日期：2026-09-17。源基线 `b17156f`，推荐 R10 保持不变。
用户授权按高场显式偏导、低场符号生成、自动微分对照及曲线验证顺序执行。

## 实现范围

- 点输入 `diagnostic_ialmob_explicit_high_field`：Caughey–Thomas 高场函数
  分离只求值与三个显式偏导，温度项保留 beta(T) 和饱和速度(T) 的贡献。
  零场沿用原选择斜率；原自动微分函数保留为独立对照。
- 点输入 `diagnostic_ialmob_generated_low_field`：低场表达式图由 SymPy
  离线求导及分支内公共子表达式消除，生成值与七个 SI 偏导的 C++ 内核。
  运行时无 SymPy 依赖，无通用 Dual 运算符链；保留原空间/温度装配链式项。
- 所有开关默认关闭，并纳入跨点准备身份。生成与 AD 的准备缓存分开，
  防止一个实现误用另一实现的中间结果。原模型、屏蔽求根、温度语义及门限不变。

生成器：[generate_ialmob_symbolic.py](../../scripts/generate_ialmob_symbolic.py)。
对照：[原低场表达式](../../include/vela/physics/detail/IalMobilityEvaluation.h)。
生成头文件：[IalMobilityGenerated.h](../../include/vela/physics/detail/IalMobilityGenerated.h)。
SymPy 1.14.0 及 mpmath 1.3.0 仅装入忽略目录 `build-release/symbolic-python`，
不更换系统 Python、编译器或运行库。复现（worktree 根目录）：

```powershell
$env:PYTHONPATH=(Resolve-Path build-release/symbolic-python).Path
D:/msys64/ucrt64/bin/python.exe scripts/generate_ialmob_symbolic.py --check
```

屏蔽下限使用原驻点包络导数约定，未对数值二分迭代过程求导；分支边界的
选定斜率不解释为经典可微性。CSE 不将奇异表达式提出其保护分支。
符号化简可能改变浮点运算顺序，不能预设全部 Newton 轨迹逐值相同；
曲线仍按原终态门限及既有状态差 1e-8 V / 1e-7 K 检查，保留拒绝/失败成本。

高场使用 `x=mu0*E/vsat`、`s=x^beta`、`d=(1+s)^(1/beta)`、
`r=s/(1+s)`，得到 `mu=mu0/d`：

- `dmu/dmu0=1/(d*(1+s))`；
- `dmu/dE=-mu*r/E`，零场单独采用原选择斜率；
- `dmu/dT=mu/T*[betaExp/beta*(log1p(s)-r*log(s))-vsatExp*r]`，
  `s=0` 时按极限处理 `r*log(s)`。

低场生成器分开优化原值和导数，保证候选自身的残差/完整 Jacobian 值路径
采用相同运算顺序。初版将两者共同 CSE，测试发现若干 ulp 的值差，已通过
修正生成器消除，未放宽相等断言。测试中的非默认粗糙度系数按其 cm^-3
内部密度口径设置；未修改生产参数以迁就测试。

验证入口：
[固定种子](../../scripts/run_templates_ldmos_symbolic_study.py)包含两栅压各四个
低/中/高压状态，交替运行顺序；[冷启动曲线](../../scripts/run_templates_ldmos_symbolic_curves.py)
支持前 8 点和完整 31 点。两者冻结二进制/DLL、输入哈希及完整失败成本。
状态对照使用各节点 QF 参考和局部增量，避免合并小量后掩盖差异。

五条曲线与冻结 R10 的状态最大差不超过 `3.56e-15 V / 5.69e-14 K`；

**本轮不能确认稳定的端到端加速。** 首组高场看似减少 18.49%，但漏压数值
分解耗时也从 50.594 降至 41.462 s；反序组墙钟趋势反转。相同程序、相同输入

低于墙钟时间。无法将这些差异全部归因于偏导实现，不能把组合的单次低耗时
解释为符号低场已带来 36% 加速，也不拼接不同组的最快结果。

原始证据位于同一暂存根目录的 `first8_guard/`、`first8_guard_reverse/`，
联合审计为 `final_audit.json`。这些是 Windows 普通 Release 的短曲线结果，
没有运行本候选的同 VM 双栅压完整 62 点、原生配对或生产晋级验收。

## 本轮结论

以下结论对应当时的 Windows 实现与短曲线阶段。其后的
[Linux 完整重复联合验收](templates_ldmos_symbolic_full_2026-09-17.md)已完成，
显式高场晋级 R11，低场仍未晋级；不将后续资格倒推到本节短曲线计时。

1. 已完成三个显式高场偏导、七方向低场符号内核、值专用入口、独立 AD 对照，
   并完成分支/温度/装配及冷启动短曲线验证；数学和数值一致性未发现失败。
2. 高场在两轮冻结代表点中有 6.48%–7.03% 的耗时下降，值得继续验证；
   当前短曲线的环境波动阻止端到端性能结论，不能认领稳定加速。
3. 低场生成内核没有稳定收益，保留为独立候选；后续应先测量幂、对数及
   中间量准备成本，再决定是否进一步优化生成表达式。
4. **两个开关保持默认关闭，R10 推荐、原 AD 及所有验收门限不变。**
   在稳定环境下重做同 VM 配对及完整曲线之前，不扩大本轮资格。
