# 会议材料使用说明

主报告：`report.md`。周期：2026-09-12 至 2026-09-17。

- 用支持 Markdown 表格与 LaTeX 数学公式的阅读器打开主报告。
- 请保留 report.md 与 figures、data、sources 的相对位置；转移到会议电脑时建议整体解压此目录。
- figures：11 张 PNG 和同名 PDF；算法流程同时有静态图片与报告内 Mermaid 源码。
- data：真实绘图数据、汇总及来源哈希，方便核对和更新。
- sources：证据报告与参数文本快照；这些历史文档的内部相对链接仍指向原仓库结构，不属于便携报告导航。
- 原始大型 TDR/状态归档没有打包。重画图需要原工作树 reference_staging 中的冻结证据。
- 生成图片的脚本原位置为 scripts/plot_templates_ldmos_group_review.py，包内保留副本供审查。

建议会议主线：报告第1节（结论）→第2节（算例）→第6节（结果）→第7节（性能）→第9节（下一步）。第3–5节及附录用于技术问答。
