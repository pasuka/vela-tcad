目标是让 Vela 真实支持 BVmethods 原版使用的动态非局部路径 BTBT，并提供可验证的
电子／空穴源项与导数。首版资格限定为该案例所需的二维三角网格、Si 同质材料、
等温漂移扩散、声子辅助过程、Fermi 和 OldSlotboom；不宣称完整覆盖 Sentaurus 所有选项。

均匀场、相应占据极限下的式(512)为
`Rnet = A (F/F0)^P exp(-B/F)`，`F0=1 V/cm`，直接过程 `P=2`、声子辅助 `P=2.5`。
它是性质测试与参数转换校验，不是动态路径实现公式。一般状态的净源仍按占据差决定，
不能强制套用正的均匀场生成值。内部统一约定生成 `G=-Rnet`，并核对 Vela 连续性行符号。

### 当前 Si 参数与单位

以下值已核查本轮原生默认导出；它们是此次参考身份，不自动成为所有材料／所有版本的全局默认。

| 参数 | 参考值 | 内部转换／约束 |
| --- | --- | --- |
| Apath | `4e14 cm^-3 s^-1` | `4e20 m^-3 s^-1`；单位不同于 E2 的 A2。 |
| Bpath | `1.9e7 V/cm` | `1.9e9 V/m`。 |
| F0 | `1 V/cm` | `100 V/m`；F/F0 始终无量纲。 |
| Ppath | `0.037 eV` | 能量转 J；N0真实400K控制已确认能量作用，派生常数见执行记录。 |
| Rpath | `0` | 自动质量分支；若使用归一化质量公式必须显式记录 m0。 |
| Dcpath／Dvpath | `0／0 eV` | 支持带偏移字段及其符号，零值也记录来源。 |
| MaxTunnelLength | `1e-5 cm` | `1e-7 m = 0.1 μm`，不得误当作10μm。 |
| m_c／m_v／Cpath／degeneracy／Dop／rho | 原生默认均为0 | 当前走 A/B 派生参数分支；先解析输入模式再校验，不能直接代零算式或以零质量报错。 |
| m_c_l／m_c_t／ldir_c | 默认零／零／零向量 | 当前不启用各向异性；非零选项首版拒绝。 |
| QuantumPotentialFactor／QuantumPotentialPosFac | 两载流子均为0 | 原版不使用量子势修正；非零请求首版拒绝。 |

Cpath 是组合量 `g Dop²/rho`，原生单位 `J²·cm/kg`；若扩展微观输入，其 SI 转换为乘0.01。
Dop 的 `J/cm` 转 `J/m` 乘100；rho 的 `g/cm³` 转 `kg/m³` 乘1000。
这些转换与输入模式优先级须有独立量纲／回转测试，不能复用 A2 的乘100转换规则。

N0已确认，当前OldSlotboom配置的A/B参考带隙包含材料常数偏移dEg0，
密度相关收缩仍只进入实际WKB带边。手册公开旧常数集的独立换算，在三种同态控制上
将双源误差降至约3.3e-10；该兼容链不得改动Vela其他模型的全局常数。
原生非局部导数参照必须绑定QS正偏置步，不能用初始化矩阵替代；见[N0证据](../../validation/bvmethods_nonlocalpath_n0_2026-10-15.md)。

### 源转移与边界

每条合法路径从唯一的起点积分权重生成一个有符号成对事件，将空穴放入起点支撑，
电子保守地放入终点重心支撑。先统一事件量，再产生两套积分；禁止分别独立归一化来掩盖不守恒。
需要核对起点采样、盒体积、终点映射、反射、重复路径和跨单元分摊。
手册未完整规定这些离散细节，不能把拟定的重心／盒规则表述为已确认的原生规则。

内部完整域账本须满足电子／空穴总事件量相等，局部源不要求相等。
Dirichlet 接触行被替换后，端点事件仍需在接触电流／自由节点源账本中闭合；
不能简单清零接触节点源来通过 KCL。绝缘体不接收载流子源；镜面反射不等同于隧穿穿过氧化层。
角点、零梯度、掠边、反复反射和数值退化单元要有确定性终止规则与诊断。
计算资源上限触发必须报告能力／数值失败，不得把未搜索路径静默算作零源。

### 导数与缓存

原版 `Math` 未声明 NonlocalPath，因此按手册非局部导数默认关闭。
但是“关闭非局部导数”不等于已证明“所有 BTBT 导数为零”或等于 E2 的 `frozen_field`。
N0/N5 要核对原生实际保留的局部项，建立三种具名记录：原版默认、原生显式 Derivative=1、
Vela 完整数学导数。显式导数控制不覆盖原件，也不与原版默认的 Jacobian 混为同一契约。

先用小网格、整套状态重新求源的中心差分建立独立 oracle，再为固定路径拓扑实现
解析／局部自动微分链：带边、起始方向、折点／端点、占据、BGN／人口依赖、前因子与指数积分。
不能只实现 dG/dψ，也不能冻结终点后称为完整导数。跨拓扑切换用双侧／单侧响应和事件标记，
不要求非光滑点具有同一个中心差分导数。

缓存分为纯几何缓存与状态路径缓存。ψ、QF、人口、温度、材料／参数、接触或网格变化时，
按真实依赖失效；线搜索试探态、拒绝步和下一次接受态不得混用。
路径决定的非局部列可跨越一环，必须在散射前注册；图变化时使符号分析／数值因子缓存正确失效。
首版优先实现确定的支撑并集＋缺项重建，记录额外非零数和内存，再优化。
Sentaurus Strategy=1/2/3 是收集策略而非不同物理；未实现的兼容选项不能忽略。

## 5. 验证矩阵与预算

### 独立性质测试

Catch2 测试检查物理或数值性质，不能只将同一实现函数的输出互相比较：

- 线性带边的解析端点、常数能量平移不变性、坐标旋转／反射对称性；路径长度与积分的网格细化。
- 声子辅助均匀场极限及参考质量转换，与独立高精度公式／积分比较；保持占据条件一致。
- 等温热平衡两端相同Fermi能的净源为零；非零占据差可生成也可复合，不截掉负源。
- A/B、温度和BGN的可分辨响应；A/B参考参数不随运行态BGN再次拟合。
- 单路径和多路径事件守恒，局部电子／空穴源位置不同；绝缘体、接触、反射和截断行为。
- 对ψ、电子QF、空穴QF的独立及混合方向比较 `Jv` 和完整重求路径的残差差分；
  缩步检验截断误差区间，弱行保留绝对尺度，不能仅报全局相对范数。
- 零更新、多次求值、拒绝步／线搜索、参数及网格变更不混缓存；动态图新增远程列可正确装配。

### 分层原生对照

| 层次 | 必须比较 | 不能用什么替代 |
| --- | --- | --- |
| 输入／状态 | 同网格、材料、参数、带边、人口／QF、接触、温度、缩放、实际后端 | 相同偏置不代表相同非线性中间态；降精度QF相减不代表内部驱动。 |
| BTBT算子 | 独立电子／空穴节点值及积分、位置、总事件量、非零区／尾部、截断计数 | 只比较 `Band2BandGeneration` 或一个总电流。 |
| 完整RHS | BTBT、输运散度、SRH、雪崩、Poisson分项与总残差、两弱行及其支撑 | 单个源闭合不代表整个残差闭合。 |
| 导数 | 相同状态与相同方向、支撑列、默认／显式导数分开；固定拓扑及切换分开 | 只比矩阵阶数、对角或全局L2；默认近似Jacobian不能当完整数学导数oracle。 |
| Newton／负载 | 线性残差、原始方向、投影／限制后方向、线搜索、内／外偏置及KCL | 首点收敛或减小外步长不代表算子正确。 |
| 轨迹 | 全部接受点、失败尝试、阈值BV、停止、电流分量、重复性 | 末点、电流模式、瞬态种子、辅助栅或旧E2恢复轨迹。 |

完整 RHS 通过后进行四臂控制：原生默认、原生显式非局部导数、Vela匹配默认、
Vela完整导数。前两者仍需各自验证实际保留的局部项；比较方程行映射和缩放后再比较矩阵元素。
这不要求两工具所有Newton迭代轨迹相同，但残差／线性求解／最终物理态必须各自合格。
若只有显式完整导数模式通过而原版默认模式失败，分别报告能力与限制；不能将前者改名为
原版默认数值契约通过。是否晋升新的数值配置须另有明确的范围变更记录。

### 门限制定方式

沿用原版总计划已冻结的负载／KCL／分量门：负载绝对误差 `<=1e-6 V`，
KCL相对 `<=1e-5` 与低电流绝对下限 `1e-12 A/μm`；位移比例 `<=1e-6`，
分量闭合相对 `<=1e-8`，既有绝对下限不变。
扫描停止为 `abs(Id)>=1.3e-3 A/μm`；BV以 `abs(Id)=1e-4 A/μm` 的内电压独立提取。
当前原生 SVisual显示6.67V、线性插值6.673594819V；不预设历史6.37V作为答案。

以下表格保留最初的 **N0评估用建议** 及其制定办法，不能继续当作当前未定任务。
N0执行后已在[版本化契约](../../validation/contracts/bvmethods_nonlocalpath_n0.v1.json)冻结正式工程预算，
包括同态源积分1e-6／加权L1 1e-5、RHS分项／弱行1e-8、方向导数1e-5，
以及自洽场量／曲线／BV的分层门。尚未实现的Vela能力没有通过这些门。

| 新检查 | 建议与确定办法 |
| --- | --- |
| 单路径积分／参数转换 | 光滑解析控制先要求相对 `1e-8`，独立提高积分阶数证明误差下降；近零使用有单位绝对误差。 |
| 成对源守恒 | `abs(sum(Se)-sum(Sh))/sum(abs(pair_events)) <=1e-12`；零事件要求两个积分均为零。分母用绝对事件量避免正负抵消，不以 `max(1,rate)` 隐藏小源。 |
| 光滑完整导数 | 可分辨方向建议相对 `1e-5`，至少三个步长观察一致区间；同时列逐行绝对差和弱行尺度，跨拓扑另行处理。 |
| 原生双源／完整RHS／场量 | N0先测输出精度、状态转移误差与原生网格细化误差，给出积分、加权L1、分位数／峰值及弱行分别预算；正式数值未定前不能将N4/N5标通过。 |
| 全轨迹／BV | 建议BV差 `<=0.5%`，可分辨电流区的曲线差先评估 `<=2%`；须固定比较内电压还是外电压、插值、低电流下限及全部覆盖区间。先证明原生／离散误差预算足够，再在N0定稿，不根据Vela试算反调。 |

若建议值缺少精度依据，N0 报告后按证据定稿并记录理由；不能默认为宽门已获用户同意。
模型正确性、离散误差和求解误差分别登记，不将经验常数／QF偏移／源比例调参用于过门。
