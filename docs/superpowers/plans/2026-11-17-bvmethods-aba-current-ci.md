# BVMethods ABA 与转电流数值回归计划

在 `codex/bvmethods-aba-current-ci` 实施，初始提交为本地 `main` 的 `260ab965`。交付 Poisson ABA、耦合 ABA、电压转电流三个端到端 CTest，保留外接电阻 BV 回归，在 T470p 和 C560 各自编译并完成验收。

## 1. 生成 Sentaurus U-2022.12 原生参考

- 通过 Vela VM 的 Sentaurus 环境核对 sdevice 的完整版本、安装库方法脚本、参数及网格来源。使用已有外接电阻 U-2022.12 归档的网格和参数作公共基准，核对 TDR/GRD/DAT 的来源与哈希、区域、接触、掺杂和 300 K 温度。用相同的物理常数配置构建 Vela。
- 在独立目录生成三个可运行 CMD。公共物理沿用外接电阻算例的适用参数，配对组统一关闭 BTBT。保留各方法原生定义的阶段、雪崩驱动力、后处理开关、目标和步长。若安装库脚本的公共物理与该基准不同，保留原始脚本并逐项记录派生 CMD 的改动；两端模拟使用同一份匹配输入。Poisson ABA 的扫描只解 Poisson，耦合 ABA 的雪崩源仅参与后处理。各自使用方法脚本的终止条件。
- 先验证版本、许可、输入身份及初始化，再独立运行三个完整原生流程。保存 CMD/PAR、网格回执、PLT、必要 TDR 和 Newton/步长日志。从日志与结果中提取各阶段状态、接受点、失败重试、实际停止原因、积分及电流曲线。新 U-2022.12 数据构成正式验收参考，旧 O-2018.06-SP2 数据保留为历史对照。

## 2. 实现并核对 Vela 执行路径

- 通过 `sd-sim` 从匹配 CMD 生成并实际执行各阶段。耦合阶段选择 `potential_density`，记录采用的电势和载流子浓度坐标及 Unit 缩放。Poisson-only 阶段仅以电势为未知量，按现有统计规则构造所需载流子量。转电流阶段从最后接受的电压状态起步，以该状态的实测端口电流确定初始目标。
- 依据实际 U-2022.12 CMD 核对每个 Quasistationary 阶段的 `InitialStep`、`MinStep`、`MaxStep`、`Increment`、`Decrement`、`Extrapolate`、迭代预算和端点裁剪。以归一化进度及实际物理量分别核对记录。电流段使用切换后的实测起始电流与目标电流之差换算步长。短程比较首个目标、接受增步、失败缩步及从最后接受态重试的行为，标出首次轨迹分叉及其原因。
- 现有前端已有电流起点绑定，DCSweep 的 `newton_iterations` 目前限制在相应的电压路径，电流阶段有离散目标入口。为当前三个用例补齐脚本到控制器的实际语义，包括所需的 Poisson 自适应和电流自适应推进、状态交接和终止原因。现有电流目标列表调用继续兼容。对存在差异的原生步长或停止行为保留记录，由实际运行证据确定可作等价验收的范围。

## 3. 新增数值 CTest

复用 `bvmethods_ci_stage` 的 DF-ISE 输入校验及 `VELA_ENABLE_BVMETHODS_CI`，让各用例拥有独立工作与报告目录。保留 `sdevice_e2e_gates` 的输入检查。用结构化结果判定各阶段、有限性、数值质量、终点与必要输出。

| 用例 | 核对内容 |
|---|---|
| Poisson ABA | 初始化和 Poisson-only 扫描、分载流子积分、排名口径、原生实际积分停扫与阈值跨越区间 |
| 耦合 ABA | 电势与浓度求解、雪崩后处理、积分停扫，以及有原生覆盖时单独比较雪崩电流与端口电流交点 |
| 电压转电流 | 电压目标、端口切换、起态交接、按命令自适应跟踪电流、目标或停流原因、KCL 和参考电流处的内压插值 |

按 U-2022.12 参考的物理量、采样和输出精度登记验收依据。历史门限只在定义一致时复用，候选失败或采样差异不作为放宽门限的依据。参考点不足以判定某项时，补充同版本原生证据再判定。超时、错误的终止事件和缺少关键输出均不能通过。

## 4. 双机编译、数值验收与归档

- T470p 使用 Windows MSYS2 UCRT64 的 `windows-ucrt64-release-sentaurus2022`，C560 使用独立 Linux Ninja Release 构建。两机分发同一候选源码快照，记录编译器、常数、实际求解后端与运行库、输入和二进制哈希。以现有回归的单线程配置运行。
- 两机均先跑相应 CMD、步长控制、积分和电流边界测试，再跑三个完整用例及既有外接电阻 BV。比较各阶段、停止原因、接受与重试、曲线误差、Newton 轮数和耗时。两平台各自满足同一物理验收，跨平台轨迹差单列，若求解器分派需诊断则保留原始结果和独立复测。
- 三个新用例及原外接电阻 BV 在两机验收后收口，归档参考源身份、运行状态、CTest JUnit 和逐项数值报告。执行时若缺少安装库入口、必要原生数据或可用许可，只补报具体缺项。
