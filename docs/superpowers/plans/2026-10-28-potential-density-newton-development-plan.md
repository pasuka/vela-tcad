# 电势／浓度主变量 Newton 模式：评估与开发计划

日期：2026-10-28。状态：评估完成，待后续实施；本文不表示求解模式已经接入。

用户要求评估新增与本轮 Sentaurus 观测相对应的 ψ/n/p 主变量模式并制定计划。
本次仅增加设计文档，没有修改求解行为、模型、验收门或启动远端仿真。
后续执行以用户授权范围和届时源码为准。

## 1. 判断和首期范围

建议新增显式可选的电势／电子浓度／空穴浓度模式，保留现有 QF 模式。
浓度成为非线性状态的权威值；QF 是由相同材料、能带和统计关系导出的物理量，
供 GradQF 迁移率、碰撞电离、输出等使用。新模式必须进入 vela_core 和标准 JSON/CMD
执行路径，不能只增加另一个私有诊断驱动。

这能统一线性方向坐标、有限人口更新、局部正值检查和重启状态，减少重复的正反统计换算。
局部检查本身只是逐节点算术，但端到端是否更快，仍由迭代数、失败尝试、算子求值和
线性求解决定。现有证据不足以承诺与 Sentaurus 相同的节点集合、迭代次数或速度。

首期资格限定为当前 BVMethods 的 300 K、经典等温 Tri3、Joyce–Dixon／OldSlotboom、
总杂质迁移率、SRH、GradQF Van Overstraeten AV、BTBT 关闭和单接触固定外电阻。
接口应允许后续扩展；其他统计、PN2D 算子、量子、电热和其他接触类型须独立验收。
不能将 BVMethods 的资格自动推广到 PN2D，或改变 PN2D 模板的原子离散化组合。

## 3. 数学与状态契约

令旧坐标 x=(ψ,fn,fp)，新坐标 y=(ψ,n,p)，统计映射为 x=Φ(y)。
在映射可微且可逆的正人口状态、物理模型相同、行定义相同的条件下：

\[
F_y(y)=F_x(\Phi(y)),\qquad J_y=J_xD\Phi(y).
\]

这里下标表示坐标，不表示更换物理方程。新模式最终直接装配 J_y；旧 J_x 的列变换
作为独立数学对照。直接装配与列变换不要求浮点逐位相同，应使用缩放后的误差和独立差分判断。
若两者使用同一物理状态、相同完整 Jacobian 与 RHS，并精确求解，则人口切向方向应一致。
所以新增模式的价值是权威状态、装配算术和有限更新路径，而不是凭坐标名改变 Newton 理论。

线性代数内部仍允许相对人口列缩放 δn=s_n z_n、δp=s_p z_p。
以当前相对缩放为首个控制，s_n=n、s_p=p，并在每次装配中固定尺度。
这不是 log(n)/log(p) 未知量；有限更新使用 n+δn，不使用 n·exp(z_n)。
矩阵缩放、物理单位和误差参考浓度必须分别记录，避免把误差参考浓度误当作人口下限。
极小浓度下避免先形成巨大 1/n 再乘回 n 的中间量；不可表示的结果须明确失败。

耦合 Poisson 行在固定 n/p 时，电荷对 ψ 的导数不再包含旧 QF 坐标下的人口响应。
Poisson 初始化仍可采用平衡统计 n(ψ)、p(ψ) 的独立标量问题，其 Jacobian 可以包含该响应。
二者是不同子问题，不能通过直接复制旧 Poisson 块完成迁移。

首期复用已核验的 JD／BGN 契约；fn/fp 的反函数及导数必须同源。
若将来支持依赖人口的能带、BGN 或其他材料模型，DΦ 中必须包含对应交叉导数，
不能永久硬编码为只依赖本节点单一浓度的对角关系。

自由半导体节点要求 n>0、p>0 且有限；氧化层不建立虚构的正人口。
初版可保留 3N 存储中的非活动占位槽和原消元映射，明确其非物理含义。
当前网格的增广完整系统仍为 7801 维；相同自由度／约束下目标自由系统为 6765 维，
由实际约束映射验证，不能通过裁剪物理行或任意补零凑维数。

## 4. 每轮更新、保护和收敛

首个参考模式固定完整物理导数、局部非正候选保护和已封存的非线性控制参数。
局部保留比例以原生观测的 0.01 建立比较基线，0.1／0.5 为显式实验参数。
不把新模式是否可用与某个比例必须通过完整 BV 混为一谈。

每轮顺序为：

1. 从权威 ψ/n/p 状态构建共享物理视图，评估完整 F、J 和端口量。
2. 缩放、精确约束消元、PARDISO 求解、回代，检查原线性后向误差。
3. 保留原始 δψ/δn/δp/δVin；计算候选 c+αδc。
4. 若选局部模式且候选非正，仅将该自由节点人口替换为 βc；正候选照常更新。
5. 更新边界并验证域、统计及状态，重算真实 RHS、端口／负载和误差指标。
6. 未收敛则重新装配，下一轮重新逐节点检查；失败恢复完整上一接受状态。

局部保护并不保证完整步使残差下降。应独立配置整体步接受策略：
局部基线采用本轮原生对照的完整步／只报告线搜索设置；其他必要的电路限步显式记录。
不能在其内部悄悄启用全局到边界缩步。全局模式保留为独立对照；自适应混合不作为首版基线。
若随后启用实际回溯，每个 α 的人口候选须重新检查，不能先投影再简单缩放已投影状态。

误差沿用原始人口方向为分子、实际更新人口为分母的既有 RMS 契约；投影后的小增量
不能取代原始方向来制造收敛。器件残差、负载线、KCL、逐行和全局守恒的 enforce/report
属性保持原配置。单独记录“停止门通过”和“守恒报告通过”。

后续导数恢复若需要近似 Jacobian，应从分块直接装配冻结项，复用同一完整 RHS；
不能继续用完整矩阵减去巨大实时导数来构造微小系数。该项与人口主变量迁移分开提交和验收。

## 5. 边界、端口、延续和存储

接触 n/p 由原接触物理与同源统计确定，保留偏压、材料和内压依赖。
不能无条件将旧 QF identity 行的系数复制到浓度列，也不能假定接触浓度总与电压无关。
接触约束元数据、非零 RHS 修正、恢复偏移量和活动节点集合需独立测试。

外电阻增广系统为：

\[
\begin{bmatrix}J_y & F_v\\R I_y & 1+R I_v\end{bmatrix}
\begin{bmatrix}\delta y\\\delta v\end{bmatrix}
=-\begin{bmatrix}F\\v+RI-u\end{bmatrix}.
\]

所有偏导按新坐标的固定量定义；映射或边界依赖 v 时须包含相应链式项。
PDE、端口电流和其导数必须读取同一份人口状态，不能一个使用原始 n/p，另一个使用 QF 重建值。
验证增广 RHS/Jv、消元回代和电流单位 A/μm，电阻 Ω·μm。

延续初版先用上一接受态，固定目标序列比较单点求解；之后单独加入人口空间线性外推。
外推可能产生非正人口，必须定义独立的预测无效处理并记录；首版建议拒绝该预测并回到上一接受态。
这不等同于一次 Newton 局部保护，且不能增加或跳过未记录的接受点。
公平比较需要相同预测起点；不同坐标下各自外推的端到端比较另列。

保存／重启明确记录 state_variables、schema、单位、活动掩码／网格身份和物理参数身份。
新模式读自己的归档时使用 ψ/n/p，派生 QF 不能覆盖权威人口。
旧 QF 归档通过显式一次转换导入，记录转换误差；不兼容 packed/reference/hi-lo 状态应明确拒绝。
要求连续运行与中途保存重启在声明的容差内等价。

## 6. 建议配置接口（尚未实现）

以下为拟议字段，不是当前可执行配置：

```json
{
  "solver": {
    "state_variables": "potential_density",
    "population_update": {
      "protection": "local_nonpositive",
      "local_retained_fraction": 0.01
    }
  }
}
```

`state_variables` 缺省继续使用现有 QF 模式；新字段使用枚举和严格校验。
全局模式的 fraction_tau 与局部 β 分开定义，输出实际采用的策略；未选择的模式参数不得误示为生效。
先要求显式已有 BVMethods 物理配置和新坐标选项；现有 `bvmethods_tri3_qf` 名称如何兼容
应在 P0 定案：保留旧名作为旧模式入口，或增加中性物理 profile 别名，不静默改变旧名语义。

CMD 不具备已证实的同名坐标关键字映射。通过显式 Vela sidecar／入口选项选择新模式，
使 --check 和实际执行生成同一有效配置；不伪造 Sentaurus 语法。

## 8. 验证矩阵与资源分配

1. 小型可解析问题：固定材料的 Poisson、均匀平衡零电流、受偏压 SG 输运、正负人口方向、
   非零接触 RHS 与外电阻解析负载。检查数值／物理性质，不仅复写实现规则。
2. BVMethods 同态分阶段：Poisson 初始化、联立零偏、前五个非零外压点。
   Poisson 初始化与耦合 Poisson Jacobian 分开核验。
3. 困难窗口：旧 0.216012467 V、0.756271783 V、健康 1.25 V 到 1.375／1.5 V。
   包括电子 384／542／533 和空穴 632／654／710 的弱行，另测完整 Jv 与随机活动人口方向，
   不能只测试自身对角系数。
4. 三条同态路径：旧 QF 加法、新核心人口模式、现有人口方向诊断适配器。
   比较原始方向、非正候选节点集合、保护前后人口及 QF、每轮物理账本。
   纯坐标等价是 Vela 内部检验；Sentaurus 集合不一致时继续拆分状态、算子和线性化策略差异。
5. 局部 β=0.01 基线、β=0.5 实验、全局 τ=0.99 对照分别运行，不混入自动策略选择。
   首先固定完整导数；恢复策略和近似导数单独引入后，完整 RHS 必须保持。
6. 原有线性精度、物理／负载／KCL 门不变；继续记录逐行和全局闭合。
   新算子一致性阈值在 P0 依据缩放、浮点误差预算和差分平台预先登记，
   不能看到结果后反向调整。近零项同时给出绝对差、尺度和可分辨性，不能仅用相对误差。
7. T470p：Windows UCRT64 Release/PARDISO 验证；C560：Linux Release/PARDISO 独立复核。
   同一机器配对测耗时，使用相同线程、目标／初态、物理和输出量。
   各机时间不能直接互作性能基线。Sentaurus 运行保持独立环境与同物理控制。
8. vela VM：P4 局部资格通过后冷 Poisson 完整 BV，固定原 R=1e7 Ω·μm 和
   停止电流 1.3e-3 A/μm。运行预算和周期监控按届时授权设置；本计划不创建作业。
9. 性能报告分别列接受／失败尝试、每点更新数、RHS／J／端口求值次数、装配／分解／回代耗时、
   峰值内存、nnz 与输出时间。另作关闭大诊断输出的普通 Release 配对基准。
10. 运行对应 Catch2、配置／CMD／状态归档回归；共享接口接入后完成匹配配置的全 CTest。
    PN2D 默认路径需保持原模板资格和契约，首期不宣称新坐标支持 PN2D 全物理。

矩阵对照必须统一坐标、行缩放、自由度与消元映射，分别报告存储条目、严格非零数和
显著位置／数值；不能通过丢弃微小物理系数或要求 nnz 总数相等来证明正确。

## 9. 风险与决定点

- 原始完整导数的弱行负斜率可能继续存在；直接人口模式不保证完整步全局收敛。
- 稳定平衡电流算术比“直接相减两个大电流”重要，不能为减少 QF 换算而破坏原 log-ratio／expm1 契约。
  派生 QF 差应尽可能直接从统计势差构造，避免大绝对电势抵消；其改变须单独差分验证。
- 浓度量级跨度和极小人口仍可能导致病态或下溢。列缩放与求解精化需保留；
  不增加未授权密度 floor、固定 QF 限幅或误差放宽。
- 近似导数的相减精度缺陷须独立修复，不能期待坐标迁移自动恢复已丢失的系数。
- 局部正值保护只是状态域处理，不是残差下降或守恒保证。1% 和 50% 都不能预先承诺全程最优。
- 首期继续显式启用；完整 BV 和回归资格完成后，另行评估是否将 BVMethods 的新模式设为默认。
  不在本计划中变更全局默认或将历史已通过报告改写为新模式资格。
