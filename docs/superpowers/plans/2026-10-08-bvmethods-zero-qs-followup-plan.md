## 1. 目标、基线与判定边界

目标是在原模型、材料、网格、固定栅压和固定电阻下，取得从 0 V 开始的完整纯电压 QS 轨迹，
达到原漏极停止电流；解释现有失败，并将有证据支持的 Vela 修复完成跨平台验证。

实施前基线为本工作树提交 `a0ed4e073efee0214c39365d3be90a12be51c624`。
两个已验收发行包的运行时代码仍绑定 `0a89942e`，后续新结果须记录实际源码及 runner 身份。

冻结输入：

- `reference_tcad/bvmethods_sentaurus2018/source/external_resistor_sdevice.cmd` 和 `models.par`。
- 原网格 2600 节点、5020 单元；SHA-256
  `7cd3968f5dd0e3cd63ef62ed0fcced465dd33bea465167f0be8139c16025902e`。
- 300 K；`R=1e7 ohm*um`；源、栅、衬底外电压保持 0 V；栅 Barrier 为 −0.55 eV。
- 保留 Fermi、OldSlotboom、DopingDep/GradQF/Enormal 迁移率、SRH(DopingDep)、
  Band2Band(E2) 和 Avalanche(Eparallel)。
- 漏极外电压 Goal 为 100000 V，原停止值为 `1.443e-3 A/um`；达到声明停止条件可提前结束。
- 长度 um、密度 cm^-3、原生终端电流 A/um；转换时明确 Vela 内部单位与终端符号。

最终资格要求每次独立运行从零初始化、全程固定其他电极偏置、保持原模型与停止值。
重载诊断态、瞬态种子、辅助栅、电流控制或伪弧长只能用于诊断，不能替代该资格。
`Math { Transient=BE }` 不等于执行瞬态；以实际 Solve 语句判定。
历史 v1 的 NonLocalPath/GradQuasiFermi 模型和 `1.3e-3 A/um` 停止声明不替代当前基线。

分别报告两个结果：

1. Sentaurus 原生固定栅压从零纯 QS 是否通过。
2. Vela 对同一物理输入的从零纯 QS 是否通过，以及对照覆盖范围。

Vela 通过不能证明 Sentaurus 原生路径已修复；原生通过也不能代替 Vela 数值验收。
现有 v4 只具有瞬态获取、独立稳态及停止值以下 QS 续扫的资格。
本计划不预先保证原生求解器在现有接口下可以取得完整原路径，也不将两个解的存在作为动态稳定性证明。

## 2. 已知证据与优先问题

原路径在外电压约 14099.811 V、内电压约 7.16026 V、电流约 1.409265 mA/um 处失败。
13 组原生控制及两组辅助栅控制已归档；大外步长、二阶预测、分组求解、电流控制未消除失败。
辅助栅只达到约 0.0966955 V，没有到 0.2 V，恢复零栅压后回到原支路。
这些已失败组合不作为无新证据的重复试验清单。

同一外电压 13 kV 下，正向纯 QS 与 v4 反向分支的内电压分别为 7.134202 V、6.637744 V，
两者负载与 KCL 都通过，但源/衬底电流分配不同。首要问题是：

- 原支路附近是否存在负载线折点或接近奇异的器件/电路耦合？
- 失败由预测越过有效区域、稳态校正失败、导数不一致还是分支获取造成？
- Vela 的现有标量电阻控制与耦合 Newton 在该区域有何差异？
- 原生与 Vela 的材料、接触、电流约定及数值离散是否已足以支持该对照？

不将寄生双极、负微分电阻或具体 Jacobian 缺陷预先写成已确认根因。

### Q3：候选选择顺序

候选是条件分支，先完成 Q2，再决定实现项；不预先认定某算法必须替换现有默认。

1. 若查实状态恢复、单位、符号或 Jacobian 一致性缺陷，优先最小修复，并增加能揭示该缺陷的物理/数值性质测试。
2. 若标量电阻根搜索的局部单调假设或耦合校正成为瓶颈，对照已有 `nested_scalar` 与
   `coupled_newton`；检查其适用条件、负载残差与接受策略，不能仅因日志收敛而晋升默认。
3. 若预测与实际内部响应失配，尝试同时约束外电压目标、内部电压变化和电流增量的预测/校正策略，
   使用 `Delta Vouter = Delta Vinner + R Delta I`。只增大外步长不再作为独立未经解释的修复方案。

伪弧长、电流控制、反向恢复和 v4 保存态可定位分支，但须输出为诊断控制。
若唯一成功方案需要瞬态、辅助栅、改变物理或网格，则报告它取得的独立资格及原路径仍失败；
涉及物理模型、验收条件或任务范围的变更，先明确其影响再由用户决定，不自行替换契约。
Sentaurus 内部求解器不能通过修改 Vela C++ 修复；原生与 Vela 的实现问题分别处理。

### Q4：资格门限与完整性

沿用 `scripts/validate_wp14_zero_qs.py` 的原路径要求，以及以下既定状态预算：

| 项目 | 既定门限 |
| --- | --- |
| 原停止电流 | `abs(Id) >= 1.443e-3 A/um`，必须与原生停止信息相符 |
| 负载关系 | `abs(Vouter - Vinner - R*Id) <= 1e-6 V` |
| 终端 KCL | 相对误差 `<=1e-5`；低电流绝对下限保留 `1e-12 A/um` |
| 位移电流 | 比例 `<=1e-6`，沿用校验器的极低电流绝对下限 |
| 电流分量闭合 | 相对误差 `<=1e-8`，沿用校验器的极低电流绝对下限 |
| 轨迹来源 | 从零起点；其他电极固定；单调外电压；无瞬态/Load/电流模式切换 |

每个接受点均需通过，不用好终点覆盖坏中间态。MinStep、线性系统失败、阶段未到目标、
巨大分量抵消和不完整 PLT 都保留失败结论；exit=0/Good Bye/Save 文件不能单独证明通过。
两次独立运行用于确认轨迹、支路及停止的重复性，不证明动态稳定性或唯一性。

这些门是原生轨迹资格，不能自动充当 Vela/native 全空间场量验收。
NMOS 跨工具场量首先按具名匹配状态报告误差与掩码；若新增正式空间资格，
须在检验候选前固定其依据、误差预算和覆盖范围，不能沿用 PN2D 十点门来冒充 NMOS 契约。
两平台 Vela 对照先固定相同配置、后端与线程，采用对应测试/案例原预算；
没有既定预算的量在候选比较前确定并写入清单，不根据失败结果放宽。
