# sd-sim 入口与 SDevice CLI 兼容计划

日期：2026-10-23。用户决定：名称采用 `sd-sim`；尚未实现的选项先预留并明确拒绝，
包括 `-d`，不在本轮开发数值调试导出。此计划替代此前聊天中“立即实现 -d”的顺序。
范围是命令入口与兼容边界，不扩展物理模型、BVmethods 研发或数值验收门。

## 依据与支持边界

以 Sentaurus Device User Guide T-2022.03 附录 D（印刷页 1511–1513）为参数核对依据；
完整状态表见[当前 CLI 文档](../../sentaurus_sdevice_workflow.md#21-调用形式)。
参考值、材料参数或字段名称输出不得冒充完整原生能力；私有采集工具不能算公共 `-d` 已完成。

## 顺序与退出条件

| 阶段 | 工作 | 状态及退出条件 |
| --- | --- | --- |
| C0 入口 | 新增 `sd-sim <cmd>`；保留 `vela device <cmd>`；两者共用前端与环境变量 | 本轮实现；要求原生启动器参数、退出码、路径及 zipapp 直跑回归通过 |
| C1 预留与边界 | 为未实现选项添加帮助与 E202；裸 `-P` 与按材料/脚本导出分开 | 本轮实现；预留项退出 2，不启动 runner、不修改输入或生成仿真输出；未知选项仍拒绝 |
| C2 语义补齐 | 实现原生 `-n` 日志过滤、`--max_threads` 上限；核实并修正 `-i` 初始解保存 | 待后续开发；目前 `-n`/`--max_threads` 预留，`-i` 明示仅首发射阶段；旧检查/线程设置改用 `--check`/`--threads` |
| C3 材料与辅助输出 | 按脚本/材料导出 `-P/-L`；字段、可扫描参数及编译器信息 | 待后续开发；逐项以真实支持集合实现，不输出虚构 PMI 索引或把全部 JSON 键当作可扫描参数 |
| C4 数值调试 | `-d` 设备 Newton、真实增广外电阻及失败试步导出 | 明确延期；当前仅预留接口，不纳入本轮实现或验收 |
| C5 发行验收 | Windows 与 Ubuntu 26.04 新包包含 root/bin 双入口；迁移、并发和相对 RUNPATH | 构建/安装/打包规则本轮更新；完整两平台发行包验收待后续，旧归档资格不自动继承 |

`-M/-S/-r`、Tcl、XML、已安装版本选择等均保持具名预留，按后续实际需求逐项安排。
从 stdin 读取仍未实现：无命令文件时报用法错误，不静默读取。

## 后续 -d 的契约草案

绑定阶段、电压、Newton 轮次及接受/失败身份；区分装配 R、求解 b=-R、Jacobian 和
约束/缩放后的实际系统。附变量单位、行列/接触映射、掩码、缩放及原始/实际更新。
真实增广路径须包含内压未知量、负载行和交叉导数。可采用 Matrix Market + 向量 + JSON
元数据；不承诺复刻原生私有 debug 文件格式。采集截断必须明示，开启/关闭时数值结果、
轨迹及退出码应一致。实现前重新审查契约，本轮不修改求解器。
