# sd-sim ExtendedPrecision 端到端 80 位开发计划

日期为 2026-11-18。本文用于实施评审和验收，所列开发工作与数值验收均待执行。

## 1. 背景

当前 `sd-sim` 已能识别 Sentaurus `Math` 段落中的 `ExtendedPrecision`、
`ExtendedPrecision(80)` 和 `-ExtendedPrecision`。前端会将精度配置写入各阶段
JSON，并选择对应的 runner。现有 `extended80` runner 只扩大部分中间算术的精度。
权威状态、稀疏矩阵、线性接口和状态存档仍有 binary64 边界。`sparselu_long_double`
从已装配的 binary64 系统取得输入，返回方向时再转换为 binary64。

SLOT LDMOS 的已有对照说明了加宽范围的重要性。冻结矩阵上，80 位写回降低了
线性化负载线缺陷。0.10 V 同态装配中，只加宽局部准费米势求值仍未复现
Sentaurus 单元 7095 的偏导符号。端到端精度、局部模型对齐和非线性收敛需要各自取得证据。

## 2. 目的、范围与交付

- **用户行为**。用 `sd-sim` 运行现有 Sentaurus 脚本时，`ExtendedPrecision` 或
  `ExtendedPrecision(80)` 请求端到端 80 位。省略该项或显式关闭时走既有 binary64
  路径。同一脚本经前端拆分、保存、加载和重新生成阶段后，精度请求继续生效。
- **精度定义**。对进入求解的实数，在可取得原始数值的最早入口按 `long double`
  解析或加载，并在派生计算、权威状态、残差、Jacobian、线性求解、试步、
  停止判据、器件接受、续算和跨进程交接中保持 80 位。已量化的外部输入可无损升精度，
  其来源精度应记录。整数索引、拓扑及仅供展示的副本沿用现有表示。
- **首批范围**。SLOT LDMOS 的电势＋浓度 BVDS，采用绑定的 13,881 节点网格、掺杂、
  材料与兼容常数配置。覆盖 Poisson 冷启动、首次耦合、外接电阻增广 Newton、
  0.10 V 短扫、断点续算和 `Save/Load`。完整保留该配置实际启用的物理、约束、保护
  和判停语义。其他算例、求解路径和未覆盖的脚本选项通过能力检查明确报告，后续逐项扩展。
- **交付物**。80 位构建与分派、上述路径的类型迁移、版本化权威存档与阶段交接、
  精度能力和测试日志、用户配置文档，以及 Vela 虚拟机上的复现实验报告。

构建使用现有的双 runner 结构。80 位能力以 `numeric_limits<long double>` 的实际
格式检测为准，要求基数 2、64 位有效尾数和 16384 的最大指数。现有混合精度实验仍有
诊断价值，应有可区分的执行标识。严格请求在平台、构建或算例能力不足时应明确失败，
错误中给出具体阶段或后端，且不得发布该阶段为已接受结果。

## 3. 实施步骤

| 工作包 | 实现内容 | 阶段退出条件 |
|---|---|---|
| **WP0 精度契约与基线** | 绑定版本、网格、模型、单位、外电阻、接受规则及实际后端。登记输入、在线状态、输出和环境变量覆盖点。冻结现有 binary64 的一条确定性参考轨迹及两份 39,150 维对照系统。定义同构建回归方式、报告单位、性能测量和物理比较的参考样本。 | 每个精度边界都能指到生产入口、消费方及一项验证。参考数据带配置、程序、网格、掺杂和材料身份。 |
| **WP1 前端与构建分派** | 扩展 `cmd_parser`、`deck_emit`、`orchestrator` 和 runner 检查。审核 `.cmd`、`.par`、侧车 JSON、网格/掺杂输入及 \(V_T\)、DOS、参考势、单位换算等派生计算。对权威文本数值保留字面量并直接按目标标量解析。记录每阶段请求值和实际运行能力。 | 脚本选项经真实入口传递，每阶段均保持请求。缺失 80 位构建、错配 runner 或不受支持的后端有可复现的错误。 |
| **WP2 主状态、冷启动与物理装配** | 在共用数值实现中按标量类型实例化状态、稠密向量、局部 AD 和稀疏矩阵。覆盖 `CoupledDDState`、`DDSolution`、`ArclengthState`、Poisson 末态交接、接触目标、SG、IALMob/HFS、复合和雪崩。电势＋浓度路径由同一份权威状态生成输运和源项操作数；残差和直接浓度 Jacobian 使用相同的缓存和分支。 | 0 V Poisson 与首次耦合之间保留主变量低位。同态回放可核对 SG、7095 的梯度及偏导、Poisson/连续性/电路块和 RHS。 |
| **WP3 线性系统与非线性更新** | 将散射、增广 \(A,b\)、约束消元与恢复、行列缩放、精化、端口电流及导数接到同一标量类型。通过 `Eigen::SparseLU<Eigen::SparseMatrix<long double>>` 接收宽矩阵和 RHS，方向全程保持宽类型。审核 `PopulationCoordinateNewton`、`CoupledLoadLine`、线搜索、保正、\(E\) 判据、实际写回和失败缩步。算法的舍入与范围判断使用目标类型，配置阈值保持原义。 | 同一冻结系统可对照 80 位方向与同方向降精度后的缺陷。正常路径以及失败、回退分支均可追踪，宽模式不会转入 binary64 后端。 |
| **WP4 持久化与续算** | 版本化 `DDSolutionState`、`StateArchive` 及相关读写接口。权威记录包含 \(\psi,n,p\)、参考势和尺度、器件内压、外电源值、跨阶段实际端口电流及续算所需状态。选用规范化二进制编码或等效无损格式，记录精度、编码和版本。让 `rebase_stage` 与 `bind_current_start` 消费无损交接记录。 | 独立进程复读保留有效 80 位内容。下一阶段种子和重新装配结果可与连续运行对照。旧 binary64 存档的显式升精度能追踪到原始格式。 |
| **WP5 集成验收与发布** | 通过真实 `sd-sim` 入口跑首批算例。核对脚本、实际后端、每阶段精度和保存态身份。完成默认路径回归、安装包试跑和错误路径测试，记录低压对照电流、守恒、负载线和成本。 | 数值验收、安全退出和默认回归均有证据后，才对首批范围发布端到端 80 位能力。 |

实施顺序为 WP0 → WP1 → WP2/WP3/WP4 → WP5。WP2 至 WP4 可以按接口并行推进，
共享状态和存档契约在集成前统一。调试先使用固定矩阵及少量冻结态，再进入冷启动和
短扫。长扫描有单独的验证范围与运行预算。

## 4. 总体验收标准

| 编号 | 验收内容 | 合格证据 |
|---|---|---|
| **A1 脚本、runner 与安装包** | 检查省略、开启、`(80)`、关闭四种输入。检查不支持位宽、缺失 runner、设置矛盾和使用失配后端。 | 真实 CLI 从安装包完成对应分派。阶段日志可查请求、实际标量格式、后端和退出码。错误分支在发布接受态之前停止。 |
| **A2 低位贯通** | 用 \(1\) 与 \(1+2^{-60}\) 这样的可分辨对照。分别放入原始文本输入、测试矩阵、线性方向、写回对象和存档。下游采用与该数据相容的单位与增量。 | 80 位路径在每个被测边界仍能区分两值，binary64 对照给出预期合并结果。测试消费生产接口实际取得的数据，覆盖残差、装配、求解、写回和复读。 |
| **A3 局部物理和线性质量** | 对同一权威 \(\psi,n,p\) 核对 SG、7095 梯度、雪崩偏导、分块 Jacobian/RHS、接触电流与负载线。冻结 \(A,b\) 并比较同一方向的 80 位和降精度副本。 | 源项与导数身份一致，可用独立回放核对。在线性原坐标独立重算 \(Ad-b\) 和分量后向误差，按绑定配置的现有门限判定。跨软件系数及电流差异独立报告。 |
| **A4 短扫、保存与继续** | 用真实 `sd-sim` 完成 0 V Poisson → 首次耦合 → 0.10 V 外电源短扫。将连续运行与 `Save/Load` 后的同目标续算比较，固定影响重复性的运行条件。 | 目标点按原判据接受，报告外电源与器件漏压、Newton 次数、分载流子电流和负载线。存档复读后的权威状态有效位一致，下一次装配的矩阵、RHS、端口和接受决定符合确定性对照。在报告模式下，超限项照实标出。 |
| **A5 默认回归与失效行为** | 运行已有解析/分派、线性、Poisson、状态、SLOT 及受影响默认配置回归，集成阶段运行完整 Debug CTest。覆盖读旧档、错误精度标签、线性失败、失败试步和阶段重启。 | 测试实际执行并通过。既有 binary64 路径满足冻结基线。失败候选不会保存为成功点或成为下一阶段父态。运行时间和峰值内存与基线配对记录。 |

A2 验证可表示低位的传递。真实 Newton 更新的低位变化另行记录。
A3 的跨软件比较用于定位物理或离散差异。能否缩小 7095 的剩余差异、把报告模式下的
负载线压到 1 µV 内，均需独立的数值证据。验收报告应分别记录精度契约通过、器件接受、
负载线状态及迁移到其他算例的资格。

## 5. 风险与记录

- **接口间隐式降精度**。优先检查 `double` 固定的 Eigen 类型、表达式转换、AD、临时数组、
  回调返回值和序列化。以逐边界受控测试及实际调用记录支持结论。
- **外部数据先天量化与近零相消**。保留输入精度来源。在内部坐标先构造势差，并把高精度
  状态传播、模型参数差异和纯算术重排分开测量。
- **排序、因子填充与性能**。固定后端和线程设置，配对记录分解时间、非零元填充、内存、
  每点更新与重试。根据首份完整基线确定后续性能目标。
- **VM 证据与重试**。每个试验使用独立目录和提交标识。SSH 重连先查询状态与退出码，
  证据缺失和求解失败分开记录。原始矩阵、存档、日志留在 VM，仓库记录配置身份、命令
  入口、结论和限制。
