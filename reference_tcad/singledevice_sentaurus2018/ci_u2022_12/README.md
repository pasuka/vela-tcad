# SingleDevice linear and saturation DG Id–Vg

The CTest drives both branches of `singledevice_idvg.cmd` through `sd-sim`.
It saves the equilibrium at `Vgs=-0.5 V, Vds=0 V`, solves the linear branch
at `Vds=0.1 V`, and reloads that equilibrium as a frozen state before
ramping the drain to `1.1 V` for the saturation branch. Both branches
sweep the gate to `2.2 V` using the original CMD step controls and its
21 `CurrentPlot` targets. The sidecar applies Newton and density-gradient
controls to the solved stages and leaves the Load stage as a frozen replay.
Transport uses electrostatic potential and referenced electron and hole
quasi-Fermi potentials. The CTest uses the outer DG iteration. The verification
driver also accepts `--dg-coupling monolithic_box` to solve the quantum
potential and transport equations in the same Newton step with the same
benchmarks and acceptance limits.

The sidecar includes the oxide-side DG interface coefficients recovered from
the T-2022.03-SP2 SingleDevice quantum Jacobian on the same mesh. The
half-jump offset is dimensionless. The reaction weight applies to the
insulator side of both Si/SiO2 and PolySilicon/SiO2 interfaces.
The semiconductor band reference comes from the PAR temperature law.
For SRH, the sidecar includes the electron quantum band shift in the
generation rate and electron emission term. The fixture pins the Scharfetter
electron and hole lifetime ceilings to 10 and 3 microseconds, respectively.
These settings reproduce the exported T-2022.03-SP2 substrate SRH rates with
the original doping, quantum potential and quasi-Fermi splitting.

`device.grd` and `device.dat` are the TDX export of the U-2022.12
SingleDevice mesh generated by the repository SDE script. The mesh has
3,548 vertices and 6,900 triangles. The reference curves are the existing
O-2018.06-SP2 linear and saturation Id–Vg curves, whose mesh had 3,584
vertices and 6,972 triangles. The comparison therefore includes mesh and version differences.
The checks use the established pointwise, low-current, threshold, swing,
and DIBL limits. Each branch checks KCL at three comparison points. The test
also checks the carrier and potential fields across the frozen reload,
self-consistent electron quantum potential on solved points, and the response
to the applied bias.

Use a Release build with the `sentaurus_u2022_12` constants profile,
oneMKL PARDISO support, and `VELA_ENABLE_SINGLEDEVICE_IDVG_CI=ON`.
The configured Python interpreter needs NumPy and h5py to check the
saved quantum states. Build the `sd-sim` and `vela_example_runner`
targets, then run the test from the build directory.

```text
ctest -R '^reference_u2022_singledevice_idvg_linear$' --no-tests=error --output-on-failure
```

The test retains its existing CTest name. The run writes `result.json`,
`comparison.csv` for the linear branch, `comparison_sat.csv` for the saturation
branch, and stage logs under
`reference-u2022-reports` in the build directory.
